## 018. 설정 창

### 1. 설정 창의 개요

[설정] 창은 **Windows의 각종 환경을 사용자에게 맞게 변경하는 통합 관리 창**입니다.

- 실행 방법
  - `⊞` + `I`
  - [시작] → [설정(톱니바퀴 아이콘)]
  - [시작] 단추 바로 가기 메뉴(`⊞` + `X`) → [설정]
  - 알림 센터 → [모든 설정]

#### 왜 [제어판]과 별도로 [설정]이 생겼을까?

기존의 제어판은 **PC 환경을 전제로 만들어진 관리 도구**였습니다.  
항목이 매우 많고, 태블릿처럼 터치로 조작하는 기기에서는 사용하기 불편했습니다.

[설정] 창은

- 자주 쓰는 항목을 **큰 아이콘과 범주 중심**으로 재구성하고
- 터치와 마우스 모두에서 편하게 조작할 수 있도록 설계되었습니다.

즉, [설정]은  
**제어판을 현대적인 사용 환경에 맞게 다시 정리한 창**입니다.

> 다만 일부 고급 기능은 여전히 제어판에서만 제공되므로, 두 창이 함께 존재합니다.

### 2. 설정 창의 주요 범주

| 범주 | 주요 내용 |
| --- | --- |
| 시스템 | 디스플레이, 소리, 알림, 전원 및 절전, 저장 공간, 정보 |
| 장치 | Bluetooth, 프린터 및 스캐너, 마우스, 입력, 자동 실행, USB |
| 전화 | 스마트폰 연결 |
| 네트워크 및 인터넷 | 상태, Wi-Fi, 이더넷, VPN, 데이터 사용량, 프록시 |
| 개인 설정 | 배경, 색, 잠금 화면, 테마, 글꼴, 시작, 작업 표시줄 |
| 앱 | 앱 및 기능, 기본 앱, 오프라인 지도, 시작 프로그램 |
| 계정 | 사용자 정보, 메일 및 계정, 로그인 옵션, 가족 및 다른 사용자, 동기화 |
| 시간 및 언어 | 날짜 및 시간, 지역, 언어, 음성 |
| 게임 | 게임 바, 캡처, 게임 모드 |
| 접근성 | 디스플레이, 커서 및 포인터, 돋보기, 고대비, 내레이터, 청각, 상호 작용 |
| 검색 | Windows 검색, 검색 권한 |
| 개인 정보 | 일반, 음성 명령, 위치, 카메라, 마이크 등 앱 권한 |
| 업데이트 및 보안 | Windows 업데이트, 백업, 복구, Windows 보안, 문제 해결 |

### 3. 설정 창의 검색 기능

설정 창 위쪽의 **검색 상자**에 원하는 항목의 이름을 입력하면,  
해당 설정 화면으로 바로 이동할 수 있습니다.

#### 왜 설정 창에도 검색이 필요할까?

설정 항목은 수백 개에 달하고, 어떤 범주에 속하는지 직관적으로 알기 어려운 경우가 많습니다.

예를 들어 "마우스 포인터 크기"는

- [장치] → [마우스] 인지
- [접근성] → [커서 및 포인터] 인지

헷갈릴 수 있습니다.

검색은 **범주를 몰라도 이름만으로 도달**할 수 있게 해 줍니다.

---

### 4. 제어판(Control Panel)

제어판은 **기존 Windows에서 사용하던 환경 설정 도구**입니다.

- 실행 방법 : 검색 상자에 '제어판' 입력, 또는 [실행(`⊞` + `R`)] → `control` 입력
- 보기 기준을 **범주 / 큰 아이콘 / 작은 아이콘**으로 변경할 수 있습니다.

| 주요 항목 | 기능 |
| --- | --- |
| 시스템 | 컴퓨터 사양, 컴퓨터 이름, 시스템 종류 확인 |
| 장치 관리자 | 하드웨어 목록 확인 및 드라이버 관리 |
| 프로그램 및 기능 | 프로그램 제거, Windows 기능 켜기/끄기 |
| 사용자 계정 | 계정 유형 변경, 암호 관리 |
| 네트워크 및 공유 센터 | 네트워크 상태 확인, 어댑터 설정 변경 |
| 색인 옵션 | 검색 색인 위치 관리 |
| 기본 프로그램 | 파일 형식별 연결 프로그램 지정 |
| 관리 도구 | 이벤트 뷰어, 서비스, 컴퓨터 관리 등 시스템 도구 모음 |

#### 설정 창 vs 제어판

| 구분 | 설정 창 | 제어판 |
| --- | --- | --- |
| 대상 | 일반 사용자용 주요 설정 | 세부·고급 설정 포함 |
| 구성 | 범주 + 큰 아이콘 (터치 친화적) | 항목 나열형 |
| 방향 | 앞으로 기능이 계속 이전됨 | 점차 축소되는 추세 |

---

### 한 줄 정리

[설정] 창은 **`⊞` + `I`로 실행하는 통합 환경 설정 창**으로,  
제어판의 기능을 범주 중심으로 재구성한 것이며 검색을 통해 원하는 항목으로 바로 이동할 수 있습니다.
