## 008. 파일 탐색기

### 1. 파일 탐색기의 개요

파일 탐색기는 컴퓨터에 저장된 **드라이브, 폴더, 파일을 계층 구조로 표시하고 관리**하는 프로그램입니다.

- 실행 방법 : `⊞` + `E`, 작업 표시줄의 파일 탐색기 아이콘, [시작] → [Windows 시스템] → [파일 탐색기]
- 파일과 폴더의 복사, 이동, 삭제, 이름 바꾸기, 속성 확인 등을 수행할 수 있습니다.

#### 왜 파일 탐색기가 필요할까?

컴퓨터에는 수만 개의 파일이 저장되어 있습니다.  
이것을 한 화면에 나열하면 원하는 파일을 절대 찾을 수 없습니다.

파일 탐색기는 저장 공간을 **드라이브 → 폴더 → 하위 폴더 → 파일** 형태의 **계층 구조(트리 구조)** 로 보여 줍니다.

즉, 파일 탐색기는  
**저장 공간을 체계적으로 나누어 탐색할 수 있게 하는 도구**입니다.

---

### 2. 폴더 계층 구조와 탐색

- 폴더 왼쪽의 **`>` 표시**를 클릭하면 하위 폴더가 펼쳐집니다.
- 하위 폴더가 펼쳐지면 표시가 **`∨`** 로 바뀝니다.
- 하위 폴더가 없는 폴더에는 아무 표시도 나타나지 않습니다.

| 키 | 기능 |
| --- | --- |
| `→` | 선택한 폴더가 닫혀 있으면 하위 폴더를 표시하고, 열려 있으면 첫 번째 하위 폴더를 선택합니다. |
| `←` | 선택한 폴더가 열려 있으면 닫고, 닫혀 있으면 상위 폴더를 선택합니다. |
| `숫자 키패드 *` | 선택한 폴더의 **모든 하위 폴더**를 표시합니다. |
| `숫자 키패드 +` | 선택한 폴더의 **한 단계 아래 하위 폴더**를 표시합니다. |
| `숫자 키패드 -` | 선택한 폴더를 축소합니다. |
| `Home` / `End` | 현재 창의 첫 번째 / 마지막 항목을 선택합니다. |
| `Backspace` | 상위 폴더로 이동합니다. |
| `Alt` + `←` / `→` | 뒤로 / 앞으로 이동합니다. |
| `Alt` + `↑` | 상위 폴더로 이동합니다. |
| `F4` | 주소 표시줄의 목록을 표시합니다. |

#### 왜 `*` 키와 `+` 키의 동작이 다를까?

폴더 구조가 깊을 때, 모든 하위 폴더를 한꺼번에 펼치면 화면이 너무 복잡해집니다.

그래서

- **한 단계씩 확인하고 싶을 때** → `+`
- **구조 전체를 한 번에 보고 싶을 때** → `*`

이렇게 상황에 따라 선택할 수 있도록 나누어 두었습니다.

---

### 3. 파일 탐색기의 리본 메뉴

| 탭 | 주요 기능 |
| --- | --- |
| 파일 | 새 창 열기, Windows PowerShell 열기, 폴더 및 검색 옵션 변경 |
| 홈 | 복사, 붙여넣기, 이동, 삭제, 이름 바꾸기, 새 폴더, 속성, 선택 |
| 공유 | 압축(ZIP), 전자 메일, 인쇄, 네트워크 공유, 고급 보안 설정 |
| 보기 | 탐색 창, 미리 보기 창, 자세히 창, 레이아웃, 정렬 기준, 표시/숨기기, 옵션 |

---

### 4. 파일 목록 보기 형식

[보기] 탭의 레이아웃에서 다음과 같이 선택할 수 있습니다.

| 형식 | 설명 |
| --- | --- |
| 아주 큰 아이콘 / 큰 아이콘 / 보통 아이콘 / 작은 아이콘 | 아이콘 크기를 조절하여 표시합니다. |
| 목록 | 아이콘과 파일 이름만 간단히 나열합니다. |
| 자세히 | 이름, 수정한 날짜, 유형, 크기 등의 정보를 열 형태로 표시합니다. |
| 타일 | 아이콘과 함께 파일 이름·유형·크기를 표시합니다. |
| 내용 | 파일 이름과 함께 수정한 날짜·크기 등을 한 줄로 표시합니다. |

#### 왜 보기 형식이 여러 가지일까?

찾으려는 기준이 상황마다 다르기 때문입니다.

- 사진처럼 **내용을 눈으로 확인해야 할 때** → 큰 아이콘
- 문서처럼 **날짜나 크기로 구분해야 할 때** → 자세히

즉, 보기 형식은 **무엇을 기준으로 파일을 찾을 것인가**에 따라 선택합니다.

---

### 5. 정렬 기준과 그룹화

- **정렬 기준** : 이름, 수정한 날짜, 유형, 크기, 만든 날짜 등으로 오름차순·내림차순 정렬
- **그룹화 기준** : 같은 조건을 가진 파일끼리 묶어서 표시
- '자세히' 보기에서는 **열 머리글을 클릭**하여 바로 정렬할 수 있습니다.

---

### 한 줄 정리

파일 탐색기는 **저장 장치의 내용을 계층 구조로 보여 주고 관리하는 도구**이며,  
`*`는 모든 하위 폴더, `+`는 한 단계 하위 폴더를 펼치고,  
`Backspace`와 `Alt` + `↑`로 상위 폴더로 이동합니다.
