## 013. 파일 / 폴더 - 선택 / 복사 / 이동 / 삭제

### 1. 파일과 폴더의 선택

| 선택 방법 | 조작 |
| --- | --- |
| 하나 선택 | 항목을 클릭합니다. |
| 연속된 항목 선택 | 첫 항목을 클릭한 후 마지막 항목을 **`Shift` + 클릭** 합니다. |
| 떨어져 있는 항목 선택 | **`Ctrl` + 클릭** 으로 하나씩 추가 선택합니다. |
| 모든 항목 선택 | **`Ctrl` + `A`** |
| 선택 반전 | [홈] 탭 → [선택] → [선택 영역 반전] |
| 드래그 선택 | 빈 공간에서 마우스를 드래그하여 사각형 범위 안의 항목을 선택합니다. |

#### 왜 `Shift`와 `Ctrl`을 구분해서 쓸까?

두 키는 선택의 **의미**가 다릅니다.

- **`Shift`** : "여기서 저기까지" → **범위** 선택
- **`Ctrl`** : "이것과 이것" → **개별** 추가 선택

파일이 정렬되어 있을 때는 범위 선택이 빠르고,  
흩어져 있을 때는 개별 선택이 정확합니다.

---

### 2. 복사(Copy)와 이동(Move)

| 구분 | 복사 | 이동 |
| --- | --- | --- |
| 결과 | 원본이 그대로 남고 사본이 생성됩니다. | 원본이 사라지고 위치만 바뀝니다. |
| 바로 가기 키 | `Ctrl` + `C` → `Ctrl` + `V` | `Ctrl` + `X` → `Ctrl` + `V` |

#### 드래그 앤 드롭으로 복사/이동하기

| 상황 | 그냥 드래그 | `Ctrl` + 드래그 | `Shift` + 드래그 |
| --- | --- | --- | --- |
| **같은 드라이브** 안에서 | 이동 | 복사 | 이동 |
| **다른 드라이브**로 | 복사 | 복사 | 이동 |

- `Ctrl` + `Shift` + 드래그 : **바로 가기 아이콘 만들기**
- 마우스 **오른쪽 단추로 드래그**하면 복사/이동/바로 가기 만들기를 메뉴에서 선택할 수 있습니다.

#### 왜 같은 드라이브에서는 "이동"이 기본일까?

같은 드라이브 안에서의 이동은 **실제로 데이터를 옮기는 것이 아니라, 파일이 속한 위치 정보만 바꾸는 작업**입니다.  
따라서 매우 빠르게 끝납니다.

반면 다른 드라이브로 옮기려면 **데이터를 실제로 읽어서 다시 써야 하므로**,  
사실상 복사와 같은 작업이 필요합니다.

그래서 Windows는

- 같은 드라이브 → 빠르고 자연스러운 **이동**
- 다른 드라이브 → 원본을 지키는 안전한 **복사**

를 기본 동작으로 정해 두었습니다.

### 3. 클립보드(Clipboard)

복사하거나 잘라낸 내용이 **임시로 저장되는 기억 장소**입니다.

- 클립보드의 내용은 **여러 번 붙여넣기 할 수 있습니다.**
- 새로운 내용을 복사하면 **이전 내용은 사라집니다.**
- 시스템을 종료하면 클립보드의 내용도 사라집니다.
- `⊞` + `V`를 누르면 **클립보드 기록**을 확인하고 이전 항목도 붙여넣을 수 있습니다.
- `Print Screen` 키를 누르면 화면 전체가 클립보드에 저장됩니다.

#### 왜 클립보드가 필요할까?

복사와 붙여넣기는 **서로 다른 프로그램 사이에서도** 이루어집니다.  
예를 들어 웹 브라우저에서 복사한 글을 워드에 붙여 넣을 수 있어야 합니다.

클립보드는 프로그램들이 **공통으로 사용하는 임시 보관 장소**이므로,  
프로그램 종류와 관계없이 데이터를 주고받을 수 있습니다.

### 4. 삭제(Delete)

| 방법 | 결과 |
| --- | --- |
| `Delete`, [홈] → [삭제], 휴지통으로 드래그 | 휴지통으로 이동 (복원 가능) |
| `Shift` + `Delete` | **휴지통을 거치지 않고 완전히 삭제** (복원 불가) |
| `Shift` + 휴지통으로 드래그 | 완전 삭제 |

#### 휴지통에 보관되지 않고 바로 삭제되는 경우

- USB 메모리, 네트워크 드라이브 등 **하드디스크가 아닌 곳의 파일**을 삭제한 경우
- **휴지통 크기보다 큰 파일**을 삭제한 경우
- 휴지통 속성에서 **'파일을 휴지통에 버리지 않고 삭제할 때 바로 제거'** 를 선택한 경우
- `Shift` + `Delete`로 삭제한 경우

#### 왜 USB의 파일은 휴지통에 가지 않을까?

휴지통은 **각 드라이브에 만들어지는 숨김 폴더**를 이용합니다.

USB 메모리는 다른 컴퓨터로 옮겨 다니는 저장 장치이므로,  
삭제한 파일을 계속 담아 두면 **용량만 차지하고 관리도 어렵습니다.**

그래서 이동식 저장 장치의 파일은 휴지통을 거치지 않고 곧바로 삭제됩니다.

### 5. 이름 바꾸기

| 방법 | 조작 |
| --- | --- |
| 바로 가기 키 | 항목 선택 후 `F2` |
| 메뉴 이용 | [홈] 탭 → [이름 바꾸기] |
| 마우스 이용 | 항목을 선택한 후 이름 부분을 한 번 더 클릭 |

- 같은 폴더 안에 **동일한 이름이 이미 있으면 변경할 수 없습니다.**
- 여러 항목을 선택한 후 이름을 바꾸면 **`이름 (1)`, `이름 (2)`** 형태로 순번이 붙습니다.
- **실행 중인 파일의 이름은 변경할 수 없습니다.**

---

### 한 줄 정리

**같은 드라이브에서 드래그하면 이동, 다른 드라이브로 드래그하면 복사**가 기본이며,  
`Ctrl`은 복사·`Shift`는 이동으로 강제할 수 있고,  
**USB·네트워크 드라이브의 파일과 `Shift` + `Delete`로 지운 파일은 휴지통에 보관되지 않습니다.**
