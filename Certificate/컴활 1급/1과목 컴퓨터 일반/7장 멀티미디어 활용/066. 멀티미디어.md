## 066. 멀티미디어

### 1. 멀티미디어의 개념

멀티미디어(Multimedia)는 **Multi(다중) + Media(매체)** 의 합성어로,  
**문자, 그림, 소리, 동영상, 애니메이션 등 여러 매체를 통합하여 표현하는 것**입니다.

---

### 2. 멀티미디어의 특징

| 특징 | 설명 |
| --- | --- |
| **디지털화(Digitalization)** | 아날로그 데이터를 **디지털로 변환**하여 컴퓨터가 처리할 수 있게 합니다. |
| **쌍방향성(Interactive)** | 정보를 일방적으로 전달하지 않고, **사용자와 상호 작용**합니다. |
| **비선형성(Non-Linear)** | 정해진 순서 없이 **사용자가 원하는 대로 이동**하며 이용합니다. |
| **통합성(Integration)** | 문자·그림·소리·동영상 등 **여러 매체를 하나로 통합**하여 처리합니다. |

#### 왜 디지털화가 멀티미디어의 출발점일까?

문자, 소리, 영상은 원래 성격이 전혀 다른 정보입니다.

그런데 모두 **0과 1의 숫자로 바꾸고 나면**, 컴퓨터 입장에서는 같은 데이터가 됩니다.

그 결과

- 하나의 기기에서 **함께 다룰 수 있고**
- 복사해도 **품질이 나빠지지 않으며**
- 편집과 전송이 자유로워집니다.

즉, 디지털화가 있었기에 **여러 매체의 통합(멀티미디어)** 이 가능해졌습니다.

#### 왜 비선형성이 중요할까?

책이나 영화 같은 전통 매체는 **처음부터 끝까지 정해진 순서**로 흘러갑니다.

반면 웹 페이지나 전자책은 링크를 통해  
**사용자가 원하는 부분으로 자유롭게 이동**할 수 있습니다.

이런 구조를 **하이퍼텍스트 / 하이퍼미디어**라고 하며,  
사용자가 정보 소비의 주도권을 갖게 된다는 점에서 큰 차이가 있습니다.

---

### 3. 멀티미디어 데이터의 종류

| 종류 | 대표 형식 |
| --- | --- |
| 텍스트 | TXT, DOC, PDF, HWP |
| 이미지 | BMP, JPG, GIF, PNG, TIF, WMF |
| 사운드 | WAV, MP3, MIDI, FLAC |
| 동영상 | AVI, MPEG, MP4, MOV, ASF, WMV |
| 애니메이션 | GIF, SWF |

---

### 4. 멀티미디어 데이터의 압축

멀티미디어 데이터는 용량이 매우 크므로 **압축이 필수적**입니다.

| 구분 | 설명 | 예 |
| --- | --- | --- |
| **손실 압축** | 사람이 잘 인지하지 못하는 정보를 **버려서** 용량을 크게 줄입니다. 원본으로 완전히 복원되지 않습니다. | JPG, MP3, MPEG |
| **비손실(무손실) 압축** | 정보를 **하나도 버리지 않고** 압축합니다. 원본으로 완전히 복원됩니다. | GIF, PNG, ZIP, FLAC |

#### 왜 손실 압축을 사용할까?

사람의 눈과 귀에는 한계가 있습니다.

- 아주 미세한 색상 차이는 구별하지 못하고
- 들리지 않는 주파수 대역의 소리도 있습니다.

손실 압축은 **어차피 인지하지 못하는 정보를 과감히 버립니다.**

그 결과 화질이나 음질의 체감 차이는 크지 않으면서  
**용량은 수십 분의 1로 줄어듭니다.**

다만 한 번 버린 정보는 되돌릴 수 없으므로,  
**편집을 반복할수록 품질이 계속 나빠진다는 점**은 주의해야 합니다.

---

### 5. 멀티미디어 관련 용어

| 용어 | 설명 |
| --- | --- |
| **코덱(CODEC)** | 데이터를 **압축(Coder)하고 복원(Decoder)** 하는 기술 또는 프로그램입니다. |
| **스트리밍(Streaming)** | 파일을 모두 내려받기 전에 **받으면서 바로 재생**하는 기술입니다. |
| **하이퍼텍스트** | 링크를 통해 다른 문서로 이동할 수 있는 문서입니다. |
| **하이퍼미디어** | 하이퍼텍스트에 이미지·소리·동영상이 포함된 형태입니다. |
| **VOD(주문형 비디오)** | 사용자가 원하는 시간에 원하는 영상을 보는 서비스입니다. |
| **키오스크(Kiosk)** | 공공장소에 설치되어 정보를 제공하는 무인 안내 시스템입니다. |
| **가상 현실(VR)** | 컴퓨터로 만든 가상 공간을 체험하는 기술입니다. |
| **CAI** | 컴퓨터를 이용한 교육 시스템입니다. |
| **화상 회의 시스템(VCS)** | 멀리 떨어진 사람들이 영상과 음성으로 회의하는 시스템입니다. |

#### 왜 코덱이 필요할까?

압축된 파일은 **압축 규칙을 알아야만** 원래대로 복원할 수 있습니다.

코덱은 그 규칙을 구현한 프로그램입니다.

동영상이 재생되지 않고 **소리만 나오거나 화면이 검게 나오는 현상**은  
대부분 **해당 코덱이 설치되어 있지 않기 때문**입니다.

같은 `.avi` 확장자라도 내부에 사용된 코덱은 서로 다를 수 있으므로,  
**확장자와 코덱은 별개의 개념**이라는 점을 기억해야 합니다.

---

### 한 줄 정리

멀티미디어의 4대 특징은 **디지털화·쌍방향성·비선형성·통합성**이며,  
**JPG·MP3·MPEG는 손실 압축, GIF·PNG는 무손실 압축**이고,  
코덱은 **압축과 복원을 담당하는 기술**입니다.
