# 01. R 개요

## R의 개념

**R**은 통계 분석과 데이터 시각화를 위해 만들어진 프로그래밍 언어이자 분석 환경이다.

R은 일반적인 프로그래밍 언어처럼 변수, 함수, 조건문, 반복문을 사용할 수 있지만,
가장 큰 특징은 **통계 분석과 데이터 처리에 특화되어 있다**는 점이다.

```markdown
R = 통계 분석과 데이터 시각화에 특화된 프로그래밍 언어
```

예를 들어 R을 사용하면 다음과 같은 작업을 할 수 있다.

```r
mean(c(80, 90, 100))
```

위 코드는 80, 90, 100의 평균을 구하는 코드다.

즉, R은 복잡한 통계 분석을 비교적 간단한 명령어로 수행할 수 있게 해준다.

---

## R의 특징

| 특징         | 설명                              |
| ---------- | ------------------------------- |
| 통계 분석 특화   | 평균, 분산, 회귀분석, 검정 등 통계 기능이 풍부하다  |
| 데이터 시각화 강점 | 그래프와 차트를 쉽게 만들 수 있다             |
| 오픈소스       | 무료로 사용할 수 있고 확장성이 높다            |
| 다양한 패키지    | 분석 목적에 맞는 패키지를 설치해 기능을 확장할 수 있다 |
| 벡터 기반 연산   | 여러 데이터를 한 번에 계산하는 벡터 연산에 강하다    |
| 대화형 분석 가능  | 명령어를 입력하고 즉시 결과를 확인할 수 있다       |

시험에서는 이렇게 이해하면 된다.

```markdown
R은 오픈소스 기반의 통계 분석 및 데이터 시각화 언어이며,
다양한 패키지를 통해 분석 기능을 확장할 수 있다.
```

# 02. R 기본 문법

## 1) 변수 할당

R에서는 값을 변수에 저장할 수 있다.

대표적인 할당 연산자는 `<-` 이다.

```r
x <- 10
y <- 20
x + y
```

결과는 다음과 같다.

```r
30
```

R에서는 `=`도 사용할 수 있지만, 일반적으로 R 문법에서는 `<-`를 많이 사용한다.

| 연산자  | 의미               | 예시        |
| ---- | ---------------- | --------- |
| `<-` | 왼쪽 변수에 오른쪽 값을 저장 | `x <- 10` |
| `=`  | 변수에 값 저장         | `x = 10`  |
| `->` | 오른쪽 변수에 왼쪽 값을 저장 | `10 -> x` |

시험에서는 보통 `<-`를 변수 할당 연산자로 기억하면 된다.

```markdown
R의 대표적인 변수 할당 연산자는 `<-`이다.
```

---

## 2) 주석

R에서 주석은 `#`을 사용한다.

```r
# 평균 계산
mean(c(10, 20, 30))
```

주석은 코드 실행에 영향을 주지 않고, 설명을 적기 위해 사용한다.

```markdown
R의 주석은 `#`으로 작성한다.
```

---

## 3) 기본 출력

R에서는 변수명을 입력하면 값이 출력된다.

```r
x <- 10
x
```

또는 `print()` 함수를 사용할 수 있다.

```r
print(x)
```

| 방법        | 설명           |
| --------- | ------------ |
| 변수명 입력    | 해당 변수의 값을 출력 |
| `print()` | 값을 명시적으로 출력  |

# 03. R의 기본 자료형

R에서 자료형은 값의 종류를 의미한다.

대표적인 자료형은 다음과 같다.

| 자료형       | 설명   | 예시              |
| --------- | ---- | --------------- |
| numeric   | 숫자형  | `10`, `3.14`    |
| integer   | 정수형  | `10L`           |
| character | 문자형  | `"hello"`       |
| logical   | 논리형  | `TRUE`, `FALSE` |
| complex   | 복소수형 | `1+2i`          |

---

## 1) 숫자형, numeric

숫자형은 정수나 실수를 표현한다.

```r
x <- 10
y <- 3.14
```

R에서는 일반 숫자를 기본적으로 numeric으로 처리한다.

```markdown
numeric = 숫자 데이터를 표현하는 자료형
```

---

## 2) 정수형, integer

정수형은 숫자 뒤에 `L`을 붙여 표현한다.

```r
x <- 10L
```

시험에서 깊게 나오지는 않지만, `10L`은 정수형이라는 점을 알아두면 된다.

```markdown
integer = 정수형 데이터, 숫자 뒤에 L을 붙여 표현
```

---

## 3) 문자형, character

문자형은 따옴표로 감싼다.

```r
name <- "ADsP"
```

문자형은 이름, 주소, 범주형 값 등을 표현할 때 사용한다.

```markdown
character = 문자 데이터를 표현하는 자료형
```

---

## 4) 논리형, logical

논리형은 참과 거짓을 표현한다.

```r
x <- TRUE
y <- FALSE
```

조건문이나 비교 연산에서 자주 사용된다.

```r
10 > 5
```

결과는 다음과 같다.

```r
TRUE
```

```markdown
logical = TRUE 또는 FALSE 값을 가지는 자료형
```

---

## 자료형 확인 함수

R에서는 자료형을 확인할 때 `class()`나 `typeof()`를 사용할 수 있다.

```r
x <- 10
class(x)
typeof(x)
```

| 함수               | 설명         |
| ---------------- | ---------- |
| `class()`        | 객체의 클래스 확인 |
| `typeof()`       | 내부 자료형 확인  |
| `is.numeric()`   | 숫자형 여부 확인  |
| `is.character()` | 문자형 여부 확인  |
| `is.logical()`   | 논리형 여부 확인  |

시험에서는 `class()`를 많이 기억하면 된다.

```markdown
class() 함수는 객체의 자료형 또는 클래스를 확인할 때 사용한다.
```

# 04. R의 연산자

## 1) 산술 연산자

산술 연산자는 숫자 계산에 사용된다.

| 연산자   | 의미   | 예시        |
| ----- | ---- | --------- |
| `+`   | 더하기  | `3 + 2`   |
| `-`   | 빼기   | `3 - 2`   |
| `*`   | 곱하기  | `3 * 2`   |
| `/`   | 나누기  | `3 / 2`   |
| `^`   | 거듭제곱 | `3 ^ 2`   |
| `%%`  | 나머지  | `5 %% 2`  |
| `%/%` | 몫    | `5 %/% 2` |

예시:

```r
5 %% 2
```

결과:

```r
1
```

```r
5 %/% 2
```

결과:

```r
2
```

시험에서는 `%/%`와 `%%`를 헷갈리지 않는 것이 중요하다.

```markdown
%% = 나머지
%/% = 몫
```

---

## 2) 비교 연산자

비교 연산자는 두 값을 비교하여 TRUE 또는 FALSE를 반환한다.

| 연산자  | 의미     |
| ---- | ------ |
| `==` | 같다     |
| `!=` | 같지 않다  |
| `>`  | 크다     |
| `<`  | 작다     |
| `>=` | 크거나 같다 |
| `<=` | 작거나 같다 |

예시:

```r
10 == 10
```

결과:

```r
TRUE
```

```r
10 != 5
```

결과:

```r
TRUE
```

---

## 3) 논리 연산자

논리 연산자는 조건을 결합할 때 사용한다.

| 연산자 | 의미       |        |
| --- | -------- | ------ |
| `&` | 그리고, AND |        |
| `   | `        | 또는, OR |
| `!` | 부정, NOT  |        |

예시:

```r
10 > 5 & 3 > 1
```

결과:

```r
TRUE
```

```r
10 > 5 | 3 < 1
```

결과:

```r
TRUE
```

```markdown
& = 둘 다 참이면 TRUE
| = 둘 중 하나라도 참이면 TRUE
! = TRUE와 FALSE를 반대로 바꿈
```

# 05. R의 주요 자료구조

R에서 가장 중요한 부분은 자료구조다.

ADsP 시험에서는 특히 다음 자료구조의 차이를 잘 알아야 한다.

```markdown
벡터, 행렬, 배열, 데이터프레임, 리스트
```

| 자료구조   |    차원 | 데이터 타입       | 특징            |
| ------ | ----: | ------------ | ------------- |
| 벡터     |   1차원 | 동일 타입        | 가장 기본적인 자료구조  |
| 행렬     |   2차원 | 동일 타입        | 행과 열로 구성      |
| 배열     |   다차원 | 동일 타입        | 3차원 이상 가능     |
| 데이터프레임 |   2차원 | 열마다 다른 타입 가능 | 표 형태 데이터      |
| 리스트    | 자유 구조 | 서로 다른 타입 가능  | 여러 객체를 하나로 묶음 |

이 표는 시험 직전에 반드시 외워야 한다.

```markdown
벡터·행렬·배열은 동일한 자료형만 가능하다.
데이터프레임은 열마다 서로 다른 자료형을 가질 수 있다.
리스트는 서로 다른 형태의 객체를 함께 저장할 수 있다.
```

---

## 1) 벡터, Vector

### 벡터의 개념

**벡터**는 R에서 가장 기본이 되는 자료구조다.

여러 개의 값을 1차원으로 저장한다.

```r
x <- c(10, 20, 30)
```

여기서 `c()`는 combine의 의미로, 여러 값을 하나로 묶을 때 사용한다.

```markdown
벡터 = 같은 자료형의 값을 1차원으로 저장하는 자료구조
```

---

### 벡터의 특징

| 특징       | 설명                  |
| -------- | ------------------- |
| 1차원 구조   | 한 줄로 나열된 데이터        |
| 동일 자료형   | 하나의 벡터에는 같은 자료형만 저장 |
| `c()` 사용 | 여러 값을 결합하여 벡터 생성    |
| 벡터 연산 가능 | 여러 값을 한 번에 계산 가능    |

예시:

```r
x <- c(1, 2, 3)
x + 10
```

결과:

```r
11 12 13
```

R은 벡터 기반 언어이기 때문에 각 원소에 자동으로 연산이 적용된다.

---

### 벡터 인덱싱

R의 인덱스는 **1부터 시작**한다.

```r
x <- c(10, 20, 30)
x[1]
```

결과:

```r
10
```

```markdown
R의 인덱스는 0이 아니라 1부터 시작한다.
```

이건 시험에서도 자주 헷갈리는 포인트다.

---

## 2) 행렬, Matrix

### 행렬의 개념

**행렬**은 2차원 자료구조로, 행과 열로 구성된다.

```r
m <- matrix(1:6, nrow = 2, ncol = 3)
```

결과 형태:

```r
     [,1] [,2] [,3]
[1,]   1    3    5
[2,]   2    4    6
```

```markdown
행렬 = 같은 자료형의 데이터를 행과 열로 저장하는 2차원 자료구조
```

---

### 행렬의 특징

| 특징            | 설명                 |
| ------------- | ------------------ |
| 2차원 구조        | 행과 열로 구성           |
| 동일 자료형        | 모든 원소가 같은 자료형이어야 함 |
| `matrix()` 사용 | 행렬 생성 함수           |
| 인덱싱           | `[행, 열]` 형태로 접근    |

예시:

```r
m[1, 2]
```

1행 2열의 값을 가져온다.

---

## 3) 배열, Array

### 배열의 개념

**배열**은 2차원 이상의 다차원 자료구조다.

행렬이 2차원이라면, 배열은 3차원 이상도 표현할 수 있다.

```r
arr <- array(1:12, dim = c(2, 3, 2))
```

```markdown
배열 = 같은 자료형의 데이터를 다차원으로 저장하는 자료구조
```

---

### 배열의 특징

| 특징           | 설명                 |
| ------------ | ------------------ |
| 다차원 구조       | 2차원 이상 가능          |
| 동일 자료형       | 모든 원소가 같은 자료형이어야 함 |
| `array()` 사용 | 배열 생성 함수           |
| 차원 지정        | `dim`으로 차원 설정      |

시험에서는 행렬과 배열의 차이를 이렇게 기억하면 된다.

```markdown
행렬 = 2차원
배열 = 다차원
```

---

## 4) 데이터프레임, Data Frame

### 데이터프레임의 개념

**데이터프레임**은 행과 열로 구성된 2차원 표 형태의 자료구조다.

R에서 실제 데이터 분석을 할 때 가장 많이 사용하는 자료구조다.

```r
df <- data.frame(
  name = c("kim", "lee", "park"),
  score = c(90, 80, 70),
  pass = c(TRUE, TRUE, FALSE)
)
```

```markdown
데이터프레임 = 열마다 서로 다른 자료형을 가질 수 있는 2차원 표 형태 자료구조
```

---

### 데이터프레임의 특징

| 특징                | 설명                      |
| ----------------- | ----------------------- |
| 2차원 구조            | 행과 열로 구성                |
| 열마다 다른 자료형 가능     | 숫자형, 문자형, 논리형을 함께 저장 가능 |
| 실제 분석에 자주 사용      | CSV, 엑셀 형태 데이터와 유사      |
| `data.frame()` 사용 | 데이터프레임 생성 함수            |

데이터프레임은 행렬과 비슷해 보이지만 가장 큰 차이가 있다.

| 구분    | 행렬         | 데이터프레임        |
| ----- | ---------- | ------------- |
| 차원    | 2차원        | 2차원           |
| 자료형   | 전체가 동일 자료형 | 열마다 다른 자료형 가능 |
| 사용 목적 | 수치 계산 중심   | 실제 데이터 분석 중심  |

시험에서는 이 차이가 중요하다.

```markdown
행렬은 모든 원소가 같은 자료형이어야 하고,
데이터프레임은 열마다 다른 자료형을 가질 수 있다.
```

---

## 5) 리스트, List

### 리스트의 개념

**리스트**는 서로 다른 자료형이나 서로 다른 구조의 객체를 하나로 묶을 수 있는 자료구조다.

```r
lst <- list(
  name = "kim",
  score = c(90, 80, 70),
  info = data.frame(age = c(20, 21), gender = c("M", "F"))
)
```

리스트 안에는 숫자, 문자, 벡터, 데이터프레임, 또 다른 리스트까지 들어갈 수 있다.

```markdown
리스트 = 서로 다른 자료형과 자료구조를 함께 저장할 수 있는 자료구조
```

---

### 리스트의 특징

| 특징           | 설명                         |
| ------------ | -------------------------- |

# 07. 조건문과 반복문

## 1) 조건문

조건문은 조건에 따라 다른 코드를 실행할 때 사용한다.

```r
score <- 80

if (score >= 60) {
  print("pass")
} else {
  print("fail")
}
```

| 문법        | 설명             |
| --------- | -------------- |
| `if`      | 조건이 참이면 실행     |
| `else`    | 조건이 거짓이면 실행    |
| `else if` | 여러 조건을 순서대로 검사 |

시험에서는 문법 자체보다 조건문이 **조건에 따라 실행 흐름을 나누는 구조**라는 점을 이해하면 된다.

```markdown
조건문 = 조건의 참과 거짓에 따라 실행할 코드를 선택하는 문법
```

---

## 2) 반복문

반복문은 같은 작업을 여러 번 수행할 때 사용한다.

### for문

```r
for (i in 1:5) {
  print(i)
}
```

`1`부터 `5`까지 반복하면서 값을 출력한다.

### while문

```r
i <- 1

while (i <= 5) {
  print(i)
  i <- i + 1
}
```

조건이 참인 동안 반복한다.

| 반복문     | 설명                  |
| ------- | ------------------- |
| `for`   | 정해진 범위나 원소를 순서대로 반복 |
| `while` | 조건이 참인 동안 반복        |

```markdown
for문은 반복 횟수나 대상이 정해져 있을 때 사용하고,
while문은 조건이 참인 동안 반복할 때 사용한다.
```

# 09. 패키지

## 패키지의 개념

**패키지**는 R의 기능을 확장하기 위한 함수와 데이터의 묶음이다.

R은 기본 기능만으로도 통계 분석을 할 수 있지만,
패키지를 설치하면 더 다양한 분석과 시각화를 수행할 수 있다.

```markdown
패키지 = R의 기능을 확장하는 함수와 데이터의 묶음
```

---

## 패키지 설치와 사용

패키지를 설치할 때는 `install.packages()`를 사용한다.

```r
install.packages("ggplot2")
```

설치한 패키지를 사용할 때는 `library()`를 사용한다.

```r
library(ggplot2)
```

| 함수                   | 설명           |
| -------------------- | ------------ |
| `install.packages()` | 패키지 설치       |
| `library()`          | 설치된 패키지 불러오기 |

시험에서는 이 둘의 차이를 명확히 기억하면 된다.

```markdown
install.packages() = 패키지 설치
library() = 패키지 로드
```

`summary()`는 데이터의 요약 통계를 확인하는 함수이고,
`str()`은 데이터 구조를 확인하는 함수이며,
`head()`는 데이터의 앞부분을 확인하는 함수이다.

`read.csv()`는 CSV 파일을 읽어 데이터프레임으로 불러오는 함수이고,
`write.csv()`는 데이터를 CSV 파일로 저장하는 함수이다.

`install.packages()`는 패키지를 설치하는 함수이고,
`library()`는 설치된 패키지를 불러오는 함수이다.
