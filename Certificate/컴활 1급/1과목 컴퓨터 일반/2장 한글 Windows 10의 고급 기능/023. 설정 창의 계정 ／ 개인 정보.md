## 023. 설정 창의 계정 / 개인 정보

### 1. 사용자 계정의 개요

Windows는 한 대의 컴퓨터를 여러 사람이 사용할 수 있도록 **계정별로 환경과 자료를 분리**합니다.

- 각 계정은 **자신만의 바탕 화면, 문서 폴더, 즐겨찾기, 설정**을 가집니다.

#### 왜 계정을 나눌까?

한 컴퓨터를 여러 사람이 쓸 때 계정이 하나뿐이라면

- 서로의 파일이 뒤섞이고
- 개인 정보가 그대로 노출되며
- 한 사람이 바꾼 설정이 모두에게 적용됩니다.

계정은 **사용자별로 독립된 작업 공간을 만들어 주는 단위**입니다.

---

### 2. 계정의 유형

| 유형 | 권한 |
| --- | --- |
| **관리자(Administrator)** | 시스템 설정 변경, 프로그램 설치/제거, 다른 사용자 계정 관리 등 **모든 작업**이 가능합니다. |
| **표준 사용자(Standard User)** | 자신의 계정 설정과 파일만 관리할 수 있으며, **시스템 전체에 영향을 주는 작업은 할 수 없습니다.** |

- 시스템에는 **최소 한 개 이상의 관리자 계정**이 있어야 합니다.
- 표준 사용자가 시스템 변경을 시도하면 **관리자 암호를 요구**합니다.

#### 왜 평소에는 표준 사용자로 쓰는 것이 안전할까?

관리자 계정으로 로그인한 상태에서는 **실행되는 프로그램도 관리자 권한을 갖게 됩니다.**

만약 악성 프로그램이 실행되면 시스템 전체를 마음대로 바꿀 수 있습니다.

표준 사용자로 사용하면 **중요한 변경이 시도될 때 반드시 암호를 물어보므로**,  
사용자가 인지하지 못한 변경을 막을 수 있습니다.

---

### 3. 계정의 종류(로그인 방식)

| 종류 | 특징 |
| --- | --- |
| **Microsoft 계정** | 이메일 주소로 로그인하며, 설정·테마·암호·OneDrive가 **여러 기기에서 동기화**됩니다. Microsoft Store 이용이 가능합니다. |
| **로컬 계정** | 해당 컴퓨터에서만 사용하는 계정으로, 동기화와 Store 이용에 제한이 있습니다. |

---

### 4. 로그인 옵션

| 항목 | 설명 |
| --- | --- |
| Windows Hello 얼굴 / 지문 | 생체 인식으로 로그인합니다. |
| **PIN** | 숫자로 된 간단한 로그인 번호이며, **해당 기기에서만 사용**됩니다. |
| 사진 암호 | 사진 위에 그리는 동작(원, 직선, 탭)으로 로그인합니다. |
| 암호 | 문자 기반의 일반 암호입니다. |
| 동적 잠금 | 연결된 휴대폰이 멀어지면 자동으로 화면을 잠급니다. |

#### 왜 PIN이 암호보다 안전하다고 할까?

암호는 Microsoft 계정 전체에 연결되어 있어, 유출되면 **다른 기기와 서비스까지 위험**해집니다.

반면 PIN은 **그 컴퓨터에서만 유효**합니다.  
유출되더라도 해당 기기에 물리적으로 접근하지 못하면 사용할 수 없습니다.

즉, PIN은 짧아서 편리한 동시에 **피해 범위가 기기 하나로 제한된다**는 점에서 더 안전합니다.

---

### 5. 가족 및 다른 사용자

| 항목 | 설명 |
| --- | --- |
| 가족 추가 | 자녀 계정을 추가하고 사용 시간·앱·웹 사이트를 제한합니다. |
| 다른 사용자 추가 | 이 PC를 함께 사용할 계정을 추가합니다. |
| 계정 유형 변경 | 표준 사용자 ↔ 관리자 로 변경합니다. |
| 계정 제거 | 계정과 해당 계정의 데이터를 삭제합니다. |

- **현재 로그인 중인 계정은 삭제할 수 없습니다.**

---

### 6. 개인 정보

앱이 접근할 수 있는 정보와 장치를 제어하는 범주입니다.

| 항목 | 설명 |
| --- | --- |
| 일반 | 광고 ID, 언어 목록 접근, 앱 실행 추적 등을 설정합니다. |
| 음성 명령 | 온라인 음성 인식 사용 여부를 지정합니다. |
| 진단 및 피드백 | Microsoft에 보낼 진단 데이터의 범위를 지정합니다. |
| 활동 기록 | 작업 기록(타임라인) 저장 및 동기화 여부를 지정합니다. |
| **앱 권한** | 위치, 카메라, 마이크, 알림, 연락처, 일정, 파일 시스템 등에 대한 **앱별 접근 권한**을 지정합니다. |

#### 왜 앱마다 권한을 따로 관리할까?

앱이 필요 이상으로 많은 정보에 접근하면 **개인 정보 유출 위험**이 커집니다.

예를 들어 계산기 앱이 카메라나 위치 정보에 접근할 이유는 없습니다.

권한 관리는 **"이 앱이 이 기능을 정말 필요로 하는가"** 를 사용자가 직접 판단하고,  
불필요한 접근을 차단할 수 있게 해 줍니다.

---

### 한 줄 정리

계정은 **관리자와 표준 사용자**로 나뉘며 시스템에는 관리자 계정이 최소 하나 필요하고,  
**PIN은 해당 기기에서만 유효**하여 암호보다 피해 범위가 좁으며,  
[개인 정보]에서는 **앱별 접근 권한**을 제어합니다.
