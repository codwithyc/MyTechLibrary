## 042. 보조기억장치

### 1. 보조기억장치의 개요

보조기억장치는 **주기억장치의 부족한 용량을 보완하고, 데이터를 영구적으로 저장**하기 위한 장치입니다.

- **비휘발성**이므로 전원이 꺼져도 저장된 내용이 유지됩니다.
- 주기억장치보다 **용량이 크고 가격이 저렴**하지만, **처리 속도는 느립니다.**
- CPU가 **직접 접근할 수 없으며**, 반드시 주기억장치를 거쳐야 합니다.

#### 왜 보조기억장치가 따로 필요할까?

주기억장치(RAM)는 빠르지만 두 가지 한계가 있습니다.

- **휘발성** : 전원이 꺼지면 내용이 사라집니다.
- **가격과 용량** : 비싸서 큰 용량을 확보하기 어렵습니다.

프로그램과 데이터를 오래 보관하려면 **전원과 무관하게 유지되는 저장 공간**이 필요합니다.  
그 역할을 하는 것이 보조기억장치입니다.

즉,

- **주기억장치** : 지금 실행할 내용을 올려 두는 작업대
- **보조기억장치** : 오래 보관하는 창고

#### 왜 CPU는 보조기억장치에 직접 접근하지 못할까?

CPU는 나노초 단위로 동작하는데, 하드디스크는 밀리초 단위로 동작합니다.  
속도 차이가 수백만 배에 이릅니다.

CPU가 직접 접근한다면 대부분의 시간을 **기다리는 데 소비**하게 됩니다.

그래서 실행에 필요한 내용을 먼저 **주기억장치로 옮긴 뒤 처리**하는 구조를 사용합니다.

### 2. 하드디스크(HDD, Hard Disk Drive)

**자기 원판(Platter)** 을 고속으로 회전시키고 **헤드(Head)** 를 이동시켜 데이터를 읽고 쓰는 장치입니다.

**구성 요소**

| 용어 | 설명 |
| --- | --- |
| **트랙(Track)** | 원판 위에 동심원 형태로 그려진 저장 공간입니다. |
| **섹터(Sector)** | 트랙을 일정한 크기로 나눈 **최소 저장 단위**입니다. |
| **실린더(Cylinder)** | 여러 원판의 **같은 번호를 가진 트랙을 모은 것**입니다. |
| **클러스터(Cluster)** | 여러 개의 섹터를 묶은 것으로, **운영체제가 파일을 저장하는 단위**입니다. |
| **헤드(Head)** | 데이터를 읽고 쓰는 부분입니다. |

**접근 시간(Access Time)**

**접근 시간 = 탐색 시간(Seek Time) + 회전 지연 시간(Latency Time) + 전송 시간(Transfer Time)**

| 용어 | 설명 |
| --- | --- |
| 탐색 시간 | 헤드가 원하는 트랙까지 이동하는 시간 |
| 회전 지연 시간 | 원판이 회전하여 원하는 섹터가 헤드 아래로 오는 시간 |
| 전송 시간 | 데이터를 실제로 주고받는 시간 |

#### 왜 실린더라는 개념을 쓸까?

하드디스크에는 원판이 여러 장 겹쳐 있고, 헤드도 원판마다 하나씩 있습니다.  
그런데 **모든 헤드는 하나의 팔에 붙어 함께 움직입니다.**

즉, 1번 원판의 5번 트랙에 헤드가 있으면, 2번·3번 원판의 헤드도 자동으로 5번 트랙에 있습니다.

이때 **헤드를 움직이지 않고도 접근할 수 있는 트랙들의 묶음**이 실린더입니다.

같은 실린더에 데이터를 모아 두면 **탐색 시간이 줄어들어** 속도가 빨라집니다.

### 3. SSD(Solid State Drive)

**플래시 메모리(반도체)** 를 이용한 저장 장치입니다.

| 특징 | 설명 |
| --- | --- |
| 구동부 없음 | 원판이나 헤드 같은 **기계적 부품이 없습니다.** |
| 빠른 속도 | 탐색 시간이 거의 없어 하드디스크보다 훨씬 빠릅니다. |
| 저소음·저발열 | 회전하는 부품이 없어 소음과 진동이 없습니다. |
| 충격에 강함 | 물리적 충격에 상대적으로 안전합니다. |
| 전력 소모 적음 | 노트북 배터리 사용 시간이 늘어납니다. |
| 단점 | 같은 용량 대비 **가격이 비싸고**, 쓰기 횟수에 **수명 제한**이 있습니다. |

#### 왜 SSD가 하드디스크보다 훨씬 빠를까?

하드디스크의 속도를 결정하는 가장 큰 요인은 **헤드의 물리적 이동**과 **원판의 회전**입니다.  
아무리 빨라도 물체가 실제로 움직여야 하므로 한계가 있습니다.

SSD는 전기 신호만으로 데이터를 읽고 쓰므로, **이동 시간 자체가 존재하지 않습니다.**

특히 여기저기 흩어진 작은 파일을 읽을 때 차이가 극적으로 벌어집니다.  
같은 이유로 **SSD에는 조각 모음이 필요 없습니다.**

### 4. 그 밖의 보조기억장치

| 장치 | 특징 |
| --- | --- |
| CD-ROM | 약 650MB~700MB를 저장하며 읽기만 가능합니다. |
| CD-R | 한 번만 기록할 수 있습니다. |
| CD-RW | 여러 번 지우고 다시 기록할 수 있습니다. |
| DVD | 약 4.7GB(단면 단층)를 저장하며, CD보다 용량이 큽니다. |
| Blu-ray | 약 25GB(단층) 이상을 저장하며, 고화질 영상에 사용됩니다. |
| USB 메모리 | 플래시 메모리 기반의 휴대용 저장 장치입니다. |
| 외장 하드디스크 | USB로 연결하는 휴대용 대용량 저장 장치입니다. |
| 메모리 카드(SD 등) | 카메라, 스마트폰 등에 사용되는 소형 플래시 메모리입니다. |

### 5. RAID(Redundant Array of Independent Disks)

**여러 개의 하드디스크를 묶어 하나의 디스크처럼 사용**하는 기술입니다.

| 레벨 | 방식 | 특징 |
| --- | --- | --- |
| **RAID 0 (스트라이핑)** | 데이터를 여러 디스크에 나누어 저장 | **속도가 빠르고 용량 손실이 없지만, 디스크 하나만 고장 나도 전체 데이터를 잃습니다.** |
| **RAID 1 (미러링)** | 같은 데이터를 두 디스크에 똑같이 저장 | **안정성이 높지만 실제 사용 가능한 용량은 절반**입니다. |
| RAID 5 | 데이터와 패리티 정보를 분산 저장 | 속도와 안정성을 균형 있게 확보하며, 디스크 1개 고장까지 복구 가능합니다. |
| RAID 1+0 | 미러링 + 스트라이핑 | 속도와 안정성을 모두 확보하지만 비용이 큽니다. |

#### 왜 스트라이핑이 빠를까?

RAID 0은 하나의 파일을 **여러 디스크에 나누어 동시에 읽고 씁니다.**

디스크가 2개면 두 곳에서 동시에 데이터를 가져오므로, 이론상 속도가 2배가 됩니다.

하지만 데이터가 여러 디스크에 나뉘어 있으므로,  
**하나라도 고장 나면 파일 전체를 복원할 수 없습니다.**

#### 왜 미러링은 안전할까?

RAID 1은 같은 데이터를 **두 디스크에 동일하게 기록**합니다.

한쪽이 고장 나도 다른 쪽에 온전한 사본이 있으므로 데이터를 잃지 않습니다.

대신 두 배의 디스크를 쓰면서 사용 가능한 용량은 절반이므로,  
**용량을 희생하여 안정성을 얻는 방식**입니다.

---

### 한 줄 정리

보조기억장치는 **비휘발성으로 데이터를 영구 저장하지만 CPU가 직접 접근할 수 없으며**,  
하드디스크의 접근 시간은 **탐색 시간 + 회전 지연 시간 + 전송 시간**,  
RAID는 **0(스트라이핑=속도), 1(미러링=안정성)** 로 구분해서 기억하면 됩니다.
