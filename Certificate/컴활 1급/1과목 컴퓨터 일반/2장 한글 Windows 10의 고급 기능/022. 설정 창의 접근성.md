## 022. 설정 창의 접근성

### 1. 접근성의 개요

접근성은 **신체에 장애가 있거나 컴퓨터 사용이 불편한 사용자도 컴퓨터를 원활하게 사용할 수 있도록 돕는 기능**입니다.

- 실행 방법 : [설정] → [접근성], `⊞` + `U`

#### 왜 접근성 기능이 운영체제에 기본으로 들어 있을까?

컴퓨터는 특정 사용자만을 위한 도구가 아닙니다.  
시력이 약하거나, 손을 자유롭게 쓰기 어렵거나, 소리를 듣기 어려운 사용자도 동일하게 사용할 수 있어야 합니다.

만약 이런 기능을 별도 프로그램으로 설치해야 한다면,  
**설치 자체가 어려운 사용자는 컴퓨터를 시작조차 할 수 없습니다.**

그래서 접근성 기능은 **운영체제에 기본 내장**되어 있습니다.

---

### 2. 시각 관련 기능

| 기능 | 설명 |
| --- | --- |
| 디스플레이 | 텍스트 크기 조정, 앱과 텍스트 크기 확대, 애니메이션 효과 표시 여부를 지정합니다. |
| 커서 및 포인터 | 마우스 포인터의 크기와 색, 텍스트 커서의 두께를 변경합니다. |
| **돋보기** | 화면의 일부를 확대하여 표시합니다. (`⊞` + `+` 로 실행, `⊞` + `Esc` 로 종료) |
| **색상 필터** | 색맹·색약 사용자를 위해 화면의 색을 변환합니다. |
| **고대비** | 배경과 글자의 색 대비를 높여 글자를 뚜렷하게 표시합니다. |
| **내레이터** | 화면의 내용을 음성으로 읽어 줍니다. (`⊞` + `Ctrl` + `Enter`) |

**돋보기의 보기 방식**

- **전체 화면** : 화면 전체를 확대
- **렌즈** : 마우스 포인터 주변만 확대
- **도킹** : 화면 위쪽 일부 영역에 확대 화면을 표시

#### 왜 돋보기에 여러 보기 방식이 있을까?

화면 전체를 확대하면 글자는 잘 보이지만 **전체 배치를 파악하기 어렵습니다.**

- 세밀하게 봐야 할 때 → **전체 화면**
- 위치를 유지하면서 일부만 크게 보고 싶을 때 → **렌즈**
- 원본 화면과 확대 화면을 함께 봐야 할 때 → **도킹**

즉, 확대의 정도가 아니라 **"무엇을 함께 볼 것인가"** 에 따라 방식이 나뉩니다.

### 3. 청각 관련 기능

| 기능 | 설명 |
| --- | --- |
| 오디오 | 시스템 볼륨을 조절하고, **소리 알림을 시각적으로 표시**하도록 설정합니다. |
| 모노 오디오 | 좌우 스테레오 채널을 하나로 합쳐 출력합니다. |
| 청각 자막 | 소리 대신 자막으로 정보를 전달하며, 자막의 글꼴·색·배경을 지정합니다. |

#### 왜 모노 오디오 기능이 필요할까?

스테레오 음향은 왼쪽과 오른쪽에 서로 다른 소리를 보냅니다.

한쪽 귀만 사용하는 사용자는 **한쪽 채널의 소리를 아예 듣지 못하게 됩니다.**

모노 오디오는 두 채널을 하나로 합쳐 출력하므로,  
한쪽 이어폰만 사용해도 **모든 소리를 들을 수 있습니다.**

### 4. 상호 작용(입력) 관련 기능

| 기능 | 설명 |
| --- | --- |
| **음성 명령** | 음성으로 컴퓨터를 조작하고 문자를 입력합니다. |
| **키보드** | 화상 키보드, 고정 키, 토글 키, 필터 키를 설정합니다. |
| **마우스** | 숫자 키패드로 마우스 포인터를 움직이는 마우스 키를 설정합니다. |
| 시선 제어 | 시선 추적 장치를 이용해 컴퓨터를 조작합니다. |

**키보드 관련 세부 기능**

| 기능 | 설명 |
| --- | --- |
| 화상 키보드 | 화면에 키보드를 표시하여 마우스나 터치로 입력합니다. |
| **고정 키(Sticky Keys)** | `Ctrl`, `Alt`, `Shift`를 **누르고 있지 않아도 눌린 상태로 유지**합니다. (`Shift` 5번) |
| **토글 키(Toggle Keys)** | `Caps Lock`, `Num Lock`, `Scroll Lock`을 누를 때 **소리로 알려 줍니다.** (`Num Lock` 5초) |
| **필터 키(Filter Keys)** | 짧게 눌리거나 반복해서 눌린 키 입력을 **무시**합니다. (오른쪽 `Shift` 8초) |

#### 왜 고정 키 기능이 필요할까?

`Ctrl` + `Alt` + `Delete` 같은 조합은 **여러 키를 동시에 눌러야** 합니다.

손을 자유롭게 쓰기 어려운 사용자에게는 이 동작 자체가 큰 장벽입니다.

고정 키는 조합 키를 **한 번씩 순서대로 눌러도 동시에 누른 것처럼 인식**하게 하여,  
한 손가락만으로도 모든 단축키를 사용할 수 있게 합니다.

#### 왜 필터 키가 필요할까?

손 떨림이 있는 경우, 키를 한 번 누르려 해도 **여러 번 입력되는 문제**가 생깁니다.

필터 키는 **너무 짧은 입력이나 지나치게 빠른 반복 입력을 무시**하여,  
의도한 입력만 정확히 전달되도록 합니다.

---

### 한 줄 정리

접근성은 **`⊞` + `U`로 실행**하며,  
**돋보기·고대비·내레이터(시각)**, **모노 오디오·자막(청각)**,  
**고정 키·토글 키·필터 키(입력)** 로 나누어 이해하면 정리하기 쉽습니다.
