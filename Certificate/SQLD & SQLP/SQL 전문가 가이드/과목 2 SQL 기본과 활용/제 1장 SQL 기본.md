# 제1절 관계형 데이터베이스 개요

* 관계형 데이터베이스는 데이터를 **테이블(Table) 형태로 저장하고 테이블끼리 관계를 맺어 관리**하는 데이터베이스다.
* 테이블의 한 줄을 **행(Row)**, 하나의 항목을 **칼럼(Column)**이라고 한다.
* **기본키(PK)**는 각 행을 유일하게 구별하는 값이고, **외래키(FK)**는 다른 테이블과 관계를 맺기 위해 사용하는 값이다.
* SQL은 관계형 데이터베이스에서 데이터를 **조회·입력·수정·삭제**하기 위한 언어다.
* `SELECT`는 조회, `INSERT`는 입력, `UPDATE`는 수정, `DELETE`는 삭제에 사용한다.
* SQL은 원하는 결과를 **어떻게 처리할지보다 무엇을 원하는지 선언하는 언어**라고 이해하면 된다.

# 제2절 SELECT 문

* `SELECT`는 테이블에서 원하는 데이터를 **조회하는 명령어**다.
* `SELECT *`는 테이블의 **모든 칼럼을 조회**한다.
* 필요한 칼럼만 지정하면 해당 칼럼만 조회할 수 있다.
* `DISTINCT`는 조회 결과에서 **중복된 값을 제거**한다.
* 칼럼에 별칭(Alias)을 지정하면 조회 결과의 칼럼명을 원하는 이름으로 표시할 수 있다.
* 산술 연산자를 사용해 조회하면서 값을 계산할 수도 있다.
* NULL이 포함된 산술 연산은 일반적으로 **결과도 NULL**이 된다.

# 제3절 함수

* 함수는 입력된 값을 받아 **가공한 결과를 반환하는 기능**이다.
* 문자 함수에는 `UPPER`, `LOWER`, `SUBSTR`, `LENGTH`, `REPLACE` 등이 있다.
* `UPPER`는 대문자, `LOWER`는 소문자로 변환한다.
* `SUBSTR`은 문자열 일부를 잘라내고, `LENGTH`는 문자열 길이를 구한다.
* `REPLACE`는 문자열의 특정 내용을 다른 값으로 바꾼다.
* 숫자 함수에는 `ROUND`, `TRUNC`, `MOD` 등이 있다.
* `ROUND`는 반올림, `TRUNC`는 버림, `MOD`는 나머지를 구한다.
* 날짜 함수에는 `SYSDATE`, `ADD_MONTHS` 등이 있다.
* `TO_CHAR`, `TO_DATE`, `TO_NUMBER`는 **데이터 형식을 변환**할 때 사용한다.
* `NVL(A, B)`는 A가 NULL이면 B를 반환한다.
* 집계 함수에는 `COUNT`, `SUM`, `AVG`, `MAX`, `MIN` 등이 있다.
* `COUNT(*)`는 행 전체를 세고, `COUNT(칼럼)`은 해당 칼럼이 NULL인 행을 제외한다.
* `SUM`, `AVG`, `MAX`, `MIN`도 일반적으로 NULL을 제외하고 계산한다.

# 제4절 WHERE 절

* `WHERE`는 조회할 행 중에서 **조건에 맞는 행만 골라내는 역할**을 한다.
* `=`는 같다, `<>`는 다르다, `>`, `<`, `>=`, `<=`는 크기 비교에 사용한다.
* `BETWEEN A AND B`는 **A 이상 B 이하의 범위**를 의미한다.
* `IN(A, B, C)`는 여러 값 중 하나와 일치하는지 확인한다.
* `LIKE`는 문자열의 일부 패턴을 검색할 때 사용한다.
* `%`는 글자 수와 상관없이 여러 문자를 의미하고, `_`는 한 글자를 의미한다.
* NULL은 `= NULL`로 비교하지 않고 `IS NULL`, `IS NOT NULL`을 사용한다.
* `AND`는 모든 조건을 만족해야 하고, `OR`는 하나 이상 만족하면 된다.
* `NOT`은 조건을 반대로 만든다.
* 일반적으로 `AND`가 `OR`보다 먼저 계산되므로 복잡한 조건에서는 괄호를 사용하는 것이 안전하다.

# 제5절 GROUP BY, HAVING 절

* `GROUP BY`는 같은 값을 가진 행들을 **하나의 그룹으로 묶는 기능**이다.
* 그룹별로 `COUNT`, `SUM`, `AVG`, `MAX`, `MIN` 같은 집계 함수를 사용할 수 있다.
* `WHERE`는 **그룹으로 묶기 전에 개별 행에 조건**을 적용한다.
* `HAVING`은 **GROUP BY로 묶은 결과에 조건**을 적용한다.
* 쉽게 말하면 `WHERE = 행 조건`, `HAVING = 그룹 조건`이다.
* GROUP BY에 없는 일반 칼럼을 SELECT 절에서 그대로 조회하면 일반적으로 오류가 발생한다.
* `ROLLUP`은 지정한 그룹을 기준으로 **소계와 전체 합계**를 만든다.
* `CUBE`는 가능한 모든 조합의 소계와 전체 합계를 만든다.
* `GROUPING SETS`는 필요한 그룹 조합만 직접 선택해 집계한다.
* `GROUPING()`은 NULL이 실제 데이터의 NULL인지, ROLLUP/CUBE가 만든 집계 행인지 구분하는 데 사용한다.
* `GROUPING(칼럼) = 0`이면 일반 데이터, `1`이면 집계로 생성된 행이다.

# 제6절 ORDER BY 절

* `ORDER BY`는 조회 결과를 **원하는 순서로 정렬**한다.
* `ASC`는 오름차순이고 기본값이다.
* `DESC`는 내림차순이다.
* 여러 칼럼을 순서대로 지정하면 첫 번째 칼럼으로 정렬한 뒤 같은 값 안에서 다음 칼럼으로 정렬한다.
* SELECT 절에서 지정한 별칭을 ORDER BY에서 사용할 수 있다.
* ORDER BY는 조회 결과를 만들어낸 뒤 **가장 마지막 단계에서 정렬**한다고 이해하면 쉽다.
* 데이터가 많을수록 정렬 작업은 많은 메모리나 디스크 공간을 사용할 수 있으므로 성능에 영향을 줄 수 있다.

# 제7절 조인

* 조인은 **두 개 이상의 테이블에서 관련된 데이터를 연결해 조회하는 것**이다.
* 일반적으로 PK와 FK처럼 서로 관계가 있는 칼럼을 기준으로 조인한다.
* `EQUI JOIN`은 `=` 조건을 이용해 두 테이블을 연결한다.
* `NON-EQUI JOIN`은 `>`, `<`, `BETWEEN` 등 `=` 이외의 조건으로 연결한다.
* 조인 조건이 없으면 두 테이블의 모든 행이 서로 조합되는 **Cartesian Product**가 발생한다.
* A 테이블이 N건, B 테이블이 M건이면 Cartesian Product는 최대 `N × M`건이 된다.
* 조인은 SQL에 작성된 테이블 순서와 실제 DB가 처리하는 조인 순서가 반드시 같지는 않다.
* 실제 조인 순서는 옵티마이저가 실행계획을 통해 결정할 수 있다.

# 제8절 표준 조인

* `INNER JOIN`은 양쪽 테이블에서 **조인 조건이 일치하는 행만 반환**한다.
* `LEFT OUTER JOIN`은 왼쪽 테이블의 모든 행을 유지하고, 오른쪽에 일치하는 데이터가 없으면 오른쪽 칼럼을 NULL로 반환한다.
* `RIGHT OUTER JOIN`은 오른쪽 테이블의 모든 행을 유지한다.
* `FULL OUTER JOIN`은 양쪽 테이블의 모든 행을 유지하고 일치하지 않는 쪽은 NULL로 채운다.
* `CROSS JOIN`은 조인 조건 없이 양쪽 데이터를 모두 조합하는 Cartesian Product다.
* `NATURAL JOIN`은 두 테이블에서 **이름이 같은 칼럼을 자동으로 찾아 조인**한다.
* `ON`은 `A.ID = B.ID`처럼 조인 조건을 직접 작성한다.
* `USING(칼럼)`은 양쪽 테이블에 같은 이름의 조인 칼럼이 있을 때 사용할 수 있다.
* `USING(A.ID = B.ID)`처럼 조건식을 작성하는 것은 잘못된 사용법이다.
* OUTER JOIN 문제에서는 `ON` 조건과 `WHERE` 조건의 위치에 따라 결과가 달라질 수 있다.
* `ON`은 **두 테이블을 붙일지 결정하는 조건**, `WHERE`는 **조인이 끝난 결과에서 행을 제거하는 조건**이라고 이해하면 쉽다.

# 장 요약

* 관계형 DB → 데이터를 테이블로 저장하고 관계로 연결한다.
* `SELECT` → 데이터 조회
* `DISTINCT` → 중복 제거
* 함수 → 데이터를 가공
* `WHERE` → 개별 행 조건
* `GROUP BY` → 같은 값끼리 묶기
* `HAVING` → 그룹 결과 조건
* `ORDER BY` → 정렬
* `JOIN` → 여러 테이블 연결
* `INNER JOIN` → 양쪽 일치 데이터만
* `LEFT JOIN` → 왼쪽 모두 유지
* `RIGHT JOIN` → 오른쪽 모두 유지
* `FULL JOIN` → 양쪽 모두 유지
* `CROSS JOIN` → 전부 × 전부
* `ON` → 조인 조건
* `USING` → 같은 이름의 조인 칼럼 사용
* NULL 비교 → `IS NULL`, `IS NOT NULL`
* 집계 함수 → `COUNT`, `SUM`, `AVG`, `MAX`, `MIN`
* `WHERE = 묶기 전`, `HAVING = 묶은 후`
* `GROUPING() = 0 일반행 / 1 집계행`
