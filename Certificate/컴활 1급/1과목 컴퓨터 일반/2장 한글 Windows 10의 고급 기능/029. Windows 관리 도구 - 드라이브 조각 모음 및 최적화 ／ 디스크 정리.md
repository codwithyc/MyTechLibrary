## 029. Windows 관리 도구 - 드라이브 조각 모음 및 최적화 / 디스크 정리

### 1. 드라이브 조각 모음 및 최적화

디스크에 **여기저기 흩어져 저장된 파일 조각을 모아, 연속된 공간에 다시 배치**하는 기능입니다.

- 실행 방법 : [시작] → [Windows 관리 도구] → [드라이브 조각 모음 및 최적화]
- 드라이브의 **접근 속도가 향상**됩니다.
- **디스크의 용량이 늘어나는 것은 아닙니다.**
- 예약 실행(매일 / 매주 / 매월)을 설정할 수 있습니다.

#### 왜 파일이 조각나서 저장될까?

디스크에 파일을 저장하고 삭제하는 일이 반복되면, **중간중간 빈 공간**이 생깁니다.

새 파일을 저장할 때 한 덩어리로 들어갈 공간이 없으면,  
운영체제는 파일을 **여러 조각으로 나누어 빈 자리마다 나눠 저장**합니다.

이것을 **단편화(Fragmentation)** 라고 합니다.

#### 왜 조각이 나면 느려질까?

하드디스크는 **자기 원판을 회전시키고 헤드를 움직여** 데이터를 읽습니다.

파일이 흩어져 있으면 헤드가 **여기저기 이동해야 하므로** 읽는 시간이 길어집니다.

조각 모음은 흩어진 조각을 **연속된 위치로 모아** 헤드 이동을 줄여 줍니다.

즉, 조각 모음은  
**저장 공간을 늘리는 작업이 아니라, 읽는 경로를 짧게 만드는 작업**입니다.

---

### 2. 조각 모음을 할 수 없는 대상

다음 대상은 조각 모음을 수행할 수 없습니다.

- **CD-ROM / DVD-ROM 드라이브**
- **네트워크 드라이브**
- Windows가 지원하지 않는 파일 시스템으로 포맷된 드라이브
- 시스템이 독점적으로 사용 중인 드라이브

**SSD의 경우**

- SSD는 물리적으로 헤드가 움직이지 않으므로 **조각 모음의 효과가 없습니다.**
- 오히려 불필요한 쓰기가 발생해 **수명을 줄일 수 있습니다.**
- Windows 10은 SSD에 대해 조각 모음 대신 **TRIM(최적화)** 을 수행합니다.

#### 왜 SSD는 조각 모음이 필요 없을까?

하드디스크가 느려지는 이유는 **헤드가 물리적으로 이동해야 하기 때문**입니다.

SSD는 반도체(플래시 메모리)에 저장하므로, 데이터가 어디에 있든 **접근 시간이 거의 동일**합니다.

따라서 조각을 모아도 속도가 빨라지지 않고,  
쓰기 횟수만 늘어나 **오히려 손해**입니다.

---

### 3. 디스크 정리

디스크에서 **불필요한 파일을 찾아 삭제하여 여유 공간을 확보**하는 기능입니다.

- 실행 방법 : [시작] → [Windows 관리 도구] → [디스크 정리]

**삭제 가능한 파일**

| 항목 | 설명 |
| --- | --- |
| 다운로드한 프로그램 파일 | 웹 페이지에서 자동으로 내려받은 ActiveX 컨트롤 등 |
| 임시 인터넷 파일 | 웹 페이지를 빠르게 열기 위해 저장해 둔 파일 |
| 휴지통 | 삭제되어 휴지통에 보관된 파일 |
| 임시 파일 | 프로그램이 작업 중 만든 `.TMP` 파일 |
| 미리 보기 사진(썸네일) | 파일 미리 보기를 위해 저장한 이미지 |
| 전송 최적화 파일 | 업데이트 배포에 사용된 파일 |
| 시스템 파일 정리 | 이전 Windows 설치 파일, Windows 업데이트 정리 등 |

#### 조각 모음 vs 디스크 정리

| 구분 | 드라이브 조각 모음 | 디스크 정리 |
| --- | --- | --- |
| 목적 | **속도 향상** | **공간 확보** |
| 방식 | 흩어진 파일 조각을 모음 | 불필요한 파일을 삭제 |
| 용량 변화 | 늘어나지 않음 | 늘어남 |

> 시험에서 **"조각 모음을 하면 디스크 용량이 늘어난다"** 는 자주 나오는 오답입니다.

### 4. 그 밖의 Windows 관리 도구

| 도구 | 기능 |
| --- | --- |
| 이벤트 뷰어 | 시스템에서 발생한 오류, 경고, 정보 등의 로그를 확인합니다. |
| 컴퓨터 관리 | 작업 스케줄러, 이벤트 뷰어, 공유 폴더, 장치 관리자, 디스크 관리, 서비스를 한곳에서 관리합니다. |
| 서비스 | 백그라운드에서 실행되는 서비스를 시작·중지·설정합니다. |
| 시스템 정보 | 하드웨어 리소스, 구성 요소, 소프트웨어 환경 정보를 확인합니다. |
| 시스템 구성(msconfig) | 부팅 옵션, 서비스, 시작 프로그램을 설정합니다. |
| 리소스 모니터 | CPU, 메모리, 디스크, 네트워크 사용 현황을 실시간으로 확인합니다. |
| 성능 모니터 | 시스템 성능 데이터를 수집하고 분석합니다. |
| 레지스트리 편집기(regedit) | Windows의 설정 정보가 저장된 레지스트리를 직접 편집합니다. |
| 작업 스케줄러 | 지정한 시간이나 조건에 프로그램이 자동 실행되도록 예약합니다. |

#### 왜 레지스트리를 함부로 수정하면 안 될까?

레지스트리는 **하드웨어, 소프트웨어, 사용자 설정 등 Windows의 거의 모든 구성 정보**가 저장된 데이터베이스입니다.

여기에 잘못된 값이 들어가면

- 프로그램이 실행되지 않거나
- 부팅 자체가 불가능해질 수 있습니다.

수정이 꼭 필요하다면 **반드시 먼저 내보내기(백업)** 를 해 두어야 합니다.

---

### 한 줄 정리

**조각 모음은 흩어진 파일을 모아 속도를 높이는 작업(용량은 늘지 않음)**,  
**디스크 정리는 불필요한 파일을 지워 공간을 확보하는 작업**이며,  
**CD-ROM·네트워크 드라이브는 조각 모음 대상이 아니고 SSD는 조각 모음이 필요 없습니다.**
