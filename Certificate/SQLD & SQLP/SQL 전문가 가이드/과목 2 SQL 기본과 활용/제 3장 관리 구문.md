## 제1절 DML

* DML(Data Manipulation Language)은 **테이블에 저장된 데이터를 조회·입력·수정·삭제하는 명령어**다.
* 쉽게 말하면 **“테이블 안의 데이터를 직접 만지는 명령어”**라고 이해하면 된다.
* `SELECT`는 데이터를 **조회**한다.
* `INSERT`는 새로운 데이터를 **추가**한다.
* `UPDATE`는 기존 데이터를 **수정**한다.
* `DELETE`는 기존 데이터를 **삭제**한다.
* `INSERT INTO 테이블 VALUES (...)` 형태로 새로운 행을 추가할 수 있다.
* `UPDATE 테이블 SET 칼럼 = 값 WHERE 조건` 형태로 원하는 데이터를 수정한다.
* `DELETE FROM 테이블 WHERE 조건` 형태로 원하는 데이터를 삭제한다.
* `UPDATE`, `DELETE`에서 `WHERE`를 생략하면 **테이블의 모든 행이 대상**이 될 수 있으므로 주의해야 한다.
* DML 작업은 일반적으로 트랜잭션에 포함되며 `COMMIT` 또는 `ROLLBACK`으로 확정하거나 취소할 수 있다.
* 쉽게 외우면 `SELECT = 보기`, `INSERT = 넣기`, `UPDATE = 바꾸기`, `DELETE = 지우기`다.

## 제2절 TCL

* TCL(Transaction Control Language)은 **트랜잭션을 제어하는 명령어**다.
* 쉽게 말하면 **“지금까지 한 작업을 저장할지, 취소할지 결정하는 명령어”**다.
* `COMMIT`은 지금까지 수행한 변경사항을 **확정**한다.
* `ROLLBACK`은 아직 COMMIT하지 않은 변경사항을 **취소하고 원래 상태로 되돌린다.**
* `SAVEPOINT`는 트랜잭션 중간에 **되돌아갈 지점을 저장**한다.
* `ROLLBACK TO SAVEPOINT명`을 사용하면 전체 트랜잭션이 아니라 특정 저장 지점까지만 되돌릴 수 있다.
* COMMIT이 수행된 변경사항은 일반적인 ROLLBACK으로 다시 취소할 수 없다.
* 트랜잭션은 여러 SQL을 **하나의 논리적 작업 단위**로 묶는 개념이다.
* 쉽게 외우면 `COMMIT = 저장`, `ROLLBACK = 취소`, `SAVEPOINT = 중간 저장점`이다.

## 제3절 DDL

* DDL(Data Definition Language)은 **테이블 같은 데이터베이스 구조를 만들고 변경하는 명령어**다.
* 쉽게 말하면 **“데이터가 아니라 데이터가 들어갈 그릇을 만드는 명령어”**다.
* `CREATE`는 테이블, 뷰, 인덱스 등의 객체를 **생성**한다.
* `ALTER`는 기존 데이터베이스 객체의 구조를 **변경**한다.
* `DROP`은 데이터베이스 객체 자체를 **삭제**한다.
* `TRUNCATE`는 테이블 구조는 남기고 **테이블의 전체 데이터를 빠르게 삭제**한다.
* `RENAME`은 객체 이름을 변경할 때 사용한다.
* `CREATE TABLE`은 새로운 테이블 구조를 만든다.
* `ALTER TABLE`을 이용해 칼럼을 추가·수정·삭제할 수 있다.
* `DROP TABLE`은 **데이터와 테이블 구조를 함께 제거**한다.
* `TRUNCATE TABLE`은 테이블 구조는 유지하지만 **전체 행을 제거**한다.
* Oracle에서 DDL을 수행하면 일반적으로 **암묵적인 COMMIT이 발생**하므로 DML처럼 ROLLBACK해서 되돌릴 수 없다고 이해하면 된다.
* `DELETE`와 `TRUNCATE`를 구별해야 한다.
* `DELETE`는 DML이라 `WHERE` 사용이 가능하고 ROLLBACK할 수 있지만, `TRUNCATE`는 DDL이며 전체 데이터를 제거하고 일반적으로 ROLLBACK할 수 없다.
* 쉽게 외우면 `CREATE = 만들기`, `ALTER = 구조 바꾸기`, `DROP = 그릇 삭제`, `TRUNCATE = 내용 전체 비우기`다.

## 제4절 DCL

* DCL(Data Control Language)은 **사용자의 권한을 관리하는 명령어**다.
* 쉽게 말하면 **“누가 무엇을 할 수 있는지 정하는 명령어”**다.
* `GRANT`는 사용자에게 권한을 **부여**한다.
* `REVOKE`는 사용자에게 부여한 권한을 **회수**한다.
* 권한은 크게 **시스템 권한과 객체 권한**으로 구분할 수 있다.
* 시스템 권한은 `CREATE TABLE`, `CREATE SESSION`처럼 데이터베이스 전체 기능과 관련된 권한이다.
* 객체 권한은 특정 테이블에 대한 `SELECT`, `INSERT`, `UPDATE`, `DELETE` 같은 권한이다.
* `GRANT SELECT ON 학생 TO USER1`은 USER1에게 학생 테이블 조회 권한을 주는 의미다.
* `REVOKE SELECT ON 학생 FROM USER1`은 해당 조회 권한을 회수하는 의미다.
* `WITH GRANT OPTION`을 사용하면 받은 객체 권한을 **다른 사용자에게 다시 부여할 수 있다.**
* 쉽게 외우면 `GRANT = 권한 주기`, `REVOKE = 권한 뺏기`다.

## 장 요약

* DML → **데이터를 만짐**
* `SELECT` → 조회
* `INSERT` → 입력
* `UPDATE` → 수정
* `DELETE` → 삭제
* TCL → **트랜잭션 제어**
* `COMMIT` → 확정
* `ROLLBACK` → 취소
* `SAVEPOINT` → 중간 저장점
* DDL → **구조를 만듦/변경**
* `CREATE` → 생성
* `ALTER` → 변경
* `DROP` → 객체 삭제
* `TRUNCATE` → 전체 데이터 빠르게 제거
* DCL → **권한 관리**
* `GRANT` → 권한 부여
* `REVOKE` → 권한 회수
* `DELETE` → DML / WHERE 가능 / ROLLBACK 가능
* `TRUNCATE` → DDL / 전체 삭제 / 일반적으로 ROLLBACK 불가
