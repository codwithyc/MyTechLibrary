## 012. 파일과 폴더

### 1. 파일(File)

파일은 **서로 관련 있는 정보를 하나로 묶어 저장한 단위**입니다.

- 파일 이름은 **파일명 + `.` + 확장자** 형태로 구성됩니다. (예: `보고서.docx`)
- 확장자는 파일의 **종류(형식)** 를 나타내며, 이를 통해 어떤 프로그램으로 열지가 결정됩니다.

#### 파일 이름 규칙

- 최대 **255자**까지 지정할 수 있으며, 공백을 포함할 수 있습니다.
- 다음 문자는 **파일 이름에 사용할 수 없습니다.**

  **`\` `/` `:` `*` `?` `"` `<` `>` `|`** (총 9개)

- 하나의 폴더 안에서는 **같은 이름의 파일을 만들 수 없습니다.**
- 파일 이름에서 **영문자의 대소문자는 구분하지 않습니다.**

#### 왜 특정 문자는 파일 이름에 쓸 수 없을까?

이 문자들은 운영체제가 이미 다른 의미로 사용하고 있기 때문입니다.

| 문자 | 운영체제에서의 의미 |
| --- | --- |
| `\` , `/` | 경로 구분자 |
| `:` | 드라이브 구분자 (예: `C:`) |
| `*` , `?` | 만능 문자(와일드카드) |
| `"` | 문자열 구분 |
| `<` , `>` | 입출력 방향 지정 |
| `|` | 파이프(명령 연결) |

만약 파일 이름에 이 문자를 허용하면, 운영체제가 **경로인지 이름인지 구분할 수 없게 됩니다.**

### 3. 폴더(Folder)

폴더는 **서로 관련 있는 파일을 모아서 관리하기 위한 공간**입니다.

- 폴더 안에는 파일뿐 아니라 **하위 폴더**도 만들 수 있습니다. (계층 구조)
- 폴더에도 파일과 동일한 이름 규칙이 적용됩니다.
- 폴더의 속성에서는 **크기, 포함된 파일 수, 하위 폴더 수, 만든 날짜, 특성(읽기 전용·숨김), 공유, 사용자 지정** 등을 확인·변경할 수 있습니다.

#### 왜 폴더를 계층 구조로 만들까?

파일이 늘어날수록 한 공간에 모아 두면 찾기가 어려워집니다.

계층 구조는 파일을 **주제별로 나누고, 다시 그 안에서 세분화**할 수 있게 해 줍니다.  
덕분에 파일 수가 아무리 많아져도 **탐색 경로만 따라가면 원하는 파일에 도달**할 수 있습니다.

### 4. 파일/폴더의 속성

파일이나 폴더를 마우스 오른쪽 단추로 클릭 → [속성]에서 확인할 수 있습니다.

| 탭 | 내용 |
| --- | --- |
| 일반 | 이름, 파일 형식, 연결 프로그램, 위치, 크기, 디스크 할당 크기, 만든/수정한/액세스한 날짜, 특성(읽기 전용·숨김) |
| 보안 | 사용자별 접근 권한을 설정합니다. (NTFS 파일 시스템에서 사용) |
| 자세히 | 제목, 태그, 만든 이 등의 추가 정보를 확인합니다. |
| 이전 버전 | 복원 지점에 저장된 이전 버전으로 되돌립니다. |

#### 왜 "크기"와 "디스크 할당 크기"가 다를까?

디스크는 파일을 **클러스터(할당 단위)** 라는 일정한 덩어리 단위로 저장합니다.

예를 들어 클러스터 크기가 4KB인데 파일이 1KB라면,  
실제로는 4KB의 공간을 차지하게 됩니다.

즉,

- **크기** : 파일 자체의 실제 용량
- **디스크 할당 크기** : 디스크에서 실제로 차지하는 공간

이 차이 때문에 작은 파일이 많을수록 **낭비되는 공간이 커집니다.**

---

### 5. 파일과 폴더의 특성

| 특성 | 설명 |
| --- | --- |
| 읽기 전용 | 내용을 읽을 수만 있고 수정할 수 없습니다. |
| 숨김 | 파일 탐색기에서 보이지 않게 합니다. (폴더 옵션에서 표시 가능) |
| 보관 | 백업 대상 여부를 표시합니다. |

---

### 한 줄 정리

파일은 **이름 + 확장자**로 구성되며 최대 255자까지 지정할 수 있고,  
**`\ / : * ? " < > |` 9개 문자는 사용할 수 없으며**,  
같은 폴더 안에서는 동일한 이름을 사용할 수 없습니다.
