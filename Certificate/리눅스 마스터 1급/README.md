# 리눅스 마스터 1급

###### 2026 이기적 리눅스마스터 1급(1·2차) 기본서 — 김윤수, 최정현 / 영진닷컴

리눅스는 전 세계 클라우드 서버의 70% 이상, 스마트폰의 80% 이상, 슈퍼컴퓨터 상위 500대 전부를 움직이는 운영체제입니다.  
백엔드 개발을 하든 인프라를 다루든, 결국 코드가 실제로 도는 곳은 리눅스 위입니다.

그동안 리눅스를 "필요할 때 명령어를 검색해서 쓰는 도구"로만 다뤄 왔는데,  
이번에는 **커널이 무엇을 하고, 파일 시스템이 어떻게 구성되며, 프로세스와 네트워크가 어떤 원리로 동작하는지**를  
자격증 커리큘럼을 따라가며 체계적으로 정리해 보려고 합니다.

## 정리 방식

- **처음 보는 사람도 이해할 수 있게** 씁니다. 명령어를 나열하기 전에 "이 개념이 왜 필요한가"부터 설명합니다.
- 개념은 **Mermaid 다이어그램**으로 그려서 구조가 눈에 보이게 합니다. (GitHub에서 바로 렌더링됩니다)
- 명령어는 **문법 → 주요 옵션 표 → 실제 실행 예시**의 순서로 정리합니다.
- 2차(실기)가 작업식이므로, 단순 암기가 아니라 **직접 쳐 볼 수 있는 형태**로 남깁니다.
- 각 문서 끝에는 **시험 포인트**와 **한 줄 정리**를 둡니다.

> **시험 기준 리눅스 버전**  
> 필기 : 커널 4.x 이상 (레드햇 계열 RHEL/Rocky Linux 8, 데비안 계열 Ubuntu 18.04 이상)  
> 실기 : Rocky Linux 8.8
