## 007. 시작 메뉴

### 1. 시작 메뉴의 개요

시작 메뉴는 Windows에 설치된 **모든 앱과 주요 기능에 접근하는 출발점**입니다.

- 실행 방법 : 작업 표시줄의 [시작] 단추 클릭, `⊞` 키, `Ctrl` + `Esc`
- 왼쪽에는 사용자 계정·문서·사진·설정·전원 아이콘이, 가운데에는 앱 목록이, 오른쪽에는 타일이 표시됩니다.

#### 왜 시작 메뉴가 필요할까?

바탕 화면에는 자주 쓰는 항목만 올려 둡니다.  
하지만 가끔 쓰는 프로그램까지 모두 올려 두면 화면이 어지러워집니다.

시작 메뉴는 **설치된 모든 앱을 한곳에 모아 두는 목록**이므로,  
바탕 화면을 깔끔하게 유지하면서도 필요한 프로그램을 찾을 수 있습니다.

---

### 2. 시작 메뉴의 구성

| 영역 | 내용 |
| --- | --- |
| 사용자 계정 | 계정 설정 변경, 잠금, 로그아웃, 계정 전환을 할 수 있습니다. |
| 문서 / 사진 | 해당 폴더를 파일 탐색기로 바로 엽니다. |
| 설정 | [설정] 창을 표시합니다. |
| 전원 | 절전, 시스템 종료, 다시 시작을 선택합니다. |
| 앱 목록 | 설치된 모든 앱이 **숫자 → 영문 → 한글 순**으로 정렬되어 표시됩니다. |
| 타일(Tile) | 자주 사용하는 앱을 사각형 모양으로 고정해 둔 영역입니다. |

---

### 3. 앱 목록

- 앱 목록은 **숫자, 영문, 한글 순서**로 자동 정렬됩니다.
- 목록의 알파벳 머리글을 클릭하면 **인덱스 화면**이 나타나 원하는 글자로 빠르게 이동할 수 있습니다.
- 앱을 마우스 오른쪽 단추로 클릭하면 다음 작업을 할 수 있습니다.

| 메뉴 | 기능 |
| --- | --- |
| 시작 화면에 고정 | 해당 앱을 타일 영역에 고정합니다. |
| 자세히 → 작업 표시줄에 고정 | 작업 표시줄에 아이콘을 고정합니다. |
| 자세히 → 파일 위치 열기 | 실행 파일이 있는 폴더를 엽니다. |
| 제거 | 해당 앱을 삭제합니다. |

#### 왜 앱 목록을 자동으로 정렬할까?

설치한 순서대로 나열하면 프로그램이 늘어날수록 원하는 항목을 찾기 어려워집니다.

이름 순으로 정렬하면 **찾는 규칙이 항상 같으므로**,  
프로그램 수가 많아져도 예측 가능한 위치에서 찾을 수 있습니다.

---

### 4. 타일(Tile)

타일은 시작 메뉴 오른쪽에 표시되는 **사각형 모양의 앱 바로 가기**입니다.

| 작업 | 방법 |
| --- | --- |
| 타일 추가 | 앱 목록에서 앱을 마우스 오른쪽 단추 클릭 → [시작 화면에 고정] |
| 타일 제거 | 타일을 마우스 오른쪽 단추 클릭 → [시작 화면에서 제거] |
| 타일 크기 조절 | 타일 바로 가기 메뉴 → [크기 조정] → 작게 / 보통 / 넓게 / 크게 |
| 라이브 타일 | 날씨, 뉴스, 메일처럼 **타일 안에서 실시간 정보가 갱신**되는 기능입니다. |
| 그룹 만들기 | 타일을 드래그하여 그룹으로 묶고 그룹 이름을 지정할 수 있습니다. |

#### 왜 라이브 타일이라는 기능이 있을까?

일반 아이콘은 실행하기 전에는 아무 정보도 알려 주지 않습니다.

라이브 타일은 **앱을 실행하지 않아도 핵심 정보(날씨, 새 메일 수 등)를 타일 위에 바로 표시**합니다.  
즉, 아이콘을 단순한 실행 버튼이 아니라 **작은 정보 창**으로 활용하는 방식입니다.

---

### 5. 빠른 링크 메뉴

[시작] 단추를 **마우스 오른쪽 단추로 클릭**하거나 `⊞` + `X`를 누르면 나타나는 메뉴입니다.

- 앱 및 기능, 전원 옵션, 이벤트 뷰어, 시스템, 장치 관리자, 네트워크 연결,  
  디스크 관리, 컴퓨터 관리, 작업 관리자, 설정, 파일 탐색기, 실행 등  
  **시스템 관리에 자주 쓰는 항목**이 모여 있습니다.

#### 왜 빠른 링크 메뉴를 따로 제공할까?

시스템 관리 도구는 [설정]이나 [제어판] 안쪽 깊숙이 위치한 경우가 많습니다.

빠른 링크 메뉴는 이런 항목만 따로 모아 두어,  
**여러 단계를 거치지 않고 한 번에 접근**할 수 있게 해 줍니다.

---

### 한 줄 정리

시작 메뉴는 **설치된 모든 앱에 접근하는 출발점**이며,  
앱 목록은 **숫자 → 영문 → 한글 순으로 정렬**되고,  
자주 쓰는 앱은 **타일에 고정**하여 라이브 타일 형태로 정보까지 확인할 수 있습니다.
