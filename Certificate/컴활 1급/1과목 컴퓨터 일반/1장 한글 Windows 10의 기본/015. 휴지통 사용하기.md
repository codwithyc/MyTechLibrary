## 015. 휴지통 사용하기

### 1. 휴지통의 개요

휴지통은 **삭제한 파일과 폴더를 임시로 보관하는 공간**입니다.

- 휴지통에 있는 항목은 **원래 위치로 복원**할 수 있습니다.
- 휴지통에 있는 동안에도 **디스크 공간을 계속 차지**합니다.
- 휴지통 안에서는 파일을 **실행하거나 내용을 편집할 수 없습니다.**
- 휴지통의 파일은 **이름을 바꿀 수 없습니다.**

#### 왜 삭제한 파일을 바로 지우지 않을까?

파일 삭제는 되돌리기 어려운 작업입니다.  
실수로 중요한 파일을 지웠는데 즉시 사라진다면 복구할 방법이 없습니다.

휴지통은 **"삭제 명령"과 "실제 제거" 사이에 한 단계를 두어**,  
사용자가 되돌릴 기회를 주는 안전장치입니다.

즉, 휴지통은  
**되돌릴 수 없는 작업을 되돌릴 수 있게 만드는 완충 장치**입니다.

#### 왜 휴지통 안에서는 파일을 실행할 수 없을까?

휴지통에 있는 파일은 **"삭제되었지만 아직 지워지지 않은 상태"** 입니다.

만약 이 상태에서 실행이나 편집이 가능하다면,  
삭제한 것인지 사용 중인 것인지 구분할 수 없게 됩니다.

그래서 휴지통에서는 **복원과 완전 삭제만** 가능하도록 제한되어 있습니다.

---

### 2. 휴지통에 보관되지 않는 경우

다음의 경우에는 휴지통을 거치지 않고 **곧바로 완전 삭제**됩니다.

- `Shift` + `Delete`로 삭제한 경우
- `Shift`를 누른 채 휴지통으로 드래그한 경우
- **USB 메모리, 네트워크 드라이브** 등 하드디스크가 아닌 곳의 파일을 삭제한 경우
- **휴지통의 최대 크기보다 큰 파일**을 삭제한 경우
- 휴지통 속성에서 **'파일을 휴지통에 버리지 않고 삭제할 때 바로 제거'** 를 선택한 경우
- 명령 프롬프트에서 `del` 명령으로 삭제한 경우

#### 왜 휴지통보다 큰 파일은 보관되지 않을까?

휴지통은 각 드라이브에 **정해진 크기만큼만** 공간을 사용합니다.

이 크기보다 큰 파일을 넣으려 하면 애초에 담을 수 없으므로,  
Windows는 경고 메시지를 표시한 뒤 곧바로 완전 삭제합니다.

---

### 3. 휴지통의 속성

휴지통 아이콘을 마우스 오른쪽 단추로 클릭 → [속성]에서 설정합니다.

| 항목 | 설명 |
| --- | --- |
| 휴지통 위치 / 사용 가능한 공간 | 드라이브별 휴지통의 위치와 용량을 표시합니다. |
| 사용자 지정 크기 | 드라이브별로 휴지통의 **최대 크기(MB)** 를 지정합니다. |
| 파일을 휴지통에 버리지 않고 삭제할 때 바로 제거 | 삭제한 파일을 휴지통에 보관하지 않고 즉시 삭제합니다. |
| 삭제 확인 대화 상자 표시 | 삭제할 때 확인 메시지를 표시할지 지정합니다. |

- 휴지통의 크기는 **드라이브마다 다르게 지정**할 수 있습니다.

#### 왜 드라이브마다 휴지통 크기를 따로 지정할까?

드라이브마다 용량과 용도가 다릅니다.

- 시스템 드라이브(C:) : 공간이 부족한 경우가 많아 작게 설정
- 데이터 드라이브(D:) : 큰 파일이 많으므로 넉넉하게 설정

이렇게 나누어 설정하면 **용량 낭비를 줄이면서도 필요한 복원 여지는 확보**할 수 있습니다.

### 4. 복원과 비우기

| 작업 | 방법 |
| --- | --- |
| 선택 항목 복원 | 휴지통에서 항목 선택 → [복원] 또는 바로 가기 메뉴 → [복원] |
| 모든 항목 복원 | [관리] 탭 → [모든 항목 복원] |
| 휴지통 비우기 | [관리] 탭 → [휴지통 비우기] 또는 휴지통 바로 가기 메뉴 → [휴지통 비우기] |

- 복원하면 **삭제되기 전의 원래 위치**로 되돌아갑니다.
- 원래 위치의 폴더가 삭제된 경우, **폴더까지 함께 다시 만들어집니다.**
- 휴지통을 비우면 **더 이상 복원할 수 없습니다.**

#### 왜 원래 위치로만 복원될까?

휴지통은 파일을 보관할 때 **"어디에서 삭제되었는지"** 를 함께 기록합니다.

복원은 이 기록을 이용해 원래 자리로 되돌리는 작업이므로,  
사용자가 위치를 따로 지정하지 않아도 정확히 복구됩니다.

다른 위치에 두고 싶다면, 복원한 뒤에 직접 이동하면 됩니다.

---

### 5. 휴지통 아이콘

- 휴지통이 **비어 있으면 빈 통 모양**, **파일이 있으면 종이가 담긴 모양**으로 표시됩니다.
- 휴지통 아이콘은 **삭제할 수 없으며**, [설정] → [개인 설정] → [테마] → [바탕 화면 아이콘 설정]에서 표시 여부만 지정할 수 있습니다.

---

### 한 줄 정리

휴지통은 **삭제한 파일을 임시 보관하여 복원 기회를 주는 안전장치**이며,  
`Shift` + `Delete`, USB·네트워크 드라이브, 휴지통 크기 초과의 경우에는 **보관되지 않고 즉시 삭제**됩니다.
