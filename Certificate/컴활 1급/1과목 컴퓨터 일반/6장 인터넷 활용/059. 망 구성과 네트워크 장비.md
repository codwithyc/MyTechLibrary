## 059. 망 구성과 네트워크 장비

### 1. 네트워크 토폴로지(망의 구성 형태)

| 형태 | 특징 |
| --- | --- |
| **성형(Star)** | 중앙에 있는 중심 장치에 모든 노드가 연결됩니다. **중앙 장치가 고장 나면 전체 통신이 마비**되지만, 개별 노드의 고장은 영향이 적고 고장 발견이 쉽습니다. |
| **버스형(Bus)** | 하나의 통신 회선에 여러 노드가 연결됩니다. 구조가 단순하고 설치가 쉽지만, **회선이 끊기면 전체가 영향**을 받습니다. |
| **링형(Ring)** | 노드가 원형으로 연결되어 한 방향으로 데이터가 전달됩니다. 한 노드가 고장 나면 전체가 영향을 받으므로 **이중 링**으로 구성하기도 합니다. |
| **트리형(Tree)** | 계층적인 구조로 연결됩니다. 확장이 쉽지만 **상위 노드가 고장 나면 하위 전체가 영향**을 받습니다. |
| **망형(Mesh)** | 모든 노드가 서로 직접 연결됩니다. **신뢰성이 매우 높지만 회선 수가 많아 비용이 큽니다.** |

#### 왜 망형은 신뢰성이 높을까?

망형은 모든 노드가 서로 직접 연결되어 있으므로,  
어떤 회선 하나가 끊겨도 **다른 경로로 우회**할 수 있습니다.

다만 노드가 n개일 때 필요한 회선 수는 **n(n-1)/2** 개로, 노드가 늘어날수록 급격히 증가합니다.

- 5개 노드 → 10개 회선
- 10개 노드 → 45개 회선

그래서 망형은 **비용을 감수하고서라도 반드시 끊기면 안 되는 곳**(군사, 기간망)에 사용합니다.

#### 왜 대부분의 사무실은 성형을 사용할까?

성형은 중앙 장치(스위치, 공유기)만 관리하면 되므로

- 새 컴퓨터를 추가하기 쉽고
- 어느 노드에 문제가 있는지 **바로 찾을 수 있습니다.**

중앙 장치 고장이라는 약점이 있지만, 관리 편의성이 압도적이므로 가장 널리 쓰입니다.

### 2. 네트워크 장비

| 장비 | 기능 | OSI 계층 |
| --- | --- | --- |
| **리피터(Repeater)** | 약해진 신호를 **증폭하여 재전송**하여 전송 거리를 연장합니다. | 물리 계층 |
| **허브(Hub)** | 여러 대의 컴퓨터를 연결하는 장치로, 받은 데이터를 **연결된 모든 포트로 전달**합니다. | 물리 계층 |
| **브리지(Bridge)** | 두 개의 네트워크를 연결하며, **MAC 주소를 보고 필요한 쪽으로만 전달**합니다. | 데이터 링크 계층 |
| **스위치(Switch)** | 브리지의 발전된 형태로, **목적지 포트로만 데이터를 전달**하여 효율이 높습니다. | 데이터 링크 계층 |
| **라우터(Router)** | 서로 다른 네트워크를 연결하며, **최적의 경로를 선택**하여 데이터를 전달합니다. | 네트워크 계층 |
| **게이트웨이(Gateway)** | **프로토콜이 다른 네트워크**를 연결합니다. 네트워크의 출입구 역할을 합니다. | 전 계층 |

#### 왜 허브 대신 스위치를 사용할까?

**허브**는 받은 데이터를 **연결된 모든 포트에 그대로 뿌립니다.**

10대가 연결되어 있다면, A가 B에게 보낸 데이터를 나머지 8대도 받게 됩니다.

이 방식은

- **불필요한 트래픽**이 발생하고
- 여러 대가 동시에 전송하면 **충돌(Collision)** 이 생기며
- 다른 사람의 데이터를 **엿볼 수 있어 보안에도 취약**합니다.

**스위치**는 어느 포트에 어떤 기기가 있는지 **MAC 주소를 기억**해 두고,  
**목적지 포트로만** 데이터를 보냅니다.

그 결과 충돌이 사라지고, 대역폭을 효율적으로 사용하며, 보안도 향상됩니다.

#### 왜 라우터가 필요할까?

스위치는 **같은 네트워크 안에서만** 데이터를 전달할 수 있습니다.

다른 네트워크(예: 우리 집 → 인터넷)로 나가려면,  
**"어느 길로 가야 목적지에 도달하는가"** 를 판단할 장치가 필요합니다.

라우터는 IP 주소를 보고 **최적의 경로를 결정**하여 데이터를 전달합니다.

정리하면

- **스위치** : MAC 주소 기준, 같은 네트워크 안에서 전달
- **라우터** : IP 주소 기준, 다른 네트워크로 경로 선택

#### 왜 게이트웨이가 따로 있을까?

라우터는 **같은 프로토콜(TCP/IP)** 을 쓰는 네트워크끼리 연결합니다.

하지만 서로 **완전히 다른 통신 규약**을 쓰는 시스템끼리 연결해야 할 때도 있습니다.

게이트웨이는 이 경우 **프로토콜 자체를 변환**하여 통신이 가능하게 해 줍니다.  
즉, 라우터가 "길 안내"라면 게이트웨이는 "번역까지 포함한 출입구"입니다.

### 3. 무선 네트워크

| 기술 | 특징 |
| --- | --- |
| **Wi-Fi (무선 랜)** | IEEE 802.11 규격을 사용하며, AP(무선 공유기)를 통해 연결합니다. |
| **AP(Access Point)** | 유선 네트워크와 무선 기기를 연결하는 장치입니다. |
| **블루투스(Bluetooth)** | 근거리(약 10m)에서 기기 간 데이터를 주고받습니다. IEEE 802.15 규격입니다. |
| **NFC** | 10cm 이내의 매우 가까운 거리에서 데이터를 주고받습니다. 교통카드, 모바일 결제에 사용합니다. |
| **테더링(Tethering)** | 스마트폰의 데이터 연결을 다른 기기와 **공유**하는 기능입니다. |
| **RFID** | 무선 주파수를 이용해 태그의 정보를 읽습니다. 물류 관리, 출입 통제에 사용합니다. |

#### 왜 NFC는 거리를 아주 짧게 제한했을까?

NFC는 결제나 신분 확인처럼 **보안이 중요한 용도**로 사용됩니다.

통신 거리가 길면 옆 사람의 카드 정보가 읽히거나,  
멀리서 도청될 위험이 있습니다.

거리를 10cm 이내로 제한하면 **"의도적으로 갖다 대야만" 통신이 이루어지므로**,  
그 자체가 하나의 보안 장치가 됩니다.

### 4. 유선 전송 매체

| 매체 | 특징 |
| --- | --- |
| **트위스티드 페어 케이블(UTP)** | 구리선을 꼬아 만든 케이블로, 가격이 저렴하고 설치가 쉽습니다. 가장 널리 사용됩니다. |
| **동축 케이블** | 중심 도체를 절연체로 감싼 케이블로, 트위스티드 페어보다 잡음에 강합니다. |
| **광섬유 케이블** | 빛으로 신호를 전달하며, **전송 속도가 매우 빠르고 잡음의 영향을 거의 받지 않으며 보안성이 높습니다.** 가격이 비쌉니다. |

#### 왜 광섬유가 잡음에 강할까?

구리선은 **전기 신호**로 데이터를 전달하므로,  
주변의 전자기파(형광등, 모터, 다른 케이블)에 영향을 받습니다.

광섬유는 **빛으로 신호를 전달**하므로 전자기 간섭의 영향을 받지 않습니다.

또한 신호가 밖으로 새어 나가지 않으므로 **도청이 어려워 보안성도 높습니다.**

---

### 한 줄 정리

망 구성은 **성형(관리 편함) / 버스형(단순) / 링형 / 트리형 / 망형(신뢰성 높지만 고비용)** 으로 나뉘며,  
**허브는 전체에 뿌리고 스위치는 목적지에만 전달**, **라우터는 다른 네트워크로 경로를 선택**,  
**게이트웨이는 프로토콜이 다른 네트워크를 연결**합니다.
