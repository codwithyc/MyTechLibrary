## 049. 하드디스크 연결 방식

### 1. IDE / EIDE (Parallel ATA)

**IDE(Integrated Drive Electronics)** 는 하드디스크를 메인보드에 연결하는 초기 방식입니다.

| 구분 | 특징 |
| --- | --- |
| IDE | 최대 **2개**의 장치를 연결할 수 있으며, 용량은 528MB까지 지원했습니다. |
| **EIDE** | IDE를 확장한 방식으로, **최대 4개**의 장치를 연결할 수 있습니다. |

- 넓은 **40핀 병렬 케이블**을 사용합니다.
- 한 케이블에 두 장치를 연결할 때는 **마스터(Master)와 슬레이브(Slave)** 를 점퍼로 지정해야 합니다.

#### 왜 마스터와 슬레이브를 지정해야 했을까?

하나의 케이블을 두 장치가 함께 사용하기 때문입니다.

두 장치가 동시에 신호를 보내면 **어느 쪽 신호인지 구분할 수 없습니다.**

그래서 **주(마스터)와 종(슬레이브)** 을 미리 정해 두어 순서를 구분했습니다.

이 설정이 잘못되면 장치가 인식되지 않았고, 이는 사용자에게 큰 불편이었습니다.

---

### 2. SATA (Serial ATA)

**SATA**는 현재 가장 널리 사용되는 하드디스크 연결 방식입니다.

| 특징 | 설명 |
| --- | --- |
| 전송 방식 | **직렬(Serial)** 방식으로 데이터를 전송합니다. |
| 케이블 | **얇고 좁은 7핀 케이블**을 사용합니다. |
| 연결 | 케이블 하나에 **장치 하나**를 연결하므로 마스터/슬레이브 설정이 필요 없습니다. |
| **핫 플러그(Hot Plug)** | **전원이 켜진 상태에서도 장치를 연결하거나 분리**할 수 있습니다. |
| 속도 | EIDE보다 전송 속도가 훨씬 빠릅니다. (SATA 3 기준 약 6Gbps) |
| 전원 | 전원 케이블도 별도의 SATA 전원 커넥터를 사용합니다. |

#### 왜 병렬(IDE)에서 직렬(SATA)로 바뀌었을까?

병렬 방식은 **여러 개의 선으로 데이터를 동시에 전송**하므로 언뜻 더 빨라 보입니다.

그런데 속도를 높일수록 문제가 생깁니다.

- 각 선의 신호 도착 시간이 **미세하게 어긋나고**(스큐)
- 선끼리 서로 **전기적 간섭**을 일으킵니다.

그래서 병렬 방식은 일정 속도 이상으로 올리기 어려웠습니다.

직렬 방식은 **하나의 선으로 순차 전송**하므로 이런 문제가 없고,  
전송 주파수를 훨씬 높일 수 있어 **결과적으로 더 빠릅니다.**

또한 케이블이 얇아져 **케이스 내부의 공기 흐름과 발열 관리**에도 유리합니다.

#### 왜 핫 플러그가 가능할까?

SATA는 커넥터의 **핀 길이를 다르게 설계**하여, 연결할 때 **접지 → 전원 → 신호** 순으로 접촉되도록 만들었습니다.

이 순서 덕분에 전원이 켜진 상태에서 꽂아도 **순간적인 전류로 회로가 손상되지 않습니다.**

### 3. SCSI (Small Computer System Interface)

| 특징 | 설명 |
| --- | --- |
| 연결 장치 수 | **최대 7개 또는 15개**의 장치를 연결할 수 있습니다. |
| 용도 | 서버, 워크스테이션 등 **고성능·다중 장치 환경**에서 사용합니다. |
| 특징 | 각 장치에 **고유한 ID**를 지정하며, 마지막 장치에는 **터미네이터**를 설치합니다. |
| 장점 | 여러 장치를 연결해도 성능 저하가 적고, CPU 부담이 적습니다. |
| 단점 | 가격이 비쌉니다. |

---

### 4. 그 밖의 연결 방식

| 방식 | 특징 |
| --- | --- |
| **NVMe / M.2** | SSD를 PCI Express 통로에 직접 연결하는 방식으로, SATA보다 훨씬 빠릅니다. |
| **USB** | 최대 **127개**의 장치를 연결할 수 있으며, **핫 플러그와 PnP를 지원**합니다. 외장 하드 연결에 사용합니다. |
| **IEEE 1394 (FireWire)** | 최대 **63개**의 장치를 연결하며, 디지털 캠코더 등 멀티미디어 장치에 사용합니다. |
| eSATA | 외장 장치를 SATA 방식으로 연결합니다. |

#### 왜 NVMe가 SATA보다 빠를까?

SATA는 원래 **하드디스크를 전제로 만들어진 규격**입니다.  
하드디스크의 속도에 맞춰 설계되었으므로, SSD의 성능을 다 담아내지 못합니다.

NVMe는 SSD를 **CPU와 직접 연결되는 고속 통로(PCI Express)** 에 붙이고,  
플래시 메모리의 병렬 처리 특성에 맞게 설계된 규격입니다.

즉,

- **SATA** : 하드디스크 시대의 규격을 SSD가 빌려 쓰는 것
- **NVMe** : 처음부터 SSD를 위해 만들어진 규격

이 차이 때문에 속도 격차가 매우 큽니다.

### 5. 포트(Port) 정리

| 포트 | 용도 |
| --- | --- |
| USB | 키보드, 마우스, 프린터, 외장 하드 등 대부분의 주변 장치 |
| HDMI / DisplayPort | 영상과 음성을 디지털로 전송 |
| D-SUB(VGA) / DVI | 모니터 연결(아날로그 / 디지털) |
| RJ-45 | 유선 랜(이더넷) 연결 |
| 직렬 포트(COM) | 모뎀 등 저속 장치 |
| 병렬 포트(LPT) | 과거의 프린터 연결 |
| PS/2 | 과거의 키보드·마우스 연결 |

#### 왜 USB가 대부분의 포트를 대체했을까?

과거에는 장치마다 전용 포트가 필요했습니다.  
키보드는 PS/2, 프린터는 병렬 포트, 모뎀은 직렬 포트를 사용했습니다.

USB는

- **하나의 규격으로 다양한 장치를 연결**할 수 있고
- **핫 플러그와 PnP**를 지원하며
- **전원까지 함께 공급**할 수 있습니다.

이 편리함 덕분에 USB가 사실상 표준 포트가 되었습니다.

---

### 한 줄 정리

**EIDE는 병렬 방식으로 최대 4개 연결(마스터/슬레이브 설정 필요)**,  
**SATA는 직렬 방식으로 케이블당 1개 연결·핫 플러그 지원**,  
**SCSI는 7~15개 연결로 서버용**, **USB는 127개·IEEE 1394는 63개**를 연결할 수 있습니다.
