## 032. 네트워크

### 1. 네트워크의 개요

네트워크는 **두 대 이상의 컴퓨터를 연결하여 자원과 정보를 공유하는 것**입니다.

- 공유 대상 : 파일, 폴더, 프린터, 인터넷 연결 등

#### 왜 네트워크를 구성할까?

컴퓨터마다 자료를 따로 보관하면

- 같은 파일을 여러 번 복사해야 하고
- 어느 것이 최신본인지 알기 어려우며
- 프린터 같은 장비도 사람 수만큼 필요합니다.

네트워크는 **자원을 한곳에 두고 여러 사람이 함께 사용**할 수 있게 하여,  
중복과 낭비를 줄입니다.

---

### 2. 네트워크 관련 주요 구성 요소

| 구성 요소 | 설명 |
| --- | --- |
| 네트워크 어댑터(NIC, 랜 카드) | 컴퓨터를 네트워크에 물리적으로 연결하는 장치입니다. |
| 프로토콜 | 통신 규약으로, 인터넷에서는 **TCP/IP**를 사용합니다. |
| 클라이언트 | 다른 컴퓨터의 자원을 사용할 수 있게 하는 소프트웨어입니다. |
| 서비스 | 자신의 자원을 다른 컴퓨터가 사용할 수 있게 제공합니다. (파일 및 프린터 공유) |

---

### 3. 네트워크 프로필

Windows 10은 연결된 네트워크를 두 가지 유형으로 구분합니다.

| 유형 | 특징 |
| --- | --- |
| **개인(사설) 네트워크** | 가정이나 회사처럼 신뢰할 수 있는 네트워크입니다. **네트워크 검색과 파일·프린터 공유가 허용**됩니다. |
| **공용 네트워크** | 카페, 공항 등 신뢰할 수 없는 네트워크입니다. **다른 기기에서 내 컴퓨터가 보이지 않도록 차단**합니다. |

#### 왜 네트워크 유형을 나눌까?

같은 "인터넷 연결"이라도 **함께 연결된 상대가 누구인지**는 전혀 다릅니다.

- 집 → 가족의 기기만 연결됨 → 공유해도 안전
- 공공 와이파이 → 모르는 사람의 기기가 함께 연결됨 → 공유하면 위험

네트워크 유형은 **연결 환경의 신뢰도에 따라 보안 수준을 자동으로 바꾸기 위한 구분**입니다.

---

### 4. 폴더 공유

- 공유할 폴더 바로 가기 메뉴 → [속성] → [공유] 탭 → [공유] 또는 [고급 공유]
- 공유된 폴더에는 **공유 표시**가 나타납니다.
- 공유 이름 뒤에 **`$`** 를 붙이면 **네트워크에서 목록에 보이지 않는 숨김 공유**가 됩니다.
- 다른 컴퓨터에서 접근할 때는 **`\\컴퓨터이름\공유이름`** 형식을 사용합니다.

**공유 권한**

| 권한 | 가능한 작업 |
| --- | --- |
| 읽기 | 파일 열기와 복사만 가능 |
| 변경 | 읽기 + 파일 추가·수정·삭제 가능 |
| 모든 권한 | 변경 + 권한 설정 변경 가능 |

#### 왜 숨김 공유(`$`)를 사용할까?

공유 폴더는 네트워크 목록에 그대로 노출됩니다.  
관리자만 사용하는 폴더까지 모두에게 보일 필요는 없습니다.

`$`를 붙이면 **목록에는 나타나지 않지만, 정확한 경로를 아는 사람은 접근**할 수 있습니다.

즉, 숨김 공유는 **접근을 막는 것이 아니라 노출을 줄이는 방법**입니다.

---

### 5. 네트워크 드라이브 연결

다른 컴퓨터의 공유 폴더를 **내 컴퓨터의 드라이브처럼 사용**하는 기능입니다.

- 파일 탐색기 → [내 PC] → [컴퓨터] 탭 → [네트워크 드라이브 연결]
- 드라이브 문자(Z:, Y: 등)를 지정하고 공유 폴더 경로를 입력합니다.
- **로그인할 때 다시 연결** 옵션을 선택하면 부팅할 때마다 자동으로 연결됩니다.

#### 왜 네트워크 드라이브로 연결할까?

`\\서버\자료실` 같은 경로를 매번 입력하는 것은 번거롭습니다.

네트워크 드라이브로 연결하면 **Z: 처럼 일반 드라이브와 똑같이 취급**되므로,  
프로그램에서도 로컬 폴더처럼 지정해서 사용할 수 있습니다.

### 6. 네트워크의 종류

| 구분 | 설명 |
| --- | --- |
| **LAN(근거리 통신망)** | 건물이나 사무실처럼 **좁은 지역**을 연결합니다. 전송 속도가 빠르고 오류가 적습니다. |
| **MAN(도시권 통신망)** | 도시 규모의 지역을 연결합니다. |
| **WAN(광역 통신망)** | 국가나 대륙 등 **넓은 지역**을 연결합니다. LAN보다 속도가 느리고 오류율이 높습니다. |
| VAN(부가가치 통신망) | 통신 회선을 빌려 새로운 부가 서비스를 제공하는 망입니다. |
| VPN(가상 사설망) | 공중망을 이용하면서도 **암호화를 통해 전용선처럼 안전하게** 사용하는 망입니다. |

#### 왜 VPN이 필요할까?

전용선을 직접 설치하면 안전하지만 **비용이 매우 큽니다.**

VPN은 이미 깔려 있는 인터넷 위에 **암호화된 통로(터널)** 를 만들어,  
저렴한 비용으로 **전용선에 가까운 보안 수준**을 얻는 방식입니다.

---

### 한 줄 정리

네트워크는 **자원 공유를 위해 컴퓨터를 연결하는 것**이며,  
**개인 네트워크는 공유 허용 / 공용 네트워크는 차단**,  
공유 이름 뒤의 **`$`는 숨김 공유**, 규모에 따라 **LAN → MAN → WAN**으로 구분합니다.
