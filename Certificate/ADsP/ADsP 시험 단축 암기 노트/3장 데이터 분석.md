기업 활동과 서비스 운영 목적의 데이터는 업무 처리와 서비스 제공을 위해 수집되고,
데이터 분석 목적의 데이터는 의사결정, 예측, 패턴 발견을 위해 수집된다.

운영 목적 데이터는 현재 업무를 정확하게 처리하는 것이 중요하고,
분석 목적 데이터는 과거 데이터를 바탕으로 의미 있는 인사이트를 찾는 것이 중요하다.

알고리즘은 문제 해결을 위한 단계적 절차이다.

인공지능은 인간의 지능적 행동을 컴퓨터가 수행하도록 하는 기술이고,
머신러닝은 데이터를 통해 패턴을 학습하여 예측이나 분류를 수행하는 기술이다.

데이터 마이닝은 대량의 데이터에서 의미 있는 패턴, 규칙, 관계를 발견하는 과정이다.

머신러닝은 학습과 예측에 초점이 있고,
데이터 마이닝은 데이터 속 숨겨진 패턴과 규칙 발견에 초점이 있다.

데이터 처리는 원천 데이터를 분석 가능한 형태로 정제, 변환, 결합하는 과정이다.

필터링은 조건에 맞는 데이터를 선택하는 작업이고,
정렬은 데이터를 특정 기준에 따라 순서대로 배열하는 작업이다.

집계는 데이터를 그룹별로 묶어 합계, 평균, 개수 등을 계산하는 작업이다.

데이터 변형은 데이터의 형태나 표현 방식을 분석 목적에 맞게 바꾸는 작업이다.

정규화는 값의 범위를 일정하게 맞추는 것이고,
표준화는 평균 0, 표준편차 1이 되도록 변환하는 것이다.

파생변수는 기존 변수를 가공하거나 조합하여 새롭게 만든 변수이다.

데이터 결합은 여러 테이블이나 데이터셋을 분석 목적에 맞게 합치는 작업이다.

데이터 정제는 오류, 중복, 결측값, 이상값 등을 처리하여 데이터 품질을 높이는 작업이다.

결측값은 데이터가 있어야 할 자리에 값이 없는 상태이며,
제거하거나 평균, 중앙값, 최빈값, 예측값 등으로 대체할 수 있다.  
(결측값 대체를 사용하는 주요 목적 중 하나는 분석에 사용할 데이터 수를 유지하여 정보 손실을 최소화하기 위함입니다)

이상값은 일반적인 데이터 범위에서 크게 벗어난 값이며,
원인을 확인한 뒤 제거, 대체, 분리 분석, 유지 중 적절한 방법을 선택한다.

기술 통계는 현재 수집된 데이터를 평균, 중앙값, 표준편차, 그래프 등으로 요약하고 설명하는 통계이다.

추론 통계는 표본 데이터를 이용해 모집단의 특성을 추정하거나 가설을 검정하는 통계이다.

탐색적 데이터 분석은 본격적인 분석 전에 데이터의 구조, 분포, 결측값, 이상값, 변수 관계를 탐색하는 과정이다.

지도학습은 정답이 있는 데이터를 학습하여 새로운 데이터의 결과를 예측하는 방법이다.

비지도학습은 정답 없이 데이터의 숨겨진 구조나 패턴을 찾는 방법이다.

회귀는 연속형 수치 값을 예측하는 지도학습 방법이고,
분류는 미리 정해진 범주를 예측하는 지도학습 방법이다.

정형 데이터 분석은 행과 열로 구성된 표 형태 데이터를 분석하는 것이고,
비정형 데이터 분석은 텍스트, 이미지, 음성, 영상처럼 고정된 구조가 없는 데이터를 분석하는 것이다.

기술 분석은 현재 상태를 설명하고,
진단 분석은 원인을 찾고,
예측 분석은 미래를 예측하며,
처방 분석은 최적의 행동을 제안한다.

평가 지표는 모델의 예측 성능을 수치로 판단하는 기준이다.

회귀 문제의 평가 지표는 실제값과 예측값의 차이를 기준으로 한다.

MAE는 실제값과 예측값 차이의 절댓값 평균이다.

MAPE는 절대 오차를 실제값으로 나누어 백분율로 표현한 지표이다.

MSE는 실제값과 예측값 차이를 제곱한 값의 평균이다.

RMSE는 MSE에 제곱근을 취한 값이다.

R²는 회귀 모델이 종속변수의 변동을 얼마나 잘 설명하는지 나타내는 지표이다.

분류 문제의 평가 지표는 실제 클래스와 예측 클래스의 일치 여부를 기준으로 한다.

오차 행렬은 실제값과 예측값을 비교하여 TP, TN, FP, FN으로 분류 결과를 정리한 표이다.

정확도는 전체 예측 중 맞게 예측한 비율이고,
오분류율은 전체 예측 중 잘못 예측한 비율이다.

재현율은 실제 Positive 중 Positive로 맞게 찾아낸 비율이다.

정밀도는 Positive라고 예측한 것 중 실제 Positive인 비율이다.

F1 Score는 정밀도와 재현율의 조화평균이다.

FPR은 실제 Negative 중 Positive로 잘못 예측한 비율이다.

ROC 곡선은 기준값 변화에 따른 TPR과 FPR의 관계를 나타낸 그래프이고,
AUC가 1에 가까울수록 분류 성능이 좋다.

군집화 평가는 정답 라벨이 없으므로 군집 내 응집도와 군집 간 분리도를 기준으로 한다.

실루엣 계수는 군집 내 응집도와 군집 간 분리도를 함께 평가하는 지표이다.

좋은 군집은 군집 내 거리가 작고, 군집 간 거리가 커야 한다.

교차 검증은 데이터를 여러 방식으로 나누어 모델의 일반화 성능을 평가하는 방법이다.

홀드아웃 검증은 데이터를 학습용과 검증용으로 한 번 나누어 평가하는 방법이다.

K-폴드 교차 검증은 데이터를 K개로 나누어 K번 학습과 검증을 반복하는 방법이다.

층화 K-폴드 교차 검증은 클래스 비율을 유지하면서 K개의 폴드로 나누는 방법이다.

LpOCV는 p개의 데이터를 검증용으로 남기고 나머지 데이터로 학습하는 교차 검증 방법이다.

선형회귀는 독립변수와 종속변수 사이의 선형 관계를 이용해 연속형 값을 예측하는 방법이다.

단순 선형회귀는 독립변수 1개로 종속변수를 예측하고,
다중 선형회귀는 여러 개의 독립변수로 종속변수를 예측한다.

선형회귀의 주요 가정은 선형성, 독립성, 정규성, 등분산성이다.

다항 회귀는 변수의 거듭제곱 항을 추가하여 곡선 관계를 표현하는 회귀분석이다.

비선형회귀는 변수와 결과의 관계를 비선형 함수로 표현하는 회귀분석이다.

변수 선택은 모델 성능과 해석력을 높이기 위해 중요한 변수를 선택하는 과정이다.

전진 선택은 변수를 하나씩 추가하고,
후진 제거는 모든 변수에서 시작해 불필요한 변수를 제거하며,
단계적 선택은 추가와 제거를 반복한다.

정규화 선형회귀는 회귀계수에 제약을 주어 과적합을 방지하는 회귀 방법이다.

릿지 회귀는 L2 정규화를 사용하여 계수를 작게 줄이고,
라쏘 회귀는 L1 정규화를 사용하여 일부 계수를 0으로 만들 수 있다.

엘라스틱넷은 L1 정규화와 L2 정규화를 함께 사용하는 회귀 방법이다.

로지스틱회귀는 사건 발생 확률을 예측하여 범주를 분류하는 방법이다.

오즈는 사건이 발생할 확률과 발생하지 않을 확률의 비율이다.

로짓은 오즈에 자연로그를 취한 값이다.

나이브 베이즈는 변수 간 독립을 가정하고 베이즈 정리를 이용해 분류하는 방법이다.

SVM은 클래스 간 마진이 최대가 되는 결정 경계를 찾는 분류 알고리즘이다.

K-NN은 새로운 데이터와 가까운 K개의 이웃을 기준으로 예측하는 방법이다.

K-NN은 거리 기반 방법이므로 변수 스케일에 민감하고 표준화가 중요하다.

의사결정나무는 조건에 따라 데이터를 분할하여 예측하는 나무 구조 모델이다.

회귀 나무는 목표 변수가 연속형일 때 사용하고,
분류 나무는 목표 변수가 범주형일 때 사용한다.

회귀 나무는 분산 감소를 기준으로 분할하고,
분류 나무는 지니 불순도나 엔트로피를 기준으로 분할한다.

가지치기는 불필요한 가지를 제거하여 의사결정나무의 과적합을 줄이는 방법이다.

ID3는 엔트로피와 정보 이득을 기준으로 분할하고,
C4.5는 정보 이득비를 기준으로 분할하며,
CART는 지니 지수와 분산 감소를 기준으로 분할한다.

앙상블은 여러 모델을 결합하여 예측 성능을 높이는 방법이다.

배깅은 여러 모델을 병렬로 학습하고 결과를 결합하여 분산을 줄이는 방법이다.

랜덤 포레스트는 여러 의사결정나무를 결합한 대표적인 배깅 기반 앙상블 모델이다.

부스팅은 이전 모델의 오류를 보완하며 여러 모델을 순차적으로 학습하는 방법이다.

스태킹은 여러 모델의 예측 결과를 다시 새로운 모델의 입력으로 사용해 최종 예측을 수행하는 방법이다.

인공신경망은 입력층, 은닉층, 출력층을 통해 복잡한 패턴을 학습하는 모델이다.

입력층은 데이터를 입력받는 층이고,
은닉층은 입력과 출력 사이에서 패턴을 학습하는 층이며,
출력층은 최종 예측 결과를 출력하는 층이다.

활성 함수는 뉴런의 출력값을 결정하고 신경망이 비선형 관계를 학습할 수 있도록 하는 함수이다.

비지도학습은 정답 라벨 없이 데이터의 구조, 패턴, 관계를 찾는 분석 방법이다.

군집 분석은 유사한 데이터끼리 그룹으로 묶는 비지도학습 방법이다.

K-means는 데이터를 K개의 군집으로 나누고, 중심점과의 거리를 기준으로 군집을 반복 갱신하는 방법이다.

계층적 군집분석은 데이터 간 거리를 기준으로 계층 구조를 만들어 군집을 형성하는 방법이다.

연관 분석은 함께 발생하는 항목 간의 관계를 찾는 분석 방법이다.

지지도는 전체 거래 중 특정 항목들이 함께 발생한 비율이다.

신뢰도는 A가 발생한 거래 중 B도 함께 발생한 비율이다.

향상도는 A가 B의 발생 가능성을 얼마나 높이는지 나타내는 지표이다.

향상도가 1보다 크면 양의 연관 관계,
1이면 독립,
1보다 작으면 음의 연관 관계로 해석한다.

Apriori 알고리즘은 빈번 항목 집합을 찾아 연관 규칙을 생성하는 알고리즘이다.

Apriori 알고리즘은 빈번 항목 집합의 부분집합도 반드시 빈번하다는 원리를 이용한다.
