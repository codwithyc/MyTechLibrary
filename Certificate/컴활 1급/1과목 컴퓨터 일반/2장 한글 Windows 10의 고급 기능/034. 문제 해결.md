## 034. 문제 해결

### 1. 메모리 부족 문제

**증상** : 프로그램 실행이 느려지거나, "메모리가 부족합니다" 메시지가 표시됩니다.

**해결 방법**

- 불필요한 프로그램을 종료합니다.
- **시작 프로그램**을 줄여 부팅 시 자동 실행되는 프로그램을 최소화합니다.
- **가상 메모리(페이징 파일)의 크기를 늘립니다.**
- **RAM을 추가로 장착**합니다.
- 작업 관리자에서 메모리를 많이 사용하는 프로세스를 확인하고 종료합니다.

#### 왜 가상 메모리를 늘리면 도움이 될까?

가상 메모리는 **하드디스크의 일부를 주기억장치처럼 사용하는 기법**입니다.

RAM이 부족할 때 당장 쓰지 않는 데이터를 하드디스크로 옮겨 두고,  
필요할 때 다시 가져오는 방식으로 **실제보다 큰 메모리를 쓰는 것처럼** 동작합니다.

다만 하드디스크는 RAM보다 훨씬 느리므로,  
가상 메모리에 지나치게 의존하면 **오히려 전체 속도가 떨어집니다.**

근본적인 해결책은 **RAM 추가**입니다.

---

### 2. 디스크 공간 부족 문제

**해결 방법**

- **디스크 정리**를 실행하여 임시 파일, 임시 인터넷 파일, 휴지통을 비웁니다.
- 사용하지 않는 프로그램을 제거합니다.
- 사용하지 않는 파일을 다른 드라이브나 외부 저장 장치로 옮깁니다.
- **저장 공간 센스**를 켜서 불필요한 파일이 자동으로 정리되게 합니다.

> **드라이브 조각 모음은 공간 확보와 관계가 없습니다.** (속도 향상 목적)

---

### 3. 시스템 속도 저하 문제

| 원인 | 해결 방법 |
| --- | --- |
| 파일 단편화 | 드라이브 조각 모음 및 최적화 실행 |
| 시작 프로그램 과다 | [설정] → [앱] → [시작 프로그램] 또는 작업 관리자에서 사용 안 함 처리 |
| 불필요한 파일 누적 | 디스크 정리 실행 |
| 바이러스 감염 | 백신으로 검사 및 치료 |
| 메모리 부족 | RAM 추가, 가상 메모리 조정 |
| 오래된 드라이버 | 장치 관리자에서 드라이버 업데이트 |

---

### 4. 프로그램이 응답하지 않을 때

- **`Ctrl` + `Shift` + `Esc`** 로 작업 관리자를 실행합니다.
- [프로세스] 탭에서 해당 프로그램을 선택하고 **[작업 끝내기]** 를 클릭합니다.
- 화면 전체가 멈춘 경우 `Ctrl` + `Alt` + `Delete`를 눌러 작업 관리자로 진입합니다.

#### 왜 강제 종료는 최후의 수단일까?

강제 종료는 프로그램에게 **정리할 시간을 주지 않고 즉시 끝내는 것**입니다.

그래서

- 저장하지 않은 작업 내용이 사라지고
- 임시 파일이 정리되지 않은 채 남을 수 있습니다.

가능하면 정상 종료를 먼저 시도하고,  
응답이 전혀 없을 때만 강제 종료해야 합니다.

### 5. 부팅 문제

| 증상 | 해결 방법 |
| --- | --- |
| 부팅이 되지 않음 | **안전 모드**로 부팅하여 문제가 되는 드라이버·프로그램을 제거합니다. |
| 최근 변경 후 문제 발생 | **시스템 복원**으로 이전 복원 지점으로 되돌립니다. |
| 부팅 파일 손상 | **시동 복구**를 실행합니다. |
| 반복적으로 문제 발생 | **이 PC 초기화**('내 파일 유지' 선택)를 수행합니다. |
| POST 단계에서 멈춤 | 메모리, 그래픽 카드 등 하드웨어 장착 상태를 확인합니다. |

### 6. 인쇄 문제

| 증상 | 원인 및 해결 |
| --- | --- |
| 인쇄가 되지 않음 | 프린터 전원·케이블 연결 확인, 기본 프린터 지정 여부 확인 |
| 대기열에 쌓여만 있음 | 인쇄 일시 중지 상태인지 확인, 스풀러 서비스 재시작 |
| 글자가 깨져 출력됨 | 프린터 드라이버를 최신 버전으로 재설치 |
| 인쇄가 느림 | 스풀 설정 확인, 해상도(DPI)를 낮춤 |
| 용지 걸림 | 프린터의 용지를 제거하고 인쇄 작업을 다시 실행 |

### 7. 네트워크 연결 문제

**확인 순서**

1. 랜 케이블 또는 Wi-Fi 연결 상태를 확인합니다.
2. **`ipconfig`** 로 IP 주소가 정상적으로 할당되었는지 확인합니다.
3. **`ping`** 으로 기본 게이트웨이(공유기)까지 연결되는지 확인합니다.
4. 외부 주소(예: `ping 8.8.8.8`)로 인터넷 연결을 확인합니다.
5. 도메인으로 `ping`이 실패하면 **DNS 서버 설정**을 확인합니다.
6. [설정] → [네트워크 및 인터넷] → [네트워크 문제 해결사]를 실행합니다.

#### 왜 IP는 되는데 도메인은 안 될까?

`ping 8.8.8.8`은 되지만 `ping www.google.com`은 실패한다면,  
**연결 자체는 정상이지만 이름을 IP로 바꾸지 못하는 상태**입니다.

즉, 네트워크 문제가 아니라 **DNS 문제**입니다.

이처럼 확인 순서를 **가까운 곳(내 PC) → 먼 곳(외부 서버)** 으로 진행하면,  
문제가 발생한 지점을 좁혀 나갈 수 있습니다.

### 8. 하드웨어 문제

| 증상 | 해결 방법 |
| --- | --- |
| 장치가 인식되지 않음 | 장치 관리자에서 **노란색 느낌표** 확인 → 드라이버 재설치 |
| 소리가 나지 않음 | 볼륨·음소거 확인, 출력 장치 선택 확인, 사운드 드라이버 확인 |
| 모니터에 화면이 나오지 않음 | 케이블 연결, 그래픽 카드 장착 상태, 해상도 설정 확인 |
| USB 장치 오류 | 다른 포트에 연결, 드라이버 재설치, 안전하게 제거 후 재연결 |

---

### 한 줄 정리

문제 해결의 기본은 **원인을 좁혀 가는 순서**이며,  
메모리 부족은 **불필요한 프로그램 종료 → 가상 메모리 조정 → RAM 추가**,  
디스크 부족은 **디스크 정리(조각 모음이 아님)**,  
부팅 문제는 **안전 모드 → 시스템 복원** 순으로 접근합니다.
