## 071. 멀티미디어 활용

### 1. 교육 분야

| 용어 | 설명 |
| --- | --- |
| **CAI (Computer Assisted Instruction)** | 컴퓨터를 이용한 **교육 보조 시스템**입니다. |
| **CBT (Computer Based Training)** | 컴퓨터를 이용한 훈련·자격 검정 시스템입니다. |
| **e-Learning** | 인터넷을 통해 시간과 장소에 구애받지 않고 학습하는 방식입니다. |
| **VOD 강의** | 원하는 시간에 강의를 반복해서 시청할 수 있는 서비스입니다. |

#### 왜 교육 분야에서 멀티미디어가 효과적일까?

전통적인 강의는 **모든 학습자가 같은 속도로** 진행됩니다.

멀티미디어 교육은

- 이해가 되지 않으면 **다시 볼 수 있고**
- 이미 아는 부분은 **건너뛸 수 있으며**
- 글로 설명하기 어려운 내용을 **영상과 애니메이션**으로 보여 줄 수 있습니다.

즉, **학습자 개인의 속도에 맞춘 학습(자기 주도 학습)** 이 가능해집니다.

---

### 2. 오락 / 문화 분야

| 용어 | 설명 |
| --- | --- |
| **VOD(주문형 비디오)** | 사용자가 원하는 시간에 원하는 영상을 시청하는 서비스입니다. |
| **IPTV** | 인터넷망을 통해 방송 콘텐츠를 제공하는 서비스입니다. |
| **인터넷 방송** | 인터넷을 통해 실시간으로 영상과 음성을 송출합니다. |
| **디지털 콘텐츠** | 게임, 음악, 영화 등 디지털 형태로 제작·유통되는 콘텐츠입니다. |
| **가상 현실(VR) / 증강 현실(AR)** | 가상 공간을 체험하거나 현실 위에 정보를 겹쳐 보여 줍니다. |

#### 왜 VOD가 기존 방송을 대체하게 되었을까?

기존 방송은 **방송사가 정한 시간에만** 시청할 수 있었습니다.  
시청자는 그 시간에 맞춰야 했습니다.

VOD는 **원하는 시간에 원하는 프로그램**을 볼 수 있으므로,  
콘텐츠 선택의 주도권이 **공급자에서 시청자로** 이동했습니다.

이는 앞서 살펴본 멀티미디어의 특징 중 **비선형성**이 실제로 구현된 사례입니다.

### 3. 산업 / 업무 분야

| 용어 | 설명 |
| --- | --- |
| **VCS(화상 회의 시스템)** | 멀리 떨어진 사람들이 영상과 음성으로 회의합니다. |
| **키오스크(Kiosk)** | 공공장소에 설치된 무인 정보 안내·주문 시스템입니다. |
| **POS 시스템** | 판매 시점의 정보를 실시간으로 관리하는 시스템입니다. |
| **CAD / CAM** | 컴퓨터를 이용한 **설계(CAD)** 와 **제조(CAM)** 시스템입니다. |
| **전자상거래(EC)** | 인터넷을 통해 상품을 사고파는 활동입니다. |
| **디지털 사이니지** | 디스플레이를 이용한 옥외 광고·안내 매체입니다. |

---

### 4. 의료 / 공공 분야

| 용어 | 설명 |
| --- | --- |
| **원격 진료(Telemedicine)** | 의료진과 환자가 원격으로 진료를 진행합니다. |
| **PACS** | 의료 영상(X-ray, CT, MRI)을 디지털로 저장·조회하는 시스템입니다. |
| **GIS(지리 정보 시스템)** | 지리 정보를 수집·분석하여 지도 형태로 제공합니다. |
| **ITS(지능형 교통 시스템)** | 교통 정보를 수집·제공하여 교통 흐름을 개선합니다. |

#### 왜 PACS가 의료 현장을 바꾸었을까?

과거에는 X-ray를 **필름으로 인화**하여 보관했습니다.

- 필름을 찾는 데 시간이 걸리고
- 분실이나 손상 위험이 있으며
- 여러 의료진이 **동시에 볼 수 없었습니다.**

PACS는 영상을 디지털로 저장하므로

- 즉시 검색하고
- 여러 곳에서 동시에 조회하며
- 과거 영상과 **바로 비교**할 수 있습니다.

### 5. 멀티미디어 콘텐츠 제작 과정

**기획 → 설계(스토리보드 작성) → 자료 수집 및 제작 → 저작(통합) → 테스트 → 배포**

| 단계 | 내용 |
| --- | --- |
| 기획 | 목적, 대상, 전달할 내용을 정합니다. |
| 설계 | **스토리보드**를 작성하여 화면 구성과 흐름을 설계합니다. |
| 자료 제작 | 텍스트, 이미지, 오디오, 비디오를 만들거나 수집합니다. |
| 저작 | 저작 도구로 자료를 **하나의 콘텐츠로 통합**합니다. |
| 테스트 | 오류와 사용성을 점검합니다. |
| 배포 | 웹, 앱, 저장 매체 등을 통해 배포합니다. |

#### 왜 스토리보드를 먼저 작성할까?

멀티미디어 콘텐츠는 **여러 사람이 나누어 제작**하는 경우가 많습니다.

디자이너, 영상 편집자, 개발자가 각자 작업하는데  
전체 그림이 공유되지 않으면 **완성 후 서로 맞지 않는 문제**가 생깁니다.

스토리보드는 **완성될 모습을 미리 그려 둔 설계도**이므로,

- 참여자들이 같은 목표를 공유하고
- 제작 전에 문제를 발견하여 **수정 비용을 줄일 수 있습니다.**

---

### 6. 멀티미디어 활용 시 고려 사항

- 저작권을 확인하고 **정당한 이용 절차**를 거쳐야 합니다.
- 사용자의 환경(속도, 기기, 해상도)을 고려해야 합니다.
- 파일 크기와 품질의 **균형**을 맞춰야 합니다.
- 다양한 사용자를 위한 **접근성**(자막, 대체 텍스트)을 고려해야 합니다.

---

### 한 줄 정리

멀티미디어는 **교육(CAI·e-Learning), 오락(VOD·IPTV·VR), 업무(VCS·키오스크·CAD/CAM), 의료·공공(PACS·GIS·ITS)** 등 전 분야에 활용되며,  
제작은 **기획 → 설계(스토리보드) → 자료 제작 → 저작 → 테스트 → 배포** 순으로 진행됩니다.
