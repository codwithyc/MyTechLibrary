# 연관 분석

연관 분석은 정형 데이터 마이닝에서 **어떤 항목들이 함께 발생하는지**를 찾는 분석 기법이다.

가장 대표적인 예시는 장바구니 분석이다.

```markdown
연관 분석 = 데이터 안에서 함께 자주 발생하는 항목 간의 관계를 찾는 분석 기법
```

예를 들어 마트 구매 데이터에서 다음과 같은 패턴을 찾을 수 있다.

```markdown
기저귀를 구매한 고객은 맥주도 함께 구매하는 경향이 있다.
라면을 구매한 고객은 김치도 함께 구매하는 경향이 있다.
노트북을 구매한 고객은 마우스나 노트북 가방도 함께 구매하는 경향이 있다.
```

즉, 연관 분석은 **A를 구매한 사람이 B도 구매하는가?** 같은 관계를 찾는 분석이다.

ADsP 시험에서는 계산보다 다음 개념 구분이 중요하다.

* 연관 분석의 개념
* 장바구니 분석
* 연관 규칙
* 지지도, 신뢰도, 향상도
* Apriori 알고리즘
* 연관 분석의 장단점
* 연관 분석 활용 사례

기존 정리처럼 개념 설명을 먼저 보고 표로 압축하는 방식이 시험 직전 복습에 좋다. 

---

# 01. 연관 분석의 개념

## 연관 분석의 정의

**연관 분석(Association Analysis)**은 대량의 거래 데이터에서 항목 간의 연관 규칙을 찾아내는 분석 기법이다.

여기서 항목은 상품, 서비스, 행동, 이벤트 등이 될 수 있다.

예를 들어 고객의 구매 데이터가 다음과 같다고 하자.

| 거래ID | 구매 항목       |
| ---- | ----------- |
| T001 | 우유, 빵, 버터   |
| T002 | 우유, 기저귀, 맥주 |
| T003 | 라면, 김치      |
| T004 | 기저귀, 맥주, 과자 |
| T005 | 우유, 빵       |

연관 분석은 이런 거래 데이터에서 다음과 같은 규칙을 찾는다.

```markdown
기저귀 → 맥주
우유 → 빵
라면 → 김치
```

이때 `기저귀 → 맥주`는 “기저귀를 구매한 고객은 맥주도 구매하는 경향이 있다”는 의미다.

```markdown
연관 분석은 대량의 거래 데이터에서 항목 간의 함께 발생하는 패턴을 찾는 분석이다.
```

---

# 02. 장바구니 분석

## 장바구니 분석의 개념

**장바구니 분석(Market Basket Analysis)**은 연관 분석의 대표적인 활용 사례다.

고객이 장바구니에 어떤 상품들을 함께 담는지 분석하여 상품 간 관계를 찾는다.

```markdown
장바구니 분석 = 고객의 구매 장바구니 데이터를 이용해 함께 구매되는 상품 간 관계를 찾는 분석
```

예를 들어 다음과 같은 질문에 답할 수 있다.

```markdown
어떤 상품들이 함께 자주 팔리는가?
A 상품을 산 고객은 B 상품도 구매하는가?
어떤 상품을 묶음 상품으로 구성하면 좋은가?
어떤 상품을 가까운 진열대에 배치하면 좋은가?
추천 상품으로 무엇을 보여주면 좋은가?
```

장바구니 분석은 유통, 이커머스, 추천 시스템에서 많이 사용된다.

---

## 장바구니 분석 활용 예시

| 활용       | 설명                      |
| -------- | ----------------------- |
| 상품 진열    | 함께 구매되는 상품을 가까운 위치에 배치  |
| 묶음 상품 구성 | 연관성이 높은 상품을 패키지로 판매     |
| 추천 시스템   | 특정 상품 구매 고객에게 관련 상품 추천  |
| 프로모션 기획  | 함께 구매 가능성이 높은 상품에 할인 적용 |
| 교차 판매    | A 상품 구매 고객에게 B 상품 구매 유도 |

시험에서는 이렇게 이해하면 된다.

```markdown
장바구니 분석은 고객의 구매 데이터를 분석하여 함께 구매되는 상품 관계를 찾는 연관 분석의 대표 사례이다.
```

# 03. 연관 규칙

## 연관 규칙의 개념

**연관 규칙(Association Rule)**은 항목 간의 관계를 `A → B` 형태로 표현한 것이다.

```markdown
A → B
```

이 규칙은 “A가 발생하면 B도 발생하는 경향이 있다”는 의미다.

예를 들어 다음과 같다.

```markdown
기저귀 → 맥주
우유 → 빵
라면 → 김치
노트북 → 마우스
```

여기서 왼쪽의 A를 **조건부**, 오른쪽의 B를 **결과부**라고 볼 수 있다.

| 구성    | 의미                | 예시       |
| ----- | ----------------- | -------- |
| 조건부   | 먼저 발생한 항목         | 기저귀      |
| 결과부   | 함께 발생할 가능성이 있는 항목 | 맥주       |
| 연관 규칙 | 조건부와 결과부의 관계      | 기저귀 → 맥주 |

```markdown
연관 규칙은 특정 항목이 발생했을 때 다른 항목이 함께 발생하는 관계를 나타낸다.
```

---

## 연관 규칙 예시

| 연관 규칙       | 의미                        |
| ----------- | ------------------------- |
| `우유 → 빵`    | 우유를 산 고객은 빵도 살 가능성이 있다    |
| `기저귀 → 맥주`  | 기저귀를 산 고객은 맥주도 살 가능성이 있다  |
| `노트북 → 마우스` | 노트북을 산 고객은 마우스도 살 가능성이 있다 |
| `라면 → 김치`   | 라면을 산 고객은 김치도 살 가능성이 있다   |

연관 규칙은 단순히 함께 발생했다는 사실만 보는 것이 아니라,
그 규칙이 얼마나 자주 나타나고, 얼마나 신뢰할 수 있고, 우연보다 얼마나 강한 관계인지 평가해야 한다.

이를 위해 사용하는 대표 지표가 다음 3가지다.

```markdown
지지도
신뢰도
향상도
```

# 04. 지지도, Support

## 지지도의 개념

**지지도(Support)**는 전체 거래 중에서 특정 항목 집합이 함께 등장한 비율이다.

즉, `A와 B가 함께 발생한 거래가 전체 거래에서 얼마나 자주 나타나는가`를 의미한다.

```markdown
지지도 = 전체 거래 중 A와 B가 함께 포함된 거래의 비율
```

공식은 다음과 같다.

```markdown
Support(A → B) = P(A ∩ B)
```

또는 거래 수 기준으로 보면 다음과 같다.

```markdown
지지도 = A와 B가 함께 포함된 거래 수 / 전체 거래 수
```

---

## 지지도 예시

전체 거래가 100건이고, 그중 우유와 빵이 함께 구매된 거래가 20건이라고 하자.

```markdown
지지도(우유 → 빵) = 20 / 100 = 0.2
```

즉, 전체 거래의 20%에서 우유와 빵이 함께 구매되었다는 의미다.

| 구분                 |    값 |
| ------------------ | ---: |
| 전체 거래 수            | 100건 |
| 우유와 빵이 함께 구매된 거래 수 |  20건 |
| 지지도                |  0.2 |

시험에서는 이렇게 이해하면 된다.

```markdown
지지도는 전체 거래에서 해당 항목 조합이 얼마나 자주 나타나는지를 의미한다.
```

---

## 지지도의 의미

지지도가 높다는 것은 해당 규칙이 데이터에서 자주 등장한다는 의미다.

하지만 지지도만 높다고 좋은 규칙은 아니다.

예를 들어 물은 워낙 많이 팔리기 때문에 여러 상품과 함께 자주 등장할 수 있다.
하지만 이것이 반드시 의미 있는 연관 관계라고 보기는 어렵다.

```markdown
지지도는 규칙의 빈도를 나타내지만, 규칙의 강도를 단독으로 판단하기에는 부족하다.
```

---

# 05. 신뢰도, Confidence

## 신뢰도의 개념

**신뢰도(Confidence)**는 A가 발생한 거래 중에서 B도 함께 발생한 거래의 비율이다.

즉, `A를 구매한 고객 중 B도 구매한 고객이 얼마나 되는가`를 의미한다.

```markdown
신뢰도 = A가 발생한 거래 중 B도 함께 발생한 거래의 비율
```

공식은 다음과 같다.

```markdown
Confidence(A → B) = P(B|A) = P(A ∩ B) / P(A)
```

거래 수 기준으로 보면 다음과 같다.

```markdown
신뢰도 = A와 B가 함께 포함된 거래 수 / A가 포함된 거래 수
```

---

## 신뢰도 예시

전체 거래 중 우유를 구매한 거래가 40건이고,
그중 우유와 빵을 함께 구매한 거래가 20건이라고 하자.

```markdown
신뢰도(우유 → 빵) = 20 / 40 = 0.5
```

즉, 우유를 구매한 고객 중 50%가 빵도 함께 구매했다는 의미다.

| 구분               |   값 |
| ---------------- | --: |
| 우유 구매 거래 수       | 40건 |
| 우유와 빵 함께 구매 거래 수 | 20건 |
| 신뢰도              | 0.5 |

시험에서는 이렇게 이해하면 된다.

```markdown
신뢰도는 A가 발생했을 때 B도 발생할 조건부 확률이다.
```

---

## 신뢰도의 의미

신뢰도가 높다는 것은 A가 발생했을 때 B가 함께 발생할 가능성이 높다는 의미다.

예를 들어 다음 규칙을 보자.

```markdown
노트북 → 마우스
```

신뢰도가 0.8이라면, 노트북을 산 고객 중 80%가 마우스도 샀다는 의미다.

하지만 신뢰도만으로도 완전하지는 않다.
왜냐하면 B가 원래 자주 발생하는 항목이라면 신뢰도가 높게 나올 수 있기 때문이다.

```markdown
신뢰도는 조건부 확률을 나타내지만, 결과 항목 B의 기본 발생률을 고려하지 못할 수 있다.
```

---

# 06. 향상도, Lift

## 향상도의 개념

**향상도(Lift)**는 A가 발생했을 때 B가 발생할 가능성이, B가 일반적으로 발생할 가능성보다 얼마나 높은지를 나타내는 지표다.

즉, A와 B가 우연히 함께 발생한 것인지, 실제로 의미 있는 연관 관계가 있는지를 판단할 때 사용한다.

```markdown
향상도 = A가 B의 발생 가능성을 얼마나 증가시키는지 나타내는 지표
```

공식은 다음과 같다.

```markdown
Lift(A → B) = Confidence(A → B) / Support(B)
```

또는 확률로 표현하면 다음과 같다.

```markdown
Lift(A → B) = P(A ∩ B) / [P(A) × P(B)]
```

---

## 향상도 해석

향상도는 1을 기준으로 해석한다.

|      향상도 | 해석             |
| -------: | -------------- |
| Lift > 1 | A와 B는 양의 연관 관계 |
| Lift = 1 | A와 B는 서로 독립    |
| Lift < 1 | A와 B는 음의 연관 관계 |

---

## 향상도 예시

우유를 구매한 고객 중 빵도 구매한 비율, 즉 신뢰도가 0.5라고 하자.
그리고 전체 거래에서 빵이 구매된 비율이 0.25라고 하자.

```markdown
Lift(우유 → 빵) = 0.5 / 0.25 = 2
```

향상도가 2라는 것은, 우유를 구매했을 때 빵을 구매할 가능성이 일반적인 빵 구매 가능성보다 2배 높다는 의미다.

시험에서는 이렇게 이해하면 된다.

```markdown
향상도는 1보다 크면 양의 연관 관계,
1이면 독립,
1보다 작으면 음의 연관 관계로 해석한다.
```

# 07. 지지도, 신뢰도, 향상도 비교

연관 분석에서 가장 중요한 지표는 지지도, 신뢰도, 향상도다.

| 지표  | 의미                  | 공식                        | 핵심           |
| --- | ------------------- | ------------------------- | ------------ |
| 지지도 | A와 B가 함께 발생한 비율     | `P(A ∩ B)`                | 얼마나 자주 나타나는가 |
| 신뢰도 | A가 발생했을 때 B도 발생한 비율 | `P(B\|A)`                 | 조건부 확률       |
| 향상도 | A가 B 발생 가능성을 높이는 정도 | `Confidence / Support(B)` | 우연인지 관계인지 판단 |

암기 방식은 다음과 같다.

```markdown
지지도 = 전체 중 같이 나온 비율
신뢰도 = A 중에서 B도 나온 비율
향상도 = A가 B 발생을 얼마나 높였는가
```

---

## 예시로 한 번에 이해하기

전체 거래가 100건이라고 하자.

| 항목          | 거래 수 |
| ----------- | ---: |
| 우유 구매       |  40건 |
| 빵 구매        |  25건 |
| 우유와 빵 함께 구매 |  20건 |
| 전체 거래       | 100건 |

### 1) 지지도

```markdown
Support(우유 → 빵) = 20 / 100 = 0.2
```

전체 거래 중 우유와 빵이 함께 나온 비율이다.

### 2) 신뢰도

```markdown
Confidence(우유 → 빵) = 20 / 40 = 0.5
```

우유를 산 거래 중 빵도 산 비율이다.

### 3) 향상도

```markdown
Lift(우유 → 빵) = 0.5 / 0.25 = 2
```

우유를 샀을 때 빵 구매 가능성이 일반적인 빵 구매 가능성보다 2배 높다는 의미다.

# 08. Apriori 알고리즘

## Apriori 알고리즘의 개념

**Apriori 알고리즘**은 연관 분석에서 자주 사용되는 대표적인 알고리즘이다.

대량의 거래 데이터에서 빈번하게 나타나는 항목 집합을 찾고, 이를 바탕으로 연관 규칙을 생성한다.

```markdown
Apriori 알고리즘 = 빈번한 항목 집합을 찾아 연관 규칙을 생성하는 알고리즘
```

Apriori 알고리즘의 핵심 아이디어는 다음과 같다.

```markdown
자주 등장하는 항목 집합의 부분집합도 반드시 자주 등장한다.
```

반대로 말하면 다음과 같다.

```markdown
어떤 항목 집합이 자주 등장하지 않는다면,
그 항목 집합을 포함하는 더 큰 항목 집합도 자주 등장할 수 없다.
```

이 성질을 이용해 불필요한 후보를 줄인다.

---

## Apriori 알고리즘의 핵심 원리

예를 들어 `{우유, 빵, 버터}`라는 항목 집합이 자주 등장한다고 하자.

그렇다면 이 항목 집합의 부분집합도 자주 등장해야 한다.

```markdown
{우유}
{빵}
{버터}
{우유, 빵}
{우유, 버터}
{빵, 버터}
```

반대로 `{우유, 버터}`가 자주 등장하지 않는다면,
`{우유, 빵, 버터}`도 자주 등장하기 어렵다.

```markdown
Apriori는 빈번하지 않은 항목 집합을 포함하는 후보를 제거하여 탐색 범위를 줄인다.
```

## Apriori 알고리즘 절차

Apriori 알고리즘은 일반적으로 다음 순서로 진행된다.

```markdown
최소 지지도 설정
→ 빈번한 1개 항목 집합 탐색
→ 빈번한 2개 항목 집합 탐색
→ 더 큰 항목 집합으로 확장
→ 최소 지지도를 만족하지 않는 후보 제거
→ 연관 규칙 생성
→ 신뢰도와 향상도 평가
```

| 단계          | 설명                           |
| ----------- | ---------------------------- |
| 최소 지지도 설정   | 자주 등장한다고 판단할 기준 설정           |
| 빈번 항목 집합 탐색 | 기준 이상으로 자주 등장하는 항목 조합 탐색     |
| 후보 생성       | 더 큰 항목 조합 후보 생성              |
| 후보 제거       | 최소 지지도를 만족하지 못하는 후보 제거       |
| 규칙 생성       | 빈번 항목 집합으로부터 `A → B` 규칙 생성   |
| 규칙 평가       | 신뢰도, 향상도 등을 기준으로 의미 있는 규칙 선택 |

시험에서는 절차 전체보다 핵심 원리를 기억하는 것이 중요하다.

```markdown
Apriori 알고리즘은 최소 지지도를 기준으로 빈번 항목 집합을 찾고,
이를 바탕으로 연관 규칙을 생성한다.
```

# 09. 연관 분석의 장점

| 장점            | 설명                         |
| ------------- | -------------------------- |
| 이해가 쉬움        | `A → B` 형태로 결과가 직관적        |
| 비지도 학습 가능     | 정답 라벨 없이 패턴 발견 가능          |
| 구매 패턴 분석에 유용  | 장바구니 분석, 추천, 진열 전략에 활용 가능  |
| 대량 거래 데이터에 적합 | 많은 거래 데이터에서 규칙 발견 가능       |
| 의사결정 활용 용이    | 마케팅, 프로모션, 상품 배치에 바로 활용 가능 |

연관 분석은 결과가 규칙 형태로 나오기 때문에 현업 담당자가 이해하기 쉽다.

예를 들어 다음 규칙은 설명하기 쉽다.

```markdown
라면 → 김치
노트북 → 마우스
기저귀 → 맥주
```

```markdown
연관 분석은 결과가 직관적이고 마케팅 전략에 활용하기 쉽다.
```

# 10. 연관 분석의 단점

| 단점                 | 설명                              |
| ------------------ | ------------------------------- |
| 규칙이 너무 많이 생성될 수 있음 | 항목이 많으면 연관 규칙이 과도하게 많아짐         |
| 의미 없는 규칙 가능        | 지지도나 신뢰도는 높아도 실제 의미가 없을 수 있음    |
| 인과관계 설명 불가         | 함께 발생한다고 해서 원인과 결과를 의미하지는 않음    |
| 희귀하지만 중요한 규칙 누락 가능 | 지지도 기준이 높으면 드문 중요한 패턴이 제외될 수 있음 |
| 계산 비용 증가           | 항목 수가 많아질수록 후보 조합이 급증           |

특히 시험에서는 **연관관계가 인과관계를 의미하지 않는다**는 점이 중요하다.

```markdown
연관 분석은 항목 간 함께 발생하는 관계를 찾는 것이며,
원인과 결과를 증명하는 분석은 아니다.
```

# 12. 연관 분석과 다른 분석 기법 비교

# 시험 직전 암기 문장

```markdown
연관 분석은 대량의 거래 데이터에서 항목 간 함께 발생하는 관계를 찾는 비지도 학습 기법이다.

연관 분석의 대표적인 예는 장바구니 분석이며,
고객이 함께 구매하는 상품 간의 관계를 찾는 데 활용된다.

연관 규칙은 A → B 형태로 표현하며,
A가 발생했을 때 B도 함께 발생하는 경향이 있다는 의미이다.

지지도는 전체 거래 중 A와 B가 함께 발생한 거래의 비율이며,
Support(A → B) = P(A ∩ B)로 표현한다.

신뢰도는 A가 발생한 거래 중 B도 함께 발생한 거래의 비율이며,
Confidence(A → B) = P(B|A) = P(A ∩ B) / P(A)로 표현한다.

향상도는 A가 B의 발생 가능성을 얼마나 높이는지를 나타내는 지표이며,
Lift(A → B) = Confidence(A → B) / Support(B)로 계산한다.

향상도가 1보다 크면 A와 B는 양의 연관 관계가 있고,
1이면 독립이며,
1보다 작으면 음의 연관 관계가 있다고 해석한다.

Apriori 알고리즘은 최소 지지도를 기준으로 빈번 항목 집합을 찾고,
이를 바탕으로 연관 규칙을 생성하는 알고리즘이다.

Apriori 알고리즘은 빈번 항목 집합의 부분집합도 반드시 빈번하다는 원리를 이용해
불필요한 후보 항목 집합을 제거한다.

연관 분석은 상품 추천, 교차 판매, 묶음 상품 구성,
상품 진열 최적화, 프로모션 기획 등에 활용된다.

연관 분석은 결과가 A → B 형태로 직관적이어서 이해하기 쉽지만,
규칙이 너무 많이 생성될 수 있고 의미 없는 규칙이 포함될 수 있다.

또한 연관 분석은 항목 간 함께 발생하는 관계를 찾는 것이며,
원인과 결과를 설명하는 인과관계 분석은 아니다.

R에서는 arules 패키지를 이용해 연관 분석을 수행할 수 있고,
apriori() 함수는 Apriori 알고리즘으로 연관 규칙을 생성할 때 사용한다.
```
