# 3장 데이터 분석


## Chapter 01. 데이터 분석 이해

데이터 분석 이해는 데이터 분석을 시작하기 전에 알아야 할 기본 개념을 다루는 영역이다.
데이터를 왜 수집하는지, 수집 목적에 따라 분석에 어떤 영향을 주는지, 그리고 알고리즘·머신러닝·인공지능·데이터 마이닝의 개념을 구분하는 것이 핵심이다.

또한 분석을 수행하기 전 데이터 처리 과정과 분석 방법의 종류를 이해해야 한다.

```markdown
데이터 분석 이해 = 데이터를 수집하고 처리한 뒤, 목적에 맞는 분석 방법을 선택하기 위한 기초 개념
```

### 01. 데이터의 수집과 알고리즘 활용

데이터의 수집과 알고리즘 활용에서는 데이터가 어떤 목적으로 수집되는지, 그리고 수집된 데이터를 분석하기 위해 어떤 알고리즘과 분석 기술이 사용되는지를 이해해야 한다.

기업에서 데이터는 보통 서비스 운영 과정에서 자연스럽게 생성된다.
하지만 운영 목적으로 수집된 데이터와 분석 목적으로 활용되는 데이터는 목적과 구조가 다르다.

```markdown
운영 목적 데이터 = 업무 처리와 서비스 제공 중심
분석 목적 데이터 = 의사결정, 예측, 패턴 발견 중심
```

#### 데이터 수집 목적의 차이

데이터는 수집 목적에 따라 활용 방식이 달라진다.

같은 고객 데이터라도 운영 목적에서는 로그인, 주문, 결제, 배송을 처리하기 위해 사용되고, 분석 목적에서는 고객 행동 분석, 구매 예측, 이탈 예측, 추천 시스템 등에 사용된다.

즉, 데이터 수집 목적의 차이를 이해한다는 것은 데이터가 어떤 업무 맥락에서 생성되었고, 분석에 활용하려면 어떤 정제와 가공이 필요한지 이해하는 것이다.

```markdown
데이터 수집 목적의 차이 = 운영을 위해 쌓인 데이터와 분석을 위해 필요한 데이터의 목적과 활용 방식이 다르다는 개념
```

**1) 기업 활동과 서비스 운영 목적**

기업 활동과 서비스 운영 목적의 데이터 수집은 현재 업무를 정확하게 처리하고 서비스를 안정적으로 제공하는 것이 목적이다.

예를 들어 쇼핑몰에서는 회원가입, 로그인, 상품 주문, 결제, 배송, 환불, 고객 문의 처리 과정에서 데이터가 생성된다.
이 데이터는 고객에게 서비스를 제공하고 내부 업무를 처리하기 위해 필요하다.

```markdown
기업 활동과 서비스 운영 목적 데이터 = 업무 처리와 서비스 제공을 위해 수집되는 데이터
```

| 구분     | 설명                                   |
| ------ | ------------------------------------ |
| 목적     | 업무 처리, 서비스 운영, 거래 기록                 |
| 중심     | 현재 발생한 업무를 정확히 처리                    |
| 중요 요소  | 정확성, 즉시성, 안정성                        |
| 데이터 구조 | 운영 시스템 중심                            |
| 예시     | 회원 정보, 주문 정보, 결제 정보, 배송 정보, 고객 문의 정보 |

운영 목적 데이터는 서비스가 정상적으로 동작하기 위해 필요한 데이터이다.
따라서 분석보다 트랜잭션 처리, 정확한 저장, 빠른 조회, 안정적인 운영이 더 중요하다.

```markdown
운영 목적 데이터는 서비스 제공과 업무 처리를 위해 생성되는 데이터이다.
```

**2) 데이터 분석 목적**

데이터 분석 목적의 데이터 수집은 의사결정, 문제 해결, 예측, 패턴 발견이 목적이다.

운영 목적 데이터가 “현재 업무를 처리하는 것”에 초점을 둔다면, 분석 목적 데이터는 “데이터를 통해 의미 있는 정보를 얻는 것”에 초점을 둔다.

```markdown
데이터 분석 목적 데이터 = 의사결정과 문제 해결을 위해 수집·가공되는 데이터
```

예를 들어 고객 주문 데이터를 분석 목적에 활용하면 다음과 같은 질문에 답할 수 있다.

```markdown
어떤 고객이 자주 구매하는가?
어떤 고객이 이탈할 가능성이 높은가?
어떤 상품이 함께 구매되는가?
특정 기간에 매출이 감소한 원인은 무엇인가?
```

| 구분     | 설명                                  |
| ------ | ----------------------------------- |
| 목적     | 의사결정, 예측, 패턴 발견, 문제 해결              |
| 중심     | 과거 데이터 기반 분석과 미래 예측                 |
| 중요 요소  | 데이터 품질, 일관성, 분석 가능성                 |
| 데이터 구조 | 분석 주제 중심                            |
| 예시     | 고객 행동 데이터, 구매 이력, 방문 로그, 캠페인 반응 데이터 |

분석 목적 데이터는 과거 데이터를 바탕으로 패턴을 찾고 미래 행동을 예측하기 위해 활용된다.

```markdown
분석 목적 데이터는 인사이트 도출과 의사결정을 위해 활용되는 데이터이다.
```

**3) 수집 목적 차이에 따른 분석 영향**

데이터가 어떤 목적으로 수집되었는지는 분석 결과에 큰 영향을 준다.

운영 목적 데이터는 업무 처리를 위해 만들어졌기 때문에 분석에 필요한 정보가 부족하거나, 분석하기 어려운 형태로 저장되어 있을 수 있다.

예를 들어 주문 시스템에는 주문 번호, 결제 금액, 배송 상태는 잘 저장되어 있지만, 고객이 왜 구매했는지, 어떤 광고를 보고 유입되었는지, 구매 전 어떤 상품을 비교했는지는 없을 수 있다.

```markdown
운영 데이터는 그대로 분석하기 어려울 수 있으며, 분석 목적에 맞게 정제와 가공이 필요하다.
```

| 구분     | 운영 목적 데이터     | 분석 목적 데이터           |
| ------ | ------------- | ------------------- |
| 목적     | 업무 처리, 서비스 제공 | 의사결정, 예측, 패턴 발견     |
| 중심     | 현재 트랜잭션 처리    | 과거 데이터 분석과 미래 예측    |
| 중요 요소  | 정확성, 즉시성, 안정성 | 품질, 일관성, 분석 가능성     |
| 데이터 구조 | 운영 시스템 중심     | 분석 주제 중심            |
| 활용 예시  | 주문 처리, 결제, 배송 | 고객 이탈 예측, 추천, 매출 분석 |

시험에서는 이렇게 정리하면 된다.

```markdown
기업 활동과 서비스 운영 목적의 데이터는 업무 처리를 위해 수집되고,
데이터 분석 목적의 데이터는 의사결정과 문제 해결을 위해 수집된다.
```

#### 머신러닝과 데이터 마이닝

머신러닝과 데이터 마이닝은 모두 데이터를 활용한다는 공통점이 있다.

하지만 머신러닝은 데이터를 학습하여 예측이나 분류를 수행하는 데 초점이 있고, 데이터 마이닝은 대량의 데이터에서 숨겨진 패턴과 규칙을 발견하는 데 초점이 있다.

```markdown
머신러닝 = 데이터를 학습해 예측·분류하는 기술
데이터 마이닝 = 대량 데이터에서 패턴과 규칙을 발견하는 과정
```

**1) 알고리즘 (Algorithm)**

알고리즘은 문제를 해결하기 위한 정해진 절차나 규칙이다.

컴퓨터가 어떤 문제를 해결하려면 입력값을 받아 정해진 순서에 따라 처리하고 결과를 출력해야 한다.
이때 사용되는 절차가 알고리즘이다.

```markdown
알고리즘 = 문제 해결을 위한 단계적 절차
```

예를 들어 평균을 구하는 알고리즘은 다음과 같다.

```markdown
1. 모든 값을 더한다.
2. 데이터의 개수를 센다.
3. 합계를 데이터 개수로 나눈다.
```

데이터 분석에서 알고리즘은 데이터를 분류하거나, 예측하거나, 군집화하거나, 연관 규칙을 찾는 데 사용된다.

| 알고리즘    | 활용    |
| ------- | ----- |
| 의사결정나무  | 분류 분석 |
| K-means | 군집 분석 |
| Apriori | 연관 분석 |
| 선형회귀    | 수치 예측 |
| 로지스틱 회귀 | 이진 분류 |

```markdown
알고리즘은 데이터를 입력받아 정해진 절차에 따라 원하는 결과를 도출하는 방법이다.
```

**2) 머신러닝 (Machine Learning, 기계학습)**

머신러닝은 컴퓨터가 데이터를 이용해 패턴을 학습하고, 그 학습 결과를 바탕으로 예측이나 판단을 수행하는 기술이다.

사람이 모든 규칙을 직접 입력하지 않아도, 알고리즘이 데이터에서 규칙을 찾아낸다는 점이 핵심이다.

```markdown
머신러닝 = 데이터로부터 패턴을 학습하여 예측이나 분류를 수행하는 기술
```

예를 들어 스팸 메일 분류에서는 과거의 스팸 메일과 정상 메일 데이터를 학습한다.
이후 새로운 메일이 들어오면 학습한 패턴을 바탕으로 스팸 여부를 예측한다.

머신러닝은 크게 다음과 같이 구분할 수 있다.

| 구분    | 설명               | 예시           |
| ----- | ---------------- | ------------ |
| 지도학습  | 정답이 있는 데이터를 학습   | 분류, 회귀       |
| 비지도학습 | 정답 없이 데이터 구조를 탐색 | 군집, 연관 분석    |
| 강화학습  | 보상을 통해 최적 행동을 학습 | 게임 AI, 로봇 제어 |

ADsP에서는 특히 지도학습과 비지도학습의 구분이 중요하다.

```markdown
지도학습은 정답이 있는 데이터를 학습하고,
비지도학습은 정답 없이 데이터의 구조나 패턴을 찾는다.
```

**3) 인공지능 (Artificial Intelligence, AI)**

인공지능은 컴퓨터가 인간의 지능적 행동을 수행하도록 하는 기술 또는 학문 분야다.

여기서 지능적 행동이란 학습, 추론, 판단, 문제 해결, 언어 이해, 이미지 인식 등을 의미한다.

```markdown
인공지능 = 컴퓨터가 인간처럼 학습, 추론, 판단을 수행하도록 하는 기술
```

인공지능, 머신러닝, 딥러닝의 관계는 다음과 같이 이해하면 된다.

```markdown
인공지능 > 머신러닝 > 딥러닝
```

| 구분   | 설명                          |
| ---- | --------------------------- |
| 인공지능 | 인간의 지능적 행동을 컴퓨터로 구현하는 넓은 개념 |
| 머신러닝 | 데이터를 통해 패턴을 학습하는 인공지능 기술    |
| 딥러닝  | 인공신경망 기반의 머신러닝 방법           |

예를 들어 음성 인식, 이미지 분류, 자율주행, 추천 시스템, 챗봇 등이 인공지능 기술에 해당한다.

```markdown
인공지능은 가장 넓은 개념이고, 머신러닝은 인공지능을 구현하는 방법 중 하나이다.
```

**4) 데이터 마이닝(Data Mining)**

데이터 마이닝은 대량의 데이터에서 의미 있는 패턴, 규칙, 관계를 발견하는 과정이다.

```markdown
데이터 마이닝 = 대량의 데이터에서 숨겨진 패턴과 규칙을 발견하는 과정
```

예를 들어 쇼핑몰 구매 데이터를 분석하면 다음과 같은 패턴을 찾을 수 있다.

```markdown
기저귀를 구매한 고객은 맥주도 함께 구매하는 경향이 있다.
최근 방문 횟수가 줄어든 고객은 이탈 가능성이 높다.
구매 패턴이 비슷한 고객들을 여러 그룹으로 나눌 수 있다.
```

데이터 마이닝의 대표 기법은 다음과 같다.

| 기법    | 설명                 | 예시        |
| ----- | ------------------ | --------- |
| 분류 분석 | 데이터를 미리 정해진 범주로 분류 | 이탈/비이탈 예측 |
| 군집 분석 | 유사한 데이터끼리 그룹화      | 고객 세분화    |
| 연관 분석 | 함께 발생하는 항목 관계 탐색   | 장바구니 분석   |
| 회귀 분석 | 변수 간 관계로 수치 예측     | 매출 예측     |
| 이상 탐지 | 비정상 패턴 탐색          | 이상 거래 탐지  |

머신러닝과 데이터 마이닝의 차이는 다음과 같다.

| 구분 | 머신러닝             | 데이터 마이닝           |
| -- | ---------------- | ----------------- |
| 핵심 | 데이터를 학습해 예측·분류   | 데이터에서 패턴·규칙 발견    |
| 목적 | 모델 학습과 예측 성능 향상  | 숨겨진 지식과 인사이트 발견   |
| 중심 | 알고리즘과 모델         | 데이터 탐색과 지식 발견     |
| 예시 | 이탈 예측 모델, 이미지 분류 | 장바구니 분석, 고객 패턴 발견 |

```markdown
머신러닝은 학습과 예측에 초점이 있고,
데이터 마이닝은 데이터에서 의미 있는 패턴과 규칙을 찾는 데 초점이 있다.
```

### 02. 데이터 분석 기법 이해

데이터 분석 기법 이해에서는 데이터를 분석하기 전에 어떤 처리 과정이 필요한지, 그리고 분석 목적에 따라 어떤 분석 방법을 사용할 수 있는지 학습한다.

데이터 분석은 단순히 알고리즘을 적용하는 과정이 아니다.
분석 전에 데이터를 정제하고, 변환하고, 결합하고, 분석 목적에 맞게 준비해야 한다.

```markdown
데이터 분석 기법 이해 = 데이터 처리 과정과 분석 방법의 종류를 이해하는 영역
```

#### 데이터 처리

데이터 처리는 원천 데이터를 분석 가능한 형태로 만드는 과정이다.

현실의 데이터는 결측값, 이상값, 중복, 형식 오류, 단위 차이, 테이블 분산 등의 문제가 있을 수 있다.
따라서 분석 전에 데이터를 정리하고 가공해야 한다.

```markdown
데이터 처리 = 원천 데이터를 분석 가능한 형태로 정제·변환·결합하는 과정
```

**1) 개요**

데이터 처리는 데이터 분석의 품질을 결정하는 중요한 과정이다.

아무리 좋은 분석 알고리즘을 사용해도 데이터가 부정확하거나 불완전하면 분석 결과를 신뢰하기 어렵다.

```markdown
Garbage In, Garbage Out
```

즉, 잘못된 데이터가 들어가면 잘못된 결과가 나온다.

데이터 처리의 주요 목적은 다음과 같다.

| 목적        | 설명                           |
| --------- | ---------------------------- |
| 분석 가능성 확보 | 데이터를 분석 도구에서 사용할 수 있는 형태로 정리 |
| 품질 향상     | 결측값, 이상값, 오류 데이터 처리          |
| 일관성 확보    | 데이터 형식, 단위, 기준 통일            |
| 변수 생성     | 분석 목적에 맞는 파생변수 생성            |
| 효율 향상     | 필요한 데이터만 선별하고 구조화            |

```markdown
데이터 처리는 분석 전에 데이터를 정제, 변환, 결합하여 분석 가능한 상태로 만드는 과정이다.
```

**2) 주요 처리 프로세스**

데이터 처리 프로세스는 데이터를 분석 목적에 맞게 준비하기 위한 여러 작업으로 구성된다.

대표적인 처리 과정은 다음과 같다.

1. 필터링(Filtering)

필터링은 조건에 맞는 데이터만 선택하는 작업이다.

```markdown
필터링 = 조건에 맞는 행이나 데이터를 선택하는 작업
```

예를 들어 전체 고객 중 최근 6개월 이내 구매 고객만 선택하거나, 특정 지역의 고객만 선택할 수 있다.

| 예시                  | 설명            |
| ------------------- | ------------- |
| 구매금액 10만 원 이상 고객 선택 | 고가 구매 고객 분석   |
| 서울 지역 고객만 선택        | 지역별 분석        |
| 최근 1년 주문만 선택        | 분석 기간 제한      |
| 결측값이 없는 행만 선택       | 품질 좋은 데이터만 사용 |

2. 정렬(Sorting)

정렬은 데이터를 특정 기준에 따라 오름차순 또는 내림차순으로 배열하는 작업이다.

```markdown
정렬 = 데이터를 특정 기준에 따라 순서대로 배열하는 작업
```

| 정렬 기준     | 활용         |
| --------- | ---------- |
| 날짜순       | 시간 흐름 분석   |
| 구매금액 내림차순 | 우수 고객 확인   |
| 점수 오름차순   | 낮은 점수부터 확인 |
| 방문횟수 내림차순 | 활동 고객 파악   |

3. 집계(Aggregation)

집계는 데이터를 그룹별로 묶고 합계, 평균, 개수 등을 계산하는 작업이다.

```markdown
집계 = 데이터를 그룹별로 묶어 합계, 평균, 개수 등을 계산하는 작업
```

| 집계 기준 | 계산 값            |
| ----- | --------------- |
| 고객별   | 총 구매금액, 평균 구매금액 |
| 상품별   | 판매량, 매출액        |
| 월별    | 월 매출, 주문 수      |
| 지역별   | 평균 구매금액, 고객 수   |

집계는 요약 변수 생성과도 연결된다.

4. 데이터 변형(Transformation)

데이터 변형은 데이터의 형태, 단위, 표현 방식을 분석 목적에 맞게 바꾸는 작업이다.

```markdown
데이터 변형 = 데이터의 형태나 표현 방식을 분석 목적에 맞게 바꾸는 작업
```

| 변형 전   | 변형 후      |
| ------ | --------- |
| 생년월일   | 나이        |
| 날짜     | 월, 분기, 연도 |
| 구매금액   | 금액 구간     |
| 문자형 숫자 | 숫자형 데이터   |
| 연속형 나이 | 연령대       |

5. 데이터 표준화 및 정규화(Standardization and Normalization)

데이터 표준화와 정규화는 변수의 단위나 범위를 맞추는 작업이다.

거리 기반 분석에서는 변수의 단위가 다르면 결과가 왜곡될 수 있다.
예를 들어 나이는 20~70 범위이고 연소득은 수천만 원 단위라면, 거리 계산에서 연소득이 지나치게 큰 영향을 줄 수 있다.

```markdown
표준화와 정규화 = 변수의 단위와 범위를 조정하여 비교 가능하게 만드는 작업
```

| 구분  | 설명                   |
| --- | -------------------- |
| 정규화 | 값을 일정 범위로 변환         |
| 표준화 | 평균 0, 표준편차 1이 되도록 변환 |

```markdown
정규화는 값의 범위를 맞추는 것이고,
표준화는 평균과 표준편차를 기준으로 변환하는 것이다.
```

6. 파생변수(Derived Variable) 생성

파생변수는 기존 변수를 활용해 새롭게 만든 변수다.

```markdown
파생변수 = 기존 변수를 가공하거나 조합하여 새롭게 만든 변수
```

예를 들어 최근 구매일을 이용해 “최근 구매 후 경과일”을 만들 수 있다.

| 기존 변수       | 파생변수        |
| ----------- | ----------- |
| 생년월일        | 나이          |
| 나이          | 연령대         |
| 최근 구매일      | 최근 구매 후 경과일 |
| 구매금액 + 구매횟수 | 고객 등급       |
| 방문횟수 + 구매횟수 | 구매 전환율      |

파생변수는 분석 결과와 모델 성능에 큰 영향을 줄 수 있다.

7. 데이터 결합(Merge, Join, Concatenation)

데이터 결합은 여러 데이터셋을 하나로 합치는 작업이다.

```markdown
데이터 결합 = 여러 테이블이나 데이터셋을 분석 목적에 맞게 합치는 작업
```

| 방식            | 설명                    |
| ------------- | --------------------- |
| Merge         | 공통 키를 기준으로 데이터 결합     |
| Join          | 테이블 간 키를 기준으로 결합      |
| Concatenation | 데이터를 위아래 또는 좌우로 단순 연결 |

예를 들어 고객 정보 테이블과 주문 정보 테이블을 고객 ID 기준으로 결합할 수 있다.

```markdown
고객 정보 + 주문 정보 = 고객별 구매 분석 데이터
```

8. 데이터 정제(Cleaning)

데이터 정제는 데이터의 오류를 수정하고 품질을 높이는 작업이다.

```markdown
데이터 정제 = 오류, 중복, 결측, 이상값 등을 처리하여 데이터 품질을 높이는 작업
```

대표적인 정제 대상은 다음과 같다.

| 정제 대상   | 설명                    |
| ------- | --------------------- |
| 결측값     | 값이 비어 있는 데이터          |
| 이상값     | 일반 범위에서 벗어난 값         |
| 중복 데이터  | 동일한 데이터가 반복 저장된 경우    |
| 형식 오류   | 날짜, 숫자, 문자 형식이 잘못된 경우 |
| 불일치 데이터 | 같은 의미인데 표현이 다른 경우     |

9. 결측값 처리(Handling Missing values, Null Values)

결측값은 값이 존재해야 하는 위치에 값이 없는 상태다.

```markdown
결측값 = 데이터가 있어야 할 자리에 값이 없는 상태
```

결측값은 입력 누락, 수집 오류, 응답 거부, 시스템 오류 등으로 발생할 수 있다.

결측값을 그대로 두면 평균 계산, 모델 학습, 통계 검정에서 문제가 발생할 수 있다.

* 결측값 처리 방법

| 처리 방법  | 설명                | 특징              |
| ------ | ----------------- | --------------- |
| 제거     | 결측값이 포함된 행이나 열 삭제 | 단순하지만 데이터 손실 발생 |
| 평균 대체  | 숫자형 결측값을 평균으로 대체  | 이상값에 민감         |
| 중앙값 대체 | 숫자형 결측값을 중앙값으로 대체 | 이상값 영향이 적음      |
| 최빈값 대체 | 범주형 결측값을 최빈값으로 대체 | 범주형 데이터에 적합     |
| 예측값 대체 | 다른 변수로 결측값을 예측    | 정보 보존 가능하지만 복잡함 |

```markdown
결측값은 제거하거나 평균, 중앙값, 최빈값, 예측값 등으로 대체할 수 있다.
```

10. 이상값 처리(Handling Outilers)

이상값은 일반적인 데이터 범위에서 크게 벗어난 값이다.

정확한 표기는 `Outliers`이다.

```markdown
이상값 = 일반적인 데이터 분포에서 크게 벗어난 값
```

예를 들어 사람의 나이가 999세로 입력되어 있거나, 구매금액이 일반 범위보다 지나치게 크다면 이상값으로 볼 수 있다.

이상값은 입력 오류일 수도 있지만, 실제로 의미 있는 특이 사례일 수도 있다.
따라서 무조건 제거하면 안 되고 원인을 먼저 확인해야 한다.

* 대표적인 이상값 처리 방법 2가지

| 처리 방법 | 설명                       | 특징               |
| ----- | ------------------------ | ---------------- |
| 제거    | 명백한 오류라고 판단되는 이상값을 삭제    | 단순하지만 정보 손실 가능   |
| 대체    | 평균, 중앙값, 상한값, 하한값 등으로 변경 | 극단값의 영향을 줄일 수 있음 |

```markdown
이상값은 원인을 확인한 뒤 제거하거나 대체할 수 있으며,
분석 목적에 따라 분리 분석하거나 유지할 수도 있다.
```

#### 분석 방법

분석 방법은 데이터를 이용해 현상을 이해하고, 패턴을 찾고, 미래를 예측하거나 의사결정을 지원하는 방법이다.

```markdown
분석 방법 = 데이터를 해석하여 의미 있는 정보와 인사이트를 도출하는 방법
```

분석 방법은 목적에 따라 기술 통계, 추론 통계, 탐색적 데이터 분석, 지도학습, 비지도학습, 정형 데이터 분석, 비정형 데이터 분석 등으로 구분할 수 있다.

**1) 개요**

데이터 분석 방법은 분석 목적에 따라 달라진다.

예를 들어 현재 매출 현황을 파악하려면 기술 통계를 사용할 수 있고, 고객 이탈 여부를 예측하려면 지도학습 기반 분류 분석을 사용할 수 있다.

| 분석 목적         | 적합한 분석 방법    |
| ------------- | ------------ |
| 현재 상태 요약      | 기술 통계        |
| 모집단 특성 추정     | 추론 통계        |
| 데이터 구조 탐색     | 탐색적 데이터 분석   |
| 범주 예측         | 지도학습, 분류 분석  |
| 수치 예측         | 지도학습, 회귀 분석  |
| 고객 세분화        | 비지도학습, 군집 분석 |
| 함께 발생하는 항목 탐색 | 연관 분석        |

```markdown
분석 방법은 분석 목적과 데이터 형태에 따라 선택해야 한다.
```

**2) 기술 통계와 추론 통계**

통계 분석은 크게 기술 통계와 추론 통계로 나눌 수 있다.

```markdown
기술 통계 = 데이터를 요약하고 설명
추론 통계 = 표본으로 모집단을 추정하거나 검정
```

1. 기술 통계(Descriptive Statistics)

기술 통계는 수집된 데이터를 요약하고 설명하는 통계 방법이다.

평균, 중앙값, 최빈값, 분산, 표준편차, 그래프 등이 기술 통계에 해당한다.

```markdown
기술 통계 = 현재 가지고 있는 데이터를 평균, 표준편차, 그래프 등으로 요약하는 통계
```

예를 들어 학생 점수 데이터에서 평균 점수, 최고 점수, 최저 점수, 표준편차를 계산하는 것이 기술 통계다.

2. 추론 통계(Inferential Statistics, 추리 통계)

추론 통계는 표본 데이터를 이용해 모집단의 특성을 추정하거나 가설을 검정하는 통계 방법이다.

```markdown
추론 통계 = 표본을 이용해 모집단을 추정하거나 가설을 검정하는 통계
```

예를 들어 일부 고객을 조사하여 전체 고객의 평균 만족도를 추정하거나, 두 집단의 평균 차이가 통계적으로 유의한지 검정하는 것이 추론 통계다.

* 기술 통계와 추론 통계의 구분

| 구분    | 기술 통계              | 추론 통계                 |
| ----- | ------------------ | --------------------- |
| 목적    | 데이터 요약과 설명         | 모집단 추정과 가설 검정         |
| 대상    | 현재 수집된 데이터         | 표본과 모집단               |
| 주요 개념 | 평균, 중앙값, 표준편차, 그래프 | 신뢰구간, 가설검정, p-value   |
| 예시    | 고객 평균 구매금액 계산      | 표본으로 전체 고객 평균 구매금액 추정 |
| 핵심    | 있는 데이터를 설명         | 표본으로 전체를 추론           |

```markdown
기술 통계는 데이터를 요약하는 것이고,
추론 통계는 표본을 이용해 모집단을 추정하거나 검정하는 것이다.
```

**3) 탐색적 데이터 분석(Exploratory Data Analysis, EDA)**

탐색적 데이터 분석은 본격적인 분석이나 모델링 전에 데이터를 다양한 관점에서 살펴보는 과정이다.

```markdown
EDA = 데이터의 구조, 분포, 패턴, 이상값, 변수 관계를 탐색하는 분석 과정
```

EDA에서는 다음과 같은 내용을 확인한다.

| 확인 항목  | 설명                    |
| ------ | --------------------- |
| 데이터 구조 | 행, 열, 변수 타입 확인        |
| 결측값    | 비어 있는 값 확인            |
| 이상값    | 극단적으로 큰 값이나 작은 값 확인   |
| 분포     | 데이터가 어떤 형태로 퍼져 있는지 확인 |
| 변수 관계  | 변수 간 상관관계 확인          |
| 시각화    | 그래프를 통해 패턴 확인         |

EDA는 분석 가설을 세우고, 적절한 분석 방법을 선택하는 데 도움을 준다.

```markdown
탐색적 데이터 분석은 데이터를 이해하고 분석 방향을 설정하기 위한 과정이다.
```

**4) 지도학습과 비지도학습**

머신러닝은 정답 데이터의 존재 여부에 따라 지도학습과 비지도학습으로 구분할 수 있다.

1. 지도 학습(Supervised Learning)

지도학습은 정답이 있는 데이터를 학습하는 방법이다.

```markdown
지도학습 = 입력 데이터와 정답 데이터를 함께 학습하여 예측 모델을 만드는 방법
```

예를 들어 고객 정보와 이탈 여부가 함께 있는 데이터를 학습해서 새로운 고객의 이탈 여부를 예측할 수 있다.

| 지도학습 유형 | 설명        | 예시            |
| ------- | --------- | ------------- |
| 분류      | 범주형 결과 예측 | 이탈/비이탈, 스팸/정상 |
| 회귀      | 연속형 수치 예측 | 매출, 가격, 온도 예측 |

2. 비지도학습(Unsupervised Learning)

비지도학습은 정답이 없는 데이터를 학습하여 데이터의 구조나 패턴을 찾는 방법이다.

```markdown
비지도학습 = 정답 없이 데이터의 숨겨진 구조와 패턴을 찾는 방법
```

예를 들어 고객의 구매 패턴을 기준으로 비슷한 고객끼리 묶는 군집 분석이 비지도학습이다.

| 비지도학습 유형 | 설명                | 예시      |
| -------- | ----------------- | ------- |
| 군집 분석    | 유사한 데이터 그룹화       | 고객 세분화  |
| 연관 분석    | 함께 발생하는 항목 관계 탐색  | 장바구니 분석 |
| 차원 축소    | 변수 수를 줄여 핵심 구조 파악 | PCA     |

```markdown
지도학습은 정답이 있는 데이터를 학습하고,
비지도학습은 정답 없이 데이터의 구조와 패턴을 찾는다.
```

**5) 정형 데이터 분석과 비정형 데이터 분석**

데이터 분석은 데이터의 구조에 따라 정형 데이터 분석과 비정형 데이터 분석으로 구분할 수 있다.

1. 정형(Structured) 데이터 분석

정형 데이터는 행과 열로 구조화된 데이터다.

```markdown
정형 데이터 = 표 형태로 정리된 구조화된 데이터
```

예를 들어 고객 테이블, 주문 테이블, 매출 데이터, 설문 데이터 등이 정형 데이터에 해당한다.

| 예시     | 설명                 |
| ------ | ------------------ |
| 고객 데이터 | 고객ID, 나이, 성별, 등급   |
| 주문 데이터 | 주문ID, 상품ID, 금액, 날짜 |
| 매출 데이터 | 일자, 상품, 매출액        |
| 설문 데이터 | 응답자, 문항, 점수        |

정형 데이터 분석은 통계 분석, 회귀 분석, 분류 분석, 군집 분석 등에서 자주 사용된다.

2. 비정형(Unstructured) 데이터 분석

비정형 데이터는 정해진 행과 열 구조가 없는 데이터다.

```markdown
비정형 데이터 = 정해진 구조 없이 생성되는 텍스트, 이미지, 음성, 영상 데이터
```

| 예시  | 분석 방법         |
| --- | ------------- |
| 텍스트 | 자연어 처리, 감성 분석 |
| 이미지 | 이미지 분류, 객체 탐지 |
| 음성  | 음성 인식         |
| 영상  | 행동 인식, 객체 추적  |
| 로그  | 패턴 분석, 이상 탐지  |

```markdown
정형 데이터는 표 형태 데이터이고,
비정형 데이터는 텍스트, 이미지, 음성, 영상처럼 고정된 구조가 없는 데이터이다.
```

**6) 다양한 분석 방법**

데이터 분석 방법은 분석 목적에 따라 다양하게 구분된다.

| 분석 방법 | 설명         | 예시            |
| ----- | ---------- | ------------- |
| 기술 분석 | 현재 상태를 요약  | 매출 현황 분석      |
| 진단 분석 | 원인을 파악     | 매출 감소 원인 분석   |
| 예측 분석 | 미래를 예측     | 고객 이탈 예측      |
| 처방 분석 | 최적의 행동 제안  | 가격 최적화, 추천 전략 |
| 분류 분석 | 범주 예측      | 스팸/정상 분류      |
| 군집 분석 | 유사 데이터 그룹화 | 고객 세분화        |
| 연관 분석 | 항목 간 관계 탐색 | 장바구니 분석       |

시험에서는 각 분석 방법의 목적을 구분하는 것이 중요하다.

```markdown
기술 분석은 현재 상태를 설명하고,
진단 분석은 원인을 찾고,
예측 분석은 미래를 예측하며,
처방 분석은 최적의 행동을 제안한다.
```

## 데이터와 확률변수

데이터와 확률변수는 통계 분석에서 가장 기본이 되는 개념이다.
데이터는 실제 관측된 값이고, 확률변수는 어떤 확률적 실험의 결과를 숫자로 표현하는 변수이다.

```markdown
데이터 = 실제로 관측되거나 수집된 값
확률변수 = 확률적 결과를 숫자로 표현한 변수
```

---

### 1) 데이터(Data, 자료)

데이터는 관찰, 측정, 조사, 실험 등을 통해 수집된 값이다.
데이터는 분석의 대상이 되는 원천 자료이며, 숫자뿐만 아니라 문자, 범주, 이미지, 음성 등 다양한 형태를 가질 수 있다.

예를 들어 고객 나이, 구매금액, 성별, 만족도 점수, 상품 리뷰 등이 모두 데이터에 해당한다.

```markdown
데이터 = 분석을 위해 수집된 관측값 또는 자료
```

| 구분      | 예시                  |
| ------- | ------------------- |
| 수치형 데이터 | 나이, 키, 매출액, 방문 횟수   |
| 범주형 데이터 | 성별, 지역, 직업, 상품 종류   |
| 문자 데이터  | 리뷰, 댓글, 문의 내용       |
| 이미지 데이터 | 사진, 의료 영상, CCTV 이미지 |

데이터는 분석 목적에 따라 정리되고, 통계량 계산이나 모델링에 활용된다.

---

### 2) 확률변수(Random Variable)

확률변수는 확률적 실험의 결과를 숫자로 나타낸 변수이다.
즉, 어떤 사건이 발생했을 때 그 결과가 하나의 숫자 값으로 표현될 수 있으면 확률변수라고 한다.

```markdown
확률변수 = 확률적 실험의 결과를 숫자로 표현한 변수
```

예를 들어 동전을 던졌을 때 앞면이 나오면 1, 뒷면이 나오면 0으로 표현할 수 있다.
이때 결과를 숫자로 나타낸 값이 확률변수이다.

| 예시       | 확률변수 표현          |
| -------- | ---------------- |
| 동전 던지기   | 앞면 = 1, 뒷면 = 0   |
| 주사위 던지기  | 1, 2, 3, 4, 5, 6 |
| 고객 구매 여부 | 구매 = 1, 미구매 = 0  |
| 하루 방문자 수 | 0명, 1명, 2명, ...  |

확률변수는 값의 형태에 따라 이산형 확률변수와 연속형 확률변수로 구분된다.

```markdown
이산형 확률변수 = 셀 수 있는 값을 가지는 확률변수
연속형 확률변수 = 연속적인 값을 가지는 확률변수
```

## 모집단과 표본

통계 분석에서는 전체 대상을 모두 조사하기 어려운 경우가 많다.
이때 전체 대상을 모집단이라고 하고, 모집단에서 일부를 추출한 데이터를 표본이라고 한다.

```markdown
모집단 = 관심 있는 전체 대상
표본 = 모집단에서 추출한 일부 대상
```

---

### 1) 모집단(Population)

모집단은 연구나 분석의 관심 대상이 되는 전체 집단이다.
분석자가 알고 싶어 하는 모든 대상이 모집단에 해당한다.

예를 들어 “대한민국 성인의 평균 키”를 알고 싶다면 대한민국 성인 전체가 모집단이다.

```markdown
모집단 = 분석자가 알고자 하는 전체 대상 집단
```

| 분석 목적            | 모집단          |
| ---------------- | ------------ |
| 대한민국 성인의 평균 키 분석 | 대한민국 성인 전체   |
| 특정 쇼핑몰 고객 만족도 분석 | 해당 쇼핑몰 전체 고객 |
| 제조 공정 불량률 분석     | 생산된 전체 제품    |
| 학생 성적 분석         | 분석 대상 전체 학생  |

모집단 전체를 조사하는 것을 전수조사라고 한다.
하지만 시간과 비용이 많이 들기 때문에 실제 분석에서는 표본을 활용하는 경우가 많다.

---

### 2) 표본(Sample)

표본은 모집단에서 일부를 추출한 데이터이다.
표본을 이용해 모집단의 특성을 추정하거나 가설을 검정한다.

```markdown
표본 = 모집단의 특성을 파악하기 위해 추출한 일부 데이터
```

예를 들어 대한민국 성인 전체의 평균 키를 알고 싶을 때, 일부 성인을 조사하여 평균 키를 계산하면 이 일부 성인이 표본이다.

| 구분  | 설명              |
| --- | --------------- |
| 모집단 | 관심 있는 전체 대상     |
| 표본  | 모집단에서 추출한 일부 대상 |
| 모수  | 모집단의 특성을 나타내는 값 |
| 통계량 | 표본의 특성을 나타내는 값  |

표본이 모집단을 잘 대표해야 분석 결과를 신뢰할 수 있다.
따라서 표본 추출 방법이 중요하다.

---

### 3) 조사 방법론과 표본 추출 방법

조사 방법은 크게 전수조사와 표본조사로 나눌 수 있다.
전수조사는 모집단 전체를 조사하는 방식이고, 표본조사는 모집단에서 일부 표본을 추출해 조사하는 방식이다.

#### 조사 방법 구분

| 구분   | 설명              | 장점        | 단점           |
| ---- | --------------- | --------- | ------------ |
| 전수조사 | 모집단 전체를 조사하는 방법 | 정확성이 높음   | 시간과 비용이 많이 듦 |
| 표본조사 | 모집단 일부를 조사하는 방법 | 시간과 비용 절감 | 표본오차 발생 가능   |

```markdown
전수조사는 전체를 조사하는 방법이고,
표본조사는 일부를 조사하여 전체를 추정하는 방법이다.
```

---

#### 1. 단순 랜덤 추출(Simple Random Sampling)

단순 랜덤 추출은 모집단의 모든 구성원이 동일한 확률로 선택되도록 표본을 추출하는 방법이다.

```markdown
단순 랜덤 추출 = 모집단의 모든 대상이 같은 확률로 선택되는 표본 추출 방법
```

예를 들어 전체 학생 명단에서 난수표를 이용해 100명을 무작위로 뽑는 방식이다.

| 특징 | 설명                |
| -- | ----------------- |
| 장점 | 이해하기 쉽고 공정함       |
| 단점 | 모집단 목록이 필요함       |
| 핵심 | 모든 대상의 선택 확률이 동일함 |

---

#### 2. 계통 추출법(Systematic Sampling)

계통 추출법은 모집단 목록에서 일정한 간격으로 표본을 추출하는 방법이다.

```markdown
계통 추출법 = 일정한 간격을 두고 표본을 추출하는 방법
```

예를 들어 전체 고객 1,000명 중 100명을 뽑는다면, 10명 간격으로 한 명씩 선택할 수 있다.

| 특징 | 설명                    |
| -- | --------------------- |
| 장점 | 단순하고 빠름               |
| 단점 | 목록에 주기성이 있으면 편향 발생 가능 |
| 핵심 | 일정 간격으로 표본 추출         |

---

#### 3. 집락/군집 추출법(Cluster Sampling)

집락 추출법은 모집단을 여러 집단으로 나눈 뒤, 일부 집단을 선택하고 그 집단 안의 대상을 조사하는 방법이다.

```markdown
집락 추출법 = 모집단을 집단으로 나누고 일부 집단을 선택하여 조사하는 방법
```

예를 들어 전국 학교 중 일부 학교를 선택한 뒤, 선택된 학교의 학생을 조사하는 방식이다.

| 특징 | 설명                |
| -- | ----------------- |
| 장점 | 넓은 지역 조사에 효율적     |
| 단점 | 집락 간 차이가 크면 오차 증가 |
| 핵심 | 집단 자체를 표본으로 선택    |

---

#### 4. 층화 추출법(Stratified Sampling)

층화 추출법은 모집단을 특성이 비슷한 층으로 나눈 뒤, 각 층에서 표본을 추출하는 방법이다.

```markdown
층화 추출법 = 모집단을 층으로 나눈 뒤 각 층에서 표본을 추출하는 방법
```

예를 들어 성별이나 연령대별로 모집단을 나눈 뒤 각 집단에서 일정 수의 표본을 뽑는 방식이다.

| 특징 | 설명                      |
| -- | ----------------------- |
| 장점 | 각 집단의 대표성 확보 가능         |
| 단점 | 층을 나누는 기준이 필요함          |
| 핵심 | 집단별 비율이나 특성을 고려하여 표본 추출 |

---

## 측정과 척도

측정은 대상의 속성을 일정한 기준에 따라 숫자나 기호로 표현하는 과정이다.
척도는 측정한 값을 어떤 수준의 정보로 해석할 수 있는지를 나타낸다.

```markdown
측정 = 대상의 속성을 숫자나 기호로 표현하는 과정
척도 = 측정값의 수준과 의미를 나타내는 기준
```

---

### 1) 개요

통계 분석에서는 데이터가 어떤 척도로 측정되었는지에 따라 사용할 수 있는 분석 방법이 달라진다.
예를 들어 성별처럼 범주만 구분하는 데이터와 키, 몸무게처럼 수치 차이를 계산할 수 있는 데이터는 분석 방법이 다르다.

```markdown
척도 수준에 따라 가능한 통계 분석 방법이 달라진다.
```

---

#### 1. 측정(Measurement)

측정은 어떤 대상의 속성을 일정한 규칙에 따라 숫자나 기호로 나타내는 과정이다.

```markdown
측정 = 대상의 속성을 일정한 기준에 따라 숫자나 기호로 부여하는 과정
```

예를 들어 사람의 키를 cm 단위로 기록하거나, 만족도를 1점부터 5점까지 부여하는 것이 측정이다.

---

#### 2. 척도(Scale)

척도는 측정된 값이 가지는 정보의 수준을 의미한다.
척도는 명목척도, 서열척도, 등간척도, 비율척도로 구분된다.

```markdown
척도 = 측정된 값의 의미와 정보 수준을 나타내는 기준
```

---

#### 3. 척도와 종류

척도는 데이터가 어떤 의미를 가지는지에 따라 4가지로 구분된다.

| 척도   | 설명                       | 예시          | 가능한 연산 |
| ---- | ------------------------ | ----------- | ------ |
| 명목척도 | 단순히 대상을 구분하기 위한 척도       | 성별, 혈액형, 지역 | 분류, 빈도 |
| 서열척도 | 순서가 있는 척도                | 만족도, 등급, 석차 | 순위 비교  |
| 등간척도 | 값의 차이가 의미 있는 척도          | 온도, IQ      | 덧셈, 뺄셈 |
| 비율척도 | 절대 0이 존재하고 비율 비교가 가능한 척도 | 키, 몸무게, 매출액 | 사칙연산   |

```markdown
명목척도는 구분만 가능하고,
서열척도는 순서 비교가 가능하며,
등간척도는 차이 비교가 가능하고,
비율척도는 비율 비교가 가능하다.
```

#### 질적 데이터와 양적 데이터

| 구분     | 포함 척도      | 설명               | 예시         |
| ------ | ---------- | ---------------- | ---------- |
| 질적 데이터 | 명목척도, 서열척도 | 범주나 순서로 표현되는 데이터 | 성별, 지역, 등급 |
| 양적 데이터 | 등간척도, 비율척도 | 수치 계산이 가능한 데이터   | 온도, 키, 매출액 |

---

## 용어와 표기법

통계에서는 변수의 개수, 표본 수, 집단 수, 데이터 구조에 따라 다양한 표현을 사용한다.
용어의 의미를 정확히 알아야 검정 방법을 선택할 수 있다.

```markdown
통계 표기법 = 변수, 관측치, 모수, 통계량을 구분하기 위한 약속
```

---

### 1) 변수의 개수 표현

변수의 개수나 집단의 수에 따라 단변량, 다변량, 단순, 다중, sample, way 등의 표현을 사용한다.

---

#### 1. 단변량 데이터(Univariate Data)와 다변량 데이터(Multivariate Data)

단변량 데이터는 하나의 변수만 가진 데이터이고, 다변량 데이터는 여러 개의 변수를 가진 데이터이다.

```markdown
단변량 데이터 = 변수 1개를 분석하는 데이터
다변량 데이터 = 변수 여러 개를 함께 분석하는 데이터
```

| 구분      | 설명           | 예시                   |
| ------- | ------------ | -------------------- |
| 단변량 데이터 | 하나의 변수만 분석   | 키 데이터만 분석            |
| 다변량 데이터 | 여러 변수를 함께 분석 | 키, 몸무게, 나이, 성별 함께 분석 |

---

#### 2. 단순(Simple)과 다중(Multiple)

단순은 독립변수가 하나인 경우를 의미하고, 다중은 독립변수가 여러 개인 경우를 의미한다.

```markdown
단순 = 독립변수 1개
다중 = 독립변수 여러 개
```

| 구분    | 설명                 | 예시                       |
| ----- | ------------------ | ------------------------ |
| 단순 회귀 | 독립변수 1개로 종속변수 예측   | 공부 시간으로 점수 예측            |
| 다중 회귀 | 독립변수 여러 개로 종속변수 예측 | 공부 시간, 출석률, 과제 점수로 점수 예측 |

---

#### 3. -sample과 -way

sample은 비교하는 표본 또는 집단의 개수를 의미하고, way는 분석에 사용하는 요인의 개수를 의미한다.

```markdown
-sample = 비교하는 표본 또는 집단의 수
-way = 분석에 사용하는 요인의 수
```

| 표현            | 의미        | 예시        |
| ------------- | --------- | --------- |
| one-sample    | 하나의 표본    | 일표본 t-검정  |
| two-sample    | 두 개의 표본   | 독립표본 t-검정 |
| paired-sample | 짝지어진 두 표본 | 대응표본 t-검정 |
| one-way       | 요인 1개     | 일원분산분석    |
| two-way       | 요인 2개     | 이원분산분석    |

---

### 2) 데이터 표기법(Notation)

데이터 표기법은 확률변수, 모수, 통계량, 관측치, 변수 등을 구분하기 위해 사용한다.

---

#### 1. 확률변수와 모수, 데이터와 통계량 구분

확률변수는 확률적 실험의 결과를 나타내는 변수이고, 모수는 모집단의 특성을 나타내는 값이다.
통계량은 표본으로부터 계산한 값이다.

```markdown
모수 = 모집단의 특성을 나타내는 값
통계량 = 표본의 특성을 나타내는 값
```

| 구분   | 설명                 | 예시         |
| ---- | ------------------ | ---------- |
| 확률변수 | 확률적 결과를 숫자로 표현한 변수 | X          |
| 모수   | 모집단의 특성값           | μ, σ²      |
| 데이터  | 실제 관측된 값           | x₁, x₂, x₃ |
| 통계량  | 표본으로 계산한 값         | x̄, s²     |

---

#### 2. 데이터의 변수와 관측치

데이터셋에서 행은 관측치, 열은 변수를 의미한다.

```markdown
관측치 = 데이터의 행
변수 = 데이터의 열
```

| 구분   | 설명              | 예시           |
| ---- | --------------- | ------------ |
| 변수   | 측정되는 속성         | 나이, 성별, 매출액  |
| 관측치  | 하나의 대상에 대한 기록   | 고객 1명, 주문 1건 |
| 데이터셋 | 변수와 관측치로 구성된 자료 | 고객 데이터 테이블   |

---

#### 3. 합계 기호

합계 기호 Σ는 여러 값을 모두 더한다는 의미이다.

```markdown
Σ = 여러 값을 합산한다는 의미
```

예를 들어 Σxi는 x₁부터 xn까지 모든 값을 더한다는 뜻이다.

| 표기          | 의미                 |
| ----------- | ------------------ |
| Σxi         | 모든 xi의 합           |
| Σxi²        | xi를 제곱한 값들의 합      |
| Σ(xi - x̄)² | 평균과의 차이를 제곱한 값들의 합 |

---

## 02. 통계분석의 이해

통계분석의 이해에서는 확률, 조건부 확률, 확률분포, 대표적인 분포, 기댓값, 분산, 상관계수 등을 학습한다.
확률분포는 통계 검정과 머신러닝의 기본이 되므로 각 분포의 특징을 구분하는 것이 중요하다.

```markdown
통계분석의 이해 = 확률과 확률분포를 바탕으로 데이터의 불확실성을 이해하는 영역
```

---

## 확률과 확률분포

확률은 어떤 사건이 발생할 가능성을 수치로 표현한 것이다.
확률분포는 확률변수가 가질 수 있는 값과 그 값이 나타날 확률을 나타낸 것이다.

```markdown
확률 = 사건이 발생할 가능성
확률분포 = 확률변수의 값과 그 확률의 대응 관계
```

---

### 1) 확률과 조건부 확률

---

#### 1. 확률(Probability)

확률은 어떤 사건이 발생할 가능성을 0과 1 사이의 값으로 나타낸 것이다.
확률이 0이면 사건이 발생하지 않고, 확률이 1이면 반드시 발생한다.

```markdown
확률 = 어떤 사건이 발생할 가능성을 수치로 나타낸 값
```

| 확률값 | 의미                  |
| --- | ------------------- |
| 0   | 절대 발생하지 않음          |
| 0.5 | 발생 가능성과 미발생 가능성이 같음 |
| 1   | 반드시 발생함             |

---

#### 2. 조건부 확률(Conditional Probability)

조건부 확률은 어떤 사건이 발생했다는 조건 아래에서 다른 사건이 발생할 확률이다.

```markdown
조건부 확률 = 특정 사건이 발생한 조건에서 다른 사건이 발생할 확률
```

예를 들어 고객이 광고를 클릭했다는 조건에서 상품을 구매할 확률이 조건부 확률이다.

| 예시            | 의미                 |
| ------------- | ------------------ |
| P(구매 | 광고 클릭) | 광고를 클릭한 고객이 구매할 확률 |
| P(합격 | 교육 수강) | 교육을 수강한 사람이 합격할 확률 |

---

### 2) 독립사건과 배반사건

---

#### 1. 독립사건(Independent Events)

독립사건은 한 사건의 발생 여부가 다른 사건의 발생 확률에 영향을 주지 않는 사건이다.

```markdown
독립사건 = 한 사건의 발생이 다른 사건의 발생 확률에 영향을 주지 않는 사건
```

예를 들어 동전을 던진 결과와 주사위를 던진 결과는 서로 독립이다.

---

#### 2. 배반사건(Mutually Exclusive Events)

배반사건은 두 사건이 동시에 발생할 수 없는 사건이다.

```markdown
배반사건 = 두 사건이 동시에 발생할 수 없는 사건
```

예를 들어 주사위를 한 번 던졌을 때 1이 나오는 사건과 2가 나오는 사건은 동시에 발생할 수 없으므로 배반사건이다.

| 구분   | 의미                | 예시              |
| ---- | ----------------- | --------------- |
| 독립사건 | 서로의 확률에 영향을 주지 않음 | 동전 던지기와 주사위 던지기 |
| 배반사건 | 동시에 발생할 수 없음      | 주사위 1과 주사위 2    |

---

### 3) 확률변수와 확률분포

---

#### 1. 확률분포(Probability Distribution)

확률분포는 확률변수가 가질 수 있는 값과 그 값이 발생할 확률을 나타낸 것이다.

```markdown
확률분포 = 확률변수의 값과 확률을 대응시킨 분포
```

예를 들어 주사위를 던졌을 때 1부터 6까지 각각 나올 확률은 1/6이다.
이 관계가 확률분포이다.

---

#### 2. 이산형 확률분포(Discrete Random Variable)

이산형 확률분포는 확률변수가 셀 수 있는 값을 가질 때의 분포이다.

```markdown
이산형 확률분포 = 셀 수 있는 값을 가지는 확률변수의 분포
```

| 예시     | 설명               |
| ------ | ---------------- |
| 고객 수   | 0명, 1명, 2명       |
| 불량품 개수 | 0개, 1개, 2개       |
| 주사위 눈  | 1, 2, 3, 4, 5, 6 |

---

#### 3. 연속형 확률분포(Continuous Random Variable)

연속형 확률분포는 확률변수가 연속적인 값을 가질 때의 분포이다.

```markdown
연속형 확률분포 = 연속적인 값을 가지는 확률변수의 분포
```

| 예시  | 설명                  |
| --- | ------------------- |
| 키   | 170.1cm, 170.15cm 등 |
| 몸무게 | 연속적인 수치             |
| 시간  | 1.2초, 1.25초 등       |

---

#### 4. 결합 확률분포(Joint Probability Distribution)

결합 확률분포는 두 개 이상의 확률변수가 동시에 가질 수 있는 값과 그 확률을 나타낸 분포이다.

```markdown
결합 확률분포 = 여러 확률변수의 값이 동시에 발생할 확률분포
```

예를 들어 고객의 성별과 구매 여부를 동시에 고려한 분포가 결합 확률분포이다.

---

### 4) 경험적 분포와 이론적 분포

---

#### 1. 경험적 분포(Empirical Distribution)

경험적 분포는 실제 관측된 데이터를 바탕으로 만든 분포이다.

```markdown
경험적 분포 = 실제 관측 데이터로부터 얻은 분포
```

예를 들어 실제 고객 1,000명의 구매금액을 이용해 만든 분포가 경험적 분포이다.

---

#### 2. 이론적 분포(Theoretical Distribution)

이론적 분포는 수학적 확률 모형에 의해 정의된 분포이다.

```markdown
이론적 분포 = 수학적 모형으로 정의된 확률분포
```

정규분포, 이항분포, 포아송분포 등이 이론적 분포에 해당한다.

---

#### 3. 경험적 확률과 이론적 확률

| 구분     | 설명                    | 예시                               |
| ------ | --------------------- | -------------------------------- |
| 경험적 확률 | 실제 관측 결과를 바탕으로 계산한 확률 | 고객 1,000명 중 100명이 구매 → 구매 확률 10% |
| 이론적 확률 | 수학적 원리나 모형으로 계산한 확률   | 공정한 동전의 앞면 확률 50%                |

```markdown
경험적 확률은 실제 데이터 기반이고,
이론적 확률은 수학적 모형 기반이다.
```

---

### 5) 대표적인 이산형 확률분포

---

#### 1. 베르누이 분포(Bernoulli Distribution)

베르누이 분포는 결과가 성공 또는 실패처럼 두 가지인 시행의 확률분포이다.

```markdown
베르누이 분포 = 결과가 성공/실패 두 가지인 확률분포
```

| 예시    | 성공 | 실패  |
| ----- | -- | --- |
| 구매 여부 | 구매 | 미구매 |
| 합격 여부 | 합격 | 불합격 |
| 클릭 여부 | 클릭 | 미클릭 |

---

#### 2. 이항 분포(Binomial Distribution)

이항 분포는 동일한 베르누이 시행을 여러 번 반복했을 때 성공 횟수의 분포이다.

```markdown
이항 분포 = 베르누이 시행을 n번 반복했을 때 성공 횟수의 분포
```

예를 들어 제품 10개 중 불량품이 몇 개인지 계산하는 경우 이항 분포를 사용할 수 있다.

| 조건       | 설명             |
| -------- | -------------- |
| 시행 횟수 고정 | n번 반복          |
| 결과는 두 가지 | 성공 또는 실패       |
| 성공 확률 일정 | 매 시행의 성공 확률 동일 |
| 시행 독립    | 각 시행은 서로 독립    |

---

#### 3. 포아송 분포(Poisson Distribution)

포아송 분포는 일정한 시간이나 공간에서 사건이 발생하는 횟수를 나타내는 분포이다.

```markdown
포아송 분포 = 일정 구간에서 사건이 발생하는 횟수의 분포
```

| 예시                    |
| --------------------- |
| 1시간 동안 콜센터에 걸려오는 전화 수 |
| 하루 동안 발생하는 교통사고 수     |
| 특정 페이지의 분당 방문자 수      |
| 생산라인의 시간당 불량 발생 수     |

---

### 6) 대표적인 연속형 확률분포

---

#### 1. 균일 분포(Uniform Distribution)

균일 분포는 특정 구간 안에서 모든 값이 동일한 확률로 발생하는 분포이다.

```markdown
균일 분포 = 구간 내 모든 값이 동일한 가능성을 가지는 분포
```

예를 들어 0부터 1 사이의 난수를 생성할 때 균일 분포를 사용할 수 있다.

---

#### 2. 정규 분포(Normal Distribution)

정규 분포는 평균을 중심으로 좌우 대칭인 종 모양의 분포이다.
자연 현상과 사회 현상에서 자주 나타난다.

```markdown
정규 분포 = 평균을 중심으로 좌우 대칭인 종 모양 분포
```

| 특징  | 설명               |
| --- | ---------------- |
| 대칭성 | 평균을 기준으로 좌우 대칭   |
| 중심  | 평균, 중앙값, 최빈값이 같음 |
| 형태  | 종 모양             |
| 활용  | 추정, 검정, 회귀분석 등   |

---

#### 3. 표준 정규 분포(Standard Normal Distribution, Z 분포)

표준 정규 분포는 평균이 0이고 표준편차가 1인 정규 분포이다.

```markdown
표준 정규 분포 = 평균 0, 표준편차 1인 정규 분포
```

일반 정규분포의 값을 표준화하면 표준 정규 분포를 이용해 확률을 계산할 수 있다.

---

#### 4. 지수 분포(Exponential Distribution)

지수 분포는 어떤 사건이 발생할 때까지 걸리는 시간이나 간격을 나타내는 분포이다.

```markdown
지수 분포 = 사건이 발생할 때까지의 대기 시간 분포
```

| 예시                    |
| --------------------- |
| 다음 고객이 도착할 때까지 걸리는 시간 |
| 기계가 고장 날 때까지 걸리는 시간   |
| 다음 전화가 올 때까지의 시간      |

---

#### 5. t 분포, 카이제곱 분포, F 분포

t 분포, 카이제곱 분포, F 분포는 통계 검정에서 자주 사용하는 이론적 분포이다.

| 분포      | 설명                              | 주 활용             |
| ------- | ------------------------------- | ---------------- |
| t 분포    | 표본 수가 작고 모집단 분산을 모를 때 평균 검정에 사용 | t-검정             |
| 카이제곱 분포 | 범주형 데이터의 빈도 차이 검정에 사용           | 적합도, 독립성, 동질성 검정 |
| F 분포    | 두 분산의 비율이나 여러 집단 평균 비교에 사용      | 분산분석             |

```markdown
t 분포는 평균 검정,
카이제곱 분포는 빈도 검정,
F 분포는 분산분석에 사용된다.
```

---

### 7) 기댓값과 분산, 표준편차

기댓값, 분산, 표준편차는 확률분포나 데이터의 특성을 요약하는 대표적인 지표이다.

---

#### 1. 기댓값(Expectation, Expected Value)

기댓값은 확률변수가 평균적으로 가질 것으로 기대되는 값이다.

```markdown
기댓값 = 확률변수의 평균적인 기대값
```

확률분포에서 평균에 해당하는 개념이다.

---

#### 2. 분산(Variance)

분산은 데이터가 평균으로부터 얼마나 떨어져 있는지를 나타내는 지표이다.

```markdown
분산 = 데이터가 평균으로부터 흩어진 정도
```

분산이 클수록 데이터가 평균 주변에 넓게 퍼져 있다.

---

#### 3. 표준편차(Standard Deviation)

표준편차는 분산의 제곱근이다.
분산과 마찬가지로 데이터의 흩어짐을 나타내지만, 원래 데이터와 같은 단위를 가진다.

```markdown
표준편차 = 분산의 제곱근
```

---

#### 4. 왜도(Skewness)

왜도는 데이터 분포가 좌우 어느 쪽으로 치우쳐 있는지를 나타내는 지표이다.

```markdown
왜도 = 분포의 비대칭 정도
```

| 왜도     | 의미           |
| ------ | ------------ |
| 왜도 > 0 | 오른쪽 꼬리가 긴 분포 |
| 왜도 = 0 | 좌우 대칭        |
| 왜도 < 0 | 왼쪽 꼬리가 긴 분포  |

---

#### 5. 첨도(Kurtosis)

첨도는 데이터 분포의 뾰족한 정도나 꼬리의 두꺼운 정도를 나타내는 지표이다.

```markdown
첨도 = 분포가 얼마나 뾰족하거나 꼬리가 두꺼운지를 나타내는 지표
```

첨도가 클수록 평균 근처에 데이터가 몰려 있고 극단값이 나타날 가능성이 높다.

---

#### 6. 분위수(Quantile)

분위수는 데이터를 크기순으로 정렬했을 때 특정 위치에 해당하는 값이다.

```markdown
분위수 = 데이터를 정렬했을 때 특정 위치를 나누는 값
```

| 구분   | 설명         |
| ---- | ---------- |
| 사분위수 | 데이터를 4등분   |
| 십분위수 | 데이터를 10등분  |
| 백분위수 | 데이터를 100등분 |

---

#### 7. 공분산(Covariance)

공분산은 두 변수가 함께 변하는 방향을 나타내는 지표이다.

```markdown
공분산 = 두 변수가 함께 변하는 방향을 나타내는 값
```

| 공분산  | 의미                |
| ---- | ----------------- |
| 양수   | 두 변수가 같은 방향으로 움직임 |
| 음수   | 두 변수가 반대 방향으로 움직임 |
| 0 근처 | 선형 관계가 약함         |

---

#### 8. 상관계수(Correlation Coefficient)

상관계수는 두 변수의 선형 관계의 방향과 강도를 나타내는 지표이다.
공분산을 표준화한 값으로, -1에서 1 사이의 값을 가진다.

```markdown
상관계수 = 두 변수의 선형 관계 방향과 강도를 나타내는 표준화된 지표
```

| 상관계수    | 의미       |
| ------- | -------- |
| 1에 가까움  | 강한 양의 상관 |
| 0에 가까움  | 선형 상관 약함 |
| -1에 가까움 | 강한 음의 상관 |

---

## 03. 기술통계량

기술통계량은 수집된 데이터를 요약하고 설명하기 위한 값이다.
데이터의 중심, 산포, 위치, 관계 등을 파악하는 데 사용한다.

```markdown
기술통계량 = 데이터를 요약하고 설명하는 통계값
```

---

## 데이터의 구조와 표현

데이터는 공간 속의 점처럼 생각할 수 있다.
변수가 하나이면 1차원 공간, 변수가 두 개이면 2차원 공간, 변수가 여러 개이면 다차원 공간에서 데이터가 표현된다.

---

### 1) 데이터와 공간

데이터는 변수의 개수에 따라 공간에서 표현될 수 있다.
예를 들어 키 하나만 있으면 1차원 데이터이고, 키와 몸무게가 있으면 2차원 데이터이다.

```markdown
데이터는 변수의 개수에 따라 1차원, 2차원, 다차원 공간에서 표현될 수 있다.
```

| 변수 개수   | 표현      | 예시             |
| ------- | ------- | -------------- |
| 변수 1개   | 1차원 데이터 | 키              |
| 변수 2개   | 2차원 데이터 | 키, 몸무게         |
| 변수 여러 개 | 다차원 데이터 | 키, 몸무게, 나이, 소득 |

---

### 2) 데이터의 정렬과 순서 통계량

순서 통계량은 데이터를 크기순으로 정렬했을 때 특정 위치에 있는 값이다.
최솟값, 최댓값, 중앙값, 사분위수 등이 대표적이다.

```markdown
순서 통계량 = 데이터를 정렬했을 때 위치에 따라 정해지는 통계량
```

---

#### 1. 최솟값(Minimum)과 최댓값(Maximum), 중앙값(Median, 중위수)

최솟값은 데이터 중 가장 작은 값이고, 최댓값은 가장 큰 값이다.
중앙값은 데이터를 크기순으로 정렬했을 때 가운데 위치한 값이다.

```markdown
최솟값 = 가장 작은 값
최댓값 = 가장 큰 값
중앙값 = 정렬된 데이터의 가운데 값
```

| 통계량 | 설명                    |
| --- | --------------------- |
| 최솟값 | 데이터 중 가장 작은 값         |
| 최댓값 | 데이터 중 가장 큰 값          |
| 중앙값 | 데이터를 정렬했을 때 가운데 위치한 값 |

---

#### 2. 사분위수(Quartiles)

사분위수는 데이터를 크기순으로 정렬한 뒤 4등분하는 위치의 값이다.

```markdown
사분위수 = 데이터를 4등분하는 위치의 값
```

#### 사분위수의 표현

| 구분  | 설명                  |
| --- | ------------------- |
| Q1  | 제1사분위수, 하위 25% 위치   |
| Q2  | 제2사분위수, 중앙값, 50% 위치 |
| Q3  | 제3사분위수, 하위 75% 위치   |
| IQR | Q3 - Q1, 사분위 범위     |

---

#### 3. 십분위수(Deciles)와 백분위수(Percentiles)

십분위수는 데이터를 10등분하는 값이고, 백분위수는 데이터를 100등분하는 값이다.

```markdown
십분위수 = 데이터를 10등분하는 값
백분위수 = 데이터를 100등분하는 값
```

| 구분     | 설명         |
| ------ | ---------- |
| 십분위수   | 데이터를 10등분  |
| 백분위수   | 데이터를 100등분 |
| 50백분위수 | 중앙값과 동일    |

---

## 데이터의 특성

데이터의 특성은 중심 척도와 산포 척도로 요약할 수 있다.
중심 척도는 데이터의 대표값을 나타내고, 산포 척도는 데이터가 얼마나 흩어져 있는지를 나타낸다.

```markdown
중심 척도 = 데이터의 대표값
산포 척도 = 데이터의 흩어짐 정도
```

---

### 1) 중심 척도(Measure of Central Tendency, Measure of Location, 위치 측도)

중심 척도는 데이터가 어느 위치를 중심으로 모여 있는지 나타내는 값이다.
대표적으로 평균, 중앙값, 최빈값이 있다.

---

#### 1. 평균(Mean)

평균은 모든 값을 더한 뒤 데이터 개수로 나눈 값이다.
가장 널리 사용되는 대표값이지만 이상값에 민감하다.

```markdown
평균 = 모든 데이터 값을 더한 뒤 개수로 나눈 값
```

---

#### 2. 중앙값(Median) 혹은 중위수

중앙값은 데이터를 크기순으로 정렬했을 때 가운데 위치한 값이다.
이상값의 영향을 평균보다 덜 받는다.

```markdown
중앙값 = 정렬된 데이터의 가운데 값
```

---

#### 3. 최빈값(Mode)

최빈값은 데이터에서 가장 자주 나타나는 값이다.
범주형 데이터에서도 사용할 수 있다.

```markdown
최빈값 = 가장 많이 나타나는 값
```

| 중심 척도 | 설명                | 특징              |
| ----- | ----------------- | --------------- |
| 평균    | 전체 값을 더해 개수로 나눈 값 | 이상값에 민감         |
| 중앙값   | 정렬했을 때 가운데 값      | 이상값에 강함         |
| 최빈값   | 가장 자주 나타나는 값      | 범주형 데이터에도 사용 가능 |

---

### 2) 산포 척도(Measure of Dispersion)

산포 척도는 데이터가 중심으로부터 얼마나 퍼져 있는지를 나타내는 값이다.
대표적으로 범위, 사분위 범위, 분산, 표준편차가 있다.

---

#### 1. 범위(Range)

범위는 최댓값에서 최솟값을 뺀 값이다.

```markdown
범위 = 최댓값 - 최솟값
```

계산이 쉽지만 극단값에 민감하다.

---

#### 2. 사분위 범위(Inter Quartile Range, IQR)

사분위 범위는 제3사분위수에서 제1사분위수를 뺀 값이다.

```markdown
IQR = Q3 - Q1
```

중앙 50% 데이터의 퍼짐 정도를 나타내며 이상값의 영향을 상대적으로 덜 받는다.

---

#### 3. 분산(Variance)

분산은 각 데이터가 평균으로부터 얼마나 떨어져 있는지 제곱하여 평균낸 값이다.

```markdown
분산 = 평균으로부터의 편차 제곱의 평균
```

---

#### 4. 표준편차(Standard Deviation)

표준편차는 분산의 제곱근이다.
원래 데이터와 같은 단위를 가지므로 해석이 쉽다.

```markdown
표준편차 = 분산의 제곱근
```

| 산포 척도 | 설명        | 특징           |
| ----- | --------- | ------------ |
| 범위    | 최댓값 - 최솟값 | 이상값에 민감      |
| IQR   | Q3 - Q1   | 중앙 50%의 퍼짐   |
| 분산    | 편차 제곱의 평균 | 제곱 단위        |
| 표준편차  | 분산의 제곱근   | 원래 단위로 해석 가능 |

---

## 데이터의 변환과 관계 분석

데이터 변환은 변수의 단위와 범위를 조정하여 분석하기 쉽게 만드는 과정이다.
관계 분석에서는 공분산과 상관계수를 이용해 두 변수의 관계를 파악한다.

```markdown
데이터 변환 = 분석하기 쉽도록 데이터의 단위와 범위를 조정하는 과정
관계 분석 = 변수 간 관계를 파악하는 과정
```

---

### 1) 정규화(Normalization)

정규화는 변수의 범위나 단위를 조정하여 서로 비교할 수 있도록 만드는 과정이다.
거리 기반 분석에서는 변수 스케일이 결과에 큰 영향을 주기 때문에 정규화나 표준화가 중요하다.

---

#### 1. 최소-최대 정규화(Min-Max Normalization)

최소-최대 정규화는 데이터를 0과 1 사이의 값으로 변환하는 방법이다.

```markdown
최소-최대 정규화 = 데이터를 0과 1 사이 범위로 변환하는 방법
```

최솟값은 0, 최댓값은 1이 된다.

---

#### 2. 중심화(Centering)

중심화는 각 데이터에서 평균을 빼서 평균이 0이 되도록 만드는 방법이다.

```markdown
중심화 = 데이터에서 평균을 빼 평균을 0으로 만드는 변환
```

---

#### 3. 척도화(Scaling)

척도화는 데이터의 단위나 크기를 조정하는 과정이다.
변수마다 단위가 다르면 분석 결과가 왜곡될 수 있으므로 척도화를 수행한다.

```markdown
척도화 = 변수의 단위나 크기를 조정하는 과정
```

---

#### 4. 표준화(Standardization)

표준화는 평균이 0, 표준편차가 1이 되도록 변환하는 방법이다.

```markdown
표준화 = 평균 0, 표준편차 1이 되도록 변환하는 방법
```

| 변환 방법     | 설명               |
| --------- | ---------------- |
| 최소-최대 정규화 | 값을 0과 1 사이로 변환   |
| 중심화       | 평균을 0으로 변환       |
| 척도화       | 변수의 단위나 크기 조정    |
| 표준화       | 평균 0, 표준편차 1로 변환 |

---

### 2) 공분산과 상관계수

---

#### 1. 공분산(Covariance)

공분산은 두 변수가 함께 변하는 방향을 나타낸다.

```markdown
공분산 = 두 변수가 함께 변하는 방향을 나타내는 값
```

공분산이 양수이면 두 변수가 같은 방향으로 움직이고, 음수이면 반대 방향으로 움직인다.

---

#### 2. 상관계수(Correlation Coefficient)

상관계수는 두 변수 사이의 선형 관계의 방향과 강도를 나타내는 값이다.
공분산을 표준화한 값이기 때문에 -1에서 1 사이의 값을 가진다.

```markdown
상관계수 = 두 변수의 선형 관계 방향과 강도를 나타내는 값
```

| 상관계수    | 해석         |
| ------- | ---------- |
| 1에 가까움  | 강한 양의 상관관계 |
| 0에 가까움  | 선형 관계가 약함  |
| -1에 가까움 | 강한 음의 상관관계 |

---

## 04. 추정과 통계 검정

추정과 통계 검정은 표본을 이용해 모집단의 특성을 파악하는 통계 분석 방법이다.
추정은 모수를 추정하는 것이고, 통계 검정은 가설이 타당한지 판단하는 과정이다.

```markdown
추정 = 표본을 이용해 모집단의 모수를 추정하는 것
통계 검정 = 표본 데이터를 이용해 가설의 타당성을 판단하는 것
```

---

## 추정(Estimation)

추정은 표본에서 계산한 통계량을 이용해 모집단의 모수를 추측하는 과정이다.

---

### 1) 통계량을 활용한 모수 추정

모수는 모집단의 특성을 나타내는 값이고, 통계량은 표본에서 계산한 값이다.
표본 통계량을 이용해 모집단 모수를 추정한다.

```markdown
모수 추정 = 표본 통계량으로 모집단의 특성값을 추정하는 것
```

---

#### 1. 점 추정(Point Estimation)

점 추정은 모수를 하나의 값으로 추정하는 방법이다.

```markdown
점 추정 = 모수를 하나의 값으로 추정하는 방법
```

예를 들어 표본 평균 70점을 이용해 모집단 평균을 70점으로 추정하는 것이 점 추정이다.

| 구분   | 예시        |
| ---- | --------- |
| 모수   | 모집단 평균 μ  |
| 통계량  | 표본 평균 x̄  |
| 점 추정 | μ를 x̄로 추정 |

---

#### 2. 구간 추정(Interval Estimation)

구간 추정은 모수가 포함될 것으로 예상되는 범위를 제시하는 방법이다.

```markdown
구간 추정 = 모수가 포함될 것으로 예상되는 구간을 추정하는 방법
```

예를 들어 모집단 평균이 65점에서 75점 사이에 있을 것이라고 추정하는 방식이다.
이때 신뢰수준과 신뢰구간 개념이 사용된다.

| 구분   | 설명                         |
| ---- | -------------------------- |
| 신뢰수준 | 추정 구간이 모수를 포함할 것으로 기대하는 정도 |
| 신뢰구간 | 모수가 포함될 것으로 추정되는 구간        |

---

### 2) 표준오차(Standard Error)

표준오차는 표본 통계량의 표준편차를 의미한다.
표본 평균이 모집단 평균 주변에서 얼마나 변동하는지를 나타낸다.

```markdown
표준오차 = 표본 통계량의 변동성을 나타내는 값
```

표준오차가 작을수록 표본 통계량이 모수에 더 가깝게 추정될 가능성이 높다.

| 구분   | 설명            |
| ---- | ------------- |
| 표준편차 | 개별 데이터 값의 흩어짐 |
| 표준오차 | 표본 통계량의 흩어짐   |

---

## 통계적 가설 검정(Statistical Hypothesis Test)

통계적 가설 검정은 표본 데이터를 이용해 모집단에 대한 주장이나 가설이 타당한지 판단하는 절차이다.

```markdown
통계적 가설 검정 = 표본 데이터를 이용해 가설의 타당성을 판단하는 과정
```

---

### 1) 통계적 가설 검정의 개념

통계적 가설 검정에서는 귀무가설과 대립가설을 설정하고, 검정 통계량과 p-value를 이용해 귀무가설을 기각할지 판단한다.

---

#### 1. 귀무가설(Null Hypothesis)

귀무가설은 기존 주장이나 차이가 없다는 가설이다.
보통 검정의 기본 가정으로 설정된다.

```markdown
귀무가설 = 차이가 없다, 효과가 없다, 관계가 없다는 기본 가설
```

예를 들어 “신약은 기존 약과 효과 차이가 없다”가 귀무가설이 될 수 있다.

---

#### 2. 대립가설(Alternative Hypothesis)

대립가설은 연구자가 입증하고자 하는 가설이다.
차이가 있다, 효과가 있다, 관계가 있다는 형태로 설정된다.

```markdown
대립가설 = 차이가 있다, 효과가 있다, 관계가 있다는 가설
```

예를 들어 “신약은 기존 약보다 효과가 있다”가 대립가설이 될 수 있다.

---

#### 3. 유의확률(Significance Probability)

유의확률은 p-value를 의미한다.
귀무가설이 참이라고 가정했을 때, 현재 관측된 결과 이상으로 극단적인 결과가 나올 확률이다.

```markdown
p-value = 귀무가설이 참일 때 현재 결과 이상이 나올 확률
```

p-value가 유의수준보다 작으면 귀무가설을 기각한다.

---

#### 4. 검정 통계량(Test Statistics)

검정 통계량은 표본 데이터로부터 계산된 값으로, 가설 검정의 판단 기준이 된다.

```markdown
검정 통계량 = 표본 데이터로 계산한 검정 기준값
```

t 검정에서는 t 통계량, 카이제곱 검정에서는 카이제곱 통계량, 분산분석에서는 F 통계량을 사용한다.

---

#### 5. 유의수준(Significance Level)

유의수준은 귀무가설을 기각할 기준이 되는 확률이다.
보통 α로 표현하며, 0.05 또는 0.01을 많이 사용한다.

```markdown
유의수준 = 귀무가설을 기각할 판단 기준
```

| 판단 기준          | 결론           |
| -------------- | ------------ |
| p-value < 유의수준 | 귀무가설 기각      |
| p-value ≥ 유의수준 | 귀무가설 기각하지 않음 |

---

#### 6. 1종 오류(Type 1 Error, α Error)와 2종 오류(Type 2 Error, β Error)

1종 오류는 참인 귀무가설을 잘못 기각하는 오류이다.
2종 오류는 거짓인 귀무가설을 기각하지 못하는 오류이다.

```markdown
1종 오류 = 참인 귀무가설을 잘못 기각하는 오류
2종 오류 = 거짓인 귀무가설을 기각하지 못하는 오류
```

#### 1종 오류와 2종 오류

| 실제 상황 / 판단 | 귀무가설 기각 | 귀무가설 기각하지 않음 |
| ---------- | ------- | ------------ |
| 귀무가설 참     | 1종 오류   | 올바른 판단       |
| 귀무가설 거짓    | 올바른 판단  | 2종 오류        |

### 2) t-분포를 활용한 검정

t-분포를 활용한 검정은 평균 차이를 검정할 때 사용한다.
대표적으로 일표본 t-검정, 독립표본 t-검정, 대응표본 t-검정이 있다.

```markdown
t-검정 = 평균 차이를 검정하는 방법
```

---

#### 1. 일표본 t-검정(One-sample t-test)

일표본 t-검정은 하나의 표본 평균이 특정 기준값과 차이가 있는지 검정하는 방법이다.

```markdown
일표본 t-검정 = 하나의 표본 평균과 기준값의 차이를 검정하는 방법
```

예를 들어 한 반의 평균 점수가 70점과 다른지 검정할 때 사용한다.

---

#### 2. 독립표본 t-검정(Independent Samples t-test)

독립표본 t-검정은 서로 독립인 두 집단의 평균 차이를 검정하는 방법이다.

```markdown
독립표본 t-검정 = 서로 독립인 두 집단의 평균 차이를 검정하는 방법
```

예를 들어 남학생과 여학생의 평균 점수 차이를 검정할 때 사용한다.

---

#### 3. 대응표본 t-검정(Paired Samples t-test)

대응표본 t-검정은 같은 대상에서 두 번 측정한 값의 평균 차이를 검정하는 방법이다.

```markdown
대응표본 t-검정 = 같은 대상의 전후 평균 차이를 검정하는 방법
```

예를 들어 교육 전 점수와 교육 후 점수의 차이를 검정할 때 사용한다.

#### 가설 설정

| 검정        | 귀무가설               | 대립가설               |
| --------- | ------------------ | ------------------ |
| 일표본 t-검정  | 표본 평균은 기준값과 차이가 없다 | 표본 평균은 기준값과 차이가 있다 |
| 독립표본 t-검정 | 두 집단의 평균은 같다       | 두 집단의 평균은 다르다      |
| 대응표본 t-검정 | 전후 평균 차이는 없다       | 전후 평균 차이는 있다       |

---

#### 4. 상관분석(Correlation Analysis)

상관분석은 두 변수 사이의 선형 관계가 있는지 확인하는 분석이다.

```markdown
상관분석 = 두 변수 사이의 선형 관계를 분석하는 방법
```

상관계수는 -1에서 1 사이의 값을 가지며, 값이 1이나 -1에 가까울수록 관계가 강하다.

#### 가설 설정

| 구분   | 가설              |
| ---- | --------------- |
| 귀무가설 | 두 변수 간 상관관계가 없다 |
| 대립가설 | 두 변수 간 상관관계가 있다 |

---

### 3) 카이제곱 분포를 활용한 검정

카이제곱 검정은 범주형 데이터의 빈도 차이를 검정할 때 사용한다.
대표적으로 적합도 검정, 독립성 검정, 동질성 검정이 있다.

```markdown
카이제곱 검정 = 범주형 데이터의 빈도 차이를 검정하는 방법
```

---

#### 1. 적합도 검정(Goodness-of-Fit Test)

적합도 검정은 관측 빈도가 기대 빈도와 일치하는지 검정하는 방법이다.

```markdown
적합도 검정 = 관측 빈도가 기대 빈도와 같은지 검정하는 방법
```

예를 들어 주사위가 공정하다면 각 눈이 비슷한 빈도로 나와야 한다.
관측된 주사위 결과가 기대 빈도와 다른지 검정할 수 있다.

---

#### 2. 독립성 검정(Test of Independence)

독립성 검정은 두 범주형 변수가 서로 독립인지 검정하는 방법이다.

```markdown
독립성 검정 = 두 범주형 변수 사이에 관계가 있는지 검정하는 방법
```

예를 들어 성별과 구매 여부가 서로 관련 있는지 확인할 때 사용한다.

---

#### 3. 동질성 검정(Homogeneity Test)

동질성 검정은 여러 집단의 범주 분포가 같은지 검정하는 방법이다.

```markdown
동질성 검정 = 여러 집단의 범주형 분포가 같은지 검정하는 방법
```

예를 들어 지역별 선호 브랜드 분포가 같은지 비교할 때 사용한다.

| 검정     | 목적                | 예시            |
| ------ | ----------------- | ------------- |
| 적합도 검정 | 관측 빈도와 기대 빈도 비교   | 주사위가 공정한지     |
| 독립성 검정 | 두 범주형 변수의 관계 확인   | 성별과 구매 여부 관계  |
| 동질성 검정 | 여러 집단의 분포가 같은지 확인 | 지역별 선호도 분포 비교 |

---

### 4) F 분포를 활용한 검정

F 분포는 여러 집단의 평균 차이를 검정하는 분산분석에서 사용된다.

---

#### 1. 분산분석(Analysis of Variance, ANOVA)

분산분석은 세 개 이상의 집단 평균 차이를 검정하는 방법이다.

```markdown
분산분석 = 세 개 이상의 집단 평균 차이를 검정하는 방법
```

두 집단 평균 차이는 t-검정을 사용할 수 있지만, 세 집단 이상을 비교할 때는 분산분석을 사용한다.

#### 가설 설정

| 구분   | 가설                 |
| ---- | ------------------ |
| 귀무가설 | 모든 집단의 평균은 같다      |
| 대립가설 | 적어도 하나의 집단 평균은 다르다 |

#### 분산분석표

| 변동 요인   | 설명                      |
| ------- | ----------------------- |
| 집단 간 변동 | 집단 평균 간 차이로 인한 변동       |
| 집단 내 변동 | 같은 집단 내부의 개별 차이로 인한 변동  |
| 전체 변동   | 집단 간 변동과 집단 내 변동의 합     |
| F 통계량   | 집단 간 변동을 집단 내 변동으로 나눈 값 |

```markdown
분산분석은 집단 간 변동이 집단 내 변동보다 충분히 큰지 확인하여 평균 차이를 검정한다.
```

---

### 5) 비모수적 검정(Non-parametric Test, 비모수 검정)

비모수적 검정은 데이터가 정규분포를 따른다는 가정을 만족하기 어렵거나, 표본 수가 작거나, 서열척도 데이터를 분석할 때 사용하는 검정 방법이다.

```markdown
비모수 검정 = 모집단 분포에 대한 강한 가정 없이 수행하는 검정
```

---

#### 1. 윌콕슨 부호순위 검정(Wilcoxon Signed-Rank Test)

윌콕슨 부호순위 검정은 대응표본 t-검정의 비모수 대안이다.
같은 대상의 전후 차이를 비교할 때 사용한다.

```markdown
윌콕슨 부호순위 검정 = 대응표본 t-검정의 비모수 대안
```

예를 들어 교육 전후 만족도 점수 차이를 비교할 때 사용할 수 있다.

---

#### 2. 윌콕슨 순위합 검정(Wilcoxon Rank-Sum Test) 혹은 맨-휘트니 U 검정(Mann-Whitney U Test)

윌콕슨 순위합 검정은 독립표본 t-검정의 비모수 대안이다.
서로 독립인 두 집단의 차이를 비교할 때 사용한다.

```markdown
윌콕슨 순위합 검정 = 독립표본 t-검정의 비모수 대안
```

예를 들어 남학생과 여학생의 만족도 차이를 비교할 때 사용할 수 있다.

---

#### 3. 크루스칼-왈리스 검정(Kruskal-Wallis Test)

크루스칼-왈리스 검정은 일원분산분석의 비모수 대안이다.
세 개 이상의 독립 집단 차이를 비교할 때 사용한다.

```markdown
크루스칼-왈리스 검정 = 일원분산분석의 비모수 대안
```

예를 들어 세 개 이상의 지역별 만족도 차이를 비교할 때 사용할 수 있다.

---

#### 4. 프리드먼 검정(Friedman Test)

프리드먼 검정은 반복측정 분산분석의 비모수 대안이다.
같은 대상에게 여러 조건을 반복 측정한 경우 사용한다.

```markdown
프리드먼 검정 = 반복측정 분산분석의 비모수 대안
```

예를 들어 같은 사람들에게 세 가지 교육 방법을 모두 적용하고 만족도 차이를 비교할 때 사용할 수 있다.

| 비모수 검정                  | 대응되는 모수 검정 | 사용 상황             |
| ----------------------- | ---------- | ----------------- |
| 윌콕슨 부호순위 검정             | 대응표본 t-검정  | 같은 대상의 전후 비교      |
| 윌콕슨 순위합 검정 / 맨-휘트니 U 검정 | 독립표본 t-검정  | 독립된 두 집단 비교       |
| 크루스칼-왈리스 검정             | 일원분산분석     | 독립된 세 집단 이상 비교    |
| 프리드먼 검정                 | 반복측정 분산분석  | 같은 대상의 세 조건 이상 비교 |

```markdown
비모수 검정은 정규성 가정을 만족하기 어렵거나,
서열척도 데이터처럼 평균 기반 검정이 적절하지 않을 때 사용한다.

기댓값은 확률변수가 평균적으로 가질 것으로 기대되는 값이다.

분산은 데이터가 평균으로부터 얼마나 떨어져 있는지를 나타내는 지표이다.

표준편차는 분산의 제곱근이며, 데이터의 흩어짐을 원래 단위로 나타낸다.

왜도는 데이터 분포의 비대칭 정도를 나타낸다.

첨도는 데이터 분포가 얼마나 뾰족하거나 꼬리가 두꺼운지를 나타낸다.

분위수는 데이터를 크기순으로 정렬했을 때 특정 위치에 해당하는 값이다.

공분산은 두 변수가 함께 변하는 방향을 나타내는 값이다.

상관계수는 두 변수의 선형 관계의 방향과 강도를 나타내는 표준화된 지표이다.

기술통계량은 수집된 데이터를 요약하고 설명하기 위한 통계값이다.

순서 통계량은 데이터를 정렬했을 때 위치에 따라 정해지는 통계량이다.

최솟값은 데이터 중 가장 작은 값이고,
최댓값은 데이터 중 가장 큰 값이다.

중앙값은 데이터를 크기순으로 정렬했을 때 가운데 위치한 값이다.

사분위수는 데이터를 4등분하는 위치의 값이다.

IQR은 제3사분위수에서 제1사분위수를 뺀 값이다.

십분위수는 데이터를 10등분하는 값이고,
백분위수는 데이터를 100등분하는 값이다.

중심 척도는 데이터의 대표값을 나타내는 지표이다.

평균은 모든 값을 더한 뒤 데이터 개수로 나눈 값이다.

중앙값은 정렬된 데이터의 가운데 값이며,
이상값의 영향을 평균보다 덜 받는다.

최빈값은 데이터에서 가장 자주 나타나는 값이다.

산포 척도는 데이터가 중심으로부터 얼마나 퍼져 있는지를 나타내는 지표이다.

범위는 최댓값에서 최솟값을 뺀 값이다.

사분위 범위는 Q3에서 Q1을 뺀 값이며,
중앙 50% 데이터의 퍼짐 정도를 나타낸다.

분산은 평균으로부터의 편차 제곱의 평균이다.

표준편차는 분산의 제곱근이며,
원래 데이터와 같은 단위로 해석할 수 있다.

정규화는 변수의 범위나 단위를 조정하여 서로 비교할 수 있도록 만드는 과정이다.

최소-최대 정규화는 데이터를 0과 1 사이의 값으로 변환하는 방법이다.

중심화는 각 데이터에서 평균을 빼서 평균이 0이 되도록 만드는 방법이다.

척도화는 변수의 단위나 크기를 조정하는 과정이다.

표준화는 평균이 0, 표준편차가 1이 되도록 변환하는 방법이다.

추정은 표본에서 계산한 통계량을 이용해 모집단의 모수를 추측하는 과정이다.

점 추정은 모수를 하나의 값으로 추정하는 방법이다.

구간 추정은 모수가 포함될 것으로 예상되는 범위를 제시하는 방법이다.

표준오차는 표본 통계량의 변동성을 나타내는 값이다.

통계적 가설 검정은 표본 데이터를 이용해 모집단에 대한 가설의 타당성을 판단하는 절차이다.

귀무가설은 차이가 없다, 효과가 없다, 관계가 없다는 기본 가설이다.

대립가설은 차이가 있다, 효과가 있다, 관계가 있다는 연구 가설이다.

p-value는 귀무가설이 참이라고 가정했을 때 현재 관측된 결과 이상으로 극단적인 결과가 나올 확률이다.

유의수준은 귀무가설을 기각할 기준이 되는 확률이다.

p-value가 유의수준보다 작으면 귀무가설을 기각한다.

검정 통계량은 표본 데이터로부터 계산된 가설 검정의 판단 기준값이다.

1종 오류는 참인 귀무가설을 잘못 기각하는 오류이다.

2종 오류는 거짓인 귀무가설을 기각하지 못하는 오류이다.

t-검정은 평균 차이를 검정하는 방법이다.

일표본 t-검정은 하나의 표본 평균이 특정 기준값과 차이가 있는지 검정하는 방법이다.

독립표본 t-검정은 서로 독립인 두 집단의 평균 차이를 검정하는 방법이다.

대응표본 t-검정은 같은 대상에서 두 번 측정한 값의 평균 차이를 검정하는 방법이다.

상관분석은 두 변수 사이의 선형 관계가 있는지 확인하는 분석이다.

카이제곱 검정은 범주형 데이터의 빈도 차이를 검정하는 방법이다.

적합도 검정은 관측 빈도가 기대 빈도와 일치하는지 검정하는 방법이다.

독립성 검정은 두 범주형 변수가 서로 독립인지 검정하는 방법이다.

동질성 검정은 여러 집단의 범주 분포가 같은지 검정하는 방법이다.

분산분석은 세 개 이상의 집단 평균 차이를 검정하는 방법이다.

분산분석의 귀무가설은 모든 집단의 평균이 같다는 것이고,
대립가설은 적어도 하나의 집단 평균이 다르다는 것이다.

비모수 검정은 모집단 분포에 대한 강한 가정 없이 수행하는 검정이다.

윌콕슨 부호순위 검정은 대응표본 t-검정의 비모수 대안이다.

윌콕슨 순위합 검정 또는 맨-휘트니 U 검정은 독립표본 t-검정의 비모수 대안이다.

크루스칼-왈리스 검정은 일원분산분석의 비모수 대안이다.

프리드먼 검정은 반복측정 분산분석의 비모수 대안이다.
```

## Chapter 03. 머신러닝

머신러닝은 데이터를 기반으로 규칙이나 패턴을 학습하여 예측, 분류, 군집화, 추천 등을 수행하는 분석 방법이다.
ADsP에서는 머신러닝 알고리즘을 깊게 구현하는 것보다 **지도학습·비지도학습의 구분, 평가 지표, 주요 알고리즘의 개념과 활용 상황**을 구분하는 것이 중요하다.

```markdown
머신러닝 = 데이터로부터 패턴을 학습하여 예측, 분류, 군집화, 추천 등을 수행하는 방법
```

### 01. 머신러닝 개요

머신러닝 개요에서는 알고리즘을 지도학습과 비지도학습으로 구분하고, 문제 유형에 따라 회귀와 분류를 구분한다.
또한 모델이 잘 학습되었는지 판단하기 위한 평가 지표와 교차 검증 방법을 학습한다.

```markdown
머신러닝 개요 = 알고리즘 유형, 평가 지표, 검증 방법을 이해하는 영역
```

#### 알고리즘 분류

머신러닝 알고리즘은 정답 데이터의 존재 여부에 따라 지도학습과 비지도학습으로 구분할 수 있다.
지도학습 안에서는 목표 변수가 연속형인지 범주형인지에 따라 회귀와 분류로 나눌 수 있다.

**1) 지도학습과 비지도학습**

지도학습은 입력 데이터와 정답 데이터를 함께 학습하여 새로운 데이터의 결과를 예측하는 방법이다.

```markdown
지도학습 = 정답이 있는 데이터를 학습하여 새로운 데이터의 결과를 예측하는 방법
```

예를 들어 고객의 나이, 구매금액, 방문횟수와 함께 이탈 여부가 주어져 있다면, 이 데이터를 학습해 새로운 고객의 이탈 여부를 예측할 수 있다.

비지도학습은 정답 없이 데이터 자체의 구조나 패턴을 찾는 방법이다.

```markdown
비지도학습 = 정답 없이 데이터의 숨겨진 구조나 패턴을 찾는 방법
```

예를 들어 고객의 구매 패턴을 기준으로 비슷한 고객끼리 묶는 군집 분석이 비지도학습에 해당한다.

| 구분    | 지도학습            | 비지도학습            |
| ----- | --------------- | ---------------- |
| 정답 라벨 | 있음              | 없음               |
| 목적    | 결과 예측           | 구조와 패턴 발견        |
| 대표 기법 | 회귀, 분류          | 군집, 연관 분석, 차원 축소 |
| 예시    | 이탈 여부 예측, 매출 예측 | 고객 세분화, 장바구니 분석  |

```markdown
지도학습은 정답이 있는 데이터를 학습하고,
비지도학습은 정답 없이 데이터의 구조와 패턴을 찾는다.
```

**2) 회귀(Regression)와 분류(Classification, 판별)**

회귀는 연속형 수치 값을 예측하는 지도학습 방법이다.

```markdown
회귀 = 연속형 수치 값을 예측하는 분석 방법
```

예를 들어 매출액, 주택 가격, 온도, 수요량을 예측하는 문제가 회귀에 해당한다.

분류는 미리 정해진 범주를 예측하는 지도학습 방법이다.

```markdown
분류 = 데이터를 미리 정의된 범주로 나누는 분석 방법
```

예를 들어 고객 이탈 여부, 스팸 여부, 합격 여부, 정상 거래 여부를 예측하는 문제가 분류에 해당한다.

| 구분      | 회귀           | 분류                   |
| ------- | ------------ | -------------------- |
| 목표 변수   | 연속형 수치       | 범주형 값                |
| 예측 결과   | 숫자           | 클래스, 라벨              |
| 예시      | 매출 예측, 가격 예측 | 이탈/비이탈, 스팸/정상        |
| 대표 알고리즘 | 선형회귀, 회귀나무   | 로지스틱 회귀, 의사결정나무, SVM |

```markdown
회귀는 숫자를 예측하고,
분류는 범주를 예측한다.
```

#### 평가 지표(Metrics)

평가 지표는 모델의 예측 결과가 실제 값과 얼마나 잘 맞는지 판단하기 위한 기준이다.

회귀 문제와 분류 문제는 예측 대상이 다르기 때문에 사용하는 평가 지표도 다르다.

```markdown
평가 지표 = 모델의 예측 성능을 수치로 판단하는 기준
```

**1) 모형 평가 지표의 활용**

모형 평가 지표는 여러 모델 중 어떤 모델이 더 좋은지 비교하거나, 하나의 모델이 실제 문제에 사용할 만한 성능을 가지는지 판단할 때 사용한다.

예를 들어 회귀 모델에서는 예측값과 실제값의 차이가 작을수록 좋은 모델이다.
분류 모델에서는 실제 클래스를 얼마나 정확하게 맞췄는지, 또는 중요한 클래스를 얼마나 놓치지 않았는지가 중요하다.

| 활용 목적    | 설명                   |
| -------- | -------------------- |
| 모델 성능 비교 | 여러 모델 중 더 좋은 모델 선택   |
| 과적합 확인   | 학습 데이터와 검증 데이터 성능 비교 |
| 모델 개선    | 오류가 큰 부분을 확인하여 개선    |
| 의사결정 기준  | 실제 서비스 적용 가능 여부 판단   |

```markdown
평가 지표는 모델의 성능을 비교하고, 개선하고, 실제 활용 가능성을 판단하는 기준이다.
```

**2) 회귀 문제의 평가 지표**

회귀 문제는 실제값과 예측값의 차이, 즉 오차를 기준으로 모델 성능을 평가한다.

```markdown
회귀 평가 지표 = 실제값과 예측값의 차이를 측정하는 지표
```

1. MAE(Mean Absolute Error, 평균 절대 오차)

MAE는 실제값과 예측값의 차이에 절댓값을 취한 뒤 평균을 구한 값이다.

```markdown
MAE = |실제값 - 예측값|의 평균
```

오차의 크기를 직관적으로 이해하기 쉽고, 실제 데이터와 같은 단위를 가진다.

| 특징 | 설명                     |
| -- | ---------------------- |
| 장점 | 해석이 쉽고 직관적             |
| 단점 | 큰 오차에 대한 패널티가 MSE보다 작음 |
| 의미 | 평균적으로 얼마나 틀렸는가         |

2. MAPE(Mean Absolute Percentage Error, 평균 절대 백분율 오차)

MAPE는 오차를 실제값으로 나누어 백분율로 표현한 지표이다.

```markdown
MAPE = 절대 오차를 실제값으로 나눈 비율의 평균
```

예측 오차를 퍼센트로 해석할 수 있어 이해하기 쉽다.
다만 실제값이 0이거나 0에 가까우면 계산이 불안정해질 수 있다.

| 특징 | 설명                 |
| -- | ------------------ |
| 장점 | 백분율로 표현되어 해석이 쉬움   |
| 단점 | 실제값이 0에 가까우면 왜곡 가능 |
| 의미 | 평균적으로 몇 % 정도 틀렸는가  |

3. MSE(Mean Squared Error, 평균 제곱 오차)

MSE는 실제값과 예측값의 차이를 제곱한 뒤 평균을 구한 값이다.

```markdown
MSE = (실제값 - 예측값)^2의 평균
```

오차를 제곱하기 때문에 큰 오차에 더 큰 패널티를 준다.

| 특징 | 설명                    |
| -- | --------------------- |
| 장점 | 큰 오차를 강하게 반영          |
| 단점 | 단위가 제곱되어 해석이 직관적이지 않음 |
| 의미 | 큰 오차를 중요하게 보는 평가 지표   |

4. RMSE(Root Mean Squared Error, 평균 제곱근 오차)

RMSE는 MSE에 제곱근을 취한 값이다.

```markdown
RMSE = MSE의 제곱근
```

MSE와 마찬가지로 큰 오차에 민감하지만, 원래 데이터와 같은 단위로 해석할 수 있다.

| 특징 | 설명                           |
| -- | ---------------------------- |
| 장점 | 큰 오차 반영, 원래 단위로 해석 가능        |
| 단점 | 이상값에 민감                      |
| 의미 | 예측값이 실제값에서 평균적으로 얼마나 떨어져 있는가 |

5. R^2(R-squared, R2) 혹은 결정계수(Coeffcient of Determination)

정확한 표기는 `Coefficient of Determination`이다.

결정계수는 회귀 모델이 종속변수의 변동을 얼마나 잘 설명하는지 나타내는 지표이다.

```markdown
R² = 회귀 모델이 데이터를 얼마나 잘 설명하는지 나타내는 지표
```

R²는 일반적으로 0에서 1 사이의 값을 가지며, 1에 가까울수록 설명력이 높다.

|      값 | 의미        |
| -----: | --------- |
| 1에 가까움 | 모델 설명력 높음 |
| 0에 가까움 | 모델 설명력 낮음 |

| 지표   | 핵심             |
| ---- | -------------- |
| MAE  | 절대 오차의 평균      |
| MAPE | 절대 오차를 백분율로 표현 |
| MSE  | 제곱 오차의 평균      |
| RMSE | MSE의 제곱근       |
| R²   | 모델의 설명력        |

```markdown
MAE는 평균 절대 오차,
MSE는 평균 제곱 오차,
RMSE는 MSE의 제곱근,
R²는 모델의 설명력을 나타낸다.
```

**3) 분류 문제의 평가 지표**

분류 문제는 실제 클래스와 예측 클래스가 얼마나 일치하는지를 기준으로 평가한다.

가장 기본이 되는 표는 오차 행렬이다.

* 오차 행렬

오차 행렬은 실제값과 예측값을 비교하여 분류 모델의 성능을 정리한 표이다.

```markdown
오차 행렬 = 실제값과 예측값을 비교하여 분류 결과를 정리한 표
```

| 실제 / 예측     | Positive 예측 | Negative 예측 |
| ----------- | ----------: | ----------: |
| 실제 Positive |          TP |          FN |
| 실제 Negative |          FP |          TN |

| 구분 | 의미                           |
| -- | ---------------------------- |
| TP | 실제 Positive를 Positive로 맞게 예측 |
| TN | 실제 Negative를 Negative로 맞게 예측 |
| FP | 실제 Negative를 Positive로 잘못 예측 |
| FN | 실제 Positive를 Negative로 잘못 예측 |

1. 정확도(Accuracy)

정확도는 전체 예측 중 맞게 예측한 비율이다.

```markdown
정확도 = (TP + TN) / (TP + TN + FP + FN)
```

정확도는 이해하기 쉽지만, 데이터 불균형이 심한 경우 성능을 제대로 보여주지 못할 수 있다.

2. 오분류울(Error Rate)

`오분류울`은 `오분류율`이 자연스럽다.

오분류율은 전체 예측 중 잘못 예측한 비율이다.

```markdown
오분류율 = (FP + FN) / 전체
```

정확도와 반대 개념으로 볼 수 있다.

```markdown
오분류율 = 1 - 정확도
```

3. 민감도(Sensitivity), 재현율(Recall), TPR(True Positive Rate)

민감도, 재현율, TPR은 실제 Positive 중 모델이 Positive로 맞게 찾아낸 비율이다.

```markdown
재현율 = TP / (TP + FN)
```

예를 들어 질병 진단에서는 실제 환자를 놓치지 않는 것이 중요하므로 재현율이 중요하다.

```markdown
재현율은 실제 Positive를 얼마나 잘 찾아냈는지를 나타낸다.
```

4. 정밀도(Precision)

정밀도는 Positive라고 예측한 것 중 실제 Positive인 비율이다.

```markdown
정밀도 = TP / (TP + FP)
```

예를 들어 스팸 메일 분류에서 정밀도가 높다는 것은 스팸이라고 분류한 메일이 실제로 스팸일 가능성이 높다는 의미다.

```markdown
정밀도는 Positive 예측이 얼마나 정확한지를 나타낸다.
```

5. F1 Score

F1 Score는 정밀도와 재현율의 조화평균이다.

```markdown
F1 Score = 2 × (정밀도 × 재현율) / (정밀도 + 재현율)
```

정밀도와 재현율의 균형을 함께 보고 싶을 때 사용한다.

6. FPR(False Positive Rate)

FPR은 실제 Negative 중 Positive로 잘못 예측한 비율이다.

```markdown
FPR = FP / (FP + TN)
```

정상인 것을 이상으로 잘못 판단하는 비율이라고 이해할 수 있다.

7. ROC 곡선(Receiver Operating Characteristic Curce)

정확한 표기는 `Receiver Operating Characteristic Curve`이다.

ROC 곡선은 분류 기준값을 바꾸면서 TPR과 FPR의 변화를 나타낸 그래프이다.

```markdown
ROC 곡선 = 기준값 변화에 따른 TPR과 FPR의 관계를 나타낸 그래프
```

ROC 곡선 아래 면적인 AUC가 1에 가까울수록 분류 성능이 좋다.

| 지표       | 공식         | 핵심                               |
| -------- | ---------- | -------------------------------- |
| 정확도      | (TP+TN)/전체 | 전체 중 맞춘 비율                       |
| 오분류율     | (FP+FN)/전체 | 전체 중 틀린 비율                       |
| 재현율      | TP/(TP+FN) | 실제 Positive를 얼마나 찾았는가            |
| 정밀도      | TP/(TP+FP) | Positive 예측이 얼마나 맞았는가            |
| F1 Score | 2PR/(P+R)  | 정밀도와 재현율의 균형                     |
| FPR      | FP/(FP+TN) | 실제 Negative를 Positive로 잘못 판단한 비율 |

```markdown
정밀도는 예측한 Positive 중 맞은 비율이고,
재현율은 실제 Positive 중 찾아낸 비율이다.
```

**4) 비지도학습 중 군집화 관련 지표**

군집화는 정답 라벨이 없기 때문에 정확도처럼 실제값과 비교하기 어렵다.
따라서 군집 내부가 얼마나 응집되어 있고, 군집 간이 얼마나 잘 분리되어 있는지를 평가한다.

1. 실루엣 계수(Silbouette Coefficient)

정확한 표기는 `Silhouette Coefficient`이다.

실루엣 계수는 군집 내부 응집도와 군집 간 분리도를 함께 고려하는 지표이다.

```markdown
실루엣 계수 = 군집 내 응집도와 군집 간 분리도를 함께 평가하는 지표
```

값은 보통 -1에서 1 사이이며, 1에 가까울수록 군집화가 잘 된 것으로 본다.

|       값 | 의미              |
| ------: | --------------- |
|  1에 가까움 | 잘 군집화됨          |
|    0 근처 | 군집 경계에 위치       |
| -1에 가까움 | 잘못된 군집에 속했을 가능성 |

2. 군집 간 거리 및 군집 내 거리

군집 내 거리는 같은 군집에 속한 데이터들이 얼마나 가까운지를 나타낸다.
군집 간 거리는 서로 다른 군집들이 얼마나 떨어져 있는지를 나타낸다.

```markdown
좋은 군집 = 군집 내 거리는 작고, 군집 간 거리는 커야 한다.
```

| 지표      | 좋은 상태   |
| ------- | ------- |
| 군집 내 거리 | 작을수록 좋음 |
| 군집 간 거리 | 클수록 좋음  |

#### 교차 검증(Cross-Validation)

교차 검증은 모델이 특정 데이터에만 잘 맞는지, 새로운 데이터에도 잘 일반화되는지 확인하기 위한 검증 방법이다.

```markdown
교차 검증 = 데이터를 여러 방식으로 나누어 모델의 일반화 성능을 평가하는 방법
```

**1) 교차 검증 활용**

교차 검증은 학습 데이터와 검증 데이터를 나누어 모델 성능을 평가할 때 사용한다.

단순히 학습 데이터에서 성능이 좋은 모델은 실제 새로운 데이터에서는 성능이 낮을 수 있다.
이를 과적합이라고 한다.

교차 검증은 이런 과적합 여부를 확인하고 모델의 일반화 성능을 평가하는 데 사용된다.

```markdown
교차 검증은 모델의 과적합을 확인하고 일반화 성능을 평가하기 위해 사용한다.
```

**2) 홀드아웃 검증(Holdout Validation)**

홀드아웃 검증은 데이터를 학습 데이터와 검증 데이터로 한 번 나누어 평가하는 방법이다.

```markdown
홀드아웃 검증 = 데이터를 학습용과 검증용으로 한 번 나누는 방법
```

예를 들어 전체 데이터를 7:3으로 나누어 70%는 학습에 사용하고 30%는 평가에 사용한다.

| 장점      | 단점                         |
| ------- | -------------------------- |
| 간단하고 빠름 | 데이터 분할 방식에 따라 결과가 달라질 수 있음 |

**3) K-폴드 교차 검증(K-fold Cross-Validation, K겹 교차 검증)**

K-폴드 교차 검증은 데이터를 K개의 부분집합으로 나눈 뒤, K번 반복하여 검증하는 방법이다.

```markdown
K-폴드 교차 검증 = 데이터를 K개로 나누어 K번 학습과 검증을 반복하는 방법
```

예를 들어 5-폴드 교차 검증은 데이터를 5개로 나누고, 매번 하나를 검증 데이터로 사용하며 총 5번 평가한다.

| 장점         | 설명                   |
| ---------- | -------------------- |
| 안정적 평가     | 모든 데이터가 한 번씩 검증에 사용됨 |
| 데이터 활용도 높음 | 작은 데이터셋에서도 유용        |

**4) 층화 K 폴드 교차 검증(Stratified K-Fold Cross-Validation)**

층화 K 폴드 교차 검증은 각 폴드에서 클래스 비율이 원래 데이터와 비슷하게 유지되도록 나누는 방법이다.

```markdown
층화 K 폴드 교차 검증 = 클래스 비율을 유지하면서 K개의 폴드로 나누는 방법
```

분류 문제에서 데이터 불균형이 있을 때 유용하다.

예를 들어 전체 데이터에서 이탈 고객이 10%, 비이탈 고객이 90%라면, 각 폴드도 이 비율을 유지하도록 나눈다.

**5) LpOCV(Leave-p-out Cross-Validation)**

LpOCV는 전체 데이터 중 p개를 검증 데이터로 남겨두고 나머지를 학습에 사용하는 과정을 반복하는 방법이다.

```markdown
LpOCV = p개의 데이터를 검증용으로 남기고 나머지로 학습하는 교차 검증 방법
```

p=1인 경우는 LOOCV, 즉 Leave-One-Out Cross-Validation이라고 한다.

| 방법      | 핵심             |
| ------- | -------------- |
| 홀드아웃    | 한 번 나눔         |
| K-폴드    | K번 나누어 반복 평가   |
| 층화 K-폴드 | 클래스 비율 유지      |
| LpOCV   | p개를 검증 데이터로 남김 |

### 02. 지도학습 (Supervised Learning)

지도학습은 입력 데이터와 정답 데이터를 함께 학습하여 새로운 데이터의 결과를 예측하는 방법이다.

지도학습은 목표 변수의 형태에 따라 회귀와 분류로 구분된다.

```markdown
지도학습 = 정답이 있는 데이터를 학습하여 새로운 데이터의 결과를 예측하는 방법
```

#### 선형회귀(Linear Regression)

선형회귀는 독립변수와 종속변수 사이의 선형 관계를 이용해 연속형 값을 예측하는 분석 방법이다.

```markdown
선형회귀 = 독립변수와 종속변수 간 선형 관계를 이용해 연속형 값을 예측하는 방법
```

**1) 단순 선형 회귀와 다중 선형회귀**

1. 단순 선형 회귀(Simple Linear Regression)

단순 선형 회귀는 하나의 독립변수를 이용해 하나의 종속변수를 예측하는 회귀분석이다.

```markdown
단순 선형 회귀 = 독립변수 1개로 종속변수를 예측하는 회귀분석
```

예를 들어 공부 시간으로 시험 점수를 예측하는 것이 단순 선형 회귀이다.

2. 다중 선형회귀(Multiple Linear Regression)

다중 선형회귀는 여러 개의 독립변수를 이용해 하나의 종속변수를 예측하는 회귀분석이다.

```markdown
다중 선형회귀 = 독립변수 여러 개로 종속변수를 예측하는 회귀분석
```

예를 들어 공부 시간, 출석률, 과제 점수로 시험 점수를 예측하는 것이 다중 선형회귀이다.

| 구분       | 독립변수 개수 | 예시                |
| -------- | ------: | ----------------- |
| 단순 선형 회귀 |      1개 | 공부 시간으로 점수 예측     |
| 다중 선형회귀  |   2개 이상 | 공부 시간, 출석률로 점수 예측 |

**2) 선형회귀의 주요 가정**

1. 성형성(Linearity)

`성형성`은 `선형성`이 자연스럽다.

선형성은 독립변수와 종속변수 사이의 관계가 직선 형태로 설명될 수 있다는 가정이다.

```markdown
선형성 = 독립변수와 종속변수 사이에 선형 관계가 있다는 가정
```

2. 독립성(Independece)

정확한 표기는 `Independence`이다.

독립성은 관측치나 오차들이 서로 독립이라는 가정이다.

```markdown
독립성 = 관측치 또는 오차가 서로 영향을 주지 않는다는 가정
```

3. 정규성(Normality)

정규성은 오차항이 정규분포를 따른다는 가정이다.

```markdown
정규성 = 오차가 정규분포를 따른다는 가정
```

4. 등분산성(Homoscedasticity)

등분산성은 독립변수 값에 관계없이 오차의 분산이 일정하다는 가정이다.

```markdown
등분산성 = 오차의 분산이 일정하다는 가정
```

| 가정   | 핵심                 |
| ---- | ------------------ |
| 선형성  | 독립변수와 종속변수의 관계가 선형 |
| 독립성  | 오차들이 서로 독립         |
| 정규성  | 오차가 정규분포를 따름       |
| 등분산성 | 오차의 분산이 일정         |

**3) 비선형 관계를 반영한 회귀 모형**

1. 다항 회귀(Polnomial Regression)

정확한 표기는 `Polynomial Regression`이다.

다항 회귀는 독립변수의 제곱항, 세제곱항 등을 추가하여 비선형 관계를 표현하는 회귀분석이다.

```markdown
다항 회귀 = 변수의 거듭제곱 항을 추가하여 곡선 관계를 표현하는 회귀분석
```

예를 들어 x와 y의 관계가 직선이 아니라 곡선 형태라면 x² 항을 추가할 수 있다.

2. 비선형회귀(Nonlinear Regression)

비선형회귀는 회귀식 자체가 선형이 아닌 형태를 가지는 회귀분석이다.

```markdown
비선형회귀 = 변수와 결과의 관계를 비선형 함수로 표현하는 회귀분석
```

예를 들어 지수 함수, 로그 함수, 곡선 형태의 관계를 모델링할 수 있다.

**4) 모형 적합 방법**

모형 적합은 데이터에 가장 잘 맞는 회귀식을 찾는 과정이다.

1. 최적 회귀 방정식 계산

최적 회귀 방정식은 실제값과 예측값의 차이, 즉 잔차를 최소화하는 방향으로 계산된다.

```markdown
최적 회귀 방정식 = 실제값과 예측값의 차이를 최소화하는 회귀식
```

일반적으로 최소제곱법을 이용해 회귀계수를 추정한다.

2. 변수 선택(Variable Selection) 혹은 특성 선택(Feature Selection)

변수 선택은 예측에 필요한 변수를 선택하고 불필요한 변수를 제거하는 과정이다.

```markdown
변수 선택 = 모델 성능과 해석력을 높이기 위해 중요한 변수를 선택하는 과정
```

* 가설 설정

회귀분석에서 개별 회귀계수에 대한 가설은 보통 다음과 같이 설정한다.

| 구분   | 가설                  |
| ---- | ------------------- |
| 귀무가설 | 해당 변수의 회귀계수는 0이다    |
| 대립가설 | 해당 변수의 회귀계수는 0이 아니다 |

회귀계수가 0이라는 것은 해당 변수가 종속변수 설명에 유의한 영향을 주지 않는다는 의미이다.

3. 변수 선택 방법

대표적인 변수 선택 방법은 전진 선택, 후진 제거, 단계적 선택이다.

| 방법     | 설명                     |
| ------ | ---------------------- |
| 전진 선택  | 변수를 하나씩 추가             |
| 후진 제거  | 모든 변수에서 시작해 불필요한 변수 제거 |
| 단계적 선택 | 추가와 제거를 반복             |

4. 모형식을 활용한 예측(Prediction)

회귀식이 만들어지면 새로운 독립변수 값을 넣어 종속변수를 예측할 수 있다.

```markdown
예측 = 학습된 회귀식에 새로운 입력값을 넣어 결과값을 계산하는 것
```

5. 회귀 모형 평가

회귀 모형은 MAE, MSE, RMSE, R² 등을 이용해 평가한다.

```markdown
회귀 모형 평가는 실제값과 예측값의 차이를 기준으로 수행한다.
```

**5) 정규화 선형회귀(Regularized Linear Regression)**

정규화 선형회귀는 회귀계수에 패널티를 부여하여 과적합을 줄이는 방법이다.

```markdown
정규화 선형회귀 = 회귀계수에 제약을 주어 과적합을 방지하는 회귀 방법
```

1. 릿지 회귀(Ridge Regression)

릿지 회귀는 회귀계수의 제곱합에 패널티를 부여하는 방법이다.

```markdown
릿지 회귀 = L2 정규화를 사용하는 회귀
```

계수를 0에 가깝게 줄이지만 완전히 0으로 만들지는 않는다.

2. 라쏘 회귀(Lasso Regression)

라쏘 회귀는 회귀계수의 절댓값 합에 패널티를 부여하는 방법이다.

```markdown
라쏘 회귀 = L1 정규화를 사용하는 회귀
```

중요하지 않은 변수의 계수를 0으로 만들 수 있어 변수 선택 효과가 있다.

3. 엘라스틱넷(Elastic Net)

엘라스틱넷은 릿지와 라쏘를 결합한 방법이다.

```markdown
엘라스틱넷 = L1 정규화와 L2 정규화를 함께 사용하는 회귀
```

| 방법    | 정규화     | 특징                      |
| ----- | ------- | ----------------------- |
| 릿지    | L2      | 계수를 작게 줄임               |
| 라쏘    | L1      | 일부 계수를 0으로 만들어 변수 선택 가능 |
| 엘라스틱넷 | L1 + L2 | 릿지와 라쏘 결합               |

#### 로지스틱회귀(Logistic Regression)

로지스틱회귀는 목표 변수가 범주형일 때 사용하는 분류 알고리즘이다.
특히 이진 분류 문제에서 자주 사용된다.

```markdown
로지스틱회귀 = 사건 발생 확률을 예측하여 범주를 분류하는 방법
```

**1) 로지스틱회귀 개요**

로지스틱회귀는 선형회귀처럼 입력 변수들의 선형 결합을 사용하지만, 결과를 확률로 변환하여 분류한다.

예를 들어 고객 이탈 확률이 0.7이면 이탈로 분류하고, 0.3이면 비이탈로 분류할 수 있다.

| 활용 예시       |
| ----------- |
| 고객 이탈 여부 예측 |
| 스팸 메일 분류    |
| 질병 여부 예측    |
| 구매 여부 예측    |

**2) 로지스틱회귀 개념 이해**

1. 오즈(Odds)

오즈는 어떤 사건이 발생할 확률과 발생하지 않을 확률의 비율이다.

```markdown
Odds = p / (1 - p)
```

예를 들어 사건 발생 확률이 0.8이면 오즈는 0.8 / 0.2 = 4이다.

2. 로짓(logit)

로짓은 오즈에 자연로그를 취한 값이다.

```markdown
logit(p) = log(p / (1 - p))
```

로지스틱회귀는 로짓을 입력 변수들의 선형 결합으로 표현한다.

**3) 모형 적합 방법**

1. Log loss 정의

Log loss는 로지스틱회귀에서 예측 확률이 실제 정답과 얼마나 다른지 측정하는 손실 함수이다.

```markdown
Log loss = 실제 정답과 예측 확률의 차이를 측정하는 손실 함수
```

예측 확률이 실제 정답에 가까울수록 Log loss는 작아진다.

2. 회귀 계수의 추정

로지스틱회귀에서는 Log loss를 최소화하는 방향으로 회귀계수를 추정한다.

```markdown
로지스틱회귀의 계수는 손실 함수를 최소화하는 방향으로 추정한다.
```

#### 나이브 베이즈 분류(Naive Bayes Classification)

나이브 베이즈 분류는 베이즈 정리를 기반으로 한 확률적 분류 방법이다.

**1) 개념**

나이브 베이즈는 입력 변수들이 서로 독립이라고 가정하고, 각 클래스에 속할 확률을 계산하여 가장 높은 확률의 클래스로 분류한다.

```markdown
나이브 베이즈 = 변수 간 독립을 가정하고 베이즈 정리를 이용해 분류하는 방법
```

스팸 메일 분류, 문서 분류, 감성 분석 등에 자주 사용된다.

**2) 확률 계산 및 분류**

나이브 베이즈는 각 클래스에 대한 조건부 확률을 계산한다.

예를 들어 이메일에 특정 단어들이 포함되어 있을 때, 이 이메일이 스팸일 확률과 정상일 확률을 비교한다.

```markdown
각 클래스의 확률을 계산한 뒤, 가장 높은 확률을 가진 클래스로 분류한다.
```

| 장점          | 단점                    |
| ----------- | --------------------- |
| 계산이 빠르고 단순함 | 변수 독립 가정이 현실과 다를 수 있음 |

#### 서포터 벡터 머신 (SVM, Support Vectore Machine)

`서포터 벡터 머신`은 보통 `서포트 벡터 머신`, `Support Vector Machine`이라고 한다.

SVM은 데이터를 가장 잘 구분하는 결정 경계를 찾는 분류 알고리즘이다.

```markdown
SVM = 클래스 간 마진이 최대가 되는 결정 경계를 찾는 분류 알고리즘
```

SVM에서 중요한 개념은 마진과 서포트 벡터이다.

| 개념     | 설명                           |
| ------ | ---------------------------- |
| 결정 경계  | 클래스를 나누는 기준선 또는 초평면          |
| 마진     | 결정 경계와 가장 가까운 데이터 사이의 거리     |
| 서포트 벡터 | 결정 경계에 가장 가까운 데이터            |
| 커널     | 비선형 데이터를 고차원 공간에서 분리하기 위한 함수 |

SVM은 마진을 최대화하여 새로운 데이터에 대한 일반화 성능을 높이고자 한다.

```markdown
SVM은 클래스 사이의 마진을 최대화하는 결정 경계를 찾는다.
```

#### K-NN(KNN, K-Nearest Neighbors, K-접근 이웃)

`K-접근 이웃`은 보통 `K-최근접 이웃`이라고 한다.

K-NN은 새로운 데이터와 가장 가까운 K개의 이웃을 찾아 다수결로 분류하거나 평균으로 예측하는 방법이다.

```markdown
K-NN = 가까운 K개의 이웃을 기준으로 예측하는 방법
```

분류 문제에서는 가까운 K개 이웃의 다수 클래스로 분류한다.
회귀 문제에서는 가까운 K개 이웃의 평균값을 예측값으로 사용할 수 있다.

| 특징  | 설명                |
| --- | ----------------- |
| 기준  | 거리 기반             |
| 장점  | 개념이 단순하고 이해하기 쉬움  |
| 단점  | 데이터가 많으면 계산 비용 증가 |
| 주의점 | 변수 스케일에 민감        |

```markdown
K-NN은 거리 기반 방법이므로 표준화가 중요하다.
```

#### 의사결정나무(Decision Tree)

의사결정나무는 데이터를 여러 조건으로 분할하여 예측 규칙을 나무 구조로 표현하는 방법이다.

```markdown
의사결정나무 = 조건에 따라 데이터를 분할하여 예측하는 나무 구조 모델
```

**1) 개요**

의사결정나무는 루트 노드에서 시작해 조건에 따라 가지를 타고 내려가며 최종 리프 노드에서 예측 결과를 얻는다.

| 구성 요소 | 설명            |
| ----- | ------------- |
| 루트 노드 | 가장 처음 분할되는 노드 |
| 내부 노드 | 분할 조건을 가지는 노드 |
| 가지    | 조건에 따른 분기     |
| 리프 노드 | 최종 예측 결과      |

의사결정나무는 해석이 쉽지만, 나무가 너무 깊어지면 과적합될 수 있다.

**2) 회귀 나무**

회귀 나무는 목표 변수가 연속형일 때 사용하는 의사결정나무이다.

1. 분산을 활용한 최적 분할

회귀 나무는 분할 후 각 노드 내부의 분산이 작아지도록 데이터를 나눈다.

```markdown
회귀 나무는 노드 내부의 분산이 작아지도록 분할한다.
```

즉, 같은 노드 안의 값들이 서로 비슷해지도록 분할 기준을 선택한다.

2. 가지치기(Pruning)

가지치기는 너무 복잡한 나무를 단순화하여 과적합을 줄이는 방법이다.

```markdown
가지치기 = 불필요한 가지를 제거하여 과적합을 줄이는 방법
```

**3) 분류 나무(Classification Tree)**

분류 나무는 목표 변수가 범주형일 때 사용하는 의사결정나무이다.

1. 지니 불순도(Gini Impurity)혹은 지니 지수(Gini Index)

지니 불순도는 노드 안에 서로 다른 클래스가 얼마나 섞여 있는지를 나타내는 지표이다.

```markdown
지니 불순도 = 노드의 클래스가 얼마나 섞여 있는지 나타내는 지표
```

지니 불순도가 낮을수록 한 클래스가 잘 모여 있는 순수한 노드이다.

2. 엔트로피(Entropy)

엔트로피는 데이터의 불확실성이나 혼잡도를 나타내는 지표이다.

```markdown
엔트로피 = 데이터의 불확실성 정도를 나타내는 지표
```

엔트로피가 낮을수록 노드가 더 순수하다.

**4) 주요 알고리즘**

의사결정나무 알고리즘에는 CART, ID3, C4.5 등이 있다.

* 분리 기준 함수 비교

| 알고리즘 | 분리 기준        | 특징           |
| ---- | ------------ | ------------ |
| ID3  | 엔트로피, 정보 이득  | 범주형 변수 중심    |
| C4.5 | 정보 이득비       | ID3 개선       |
| CART | 지니 지수, 분산 감소 | 분류와 회귀 모두 가능 |

```markdown
분류 나무는 지니 불순도나 엔트로피를 기준으로 분할하고,
회귀 나무는 분산 감소를 기준으로 분할한다.
```

#### 앙상블 기법(Ensemble Method)

앙상블은 여러 모델을 결합하여 하나의 모델보다 더 안정적이고 좋은 성능을 얻는 방법이다.

**1) 개요**

앙상블은 여러 모델의 예측 결과를 결합한다.

```markdown
앙상블 = 여러 모델을 결합하여 예측 성능을 높이는 방법
```

대표적인 앙상블 기법에는 배깅, 부스팅, 스태킹이 있다.

**2) 배깅(Bagging, Bootstrap Aggregating)**

배깅은 여러 개의 학습 데이터를 복원추출 방식으로 만들고, 각 데이터로 모델을 학습한 뒤 결과를 결합하는 방법이다.

```markdown
배깅 = 여러 모델을 병렬로 학습하고 결과를 결합하는 방법
```

배깅은 모델의 분산을 줄이고 예측을 안정화하는 데 유용하다.

※ 랜덤 포레스트(Random Forest)

랜덤 포레스트는 여러 개의 의사결정나무를 학습하고 그 결과를 결합하는 대표적인 배깅 기반 앙상블 기법이다.

```markdown
랜덤 포레스트 = 여러 의사결정나무를 결합한 앙상블 모델
```

의사결정나무 하나는 과적합되기 쉽지만, 여러 나무를 결합하면 안정적인 예측이 가능하다.

**3) 부스팅(Boosting)**

부스팅은 여러 모델을 순차적으로 학습하면서 이전 모델이 틀린 데이터를 다음 모델이 더 잘 맞추도록 하는 방법이다.

```markdown
부스팅 = 이전 모델의 오류를 보완하며 순차적으로 학습하는 방법
```

대표적으로 AdaBoost, Gradient Boosting, XGBoost 등이 있다.

**4) 스태킹(Stacking)**

스태킹은 여러 모델의 예측 결과를 다시 새로운 모델의 입력으로 사용하여 최종 예측을 수행하는 방법이다.

```markdown
스태킹 = 여러 모델의 예측 결과를 다시 학습하여 최종 예측을 만드는 방법
```

| 기법  | 핵심              |
| --- | --------------- |
| 배깅  | 병렬 학습, 분산 감소    |
| 부스팅 | 순차 학습, 오류 보완    |
| 스태킹 | 여러 모델 결과를 다시 학습 |

#### 인공신경망(Artificial Neural Network, ANN) 모형

인공신경망은 인간의 신경망 구조를 모방하여 입력과 출력 사이의 복잡한 관계를 학습하는 모델이다.

**1) 개요**

인공신경망은 여러 뉴런과 층을 이용해 비선형 관계를 학습할 수 있다.

```markdown
인공신경망 = 입력층, 은닉층, 출력층을 통해 복잡한 패턴을 학습하는 모델
```

이미지 분류, 음성 인식, 자연어 처리 등 다양한 분야에 활용된다.

**2) 측 구성**

`측 구성`은 `층 구성`이 자연스럽다.

1. 입력층(Input Layer)

입력층은 데이터를 입력받는 층이다.

```markdown
입력층 = 모델에 데이터가 들어오는 층
```

2. 은닉층(Hidden Layer)

은닉층은 입력값을 조합하고 변환하여 패턴을 학습하는 층이다.

```markdown
은닉층 = 입력과 출력 사이에서 패턴을 학습하는 층
```

3. 출력층(Output Layer)

출력층은 최종 예측 결과를 출력하는 층이다.

```markdown
출력층 = 모델의 최종 예측 결과를 출력하는 층
```

**3) 활설 함수(Activation Function)**

`활설 함수`는 `활성 함수`가 자연스럽다.

활성 함수는 뉴런의 출력값을 결정하고, 신경망이 비선형 관계를 학습할 수 있도록 한다.

```markdown
활성 함수 = 뉴런의 출력값을 결정하는 함수
```

1. 계단(Step) 함수와 부호(Sign) 함수

계단 함수는 입력값이 기준보다 크면 1, 작으면 0을 출력하는 함수이다.
부호 함수는 입력값의 부호에 따라 값을 출력한다.

2. 시그모이드(Sigmoid) 함수

시그모이드 함수는 값을 0과 1 사이로 변환하는 함수이다.

```markdown
시그모이드 함수 = 출력을 0과 1 사이의 값으로 변환하는 함수
```

이진 분류의 확률 출력에 자주 사용된다.

3. ReLU(Rectified Linear Unit) 함수

ReLU는 입력값이 0보다 작으면 0, 0보다 크면 입력값 그대로 출력하는 함수이다.

```markdown
ReLU = max(0, x)
```

딥러닝에서 널리 사용되는 활성 함수이다.

4. Softmax 함수

Softmax 함수는 여러 클래스에 대한 값을 확률처럼 변환하는 함수이다.

```markdown
Softmax = 다중 클래스 분류에서 각 클래스의 확률을 출력하는 함수
```

**4) 층 구성에 따른 모형 구분**

1. 퍼셉트론(Perceptron)

퍼셉트론은 가장 기본적인 인공신경망 구조이다.

```markdown
퍼셉트론 = 입력값에 가중치를 곱해 출력값을 계산하는 기본 신경망 모델
```

단순한 선형 분류 문제를 해결할 수 있다.

2. 다층 퍼셉트론(Multi-Layer Perceptron, MLP)

다층 퍼셉트론은 입력층과 출력층 사이에 하나 이상의 은닉층을 가진 신경망이다.

```markdown
MLP = 하나 이상의 은닉층을 가진 인공신경망
```

비선형 문제를 학습할 수 있다.

**5) 모형 학습 과정**

1. 순전파(Forward Propagation)

순전파는 입력값이 신경망을 통과해 출력값을 계산하는 과정이다.

```markdown
순전파 = 입력에서 출력까지 예측값을 계산하는 과정
```

2. 손실 계산(Loss Computation)

손실 계산은 예측값과 실제값의 차이를 계산하는 과정이다.

```markdown
손실 = 예측값과 실제값의 차이
```

3. 역전파(backpropagation)

역전파는 손실을 줄이기 위해 출력층에서 입력층 방향으로 오차를 전달하며 기울기를 계산하는 과정이다.

```markdown
역전파 = 오차를 뒤로 전달하여 가중치 조정 방향을 계산하는 과정
```

4. 가중치 업데이트(Weight Update)

가중치 업데이트는 계산된 기울기를 이용해 가중치를 조정하는 과정이다.

```markdown
가중치 업데이트 = 손실을 줄이기 위해 가중치를 조정하는 과정
```

5. 반복과 수렴

순전파, 손실 계산, 역전파, 가중치 업데이트를 반복하면서 모델은 점차 손실이 작아지는 방향으로 학습된다.

```markdown
신경망 학습 = 순전파 → 손실 계산 → 역전파 → 가중치 업데이트 반복
```

#### 시계열 데이터 분석

시계열 데이터 분석은 시간 순서에 따라 관측된 데이터를 분석하는 방법이다.

**1) 개요**

시계열 데이터는 시간의 흐름에 따라 수집된 데이터이다.

```markdown
시계열 데이터 = 시간 순서에 따라 관측된 데이터
```

예를 들어 일별 매출, 월별 방문자 수, 주가, 기온 데이터 등이 시계열 데이터이다.

**2) 정상성(Stationarity)**

정상성은 시계열의 평균, 분산, 공분산 구조가 시간에 따라 일정하다는 성질이다.

```markdown
정상성 = 시계열의 통계적 특성이 시간에 따라 일정한 상태
```

시계열 모델링에서는 정상성을 만족하는 데이터가 중요하다.

**3) 자기회귀 모형(AutoRegressive Model AR)**

AR 모형은 현재 값이 과거 값들의 영향을 받는다고 보는 모형이다.

```markdown
AR 모형 = 현재 값을 과거 값으로 설명하는 모형
```

예를 들어 오늘 매출이 어제와 그제 매출의 영향을 받는다고 볼 수 있다.

**4) 이동평균 모형(Moving Average Model, MA)**

MA 모형은 현재 값이 과거 오차항들의 영향을 받는다고 보는 모형이다.

```markdown
MA 모형 = 현재 값을 과거 오차로 설명하는 모형
```

**5) 자기회귀이동평균 모형(AutoRegressive Moving Average Model, ARMA)**

ARMA 모형은 AR 모형과 MA 모형을 결합한 모형이다.

```markdown
ARMA 모형 = 자기회귀 모형과 이동평균 모형을 결합한 모형
```

정상성을 가진 시계열에 사용한다.

**6) 자기회귀누적이동평균 모형(AutoRegressive Integrated Moving Average Model, ARIMA)**

ARIMA 모형은 비정상 시계열을 차분하여 정상 시계열로 만든 뒤 ARMA를 적용하는 모형이다.

```markdown
ARIMA 모형 = 차분을 통해 비정상 시계열을 정상화한 뒤 분석하는 모형
```

ARIMA의 I는 Integrated, 즉 누적 또는 차분 과정을 의미한다.

**7) 시계열 분해(Time Series Decomposition)**

시계열 분해는 시계열 데이터를 추세, 계절성, 불규칙성으로 나누어 분석하는 방법이다.

1. 추세(Trend)

추세는 장기적으로 증가하거나 감소하는 방향성이다.

```markdown
추세 = 장기적인 증가 또는 감소 경향
```

2. 계줄성(Seasonality)

`계줄성`은 `계절성`이 자연스럽다.

계절성은 일정한 주기로 반복되는 패턴이다.

```markdown
계절성 = 일정 주기로 반복되는 패턴
```

예를 들어 여름철 아이스크림 매출 증가, 연말 쇼핑 증가가 계절성에 해당한다.

3. 불규칙성(Random) 혹은 잔차(Residual)

불규칙성은 추세나 계절성으로 설명되지 않는 무작위 변동이다.

```markdown
불규칙성 = 설명하기 어려운 무작위 변동
```

4. 가법 모형(Additive Model)과 승법 모형(Multiplicative Model)

가법 모형은 시계열이 추세, 계절성, 불규칙성의 합으로 구성된다고 본다.

```markdown
가법 모형 = 추세 + 계절성 + 불규칙성
```

승법 모형은 시계열이 추세, 계절성, 불규칙성의 곱으로 구성된다고 본다.

```markdown
승법 모형 = 추세 × 계절성 × 불규칙성
```

### 03. 비지도학습 (Unsupervised Learning)

비지도학습은 정답 라벨 없이 데이터의 구조, 패턴, 유사성, 관계를 찾는 방법이다.

```markdown
비지도학습 = 정답 없이 데이터의 숨겨진 구조나 패턴을 찾는 학습 방법
```

#### 주요 개념

비지도학습에서는 데이터 간 거리와 유사도를 계산하여 군집화, 차원 축소, 추천 등에 활용한다.

**1) 거리(Distance)**

거리는 두 데이터가 얼마나 떨어져 있는지를 나타낸다.
거리가 가까울수록 유사하다고 볼 수 있다.

```markdown
거리 = 두 데이터 사이의 차이를 수치로 나타낸 값
```

1. 유클리드 거리(euclidean Distance)

유클리드 거리는 두 점 사이의 직선거리이다.

```markdown
유클리드 거리 = 두 점 사이의 직선거리
```

가장 일반적으로 사용되는 거리 측도이다.

2. 맨해튼 거리(Manhattan Distance)

맨해튼 거리는 각 변수 차이의 절댓값을 모두 더한 거리이다.

```markdown
맨해튼 거리 = 각 좌표 차이의 절댓값 합
```

격자형 도로를 이동하는 거리와 비슷하다.

3. 민코프스키 거리(Minkowski Distance)

민코프스키 거리는 유클리드 거리와 맨해튼 거리를 일반화한 거리이다.

```markdown
민코프스키 거리 = 유클리드 거리와 맨해튼 거리를 포함하는 일반화된 거리
```

p=1이면 맨해튼 거리, p=2이면 유클리드 거리이다.

4. 체비쇼프 거리(Chebyshev Distance)

체비쇼프 거리는 각 변수 차이 중 가장 큰 값을 거리로 사용하는 방법이다.

```markdown
체비쇼프 거리 = 변수별 차이 중 최댓값을 거리로 사용하는 방법
```

| 거리       | 핵심         |
| -------- | ---------- |
| 유클리드 거리  | 직선거리       |
| 맨해튼 거리   | 절댓값 차이의 합  |
| 민코프스키 거리 | 거리 측도의 일반화 |
| 체비쇼프 거리  | 차이 중 최댓값   |

**2) 유사도(Similarity)**

유사도는 두 데이터가 얼마나 비슷한지를 나타낸다.
유사도가 높을수록 서로 비슷하다.

```markdown
유사도 = 두 데이터가 얼마나 비슷한지를 나타내는 값
```

1. 피어슨 상관계수(Pearson's Correlation Coeffcient)

정확한 표기는 `Pearson's Correlation Coefficient`이다.

피어슨 상관계수는 두 변수 간 선형 관계의 방향과 강도를 나타낸다.

```markdown
피어슨 상관계수 = 두 변수 간 선형 관계의 방향과 강도
```

2. 코사인 유사도(Cosine Similarity)

코사인 유사도는 두 벡터가 이루는 각도의 코사인 값을 이용해 유사도를 측정한다.

```markdown
코사인 유사도 = 두 벡터의 방향이 얼마나 비슷한지 측정하는 지표
```

문서 유사도, 추천 시스템에서 자주 사용된다.

3. 자카드 지수(Jaccard Index)와 자카드 거리(Jaccard Distance)

자카드 지수는 두 집합의 교집합 크기를 합집합 크기로 나눈 값이다.

```markdown
자카드 지수 = 교집합 / 합집합
```

자카드 거리는 1에서 자카드 지수를 뺀 값이다.

```markdown
자카드 거리 = 1 - 자카드 지수
```

| 유사도      | 핵심         |
| -------- | ---------- |
| 피어슨 상관계수 | 선형 관계      |
| 코사인 유사도  | 벡터 방향의 유사성 |
| 자카드 지수   | 집합 간 공통 비율 |

#### 차원 축소 및 행렬 분해 관련 방법론

차원 축소는 많은 변수 중 중요한 정보를 유지하면서 변수 수를 줄이는 방법이다.

```markdown
차원 축소 = 데이터의 주요 정보를 유지하면서 변수 수를 줄이는 방법
```

**1) 주성분 분석(Principal Component Analysis, PCA)**

PCA는 서로 상관된 여러 변수를 정보 손실을 최소화하면서 적은 수의 주성분으로 변환하는 방법이다.

```markdown
PCA = 데이터의 분산을 최대한 보존하는 방향으로 새로운 축을 만드는 차원 축소 방법
```

PCA는 변수 수를 줄이고 시각화나 노이즈 제거에 활용된다.

**2) 유인 분석(Factor Analysis, FA)**

`유인 분석`은 보통 `요인 분석`이라고 한다.

요인 분석은 여러 관측 변수 뒤에 숨어 있는 공통 요인을 찾아내는 방법이다.

```markdown
요인 분석 = 여러 변수에 공통적으로 영향을 주는 잠재 요인을 찾는 방법
```

예를 들어 여러 설문 문항을 분석해 만족도, 신뢰도, 편의성 같은 요인을 찾을 수 있다.

**3) 다차원 척도법(Multidimensional Scaling, MDS)**

MDS는 객체 간 거리나 유사도를 낮은 차원의 공간에 표현하는 방법이다.

```markdown
MDS = 객체 간 거리 관계를 저차원 공간에 배치하는 방법
```

1. 고전적 다차원 척도법(Classical MDS)

고전적 MDS는 거리 정보를 이용해 객체들을 저차원 공간에 배치하는 방법이다.

```markdown
고전적 MDS = 거리 행렬을 이용해 객체를 저차원 공간에 표현하는 방법
```

2. 계란형 다차원 척도법(Metric MDS)

`계란형`은 오타로 보이며, 문맥상 `계량형` 또는 `Metric MDS`를 의미한다.

Metric MDS는 원래 거리와 저차원 공간에서의 거리 차이가 작아지도록 배치하는 방법이다.

```markdown
Metric MDS = 원래 거리 관계를 최대한 보존하도록 저차원에 배치하는 방법
```

**4) 자기 조직화 지도(Self-Organizing Map, SOM)**

SOM은 고차원 데이터를 저차원 격자 구조로 표현하는 인공신경망 기반 비지도학습 방법이다.

```markdown
SOM = 고차원 데이터를 저차원 격자에 시각화하는 비지도학습 방법
```

군집화와 시각화에 활용된다.

#### 군집화 (Clustering)

군집화는 정답 없이 유사한 데이터끼리 그룹으로 묶는 비지도학습 방법이다.

```markdown
군집화 = 데이터 간 유사성을 기준으로 비슷한 데이터끼리 묶는 방법
```

**1) 계층적 군집화(Hierarchical Clustering)**

계층적 군집화는 군집 간 계층 구조를 만드는 방법이다.

```markdown
계층적 군집화 = 데이터를 단계적으로 묶거나 나누어 계층 구조를 만드는 방법
```

결과는 덴드로그램으로 표현할 수 있다.

* 군집 간 거리 측정 방식

| 방식      | 설명                     |
| ------- | ---------------------- |
| 최단연결법   | 두 군집에서 가장 가까운 객체 간 거리  |
| 최장연결법   | 두 군집에서 가장 먼 객체 간 거리    |
| 평균연결법   | 모든 객체 간 거리의 평균         |
| 중심연결법   | 군집 중심점 간 거리            |
| Ward 방법 | 군집 내 분산 증가가 최소가 되도록 병합 |

**2) K-평균 군집화(K-means Clustering)**

K-평균 군집화는 데이터를 K개의 군집으로 나누는 비계층적 군집화 방법이다.

```markdown
K-means = 데이터를 K개의 군집으로 나누는 군집화 방법
```

절차는 다음과 같다.

```markdown
K 결정 → 초기 중심 선택 → 가까운 중심에 할당 → 중심 재계산 → 반복
```

K-means는 이해하기 쉽고 계산이 빠르지만 K값을 미리 정해야 하며, 초기 중심점과 이상값에 민감하다.

**3) DBSCAN(Density Based Spatial Clustering of Applicaitons with Noise)

정확한 표기는 `Density-Based Spatial Clustering of Applications with Noise`이다.

DBSCAN은 밀도 기반 군집화 방법으로, 데이터가 밀집된 영역을 군집으로 찾고 밀도가 낮은 점은 잡음으로 처리한다.

```markdown
DBSCAN = 밀도가 높은 영역을 군집으로 찾고 잡음을 구분하는 군집화 방법
```

| 특징             | 설명                      |
| -------------- | ----------------------- |
| 밀도 기반          | 가까운 데이터가 많은 영역을 군집으로 인식 |
| 군집 수 사전 지정 불필요 | K-means와 달리 K값을 정하지 않음  |
| 이상값 탐지 가능      | 밀도가 낮은 점을 잡음으로 처리       |
| 복잡한 형태 군집 가능   | 구형이 아닌 군집도 탐지 가능        |

#### 유사도 기반 추천 알고리즘

유사도 기반 추천 알고리즘은 사용자, 상품, 항목 간 유사도나 연관성을 이용해 추천을 수행하는 방법이다.

```markdown
유사도 기반 추천 = 비슷한 사용자나 항목, 또는 함께 발생하는 항목 관계를 이용해 추천하는 방법
```

**1) 연관 규칙 분석(Assocication Rule Analysis)**

정확한 표기는 `Association Rule Analysis`이다.

연관 규칙 분석은 대량의 거래 데이터에서 항목 간 함께 발생하는 관계를 찾는 분석이다.

```markdown
연관 규칙 분석 = 항목 간 함께 발생하는 관계를 찾는 분석 방법
```

1. 연관 규칙의 정의

연관 규칙은 `A → B` 형태로 표현된다.

```markdown
A → B = A가 발생하면 B도 발생하는 경향이 있다
```

예를 들어 `노트북 → 마우스`는 노트북을 구매한 고객이 마우스도 구매하는 경향이 있다는 의미이다.

2. 지지도(Support)

지지도는 전체 거래 중 A와 B가 함께 발생한 비율이다.

```markdown
Support(A → B) = P(A ∩ B)
```

3. 신뢰도(Confidence)

신뢰도는 A가 발생한 거래 중 B도 발생한 비율이다.

```markdown
Confidence(A → B) = P(B|A)
```

4. 향상도(Lift)

향상도는 A가 B의 발생 가능성을 얼마나 높이는지 나타내는 지표이다.

```markdown
Lift(A → B) = Confidence(A → B) / Support(B)
```

|      향상도 | 의미       |
| -------: | -------- |
| Lift > 1 | 양의 연관 관계 |
| Lift = 1 | 독립       |
| Lift < 1 | 음의 연관 관계 |

**2) 연관 분석 알고리즘**

대표적인 연관 분석 알고리즘은 Apriori 알고리즘이다.

Apriori 알고리즘은 최소 지지도를 기준으로 빈번 항목 집합을 찾고, 이를 바탕으로 연관 규칙을 생성한다.

```markdown
Apriori 알고리즘 = 빈번 항목 집합을 찾아 연관 규칙을 생성하는 알고리즘
```

핵심 원리는 다음과 같다.

```markdown
빈번 항목 집합의 부분집합도 반드시 빈번해야 한다.
```

즉, 어떤 항목 집합이 자주 등장하지 않는다면 그것을 포함하는 더 큰 항목 집합도 자주 등장하기 어렵다.
이 원리를 이용해 탐색 범위를 줄인다.

# 시험 직전 암기 문장

```markdown
지도학습은 정답이 있는 데이터를 학습하여 예측하는 방법이고,
비지도학습은 정답 없이 데이터의 구조와 패턴을 찾는 방법이다.

회귀는 연속형 수치 값을 예측하고,
분류는 미리 정의된 범주를 예측한다.

회귀 문제는 실제값과 예측값의 오차를 기준으로 평가하며,
MAE, MSE, RMSE, MAPE, R² 등을 사용한다.

분류 문제는 오차 행렬을 바탕으로 정확도, 정밀도, 재현율, F1 Score, ROC 곡선 등을 사용한다.

정확도는 전체 예측 중 맞춘 비율이고,
정밀도는 Positive라고 예측한 것 중 실제 Positive인 비율이며,
재현율은 실제 Positive 중 Positive로 맞게 찾아낸 비율이다.

교차 검증은 모델의 일반화 성능을 평가하기 위해 데이터를 여러 방식으로 나누어 검증하는 방법이다.

선형회귀는 독립변수와 종속변수의 선형 관계를 이용해 연속형 값을 예측하는 방법이다.

로지스틱회귀는 사건 발생 확률을 예측하여 범주를 분류하는 방법이다.

나이브 베이즈는 변수 간 독립을 가정하고 베이즈 정리를 이용해 분류하는 방법이다.

SVM은 클래스 사이의 마진을 최대화하는 결정 경계를 찾는 알고리즘이다.

K-NN은 가까운 K개의 이웃을 기준으로 새로운 데이터를 예측하는 방법이다.

의사결정나무는 조건에 따라 데이터를 분할하여 예측 규칙을 나무 구조로 표현하는 방법이다.

앙상블은 여러 모델을 결합해 성능을 높이는 방법이며,
배깅은 병렬 학습, 부스팅은 순차 학습, 스태킹은 여러 모델 결과를 다시 학습하는 방식이다.

인공신경망은 입력층, 은닉층, 출력층을 통해 복잡한 패턴을 학습하는 모델이다.

시계열 데이터는 시간 순서에 따라 관측된 데이터이며,
추세, 계절성, 불규칙성으로 분해할 수 있다.

PCA는 데이터의 분산을 최대한 보존하면서 차원을 축소하는 방법이다.

군집화는 데이터 간 유사성을 기준으로 비슷한 데이터끼리 묶는 비지도학습 방법이다.

K-means는 데이터를 K개의 군집으로 나누는 방법이고,
DBSCAN은 밀도 기반으로 군집을 찾고 잡음을 구분하는 방법이다.

연관 규칙 분석은 A → B 형태로 항목 간 함께 발생하는 관계를 찾는 분석이다.

지지도는 전체 거래 중 A와 B가 함께 발생한 비율이고,
신뢰도는 A가 발생했을 때 B도 발생한 비율이며,
향상도는 A가 B의 발생 가능성을 얼마나 높이는지 나타낸다.
```
