## 068. 멀티미디어 소프트웨어

### 1. 멀티미디어 소프트웨어의 분류

| 구분 | 기능 | 예 |
| --- | --- | --- |
| **재생 소프트웨어** | 오디오·비디오를 재생합니다. | Windows Media Player, VLC, 곰플레이어 |
| **편집 소프트웨어** | 이미지·오디오·비디오를 편집합니다. | 포토샵, 일러스트레이터, 프리미어 |
| **저작 소프트웨어** | 여러 멀티미디어 요소를 **하나의 콘텐츠로 통합**합니다. | 디렉터, 오소웨어, 툴북 |
| **압축 소프트웨어** | 데이터를 압축하고 해제합니다. | 알집, 반디집, 7-Zip |

#### 왜 "저작 소프트웨어"를 따로 구분할까?

편집 소프트웨어는 **하나의 매체를 다듬는 도구**입니다.  
포토샵은 이미지만, 프리미어는 영상만 다룹니다.

저작 소프트웨어는 이렇게 만들어진 요소들을

- 화면에 배치하고
- 재생 순서를 정하고
- **사용자의 클릭에 따라 반응하도록** 연결합니다.

즉, 저작 도구는 **"재료를 만드는 것"이 아니라 "재료를 엮어 하나의 작품으로 완성하는 것"** 이 목적입니다.

### 2. 그래픽 편집 소프트웨어

| 구분 | 특징 | 예 |
| --- | --- | --- |
| **비트맵(래스터) 편집** | 화소(픽셀) 단위로 이미지를 편집합니다. 사진 보정에 적합합니다. | 포토샵, 페인트샵, 그림판 |
| **벡터 편집** | 점과 선의 **수학적 계산**으로 이미지를 표현합니다. 로고·도형 제작에 적합합니다. | 일러스트레이터, 코렐드로우, 플래시 |

#### 왜 로고는 벡터로 만들까?

로고는 명함처럼 작게도 쓰이고, 건물 간판처럼 크게도 쓰입니다.

**비트맵**은 픽셀의 집합이므로 확대하면 픽셀이 커져 **계단 현상(깨짐)** 이 발생합니다.

**벡터**는 "이 위치에서 저 위치까지 선을 그어라"라는 **수식**으로 저장되므로,  
크기를 바꿀 때 **다시 계산해서 그립니다.**

따라서 아무리 확대해도 **선명함이 유지**됩니다.

### 3. 그래픽 관련 기법

| 기법 | 설명 |
| --- | --- |
| **디더링(Dithering)** | 표현할 수 없는 색을 **인접한 색들을 섞어** 비슷하게 표현하는 기법입니다. |
| **안티앨리어싱(Anti-Aliasing)** | 이미지의 **계단 현상을 제거**하기 위해 경계선을 부드럽게 처리하는 기법입니다. |
| **모델링(Modeling)** | 3차원 물체의 **형태를 만드는** 과정입니다. |
| **렌더링(Rendering)** | 3차원 모델에 **색상, 명암, 질감을 입혀 실감 나게** 표현하는 과정입니다. |
| **모핑(Morphing)** | 두 이미지를 자연스럽게 **변형·합성**하여 다른 이미지로 바뀌게 하는 기법입니다. |
| **인터레이싱(Interlacing)** | 이미지를 **대략적인 형태부터 점차 선명하게** 표시하는 기법입니다. |
| **메조틴트(Mezzotint)** | 점과 선을 이용해 **동판화 느낌**을 내는 기법입니다. |
| **솔러리제이션(Solarization)** | 사진을 **음화와 양화가 섞인 듯한** 효과로 표현합니다. |
| **필터링(Filtering)** | 이미지에 다양한 효과를 적용합니다. |
| **리터칭(Retouching)** | 이미지의 결점을 수정하거나 보정합니다. |

#### 왜 안티앨리어싱이 필요할까?

화면은 **네모난 픽셀의 집합**입니다.

그래서 대각선이나 곡선을 그리면, 픽셀 단위로 끊겨  
**들쭉날쭉한 계단 모양**이 나타납니다. (이를 앨리어싱이라고 합니다.)

안티앨리어싱은 경계 부분에 **중간 밝기의 픽셀을 넣어** 눈속임을 합니다.

멀리서 보면 사람의 눈이 이를 섞어서 인식하므로,  
**부드러운 선처럼 보이게** 됩니다.

#### 왜 디더링이 필요할까?

표현할 수 있는 색의 수가 제한적일 때(예: 256색),  
원본의 미세한 색상 변화를 그대로 표현할 수 없습니다.

디더링은 **가지고 있는 색들을 촘촘히 섞어 배치**하여,  
사람의 눈에는 **중간색으로 보이게** 만드는 기법입니다.

인쇄물의 색을 확대해서 보면 작은 점들의 조합인 것과 같은 원리입니다.

#### 모델링과 렌더링의 관계

3D 작업은 두 단계로 나뉩니다.

- **모델링** : 형태를 만드는 단계 (뼈대와 모양)
- **렌더링** : 그 형태에 색·빛·질감을 입혀 **실제처럼 보이게** 만드는 단계

조각에 비유하면 모델링은 **형태를 깎는 일**, 렌더링은 **색을 칠하고 조명을 비추는 일**입니다.

렌더링은 빛의 반사와 그림자를 계산해야 하므로 **연산량이 매우 많고 시간이 오래 걸립니다.**

### 4. 오디오 / 비디오 편집 소프트웨어

| 종류 | 기능 |
| --- | --- |
| 오디오 편집 | 소리의 자르기, 합치기, 효과 적용, 잡음 제거 |
| 비디오 편집 | 영상의 자르기, 전환 효과, 자막 삽입, 색 보정, 인코딩 |
| 인코딩 프로그램 | 영상을 다른 형식이나 코덱으로 변환합니다. |

### 5. 멀티미디어 콘텐츠 관련 용어

| 용어 | 설명 |
| --- | --- |
| **CAI** | 컴퓨터를 이용한 교육 시스템입니다. |
| **VOD** | 원하는 시간에 원하는 영상을 시청하는 서비스입니다. |
| **VCS(화상 회의 시스템)** | 원거리의 참가자가 영상과 음성으로 회의합니다. |
| **키오스크** | 공공장소의 무인 정보 안내 시스템입니다. |
| **전자책(e-Book)** | 책의 내용을 디지털로 만들어 화면으로 읽는 형태입니다. |
| **인포테인먼트** | 정보(Information)와 오락(Entertainment)을 결합한 콘텐츠입니다. |

---

### 한 줄 정리

멀티미디어 소프트웨어는 **재생·편집·저작·압축**으로 나뉘며,  
**비트맵은 픽셀 단위(확대 시 깨짐), 벡터는 수식 기반(확대해도 선명)** 이고,  
**안티앨리어싱은 계단 현상 제거, 디더링은 색상 혼합, 렌더링은 3D에 질감·명암을 입히는 기법**입니다.
