## 010. 폴더 옵션

### 1. 폴더 옵션의 개요

폴더 옵션은 **파일과 폴더의 표시 방법, 검색 방법 등을 사용자가 원하는 대로 설정**하는 기능입니다.

- 실행 방법
  - 파일 탐색기 → [파일] 탭 → [폴더 및 검색 옵션 변경]
  - 파일 탐색기 → [보기] 탭 → [옵션]
  - [제어판] → [파일 탐색기 옵션]

#### 왜 폴더 옵션이 필요할까?

사용자마다 파일을 다루는 방식이 다릅니다.  
확장자를 항상 보고 싶은 사람도 있고, 화면을 단순하게 유지하고 싶은 사람도 있습니다.

폴더 옵션은 이런 **표시 기준을 사용자가 직접 정하도록** 제공하는 설정 창입니다.

---

### 2. [일반] 탭

| 항목 | 설명 |
| --- | --- |
| 파일 탐색기 열기 | 파일 탐색기 실행 시 처음 표시할 위치를 '즐겨찾기' 또는 '내 PC' 중에서 선택합니다. |
| 폴더 찾아보기 | 같은 창에서 폴더 열기 / 새 창에서 폴더 열기 중 선택합니다. |
| 항목을 다음과 같이 클릭 | 한 번 클릭해서 열기 / 두 번 클릭해서 열기 중 선택합니다. |
| 개인 정보 보호 | 즐겨찾기에 최근에 사용된 파일·폴더 표시 여부를 지정하고, 탐색기 기록을 지웁니다. |

#### 왜 "한 번 클릭해서 열기" 옵션이 있을까?

웹 브라우저에서는 링크를 한 번만 클릭해도 열립니다.  
이 방식에 익숙한 사용자를 위해 파일 탐색기에서도 **웹과 동일한 조작감**을 선택할 수 있도록 제공합니다.

---

### 3. [보기] 탭

**고급 설정**에서 다음과 같은 항목을 지정할 수 있습니다.

| 항목 | 설명 |
| --- | --- |
| 알려진 파일 형식의 파일 확장명 숨기기 | 체크를 해제하면 `.txt`, `.exe` 같은 확장자가 표시됩니다. |
| 숨김 파일, 폴더 및 드라이브 표시 | 숨김 속성이 지정된 항목을 화면에 표시합니다. |
| 보호된 운영 체제 파일 숨기기(권장) | 시스템 동작에 필요한 파일을 숨겨 실수로 삭제하는 것을 방지합니다. |
| 폴더 팁에 파일 크기 정보 표시 | 폴더에 마우스를 가져갔을 때 크기 정보를 표시합니다. |
| 제목 표시줄에 전체 경로 표시 | 창 제목에 전체 경로를 표시합니다. |
| 미리 보기 창에 미리 보기 처리기 표시 | 미리 보기 창에서 파일 내용을 표시합니다. |
| 폴더에 보기 적용 / 폴더를 원래대로 | 현재 폴더의 보기 형식을 같은 유형의 모든 폴더에 적용하거나 초기화합니다. |

#### 왜 확장자를 기본적으로 숨겨 둘까?

일반 사용자가 파일 이름을 바꾸다가 확장자까지 함께 바꾸면,  
파일이 열리지 않는 문제가 생길 수 있습니다.

그래서 기본값은 숨김이지만,  
**악성 파일 구분이나 파일 형식 확인**이 필요한 경우에는 표시하도록 바꾸는 편이 안전합니다.

(예 : `사진.jpg.exe` 처럼 이미지를 위장한 실행 파일은 확장자를 표시해야 구분할 수 있습니다.)

#### 왜 보호된 운영 체제 파일은 따로 숨길까?

숨김 파일 표시를 켜더라도 시스템 파일은 여전히 감춰져 있습니다.

시스템 파일은 잘못 삭제하거나 수정하면 **부팅 자체가 불가능**해질 수 있으므로,  
일반 숨김 파일보다 한 단계 더 강하게 보호합니다.

---

### 4. [검색] 탭

| 항목 | 설명 |
| --- | --- |
| 색인에서 검색 시 파일 이름 및 내용 찾기 | 색인이 만들어진 위치에서는 파일 이름과 내용을 모두 검색합니다. |
| 색인되지 않은 위치 검색 시 시스템 디렉터리 포함 | 시스템 폴더도 검색 대상에 포함합니다. |
| 압축 파일 포함 | ZIP, CAB 등 압축 파일 내부까지 검색합니다. |
| 파일 이름 및 내용 항상 검색 | 색인 여부와 관계없이 내용까지 검색합니다. (시간이 오래 걸립니다.) |

#### 왜 색인(Index)을 사용할까?

검색할 때마다 모든 파일을 하나하나 열어서 확인하면 시간이 매우 오래 걸립니다.

색인은 **파일의 이름과 내용을 미리 정리해 둔 목록**입니다.  
책의 찾아보기(색인)를 이용하면 원하는 내용을 빨리 찾을 수 있는 것과 같은 원리입니다.

즉, 색인은  
**검색 속도를 높이기 위해 미리 만들어 두는 요약 정보**입니다.

---

### 한 줄 정리

폴더 옵션은 **[일반] · [보기] · [검색]** 세 개의 탭으로 구성되며,  
확장자 표시와 숨김 파일 표시는 **[보기] 탭**에서,  
색인 기반 검색 설정은 **[검색] 탭**에서 지정합니다.
