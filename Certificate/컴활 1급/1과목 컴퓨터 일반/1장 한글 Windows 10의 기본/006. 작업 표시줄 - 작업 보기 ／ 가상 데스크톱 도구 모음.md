## 006. 작업 표시줄 - 작업 보기 / 가상 데스크톱 / 도구 모음

### 1. 작업 보기(Task View)

작업 보기는 **현재 실행 중인 모든 앱을 축소된 미리 보기 형태로 한 화면에 표시**하는 기능입니다.

- 실행 방법 : 작업 표시줄의 [작업 보기] 단추 클릭 또는 `⊞` + `Tab`
- 미리 보기에서 원하는 창을 클릭하면 해당 창으로 전환됩니다.
- 화면 위쪽에서는 **가상 데스크톱**을 추가하거나 전환할 수 있습니다.
- 아래쪽에는 **타임라인(과거에 작업한 항목 기록)** 이 표시됩니다.

#### 왜 작업 보기가 필요할까?

`Alt` + `Tab`으로도 창을 전환할 수 있지만, 창이 많아지면 목록이 작아져 구분하기 어렵습니다.

작업 보기는 **화면 전체를 사용해 큼직한 미리 보기**를 제공하므로,  
창이 많을수록 원하는 창을 정확히 찾기 쉽습니다.

---

### 2. 가상 데스크톱(Virtual Desktop)

가상 데스크톱은 **하나의 컴퓨터에서 여러 개의 바탕 화면을 만들어 사용하는 기능**입니다.

| 작업 | 방법 |
| --- | --- |
| 새 데스크톱 추가 | 작업 보기 → [새 데스크톱] 또는 `⊞` + `Ctrl` + `D` |
| 데스크톱 전환 | `⊞` + `Ctrl` + `←` / `→` |
| 현재 데스크톱 닫기 | `⊞` + `Ctrl` + `F4` |
| 창을 다른 데스크톱으로 이동 | 작업 보기에서 창을 드래그하거나, 바로 가기 메뉴 → [이동] |

- 데스크톱을 닫으면 **그 안에서 실행 중이던 앱은 종료되지 않고 이전 데스크톱으로 이동**합니다.
- 각 데스크톱은 **바탕 화면 아이콘과 배경을 공유**하며, 실행 중인 창만 구분됩니다.

#### 왜 가상 데스크톱을 쓸까?

한 화면에서 여러 종류의 작업을 동시에 하면 창이 뒤섞여 집중하기 어렵습니다.

가상 데스크톱은 성격이 다른 작업을 **아예 다른 화면으로 분리**해 줍니다.

예를 들어

- 데스크톱 1 : 문서 작업
- 데스크톱 2 : 자료 조사
- 데스크톱 3 : 메신저

이렇게 나누면 필요한 작업 공간만 보면서 일할 수 있습니다.

#### 왜 데스크톱을 닫아도 앱은 종료되지 않을까?

가상 데스크톱은 **작업 공간을 나누는 논리적 구분**일 뿐,  
프로그램을 실제로 격리하여 실행하는 것이 아닙니다.

따라서 데스크톱을 닫는 것은 "칸막이를 치우는 것"에 가깝고,  
그 안에 있던 창은 사라지지 않고 다른 데스크톱으로 옮겨집니다.

---

### 3. 타임라인(Timeline)

작업 보기 화면 아래쪽에 표시되는 기능으로, **과거에 사용했던 앱과 문서의 기록**을 보여 줍니다.

- 날짜별로 정리되어 있어 이전 작업을 다시 이어서 할 수 있습니다.
- Microsoft 계정으로 로그인하면 여러 기기의 활동 기록을 함께 볼 수 있습니다.

---

### 4. 작업 표시줄의 도구 모음

작업 표시줄의 바로 가기 메뉴 → [도구 모음]에서 다음 항목을 추가할 수 있습니다.

| 도구 모음 | 기능 |
| --- | --- |
| 주소 | 작업 표시줄에 주소 입력란을 표시하여 웹 사이트나 폴더 경로를 바로 열 수 있습니다. |
| 링크 | 자주 사용하는 웹 사이트 링크를 표시합니다. |
| 바탕 화면 | 바탕 화면에 있는 아이콘 목록을 작업 표시줄에서 바로 열 수 있습니다. |
| 새 도구 모음 | 사용자가 지정한 폴더를 도구 모음으로 추가합니다. |

#### 왜 도구 모음을 작업 표시줄에 둘까?

작업 표시줄은 **항상 화면에 떠 있는 영역**입니다.

자주 접근하는 폴더나 사이트를 이곳에 두면,  
바탕 화면을 보이게 하거나 탐색기를 열지 않고도 바로 접근할 수 있습니다.

---

### 한 줄 정리

작업 보기는 **실행 중인 창을 한눈에 보고 전환하는 기능**,  
가상 데스크톱은 **작업 성격에 따라 바탕 화면을 여러 개로 분리하는 기능**이며,  
가상 데스크톱을 닫아도 **그 안의 앱은 종료되지 않고 다른 데스크톱으로 이동**합니다.
