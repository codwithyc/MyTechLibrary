# 군집 분석

군집 분석은 정형 데이터 마이닝에서 자주 나오는 핵심 분석 기법이다.
분류 분석이 “정답이 있는 상태에서 데이터를 나누는 것”이라면, 군집 분석은 **정답이 없는 상태에서 데이터의 유사성을 기준으로 그룹을 나누는 것**이다.

```markdown
군집 분석 = 데이터 간 유사성을 기준으로 비슷한 데이터끼리 묶는 비지도 학습 기법
```

ADsP 시험에서는 계산보다 다음 개념 구분이 중요하다.

* 군집 분석의 개념
* 분류 분석과 군집 분석의 차이
* 군집 분석의 목적
* 거리 측도
* 계층적 군집 분석
* 비계층적 군집 분석
* K-means 군집 분석
* 군집 분석 결과 해석
* 군집 분석의 장단점

기존 정리처럼 개념을 먼저 이해하고 표로 압축하는 방식이 시험 직전 복습에 좋다. 

---

# 01. 군집 분석의 개념

## 군집 분석의 정의

**군집 분석(Clustering Analysis)**은 데이터 간의 유사도 또는 거리를 기준으로 비슷한 데이터는 같은 그룹으로 묶고, 서로 다른 데이터는 다른 그룹으로 나누는 분석 기법이다.

여기서 중요한 점은 **미리 정해진 정답이 없다는 것**이다.

예를 들어 고객 데이터가 있다고 하자.

```markdown
나이
구매 금액
방문 횟수
최근 구매일
관심 상품
```

이 데이터를 이용해서 고객을 다음과 같이 나눌 수 있다.

```markdown
고가 상품을 자주 구매하는 고객군
방문은 많지만 구매는 적은 고객군
최근에 이탈 가능성이 높은 고객군
신규 유입 고객군
```

이처럼 군집 분석은 데이터 안에 숨어 있는 자연스러운 그룹을 찾는 데 사용한다.

```markdown
군집 분석은 정답 라벨 없이 데이터의 특성을 기준으로 유사한 객체들을 그룹화하는 분석이다.
```

---

# 02. 군집 분석의 목적

군집 분석의 목적은 데이터를 비슷한 특성을 가진 그룹으로 나누어, 각 그룹의 특징을 파악하는 것이다.

| 목적        | 설명                        |
| --------- | ------------------------- |
| 데이터 구조 파악 | 데이터 안에 어떤 그룹이 존재하는지 확인    |
| 고객 세분화    | 고객을 비슷한 특성의 집단으로 나눔       |
| 패턴 발견     | 데이터 속 숨겨진 유사 패턴을 탐색       |
| 이상값 탐지    | 다른 데이터와 멀리 떨어진 특이 데이터를 찾음 |
| 마케팅 전략 수립 | 군집별 맞춤형 전략을 설계            |
| 추천 및 타겟팅  | 비슷한 사용자나 상품을 묶어 활용        |

예를 들어 쇼핑몰 고객을 군집 분석하면 다음과 같이 활용할 수 있다.

```markdown
VIP 고객군 → 프리미엄 혜택 제공
가격 민감 고객군 → 할인 쿠폰 제공
휴면 위험 고객군 → 재방문 이벤트 제공
신규 고객군 → 온보딩 캠페인 제공
```

시험에서는 이렇게 이해하면 된다.

```markdown
군집 분석의 목적은 유사한 데이터끼리 그룹화하여 데이터 구조와 집단별 특성을 파악하는 것이다.
```

# 03. 분류 분석과 군집 분석의 차이

군집 분석은 분류 분석과 자주 비교된다.

둘 다 데이터를 그룹으로 나누는 분석이지만, 가장 큰 차이는 **정답 라벨의 존재 여부**다.

| 구분    | 분류 분석                  | 군집 분석                |
| ----- | ---------------------- | -------------------- |
| 학습 유형 | 지도 학습                  | 비지도 학습               |
| 정답 라벨 | 있음                     | 없음                   |
| 목적    | 새로운 데이터를 미리 정의된 범주로 분류 | 데이터의 유사성을 기준으로 그룹 발견 |
| 예시    | 이탈/비이탈 예측, 합격/불합격 예측   | 고객 세분화, 유사 상품 그룹화    |
| 결과    | 정해진 클래스                | 새롭게 발견된 군집           |

예를 들어 고객 이탈 여부가 이미 `이탈`, `비이탈`로 표시되어 있고, 이를 학습해 새로운 고객의 이탈 여부를 예측한다면 분류 분석이다.

반면 고객에게 정답 라벨이 없고, 구매 패턴을 기준으로 비슷한 고객끼리 묶는다면 군집 분석이다.

```markdown
분류 분석은 정답이 있는 지도 학습이고,
군집 분석은 정답 없이 유사성을 기준으로 그룹을 찾는 비지도 학습이다.
```

# 04. 군집 분석의 주요 개념

## 1) 객체

군집 분석에서 **객체**는 군집화의 대상이 되는 데이터 하나하나를 의미한다.

예를 들어 고객 데이터를 분석한다면 고객 한 명이 객체가 된다.

```markdown
객체 = 군집 분석에서 그룹화의 대상이 되는 개별 데이터
```

---

## 2) 군집

**군집(Cluster)**은 서로 유사한 객체들이 모인 그룹이다.

하나의 군집 안에 있는 객체들은 서로 비슷해야 하고, 서로 다른 군집에 있는 객체들은 차이가 커야 한다.

```markdown
군집 = 유사한 객체들이 모인 그룹
```

---

## 3) 유사도와 거리

군집 분석은 데이터 간의 유사성을 기준으로 한다.

* 유사도가 높다 → 서로 비슷하다
* 거리가 가깝다 → 서로 비슷하다
* 거리가 멀다 → 서로 다르다

```markdown
군집 분석에서는 데이터 간 거리가 가까울수록 유사하다고 판단한다.
```

---

# 05. 거리 측도

군집 분석에서는 객체 간 거리를 계산해야 한다.

거리 측도는 데이터가 얼마나 비슷하거나 다른지를 수치로 표현하는 방법이다.

대표적인 거리 측도는 다음과 같다.

```markdown
유클리드 거리
맨해튼 거리
민코프스키 거리
마할라노비스 거리
```

---

## 1) 유클리드 거리

**유클리드 거리(Euclidean Distance)**는 두 점 사이의 직선거리를 의미한다.

가장 일반적으로 사용되는 거리 측도다.

예를 들어 2차원 평면에서 두 점이 있을 때, 두 점 사이의 직선거리를 계산한다.

```markdown
유클리드 거리 = 두 점 사이의 직선거리
```

| 특징          | 설명                 |
| ----------- | ------------------ |
| 가장 일반적      | 군집 분석에서 자주 사용      |
| 직선거리        | 두 점 사이의 최단 거리      |
| 수치형 데이터에 적합 | 연속형 변수 간 거리 계산에 사용 |

시험에서는 이렇게 기억하면 된다.

```markdown
유클리드 거리는 두 객체 사이의 직선거리이다.
```

---

## 2) 맨해튼 거리

**맨해튼 거리(Manhattan Distance)**는 각 좌표 차이의 절댓값을 모두 더한 거리다.

도시의 격자형 도로를 이동하는 것처럼 가로와 세로 방향으로 이동한 거리라고 이해하면 된다.

```markdown
맨해튼 거리 = 각 변수 차이의 절댓값 합
```

| 특징       | 설명                       |
| -------- | ------------------------ |
| 격자 이동 거리 | 직선이 아니라 축 방향 이동 거리       |
| 절댓값 합    | 변수별 차이를 절댓값으로 더함         |
| 도시 블록 거리 | City Block Distance라고도 함 |

시험에서는 이렇게 기억하면 된다.

```markdown
맨해튼 거리는 가로·세로로 이동한 거리의 합이다.
```

---

## 3) 민코프스키 거리

**민코프스키 거리(Minkowski Distance)**는 유클리드 거리와 맨해튼 거리를 일반화한 거리다.

p값에 따라 거리 계산 방식이 달라진다.

|    p값 | 거리      |
| ----: | ------- |
| p = 1 | 맨해튼 거리  |
| p = 2 | 유클리드 거리 |

```markdown
민코프스키 거리는 유클리드 거리와 맨해튼 거리를 포함하는 일반화된 거리이다.
```

---

## 4) 마할라노비스 거리

**마할라노비스 거리(Mahalanobis Distance)**는 변수 간 상관관계를 고려한 거리다.

일반적인 유클리드 거리는 변수 간 상관관계를 고려하지 않는다.
하지만 마할라노비스 거리는 데이터의 분산과 공분산 구조를 반영한다.

```markdown
마할라노비스 거리 = 변수 간 상관관계와 분산을 고려한 거리
```

| 특징        | 설명                    |
| --------- | --------------------- |
| 상관관계 고려   | 변수 간 관계를 반영           |
| 분산 고려     | 변수별 퍼짐 정도 반영          |
| 이상값 탐지 활용 | 평균으로부터 얼마나 특이한지 판단 가능 |

시험에서는 깊은 계산보다 개념만 기억하면 된다.

```markdown
마할라노비스 거리는 변수 간 상관관계를 고려한 거리이다.
```

---

## 거리 측도 정리

| 거리 측도     | 핵심                 |
| --------- | ------------------ |
| 유클리드 거리   | 두 점 사이의 직선거리       |
| 맨해튼 거리    | 각 변수 차이의 절댓값 합     |
| 민코프스키 거리  | 유클리드와 맨해튼을 일반화한 거리 |
| 마할라노비스 거리 | 변수 간 상관관계를 고려한 거리  |

# 06. 군집 분석의 종류

군집 분석은 크게 두 가지로 나눌 수 있다.

```markdown
계층적 군집 분석
비계층적 군집 분석
```

| 구분         | 핵심                       |
| ---------- | ------------------------ |
| 계층적 군집 분석  | 군집 간 계층 구조를 만드는 방식       |
| 비계층적 군집 분석 | 미리 군집 수를 정하고 데이터를 나누는 방식 |

시험에서는 특히 **계층적 군집 분석과 K-means 군집 분석**의 차이가 중요하다.

---

# 07. 계층적 군집 분석

## 계층적 군집 분석의 개념

**계층적 군집 분석(Hierarchical Clustering)**은 객체들을 단계적으로 묶거나 나누면서 계층 구조를 만드는 방법이다.

분석 결과는 보통 **덴드로그램(Dendrogram)**이라는 나무 모양 그래프로 표현된다.

```markdown
계층적 군집 분석 = 군집 간 계층 구조를 단계적으로 형성하는 군집 분석 방법
```

예를 들어 처음에는 각 고객이 각각 하나의 군집이라고 생각한다.
그다음 가장 비슷한 고객끼리 묶고, 다시 비슷한 군집끼리 묶으면서 점점 큰 군집을 만든다.

---

## 계층적 군집 분석의 방식

계층적 군집 분석에는 두 가지 방식이 있다.

```markdown
병합적 방법
분할적 방법
```

| 방식     | 설명                            |
| ------ | ----------------------------- |
| 병합적 방법 | 작은 군집에서 시작해 점점 큰 군집으로 병합      |
| 분할적 방법 | 전체를 하나의 군집으로 보고 점점 작은 군집으로 분할 |

---

## 1) 병합적 방법

**병합적 방법(Agglomerative Method)**은 각 객체를 하나의 군집으로 시작한 뒤, 가까운 군집끼리 차례대로 합쳐가는 방식이다.

```markdown
병합적 방법 = 작은 군집에서 시작해 큰 군집으로 합쳐가는 방식
```

흐름은 다음과 같다.

```markdown
각 객체가 하나의 군집
→ 가장 가까운 군집끼리 병합
→ 다시 가까운 군집끼리 병합
→ 하나의 군집이 될 때까지 반복
```

계층적 군집 분석에서 가장 많이 언급되는 방식이다.

---

## 2) 분할적 방법

**분할적 방법(Divisive Method)**은 전체 데이터를 하나의 군집으로 보고, 이를 점점 작은 군집으로 나누는 방식이다.

```markdown
분할적 방법 = 큰 군집에서 시작해 작은 군집으로 나누는 방식
```

흐름은 다음과 같다.

```markdown
전체 데이터가 하나의 군집
→ 서로 다른 특성의 군집으로 분할
→ 다시 하위 군집으로 분할
→ 적절한 수준까지 반복
```

---

## 덴드로그램

**덴드로그램(Dendrogram)**은 계층적 군집 분석 결과를 나무 구조로 표현한 그래프다.

덴드로그램을 보면 어떤 객체나 군집이 어느 단계에서 묶였는지 확인할 수 있다.

```markdown
덴드로그램 = 계층적 군집 분석 결과를 나타내는 나무 모양 그래프
```

| 특징         | 설명                        |
| ---------- | ------------------------- |
| 계층 구조 표현   | 군집이 병합되거나 분할되는 과정 표시      |
| 군집 수 결정 가능 | 특정 높이에서 자르면 군집 수를 정할 수 있음 |
| 시각적 해석 가능  | 객체 간 유사성 구조를 직관적으로 확인     |

시험에서는 이렇게 기억하면 된다.

```markdown
계층적 군집 분석은 덴드로그램으로 결과를 표현한다.
```

# 08. 계층적 군집의 연결 방법

계층적 군집 분석에서는 군집과 군집 사이의 거리를 어떻게 정의할지 정해야 한다.

대표적인 연결 방법은 다음과 같다.

```markdown
최단연결법
최장연결법
평균연결법
중심연결법
Ward 연결법
```

---

## 1) 최단연결법

**최단연결법(Single Linkage)**은 두 군집에 속한 객체들 중 가장 가까운 두 객체 사이의 거리를 군집 간 거리로 보는 방법이다.

```markdown
최단연결법 = 군집 간 가장 가까운 객체 사이의 거리 사용
```

| 특징        | 설명                        |
| --------- | ------------------------- |
| 가까운 객체 기준 | 두 군집에서 가장 가까운 점끼리 비교      |
| 사슬 현상 가능  | 길게 연결되는 형태가 나타날 수 있음      |
| 이상값 영향 가능 | 일부 가까운 점 때문에 군집이 연결될 수 있음 |

---

## 2) 최장연결법

**최장연결법(Complete Linkage)**은 두 군집에 속한 객체들 중 가장 먼 두 객체 사이의 거리를 군집 간 거리로 보는 방법이다.

```markdown
최장연결법 = 군집 간 가장 먼 객체 사이의 거리 사용
```

| 특징        | 설명                     |
| --------- | ---------------------- |
| 먼 객체 기준   | 두 군집에서 가장 먼 점끼리 비교     |
| 조밀한 군집 형성 | 군집 내부 응집도가 높아지는 경향     |
| 보수적 병합    | 너무 멀리 떨어진 군집은 잘 묶이지 않음 |

---

## 3) 평균연결법

**평균연결법(Average Linkage)**은 두 군집에 속한 모든 객체 쌍의 거리 평균을 군집 간 거리로 보는 방법이다.

```markdown
평균연결법 = 군집 간 모든 객체 거리의 평균 사용
```

| 특징     | 설명                   |
| ------ | -------------------- |
| 평균 기준  | 전체 객체 간 거리 평균 사용     |
| 균형적 방법 | 최단·최장연결법의 중간적 성격     |
| 안정적    | 일부 극단값의 영향이 상대적으로 적음 |

---

## 4) 중심연결법

**중심연결법(Centroid Linkage)**은 각 군집의 중심점 사이의 거리를 군집 간 거리로 보는 방법이다.

```markdown
중심연결법 = 군집 중심점 사이의 거리 사용
```

| 특징       | 설명                |
| -------- | ----------------- |
| 중심 기준    | 군집의 평균 위치를 비교     |
| 계산 직관적   | 군집 대표점 간 거리 사용    |
| 중심 이동 가능 | 군집이 합쳐질 때 중심점이 변함 |

---

## 5) Ward 연결법

**Ward 연결법(Ward Method)**은 군집 내 분산의 증가량이 가장 작아지는 방향으로 군집을 병합하는 방법이다.

즉, 군집을 합쳤을 때 군집 내부의 응집성이 최대한 유지되도록 한다.

```markdown
Ward 연결법 = 군집 내 분산 증가가 최소가 되도록 병합하는 방법
```

| 특징       | 설명                     |
| -------- | ---------------------- |
| 분산 기준    | 군집 내 제곱합 증가 최소화        |
| 응집도 높음   | 내부적으로 비슷한 군집 형성        |
| 실무 활용 많음 | 비교적 균형 잡힌 군집을 만드는 데 유용 |

---

## 연결 방법 정리

| 연결 방법    | 기준             |
| -------- | -------------- |
| 최단연결법    | 가장 가까운 객체 간 거리 |
| 최장연결법    | 가장 먼 객체 간 거리   |
| 평균연결법    | 모든 객체 간 거리의 평균 |
| 중심연결법    | 군집 중심점 간 거리    |
| Ward 연결법 | 군집 내 분산 증가 최소화 |

암기 방식은 다음과 같다.

```markdown
최단 = 가장 가까운 거리
최장 = 가장 먼 거리
평균 = 거리 평균
중심 = 중심점 거리
Ward = 분산 증가 최소
```

# 09. 비계층적 군집 분석

## 비계층적 군집 분석의 개념

**비계층적 군집 분석**은 미리 군집 수를 정한 뒤, 데이터를 해당 개수의 군집으로 나누는 방법이다.

대표적인 방법은 **K-means 군집 분석**이다.

```markdown
비계층적 군집 분석 = 미리 군집 수를 정하고 데이터를 나누는 군집 분석 방법
```

계층적 군집 분석은 군집이 만들어지는 과정을 계층 구조로 보여준다.
반면 비계층적 군집 분석은 주어진 군집 수에 맞게 데이터를 빠르게 나누는 데 초점이 있다.

---

## 비계층적 군집 분석의 특징

| 특징          | 설명                      |
| ----------- | ----------------------- |
| 군집 수 사전 지정  | 분석자가 K값을 미리 정해야 함       |
| 대용량 데이터에 적합 | 계층적 방법보다 계산이 빠른 편       |
| 반복적 재배치     | 중심점을 기준으로 데이터를 반복적으로 할당 |
| 초기값 영향      | 초기 중심점에 따라 결과가 달라질 수 있음 |

시험에서는 이렇게 이해하면 된다.

```markdown
비계층적 군집 분석은 군집 수를 미리 정해야 하며, 대표적으로 K-means가 있다.
```

---

# 10. K-means 군집 분석

## K-means의 개념

**K-means 군집 분석**은 데이터를 K개의 군집으로 나누는 대표적인 비계층적 군집 분석 방법이다.

여기서 K는 군집의 개수를 의미한다.

```markdown
K-means = 데이터를 K개의 군집으로 나누는 비계층적 군집 분석 방법
```

예를 들어 K를 3으로 정하면 데이터는 3개의 군집으로 나뉜다.

```markdown
K = 3 → 군집 3개 생성
```

K-means는 각 군집의 중심점과 데이터 간 거리를 계산하여, 데이터가 가장 가까운 중심점의 군집에 속하도록 반복적으로 조정한다.

---

## K-means 수행 절차

K-means는 일반적으로 다음 순서로 진행된다.

```markdown
군집 수 K 결정
→ 초기 중심점 선택
→ 각 데이터를 가장 가까운 중심점에 할당
→ 군집별 중심점 재계산
→ 군집 할당이 더 이상 변하지 않을 때까지 반복
```

| 단계           | 설명                          |
| ------------ | --------------------------- |
| 1. K 결정      | 나눌 군집 수를 미리 정한다             |
| 2. 초기 중심점 선택 | K개의 중심점을 임의로 선택한다           |
| 3. 데이터 할당    | 각 데이터를 가장 가까운 중심점의 군집에 배정한다 |
| 4. 중심점 갱신    | 각 군집의 평균 위치로 중심점을 다시 계산한다   |
| 5. 반복        | 군집 변화가 거의 없을 때까지 반복한다       |

시험에서는 순서를 이렇게 외우면 된다.

```markdown
K 결정 → 초기 중심 선택 → 가까운 군집에 할당 → 중심 재계산 → 반복
```

---

## K-means의 장점

| 장점     | 설명                  |
| ------ | ------------------- |
| 이해가 쉬움 | 중심점과 거리 기반이라 직관적    |
| 계산이 빠름 | 대용량 데이터에도 비교적 적용 가능 |
| 구현이 간단 | 알고리즘 구조가 단순         |
| 해석이 쉬움 | 군집 중심을 통해 특징 파악 가능  |

---

## K-means의 단점

| 단점           | 설명                         |
| ------------ | -------------------------- |
| K값을 미리 정해야 함 | 적절한 군집 수 선택이 필요            |
| 초기 중심점 영향    | 초기값에 따라 결과가 달라질 수 있음       |
| 이상값에 민감      | 극단값이 중심점에 영향을 줄 수 있음       |
| 구형 군집에 적합    | 복잡한 모양의 군집에는 부적합할 수 있음     |
| 변수 스케일 영향    | 변수 단위가 다르면 거리 계산이 왜곡될 수 있음 |

특히 변수 스케일은 시험에서도 중요하다.

예를 들어 `나이`는 20~70 정도이고, `연소득`은 수천만 원 단위라면, 거리 계산에서 연소득이 훨씬 큰 영향을 미친다.
그래서 군집 분석 전에는 표준화가 필요한 경우가 많다.

```markdown
K-means는 거리 기반 방법이므로 변수 스케일에 민감하고, 필요하면 표준화를 수행해야 한다.
```

---

# 11. 적절한 군집 수 결정

K-means에서는 K값을 미리 정해야 한다.

하지만 처음부터 적절한 K값을 알기 어렵기 때문에 여러 방법을 사용해 군집 수를 판단한다.

대표적인 방법은 다음과 같다.

```markdown
엘보우 방법
실루엣 계수
```

---

## 1) 엘보우 방법

**엘보우 방법(Elbow Method)**은 군집 수 K를 늘려가면서 군집 내 제곱합이 얼마나 줄어드는지 확인하는 방법이다.

K가 증가하면 군집이 많아지므로 군집 내 거리는 줄어든다.
하지만 어느 순간부터 감소 폭이 작아진다.

이때 그래프가 팔꿈치처럼 꺾이는 지점을 적절한 K로 본다.

```markdown
엘보우 방법 = 군집 내 제곱합 감소 폭이 급격히 완만해지는 지점을 K로 선택하는 방법
```

시험에서는 계산보다 “팔꿈치처럼 꺾이는 지점”을 기억하면 된다.

---

## 2) 실루엣 계수

**실루엣 계수(Silhouette Coefficient)**는 군집이 얼마나 잘 나뉘었는지를 평가하는 지표다.

같은 군집 내 데이터는 가까워야 하고, 다른 군집과는 멀어야 좋은 군집이다.

```markdown
실루엣 계수 = 군집 내 응집도와 군집 간 분리도를 함께 평가하는 지표
```

| 평가 관점 | 의미                     |
| ----- | ---------------------- |
| 응집도   | 같은 군집 안의 데이터가 얼마나 가까운가 |
| 분리도   | 다른 군집과 얼마나 잘 떨어져 있는가   |

---

# 12. 군집 분석 결과 해석

군집 분석은 군집을 만드는 것에서 끝나지 않는다.
각 군집이 어떤 특성을 가지는지 해석해야 한다.

예를 들어 고객 군집 분석 결과가 3개 군집으로 나왔다고 하자.

| 군집   | 특징                 | 해석       |
| ---- | ------------------ | -------- |
| 군집 1 | 구매 금액 높음, 방문 빈도 높음 | VIP 고객   |
| 군집 2 | 방문 빈도 높음, 구매 금액 낮음 | 관심 고객    |
| 군집 3 | 최근 방문 없음, 구매 감소    | 이탈 위험 고객 |

이처럼 군집마다 특징을 파악하고 의미 있는 이름을 붙이는 것이 중요하다.

```markdown
군집 분석 결과는 각 군집의 특성을 비교하여 비즈니스적으로 해석해야 한다.
```

```markdown
군집 분석은 정답 없이 데이터 구조를 찾을 수 있지만,
군집 수, 변수 선택, 거리 측도, 결과 해석에 따라 결과가 달라질 수 있다.
```

# 15. R에서 군집 분석 관련 함수

ADsP 수준에서는 함수 이름과 역할 정도만 기억하면 충분하다.

| 함수         | 설명               |
| ---------- | ---------------- |
| `dist()`   | 객체 간 거리 행렬 계산    |
| `hclust()` | 계층적 군집 분석 수행     |
| `plot()`   | 덴드로그램 시각화        |
| `cutree()` | 덴드로그램을 잘라 군집 생성  |
| `kmeans()` | K-means 군집 분석 수행 |
| `scale()`  | 데이터 표준화          |

---

## 계층적 군집 분석 예시

```r
# 거리 행렬 계산
d <- dist(data)

# 계층적 군집 분석
hc <- hclust(d)

# 덴드로그램 출력
plot(hc)

# 3개 군집으로 자르기
cluster <- cutree(hc, k = 3)
```

---

## K-means 군집 분석 예시

```r
# 데이터 표준화
data_scaled <- scale(data)

# K-means 수행
km <- kmeans(data_scaled, centers = 3)

# 군집 결과 확인
km$cluster
```

시험에서는 이렇게 기억하면 된다.

```markdown
hclust()는 계층적 군집 분석,
kmeans()는 K-means 군집 분석,
scale()은 표준화에 사용한다.
```

# 시험 직전 암기 문장

```markdown
군집 분석은 정답 라벨이 없는 상태에서 데이터 간 유사성이나 거리를 기준으로
비슷한 데이터끼리 그룹화하는 비지도 학습 기법이다.

분류 분석은 정답 라벨이 있는 지도 학습이고,
군집 분석은 정답 라벨 없이 데이터의 유사성을 기준으로 그룹을 찾는 비지도 학습이다.

군집 분석은 고객 세분화, 시장 세분화, 이상값 탐지,
문서 군집화, 마케팅 타겟팅 등에 활용된다.

군집 분석에서는 객체 간 거리가 가까울수록 유사하다고 판단한다.

유클리드 거리는 두 점 사이의 직선거리이고,
맨해튼 거리는 각 변수 차이의 절댓값을 모두 더한 거리이다.

민코프스키 거리는 유클리드 거리와 맨해튼 거리를 일반화한 거리이며,
마할라노비스 거리는 변수 간 상관관계를 고려한 거리이다.

군집 분석은 크게 계층적 군집 분석과 비계층적 군집 분석으로 구분된다.

계층적 군집 분석은 군집 간 계층 구조를 형성하는 방법이며,
분석 결과를 덴드로그램이라는 나무 구조 그래프로 표현한다.

병합적 방법은 각 객체를 하나의 군집으로 시작하여 가까운 군집끼리 차례대로 합치는 방법이고,
분할적 방법은 전체 데이터를 하나의 군집으로 보고 점점 작은 군집으로 나누는 방법이다.

최단연결법은 군집 간 가장 가까운 객체 사이의 거리를 사용하고,
최장연결법은 군집 간 가장 먼 객체 사이의 거리를 사용한다.

평균연결법은 모든 객체 간 거리의 평균을 사용하고,
중심연결법은 군집 중심점 간 거리를 사용한다.

Ward 연결법은 군집 내 분산 증가가 최소가 되도록 군집을 병합하는 방법이다.

비계층적 군집 분석은 미리 군집 수를 정한 뒤 데이터를 나누는 방법이며,
대표적인 방법으로 K-means 군집 분석이 있다.

K-means 군집 분석은 데이터를 K개의 군집으로 나누는 방법이다.

K-means는 군집 수 K를 정하고, 초기 중심점을 선택한 뒤,
각 데이터를 가장 가까운 중심점에 할당하고,
군집별 중심점을 다시 계산하는 과정을 반복한다.

K-means는 이해하기 쉽고 계산이 빠르지만,
K값을 미리 정해야 하며 초기 중심점, 이상값, 변수 스케일에 민감하다.

군집 분석 결과는 단순히 군집을 나누는 것에서 끝나는 것이 아니라,
각 군집의 특성을 비교하여 비즈니스적으로 의미 있게 해석해야 한다.
```
