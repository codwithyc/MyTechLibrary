## 033. 기본 네트워크 정보 및 연결 설정

### 1. 네트워크 및 공유 센터

네트워크 연결 상태를 확인하고 설정을 변경하는 창입니다.

- 실행 방법 : [제어판] → [네트워크 및 공유 센터], 또는 [설정] → [네트워크 및 인터넷] → [네트워크 및 공유 센터]

| 항목 | 기능 |
| --- | --- |
| 활성 네트워크 보기 | 현재 연결된 네트워크의 종류(개인/공용)와 연결 상태를 표시합니다. |
| 새 연결 또는 네트워크 설정 | 인터넷 연결, VPN, 다이얼업 연결 등을 새로 만듭니다. |
| 문제 해결 | 네트워크 문제를 자동으로 진단하고 해결합니다. |
| 어댑터 설정 변경 | 네트워크 어댑터(이더넷, Wi-Fi)의 사용/사용 안 함, 속성을 설정합니다. |
| 고급 공유 설정 변경 | 네트워크 검색, 파일 및 프린터 공유, 암호 보호 공유를 설정합니다. |

### 2. TCP/IP 속성 설정

[어댑터 설정 변경] → 어댑터 바로 가기 메뉴 → [속성] → **[인터넷 프로토콜 버전 4(TCP/IPv4)]** → [속성]

| 항목 | 설명 |
| --- | --- |
| **IP 주소** | 네트워크에서 컴퓨터를 구분하는 고유한 주소입니다. |
| **서브넷 마스크** | IP 주소에서 **네트워크 주소와 호스트 주소를 구분**하는 값입니다. |
| **기본 게이트웨이** | 다른 네트워크로 나가는 **출입구 역할**을 하는 장치의 주소입니다. |
| **DNS 서버 주소** | 도메인 이름을 IP 주소로 변환해 주는 서버의 주소입니다. |

- **자동으로 IP 주소 받기** 를 선택하면 **DHCP 서버**로부터 IP 주소를 자동으로 할당받습니다.

#### 왜 서브넷 마스크가 필요할까?

IP 주소만 보아서는 **어디까지가 네트워크를 나타내고, 어디부터가 개별 컴퓨터인지** 알 수 없습니다.

서브넷 마스크는 이 경계를 알려 주는 값입니다.

예를 들어 IP가 `192.168.0.10`, 서브넷 마스크가 `255.255.255.0`이라면

- 네트워크 주소 : `192.168.0`
- 호스트 주소 : `10`

이 구분을 통해 컴퓨터는 **상대가 같은 네트워크에 있는지, 밖으로 나가야 하는지**를 판단합니다.

#### 왜 기본 게이트웨이가 필요할까?

같은 네트워크 안의 컴퓨터끼리는 직접 통신할 수 있습니다.

하지만 다른 네트워크(예: 인터넷)에 있는 컴퓨터와 통신하려면 **밖으로 나가는 통로**가 필요합니다.

기본 게이트웨이는 **"우리 네트워크 밖으로 나갈 때 거쳐야 하는 문"** 이며,  
일반 가정에서는 보통 공유기(라우터)가 그 역할을 합니다.

#### 왜 DNS 서버가 필요할까?

컴퓨터는 숫자로 된 IP 주소로만 통신할 수 있습니다.  
하지만 사람이 `142.250.x.x` 같은 숫자를 외우기는 어렵습니다.

DNS는 `www.google.com` 같은 **이름을 IP 주소로 바꿔 주는 전화번호부** 역할을 합니다.

DNS 서버 설정이 잘못되면, 인터넷은 연결되어 있어도  
**주소를 입력했을 때 사이트를 찾지 못하는 현상**이 발생합니다.

### 3. DHCP

**DHCP(Dynamic Host Configuration Protocol)** 는  
네트워크에 연결된 컴퓨터에 **IP 주소를 자동으로 할당**하는 프로토콜입니다.

| 구분 | 특징 |
| --- | --- |
| 고정 IP | 사용자가 직접 입력하며, 항상 같은 주소를 사용합니다. 서버에 주로 사용합니다. |
| 유동 IP(DHCP) | 접속할 때마다 자동으로 주소를 할당받습니다. 관리가 편리합니다. |

#### 왜 DHCP를 사용할까?

기기가 많아질수록 IP 주소를 사람이 일일이 지정하기는 어렵습니다.  
실수로 **같은 주소를 두 기기에 지정하면 충돌**이 발생합니다.

DHCP는 서버가 사용 가능한 주소를 관리하면서 자동으로 나눠 주므로,  
**중복 없이, 설정 없이** 네트워크를 사용할 수 있습니다.

### 4. 고급 공유 설정

| 항목 | 설명 |
| --- | --- |
| 네트워크 검색 | 이 컴퓨터가 다른 컴퓨터를 찾고, 다른 컴퓨터에게도 보이도록 합니다. |
| 파일 및 프린터 공유 | 공유한 파일과 프린터에 다른 사용자가 접근할 수 있게 합니다. |
| 공용 폴더 공유 | 공용 폴더에 대한 네트워크 접근을 허용합니다. |
| 암호 보호 공유 | 이 컴퓨터에 계정과 암호가 있는 사용자만 공유 자원에 접근할 수 있게 합니다. |

### 5. 네트워크 상태 확인 명령어

| 명령어 | 기능 |
| --- | --- |
| `ipconfig` | IP 주소, 서브넷 마스크, 기본 게이트웨이를 확인합니다. |
| `ipconfig /all` | MAC 주소, DNS 서버 등 상세 정보를 확인합니다. |
| `ipconfig /release` | 할당받은 IP 주소를 반납합니다. |
| `ipconfig /renew` | IP 주소를 새로 할당받습니다. |
| `ping 주소` | 상대 컴퓨터와의 연결 상태를 확인합니다. |
| `tracert 주소` | 목적지까지의 경로를 추적합니다. |
| `nslookup 도메인` | 도메인의 IP 주소를 조회합니다. |

---

### 한 줄 정리

TCP/IP 설정의 핵심은 **IP 주소(신원), 서브넷 마스크(네트워크 구분), 기본 게이트웨이(외부 출구), DNS(이름 → IP 변환)** 네 가지이며,  
**DHCP를 사용하면 IP 주소를 자동으로 할당**받습니다.
