## 052. PC 응급처치

### 1. 부팅이 되지 않을 때

| 증상 | 원인 및 조치 |
| --- | --- |
| 전원이 전혀 들어오지 않음 | 전원 케이블, 멀티탭, 파워 서플라이 스위치를 확인합니다. |
| 팬은 돌지만 화면이 나오지 않음 | 모니터 케이블 연결, **RAM과 그래픽 카드의 장착 상태**를 확인합니다. |
| 경고음(비프음)이 울림 | 메인보드 설명서에서 비프음 코드를 확인합니다. (주로 **RAM 또는 그래픽 카드** 문제) |
| "운영체제를 찾을 수 없음" | CMOS의 **부팅 순서**와 하드디스크 연결 상태를 확인합니다. |
| Windows 로고에서 멈춤 | **안전 모드**로 부팅하여 최근 설치한 드라이버·프로그램을 제거합니다. |
| 최근 변경 후 문제 발생 | **시스템 복원**으로 이전 복원 지점으로 되돌립니다. |

#### 왜 RAM 문제부터 확인할까?

RAM은 **CPU 다음으로 부팅에 필수적인 부품**입니다.  
RAM을 읽을 수 없으면 운영체제는커녕 POST 과정도 진행되지 않습니다.

또한 RAM은 **접점이 산화되거나 살짝 헐거워지는 일이 자주** 발생합니다.

그래서 화면이 나오지 않는 문제의 상당수는  
**RAM을 뽑았다가 접점을 닦고 다시 꽂는 것만으로 해결**됩니다.

---

### 2. 시스템 속도가 느려졌을 때

| 원인 | 조치 |
| --- | --- |
| 시작 프로그램 과다 | [설정] → [앱] → [시작 프로그램] 또는 작업 관리자에서 정리합니다. |
| 디스크 공간 부족 | **디스크 정리**를 실행합니다. |
| 파일 단편화 | **드라이브 조각 모음**을 실행합니다. (SSD는 제외) |
| 메모리 부족 | 불필요한 프로그램 종료, 가상 메모리 조정, **RAM 추가** |
| 바이러스 감염 | 백신으로 전체 검사 후 치료합니다. |
| 발열로 인한 성능 저하 | 팬과 방열판의 먼지를 제거합니다. |

#### 왜 발열이 성능을 떨어뜨릴까?

CPU는 온도가 지나치게 올라가면 손상될 수 있습니다.

이를 막기 위해 CPU는 스스로 **동작 속도를 낮춰 발열을 줄이는 기능(스로틀링)** 을 가지고 있습니다.

따라서 먼지가 쌓여 냉각이 제대로 되지 않으면,  
**부품이 고장 나지 않았는데도 성능이 계속 떨어지는 현상**이 나타납니다.

---

### 3. 프로그램이 응답하지 않을 때

1. **`Ctrl` + `Shift` + `Esc`** 로 작업 관리자를 실행합니다.
2. [프로세스] 탭에서 해당 프로그램을 선택하고 **[작업 끝내기]** 를 클릭합니다.
3. 화면 전체가 멈춘 경우 `Ctrl` + `Alt` + `Delete` → [작업 관리자]로 진입합니다.
4. 그래도 반응이 없으면 전원 단추를 길게 눌러 강제 종료합니다. (**최후의 수단**)

> 강제 종료는 저장하지 않은 데이터가 사라지고 파일이 손상될 수 있으므로, 다른 방법을 먼저 시도해야 합니다.

---

### 4. 저장 장치 관련 문제

| 증상 | 조치 |
| --- | --- |
| 파일이 열리지 않음 | **드라이브 오류 검사(`chkdsk`)** 를 실행합니다. |
| 디스크 인식 불가 | 케이블 연결, CMOS에서의 인식 여부, 다른 포트 연결을 확인합니다. |
| 갑자기 용량이 줄어듦 | 디스크 정리, 휴지통 비우기, 이전 Windows 설치 파일 제거를 수행합니다. |
| 이상한 소리(딸깍거림) | **물리적 손상 신호**이므로 즉시 **중요 데이터를 백업**하고 교체를 준비합니다. |
| USB 인식 불가 | 다른 포트에 연결, 드라이버 재설치, 다른 컴퓨터에서 확인합니다. |

#### 왜 하드디스크에서 소리가 나면 바로 백업해야 할까?

딸깍거리는 소리는 대개 **헤드가 정상 위치를 찾지 못하고 반복 이동하는 현상**입니다.

이는 물리적 손상이 진행 중이라는 신호이며,  
**시간이 지날수록 복구 가능성이 급격히 낮아집니다.**

이 상태에서는 검사나 복구를 시도하기보다  
**가장 먼저 데이터를 다른 곳으로 옮기는 것**이 우선입니다.

### 5. 네트워크 연결 문제

**확인 순서 (가까운 곳 → 먼 곳)**

1. 랜 케이블 / Wi-Fi 연결 상태 확인
2. `ipconfig` 로 IP 주소 정상 할당 여부 확인
3. `ping 게이트웨이주소` 로 공유기까지 연결 확인
4. `ping 8.8.8.8` 로 외부 인터넷 연결 확인
5. `ping www.google.com` 이 실패하면 **DNS 문제**
6. 공유기·모뎀 재시작, 네트워크 문제 해결사 실행

#### 왜 이 순서로 확인할까?

문제가 어디에서 발생했는지 모르는 상태에서 아무 곳이나 손대면 원인을 찾기 어렵습니다.

**내 컴퓨터 → 공유기 → 인터넷 → 이름 해석** 순으로 하나씩 확인하면,  
**어느 단계까지는 정상인지**가 드러나므로 문제 지점을 정확히 좁힐 수 있습니다.

---

### 6. 바이러스 감염이 의심될 때

- 네트워크 연결을 **먼저 차단**합니다. (다른 시스템으로의 전파 방지)
- 백신 프로그램을 **최신 버전으로 업데이트**한 후 **전체 검사**를 실행합니다.
- 치료가 되지 않으면 **안전 모드**로 부팅한 뒤 다시 검사합니다.
- 중요한 데이터를 백업한 후, 필요하면 **운영체제를 다시 설치**합니다.
- 감염 원인이 된 파일이나 프로그램은 삭제하고, 관련 계정의 **암호를 변경**합니다.

#### 왜 네트워크부터 끊을까?

많은 악성 코드는 **네트워크를 통해 다른 기기로 퍼지거나, 외부로 정보를 전송**합니다.

연결을 유지한 채 치료를 시도하면

- 다른 기기까지 감염되고
- 그동안 정보가 계속 유출될 수 있습니다.

따라서 **확산과 유출을 먼저 차단한 뒤 치료**하는 것이 올바른 순서입니다.

---

### 한 줄 정리

응급처치의 기본은 **연결 → 전원 → 부품 → 소프트웨어 순으로 원인을 좁혀 가는 것**이며,  
화면이 안 나오면 **RAM·그래픽 카드 접점**, 부팅이 안 되면 **안전 모드·시스템 복원**,  
디스크에서 이상한 소리가 나면 **무엇보다 먼저 백업**해야 합니다.
