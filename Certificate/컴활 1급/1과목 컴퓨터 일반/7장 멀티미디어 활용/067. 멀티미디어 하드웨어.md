## 067. 멀티미디어 하드웨어

### 1. 사운드 카드

컴퓨터에서 **소리를 입력받고 출력하는 장치**입니다.

| 기능 | 설명 |
| --- | --- |
| 아날로그 → 디지털 변환(ADC) | 마이크로 들어온 소리를 컴퓨터가 처리할 수 있는 디지털 데이터로 변환합니다. |
| 디지털 → 아날로그 변환(DAC) | 디지털 데이터를 스피커로 들을 수 있는 아날로그 신호로 변환합니다. |
| 샘플링 | 아날로그 소리를 일정 간격으로 측정하여 디지털로 바꿉니다. |

**사운드 카드 관련 용어**

| 용어 | 설명 |
| --- | --- |
| **샘플링(Sampling)** | 아날로그 소리를 **일정 시간 간격으로 측정**하여 디지털로 바꾸는 과정입니다. |
| **샘플링률(Sampling Rate)** | 1초 동안 샘플링하는 횟수로, 단위는 **Hz**입니다. **높을수록 원음에 가깝습니다.** |
| **샘플링 비트 수** | 각 샘플을 몇 비트로 표현할지 나타냅니다. **클수록 정밀합니다.** (8bit, 16bit, 24bit) |

#### 왜 샘플링이 필요할까?

소리는 원래 **끊김 없이 이어지는 연속적인 파형(아날로그)** 입니다.

그런데 컴퓨터는 **0과 1이라는 끊어진 값(디지털)** 만 다룰 수 있습니다.

그래서 연속된 파형을 일정 간격으로 **잘라서 높이를 숫자로 기록**하는데,  
이것이 샘플링입니다.

#### 왜 샘플링률이 높을수록 원음에 가까울까?

측정 간격이 넓으면 그 사이의 변화를 놓치게 됩니다.

- 간격이 넓음 → 계단처럼 뚝뚝 끊긴 근사값 → 원음과 차이가 큼
- 간격이 좁음 → 원래 파형에 가까운 곡선 → 원음에 가까움

다만 샘플링률을 높이면 **저장할 데이터 양도 함께 늘어납니다.**

그래서 음악 CD는 사람이 들을 수 있는 범위를 고려하여  
**44.1kHz / 16bit** 를 표준으로 사용합니다.

### 2. 비디오 카드(그래픽 카드)

컴퓨터의 처리 결과를 **모니터에 표시할 신호로 변환**하는 장치입니다.

| 용어 | 설명 |
| --- | --- |
| **GPU** | 그래픽 연산을 전담하는 프로세서입니다. |
| **비디오 메모리(VRAM)** | 화면에 표시할 데이터를 저장하는 메모리로, **용량이 클수록 높은 해상도와 색상을 표현**할 수 있습니다. |
| 출력 단자 | HDMI, DisplayPort, DVI, D-SUB 등 |

#### 왜 그래픽 처리를 별도의 장치가 담당할까?

화면을 그리는 작업은 **같은 종류의 계산을 아주 많이 반복**하는 특성이 있습니다.  
예를 들어 화소 200만 개의 색을 각각 계산해야 합니다.

CPU는 복잡한 계산을 **순서대로 잘 처리**하도록 설계되어 있습니다.  
반면 GPU는 단순한 계산을 **수천 개씩 동시에 처리**하도록 설계되었습니다.

즉, 두 장치는 성능의 우열이 아니라 **잘하는 일의 종류가 다릅니다.**

이 특성 덕분에 GPU는 최근 **인공지능 학습**에도 널리 사용됩니다.

### 3. CD-ROM 드라이브 / 광 저장 장치

| 장치 | 용량 | 특징 |
| --- | --- | --- |
| CD | 약 650~700MB | 음악, 소프트웨어 배포에 사용 |
| DVD | 약 4.7GB(단면 단층) | 영화, 대용량 데이터 |
| Blu-ray | 약 25GB(단층) | 고화질 영상 |

- **배속** : 데이터 전송 속도를 나타내며, 값이 클수록 빠릅니다. (CD 1배속 = 150KB/s)

#### 왜 CD → DVD → Blu-ray로 용량이 커졌을까?

광 저장 장치는 디스크 표면에 **미세한 홈을 만들어** 데이터를 기록하고,  
**레이저를 쏘아 그 홈을 읽습니다.**

홈을 더 작게 만들면 같은 면적에 더 많은 데이터를 담을 수 있는데,  
홈이 작아질수록 **더 짧은 파장의 레이저**가 필요합니다.

- CD : 적외선 레이저 (780nm)
- DVD : 붉은색 레이저 (650nm)
- Blu-ray : **푸른색 레이저 (405nm)**

Blu-ray라는 이름 자체가 **푸른색 레이저를 사용한다는 뜻**입니다.

### 4. 그 밖의 멀티미디어 하드웨어

| 장치 | 설명 |
| --- | --- |
| **스캐너** | 그림이나 문서를 읽어 디지털 이미지로 변환합니다. 해상도 단위는 **DPI**. |
| **디지털 카메라 / 캠코더** | 영상을 디지털 데이터로 저장합니다. |
| **웹캠** | 실시간 영상을 입력받는 카메라입니다. |
| **마이크** | 소리를 입력받습니다. |
| **MIDI 장치** | 전자 악기와 컴퓨터를 연결하여 음악을 제작합니다. |
| **TV 수신 카드** | 컴퓨터에서 TV 방송을 시청할 수 있게 합니다. |
| **영상 압축 보드** | 영상 데이터를 압축·복원하는 전용 장치입니다. |
| **프로젝터** | 화면을 스크린에 확대 투사합니다. |

#### 왜 MIDI는 용량이 매우 작을까?

WAV나 MP3는 **소리 자체를 녹음한 데이터**입니다.

반면 MIDI는 소리를 저장하지 않고,  
**"어떤 악기로 어떤 음을 언제 얼마나 연주하라"는 연주 정보**만 저장합니다.

즉, 녹음이 아니라 **악보에 가깝습니다.**

그래서

- 용량이 매우 작고
- 음의 높이나 악기를 자유롭게 바꿀 수 있지만
- **사람의 목소리는 표현할 수 없습니다.**

---

### 한 줄 정리

사운드 카드는 **샘플링을 통해 아날로그 소리를 디지털로 변환**하며 **샘플링률(Hz)이 높을수록 원음에 가깝고**,  
비디오 카드의 **VRAM 용량이 클수록 높은 해상도와 색상**을 표현할 수 있으며,  
**MIDI는 소리가 아닌 연주 정보만 저장**하므로 용량이 매우 작습니다.
