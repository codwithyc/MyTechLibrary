## 020. 설정 창의 개인 설정

### 1. 개인 설정의 개요

[개인 설정]은 **바탕 화면, 색, 잠금 화면, 테마, 글꼴, 시작 메뉴, 작업 표시줄** 등  
화면의 겉모습을 사용자 취향에 맞게 바꾸는 범주입니다.

- 실행 방법 : [설정] → [개인 설정], 또는 **바탕 화면 바로 가기 메뉴 → [개인 설정]**

---

### 2. 배경

바탕 화면에 표시할 그림이나 색을 지정합니다.

| 항목 | 설명 |
| --- | --- |
| 사진 | 지정한 그림 파일 하나를 배경으로 사용합니다. |
| 단색 | 단일 색상을 배경으로 사용합니다. |
| 슬라이드 쇼 | 지정한 폴더의 사진들을 일정 시간마다 바꿔 가며 표시합니다. |

**맞춤 선택** : 채우기, 맞춤, 확대, 바둑판식 배열, 가운데, 스팬

#### 왜 "맞춤 선택"이 필요할까?

배경 그림의 크기와 모니터 해상도가 항상 같지는 않습니다.

- 그림이 화면보다 작으면 → 여백이 생기거나 늘려야 함
- 그림이 화면보다 크면 → 잘라내거나 줄여야 함

맞춤 선택은 **"비율을 지킬 것인가, 화면을 가득 채울 것인가"** 를 정하는 옵션입니다.

- **채우기** : 비율 유지 + 화면 가득 (일부 잘림)
- **맞춤** : 비율 유지 + 전체 표시 (여백 생김)
- **바둑판식 배열** : 작은 그림을 반복해서 배치

---

### 3. 색

| 항목 | 설명 |
| --- | --- |
| 색 선택 | 밝게 / 어둡게 / 사용자 지정 모드를 선택합니다. |
| 투명 효과 | 시작 메뉴, 작업 표시줄, 알림 센터에 투명 효과를 적용합니다. |
| 테마 컬러 | 시작 메뉴, 작업 표시줄, 제목 표시줄, 창 테두리에 적용할 강조 색을 지정합니다. |

---

### 4. 잠금 화면

| 항목 | 설명 |
| --- | --- |
| 배경 | Windows 추천 / 사진 / 슬라이드 쇼 중에서 선택합니다. |
| 세부 상태를 표시할 앱 선택 | 잠금 화면에 일정, 메일 등의 정보를 표시할 앱을 지정합니다. |
| 화면 시간 제한 설정 | 일정 시간 후 화면을 끄거나 절전 모드로 전환합니다. |
| 화면 보호기 설정 | 화면 보호기 종류, 대기 시간, **다시 시작할 때 로그온 화면 표시** 여부를 지정합니다. |

#### 왜 화면 보호기를 사용할까?

과거 CRT 모니터에서는 같은 화면을 오래 표시하면 **화면에 잔상이 남는 문제(번인)** 가 있었습니다.  
화면 보호기는 원래 이를 방지하기 위한 기능이었습니다.

지금은 화면 손상 문제가 거의 없어졌지만,

- 자리를 비운 사이 화면 내용을 가리고
- **암호를 입력해야 복귀할 수 있게 하여**

**보안 목적**으로 더 많이 사용됩니다.

---

### 5. 테마

배경, 색, 소리, 마우스 커서를 **하나의 묶음**으로 저장하고 적용하는 기능입니다.

- 저장한 테마는 다른 컴퓨터에 적용할 수 있도록 **파일로 내보낼 수 있습니다.**
- **바탕 화면 아이콘 설정** 에서 컴퓨터, 휴지통, 사용자 파일, 제어판, 네트워크 아이콘의 표시 여부를 지정합니다.

#### 왜 테마라는 개념이 필요할까?

배경·색·소리를 매번 따로 설정하면, 다른 컴퓨터에서 같은 환경을 만들기 어렵습니다.

테마는 이 설정들을 **한 덩어리로 묶어** 저장하므로,  
클릭 한 번으로 전체 화면 분위기를 바꾸거나 그대로 옮길 수 있습니다.

---

### 6. 글꼴

- 설치된 글꼴을 확인하고, 새 글꼴을 설치하거나 삭제합니다.
- 글꼴 파일의 확장자는 **`.TTF`(트루타입)**, **`.OTF`(오픈타입)**, **`.FON`** 등입니다.
- 글꼴 파일은 **`C:\Windows\Fonts`** 폴더에 저장됩니다.
- 글꼴 파일을 이 폴더로 드래그하거나, 파일 바로 가기 메뉴 → [설치]로 추가할 수 있습니다.

---

### 7. 시작 / 작업 표시줄

| 범주 | 주요 설정 |
| --- | --- |
| 시작 | 시작 화면에 더 많은 타일 표시, 앱 목록 표시, 최근에 추가된 앱 표시, 시작 메뉴에 표시할 폴더 선택 |
| 작업 표시줄 | 작업 표시줄 잠금, 자동 숨기기, 작은 단추 사용, 위치 지정, 단추 하나로 표시, 알림 영역 설정 |

---

### 한 줄 정리

[개인 설정]은 **배경·색·잠금 화면·테마·글꼴·시작 메뉴·작업 표시줄**의 겉모습을 바꾸는 범주이며,  
**바탕 화면 바로 가기 메뉴에서도 바로 접근**할 수 있고 글꼴은 `C:\Windows\Fonts` 폴더에서 관리됩니다.
