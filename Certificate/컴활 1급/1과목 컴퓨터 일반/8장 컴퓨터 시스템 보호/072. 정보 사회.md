## 072. 정보 사회

### 1. 정보 사회의 개념

정보 사회란 **정보가 물질이나 에너지보다 더 중요한 가치를 갖는 사회**를 말합니다.

- 정보의 생산·가공·유통·소비가 사회 활동의 중심이 됩니다.
- 농업 사회 → 산업 사회 → **정보 사회** 로 발전해 왔습니다.

---

### 2. 정보 사회의 특징

| 특징 | 설명 |
| --- | --- |
| **정보의 가치 증대** | 정보 그 자체가 중요한 자원이자 재화가 됩니다. |
| **시간과 공간의 제약 감소** | 언제 어디서나 정보에 접근하고 업무를 수행할 수 있습니다. |
| **다품종 소량 생산** | 개인의 다양한 요구에 맞춘 생산이 가능해집니다. |
| **개인의 참여 확대** | 누구나 정보를 생산하고 전파할 수 있습니다. |
| **탈대량화 · 분권화** | 획일적인 대량 생산에서 벗어나 개별화·분산화됩니다. |
| **네트워크화** | 사회 구성원과 조직이 네트워크로 연결됩니다. |

#### 왜 정보 사회에서는 "다품종 소량 생산"이 가능해졌을까?

산업 사회에서는 **같은 제품을 대량으로** 만들어야 비용을 낮출 수 있었습니다.  
생산 설비를 바꾸는 데 큰 비용이 들었기 때문입니다.

정보 기술이 발달하면서

- 설계를 **소프트웨어로 쉽게 변경**할 수 있고
- 고객의 요구를 **데이터로 정확히 파악**할 수 있게 되었습니다.

그 결과 **개인 맞춤형 제품을 소량으로도 경제적으로** 생산할 수 있게 되었습니다.

#### 왜 "개인의 참여"가 확대되었을까?

과거에는 정보를 전달하려면 **신문사나 방송국 같은 매체**가 필요했습니다.  
개인이 다수에게 정보를 전달할 방법이 사실상 없었습니다.

인터넷은 누구나 **정보의 생산자이자 유통자**가 될 수 있게 만들었습니다.

이것이 정보 사회의 가장 큰 변화이며,  
동시에 **잘못된 정보의 확산**이라는 문제의 원인이기도 합니다.

---

### 3. 정보 사회의 순기능

- 시간과 공간의 제약이 줄어 **업무 효율이 향상**됩니다.
- 원하는 정보를 **신속하고 정확하게** 얻을 수 있습니다.
- 재택근무, 원격 교육, 원격 진료 등 **새로운 생활 방식**이 가능해집니다.
- 정보 공유를 통해 **사회 전체의 지식 수준**이 높아집니다.
- 개인의 창의성과 다양성이 존중됩니다.

---

### 4. 정보 사회의 역기능

| 문제 | 설명 |
| --- | --- |
| **개인 정보 유출** | 개인의 신상 정보가 유출되어 악용될 수 있습니다. |
| **사생활 침해** | 감시와 추적이 쉬워져 프라이버시가 위협받습니다. |
| **컴퓨터 범죄** | 해킹, 바이러스 유포, 사이버 사기 등이 발생합니다. |
| **정보 격차(Digital Divide)** | 정보 접근 능력의 차이가 **경제적·사회적 격차**로 이어집니다. |
| **인간 소외 현상** | 대면 접촉이 줄어들어 인간관계가 단절됩니다. |
| **정보 과잉 / 무분별한 정보** | 정보가 지나치게 많아 판단이 어려워집니다. |
| **인터넷 중독** | 지나친 사용으로 일상생활에 지장을 줍니다. |
| **저작권 침해** | 디지털 자료의 무단 복제와 배포가 쉬워집니다. |
| **VDT 증후군** | 장시간 화면을 보아 생기는 눈·목·어깨의 건강 문제입니다. |
| **테크노스트레스** | 정보 기술에 적응하지 못해 겪는 스트레스입니다. |

#### 왜 정보 격차가 심각한 문제일까?

정보 사회에서는 **정보에 접근할 수 있는가**가 곧 기회의 차이가 됩니다.

- 온라인으로만 접수되는 서비스
- 인터넷으로만 제공되는 할인과 정보
- 디지털 능력을 요구하는 일자리

정보 접근이 어려운 사람은 이런 기회에서 **구조적으로 배제**됩니다.

그 결과 정보 격차는 단순한 불편이 아니라  
**경제적 격차와 사회적 배제로 이어지는 문제**가 됩니다.

#### 왜 디지털 자료는 저작권 침해가 쉬울까?

아날로그 복제는 복사할수록 **품질이 나빠집니다.** (복사한 사진, 녹음한 테이프)

반면 디지털 자료는

- **복사해도 품질이 전혀 떨어지지 않고**
- 복사 비용이 사실상 **0에 가까우며**
- 인터넷으로 **순식간에 전 세계에 퍼집니다.**

이 특성 때문에 디지털 시대에는 저작권 보호 기술(DRM, 워터마크)이 별도로 필요해졌습니다.

| 문제 | 대책 |
| --- | --- |
| 개인 정보 유출 | 암호 관리 강화, 개인 정보 보호법 시행, 최소 수집 원칙 |
| 컴퓨터 범죄 | 보안 시스템 구축, 관련 법률 정비, 처벌 강화 |
| 정보 격차 | 정보화 교육 확대, 취약 계층 지원, 공공 인프라 확충 |
| 저작권 침해 | 저작권 보호 기술 적용, 정당한 이용 문화 확산 |
| 인터넷 중독 | 사용 시간 관리, 상담 및 교육 프로그램 운영 |
| 건강 문제 | 올바른 자세, 정기적인 휴식, 작업 환경 개선 |

---

### 한 줄 정리

정보 사회는 **정보가 핵심 가치가 되는 사회**로 시간·공간의 제약을 줄이고 개인의 참여를 확대했지만,  
**개인 정보 유출, 사생활 침해, 컴퓨터 범죄, 정보 격차, 저작권 침해** 등의 역기능도 함께 가져왔습니다.
