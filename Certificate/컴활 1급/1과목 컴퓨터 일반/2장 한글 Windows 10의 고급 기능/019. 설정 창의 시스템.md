## 019. 설정 창의 시스템

### 1. 디스플레이

화면의 표시 방법을 설정합니다.

| 항목 | 설명 |
| --- | --- |
| 야간 모드 | 청색광을 줄여 눈의 피로를 낮춥니다. 시간대를 지정해 자동으로 켜지게 할 수 있습니다. |
| 배율 및 레이아웃 | 텍스트, 앱 등의 크기를 100%, 125%, 150% 등으로 확대/축소합니다. |
| 디스플레이 해상도 | 화면에 표시되는 픽셀 수를 지정합니다. (예: 1920 × 1080) |
| 디스플레이 방향 | 가로 / 세로 / 가로(대칭 이동) / 세로(대칭 이동) 중 선택합니다. |
| 여러 디스플레이 | 모니터를 두 대 이상 연결했을 때 표시 방식을 지정합니다. |

**여러 디스플레이 옵션**

- **디스플레이 복제** : 두 모니터에 같은 화면을 표시합니다.
- **디스플레이 확장** : 두 모니터를 하나의 넓은 화면처럼 사용합니다.
- **1(또는 2)에만 표시** : 지정한 모니터에만 화면을 표시합니다.

#### 왜 해상도를 바꾸면 글자 크기가 달라질까?

해상도는 **화면에 표시되는 점(픽셀)의 개수**입니다.

- 해상도를 높이면 → 같은 화면에 점이 더 많아짐 → 글자가 작아지고 더 많은 내용이 보임
- 해상도를 낮추면 → 점이 적어짐 → 글자가 커지고 보이는 내용은 줄어듦

글자만 크게 하고 싶다면 해상도를 낮추기보다 **배율(100% → 125%)** 을 조정하는 편이 화질 손상 없이 낫습니다.

### 2. 소리

| 항목 | 설명 |
| --- | --- |
| 출력 | 소리를 재생할 장치(스피커, 헤드폰)를 선택하고 볼륨을 조절합니다. |
| 입력 | 마이크 등 녹음 장치를 선택하고 입력 볼륨을 조절합니다. |
| 앱 볼륨 및 장치 기본 설정 | **앱별로 볼륨과 입출력 장치를 다르게 지정**합니다. |

---

### 3. 알림 및 작업

- 앱과 시스템이 보내는 알림의 표시 여부를 설정합니다.
- 알림 센터에 표시할 **빠른 실행 단추**를 추가하거나 제거합니다.
- **집중 지원(Focus Assist)** : 특정 시간이나 상황(게임 중, 프레젠테이션 중)에 알림을 차단합니다.

#### 왜 집중 지원 기능이 필요할까?

알림은 유용하지만, 발표나 작업 중에 뜨면 흐름을 끊고 화면에 노출되어 곤란한 상황도 생깁니다.

집중 지원은 **알림을 완전히 끄는 대신, 필요한 순간에만 잠시 미뤄 두는 기능**입니다.  
차단된 알림은 나중에 알림 센터에서 한꺼번에 확인할 수 있습니다.

### 4. 전원 및 절전

| 항목 | 설명 |
| --- | --- |
| 화면 | 지정한 시간 동안 사용하지 않으면 화면을 끕니다. |
| 절전 모드 | 지정한 시간 동안 사용하지 않으면 절전 모드로 전환합니다. |
| 추가 전원 설정 | 균형 조정 / 절전 / 고성능 등 전원 관리 옵션을 선택합니다. |

---

### 5. 저장 공간

| 항목 | 설명 |
| --- | --- |
| 저장 공간 사용 현황 | 앱, 문서, 임시 파일 등이 차지하는 용량을 항목별로 표시합니다. |
| 저장 공간 센스 | 임시 파일과 휴지통의 오래된 항목을 **자동으로 삭제**하여 공간을 확보합니다. |
| 새 콘텐츠가 저장되는 위치 변경 | 앱, 문서, 음악, 사진 등의 기본 저장 드라이브를 지정합니다. |

#### 왜 저장 공간 센스가 필요할까?

디스크 공간은 **부족해지기 전까지는 신경 쓰지 않는 자원**입니다.  
그러다 갑자기 공간이 없어 프로그램이 동작하지 않는 상황이 생깁니다.

저장 공간 센스는 임시 파일이나 오래된 휴지통 항목처럼  
**지워도 문제없는 파일을 자동으로 정리**해 이런 상황을 예방합니다.

### 6. 정보(시스템 정보)

시스템의 기본 사양을 확인하는 화면으로, **`⊞` + `Pause/Break`** 로 바로 열 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| 장치 사양 | 장치 이름, 프로세서(CPU), 설치된 RAM, 장치 ID, 시스템 종류(32비트/64비트) |
| Windows 사양 | 에디션, 버전, 설치 날짜, OS 빌드 |
| 관련 설정 | BitLocker 설정, 장치 관리자, 원격 데스크톱, 시스템 보호, 고급 시스템 설정 |

- **컴퓨터 이름 바꾸기** 를 통해 네트워크에서 사용할 이름을 변경할 수 있습니다.

#### 왜 "시스템 종류"를 확인해야 할까?

프로그램은 32비트용과 64비트용으로 나뉘어 배포되는 경우가 많습니다.

- 64비트 시스템 → 32비트·64비트 프로그램 모두 실행 가능
- 32비트 시스템 → **64비트 프로그램은 실행 불가**

따라서 프로그램을 내려받기 전에 시스템 종류를 확인해야 올바른 버전을 설치할 수 있습니다.

### 한 줄 정리

[시스템] 범주에서는 **디스플레이(해상도·배율·여러 모니터), 소리, 알림, 전원, 저장 공간, 시스템 정보**를 설정하며,  
시스템 정보 화면은 **`⊞` + `Pause/Break`** 로 바로 열 수 있습니다.
