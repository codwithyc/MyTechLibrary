## 064. 웹 브라우저 / 검색 엔진

### 1. 웹 브라우저의 개요

웹 브라우저는 **웹 서버에서 문서를 가져와 화면에 표시해 주는 프로그램**입니다.

- 종류 : Microsoft Edge, Google Chrome, Mozilla Firefox, Safari, Opera 등

**주요 기능**

| 기능 | 설명 |
| --- | --- |
| 웹 페이지 표시 | HTML 문서를 해석하여 화면에 나타냅니다. |
| **즐겨찾기(북마크)** | 자주 방문하는 사이트의 주소를 저장합니다. |
| **방문 기록(히스토리)** | 이전에 방문한 사이트 목록을 기록합니다. |
| **캐시** | 방문한 페이지의 데이터를 임시 저장하여 **다시 방문할 때 빠르게** 표시합니다. |
| 자동 완성 | 이전에 입력한 주소나 검색어를 제안합니다. |
| 소스 보기 | 웹 페이지의 HTML 소스를 확인합니다. |
| 파일 다운로드 | 웹의 파일을 컴퓨터에 저장합니다. |
| 전자 우편 / FTP | 브라우저에서 메일 발송이나 FTP 접속을 수행할 수 있습니다. |
| 인쇄 | 웹 페이지를 인쇄하거나 PDF로 저장합니다. |

#### 왜 캐시를 사용할까?

같은 사이트를 방문할 때마다 **로고, 배경 이미지, 스타일 파일**을 다시 내려받는 것은 낭비입니다.

이런 파일은 자주 바뀌지 않으므로, 한 번 받아 두고 **저장해 둔 것을 재사용**하면

- 페이지가 훨씬 빨리 열리고
- 데이터 사용량도 줄어듭니다.

다만 사이트가 변경되었는데 캐시된 옛 화면이 보일 수 있으므로,  
이럴 때는 **`Ctrl` + `F5`(강력 새로 고침)** 로 캐시를 무시하고 다시 받으면 됩니다.

### 2. 웹 브라우저의 설정

| 항목 | 설명 |
| --- | --- |
| 홈페이지 지정 | 브라우저를 실행할 때 처음 열리는 페이지를 지정합니다. |
| 검색 엔진 지정 | 주소 표시줄에서 검색할 때 사용할 검색 엔진을 지정합니다. |
| 검색 기록 삭제 | 방문 기록, 쿠키, 캐시, 저장된 암호 등을 삭제합니다. |
| 팝업 차단 | 원하지 않는 팝업 창을 차단합니다. |
| **InPrivate / 시크릿 모드** | **방문 기록, 쿠키, 임시 파일을 저장하지 않고** 인터넷을 사용합니다. |
| 확장 프로그램 | 브라우저에 추가 기능을 설치합니다. |
| 보안 설정 | 위험한 사이트 차단, 인증서 관리 등을 설정합니다. |

#### 왜 시크릿 모드를 사용할까?

브라우저는 편의를 위해 **방문 기록, 검색어, 로그인 정보**를 저장합니다.

그런데 공용 컴퓨터에서 사용한다면,  
이 기록이 다음 사용자에게 그대로 노출될 수 있습니다.

시크릿 모드는 **종료할 때 그 세션의 기록을 남기지 않습니다.**

다만 주의할 점이 있습니다.

- 내 컴퓨터에 기록이 남지 않을 뿐,
- **방문한 사이트·회사 네트워크·ISP는 여전히 접속 사실을 알 수 있습니다.**

즉, 시크릿 모드는 **익명성이 아니라 "로컬 기록 미저장"** 기능입니다.

### 4. 검색 엔진

인터넷에서 원하는 정보를 찾아 주는 시스템입니다.

**검색 엔진의 종류**

| 종류 | 설명 |
| --- | --- |
| **주제별(디렉터리) 검색 엔진** | 정보를 주제별로 분류해 두고 **단계적으로 찾아 들어가는** 방식입니다. |
| **키워드(단어별) 검색 엔진** | 검색어를 입력하면 관련 정보를 찾아 주는 방식입니다. |
| **메타 검색 엔진** | 자체 데이터베이스 없이 **여러 검색 엔진의 결과를 모아** 보여 줍니다. |
| **통합 검색 엔진** | 주제별·키워드 방식을 함께 제공합니다. |

#### 왜 메타 검색 엔진이 있을까?

검색 엔진마다 수집한 데이터와 정렬 기준이 다릅니다.  
따라서 같은 검색어를 넣어도 **결과가 서로 다릅니다.**

메타 검색 엔진은 여러 엔진에 동시에 질의하여 결과를 합치므로,  
**한 엔진에서 놓칠 수 있는 정보까지 확인**할 수 있습니다.

### 5. 검색 연산자

| 연산자 | 의미 | 예시 |
| --- | --- | --- |
| **AND (`&`, 공백)** | 두 단어를 **모두 포함** | `컴퓨터 AND 활용` |
| **OR (`|`)** | 두 단어 중 **하나라도 포함** | `컴퓨터 OR 전산` |
| **NOT (`-`, `!`)** | 해당 단어를 **제외** | `컴퓨터 -게임` |
| **NEAR** | 두 단어가 **가까이 있는** 문서 | `컴퓨터 NEAR 활용` |
| **" "** | **정확히 일치하는 구문** | `"컴퓨터활용능력 1급"` |

#### 왜 큰따옴표로 묶으면 결과가 달라질까?

일반 검색에서는 단어를 각각 분리해서 찾습니다.  
그래서 단어들이 문서의 서로 다른 위치에 흩어져 있어도 결과에 나옵니다.

큰따옴표로 묶으면 **그 순서와 형태 그대로 붙어 있는 문장**만 찾습니다.

찾는 문구가 정확할수록 결과의 정확도가 크게 올라갑니다.

### 6. 웹 관련 보안 기능

| 기능 | 설명 |
| --- | --- |
| **HTTPS** | 통신 내용을 암호화하여 도청과 변조를 막습니다. 주소 표시줄에 **자물쇠 표시**가 나타납니다. |
| SmartScreen 필터 | 피싱 사이트와 악성 소프트웨어를 차단합니다. |
| 팝업 차단 | 원치 않는 광고 창을 차단합니다. |
| 추적 방지 | 광고 목적의 사용자 추적을 제한합니다. |

#### 왜 HTTPS를 확인해야 할까?

HTTP는 데이터를 **암호화하지 않고 그대로 전송**합니다.

중간에서 누군가 가로채면 **아이디와 비밀번호가 그대로 노출**됩니다.

HTTPS는 이를 암호화하므로, 가로채더라도 내용을 알 수 없습니다.

로그인이나 결제를 하는 페이지에서는  
반드시 주소가 **`https://`** 로 시작하는지 확인해야 합니다.

---

### 한 줄 정리

웹 브라우저는 **웹 문서를 표시하고 즐겨찾기·기록·캐시를 관리**하며,  
**시크릿 모드는 로컬 기록만 남기지 않을 뿐 완전한 익명은 아니고**,  
검색은 **AND(모두 포함) / OR(하나라도) / NOT(제외) / " "(정확한 구문)** 연산자로 정확도를 높일 수 있습니다.
