## 003. 바로 가기 키

### 1. 바로 가기 키의 개요

바로 가기 키(단축키)는 마우스로 여러 단계를 거쳐야 하는 작업을 **키보드 조합 한 번으로 실행**하는 기능입니다.

- 핫키(Hot Key)라고도 부릅니다.
- 시험에서는 **키 조합과 기능을 짝지어 묻는 문제**가 자주 출제됩니다.

#### 왜 바로 가기 키를 따로 외워야 할까?

GUI 환경은 직관적이지만, 같은 작업을 반복할 때는 오히려 느립니다.  
메뉴를 열고 항목을 찾아 클릭하는 과정이 매번 반복되기 때문입니다.

바로 가기 키는 이 과정을 건너뛰고 **명령을 직접 호출**하므로,  
익숙해질수록 작업 속도가 크게 빨라집니다.

---

### 2. 기본 편집 관련 바로 가기 키

| 바로 가기 키 | 기능 |
| --- | --- |
| `Ctrl` + `C` | 복사 |
| `Ctrl` + `X` | 잘라내기 |
| `Ctrl` + `V` | 붙여넣기 |
| `Ctrl` + `Z` | 실행 취소 |
| `Ctrl` + `Y` | 다시 실행 |
| `Ctrl` + `A` | 모두 선택 |
| `Ctrl` + `D` (또는 `Delete`) | 선택한 항목을 삭제하여 휴지통으로 이동 |
| `Shift` + `Delete` | 휴지통을 거치지 않고 완전히 삭제 |
| `F2` | 선택한 항목의 이름 바꾸기 |

#### 왜 `Shift` + `Delete`는 휴지통을 거치지 않을까?

휴지통은 실수로 지운 파일을 되돌리기 위한 장치입니다.  
하지만 휴지통에 보관하는 동안에는 디스크 공간을 계속 차지합니다.

용량이 아주 크거나 확실히 필요 없는 파일이라면 곧바로 지우는 편이 낫기 때문에,  
`Shift`를 함께 눌러 **복원 없이 완전히 삭제**하는 방법을 제공합니다.

---

### 3. 창 / 프로그램 관련 바로 가기 키

| 바로 가기 키 | 기능 |
| --- | --- |
| `Alt` + `Tab` | 실행 중인 프로그램 간 전환 |
| `Alt` + `Esc` | 실행 중인 프로그램을 실행 순서대로 전환 |
| `Alt` + `F4` | 현재 실행 중인 창(프로그램) 종료 (바탕 화면에서는 Windows 종료 창 표시) |
| `Alt` + `Enter` | 선택한 항목의 속성 창 표시 |
| `Alt` + `Space Bar` | 현재 창의 조절 메뉴 표시 |
| `Ctrl` + `Esc` | [시작] 메뉴 표시 |
| `Ctrl` + `Shift` + `Esc` | 작업 관리자 실행 |
| `Ctrl` + `Alt` + `Delete` | 잠금, 사용자 전환, 로그아웃, 작업 관리자 등을 선택하는 화면 표시 |
| `F5` | 새로 고침 |
| `F1` | 도움말 |

#### 왜 `Alt` + `Tab`과 `Alt` + `Esc`가 나뉘어 있을까?

두 키는 "어떤 순서로 전환하는가"가 다릅니다.

- **`Alt` + `Tab`** : 창 목록을 미리 보면서 원하는 창을 골라 전환
- **`Alt` + `Esc`** : 목록 없이 실행된 순서대로 바로 전환

즉, 여러 창 중에서 **골라야 할 때는 `Alt` + `Tab`**,  
단순히 **다음 창으로 넘길 때는 `Alt` + `Esc`** 가 적합합니다.

### 4. Windows 로고 키(⊞) 관련 바로 가기 키

| 바로 가기 키 | 기능 |
| --- | --- |
| `⊞` | [시작] 메뉴 표시 |
| `⊞` + `D` | 바탕 화면 표시 / 이전 상태로 복원 |
| `⊞` + `E` | 파일 탐색기 실행 |
| `⊞` + `R` | '실행' 창 표시 |
| `⊞` + `L` | 컴퓨터 잠금 |
| `⊞` + `I` | '설정' 창 표시 |
| `⊞` + `X` | 빠른 링크 메뉴 표시 |
| `⊞` + `S` | 검색 상자로 이동 |
| `⊞` + `Tab` | 작업 보기(Task View) 실행 |
| `⊞` + `Ctrl` + `D` | 새 가상 데스크톱 추가 |
| `⊞` + `Ctrl` + `F4` | 현재 가상 데스크톱 닫기 |
| `⊞` + `Pause/Break` | [설정] → [시스템] → [정보] 창 표시 |
| `⊞` + `M` | 모든 창 최소화 |
| `⊞` + `←`, `→` | 창을 화면 왼쪽/오른쪽에 맞춰 배치(에어로 스냅) |
| `⊞` + `↑`, `↓` | 창 최대화 / 최소화 |
| `⊞` + `Print Screen` | 화면 전체를 캡처하여 '사진' 폴더에 저장 |

#### 왜 Windows 로고 키에 기능을 몰아 두었을까?

`Ctrl`이나 `Alt` 조합은 응용 프로그램마다 이미 사용 중인 경우가 많습니다.  
그래서 프로그램의 단축키와 충돌하지 않는 별도의 키가 필요했습니다.

Windows 로고 키는 **운영체제 전용 단축키**로 예약되어 있어,  
어떤 프로그램을 사용 중이든 항상 동일하게 동작합니다.

---

### 5. 화면 캡처 관련 바로 가기 키

| 바로 가기 키 | 기능 |
| --- | --- |
| `Print Screen` | 화면 전체를 클립보드에 복사 |
| `Alt` + `Print Screen` | 현재 활성 창만 클립보드에 복사 |
| `⊞` + `Print Screen` | 화면 전체를 캡처하여 파일로 저장 |
| `⊞` + `Shift` + `S` | 캡처 및 스케치(영역 지정 캡처) 실행 |

#### 왜 클립보드 복사와 파일 저장이 나뉘어 있을까?

캡처한 이미지를 곧바로 문서에 붙여 넣을 때는 파일로 저장할 필요가 없습니다.  
반대로 나중에 다시 쓰거나 전달해야 한다면 파일로 남아 있어야 합니다.

그래서 Windows는 **일회성 사용은 클립보드**, **보관이 필요하면 파일 저장**으로 방식을 나누어 제공합니다.

---

### 한 줄 정리

바로 가기 키는 **반복 작업의 단계를 줄이기 위한 기능**이며,  
`Ctrl` 계열은 편집, `Alt` 계열은 창 조작, **Windows 로고 키 계열은 운영체제 기능 호출**에 주로 사용됩니다.
