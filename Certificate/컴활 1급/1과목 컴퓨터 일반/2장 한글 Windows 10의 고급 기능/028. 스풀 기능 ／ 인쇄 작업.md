## 028. 스풀 기능 / 인쇄 작업

### 1. 스풀(SPOOL)의 개요

**SPOOL**은 **S**imultaneous **P**eripheral **O**peration **O**n-**L**ine의 약자로,  
인쇄할 데이터를 **하드디스크에 임시로 저장한 뒤 프린터로 보내는 기능**입니다.

- 인쇄 데이터를 저장하는 하드디스크 공간을 **스풀 파일**이라고 합니다.
- 스풀을 사용하면 **인쇄가 진행되는 동안에도 다른 작업을 할 수 있습니다.**
- 스풀은 **저용량의 데이터를 프린터로 전송할 때 유리**하며,  
  **인쇄 속도 자체는 스풀을 사용하지 않을 때보다 느려집니다.**

#### 왜 스풀이 필요할까?

CPU와 프린터의 속도 차이는 매우 큽니다.

- CPU : 데이터를 순식간에 만들어 냄
- 프린터 : 종이 한 장을 뽑는 데 몇 초 소요

스풀이 없다면 CPU는 프린터가 한 줄씩 출력할 때까지 **계속 기다려야** 합니다.  
그동안 다른 작업은 할 수 없습니다.

스풀은 인쇄 데이터를 **하드디스크에 먼저 통째로 넘겨 두고**,  
프린터는 그것을 천천히 가져가 출력하는 구조입니다.

즉, 스풀은  
**속도가 다른 두 장치를 분리하여, 빠른 쪽이 기다리지 않게 하는 기법**입니다.

#### 왜 스풀을 쓰면 인쇄 속도가 오히려 느려질까?

스풀은 데이터를 **하드디스크에 한 번 기록했다가 다시 읽어서** 프린터로 보냅니다.

이 과정에서 **디스크 입출력이 추가로 발생**하므로,  
프린터로 곧바로 보내는 것보다 전체 인쇄 완료 시간은 길어집니다.

하지만 그 대신 **사용자는 기다리지 않고 다른 작업을 할 수 있습니다.**

즉, 스풀은

- **인쇄 속도**를 희생하고
- **전체 작업 효율**을 얻는

방식입니다. 시험에서 자주 나오는 포인트이므로 반드시 구분해서 기억해야 합니다.

---

### 2. 스풀 설정

[프린터 속성] → [고급] 탭에서 설정합니다.

| 옵션 | 설명 |
| --- | --- |
| **스풀에 인쇄 문서를 저장한 후 인쇄 속도를 빠르게 함** | 스풀을 사용합니다. |
| ├ 마지막 페이지까지 스풀한 후 인쇄 시작 | 문서 전체를 스풀에 저장한 뒤 인쇄를 시작합니다. |
| └ 즉시 인쇄 시작 | 스풀에 저장하면서 동시에 인쇄를 시작합니다. |
| **프린터로 인쇄 문서를 직접 보냄** | 스풀을 사용하지 않고 프린터로 바로 전송합니다. |

#### 왜 "마지막 페이지까지 스풀한 후 인쇄"라는 옵션이 있을까?

문서를 만드는 프로그램이 느리면, 인쇄 도중에 데이터가 끊길 수 있습니다.  
그러면 프린터가 중간에 멈추거나 오류가 발생합니다.

전체를 먼저 스풀에 저장해 두면 **데이터가 끊길 걱정 없이** 안정적으로 인쇄할 수 있습니다.

반대로 **즉시 인쇄 시작**은 첫 페이지가 더 빨리 나온다는 장점이 있습니다.

### 3. 인쇄 작업(인쇄 대기열) 관리

프린터를 더블클릭하면 **인쇄 관리 창(인쇄 대기열)** 이 열립니다.

| 표시 항목 | 내용 |
| --- | --- |
| 문서 이름 | 인쇄할 문서의 이름 |
| 상태 | 인쇄 중, 일시 중지, 오류 등 |
| 소유자 | 인쇄를 요청한 사용자 |
| 페이지 수 | 문서의 전체 페이지 수 |
| 크기 | 문서의 용량 |
| 제출 시간 | 인쇄를 요청한 시각 |
| 포트 | 프린터가 연결된 포트 |

**가능한 작업**

| 메뉴 | 기능 |
| --- | --- |
| [프린터] → 인쇄 일시 중지 | 프린터 전체의 인쇄를 일시 중지합니다. |
| [프린터] → 모든 문서 취소 | 대기 중인 모든 인쇄 작업을 취소합니다. |
| [문서] → 일시 중지 / 다시 시작 / 취소 | **선택한 문서**의 인쇄를 제어합니다. |
| 순서 변경 | 대기 중인 문서를 드래그하여 인쇄 순서를 바꿉니다. |

#### 인쇄 작업에서 반드시 기억할 점

- **인쇄 중인 문서도 일시 중지하거나 취소할 수 있습니다.**
- **이미 인쇄가 완료되어 출력된 문서는 취소할 수 없습니다.**
- 인쇄 대기 중인 문서의 **인쇄 순서는 변경할 수 있지만**, 문서의 **내용은 변경할 수 없습니다.**
- 다른 프린터로 **작업을 이동할 수 있습니다.** (같은 드라이버를 사용하는 경우)

#### 왜 대기 중인 문서의 내용은 바꿀 수 없을까?

인쇄 대기열에 들어간 문서는 이미 **프린터가 이해하는 형식으로 변환된 데이터**입니다.

원본 문서와는 별개의 데이터이므로,  
내용을 수정하려면 **원본을 고쳐서 다시 인쇄**해야 합니다.

---

### 4. 인쇄 방법

| 방법 | 설명 |
| --- | --- |
| 프로그램에서 인쇄 | `Ctrl` + `P` 또는 [파일] → [인쇄] |
| 드래그 앤 드롭 | 문서 파일을 프린터 아이콘 위로 끌어다 놓습니다. |
| 바로 가기 메뉴 | 파일 바로 가기 메뉴 → [인쇄] |

- 인쇄 중에는 **알림 영역에 프린터 아이콘**이 표시되며, 인쇄가 끝나면 사라집니다.

---

### 한 줄 정리

스풀은 **인쇄 데이터를 하드디스크에 임시 저장하여 다른 작업을 병행할 수 있게 하는 기능**이며,  
**전체 작업 효율은 높아지지만 인쇄 속도 자체는 느려집니다.**  
인쇄 중인 문서도 **취소·일시 중지·순서 변경은 가능하지만 내용 수정은 불가능**합니다.
