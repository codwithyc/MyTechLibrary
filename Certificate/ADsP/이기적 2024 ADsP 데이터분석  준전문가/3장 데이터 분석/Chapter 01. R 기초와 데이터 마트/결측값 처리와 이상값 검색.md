# 결측값 처리와 이상값 검색

결측값 처리와 이상값 검색은 데이터 분석 전에 반드시 수행해야 하는 **데이터 전처리 과정**이다.

데이터 분석은 데이터 품질에 크게 영향을 받는다.
데이터에 비어 있는 값이나 비정상적으로 큰 값, 작은 값이 포함되어 있으면 분석 결과가 왜곡될 수 있다.

```markdown id="yi2lo3"
결측값 처리와 이상값 검색 = 분석 전에 데이터 품질을 점검하고 분석 가능한 상태로 만드는 과정
```

이번 단원에서는 크게 두 가지를 이해하면 된다.

```markdown id="rfa8xu"
결측값 = 값이 비어 있는 데이터
이상값 = 일반적인 범위에서 벗어난 비정상적인 데이터
```

---

# 01. 결측값

## 결측값의 개념

**결측값(Missing Value)**이란 데이터가 존재해야 하는 위치에 값이 비어 있는 경우를 의미한다.

예를 들어 고객 정보 데이터가 다음과 같다고 하자.

| 고객ID | 나이 | 성별 |  구매금액 |
| ---- | -: | -- | ----: |
| A001 | 25 | 남  | 30000 |
| A002 | 31 | 여  | 45000 |
| A003 |    | 남  | 20000 |
| A004 | 28 |    | 50000 |

여기서 A003 고객의 나이, A004 고객의 성별이 비어 있다.
이런 값이 결측값이다.

```markdown id="fuiw20"
결측값 = 데이터가 있어야 할 자리에 값이 없는 상태
```

R에서는 결측값을 보통 `NA`로 표현한다.

```r id="tx3wvh"
x <- c(10, 20, NA, 40)
```

여기서 `NA`가 결측값이다.

---

## 결측값이 발생하는 이유

결측값은 여러 이유로 발생한다.

| 원인        | 설명                             |
| --------- | ------------------------------ |
| 입력 누락     | 사용자가 값을 입력하지 않음                |
| 수집 오류     | 센서, 시스템, 로그 수집 과정에서 값이 누락됨     |
| 응답 거부     | 설문조사에서 응답자가 특정 문항에 답하지 않음      |
| 데이터 병합 오류 | 여러 데이터를 합치는 과정에서 일부 값이 매칭되지 않음 |
| 시스템 오류    | 저장, 전송, 처리 과정에서 데이터가 손실됨       |

결측값은 단순히 “비어 있는 값”이 아니라,
분석 결과에 영향을 줄 수 있는 데이터 품질 문제다.

예를 들어 고객 나이 데이터에 결측값이 많으면 연령대별 구매 분석이 부정확해질 수 있다.

---

# 02. R에서 결측값 확인

R에서는 결측값을 확인할 때 `is.na()` 함수를 사용한다.

## 1) `is.na()`

`is.na()`는 값이 결측값인지 확인하는 함수다.

```r id="efby4h"
x <- c(10, 20, NA, 40)

is.na(x)
```

결과는 다음과 같다.

```r id="cn3gwu"
FALSE FALSE TRUE FALSE
```

결측값이면 `TRUE`, 결측값이 아니면 `FALSE`가 나온다.

```markdown id="o7474y"
is.na() = 결측값 여부를 TRUE/FALSE로 확인하는 함수
```

---

## 2) 결측값 개수 확인

결측값의 개수를 확인할 때는 `sum(is.na())`를 사용한다.

```r id="nyiz7b"
x <- c(10, 20, NA, 40)

sum(is.na(x))
```

결과는 다음과 같다.

```r id="gj7yra"
1
```

`is.na(x)`는 결측값 여부를 TRUE/FALSE로 반환하고,
R에서는 `TRUE`를 1, `FALSE`를 0처럼 계산할 수 있기 때문에 결측값 개수를 셀 수 있다.

```markdown id="w20pkl"
sum(is.na(x)) = 결측값 개수 확인
```

---

## 3) 데이터프레임에서 결측값 확인

데이터프레임 전체의 결측값을 확인할 수도 있다.

```r id="d6srga"
df <- data.frame(
  name = c("kim", "lee", "park"),
  age = c(20, NA, 25),
  score = c(90, 80, NA)
)

is.na(df)
```

결측값 개수는 다음처럼 확인한다.

```r id="4bey7h"
sum(is.na(df))
```

컬럼별 결측값 개수를 확인하려면 `colSums()`를 사용할 수 있다.

```r id="ecx070"
colSums(is.na(df))
```

| 함수                 | 설명           |
| ------------------ | ------------ |
| `is.na()`          | 결측값 여부 확인    |
| `sum(is.na())`     | 전체 결측값 개수 확인 |
| `colSums(is.na())` | 열별 결측값 개수 확인 |
| `complete.cases()` | 결측값이 없는 행 확인 |

시험에서는 `is.na()`와 `sum(is.na())`를 우선 기억하면 된다.

# 03. 결측값 처리 방법

결측값 처리 방법은 크게 세 가지로 정리할 수 있다.

```markdown id="vnlzn8"
결측값 제거
대표값으로 대체
예측값으로 대체
```

| 처리 방법  | 설명                       |
| ------ | ------------------------ |
| 제거     | 결측값이 포함된 행이나 열을 삭제       |
| 대표값 대체 | 평균, 중앙값, 최빈값 등으로 대체      |
| 예측값 대체 | 다른 변수들을 이용해 결측값을 예측하여 대체 |

---

## 1) 결측값 제거

결측값 제거는 결측값이 포함된 행이나 열을 분석 대상에서 제외하는 방법이다.

R에서는 `na.omit()`을 사용할 수 있다.

```r id="42w2n1"
x <- c(10, 20, NA, 40)

na.omit(x)
```

결과는 결측값이 제거된 값이다.

```r id="uvg365"
10 20 40
```

데이터프레임에서도 사용할 수 있다.

```r id="maudul"
df_clean <- na.omit(df)
```

```markdown id="7gepzv"
na.omit() = 결측값이 포함된 행을 제거하는 함수
```

---

### 결측값 제거의 장단점

| 구분     | 설명                             |
| ------ | ------------------------------ |
| 장점     | 처리 방법이 단순하고 빠르다                |
| 단점     | 데이터 손실이 발생할 수 있다               |
| 적합한 경우 | 결측값 비율이 낮고 삭제해도 분석에 큰 영향이 없을 때 |

결측값이 적으면 제거해도 괜찮을 수 있다.
하지만 결측값이 많으면 데이터를 많이 잃게 되어 분석 결과가 왜곡될 수 있다.

```markdown id="jdes7g"
결측값 제거는 간단하지만 데이터 손실 위험이 있다.
```

---

## 2) 대표값으로 대체

결측값을 평균, 중앙값, 최빈값 같은 대표값으로 바꾸는 방법이다.

예를 들어 나이 데이터에 결측값이 있으면 평균 나이나 중앙값으로 대체할 수 있다.

```r id="6vv21f"
x <- c(10, 20, NA, 40)

x[is.na(x)] <- mean(x, na.rm = TRUE)
x
```

여기서 `na.rm = TRUE`는 계산할 때 결측값을 제외하라는 의미다.

```markdown id="8k1jif"
na.rm = TRUE는 계산할 때 NA를 제외하라는 의미이다.
```

---

### 평균 대체

평균 대체는 결측값을 평균으로 바꾸는 방법이다.

```r id="gy5tdk"
x[is.na(x)] <- mean(x, na.rm = TRUE)
```

| 구분     | 설명                       |
| ------ | ------------------------ |
| 장점     | 간단하고 이해하기 쉽다             |
| 단점     | 이상값에 영향을 많이 받는다          |
| 적합한 경우 | 데이터가 비교적 대칭적이고 이상값이 적을 때 |

---

### 중앙값 대체

중앙값 대체는 결측값을 중앙값으로 바꾸는 방법이다.

```r id="wvxhc6"
x[is.na(x)] <- median(x, na.rm = TRUE)
```

| 구분     | 설명                     |
| ------ | ---------------------- |
| 장점     | 이상값의 영향을 평균보다 적게 받는다   |
| 단점     | 데이터 분포를 단순화할 수 있다      |
| 적합한 경우 | 이상값이 있거나 데이터가 치우쳐 있을 때 |

---

### 최빈값 대체

최빈값은 가장 자주 등장하는 값이다.
성별, 지역, 등급 같은 범주형 데이터의 결측값을 대체할 때 자주 사용한다.

| 구분  | 설명                    |
| --- | --------------------- |
| 평균  | 숫자형 데이터에 사용           |
| 중앙값 | 숫자형 데이터, 이상값이 있을 때 유용 |
| 최빈값 | 범주형 데이터에 사용           |

시험에서는 이렇게 구분하면 된다.

```markdown id="ar7bdf"
숫자형 결측값은 평균이나 중앙값으로 대체할 수 있고,
범주형 결측값은 최빈값으로 대체할 수 있다.
```

---

## 3) 예측값으로 대체

예측값 대체는 다른 변수들을 이용해 결측값을 예측한 뒤 대체하는 방법이다.

예를 들어 나이가 결측인 고객이 있을 때,
구매 패턴, 직업, 소득, 방문 빈도 등을 이용해 나이를 추정할 수 있다.

| 구분     | 설명                           |
| ------ | ---------------------------- |
| 장점     | 단순 대체보다 데이터 특성을 더 잘 반영할 수 있다 |
| 단점     | 구현이 복잡하고 예측 오류가 발생할 수 있다     |
| 적합한 경우 | 결측값이 중요하고 다른 변수와 관계가 있을 때    |

ADsP 수준에서는 깊은 모델 구현보다 개념 중심으로 이해하면 된다.

```markdown id="3rf2h5"
예측값 대체 = 다른 변수와의 관계를 이용해 결측값을 추정하여 대체하는 방법
```

# 04. 결측값 처리 방법 비교

| 방법     | 핵심              | 장점        | 단점         |
| ------ | --------------- | --------- | ---------- |
| 제거     | 결측값 포함 행/열 삭제   | 단순하고 빠름   | 데이터 손실 발생  |
| 평균 대체  | 평균값으로 대체        | 간단함       | 이상값에 민감    |
| 중앙값 대체 | 중앙값으로 대체        | 이상값 영향 적음 | 분포 단순화 가능  |
| 최빈값 대체 | 가장 자주 나온 값으로 대체 | 범주형에 적합   | 특정 값 비중 증가 |
| 예측값 대체 | 모델로 결측값 추정      | 정보 보존 가능  | 복잡하고 오류 가능 |

시험에서는 이렇게 기억하면 된다.

```markdown id="vzh34v"
결측값은 제거하거나, 평균·중앙값·최빈값으로 대체하거나, 예측값으로 대체할 수 있다.
```

# 05. 이상값

## 이상값의 개념

**이상값(Outlier)**이란 일반적인 데이터 범위에서 크게 벗어난 값을 의미한다.

예를 들어 사람의 나이 데이터가 다음과 같다고 하자.

```markdown id="0t4710"
20, 21, 22, 23, 24, 999
```

여기서 `999`는 일반적인 나이 범위에서 벗어난 값이다.
이런 값이 이상값이다.

```markdown id="fu7x3f"
이상값 = 일반적인 데이터 분포에서 크게 벗어난 비정상적인 값
```

이상값은 실제로 매우 특이한 값일 수도 있고, 데이터 입력 오류일 수도 있다.

---

## 이상값이 발생하는 이유

| 원인       | 설명                              |
| -------- | ------------------------------- |
| 입력 오류    | 나이를 29가 아니라 299로 입력             |
| 측정 오류    | 센서나 장비 오류로 잘못된 값 수집             |
| 처리 오류    | 데이터 변환이나 단위 변환 과정에서 오류 발생       |
| 실제 특이 사례 | 매우 큰 구매 금액, 매우 높은 소득처럼 실제로 드문 값 |
| 부정 행위    | 이상 거래, 사기 거래, 비정상 접근 패턴         |

이상값이라고 해서 무조건 제거하면 안 된다.
이상값이 실제 중요한 의미를 가질 수도 있기 때문이다.

예를 들어 금융 데이터에서 이상값은 사기 거래를 의미할 수 있다.

```markdown id="rg7g1q"
이상값은 오류일 수도 있지만, 중요한 분석 대상일 수도 있다.
```

# 06. 이상값 검색 방법

이상값을 찾는 대표적인 방법은 다음과 같다.

```markdown id="cxqp4b"
사분위수 기반 방법
표준편차 기반 방법
시각화 기반 방법
```

---

## 1) 사분위수 기반 방법, IQR

사분위수 기반 방법은 데이터를 작은 값부터 큰 값까지 정렬한 뒤,
1사분위수와 3사분위수를 이용해 이상값을 판단하는 방법이다.

| 용어  | 의미                |
| --- | ----------------- |
| Q1  | 제1사분위수, 하위 25% 지점 |
| Q2  | 제2사분위수, 중앙값       |
| Q3  | 제3사분위수, 하위 75% 지점 |
| IQR | Q3 - Q1           |

```markdown id="ifnxse"
IQR = Q3 - Q1
```

일반적으로 다음 범위를 벗어나면 이상값으로 본다.

```markdown id="a21xmg"
하한값 = Q1 - 1.5 × IQR
상한값 = Q3 + 1.5 × IQR
```

| 판단 기준    | 설명     |
| -------- | ------ |
| 하한값보다 작음 | 이상값 가능 |
| 상한값보다 큼  | 이상값 가능 |
| 범위 안     | 일반값    |

시험에서 매우 자주 나오는 기준이다.

```markdown id="zpcsn8"
IQR 기준 이상값 = Q1 - 1.5IQR보다 작거나 Q3 + 1.5IQR보다 큰 값
```

---

## R에서 IQR 기반 이상값 확인

R에서는 `boxplot()`을 사용하면 이상값을 시각적으로 확인할 수 있다.

```r id="7nz3f2"
x <- c(10, 12, 13, 15, 18, 100)

boxplot(x)
```

박스플롯에서 수염 밖에 따로 표시되는 점이 이상값이다.

또는 `boxplot.stats()`를 사용할 수 있다.

```r id="x0fgci"
boxplot.stats(x)$out
```

이 명령어는 이상값으로 판단되는 값을 반환한다.

```markdown id="bentky"
boxplot.stats(x)$out = 박스플롯 기준 이상값 확인
```

---

## 2) 표준편차 기반 방법

표준편차 기반 방법은 평균에서 얼마나 멀리 떨어져 있는지를 기준으로 이상값을 판단하는 방법이다.

보통 평균에서 표준편차의 3배 이상 떨어진 값을 이상값으로 보는 경우가 많다.

```markdown id="s4u6se"
평균 ± 3 × 표준편차 범위를 벗어나면 이상값으로 판단할 수 있다.
```

예를 들어 평균이 50이고 표준편차가 10이라면 일반적인 범위는 다음과 같다.

```markdown id="2szgat"
50 - 3 × 10 = 20
50 + 3 × 10 = 80
```

따라서 20보다 작거나 80보다 큰 값은 이상값으로 의심할 수 있다.

| 기준               | 설명           |
| ---------------- | ------------ |
| 평균 + 3 × 표준편차 초과 | 매우 큰 이상값 가능  |
| 평균 - 3 × 표준편차 미만 | 매우 작은 이상값 가능 |

시험에서는 IQR 기준이 더 자주 나오지만, 표준편차 기준도 함께 알아두면 좋다.

```markdown id="klbgvu"
표준편차 기준 이상값 = 평균에서 지나치게 멀리 떨어진 값
```

## 3) 시각화 기반 방법

그래프를 통해 이상값을 확인할 수도 있다.

| 방법    | 설명                        |

| 산점도   | 두 변수 관계에서 비정상적으로 떨어진 점 확인 |
| 히스토그램 | 데이터 분포에서 극단적인 값 확인        |

---

### 박스플롯

박스플롯은 이상값 탐지에 자주 사용된다.

```r id="0005w7"
boxplot(x)
```

박스 바깥의 점은 이상값으로 볼 수 있다.

```markdown id="09bn4a"
박스플롯은 사분위수 기준으로 이상값을 시각적으로 확인하는 그래프이다.
```

---

### 산점도

산점도는 두 변수 사이의 관계에서 이상한 패턴을 찾을 때 유용하다.

예를 들어 공부 시간과 시험 점수의 관계를 보는데,
공부 시간이 매우 적은데 점수가 매우 높거나, 공부 시간이 매우 많은데 점수가 매우 낮은 데이터가 있다면 이상값으로 의심할 수 있다.

```markdown id="w8n19q"
산점도는 두 변수 관계에서 비정상적으로 떨어진 값을 확인할 때 사용한다.
```

---

### 히스토그램

히스토그램은 데이터의 분포를 확인하는 그래프다.

대부분의 값이 특정 구간에 몰려 있는데, 일부 값이 멀리 떨어져 있으면 이상값을 의심할 수 있다.

```markdown id="fjc6fw"
히스토그램은 데이터 분포와 극단값을 확인할 때 사용한다.
```

# 07. 이상값 처리 방법

이상값은 발견한 뒤 바로 제거하는 것이 아니라, 원인을 먼저 확인해야 한다.

처리 방법은 크게 다음과 같다.

```markdown id="kgi99o"
제거
대체
분리 분석
유지
```

| 처리 방법 | 설명                       |
| ----- | ------------------------ |
| 제거    | 입력 오류나 측정 오류로 판단되면 제거    |
| 대체    | 평균, 중앙값, 상한값, 하한값 등으로 대체 |
| 분리 분석 | 이상값 자체가 의미 있을 경우 별도로 분석  |
| 유지    | 실제 값이고 분석상 중요하면 그대로 유지   |

---

## 1) 제거

명백한 오류라면 제거할 수 있다.

예를 들어 사람 나이가 `999`로 입력되어 있다면 입력 오류일 가능성이 높다.

```markdown id="bt3vsk"
이상값 제거 = 명백한 오류 데이터를 분석 대상에서 제외하는 방법
```

---

## 2) 대체

이상값을 적절한 값으로 바꿀 수도 있다.

대표적으로 상한값이나 하한값으로 대체하는 방법이 있다.

예를 들어 IQR 기준 상한값보다 큰 값을 상한값으로 바꾸는 방식이다.

```markdown id="bfrk2d"
이상값 대체 = 비정상적인 값을 평균, 중앙값, 상한값, 하한값 등으로 바꾸는 방법
```

---

## 3) 분리 분석

이상값 자체가 중요한 의미를 가질 때는 따로 분석한다.

예를 들어 금융 이상 거래, 서버 장애 로그, 고액 구매 고객은 이상값이지만 중요한 분석 대상일 수 있다.

```markdown id="bi0cgh"
분리 분석 = 이상값을 제거하지 않고 별도 그룹으로 분석하는 방법
```

---

## 4) 유지

이상값이 실제 관측값이고 분석 목적상 필요하다면 유지할 수 있다.

예를 들어 고소득자 분석, VIP 고객 분석, 대규모 주문 분석에서는 극단값이 핵심일 수 있다.

```markdown id="07j9l9"
이상값 유지 = 실제 의미 있는 값이면 제거하지 않고 분석에 포함하는 방법
```

# 시험 직전 암기 문장

```markdown id="ds2m3x"
결측값은 데이터가 있어야 할 위치에 값이 없는 상태를 의미하며,
R에서는 주로 NA로 표현한다.

결측값은 입력 누락, 수집 오류, 응답 거부, 데이터 병합 오류 등으로 발생할 수 있다.

R에서 결측값 여부는 is.na() 함수로 확인하고,
결측값의 개수는 sum(is.na())로 확인할 수 있다.

na.omit() 함수는 결측값이 포함된 행을 제거할 때 사용한다.

평균이나 표준편차를 계산할 때 결측값을 제외하려면 na.rm = TRUE 옵션을 사용한다.

결측값 처리 방법에는 결측값 제거, 평균·중앙값·최빈값 대체, 예측값 대체가 있다.

숫자형 데이터의 결측값은 평균이나 중앙값으로 대체할 수 있고,
범주형 데이터의 결측값은 최빈값으로 대체할 수 있다.

이상값은 일반적인 데이터 범위에서 크게 벗어난 값을 의미한다.

이상값은 입력 오류나 측정 오류로 발생할 수도 있고,
실제 의미 있는 특이 사례일 수도 있으므로 무조건 제거하면 안 된다.

이상값은 박스플롯, 사분위수 기반 IQR 방법, 표준편차 기준, 산점도 등을 통해 확인할 수 있다.

IQR은 Q3에서 Q1을 뺀 값이며,
일반적으로 Q1 - 1.5IQR보다 작거나 Q3 + 1.5IQR보다 큰 값은 이상값으로 판단한다.

이상값 처리 방법에는 제거, 대체, 분리 분석, 유지가 있다.

결측값은 값이 없는 것이고,
이상값은 값은 존재하지만 일반적인 범위에서 벗어난 값이다.
```
