## 네트워크 회선 운영
### 1. 리피터
#### 개요
- Repeater, **물리 계층에서 감쇠한 전기신호를 증폭하는 장치**입니다.
- 네트워크를 통해서 신호를 전송할 때 전송회선이 긴 경우, 신호가 약해지는 에너지 감쇠현상이 발생합니다.
- 이를 보정하기 위해 신호를 다시 반복(Repeat)하여 감쇠한 신호를 보정하는 장치입니다.
    - 입력한 신호의 에너지를 증가시켜 더 큰 에너지로 출력하는 장치인 증폭기와 헷갈리지 않도록 합니다.

| 리피터와 증폭기의 차이 |||
| ----------------------- | ---------- | ------------ | 
| 구분 | 리피터 (Repeater) | 증폭기(Amplifier) |
| 역할 | 신호를 원래돼로 보정 | 신호를 원래보다 더 크게 증폭 | 
| 비유 | 물 높이가 일정하도록 물이 마를 때쯤 다시 물을 채웁니다. | 물의 양을 늘리거나, 물이 더 세게 흐를 수 있게 만듭니다. |
| 사례 | HDMI 리피터 : HDMI를 통해 전송되는 신호가 도중에 손실되지 않도록 원래의 신호를 반복적으로 보냅니다. | 와이파이 증폭기 : 약한 와이파이 신호를 더 크게 증폭시킵니다. | 

####  리피터의 특징
- OSI 7계층 중 가장 하위 계층인 물리 계층에 해당합니다.
- 한 쪽 포트에서 들어오는 전기신호를 다른 쪽 프트로 전송할 때 신호를 증폭하거나 재생합니다.
- 전송 거리에 따라 감쇠되는 신호를 증폭시켜 장거리 전송을 가능하게 합니다.
- 케이블 연결 배선을 자유롭게 할 수 있고, 전송 거리를 늘릴 수 있지만 무제한으로 연장할 수는 없습니다.
- 리피터 기능이 내장된 하브도 있으므로, 이때는 따로 리피터를 사용하지 않아도 됩니다.

### 2. 허브 
#### 개요
- **LAN 상에서 연결된 여러 시스템을 포트별로 분리하여 사용할 수 있게 하는 물리 계층의 장치**입니다.
    - 많은 비행기가 모였다가 다시 나가는 메인 플랫폼이라는 의미에서 인천 국제공항을 동북아 물류의 허브라고 부르기도 하고 하는 것처럼,  
    Hub는 어떠한 신호가 한 번에 모이기도 하고 다시 분산되어 나가기도 하는 중심을 의미합니다.

#### 허브의 특징
- 각 포트별로 연결된 케이블이 허브로 모였다가 다시 허브로부터 여러 개의 포트로 분배되어 송신됩니다.
- 허브 장치의 특성에 따라 데이터 링크 계층이나 네트워크 계층에서도 동작합니다.
- 기본적으로 리피터 기능을 장착하고 있어 디지털 신호를 증폭합니다.
- 네트워크 상태를 모니터링할 수 있습니다.
- LAN 선을 보다 간편하게 관리할 수 있습니다.
- 허브 장치에 장애가 발생하면 해당 허브에 연결된 네트워크 전체에 장애가 발생합니다.  
하지만 허브 장치에 연결된 하나의 노드에 장애가 발생하면 다른 노드에는 영향을 미치지 않습니다.
- 포트 트렁크(Port Trunk) : VLAN Trunking의 사례와 같이 여러 개의 포트를 하나로 묶어 각 포트의 속도를 하나로 합쳐 네트워크 속도를 향상시키는 기법입니다.

#### 허브의 종류 
| 종류 | 설명 | 
| --- | ---------------- | 
| 더미 허브 <br> (Durmmy Hub) | - 단순히 시스템과 네트워크의 연결만 수행하는 장치 <br> - OSI 7계층에서 가장 하위 계층인 물리 계층에 해당하며, 리피터로 구성 <br> - 하나의 대역폭(10Mbps)을 연결된 모든 노드들이 공유하므로 노드 숫자가 많아지면 성능과 속도가 줄어듭니다. | 
| 지능형 허브 <br> (Intelligent Hub) | - SNMP 프로토콜을 추가하여 네트워크 관리 기능을 포함합니다. <br> - 포트에 연결된 노드의 네트워크 상태를 감시하며, 노드가 고장나면 해당 노드의 통신을 중지한다. | 
| 스위칭 허브 <br> (Switching Hub) | - 프로세서, 메모리, 운영 소프트웨어로 구성되어 스위칭 기능을 추가합니다. <br> - 리피터 회로 내장 <br> - 여러 개의 포트에서 데이터 패킷을 받고, 프로세스는 데이터 패킷의 수신지 주소를 읽어 특정 포트로만 패킷을 전송합니다. <br> - 각각의 노드에 전체 대역폭(10Mbps)를 보장하고, 대역폭을 할당할 수 있어 전송 성능을 보장할 수 있다 | 

### 3. 브리지
#### 개요
- LAN과 LAN을 연결하는 인터페이스 장치로, 송수신 데이터의 흐름 제어와 에러 제어를 수행하는 데이터링크 계층의 장비입니다.
- 두 개의 LAN을 연결시킨다는 점에서 리피터와 유사하나, 리피터는 전체 신호를 증폭하는 것만 가능한 반면, 브리지는 통신량을 관리하고 제어할 수 있습니다.

#### 브리지의 특징
- 데이터링크 계층에 해당하는 장비로 MAC 주소를 관리합니다.
- 네트워크에 많은 노드를 연결하여 네트워크의 영역을 확장할 수 있으며, 데이터 흐름 제어와 에러 제어를 통해 데이터 병목현상을 해결합니다.
- 입력 신호를 출력 신호로 전환하여 전송하는 포워딩 (Forwarding) 기능을 수행하되, 무조건적으로 전송하지 않고, 자체 필터링을 거치므로 다른  
패킷 전송 장비들에 비해 독립적입니다.
- 서로 다른 물리적 네트워크를 연결할 수 있습니다. (이더넷과 토큰링 네트워크)

#### 브리지의 종류
| 종류 | 설명 |
| --- | ----------------- |
| 기본 브리지 <br> (Simple Bridge) | 단순 패킷 포워딩 기능만을 수행 | 
| 학습형 브리지 <br> (Learning Bridge) | 패킷의 내용에 따라 패킷 포워딩 테이블을 변경 | 
| 라우팅 브리지 <br> (Source Routing Bridge) | 여러 개의 브리지가 연결되어 있는 경우, 패킷을 전송하기 위한 최선의 경로를 선택 | 
| 지능형 브리지 <br> (Intelligent Bridge) | 위의 모든 기능에 더하여 목적지를 분석하여 패킷을 필터링함으로써 보안 기능을 강화 | 

### 4. 스위치
#### 개요
- 허브(Hub)와 유사하나 허브에 비해 기능과 성능이 확장된 장치로, 스위칭 허브(Switching Hub)라고 칭하기도 합니다.
- 단순히 데이터를 수신하는 허브와는 달리, **수신된 데이터를 어떻게 전송할지를 파악하여 충돌이 발생하지 않도록 제어합니다.**

#### 스위치의 특징
- 목적지 포트와 1 : 1 연결하여 전송하므로 네트워크를 효율적으로 활용할 수 있다.
- 전이중 (Full-Duplex) 통신 방식으로 노드의 수가 증가하거나 노드 간의 통신이 증가해도 전체 데이터 성능 부하를 발생시키지 않는다.
- 패킷 감청이 어렵고 보안성이 높다.

#### 스위칭 방식에 따른 분류 
| 스위칭 방식| 특징 |
| ----- | ---------------------- |
| Store and Forward | - 스위치의 모든 프레임을 수신하고 메모리에 저장한 후 ㅇ에러 확인 및 정정을 마친 뒤 <br> 목적지의 MAC 주소를 보고 목적지 포트로 전달합니다. <br> - 도중에 패킷 내용이 손실되어도 스위치에 모든 프레임이 도착한 이후 전달이 이루어지므로 정확하게 전달할 수 있다. <br> - 상대적으로 우수한 성능의 스위체에서 가능한 방식입니다. <br> - 전송 속도 및 지연 시간이 길다. | 
| Cut Through | - 목적지의 MAC 주소만 확인되면 프레임이 수신되는 대로 에러 체크 과정 없이 빠르게 전달한다. <br> - 낮은 사양의 스위치에서도 가능한 방식이며, 패킷이 도착하는 즉시 바로 목적지 포트로 전달하므로 전달 시간이 짧다. <br> - 동시에 여러 개의 프레임이 도착하여 한 번에 여러 개의 프레임을 전달해야 할 떄 일부 패킷이 소실되기도 하여 신뢰성을 보장할 수 없다. | 
| Fragment Free | - Store and Forward 방식과 Cut Through 방식을 혼합한 개념으로, 현재 가장 많이 사용되는 개선된 방식입니다. <br> - 스위치가 프레임 전송 전의 64 Byte 까지의 저장 검사하여 헤더의 에러를 체크한 뒤 전송합니다. <br> - 전송 속도를 높이면서도 프레임 간의 충돌을 방지합니다. |

### 5. 라우터
#### 개요 
- 서로 다른 두 개의 네트워크를 연결하는 Internetworking(인터네트워킹) 장비로, 두 네트워크 간의 연결 경로를 선택하여 데이터를 전송한다.
- LAN과 LAN을 연결하고, TCP/IP나 IPX/SPX 등의 프로토콜을 지원하며, 주로 TCP/IP 프로토콜을 기반으로 설정합니다.

#### 라우터의 특징
- 네트워크 계층에서 동작하는 장비입니다.
- 데이터 패킷을 출발지에서 목적지까지 전달하기 위하여 가장 효율적인 전송로를 선택하여 전송을 수행합니다.
- 라우팅 정보를 주기적으로 갱신하여 최신의 라우팅 테이블(Routing Table)을 유지하고 해당 정보를 주변 라우터들과 교환하며 목적지까지의 최적 경로를 도출해낼 수 있다.

### 6. 게이트웨이
#### 개요
- 서로 다른 두 개의 네트워크를 상호 연결하는 장치입니다.
- 필요시 프로토콜을 변환하여 두 네트워크 간의 프로토콜이 달라도 통신할 수 있도록 중개합니다. 

#### 게이트웨이의 특징
- 통신 시의 속도 및 트래픽 제어, 네트워크 주소 반환, 프로토콜 변환 등 단순한 데이터 전송을 넘어 통신환경을 컨트롤합니다.
- 서로 다른 네트워크 전송 방식을 가진 네트워크가 데이터를 송수신할 수 있게 합니다.
- 방화벽(Firewall)이나 프록시 섭(Proxy Server)와 같은 보안 필터링 기능을 제공합니다.
- 목적지의 디바이스에 맞게 패킷 크기나 형식을 자동으로 조정하여 통신을 가능하게 합니다.

#### 게이트웨이의 기능
| 기능 | 설명 | 
| ---- | -------------- | 
| 메시지 포맷 변환 | - 서로 다른 데이터들의 형식을 변환하여 데이터 포맷을 일치시킨다. | 
| 프로토콜 변환 기능 | - 서로 다른 프로토콜을 변환하여 통신이 가능하게 한다. <br> - 패킷 내에서 제어 정보를 변환하여 에러 제어, 데이터 흐름 제어 등에 활용한다. | 
| 주소 변환 기능 | - 서로 다른 네트워크나 주소의 구조를 변환한다. | 
| 패킷 크기 조절 기능 | - 목적지의 디바이스가 수용하는 데이터 용량에 맞게 패킷의 사이즈나 형식을 자동으로 조정한다. | 
| 방화벽 | 필터링 등 방화벽 역할을 한다. | 
| 프록시 서버 | 실제 정보를 제공하는 서버를 대신하여 다른 네트워크로 접근한다. |
