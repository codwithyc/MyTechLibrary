## 009. 파일 탐색기의 구성 요소

### 1. 파일 탐색기 창의 구성

파일 탐색기 창은 크게 다음과 같은 영역으로 구성됩니다.

**빠른 실행 도구 모음 → 리본 메뉴 → 주소 표시줄 → 검색 상자 → 탐색 창 → 파일 목록 창 → 미리 보기/자세히 창 → 상태 표시줄**

---

### 2. 각 구성 요소의 기능

| 구성 요소 | 기능 |
| --- | --- |
| 빠른 실행 도구 모음 | 자주 사용하는 명령을 등록해 두고 클릭 한 번으로 실행합니다. |
| 리본 메뉴 | [파일], [홈], [공유], [보기] 탭으로 구성되며, `Ctrl` + `F1`로 표시/숨기기를 전환합니다. |
| 뒤로 / 앞으로 / 위로 | 이전 위치, 다음 위치, 상위 폴더로 이동합니다. |
| 주소 표시줄 | 현재 위치의 경로를 표시하며, 경로를 직접 입력하여 이동할 수 있습니다. |
| 검색 상자 | 현재 폴더와 하위 폴더에서 항목을 검색합니다. |
| 탐색 창(왼쪽) | 즐겨찾기, OneDrive, 내 PC, 네트워크 등을 계층 구조로 표시합니다. |
| 파일 목록 창(오른쪽) | 탐색 창에서 선택한 위치의 하위 폴더와 파일을 표시합니다. |
| 미리 보기 창 | 선택한 파일의 내용을 실행하지 않고 미리 확인합니다. |
| 자세히 창 | 선택한 파일의 속성 정보(크기, 수정한 날짜, 만든 이 등)를 표시합니다. |
| 상태 표시줄 | 항목 개수, 선택한 항목 수, 용량 등을 표시하며 보기 형식 전환 단추가 있습니다. |

#### 왜 창이 좌우로 나뉘어 있을까?

폴더를 탐색할 때는 두 가지 정보가 동시에 필요합니다.

- **지금 어디에 있는가**(전체 구조 속에서의 위치)
- **여기에 무엇이 있는가**(해당 폴더의 내용)

왼쪽 탐색 창은 전체 구조를, 오른쪽 파일 목록 창은 현재 위치의 내용을 보여 줍니다.

즉, 좌우 분할은  
**위치 파악과 내용 확인을 동시에 하기 위한 구조**입니다.

---

### 3. 미리 보기 창과 자세히 창

| 구분 | 미리 보기 창 | 자세히 창 |
| --- | --- | --- |
| 표시 내용 | 파일의 실제 내용 | 파일의 속성 정보 |
| 위치 | 창 오른쪽 | 창 오른쪽 |
| 동시 표시 | 두 창은 **동시에 표시할 수 없습니다.** | |

#### 왜 미리 보기 창이 필요할까?

파일 이름만으로는 내용을 확신하기 어렵습니다.  
그렇다고 확인할 때마다 프로그램을 실행하면 시간이 오래 걸립니다.

미리 보기 창은 **프로그램을 실행하지 않고도 내용을 확인**할 수 있게 해 주므로,  
여러 파일 중 필요한 것을 빠르게 골라낼 수 있습니다.

---

### 4. 탐색 창의 항목

| 항목 | 내용 |
| --- | --- |
| 즐겨찾기 / 바로 가기 | 자주 사용하는 폴더를 고정해 둡니다. |
| OneDrive | 클라우드 저장소의 파일을 표시합니다. |
| 내 PC | 3D 개체, 다운로드, 동영상, 문서, 바탕 화면, 사진, 음악 및 드라이브를 표시합니다. |
| 네트워크 | 네트워크에 연결된 다른 컴퓨터와 공유 자원을 표시합니다. |

- [보기] 탭 → [탐색 창]에서 **모든 폴더 표시**, **확장하여 폴더 열기** 등을 설정할 수 있습니다.

---

### 5. 주소 표시줄

- 현재 폴더의 경로가 **`>` 로 구분된 단추 형태**로 표시됩니다.
- 각 단추를 클릭하면 해당 위치로 바로 이동합니다.
- 빈 공간을 클릭하면 **일반 경로 문자열(예: `C:\Users\Public`)** 로 바뀌어 직접 입력할 수 있습니다.
- 웹 주소를 입력하면 기본 웹 브라우저가 실행됩니다.

#### 왜 주소 표시줄을 단추 형태로 만들었을까?

기존의 문자열 경로는 상위 폴더로 가려면 경로를 직접 지우고 다시 입력해야 했습니다.

단추 형태로 만들면 **경로의 중간 단계를 클릭 한 번으로 이동**할 수 있습니다.  
즉, 경로 자체가 이동 수단이 되는 방식입니다.

---

### 한 줄 정리

파일 탐색기는 **왼쪽 탐색 창(위치)과 오른쪽 파일 목록 창(내용)** 으로 나뉘며,  
**미리 보기 창과 자세히 창은 동시에 표시할 수 없고**,  
주소 표시줄은 단추 형태와 경로 문자열 형태를 모두 지원합니다.
