## 025. 설정 창의 장치 / 시간 및 언어

### 1. 장치 - Bluetooth 및 기타 디바이스

- Bluetooth 장치, 무선 디스플레이, 도크 등을 **추가·제거**합니다.
- 연결된 마우스, 키보드, 오디오 장치 등의 목록을 확인할 수 있습니다.

---

### 2. 장치 - 프린터 및 스캐너

| 항목 | 설명 |
| --- | --- |
| 프린터 또는 스캐너 추가 | 새 프린터를 검색하여 설치합니다. |
| 기본 프린터 | 인쇄 명령 시 자동으로 선택되는 프린터를 지정합니다. |
| Windows에서 기본 프린터 관리 | 체크하면 **가장 최근에 사용한 프린터가 자동으로 기본 프린터**가 됩니다. |

---

### 3. 장치 - 마우스

| 항목 | 설명 |
| --- | --- |
| 기본 단추 선택 | 왼쪽 / 오른쪽 단추 중 주 단추를 지정합니다. |
| 커서 속도 | 마우스 포인터의 이동 속도를 조절합니다. |
| 마우스 휠을 굴리면 스크롤할 양 | 한 번에 여러 줄 / 한 화면씩 스크롤하도록 지정합니다. |
| 추가 마우스 옵션 | 두 번 클릭 속도, 포인터 모양, 휠 설정 등 세부 항목을 지정합니다. |

#### 왜 왼손잡이용 단추 전환 기능이 있을까?

마우스는 기본적으로 **오른손 사용을 전제로 설계**되어 있습니다.

왼손으로 마우스를 잡으면 검지가 오른쪽 단추 위에 놓이므로,  
기본 단추를 오른쪽으로 바꾸면 **오른손 사용자와 동일한 조작감**을 얻을 수 있습니다.

---

### 4. 장치 - 입력 / 펜 및 Windows Ink / 자동 실행 / USB

| 항목 | 설명 |
| --- | --- |
| 입력 | 입력하는 동안 맞춤법 검사, 텍스트 제안 등을 설정합니다. |
| 펜 및 Windows Ink | 펜 입력 방식과 필기 관련 기능을 설정합니다. |
| **자동 실행** | USB 메모리, CD/DVD, 메모리 카드 등을 연결했을 때 **자동으로 수행할 동작**을 지정합니다. |
| USB | USB 연결 알림 표시 여부를 지정합니다. |

#### 왜 자동 실행 기능을 꺼 두는 것이 안전할까?

자동 실행은 저장 매체를 연결하자마자 **그 안의 프로그램이 실행되도록** 하는 기능입니다.

이 특성은 편리하지만, **USB를 통해 퍼지는 악성 코드**에게도 좋은 통로가 됩니다.  
사용자가 아무것도 클릭하지 않아도 감염될 수 있기 때문입니다.

그래서 보안을 위해서는 자동 실행을 끄고,  
**직접 폴더를 열어 확인한 뒤 실행**하는 것이 안전합니다.

### 5. 시간 및 언어 - 날짜 및 시간

| 항목 | 설명 |
| --- | --- |
| 자동으로 시간 설정 | 인터넷 시간 서버와 동기화하여 시간을 자동으로 맞춥니다. |
| 표준 시간대 자동 설정 | 위치를 기준으로 표준 시간대를 자동 지정합니다. |
| 날짜 및 시간 수동 변경 | 자동 설정을 끈 경우 직접 변경합니다. |
| 다른 표준 시간대의 시계 추가 | 최대 **2개**의 시계를 추가로 표시할 수 있습니다. |

#### 왜 시간을 인터넷 서버와 맞출까?

컴퓨터 내부의 시계는 아주 조금씩 오차가 쌓입니다.

시간이 어긋나면

- 예약 작업이 잘못된 시각에 실행되고
- 보안 인증서 검증에 실패하며
- 파일의 수정 시각이 뒤죽박죽이 됩니다.

그래서 **표준 시간 서버(NTP)와 주기적으로 동기화**하여 오차를 바로잡습니다.

### 6. 시간 및 언어 - 지역 / 언어

| 항목 | 설명 |
| --- | --- |
| 국가 또는 지역 | 국가를 지정하면 해당 지역에 맞는 콘텐츠가 제공됩니다. |
| 국가별 표시 형식 | 날짜, 시간, 통화, 숫자의 표시 형식을 지정합니다. |
| **Windows 표시 언어** | 메뉴, 대화 상자 등 Windows 화면에 표시할 언어를 선택합니다. |
| 기본 설정 언어 추가 | 사용할 언어와 키보드 입력기를 추가합니다. |

- 언어를 여러 개 추가한 경우 **`⊞` + `Space Bar`** 로 입력 언어를 전환할 수 있습니다.

#### 왜 "표시 형식"을 지역별로 다르게 둘까?

같은 날짜라도 나라마다 표기 방식이 다릅니다.

- 한국 : 2026-01-06
- 미국 : 1/6/2026
- 유럽 : 06/01/2026

형식이 통일되어 있지 않으면 **1월 6일과 6월 1일을 혼동**할 수 있습니다.

지역 설정은 이런 표기 규칙을 **사용자가 익숙한 방식으로 통일**해 줍니다.
