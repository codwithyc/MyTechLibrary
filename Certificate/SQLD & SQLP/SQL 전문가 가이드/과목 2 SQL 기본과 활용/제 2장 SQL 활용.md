## 제1절 서브 쿼리

* 서브 쿼리는 **SQL 문 안에 들어가는 또 다른 SQL 문**이다.
* 쉽게 말하면 **“먼저 안쪽 SQL로 값을 구하고, 그 결과를 바깥 SQL에서 사용한다”**라고 이해하면 된다.
* 서브 쿼리는 `SELECT`, `FROM`, `WHERE`, `HAVING` 절 등 여러 위치에서 사용할 수 있다.
* 결과가 한 행이면 **단일행 서브 쿼리**, 여러 행이면 **다중행 서브 쿼리**라고 한다.
* 단일행 서브 쿼리는 `=`, `>`, `<`, `>=`, `<=`, `<>` 같은 연산자를 주로 사용한다.
* 다중행 서브 쿼리는 `IN`, `ANY`, `ALL`, `EXISTS` 등을 사용한다.
* `IN`은 **여러 값 중 하나와 같으면 참**이다.
* `EXISTS`는 **서브 쿼리 결과가 존재하는지만 확인**한다.
* `NOT EXISTS`는 **서브 쿼리 결과가 하나도 없을 때 참**이다.
* `> ANY`는 서브 쿼리 값 중 하나보다만 크면 되고, 쉽게는 **최솟값보다 크다**고 이해하면 된다.
* `> ALL`은 모든 값보다 커야 하므로 **최댓값보다 크다**고 이해하면 된다.
* `< ANY`는 쉽게 **최댓값보다 작다**, `< ALL`은 **최솟값보다 작다**고 이해하면 된다.
* 여러 칼럼을 함께 비교하는 서브 쿼리는 **다중 칼럼 서브 쿼리**라고 한다.
* 상관 서브 쿼리는 바깥 쿼리의 값을 안쪽 쿼리가 참조하는 형태로, 바깥 행과 연결해서 처리한다.

## 제2절 집합 연산자

* 집합 연산자는 **여러 SELECT 결과를 위아래로 합치는 기능**이다.
* `UNION`은 두 결과를 합치고 **중복을 제거**한다.
* `UNION ALL`은 두 결과를 합치되 **중복도 그대로 유지**한다.
* `INTERSECT`는 두 결과에 **공통으로 존재하는 행만 반환**한다.
* `MINUS`는 첫 번째 SELECT에는 있고 두 번째 SELECT에는 없는 행을 반환한다.
* 집합 연산자를 사용할 때 각 SELECT의 **칼럼 개수와 위치가 맞아야 한다.**
* 대응하는 칼럼의 데이터 타입도 서로 호환 가능해야 한다.
* `UNION`은 중복 제거 작업이 필요하므로 `UNION ALL`보다 추가 작업이 발생할 수 있다.
* 쉽게 외우면 `UNION = 합치고 중복 제거`, `UNION ALL = 그냥 합치기`, `INTERSECT = 공통`, `MINUS = 앞에서 뒤 빼기`다.

## 제3절 그룹 함수

* 그룹 함수는 여러 행을 묶어서 **소계, 합계 같은 집계 결과를 만드는 기능**이다.
* `ROLLUP`은 계층적으로 소계와 전체 합계를 만든다.
* `ROLLUP(A, B)`는 `(A,B) → (A) → ()` 순서로 집계한다고 이해하면 된다.
* `()`는 아무 칼럼으로도 그룹핑하지 않는 **전체 총계**를 의미한다.
* `CUBE`는 지정한 칼럼으로 만들 수 있는 **모든 조합의 집계**를 만든다.
* `CUBE(A, B)`는 `(A,B)`, `(A)`, `(B)`, `()`를 모두 만든다.
* `GROUPING SETS`는 필요한 그룹 조합만 직접 선택해서 집계한다.
* `GROUPING SETS((상품ID, 월))`은 **상품ID와 월 조합별 합계**를 의미한다.
* `GROUPING SETS((상품ID), (월))`은 **상품별 합계와 월별 합계**를 각각 만든다.
* `GROUPING()`은 NULL이 원래 데이터의 NULL인지 집계 때문에 생긴 NULL인지 구분한다.
* `GROUPING(칼럼) = 0`이면 일반 데이터, `1`이면 ROLLUP/CUBE가 만든 집계 행이다.
* 쉽게 외우면 `ROLLUP = 계층 합계`, `CUBE = 모든 조합`, `GROUPING SETS = 원하는 것만`이다.

## 제4절 윈도우 함수

* 윈도우 함수는 **행 수를 줄이지 않고 각 행 옆에 계산 결과를 붙이는 함수**다.
* `GROUP BY`는 여러 행을 한 그룹으로 줄이지만, 윈도우 함수는 원래 행을 그대로 유지한다.
* 기본 형태는 `함수() OVER (...)`이다.
* `PARTITION BY`는 **같은 그룹으로 나눠 계산**하는 기능이다.
* `ORDER BY`는 파티션 안에서 **계산 순서를 정한다.**
* `SUM(급여) OVER(PARTITION BY 부서)`는 각 사원 행을 유지하면서 부서 총급여를 같이 보여준다.
* `RANK`는 공동순위가 있으면 다음 순위를 건너뛴다. 예: `1, 2, 2, 4`.
* `DENSE_RANK`는 공동순위가 있어도 다음 순위를 이어간다. 예: `1, 2, 2, 3`.
* `ROW_NUMBER`는 같은 값이 있어도 각 행에 서로 다른 번호를 부여한다.
* `PERCENT_RANK`는 그룹 안에서 내 순위가 전체 중 어느 위치인지 `0~1` 사이 값으로 나타낸다.
* `CUME_DIST`는 현재 행까지 누적해서 전체의 어느 정도가 왔는지 나타낸다.
* `NTILE(N)`은 정렬된 행을 N개의 비슷한 크기 그룹으로 나눈다.
* 쉽게 외우면 `RANK = 순위 건너뜀`, `DENSE_RANK = 순위 이어감`, `ROW_NUMBER = 무조건 번호`다.

## 제5절 Top N 쿼리

* Top N 쿼리는 **정렬된 결과에서 위쪽 몇 건만 가져오는 것**이다.
* 예를 들어 매출이 가장 높은 상위 10건, 점수가 가장 높은 학생 5명 같은 문제에 사용한다.
* Oracle에서는 전통적으로 `ROWNUM`을 이용해 Top N을 구현할 수 있다.
* `ROWNUM`은 행이 결과로 나오는 과정에서 번호가 붙기 때문에 `ORDER BY`와 함께 사용할 때 순서를 주의해야 한다.
* 제대로 된 Top N을 구하려면 **먼저 정렬하고 그 결과에 ROWNUM을 적용**하는 형태가 필요하다.
* `ROW_NUMBER()`를 이용해서 순위를 만든 뒤 원하는 순위만 조회할 수도 있다.
* 페이징에서는 보통 특정 구간의 행만 가져오도록 `ROWNUM` 또는 `ROW_NUMBER()`를 사용한다.
* 쉽게 말하면 **Top N = 정렬 먼저, 필요한 위쪽 행만 자르기**다.

## 제6절 계층형 질의와 셀프 조인

* 계층형 질의는 **부모-자식 구조를 위아래로 따라가며 조회하는 방식**이다.
* 대표적인 예는 조직도, 메뉴 구조, 게시판 댓글 구조다.
* Oracle에서는 `START WITH`로 시작점을 정한다.
* `CONNECT BY`는 부모와 자식이 어떻게 연결되는지 정의한다.
* `PRIOR`는 이전 단계, 즉 보통 **부모 행의 값**을 의미한다.
* `LEVEL`은 현재 행이 계층에서 몇 번째 깊이인지 나타낸다.
* 루트 행의 `LEVEL`은 1이고 자식으로 내려갈수록 2, 3처럼 증가한다.
* `ORDER SIBLINGS BY`는 같은 부모를 가진 형제 행끼리 정렬하면서 계층 구조는 유지한다.
* 셀프 조인은 **같은 테이블을 자기 자신과 조인**하는 방식이다.
* 예를 들어 사원 테이블에 `사원번호`와 `상사번호`가 같이 있으면 같은 사원 테이블을 두 번 사용해 사원과 상사를 연결할 수 있다.
* 쉽게 외우면 `START WITH = 시작`, `CONNECT BY = 연결`, `PRIOR = 부모`, `LEVEL = 깊이`다.

## 제7절 PIVOT 절과 UNPIVOT 절

* `PIVOT`은 **행으로 있던 값을 칼럼 방향으로 펼치는 기능**이다.
* 쉽게 말하면 세로로 있던 데이터를 가로 표 형태로 바꾸는 것이다.
* 예를 들어 월별 매출 행을 `1월`, `2월`, `3월` 칼럼으로 펼칠 수 있다.
* PIVOT에서는 보통 `SUM`, `COUNT`, `AVG` 같은 집계 함수와 함께 사용한다.
* `UNPIVOT`은 반대로 **여러 칼럼을 여러 행으로 바꾸는 기능**이다.
* 쉽게 말하면 가로로 펼쳐진 데이터를 다시 세로로 세우는 것이다.
* `PIVOT = 행 → 칼럼`, `UNPIVOT = 칼럼 → 행`이라고 기억하면 된다.

## 제8절 정규 표현식

* 정규 표현식은 문자열에서 **특정한 문자 패턴을 찾거나 검사하는 방법**이다.
* `REGEXP_LIKE`는 문자열이 특정 패턴과 일치하는지 확인한다.
* `REGEXP_REPLACE`는 정규식과 일치하는 문자열을 다른 값으로 바꾼다.
* `REGEXP_SUBSTR`은 정규식과 일치하는 문자열 일부를 추출한다.
* `REGEXP_INSTR`은 정규식과 일치하는 문자열의 위치를 찾는다.
* `.`은 보통 임의의 한 문자를 의미한다.
* `^`는 문자열의 시작, `$`는 문자열의 끝을 의미한다.
* `*`는 앞의 패턴이 0번 이상, `+`는 1번 이상 반복되는 것을 의미한다.
* `[0-9]`는 숫자 한 자리, `[A-Za-z]`는 영문자 한 자리를 의미하는 식으로 사용할 수 있다.
* 쉽게 말하면 정규 표현식은 **“문자열에서 이런 모양을 찾아줘”**라고 요청하는 규칙이다.

## 장 요약

* 서브 쿼리 → SQL 안의 SQL
* 단일행 → `=`, `>`, `<`
* 다중행 → `IN`, `ANY`, `ALL`, `EXISTS`
* `UNION` → 합치고 중복 제거
* `UNION ALL` → 그대로 합치기
* `INTERSECT` → 공통
* `MINUS` → 앞에서 뒤 빼기
* `ROLLUP` → 계층적 소계 + 총계
* `CUBE` → 모든 조합 집계
* `GROUPING SETS` → 원하는 그룹만
* `GROUPING() 0` → 실제 행
* `GROUPING() 1` → 집계 행
* 윈도우 함수 → 행 유지 + 계산값 추가
* `RANK` → 공동순위 후 건너뜀
* `DENSE_RANK` → 공동순위 후 이어감
* `ROW_NUMBER` → 각 행 고유 번호
* Top N → 정렬 후 위쪽 N건
* `START WITH` → 계층 시작
* `CONNECT BY` → 부모-자식 연결
* `PRIOR` → 부모
* `LEVEL` → 깊이
* `PIVOT` → 행을 칼럼으로
* `UNPIVOT` → 칼럼을 행으로
* 정규 표현식 → 문자열 패턴 검색/변환
