## 026. 하드웨어 추가/제거 / 장치 관리자

### 1. 하드웨어 추가

새로운 하드웨어를 컴퓨터에 연결하고 사용할 수 있도록 설정하는 과정입니다.

- **PnP(Plug and Play)를 지원하는 장치**는 연결하면 운영체제가 자동으로 인식하여 드라이버를 설치합니다.
- PnP를 지원하지 않는 장치는 [제어판] → [장치 및 프린터] → [장치 추가]에서 직접 설치합니다.

#### 왜 "장치 드라이버"가 필요할까?

하드웨어는 제조사마다 동작 방식과 명령 체계가 다릅니다.  
운영체제가 세상의 모든 장치를 미리 알고 있을 수는 없습니다.

장치 드라이버는 **운영체제의 일반적인 명령을, 특정 하드웨어가 알아들을 수 있는 신호로 바꿔 주는 프로그램**입니다.

즉, 드라이버는  
**운영체제와 하드웨어 사이의 통역사**라고 이해하면 됩니다.

그래서 드라이버가 없거나 잘못된 버전이면, 장치는 연결되어 있어도 동작하지 않습니다.

---

### 2. 하드웨어 제거

- USB 메모리, 외장 하드 같은 이동식 장치는 **알림 영역의 [하드웨어 안전하게 제거] 아이콘**을 이용해 제거합니다.
- 내부 장치는 전원을 끄고 물리적으로 분리한 뒤, 필요하면 장치 관리자에서 드라이버를 제거합니다.

#### 왜 USB를 "안전하게 제거"해야 할까?

운영체제는 성능을 높이기 위해 **쓰기 작업을 모아 두었다가 한꺼번에 처리(캐시)** 합니다.

복사가 끝난 것처럼 보여도, 실제로는 아직 기록이 완료되지 않았을 수 있습니다.

'안전하게 제거'는 **남아 있는 작업을 모두 기록한 뒤 연결을 끊도록** 하는 절차이므로,  
이를 생략하면 **파일 손상이나 저장 매체 오류**가 발생할 수 있습니다.

---

### 3. 장치 관리자

컴퓨터에 설치된 **모든 하드웨어의 목록을 확인하고 드라이버를 관리**하는 도구입니다.

- 실행 방법
  - `⊞` + `X` → [장치 관리자]
  - [제어판] → [장치 관리자]
  - [설정] → [시스템] → [정보] → [장치 관리자]

| 기능 | 설명 |
| --- | --- |
| 드라이버 업데이트 | 최신 드라이버를 검색하여 설치합니다. |
| 디바이스 사용 안 함 | 장치를 물리적으로 제거하지 않고 일시적으로 비활성화합니다. |
| 디바이스 제거 | 장치와 드라이버를 시스템에서 제거합니다. |
| 하드웨어 변경 사항 검색 | 새로 연결된 장치를 다시 검색합니다. |
| 속성 | 장치 상태, 드라이버 정보, 리소스(IRQ, DMA, 메모리 주소)를 확인합니다. |

---

### 4. 장치 관리자의 아이콘 표시

| 표시 | 의미 |
| --- | --- |
| **노란색 느낌표(!)** | 장치에 문제가 있거나 드라이버가 올바르게 설치되지 않았습니다. |
| **아래쪽 화살표(↓)** | 장치가 **사용 안 함** 상태입니다. |
| **물음표(?)** | 알 수 없는 장치로, 드라이버가 설치되지 않았습니다. |

#### 왜 "사용 안 함" 기능이 필요할까?

장치를 물리적으로 분리하지 않고도 **잠시 동작을 멈추게 하고 싶은 경우**가 있습니다.

- 노트북의 내장 카메라를 보안상 꺼 두고 싶을 때
- 어떤 장치가 문제를 일으키는지 하나씩 확인하며 원인을 찾을 때

'사용 안 함'은 하드웨어를 그대로 둔 채 **소프트웨어적으로만 비활성화**하는 방법입니다.

---

### 5. 시스템 자원(리소스)

하드웨어가 정상적으로 동작하려면 다음과 같은 자원이 **서로 겹치지 않게** 할당되어야 합니다.

| 자원 | 설명 |
| --- | --- |
| **IRQ(인터럽트 요청)** | 장치가 CPU에게 처리를 요청할 때 사용하는 번호입니다. |
| **DMA 채널** | CPU를 거치지 않고 메모리와 직접 데이터를 주고받을 때 사용하는 통로입니다. |
| **입출력 주소(I/O)** | 장치와 데이터를 주고받기 위한 주소입니다. |
| **메모리 주소** | 장치가 사용하는 메모리 영역입니다. |

#### 왜 자원이 겹치면 안 될까?

두 장치가 같은 IRQ 번호를 사용하면,  
CPU는 **어느 장치가 요청을 보냈는지 구분할 수 없습니다.**

그 결과 장치가 동작하지 않거나 시스템이 불안정해집니다.

PnP는 이런 자원 할당을 **운영체제가 자동으로 조정**해 주므로,  
과거처럼 사용자가 직접 번호를 지정하지 않아도 됩니다.

---

### 한 줄 정리

장치 관리자는 **하드웨어 목록과 드라이버를 관리하는 도구**이며,  
**노란색 느낌표는 문제 발생, 아래쪽 화살표는 사용 안 함**을 뜻하고,  
IRQ·DMA 등의 시스템 자원이 겹치지 않아야 장치가 정상 동작합니다.
