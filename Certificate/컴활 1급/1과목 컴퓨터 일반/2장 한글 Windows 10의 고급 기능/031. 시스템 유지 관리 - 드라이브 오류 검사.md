## 031. 시스템 유지 관리 - 드라이브 오류 검사

### 1. 드라이브 오류 검사의 개요

드라이브 오류 검사는 **디스크의 논리적·물리적 오류를 찾아 수정**하는 기능입니다.

- 실행 방법 : 드라이브 바로 가기 메뉴 → [속성] → [도구] 탭 → [오류 검사] → [검사]
- 명령 프롬프트에서는 **`chkdsk`** 명령으로 실행합니다.

#### 왜 디스크에 오류가 생길까?

파일을 저장하는 도중에

- 갑자기 전원이 꺼지거나
- 프로그램이 비정상 종료되거나
- USB를 안전하게 제거하지 않고 뽑으면

**"데이터는 기록했지만 관리 정보는 갱신되지 않은"** 어중간한 상태가 남을 수 있습니다.

이런 상태가 쌓이면 파일이 열리지 않거나 디스크 용량이 이상하게 표시됩니다.

---

### 2. 오류의 종류

| 구분 | 설명 |
| --- | --- |
| **논리적 오류** | 파일 시스템의 관리 정보가 어긋난 상태입니다. (교차 연결, 잃어버린 클러스터 등) → **복구 가능** |
| **물리적 오류** | 디스크 표면이 손상되어 데이터를 읽을 수 없는 상태입니다. (배드 섹터) → **해당 영역을 사용하지 않도록 표시** |

**주요 논리 오류**

| 용어 | 설명 |
| --- | --- |
| 잃어버린 클러스터(Lost Cluster) | 어떤 파일에도 속하지 않은 채 사용 중으로 표시된 클러스터입니다. |
| 교차 연결(Cross-linked) | 두 개 이상의 파일이 같은 클러스터를 사용한다고 기록된 상태입니다. |
| 배드 섹터(Bad Sector) | 물리적으로 손상되어 읽고 쓸 수 없는 영역입니다. |

#### 왜 배드 섹터는 "고치는" 것이 아니라 "표시"할까?

배드 섹터는 디스크 표면 자체가 손상된 것이므로, **소프트웨어로 되돌릴 수 없습니다.**

대신 오류 검사는 그 영역을 **"사용 금지" 목록에 등록**하여,  
앞으로 그 자리에는 데이터를 저장하지 않게 합니다.

즉, 배드 섹터 처리는 **치료가 아니라 회피**입니다.

> 배드 섹터가 계속 늘어난다면 디스크 수명이 다해 가는 신호이므로, **백업 후 교체**를 고려해야 합니다.

---

### 3. 오류 검사의 특징

- 검사할 수 있는 대상 : **하드디스크, SSD, USB 메모리, 메모리 카드**
- 검사할 수 **없는** 대상 : **CD-ROM / DVD-ROM 드라이브, 네트워크 드라이브**
- 검사 중에는 해당 드라이브를 사용할 수 없습니다.
- 시스템 드라이브(C:)를 검사할 때는 **다시 시작 후 검사**가 진행되는 경우가 많습니다.

#### 왜 시스템 드라이브는 재부팅해야 검사할 수 있을까?

Windows가 실행되는 동안 시스템 드라이브의 파일은 **계속 사용되고 있습니다.**

사용 중인 파일을 검사·수정하면 오히려 시스템이 불안정해지므로,  
**Windows가 완전히 올라오기 전 단계에서 검사를 수행**합니다.

---

### 4. 시스템 복원

시스템 복원은 **시스템 파일과 레지스트리를 이전 시점(복원 지점)의 상태로 되돌리는 기능**입니다.

- 실행 방법 : [설정] → [시스템] → [정보] → [시스템 보호] → [시스템 복원]
- **개인 파일(문서, 사진 등)은 삭제되지 않습니다.**
- 복원 지점은 다음 상황에서 자동으로 생성됩니다.
  - 프로그램이나 드라이버 설치 전
  - Windows 업데이트 전
  - 사용자가 직접 생성한 경우
- 복원 후에도 다시 **이전 상태로 되돌릴 수 있습니다.**

#### 왜 복원 지점을 "미리" 만들어 둘까?

문제는 대부분 **무언가를 설치하거나 변경한 직후**에 발생합니다.

복원 지점은 그 변경 **직전의 상태를 저장해 두는 스냅샷**이므로,  
문제가 생기면 변경 이전으로 되돌릴 수 있습니다.

즉, 복원 지점은  
**"되돌릴 수 있는 지점"을 미리 확보해 두는 안전장치**입니다.

---

### 5. 시스템 이미지 / 백업

| 기능 | 설명 |
| --- | --- |
| 시스템 이미지 만들기 | 드라이브 전체를 하나의 이미지 파일로 만들어 두고, 필요할 때 통째로 복원합니다. |
| 파일 히스토리 | 지정한 폴더의 파일을 주기적으로 백업하여 이전 버전으로 되돌립니다. |
| 이 PC 초기화 | Windows를 다시 설치합니다. ('내 파일 유지' / '모든 항목 제거' 선택 가능) |

#### 시스템 복원 vs 시스템 이미지 복원

| 구분 | 시스템 복원 | 시스템 이미지 복원 |
| --- | --- | --- |
| 대상 | 시스템 파일 + 레지스트리 | **드라이브 전체** |
| 개인 파일 | 유지됨 | **이미지 시점의 상태로 덮어씀** |
| 용도 | 가벼운 문제 해결 | 심각한 손상, 디스크 교체 |

---

### 한 줄 정리

드라이브 오류 검사는 **논리 오류는 복구하고 물리 오류(배드 섹터)는 사용하지 않도록 표시**하며,  
**CD-ROM과 네트워크 드라이브는 검사할 수 없고**,  
시스템 복원은 **시스템 영역만 되돌리고 개인 파일은 유지**합니다.
