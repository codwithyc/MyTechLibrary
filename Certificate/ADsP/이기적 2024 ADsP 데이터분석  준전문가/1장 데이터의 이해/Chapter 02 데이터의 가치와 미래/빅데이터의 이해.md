## 빅데이터의 이해
### 01. 빅데이터(Big Data)
- 빅데이터는 기존의 일반적인 소프트웨어로는 수집, 저장 분석이 어려운 규모의 데이터로 정형과 비정형 데이터로 나뉘어지며,  
대용량 데이터를 활용해 새로운 가치나 인사이트를 추출할 수 있습니다. 또한 이를 활용해 시장, 기업 및 시민과 정보의 관계 등 많은 분야에 변화를 가져옵니다.
- 빅데이터는 데이터 처리, 저장, 분석기술 및 아키텍쳐 클라우드 컴퓨팅의 활용, 저장장치의 가격하락 등을 포함하는 개념입니다.
- 빅데이터는 다양한 종류의 대규모 데이터로부터 저렵함 비용으로 가치를 추출하고 데이터의 초고속 수집, 발굴, 분석을 지원하도록 고안된  
차세대 기술 및 아키텍쳐입니다. 
- 빅데이터는 비즈니스 측면에서는 '공통 활용의 목적으로 구축된 유무형의 구조물'을 의미합니다.

#### 빅데이터 비유
| 비유 | 예상 | 
| --- | ------------ | 
| 산업혁명의 석탄, 철 | 제조업 뿐만 아니라 서비스 분야 생상성도 획기적으로 끌어올릴 것 | 
| 21세기의 원유 | 경제 성장에 필요한 정보를 제공함으로써 산업 전반의 생산성을 향상 | 
| 렌즈 | 현미경이 생물학 발전에 영향을 미쳤던 만큼 데이터가 산업 발전에 영향을 미칠 것 | 
| 플랫폼 | - 공동 활용의 목적으로 구축된 유무형의 구조물로써 다양한 서드 파티 비즈니스에 활용될 것 <br> - 하둡은 대규모 분산 병렬처리의 업계 표준으로 맵리듀스 시스템과 분산 파일 시스템인 HDFS로 구성된 플랫폼 기술이며, <br> 아마존은 S3와 B2C 환경을 제공함으로써 플랫폼을 위한 클라우드 서비스 최초 실현

### 02. 빅데이터 특성 
빅데이터는 과거에는 구조적인 데이터 형태였으며, 최근들어 데이터는 다양하고 복잡한 구조를 띄며, 소셜 데이터, 센서 기반의 사물인터넷(IoT) 등  
실시간 데이터로 변화하고 있다. 빅데이터의 특징은 3V, 4V, 5V, 7V로 분류할 수 있다.

- 3V : 데이터 양(Volume), 데이터 유형 및 다양성(Variety), 데이터 처리 속도(Velocity)
- 4V : 3V + 데이터 가치 (Value)
- 5V : 4V + 데이터 신뢰성 (Veracity)
- 7V : 5V + 데이터 정확성 (Validity) + 데이터 휘발성 (Volatility)

#### 빅데이터 특성 (7V)
| 종류 | 설명 | 
| --- | ----------------------- | 
| 데이터 규모 <br> (Volume) | - 디지털 정보량이 기하급수적으로 생성 <br> - IoT 센싱 데이터 및 비정형 등 정보기술의 발전과 함께 <br> 데이터 규모가 테라바이트에서 페타/제타 바이트 시대로 진입 |
| 데이터의 다양성 <br> (Variety) | - 데이터베이스의 정형 데이터뿐만 아니라 텍스트, 비디오, 오디오와 같은 비정형 데이터가 증가 <br> - 시스템 로그, 위치 정보, 소셜 데이터 등 데이터의 종류가 다양해짐 |
| 데이터 속도 <br> (Velocity) | - 대규모 데이터 수집 및 처리 측면에서 데이터 추출 및 분석 속도 증가 <br> - 사용자에게 빠른 시간내에 데이터를 분석하여 결과를 제공 <br> - 데이터의 속도, 사용자가 원하는 시간 내 데이터 분석 결과 제공, 업데이트 속도가 빨라짐 |
| 데이터 가치 <br> (Value) | 빅데이터는 사용자에게 새로운 가치나 통찰을 추출해 낼 수 있어야 합니다 | 
| 데이터 신뢰성 <br> (Veracity) | - 수집 데이터에 대한 신뢰도에 관련된 특징 <br> - 데이터 전처리 과정에서 노이즈 등을 제거하여 데이터에 대한 신뢰도를 높일 수 있습니다. |
| 데이터 정확성 <br> (Validity) | - 수집 데이터에 대한 정확성과 유효성 <br> - 데이터의 규모가 크더라도 데이터의 품질이 높아야 정확한 분석 결과를 도출할 수 있음 |
| 데이터 휘발성 <br> (Volatility) | - 데이터가 수집된 이후로 의미 있게 사용될 수 있는 기간 <br> - 데이터는 장기적인 관점에서 의미있는 가치를 창출할 수 있어야 합니다 |

#### 과거 데이터 와 빅데이터 특징 비교
| 구분 | 과거 데이터 | 빅데이터 |
| --- | -------- | -------- |
| 데이터 규모 | 기가비이트 (Gigabyte GB) | 테라(Terabyte TB), 페타(Petabyte, PB)|
| 데이터 구조 | 정형 데이터 | 비정형 데이터 | 
| 데이터 저장 | 관계 데이터베이스 (RDB) | 분산 데이터베이스 (HDFS, NoSQL) | 
| 데이터 속도 | 시간 또는 일 단위 데이터 | 실시간 데이터 |
