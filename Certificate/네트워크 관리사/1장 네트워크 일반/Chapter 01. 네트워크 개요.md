# 네트워크 개요
## 1.1 정보통신과 네트워크
### 1) 정보통신
1. 정의
    - 데이터(DATA) : 분석이나 참조를 목적으로 수집한 단순한 자료로, 숫자, 문자, 기호 등으로 표현됩니다.
    - 정보(Information) : 특정한 목적을 달성하기 위하여 가공하고 의미를 부여한 데이터입니다.
    - 정보통신의 정의 : 다수의 통신 수단을 활용하여 정보를 필요로 하는 대상과 주고받는 행위입니다.

2. 정보통신의 목표
    - 정확 : 통신 도중 신호의 세기가 약해지거나 외부의 영향을 받아 변형되거나 손실되지 않아야 합니다.
    - 효율 : 통신에 사용된 장비나 비용 대비 얻는 정보의 가치가 커야 합니다.
    - 보안 : 통신을 통해 주고받는 정보가 타인에게 유출되지 않아야 합니다.

3. 정보통신의 주요 요소
    - 송신자 (Sender) : 정보를 생산하여 보내는 사람이나 장치, 컴퓨터 노드
    - 수신자 (Receiver) : 정보를 받아서 처리하는 사람이나 장치, 컴퓨터 노드
    - 전송매체 (Medium) : 송신자가 수신자에게 정보를 보낼 때 사용하는 물리적 경로 및 수단
    - 프로토콜 (Protocol) : 다수의 송신자와 수신자 사이에서 정보통신을 원할하게 하기 위한 상호 간의 규칙 혹은 약속

### 2) 네트워크
1. 네트워크의 정의
    - 어원 Net(그물, 망) Work(일하다), 그물의 형태로 얽혀 임의의 일을 하는 행위입니다.
    - 정보통신에서 말하는 네트워크의 정의 : 정보의 송신자와 수신자가 통신 기술을 이용하여 서로 소통하는 그물망처럼 연결된 통신망으로,  
    근거리나 원거리 통신을 제공하여 수신자와 송신자 사이에 데이터 등을 전송합니다.

2. 인터넷과 인트라넷의 차이
    - 인터넷 (Inter(~사이의)+Net(그물, 망)) : 망과 망 사이의 통신 (ex., WWW(World Wide Web))

    > 참조 인트라넷 : Intra(~내부의) + Net (그물, 망) : 하나의 망 안에서의 통신, 외부망과 차단되어 군대 회사 등  
    > 특정 단체의 직원만 접근할 수 있는 통신 형태

3. 네트워크 출현
    - 전기, 전자 기술의 발전과 함께 컴퓨터가 발전하고, 컴퓨터 간의 통신을 위하여 네트워크가 발전되었으며,  
    이를 통해 정보 형태가 다양하게 되었습니다.

4. 네트워크의 발전 과정
    - 음성 회선 (전화, 중, 저속 데이터) -> 공중전화 교환망 (PSTN : Public Switched Telephone Network) : 전 세계적으로 연결된 음성 전화망으로,  
    지금은 대부분 디지털 방식으로 전환됨 -> 디지털 전용회선 : 네트워크 망의 일부를 독립적으로 사용 -> 데이터 전용 교환망 -> 종합정보통신망 -> 광대역 종합 통신망

5. 네트워크의 장점
    - 데이터 통신 수단 : 서로 멀리 떨어져 있더라도 데이터를 교환할 수 있습니다.
    - 자원의 공동 소유화 : 데이터를 공유할 수 있고, 커다란 파일을 여러 대의 커퓨터에 분산 보관할 수 있어 한 컴퓨터에 부담되는 가중을 완화할 수 있습니다.
    - 업무 환경의 효율화 : 네트워크 통해 통신이 가능한 어느 장소에서도 근무할 수 있으므로 근무 환경이 유연해집니다.
    - 위험의 분산 : 동일한 기능을 수행하는 여러 대의 컴퓨터가 동일 네트워크에 연결되어 있을 경우, 하나의 컴퓨터가 고장 나더라도 다른 컴퓨터로 기능을  
    대신 수행할 수 있어 위험이 분산된다.

## 1.2 네트워크 토폴로지
### 1) 네트워크 토폴로지의 형태와 특징
- 네트워크는 그 목적과 형태에 따라 여러 가지 모양으로 설계, 구축되는데, 형태에 따른 다양한 설계 방법을 토폴로지(Topology)라고 합니다.
- 각 토폴로지별 특징과 장단점을 이해하면, 목적에 맞게 네트워크를 설계하고 구출할 수 있습니다.

1. 망형 (Mesh Topology)
    - 모든 디바이스들이 점대점으로 연결되었습니다.
    - 하나의 통신 회선이 고장 나더라도 전체 네트워크에는 영향을 미치지 않습니다.
    - 모든 디바이스들을 연결해야 하므로 작업공간이 많이 필요하며, 설치 비용도 많이 듭니다.
    - 메시형이라고도 합니다.

2. 성형 (Star Topology)
    - 각각의 디바이스가 중앙의 시스템(허브)에 점 대 점(Point to Point) 방식으로 연결되어 있습니다.
    - 중앙 제어 노드가 통신 상의 모든 제어를 관리하므로 중앙 제어 노드 작동 불능 시 전체 네트워크가 정지합니다.
    - 망향 토폴로지에 비해 설치 비용이 적게 들고 효율적인 토폴로지이지만, 중앙 시스템이 고장 나면 전체에 영향을  
    미친다는 점에서 견고성이 떨어집니다.
    - 스타형이라고도 부릅니다.

3. 트리형 (Tree Topology)
    - 나무가 가지를 뻗어 나가듯 하나의 디바이스에서 여러 개의 디바이스를 향해 네트워크가 방사형으로 펼쳐지는 형태입니다.
    - 허브만 있다면 많은 네트워크를 한 번에 쉽게 연결할 수 있다는 장점이 있으나, 특정 디바이스가 고장 나면 해당 계층 이하의 디바이스는 작동되지 않는다.

4. 버스형 (Bus Topology)
    - 네트워크상의 모든 디바이스들이 하나의 케이블에 연결되어 있습니다.
    - 구조가 간단하고 설치 비용이 적게 들며, 디바이스의 추가와 삭제가 용이합니다.
    - 회선의 양 끝에 터미널데이터(Terminator)가 시그널의 반사를 방지하기 위해 사용됩니다.
    - 단, 하나의 통신 회선 안에 너무 많은 디바이스가 연결되면 통신 성능이 저하될 수 있으며, 통신 회선이 고장 나면 전체 네트워크에 영향을 미칩니다.

5. 링형 (Ring Topology)
    - 버스 토폴로지와 유사하지만, 양 끝단이 서로 연결되어 있어 링 형태를 이룹니다.
    - 캠퍼스 등 특정 공간 내에서 네트워크를 구축할 때 주로 사용합니다.
    - 장단점은 버스형과 유사합니다.

6. 하이브리드형 (Hybrid Topology)
    - 두 가지 이상의 토폴로지가 혼합되어 있는 네트워크 형태로, 각 토폴로지의 단점을 보안하여 필요에 맞게 구성한 것입니다.

## 1.3 네트워크의 다양한 분류
### 1) 데이터 전송 방식에 따른 분류
데이터 전송 방식에 따라 네트워크를 회선 교환망과 패킷 교환망으로 분류할 수 있습니다.  

1. 회선 교환망 (아날로그 통신)

**회선 교환망의 특징**
- 회선을 독립적으로 사용할 수 있습니다.
- 독립적 회선을 구축해야 하므로 설치 비용이 많이 듭니다.
- 한 회선이 처리할 수 있는 데이터의 양(Bandwidth)가 적고, 전송 효율이 떨어집니다.
- 보안에 강합니다. (군부대에서 보안용으로 사용)
- 데이터를 실시간으로 처리하거나, 대량의 데이터를 전송할 때 적합합니다.
- 한 회선을 지속적으로 점유하므로 네트워크 효율이 떨어집니다.

2. 패킨 교환망 (디지털 통신)
- 모든 컴퓨터가 선으로 이루어져 있고, 선을 뽑거나 교환하지 않은 채로 데이터만 이동하는 통신 형태입니다.
- 데이터를 작은 패킷 단위로 나누어서 목적지까지 전달합니다.
- 패킷 교환망의 선로 위에는 출발지와 목적지가 다른 패킷 여러 개가 동시에 있고, 패킷 안에는 패킷이 도착해야 하는 목적지 주소 정보가 들어있습니다.
- Switch는 어떤 경로로 패킷을 보내는 것이 더 빠른지 판단하여 효율적인 경로로 안내합니다.
- 회선 교환망의 단점을 극복한 통신 방법입니다.

**패킷 교환망의 특징**
- 설치 비용이 적게 듭니다.
- 한 회선이 처리할 수 있는 데이터의 양이 많고, 전송 효율이 좋습니다.
- 하나의 전송로를 여러 패킷이 공유하여 사용할 수 있습니다.

### 2) 통신 방식에 따른 분류
| 구분                | 의미                                        | 전송 대상     | 특징                                     | 예시                    |
| ----------------- | ----------------------------------------- | --------- | -------------------------------------- | --------------------- |
| 유니캐스트(Unicast)    | 하나의 송신자가 하나의 수신자에게 데이터를 전송하는 방식           | 1 : 1     | 가장 일반적인 통신 방식이며, 특정 대상에게만 데이터를 전달함     | 웹 접속, 파일 전송, 이메일 전송   |
| 브로드캐스트(Broadcast) | 하나의 송신자가 같은 네트워크에 있는 모든 장비에게 데이터를 전송하는 방식 | 1 : 전체    | 네트워크 내 모든 장비가 데이터를 수신하므로 트래픽이 증가할 수 있음 | ARP 요청, DHCP Discover |
| 멀티캐스트(Multicast)  | 하나의 송신자가 특정 그룹에 속한 여러 수신자에게 데이터를 전송하는 방식  | 1 : 특정 그룹 | 필요한 그룹에게만 데이터를 보내므로 브로드캐스트보다 효율적임      | IPTV, 화상 회의, 실시간 스트리밍 |

> 한 줄 정리  
> 
> 유니캐스트 = 한 명에게 전송  
> 브로드캐스트 = 모두에게 전송  
> 멀티캐스트 = 특정 그룹에게 전송  

### 3) 규모와 범위에 따른 분류
| 구분                             | 의미                      | 범위             | 특징                                     | 예시                          |
| ------------------------------ | ----------------------- | -------------- | -------------------------------------- | --------------------------- |
| LAN(Local Area Network)        | 가까운 지역 내의 장비들을 연결한 네트워크 | 건물, 사무실, 학교, 집 | 전송 속도가 빠르고 오류율이 낮음. 비교적 작은 범위에서 사용     | 회사 내부망, 학교 전산망, 가정 Wi-Fi    |
| MAN(Metropolitan Area Network) | 도시 규모의 지역을 연결한 네트워크     | 도시, 캠퍼스, 지역 단위 | LAN보다 넓고 WAN보다 좁은 범위. 여러 LAN을 연결할 수 있음 | 도시 내 공공기관 네트워크, 대학 캠퍼스 간 연결 |
| WAN(Wide Area Network)         | 넓은 지역을 연결한 네트워크         | 국가, 대륙, 전 세계   | 범위가 가장 넓고, 통신 사업자의 회선을 이용하는 경우가 많음     | 인터넷, 본사-지사 간 네트워크, 국제망      |


### 4) 전송 매체에 따른 분류
1. 유선 전송 매체
    - 이중 나선 케이블 (Twisted Pair, 꼬임선)
        - 구성 : 플라스틱 절연체로 감싼 가느다란 동선 2개가 꼬여 있는(twisted) 형태로 되어 있으며, 아날로그 전송과 디지털 전송 모두에 사용됩니다.  
        외부 신호의 간섭을 막기 위한 방법에 따라 세 가지로 분류됩니다.
        - 장점 : 저렴하고 대중적입니다.
        - 단점 : 고속 전송에 부적합하며, 외부 신호의 간섭에 상대적으로 민감합니다.
        - 종류 : UTP / FTP / STP
            - UTP (Unshielded Twisted Pair, 보호되지 않은 꼬임선) : 케이블을 나선형으로 꼬아 놓고, 별도의 포일 피복 없이  
            플라스틱 절연체로 감싼 것으로, 외부 신호의 간섭을 막기 위한 특별한 기능은 없지만, **저렴하기 때문에 가장 대중적으로 사용됩니다.**
            - FTP (Foiled Twisted Pair, 포일 피복 처리된 꼬임선) : 외부 신호의 간섭을 막기 위해 전체 케이블에 필복을 씌운 후 플라스틱 절연체로 감쌉니다.
            - STP (Shielded Twisted Pair, 강하게 피복 처리된 꼬임선) : 외부 신호의 간섭을 막기 위하여 각각의 꼬임선에도 피복을 씌운 후  
            플라스틱 절연체로 감쌉니다.

                | ------ | --------------: | -------: | ----: | ---------------------------------- |
                | CAT 3  |          10Mbps |    16MHz |  100m | 음성 통신, 10BASE-T 이더넷에 사용되던 케이블      |
                | CAT 4  |          16Mbps |    20MHz |  100m | 토큰링 네트워크 등에 사용되었으나 현재는 거의 사용하지 않음  |
                | CAT 5  |         100Mbps |   100MHz |  100m | 100BASE-TX 이더넷에 사용되던 케이블           |
                | CAT 5e |           1Gbps |   100MHz |  100m | CAT 5 개선형으로 기가비트 이더넷에서 많이 사용       |
                | CAT 6  |           1Gbps |   250MHz |  100m | 일반적인 기가비트 이더넷 환경에서 사용              |

                | CAT 7a |          10Gbps | 1,000MHz |  100m | CAT 7보다 주파수 대역이 높고 차폐 성능이 강화됨      |
                | CAT 8  | 25Gbps / 40Gbps | 2,000MHz |   30m | 데이터센터 등 짧은 거리의 초고속 네트워크에 사용        |  
                
                > 한 줄 정리
                > 
                > CAT 숫자가 높을수록 일반적으로 전송 속도와 주파수 대역이 높다.
                > 다만 CAT 8은 최대 거리가 30m로 짧고, 주로 데이터센터에서 사용된다.

                > 핵심 암기  
                > 
                > CAT 5e = 1Gbps / 100MHz / 100m
                > CAT 6 = 1Gbps / 250MHz / 100m
                > CAT 6a = 10Gbps / 500MHz / 100m
                > CAT 8 = 25~40Gbps / 2000MHz / 30m

    - 동축 케이블 (Coaxial Cable)
        - 구성 : 중앙에 위치한 와이어와 와이어를 둘러싸는 체폐용 그물망, 총 두 개의 전도체로 구성되어 있습니다. 중앙 와이어와 주변 그물망 사이는 절연체로  
        분리되어 있고 모니터 연결 디자인 DVI 방식과 유사합니다.
        - 장점 : 설치가 용이하며, 이중 나선 케이블형보다 **큰 대역폭을 지원하여 한 번에 더 많은 데이터를 빠르게 전송할 수 있습니다.**
        - 단점 : 대체로 이중 나선 케이블형보다 비쌉니다.
            | 구분       |  전송 속도 |  전송 길이 | 특징                                      |
            | -------- | -----: | -----: | --------------------------------------- |
            | 10BASE-2 | 10Mbps | 약 185m | 얇은 동축 케이블을 사용하며, 설치가 비교적 쉽지만 전송 거리가 짧음  |
            | 10BASE-5 | 10Mbps | 약 500m | 굵은 동축 케이블을 사용하며, 전송 거리가 길지만 설치와 관리가 어려움 |

            > 한 줄 정리  
            >
            > 10BASE-2 = 얇은 동축 케이블, 약 185m  
            > 10BASE-5 = 굵은 동축 케이블, 약 500m  

            | 구분   | 의미       | 예시                   |
            | ---- | -------- | -------------------- |
            | 10   | 전송 속도    | 10Mbps               |
            | BASE | 전송 방식    | 베이스밴드 방식             |
            | 2    | 최대 전송 거리 | 약 200m급, 실제로는 약 185m |
            | 5    | 최대 전송 거리 | 약 500m               |

            > 한 줄 정리  
            > 
            > 10 = 10Mbps  
            > BASE = 베이스밴드  
            > 2/5 = 대략적인 최대 전송 거리
        
        - 이해를 돕는 설명 : 이더넷 구축을 위하여 일반적으로 동축 케이블 혹은 UTP 케이블을 사용하고, 버스형 토폴로지로 구성됩니다.
    - 광섬유 케이블 (Optical Fiver Cable)
        - 구성 : 머리카보다 가느다란 **유리섬유**의 한쪽 끝(송신 측)에서 **주파수 신호를 빛의 펄스로 변환**하여 수신 측에 전달하면 수신기가  
        빛의 펄스를 다시 주파수 신호로 변환합니다. 코어(Core), 클래딩(Cladding), 코팅(Coating)으로 되어 있습니다.
        - 장점
            - 전송하는 빛의 각도를 무한대로 조절하여 한 번에 많은 데이터를 전송할 수 있으며 외부 신호의 간섭을 적게 받습니다.
            - 주파수가 마이크로파보다 수만 배 높은 광파를 사용하므로 매우 많은 정보량(넓은 대역폭)을 장거리 전송할 수 있으며, 전송 손실이 매우 적습니다.
            - 비전도체(유리)이므로 습기에 영향을 받지 않고 타 전자파나 고압선 전류 유도에 대한 방해를 전혀 받지 않아 송신선에 광섬유 케이블을 함께 실어 전송할 수 있습니다.
        - 단점 
            - **단방향**으로만 데이터를 보낼 수 있습니다. **구축 비용이 비싸며**, 설치 방법이 복잡하고 끊어지기 쉽기 때문에 외부에 노출되기보다는  
            매립하여 설치해야 합니다.
2. 무선 전송 매체
    - 공기중으로 전파되는 **전자파를 매개로 하여 데이터를 전송하는 방식**입니다.
    - 전자파 파장 종류 및 주파수 대역에 따라 특징이 달라지므로, 목적에 따른 주파수 범위를 선택하여 사용합니다.


    - 무선 전자파의 종류
        | 구분         |         주파수 범위 |      파장 범위 | 특징                            | 활용 예시                   |
        | ---------- | -------------: | ---------: | ----------------------------- | ----------------------- |
        | 장파(LF)     | 30kHz ~ 300kHz | 10km ~ 1km | 전파 거리가 길고 장애물 회절성이 좋음         | 항법 신호, 해상 통신            |
        | 중파(MF)     |  300kHz ~ 3MHz | 1km ~ 100m | 지표파 전파가 가능하고 비교적 먼 거리 통신 가능   | AM 라디오 방송               |
        | 단파(HF)     |   3MHz ~ 30MHz | 100m ~ 10m | 전리층 반사를 이용해 장거리 통신 가능         | 국제 단파 방송, 항공·선박 통신      |
        | 초단파(VHF)   | 30MHz ~ 300MHz |   10m ~ 1m | 직진성이 강해지고 음성·영상 전송에 적합        | FM 라디오, TV 방송, 무전기      |
        | 극초단파(UHF)  |  300MHz ~ 3GHz |  1m ~ 10cm | 직진성이 강하며 이동통신과 무선 네트워크에 많이 사용 | TV 방송, 휴대전화, Wi-Fi, GPS |
        | 센티미터파(SHF) |   3GHz ~ 30GHz | 10cm ~ 1cm | 대용량 전송에 적합하지만 장애물에 약함         | 위성 통신, 레이더, 5GHz Wi-Fi  |
        | 밀리미터파(EHF) | 30GHz ~ 300GHz |  1cm ~ 1mm | 초고속·대용량 통신 가능, 전파 도달 거리는 짧음   | 5G 밀리미터파, 고해상도 레이더      |

    수신기(안테나)를 통해 방송을 송출하던 아날로그 TV 시절에는, VHF(2 ~ 13) 채널로 신호가 도달하지 않는 지역에 UHF(14 ~ 83) 채널을 통해 신호를 보내  
    TV를 볼 수 있게 하였다.
