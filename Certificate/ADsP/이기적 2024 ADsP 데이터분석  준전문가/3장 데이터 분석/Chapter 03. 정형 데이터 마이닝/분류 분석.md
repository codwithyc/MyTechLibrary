# 분류 분석

분류 분석은 정형 데이터 마이닝에서 가장 중요한 분석 기법 중 하나다.
핵심은 **이미 정답이 있는 데이터를 학습해서, 새로운 데이터가 어떤 범주에 속하는지 예측하는 것**이다.

```markdown id="1bxk3h"
분류 분석 = 정답 라벨이 있는 데이터를 학습하여 새로운 데이터를 미리 정의된 범주로 분류하는 지도 학습 기법
```

예를 들어 고객 데이터에 이미 다음과 같은 정답이 있다고 하자.

| 고객ID | 나이 |   구매금액 | 방문횟수 | 이탈여부 |
| ---- | -: | -----: | ---: | ---- |
| A001 | 25 |  30000 |   10 | 이탈   |
| A002 | 35 | 120000 |   30 | 비이탈  |
| A003 | 42 |  50000 |    5 | 이탈   |

여기서 `이탈여부`가 정답 라벨이다.
분류 분석은 이 데이터를 학습해서 새로운 고객이 들어왔을 때 다음을 예측한다.

```markdown id="8a1v4a"
이 고객은 이탈할 가능성이 높은가?
이 고객은 비이탈 고객인가?
```

즉, 분류 분석은 **과거의 정답이 있는 데이터를 바탕으로 새로운 데이터의 범주를 예측하는 분석**이다.
기존 정리처럼 개념을 먼저 이해하고 표로 압축하는 방식이 시험 직전 복습에 좋다. 

---

# 01. 분류 분석의 개념

## 분류 분석의 정의

**분류 분석(Classification Analysis)**은 데이터가 어떤 범주에 속하는지 예측하는 분석 기법이다.

여기서 범주는 미리 정해져 있어야 한다.

예를 들어 다음과 같은 값들이 분류 분석의 예시가 된다.

```markdown id="6knwut"
이탈 / 비이탈
합격 / 불합격
정상 거래 / 이상 거래
스팸 메일 / 정상 메일
구매 / 미구매
고위험 고객 / 저위험 고객
```

분류 분석은 과거 데이터를 학습해서 새로운 데이터의 결과를 예측한다.

```markdown id="42yt26"
분류 분석은 기존 데이터의 입력 변수와 정답 라벨 사이의 관계를 학습한 뒤,
새로운 데이터가 어떤 범주에 속하는지 예측하는 분석이다.
```

---

## 분류 분석의 구조

분류 분석에서는 보통 다음과 같은 구조를 가진다.

| 구분     | 의미             | 예시                |
| ------ | -------------- | ----------------- |
| 입력 변수  | 예측에 사용하는 변수    | 나이, 구매금액, 방문횟수    |
| 목표 변수  | 예측하려는 정답       | 이탈여부              |
| 학습 데이터 | 정답이 포함된 과거 데이터 | 기존 고객 데이터         |
| 분류 모델  | 범주를 예측하는 분석 모델 | 의사결정나무, 로지스틱 회귀 등 |
| 예측 결과  | 새 데이터의 분류 결과   | 이탈 또는 비이탈         |

시험에서는 입력 변수와 목표 변수를 구분하는 것이 중요하다.

```markdown id="vnpsr6"
입력 변수는 예측에 사용하는 변수이고,
목표 변수는 예측하려는 정답 변수이다.
```

---

# 02. 분류 분석의 목적

분류 분석의 목적은 새로운 데이터가 어떤 범주에 속하는지 예측하는 것이다.

대표적인 목적은 다음과 같다.

| 목적      | 설명                      |
| ------- | ----------------------- |
| 범주 예측   | 새로운 데이터가 어떤 그룹에 속하는지 예측 |
| 위험 판단   | 고객, 거래, 시스템의 위험 여부 판단   |
| 의사결정 지원 | 예측 결과를 바탕으로 업무 판단 지원    |
| 자동 분류   | 대량의 데이터를 자동으로 분류        |
| 타겟팅     | 특정 행동 가능성이 높은 대상을 선별    |

예를 들어 기업에서는 분류 분석을 다음처럼 활용할 수 있다.

```markdown id="xgm4co"
이탈 가능성이 높은 고객을 예측한다.
대출 상환 위험이 높은 고객을 분류한다.
스팸 메일을 자동으로 걸러낸다.
이상 거래 가능성이 높은 결제를 탐지한다.
상품을 구매할 가능성이 높은 고객을 선별한다.
```

시험에서는 이렇게 이해하면 된다.

```markdown id="6wr6aw"
분류 분석의 목적은 정답이 있는 과거 데이터를 이용해 새로운 데이터의 범주를 예측하는 것이다.
```

# 03. 분류 분석과 군집 분석의 차이

분류 분석은 군집 분석과 자주 비교된다.

둘 다 데이터를 그룹으로 나눈다는 점은 같지만, 가장 큰 차이는 **정답 라벨의 존재 여부**다.

| 구분    | 분류 분석            | 군집 분석           |
| ----- | ---------------- | --------------- |
| 학습 유형 | 지도 학습            | 비지도 학습          |
| 정답 라벨 | 있음               | 없음              |
| 목적    | 미리 정해진 범주로 예측    | 유사한 데이터끼리 그룹화   |
| 기준    | 입력 변수와 정답 라벨의 관계 | 데이터 간 유사도 또는 거리 |
| 결과    | 기존 범주 중 하나       | 새롭게 발견된 군집      |
| 예시    | 이탈/비이탈 예측        | 고객 세분화          |

예를 들어 고객 데이터에 이미 `이탈`, `비이탈`이라는 정답이 있으면 분류 분석이다.

반대로 정답 없이 구매 패턴이 비슷한 고객끼리 묶는다면 군집 분석이다.

```markdown id="n5kycg"
분류 분석은 정답 라벨이 있는 지도 학습이고,
군집 분석은 정답 라벨 없이 유사성을 기준으로 그룹을 찾는 비지도 학습이다.
```

# 04. 분류 분석의 주요 절차

분류 분석은 일반적으로 다음 순서로 진행된다.

```markdown id="t17kxq"
데이터 준비 → 학습 데이터와 평가 데이터 분리 → 모델 학습 → 예측 → 성능 평가
```

| 단계     | 설명                       |
| ------ | ------------------------ |
| 데이터 준비 | 결측값, 이상값, 변수 변환 등 전처리 수행 |
| 데이터 분리 | 학습용 데이터와 평가용 데이터를 나눔     |
| 모델 학습  | 정답이 있는 데이터로 분류 규칙 학습     |
| 예측     | 새로운 데이터의 범주 예측           |
| 성능 평가  | 예측 결과가 얼마나 정확한지 평가       |

---

## 1) 데이터 준비

분류 분석을 하기 전에는 데이터를 분석 가능한 형태로 정리해야 한다.

대표적인 작업은 다음과 같다.

```markdown id="l43y5d"
결측값 처리
이상값 확인
범주형 변수 변환
불필요한 변수 제거
입력 변수와 목표 변수 구분
```

분류 분석은 목표 변수가 있어야 한다.
예를 들어 이탈 여부를 예측하려면 과거 데이터에 `이탈`, `비이탈` 같은 정답이 있어야 한다.

```markdown id="ehs5i0"
분류 분석에서는 예측하려는 목표 변수가 명확해야 한다.
```

---

## 2) 학습 데이터와 평가 데이터 분리

분류 모델을 만들 때는 데이터를 보통 **학습 데이터**와 **평가 데이터**로 나눈다.

| 구분     | 설명                   |
| ------ | -------------------- |
| 학습 데이터 | 모델을 학습하는 데 사용하는 데이터  |
| 평가 데이터 | 학습된 모델의 성능을 확인하는 데이터 |

왜 나눌까?

모델이 학습 데이터만 잘 맞추는지,
처음 보는 데이터에도 잘 예측하는지 확인해야 하기 때문이다.

```markdown id="tqnpd8"
학습 데이터는 모델을 만드는 데 사용하고,
평가 데이터는 모델의 예측 성능을 검증하는 데 사용한다.
```

---

## 3) 모델 학습

모델 학습은 입력 변수와 목표 변수 사이의 관계를 찾는 과정이다.

예를 들어 다음과 같은 규칙을 학습할 수 있다.

```markdown id="b1evbq"
최근 방문일이 오래되었다.
구매 횟수가 줄었다.
고객 문의가 많아졌다.
→ 이탈 가능성이 높다.
```

이처럼 분류 모델은 과거 데이터에서 패턴을 찾아 새로운 데이터를 분류한다.

---

## 4) 예측

학습된 모델을 이용해 새로운 데이터의 범주를 예측한다.

예를 들어 신규 고객 데이터가 들어오면 다음처럼 예측할 수 있다.

```markdown id="obfwbo"
고객 A → 이탈 가능성 높음
고객 B → 이탈 가능성 낮음
```

---

## 5) 성능 평가

분류 모델은 예측 결과가 실제 정답과 얼마나 일치하는지 평가해야 한다.

대표적인 평가 지표는 다음과 같다.

```markdown id="25fhr5"
정확도
정밀도
재현율
F1-score
ROC 곡선
AUC
```

ADsP에서는 특히 **혼동행렬, 정확도, 정밀도, 재현율** 개념이 중요하다.

# 06. 로지스틱 회귀분석

## 로지스틱 회귀분석의 개념

**로지스틱 회귀분석(Logistic Regression)**은 목표 변수가 범주형일 때 사용하는 분류 기법이다.

특히 결과가 두 가지인 경우에 자주 사용된다.

```markdown id="to8kea"
로지스틱 회귀분석 = 목표 변수가 범주형일 때 사건 발생 확률을 예측하는 분류 기법
```

예를 들어 다음과 같은 문제에 사용할 수 있다.

```markdown id="czbjts"
고객이 이탈할 것인가? 이탈하지 않을 것인가?
메일이 스팸인가? 정상인가?
환자가 질병을 가지고 있는가? 아닌가?
고객이 상품을 구매할 것인가? 구매하지 않을 것인가?
```

로지스틱 회귀는 결과를 바로 `0` 또는 `1`로 예측하기보다,
먼저 어떤 사건이 발생할 **확률**을 예측한다.

예를 들어 고객 이탈 확률이 0.8이면 이탈 고객으로 분류할 수 있다.

```markdown id="uy0kpf"
로지스틱 회귀는 사건 발생 확률을 예측하고,
기준값에 따라 범주를 분류한다.
```

---

## 로지스틱 회귀분석의 특징

| 특징      | 설명                  |
| ------- | ------------------- |
| 목표 변수   | 범주형 변수              |
| 주 사용 상황 | 이진 분류               |
| 결과      | 사건 발생 확률            |
| 장점      | 해석이 비교적 쉽다          |
| 예시      | 이탈 여부, 구매 여부, 스팸 여부 |

시험에서는 이렇게 기억하면 된다.

```markdown id="pja6lm"
로지스틱 회귀분석은 이탈/비이탈처럼 결과가 두 범주인 분류 문제에 자주 사용된다.
```

# 07. 의사결정나무

## 의사결정나무의 개념

**의사결정나무(Decision Tree)**는 데이터를 여러 기준으로 분할하여 분류 규칙을 나무 형태로 표현하는 기법이다.

```markdown id="vwzkzi"
의사결정나무 = 데이터를 조건에 따라 나누어 분류 규칙을 나무 구조로 표현하는 기법
```

예를 들어 고객 이탈 여부를 예측할 때 다음과 같은 규칙이 만들어질 수 있다.

```markdown id="oqs5sh"
최근 방문일이 30일 이상인가?
 ├─ 예: 구매 횟수가 감소했는가?
 │    ├─ 예: 이탈 가능성 높음
 │    └─ 아니오: 관찰 필요
 └─ 아니오: 이탈 가능성 낮음
```

의사결정나무는 사람이 이해하기 쉬운 규칙 형태로 결과를 보여준다.

---

## 의사결정나무의 구성 요소

| 구성 요소 | 설명              |
| ----- | --------------- |
| 루트 노드 | 나무가 시작되는 최상위 노드 |
| 내부 노드 | 분류 기준이 되는 조건 노드 |
| 가지    | 조건에 따른 분기       |
| 리프 노드 | 최종 분류 결과        |
| 깊이    | 루트에서 리프까지의 단계 수 |

시험에서는 노드와 가지 개념을 가볍게 이해하면 된다.

```markdown id="o18unm"
의사결정나무는 루트 노드에서 시작해 조건에 따라 가지를 타고 내려가며 최종 리프 노드에서 분류 결과를 얻는다.
```

---

## 의사결정나무의 장점

| 장점                  | 설명                    |
| ------------------- | --------------------- |
| 해석이 쉬움              | 분류 규칙을 나무 구조로 확인 가능   |
| 시각화 가능              | 결과를 직관적으로 표현          |
| 변수 중요도 파악 가능        | 어떤 변수가 분류에 중요한지 확인 가능 |
| 수치형·범주형 변수 모두 사용 가능 | 다양한 데이터에 적용 가능        |

---

## 의사결정나무의 단점

| 단점           | 설명                             |
| ------------ | ------------------------------ |
| 과적합 위험       | 나무가 너무 복잡하면 학습 데이터에만 잘 맞을 수 있음 |
| 작은 변화에 민감    | 데이터가 조금만 바뀌어도 나무 구조가 달라질 수 있음  |
| 일반화 성능 저하 가능 | 새로운 데이터 예측력이 낮아질 수 있음          |

시험에서는 **해석이 쉽지만 과적합 위험이 있다**는 점이 중요하다.

```markdown id="w4m091"
의사결정나무는 해석이 쉽지만 나무가 지나치게 깊어지면 과적합이 발생할 수 있다.
```

# 08. 나이브 베이즈

## 나이브 베이즈의 개념

**나이브 베이즈(Naive Bayes)**는 베이즈 정리를 기반으로 한 분류 기법이다.

여기서 “나이브”는 입력 변수들이 서로 독립이라고 단순하게 가정한다는 의미다.

```markdown id="a18tid"
나이브 베이즈 = 입력 변수들이 서로 독립이라고 가정하고 베이즈 정리를 이용해 분류하는 기법
```

대표적으로 스팸 메일 분류에 자주 사용된다.

예를 들어 이메일에 다음 단어들이 포함되어 있다고 하자.

```markdown id="ntnrkj"
무료
당첨
이벤트
쿠폰
```

이런 단어들이 스팸 메일에서 자주 등장한다면, 해당 이메일을 스팸으로 분류할 가능성이 높다.

---

## 나이브 베이즈의 특징

| 특징    | 설명                    |
| ----- | --------------------- |
| 기반 이론 | 베이즈 정리                |
| 가정    | 변수 간 독립성 가정           |
| 장점    | 계산이 빠르고 구현이 단순        |
| 단점    | 변수 독립 가정이 현실과 다를 수 있음 |
| 활용    | 스팸 필터링, 문서 분류, 감성 분석  |

시험에서는 이렇게 기억하면 된다.

```markdown id="gm94qk"
나이브 베이즈는 변수 간 독립을 가정하고 베이즈 정리를 이용하는 분류 기법이다.
```

# 09. K-최근접 이웃, KNN

## KNN의 개념

**K-최근접 이웃(K-Nearest Neighbor, KNN)**은 새로운 데이터와 가장 가까운 K개의 기존 데이터를 보고, 다수결로 범주를 결정하는 분류 기법이다.

```markdown id="q62fir"
KNN = 가까운 K개의 이웃 데이터를 기준으로 새로운 데이터의 범주를 분류하는 기법
```

예를 들어 새로운 고객 A가 들어왔을 때,
기존 고객 중 A와 가장 비슷한 5명을 찾는다.

그 5명 중 4명이 이탈 고객이라면, A도 이탈 고객으로 분류한다.

---

## KNN의 특징

| 특징  | 설명                |
| --- | ----------------- |
| 기준  | 거리 기반             |
| 방식  | 가까운 K개 이웃의 다수결    |
| 장점  | 개념이 단순하고 이해하기 쉬움  |
| 단점  | 데이터가 많으면 계산 비용 증가 |
| 주의점 | 변수 스케일에 민감        |

KNN은 거리 기반 방법이기 때문에 변수 스케일이 중요하다.

예를 들어 `나이`는 20~70 정도인데, `연소득`은 수천만 원 단위라면 연소득이 거리 계산을 지배할 수 있다.
따라서 표준화가 필요한 경우가 많다.

```markdown id="jd66fj"
KNN은 거리 기반 분류 기법이므로 변수 스케일에 민감하다.
```

# 10. 인공신경망

## 인공신경망의 개념

**인공신경망(Artificial Neural Network)**은 인간의 신경망 구조를 모방하여 입력값과 출력값 사이의 복잡한 관계를 학습하는 분석 기법이다.

```markdown id="b2dahl"
인공신경망 = 입력층, 은닉층, 출력층을 통해 복잡한 패턴을 학습하는 분류·예측 기법
```

인공신경망은 다음과 같은 구조를 가진다.

| 구성  | 설명                   |
| --- | -------------------- |
| 입력층 | 데이터를 입력받는 층          |
| 은닉층 | 입력값을 조합하고 패턴을 학습하는 층 |
| 출력층 | 최종 예측 결과를 출력하는 층     |

---

## 인공신경망의 특징

| 특징        | 설명                            |
| --------- | ----------------------------- |
| 복잡한 패턴 학습 | 비선형 관계를 학습할 수 있음              |
| 예측 성능 우수  | 충분한 데이터가 있으면 높은 성능 가능         |
| 해석 어려움    | 내부 판단 과정을 설명하기 어려움            |
| 많은 데이터 필요 | 학습에 충분한 데이터가 필요               |
| 과적합 가능    | 모델이 복잡하면 학습 데이터에 과도하게 맞을 수 있음 |

시험에서는 이렇게 이해하면 된다.

```markdown id="cm48wn"
인공신경망은 복잡한 패턴을 학습할 수 있지만 해석이 어렵고 많은 데이터가 필요하다.
```

# 11. 앙상블 기법

## 앙상블의 개념

**앙상블(Ensemble)**은 여러 개의 모델을 결합하여 더 좋은 예측 성능을 얻는 기법이다.

```markdown id="ca8p6g"
앙상블 = 여러 모델의 예측 결과를 결합해 성능을 높이는 기법
```

한 명의 판단보다 여러 명의 판단을 종합하면 더 안정적인 결론을 얻을 수 있는 것과 비슷하다.

대표적인 앙상블 기법은 다음과 같다.

```markdown id="i0jx72"
배깅
부스팅
랜덤 포레스트
```

---

## 1) 배깅

**배깅(Bagging)**은 여러 개의 학습 데이터를 복원추출 방식으로 만들고, 각 데이터로 모델을 학습한 뒤 결과를 결합하는 방법이다.

```markdown id="7otw37"
배깅 = 여러 모델을 병렬로 학습하고 결과를 결합해 분산을 줄이는 방법
```

배깅은 모델의 불안정성을 줄이고 예측을 안정화하는 데 유용하다.

---

## 2) 부스팅

**부스팅(Boosting)**은 여러 모델을 순차적으로 학습하면서, 이전 모델이 틀린 데이터를 다음 모델이 더 잘 맞추도록 학습하는 방법이다.

```markdown id="x8om6y"
부스팅 = 이전 모델의 오류를 보완하도록 모델을 순차적으로 학습하는 방법
```

부스팅은 예측 성능이 높지만, 과적합에 주의해야 한다.

---

## 3) 랜덤 포레스트

**랜덤 포레스트(Random Forest)**는 여러 개의 의사결정나무를 만들고, 그 결과를 종합하여 분류하는 앙상블 기법이다.

```markdown id="83tq9q"
랜덤 포레스트 = 여러 의사결정나무를 결합한 앙상블 분류 기법
```

의사결정나무 하나는 과적합에 취약할 수 있지만, 여러 나무를 결합하면 더 안정적인 예측이 가능하다.

---

## 앙상블 기법 비교

| 기법      | 핵심                    |
| ------- | --------------------- |
| 배깅      | 여러 모델을 병렬로 학습하여 결과 결합 |
| 부스팅     | 이전 모델의 오류를 보완하며 순차 학습 |
| 랜덤 포레스트 | 여러 의사결정나무를 결합         |

시험에서는 이렇게 기억하면 된다.

```markdown id="8xcbtu"
배깅은 병렬 학습,
부스팅은 순차 학습,
랜덤 포레스트는 여러 의사결정나무의 결합이다.
```

# 12. 혼동행렬

## 혼동행렬의 개념

**혼동행렬(Confusion Matrix)**은 분류 모델의 예측 결과와 실제 정답을 비교한 표다.

분류 모델이 얼마나 잘 맞췄는지 평가할 때 사용한다.

```markdown id="e3cskq"
혼동행렬 = 실제값과 예측값을 비교하여 분류 성능을 평가하는 표
```

이진 분류에서는 보통 다음 4가지 값으로 구성된다.

| 구분 | 의미                           |
| -- | ---------------------------- |
| TP | 실제 Positive를 Positive로 맞게 예측 |
| TN | 실제 Negative를 Negative로 맞게 예측 |
| FP | 실제 Negative를 Positive로 잘못 예측 |
| FN | 실제 Positive를 Negative로 잘못 예측 |

---

## 혼동행렬 구조

| 실제 / 예측     | Positive 예측 | Negative 예측 |
| ----------- | ----------: | ----------: |
| 실제 Positive |          TP |          FN |
| 실제 Negative |          FP |          TN |

예를 들어 질병 진단 모델에서 Positive를 “질병 있음”으로 보면 다음과 같다.

| 구분 | 의미                       |
| -- | ------------------------ |
| TP | 실제 질병 있음 → 질병 있음으로 예측    |
| TN | 실제 질병 없음 → 질병 없음으로 예측    |
| FP | 실제 질병 없음 → 질병 있음으로 잘못 예측 |
| FN | 실제 질병 있음 → 질병 없음으로 잘못 예측 |

시험에서는 FP와 FN을 구분하는 것이 중요하다.

```markdown id="bc7a3z"
FP는 실제로는 아닌데 맞다고 예측한 것이고,
FN은 실제로는 맞는데 아니라고 예측한 것이다.
```

---

# 13. 분류 모델 평가 지표

분류 모델은 혼동행렬을 바탕으로 여러 성능 지표를 계산한다.

---

## 1) 정확도, Accuracy

**정확도**는 전체 예측 중 맞게 예측한 비율이다.

```markdown id="ttftb3"
정확도 = (TP + TN) / (TP + TN + FP + FN)
```

| 특징 | 설명                 |
| -- | ------------------ |
| 의미 | 전체 중 맞춘 비율         |
| 장점 | 이해하기 쉬움            |
| 단점 | 데이터 불균형이 심하면 왜곡 가능 |

예를 들어 정상 거래가 99%, 이상 거래가 1%인 데이터에서 전부 정상이라고 예측해도 정확도는 99%가 된다.
하지만 이상 거래를 하나도 잡지 못하므로 좋은 모델이라고 보기 어렵다.

```markdown id="5es3sp"
정확도는 전체 정답률이지만, 데이터 불균형 상황에서는 성능을 제대로 보여주지 못할 수 있다.
```

---

## 2) 정밀도, Precision

**정밀도**는 Positive라고 예측한 것 중 실제 Positive인 비율이다.

```markdown id="ychuim"
정밀도 = TP / (TP + FP)
```

즉, 모델이 “맞다”고 예측한 것 중 실제로 맞은 비율이다.

예를 들어 스팸 메일 분류에서 정밀도가 높다는 것은,
스팸이라고 분류한 메일이 실제로 스팸일 가능성이 높다는 의미다.

```markdown id="48f4om"
정밀도 = Positive 예측의 정확성
```

---

## 3) 재현율, Recall

**재현율**은 실제 Positive 중 모델이 Positive로 맞게 찾아낸 비율이다.

```markdown id="snnxwa"
재현율 = TP / (TP + FN)
```

즉, 실제로 맞는 것들을 얼마나 놓치지 않고 찾아냈는지를 나타낸다.

예를 들어 질병 진단에서는 실제 환자를 놓치면 위험하다.
이런 경우 재현율이 중요하다.

```markdown id="gc5kj2"
재현율 = 실제 Positive를 얼마나 잘 찾아냈는가
```

---

## 4) F1-score

**F1-score**는 정밀도와 재현율의 조화평균이다.

정밀도와 재현율을 함께 고려할 때 사용한다.

```markdown id="ri3bxz"
F1-score = 2 × (정밀도 × 재현율) / (정밀도 + 재현율)
```

정밀도와 재현율 중 하나만 높고 다른 하나가 낮으면 F1-score도 낮아진다.

```markdown id="9wa7au"
F1-score는 정밀도와 재현율의 균형을 평가하는 지표이다.
```

---

## 5) 특이도, Specificity

**특이도**는 실제 Negative 중 모델이 Negative로 맞게 예측한 비율이다.

```markdown id="ax5um5"
특이도 = TN / (TN + FP)
```

즉, 실제로 아닌 것을 아니라고 잘 판별하는 능력이다.

```markdown id="84qm6j"
특이도 = 실제 Negative를 얼마나 잘 찾아냈는가
```

---

## 평가 지표 비교

| 지표       | 공식               | 핵심                      |
| -------- | ---------------- | ----------------------- |
| 정확도      | `(TP + TN) / 전체` | 전체 중 맞춘 비율              |
| 정밀도      | `TP / (TP + FP)` | Positive 예측이 얼마나 정확한가   |
| 재현율      | `TP / (TP + FN)` | 실제 Positive를 얼마나 잘 찾았는가 |
| F1-score | `2PR / (P + R)`  | 정밀도와 재현율의 균형            |
| 특이도      | `TN / (TN + FP)` | 실제 Negative를 얼마나 잘 찾았는가 |

시험에서는 정밀도와 재현율 차이가 특히 중요하다.

```markdown id="2w1q75"
정밀도는 예측한 Positive 중 맞은 비율이고,
재현율은 실제 Positive 중 찾아낸 비율이다.
```

---

# 14. ROC 곡선과 AUC

## ROC 곡선

**ROC 곡선**은 분류 모델의 성능을 다양한 기준값에서 평가하는 그래프다.

ROC 곡선은 다음 두 값을 이용한다.

| 축  | 의미                       |
| -- | ------------------------ |
| x축 | False Positive Rate, FPR |
| y축 | True Positive Rate, TPR  |

여기서 TPR은 재현율과 같다.

```markdown id="5odd42"
TPR = 재현율 = TP / (TP + FN)
```

FPR은 실제 Negative 중 Positive로 잘못 예측한 비율이다.

```markdown id="x39n45"
FPR = FP / (FP + TN)
```

시험에서는 ROC 곡선의 자세한 계산보다 **분류 성능을 시각적으로 평가하는 그래프**라는 점을 기억하면 된다.

```markdown id="dtg0c6"
ROC 곡선은 분류 모델의 성능을 기준값 변화에 따라 시각적으로 평가하는 그래프이다.
```

---

## AUC

**AUC(Area Under Curve)**는 ROC 곡선 아래 면적이다.

AUC 값이 클수록 분류 모델의 성능이 좋다고 본다.

|    AUC 값 | 의미           |
| -------: | ------------ |
|   1에 가까움 | 분류 성능 우수     |
|   0.5 근처 | 무작위 분류와 비슷   |
| 0.5보다 작음 | 분류 성능이 좋지 않음 |

```markdown id="ozw2vo"
AUC는 ROC 곡선 아래 면적이며, 1에 가까울수록 분류 성능이 좋다.
```

---

# 15. 과적합과 과소적합

## 1) 과적합

**과적합(Overfitting)**은 모델이 학습 데이터에 지나치게 맞춰져서 새로운 데이터에 대한 예측 성능이 떨어지는 현상이다.

```markdown id="6p7pxl"
과적합 = 학습 데이터에는 잘 맞지만 새로운 데이터에는 잘 맞지 않는 상태
```

예를 들어 의사결정나무가 너무 깊어지면 학습 데이터의 작은 패턴까지 모두 외워버릴 수 있다.
이 경우 학습 데이터 성능은 높지만 평가 데이터 성능은 낮을 수 있다.

---

## 2) 과소적합

**과소적합(Underfitting)**은 모델이 너무 단순해서 학습 데이터의 패턴도 제대로 학습하지 못한 상태다.

```markdown id="my3b09"
과소적합 = 모델이 너무 단순하여 데이터의 패턴을 충분히 학습하지 못한 상태
```

---

## 과적합과 과소적합 비교

| 구분        | 과적합               | 과소적합                |
| --------- | ----------------- | ------------------- |
| 의미        | 학습 데이터에 지나치게 맞음   | 데이터 패턴을 충분히 학습하지 못함 |
| 학습 데이터 성능 | 높음                | 낮음                  |
| 평가 데이터 성능 | 낮음                | 낮음                  |
| 원인        | 모델이 너무 복잡         | 모델이 너무 단순           |
| 해결        | 모델 단순화, 가지치기, 정규화 | 모델 복잡도 증가, 변수 추가    |

시험에서는 이렇게 기억하면 된다.

```markdown id="zvvta3"
과적합은 너무 복잡한 모델이 학습 데이터를 외운 상태이고,
과소적합은 너무 단순한 모델이 데이터 패턴을 못 배운 상태이다.
```

| 함수 / 패키지           | 설명              |
| ------------------ | --------------- |
| `glm()`            | 로지스틱 회귀분석 등에 사용 |

| `party` 패키지        | 의사결정나무 분석       |

| `caret` 패키지        | 모델 학습과 평가 지원    |

예시로 로지스틱 회귀는 다음처럼 사용할 수 있다.

```r id="g57vdr"
model <- glm(target ~ x1 + x2, data = train, family = "binomial")
```

의사결정나무는 다음처럼 사용할 수 있다.

```r id="wup2h7"
library(rpart)

model <- rpart(target ~ ., data = train)
```

```markdown id="kqhmfy"

randomForest는 랜덤 포레스트에 사용된다.
```

# 시험 직전 암기 문장

```markdown id="c57qmq"
분류 분석은 정답 라벨이 있는 데이터를 학습하여
새로운 데이터를 미리 정의된 범주로 분류하는 지도 학습 기법이다.

분류 분석은 이탈/비이탈, 스팸/정상, 구매/미구매처럼
범주형 목표 변수를 예측할 때 사용한다.

분류 분석은 정답 라벨이 있는 지도 학습이고,
군집 분석은 정답 라벨 없이 유사성을 기준으로 그룹을 찾는 비지도 학습이다.

분류 분석은 데이터 준비, 학습 데이터와 평가 데이터 분리,
모델 학습, 예측, 성능 평가의 절차로 진행된다.

로지스틱 회귀분석은 목표 변수가 범주형일 때
사건 발생 확률을 예측하는 분류 기법이며, 이진 분류에 자주 사용된다.

의사결정나무는 데이터를 조건에 따라 나누어
분류 규칙을 나무 구조로 표현하는 기법이다.

의사결정나무는 해석이 쉽고 시각화가 가능하지만,
나무가 지나치게 깊어지면 과적합이 발생할 수 있다.

나이브 베이즈는 입력 변수들이 서로 독립이라고 가정하고,
베이즈 정리를 이용해 분류하는 기법이다.

KNN은 새로운 데이터와 가까운 K개의 이웃 데이터를 기준으로
다수결을 통해 범주를 분류하는 기법이다.

KNN은 거리 기반 방법이므로 변수 스케일에 민감하다.

인공신경망은 입력층, 은닉층, 출력층을 통해 복잡한 패턴을 학습하는 기법이며,
성능은 좋을 수 있지만 해석이 어렵고 많은 데이터가 필요하다.

앙상블은 여러 모델의 예측 결과를 결합해 성능을 높이는 기법이다.

배깅은 여러 모델을 병렬로 학습하여 결과를 결합하는 방법이고,
부스팅은 이전 모델의 오류를 보완하도록 모델을 순차적으로 학습하는 방법이다.

랜덤 포레스트는 여러 개의 의사결정나무를 결합한 앙상블 분류 기법이다.

혼동행렬은 실제값과 예측값을 비교하여 분류 성능을 평가하는 표이다.

TP는 실제 Positive를 Positive로 맞게 예측한 것이고,
TN은 실제 Negative를 Negative로 맞게 예측한 것이다.

FP는 실제 Negative를 Positive로 잘못 예측한 것이고,
FN은 실제 Positive를 Negative로 잘못 예측한 것이다.

정확도는 전체 예측 중 맞게 예측한 비율이고,
정밀도는 Positive라고 예측한 것 중 실제 Positive인 비율이다.

재현율은 실제 Positive 중 모델이 Positive로 맞게 찾아낸 비율이며,
F1-score는 정밀도와 재현율의 조화평균이다.

ROC 곡선은 분류 모델의 성능을 기준값 변화에 따라 시각적으로 평가하는 그래프이고,
AUC는 ROC 곡선 아래 면적으로 1에 가까울수록 분류 성능이 좋다.

과적합은 모델이 학습 데이터에 지나치게 맞춰져
새로운 데이터에 대한 예측 성능이 떨어지는 현상이다.

과소적합은 모델이 너무 단순하여
학습 데이터의 패턴을 충분히 학습하지 못한 상태이다.
```
