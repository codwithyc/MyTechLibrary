## 060. 인터넷의 개요

### 1. 인터넷의 정의

인터넷은 **TCP/IP 프로토콜을 사용하여 전 세계의 컴퓨터를 연결한 거대한 네트워크**입니다.

- 1969년 미국 국방부의 **ARPANET**에서 시작되었습니다.
- 중앙에서 관리하는 주체가 없는 **분산형 네트워크**입니다.
- 기종이나 운영체제에 관계없이 통신할 수 있습니다.

#### 왜 중앙 관리자가 없을까?

ARPANET은 원래 **군사 목적**으로 만들어졌습니다.

중앙 통제소가 있으면, 그곳이 공격받았을 때 **네트워크 전체가 마비**됩니다.

그래서 중앙 없이 **각 노드가 스스로 경로를 찾아 우회**할 수 있도록 설계되었습니다.

이 설계 덕분에 인터넷은

- 일부가 끊겨도 나머지가 동작하고
- 누구나 자유롭게 연결을 추가할 수 있는

구조가 되었습니다.

---

### 2. 인터넷 연결 방식

| 방식 | 특징 |
| --- | --- |
| 전화 접속(다이얼업) | 전화선과 모뎀을 이용한 초기 방식으로, 속도가 매우 느립니다. |
| **ADSL** | 전화선을 이용하며, **내려받기 속도가 올려보내기 속도보다 빠른 비대칭 방식**입니다. |
| VDSL | ADSL보다 빠른 속도를 제공합니다. |
| 케이블 모뎀 | 유선 방송 케이블망을 이용합니다. |
| **광랜(FTTH)** | 광섬유를 이용하여 매우 빠른 속도를 제공합니다. |
| 무선(Wi-Fi, LTE, 5G) | 무선 신호를 이용하여 연결합니다. |

#### 왜 ADSL은 비대칭일까?

일반 사용자의 인터넷 사용 패턴을 보면,  
**받는 데이터가 보내는 데이터보다 훨씬 많습니다.**

- 웹 페이지 보기, 동영상 시청, 파일 다운로드 → 받기
- 주소 입력, 검색어 전송 → 보내기 (매우 적음)

그래서 제한된 회선 용량을 **받는 쪽에 더 많이 배분**한 것이 ADSL입니다.

이름의 A도 **Asymmetric(비대칭)** 을 뜻합니다.

### 3. 인터넷 관련 기관과 용어

| 용어 | 설명 |
| --- | --- |
| **ISP(Internet Service Provider)** | 인터넷 접속 서비스를 제공하는 사업자입니다. |
| **ICANN** | 인터넷 도메인 이름과 IP 주소를 관리하는 국제 기구입니다. |
| **W3C** | 웹 표준을 제정하는 기구입니다. |
| **IETF** | 인터넷 기술 표준을 개발하는 기구입니다. |
| **인트라넷(Intranet)** | 인터넷 기술을 **기업 내부**에 적용한 폐쇄형 네트워크입니다. |
| **엑스트라넷(Extranet)** | 인트라넷을 **협력사·고객 등 외부 관계자에게 일부 개방**한 네트워크입니다. |

#### 인트라넷 vs 엑스트라넷

| 구분 | 인트라넷 | 엑스트라넷 |
| --- | --- | --- |
| 사용자 | 조직 **내부 구성원만** | 내부 구성원 + **허가된 외부 관계자** |
| 목적 | 사내 정보 공유 | 협력사와의 업무 연계 |

두 가지 모두 **인터넷 기술(웹, TCP/IP)** 을 그대로 사용하되,  
**누구에게 열어 줄 것인지**만 다릅니다.

기존 사내 전용 시스템을 따로 개발하는 대신 익숙한 웹 기술을 재활용하므로,  
**개발 비용이 낮고 사용자가 배우기 쉽다**는 장점이 있습니다.

### 4. IP 주소 할당 방식

| 방식 | 특징 |
| --- | --- |
| **고정 IP** | 항상 같은 주소를 사용합니다. 서버 운영에 적합합니다. |
| **유동 IP** | 접속할 때마다 **DHCP 서버**로부터 주소를 자동 할당받습니다. |

### 5. 인터넷 관련 개념

| 용어 | 설명 |
| --- | --- |
| **클라이언트-서버(Client-Server)** | **서비스를 요청하는 쪽(클라이언트)** 과 **제공하는 쪽(서버)** 으로 역할을 나눈 구조입니다. |
| **P2P(Peer to Peer)** | 서버 없이 **각 컴퓨터가 서로 대등한 관계로 직접** 데이터를 주고받습니다. |
| **하이퍼텍스트(Hypertext)** | 문서 안의 링크를 통해 다른 문서로 이동할 수 있는 문서 형태입니다. |
| **하이퍼미디어(Hypermedia)** | 하이퍼텍스트에 **그림, 소리, 동영상**을 포함한 형태입니다. |
| **미러 사이트(Mirror Site)** | 인기 있는 사이트의 **부하를 분산**하기 위해 동일한 내용을 복사해 둔 사이트입니다. |
| **포털 사이트(Portal Site)** | 검색, 메일, 뉴스 등 다양한 서비스를 한곳에서 제공하는 사이트입니다. |

#### 왜 미러 사이트가 필요할까?

인기 있는 사이트에 사용자가 몰리면

- 서버가 감당하지 못해 접속이 느려지고
- 심하면 접속 자체가 되지 않습니다.

미러 사이트는 **같은 내용을 여러 곳에 복사해 두고 사용자를 분산**시킵니다.

또한 지리적으로 가까운 서버에 접속하게 하면 **응답 속도도 빨라집니다.**

#### 클라이언트-서버 vs P2P

| 구분 | 클라이언트-서버 | P2P |
| --- | --- | --- |
| 구조 | 중앙 서버에 집중 | 참여자끼리 직접 연결 |
| 장점 | 관리와 보안이 쉬움 | 서버 부담이 없고 참여자가 많을수록 유리 |
| 단점 | **서버 장애 시 전체 중단** | 관리·보안이 어려움 |

---

### 한 줄 정리

인터넷은 **TCP/IP 기반의 분산형 네트워크**로 중앙 관리자가 없으며,  
**인트라넷은 내부용, 엑스트라넷은 협력사까지 개방**하고,  
**ADSL은 받기 속도가 더 빠른 비대칭 방식**입니다.
