| 구분  | 자료형      | 설명                |
| --- | -------- | ----------------- |
| 문자형 | `char`   | 문자 또는 작은 정수 저장    |

#### JAVA

| 구분  | 자료형       | 설명              |

## 098. 변수

### 1. 변수명 작성 규칙

변수는 프로그램에서 데이터를 저장하기 위한 **기억 공간의 이름**입니다.

변수명 작성 규칙은 다음과 같습니다.

* 영문자, 숫자, `_`를 사용할 수 있습니다.
* 숫자로 시작할 수 없습니다.
* 공백을 사용할 수 없습니다.
* 예약어를 변수명으로 사용할 수 없습니다.
* 대소문자를 구분합니다.
* 의미를 알 수 있는 이름을 사용하는 것이 좋습니다.

```text
올바른 변수명
age
studentName
user_count

잘못된 변수명
1age
user-name
class
```

## 099. 연산자

### 1. 산술 연산자

숫자의 계산에 사용하는 연산자입니다.

| 연산자  | 의미   |
| ---- | ---- |
| `+`  | 덧셈   |
| `-`  | 뺄셈   |
| `*`  | 곱셈   |
| `/`  | 나눗셈  |
| `%`  | 나머지  |
| `++` | 1 증가 |
| `--` | 1 감소 |

```c
10 + 5  // 15
10 % 3  // 1
```

---

### 2. 관계 연산자

두 값의 크기나 동일 여부를 비교합니다.

| 연산자  | 의미     |
| ---- | ------ |
| `>`  | 크다     |
| `<`  | 작다     |
| `>=` | 크거나 같다 |
| `<=` | 작거나 같다 |
| `==` | 같다     |
| `!=` | 같지 않다  |

결과는 일반적으로 `true` 또는 `false`가 됩니다.

---

### 3. 비트 연산자

정수 값을 **2진수 비트 단위**로 연산합니다.

| 연산자  | 의미      |    |
| ---- | ------- | -- |
| `&`  | AND     |    |
| `    | `       | OR |
| `^`  | XOR     |    |
| `~`  | NOT     |    |
| `<<` | 왼쪽 시프트  |    |
| `>>` | 오른쪽 시프트 |    |

예:

```text
5 = 0101
3 = 0011

5 & 3 = 0001 = 1
5 | 3 = 0111 = 7
5 ^ 3 = 0110 = 6
```

---

### 4. 논리 연산자

여러 조건을 결합할 때 사용합니다.

| 연산자  | 의미  | 설명        |    |            |
| ---- | --- | --------- | -- | ---------- |
| `&&` | AND | 모두 참이면 참  |    |            |
| `    |     | `         | OR | 하나라도 참이면 참 |
| `!`  | NOT | 참과 거짓을 반전 |    |            |

```c
age >= 20 && age < 30
```

---

### 5. 조건 연산자

조건에 따라 서로 다른 값을 선택하는 연산자로 **삼항 연산자**라고도 합니다.

```c
조건 ? 참일_때_값 : 거짓일_때_값;
```

예:

```c
int max = a > b ? a : b;
```

`a > b`가 참이면 `a`, 거짓이면 `b`가 저장됩니다.

---

### 5.1 조건 연산자 우선순위

대표적인 연산자 우선순위는 다음과 같습니다.

```text
높음
  ↓
()
++ --
* / %
+ -
<< >>
< <= > >=
== !=
&
^
|
&&
||
? :
=
낮음
```

> 우선순위가 헷갈리는 경우에는 `()`를 사용하는 것이 가장 안전합니다.

int age = 20;

## 101. 제어문

### 1. 단순 if문

조건이 참일 경우 특정 명령을 수행합니다.

```c
if (조건) {
    실행문;
}
```

예:

```c
if (score >= 60) {
    printf("합격");
}
```

---

### 2. 다중 if문

여러 조건을 순서대로 검사합니다.

```c
if (조건1) {
    실행문1;
}
else if (조건2) {
    실행문2;
}
else {
    실행문3;
}
```

예:

```c
if (score >= 90) {
    grade = 'A';
}
else if (score >= 80) {
    grade = 'B';
}
else {
    grade = 'C';
}
```

---

### 3. switch문

하나의 값에 따라 여러 실행 경로 중 하나를 선택합니다.

```c
switch (변수) {
    case 값1:
        실행문;
        break;

    case 값2:
        실행문;
        break;

    default:
        실행문;
}
```

`break`가 없으면 다음 `case`까지 연속으로 실행될 수 있습니다.

## 102. 반복문

### 1. for문

반복 횟수가 명확할 때 주로 사용합니다.

```c
for (초기값; 조건식; 증감식) {
    실행문;
}
```

예:

```c
for (int i = 0; i < 5; i++) {
    printf("%d", i);
}
```

---

### 2. while문

조건이 참인 동안 반복합니다.

```c
while (조건식) {
    실행문;
}
```

예:

```c
int i = 0;

while (i < 5) {
    printf("%d", i);
    i++;
}
```

---

### 3. do~while문

실행문을 먼저 실행한 뒤 조건을 검사합니다.

```c
do {
    실행문;
} while (조건식);
```

따라서 조건이 처음부터 거짓이더라도 **최소 한 번은 실행**됩니다.

---

### 4. break, continue

#### break

현재 반복문을 즉시 종료합니다.

```c
if (i == 5) {
    break;
}
```

#### continue

현재 반복 과정만 건너뛰고 다음 반복을 수행합니다.

```c
if (i == 5) {
    continue;
}
```

## 104. 포인터

### 1. 포인터와 포인터 변수

포인터는 다른 변수의 **메모리 주소를 저장하는 변수**입니다.

```c
int a = 10;
int *p = &a;
```

| 표현   | 의미           |
| ---- | ------------ |
| `&a` | 변수 `a`의 주소   |
| `p`  | `a`의 주소      |
| `*p` | 해당 주소에 저장된 값 |

```text
a  = 10
&p = 해당 없음
p  = a의 주소
*p = 10
```

---

### 2. 포인터와 배열

C언어에서 배열의 이름은 일반적으로 배열의 **첫 번째 요소의 주소**를 나타냅니다.

```c
int arr[3] = {10, 20, 30};

int *p = arr;
```

다음 표현들은 같은 값을 나타냅니다.

```c
arr[0]
*arr
*p
```

또한

```c
arr[1]
*(arr + 1)
```

도 같은 값을 나타냅니다.

## 106. Python의 기초

### 1. input() 함수

사용자로부터 값을 입력받습니다.

```python
name = input()
```

안내 문구와 함께 입력:

```python
name = input("이름 : ")
```

> `input()`으로 입력받은 값은 기본적으로 문자열(`str`)입니다.

---

### 2. print() 함수

데이터를 화면에 출력합니다.

```python
print("Hello")
```

여러 값을 출력할 수도 있습니다.

```python
print("Age:", 20)
```

---

### 3. 입력 값의 형변환

`input()`의 결과는 문자열이므로 숫자로 사용하려면 형변환해야 합니다.

```python
age = int(input())
```

실수:

```python
height = float(input())
```

주요 형변환 함수:

| 함수        | 변환  |
| --------- | --- |
| `int()`   | 정수  |
| `float()` | 실수  |
| `str()`   | 문자열 |
| `list()`  | 리스트 |
| `tuple()` | 튜플  |

---

### 4. 리스트(List)

여러 데이터를 순서대로 저장하는 자료형입니다.

```python
numbers = [10, 20, 30]
```

값 접근:

```python
numbers[0]
```

값 추가:

```python
numbers.append(40)
```

값 삭제:

```python
numbers.remove(20)
```

리스트는 **값을 변경할 수 있는 Mutable 자료형**입니다.

---

### 5. 딕셔너리(Dictionary)

`Key : Value` 형태로 데이터를 저장합니다.

```python
student = {
    "name": "Kim",
    "age": 20
}
```

값 접근:

```python
student["name"]
```

값 변경:

```python
student["age"] = 21
```

값 추가:

```python
student["score"] = 90
```

---

### 6. 슬라이스(Slice)

리스트나 문자열의 일부 범위를 가져오는 기능입니다.

```python
데이터[시작:끝:간격]
```

예:

```python
numbers = [10, 20, 30, 40, 50]

numbers[1:4]
```

결과:

```text
[20, 30, 40]
```

끝 인덱스의 값은 포함하지 않습니다.

```python
numbers[:3]
numbers[2:]
numbers[::2]
```

result = add(10, 20)

## 109. 라이브러리

### 1. 라이브러리의 개념

라이브러리(Library)는 자주 사용하는 기능을 미리 작성하여 **재사용할 수 있도록 만들어 놓은 함수나 프로그램의 모음**입니다.

라이브러리를 사용하면 동일한 기능을 직접 구현할 필요가 없어 개발 효율성과 코드 재사용성을 높일 수 있습니다.

---

### 2. C언어의 stdio.h

**Standard Input/Output**의 약자로 표준 입출력 기능을 제공합니다.

대표 함수:

| 함수          | 기능    |
| ----------- | ----- |
| `printf()`  | 출력    |
| `scanf()`   | 입력    |
| `getchar()` | 문자 입력 |
| `putchar()` | 문자 출력 |
| `fopen()`   | 파일 열기 |
| `fclose()`  | 파일 닫기 |

```c
#include <stdio.h>
```

---

### 3. C언어의 math.h

수학 계산과 관련된 함수를 제공합니다.

| 함수        | 기능   |
| --------- | ---- |
| `sqrt()`  | 제곱근  |
| `pow()`   | 거듭제곱 |
| `sin()`   | 사인   |
| `cos()`   | 코사인  |
| `ceil()`  | 올림   |
| `floor()` | 내림   |

```c
#include <math.h>

sqrt(16);     // 4
pow(2, 3);    // 8
```

---

### 4. C언어의 string.h

문자열을 처리하기 위한 함수를 제공합니다.

| 함수         | 기능     |
| ---------- | ------ |
| `strlen()` | 문자열 길이 |
| `strcpy()` | 문자열 복사 |
| `strcat()` | 문자열 연결 |
| `strcmp()` | 문자열 비교 |

```c
#include <string.h>
```

---

### 5. C언어의 stdlib.h

표준 유틸리티 기능을 제공합니다.

| 함수          | 기능              |
| ----------- | --------------- |
| `malloc()`  | 동적 메모리 할당       |
| `calloc()`  | 동적 메모리 할당 및 초기화 |
| `realloc()` | 메모리 크기 변경       |
| `free()`    | 동적 메모리 해제       |
| `rand()`    | 난수 생성           |
| `atoi()`    | 문자열 → 정수 변환     |
| `exit()`    | 프로그램 종료         |

```c
#include <stdlib.h>
```

> `stdilb.h`가 아니라 **`stdlib.h`**가 올바른 이름입니다.

---

### 6. C언어의 time.h

시간 및 날짜를 처리하기 위한 기능을 제공합니다.

대표 함수:

| 함수            | 기능         |
| ------------- | ---------- |
| `time()`      | 현재 시간      |
| `clock()`     | CPU 사용 시간  |
| `difftime()`  | 두 시간의 차이   |
| `localtime()` | 지역 시간으로 변환 |

```c
#include <time.h>
```

## 110. 예외처리

### 1. JAVA의 예외 처리

예외(Exception)는 프로그램 실행 중 발생하는 **비정상적인 상황이나 오류**입니다.

JAVA에서는 `try`, `catch`, `finally`, `throw`, `throws` 등을 이용하여 예외를 처리합니다.

#### try-catch

```java
try {
    // 예외가 발생할 수 있는 코드
} catch (Exception e) {
    // 예외 처리
}
```

예:

```java
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("0으로 나눌 수 없습니다.");
}
```

#### finally

예외 발생 여부와 관계없이 실행할 코드를 작성합니다.

```java
try {
    // 실행
} catch (Exception e) {
    // 예외 처리
} finally {
    // 항상 실행
}
```

#### throw

개발자가 직접 예외를 발생시킬 때 사용합니다.

```java
throw new IllegalArgumentException();
```

#### throws

메소드에서 발생할 수 있는 예외를 호출한 곳으로 전달합니다.

```java
void method() throws IOException {
}
```

정리하면 다음과 같습니다.

| 키워드       | 의미                |
| --------- | ----------------- |
| `try`     | 예외 발생 가능 코드       |
| `catch`   | 발생한 예외 처리         |
| `finally` | 예외 여부와 관계없이 실행    |
| `throw`   | 예외를 직접 발생         |
| `throws`  | 예외 처리를 호출한 곳으로 전달 |

JAVA의 예외는 크게 다음과 같이 구분할 수 있습니다.

```text
Throwable
├── Error
└── Exception
    ├── RuntimeException
    └── 기타 Exception
```

* **Error**: 시스템 수준의 심각한 오류
* **Exception**: 프로그램에서 처리할 수 있는 예외
* **RuntimeException**: 실행 중 발생하는 대표적인 예외
