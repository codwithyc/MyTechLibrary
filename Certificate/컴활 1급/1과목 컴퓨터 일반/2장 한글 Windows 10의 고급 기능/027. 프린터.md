## 027. 프린터

### 1. 프린터의 설치

- [설정] → [장치] → [프린터 및 스캐너] → [프린터 또는 스캐너 추가]
- [제어판] → [장치 및 프린터] → [프린터 추가]

**설치 시 선택 항목**

| 구분 | 설명 |
| --- | --- |
| 로컬 프린터 | 컴퓨터에 직접 케이블로 연결된 프린터입니다. |
| 네트워크 프린터 | 네트워크를 통해 연결된 프린터로, 다른 컴퓨터에 연결된 프린터도 공유하여 사용할 수 있습니다. |

- 한 대의 컴퓨터에 **여러 대의 프린터를 설치**할 수 있습니다.
- 한 대의 프린터를 **여러 대의 컴퓨터에서 공유**할 수 있습니다.
- 같은 프린터를 **이름을 달리하여 여러 번 설치**할 수도 있습니다.

#### 왜 같은 프린터를 여러 번 설치할까?

프린터 설정(용지 크기, 인쇄 품질, 양면 인쇄 등)은 **프린터 단위로 저장**됩니다.

같은 프린터를 이름만 다르게 두 번 설치하면

- "보고서용" : 흑백, 양면
- "발표자료용" : 컬러, 단면

처럼 **설정 묶음을 미리 만들어 두고 골라 쓸 수 있습니다.**

즉, 매번 옵션을 바꾸는 대신 **설정을 프린터 이름으로 저장해 두는 방법**입니다.

---

### 2. 기본 프린터

인쇄 명령을 내렸을 때 **특별히 지정하지 않으면 자동으로 선택되는 프린터**입니다.

- 기본 프린터는 **한 대만 지정**할 수 있습니다.
- 기본 프린터로 지정된 프린터 아이콘에는 **체크 표시(✔)** 가 나타납니다.
- 네트워크 프린터도 기본 프린터로 지정할 수 있습니다.
- 이미 설치된 프린터 중에서 선택하며, 지정 후에도 언제든 변경할 수 있습니다.
- [설정]에서 **'Windows에서 기본 프린터 관리'** 를 켜면 **가장 최근에 사용한 프린터가 자동으로 기본 프린터**가 됩니다.

#### 왜 기본 프린터가 필요할까?

대부분의 사용자는 실제로 **한 대의 프린터만 주로 사용**합니다.

그런데 인쇄할 때마다 프린터를 고르게 하면 매번 불필요한 선택 단계가 생깁니다.

기본 프린터는 **가장 흔한 경우를 미리 정해 두어**,  
`Ctrl` + `P` → [인쇄]만으로 바로 출력할 수 있게 해 줍니다.

### 3. 프린터 속성

프린터 아이콘의 바로 가기 메뉴 → [프린터 속성]에서 설정합니다.

| 탭 | 주요 내용 |
| --- | --- |
| 일반 | 프린터 이름, 위치, 설명, 기능(컬러 여부, 양면 인쇄, 최대 해상도), 테스트 페이지 인쇄 |
| 공유 | 프린터 공유 여부와 공유 이름, 추가 드라이버 설치 |
| 포트 | 프린터가 연결된 포트(LPT1, USB 등)를 지정하고 프린터 풀링을 설정 |
| 고급 | 사용 가능 시간, 우선 순위, 드라이버, **스풀 설정** |
| 색 관리 | 색상 프로필을 지정 |
| 보안 | 사용자별 인쇄 권한을 지정 |
| 장치 설정 | 용지함별 용지 종류 등을 지정 |

**우선 순위**

- 1(가장 낮음) ~ 99(가장 높음) 사이의 값으로 지정합니다.
- 값이 클수록 먼저 인쇄됩니다.

#### 왜 프린터에 "우선 순위"가 필요할까?

여러 사람이 한 프린터를 공유하면 인쇄 작업이 대기열에 쌓입니다.

만약 급한 문서가 뒤에 들어오면, 앞의 작업이 모두 끝날 때까지 기다려야 합니다.

같은 프린터를 이름만 다르게 두 번 설치하고 **서로 다른 우선 순위**를 주면,  
급한 작업은 높은 우선 순위 프린터로 보내 **먼저 처리**할 수 있습니다.

### 4. 프린터 공유

- [프린터 속성] → [공유] 탭에서 **'이 프린터 공유'** 를 선택합니다.
- 공유된 프린터 아이콘에는 **공유 표시**가 나타납니다.
- 공유 이름은 **다른 컴퓨터에서 접근할 때 사용하는 이름**입니다.
- 네트워크 상의 다른 컴퓨터에서 **`\\컴퓨터이름\공유이름`** 형태로 접근합니다.

#### 왜 프린터를 공유할까?

프린터는 비싸고 자리도 차지하지만, **실제 사용 시간은 매우 짧은 장치**입니다.

사람마다 프린터를 따로 두면 대부분의 시간 동안 놀게 됩니다.

공유는 **하나의 장치를 여러 사용자가 번갈아 사용**하게 하여 자원 낭비를 줄입니다.

---

### 5. 프린터 관련 용어

| 용어 | 설명 |
| --- | --- |
| **DPI(Dots Per Inch)** | 1인치에 인쇄되는 점의 수로, 인쇄 **해상도**를 나타냅니다. 값이 클수록 선명합니다. |
| **CPS / LPM / PPM** | 인쇄 속도 단위입니다. (CPS: 초당 문자 수, LPM: 분당 줄 수, PPM: 분당 페이지 수) |
| 프린터 풀링 | 여러 대의 프린터를 하나처럼 묶어, 사용 가능한 프린터로 작업을 자동 분배합니다. |

---

### 한 줄 정리

프린터는 **여러 대 설치·공유가 가능**하지만 **기본 프린터는 한 대만 지정**할 수 있으며,  
우선 순위는 **값이 클수록(99에 가까울수록) 먼저 인쇄**되고, 해상도 단위는 **DPI**입니다.
