## 051. PC 업그레이드

### 1. 업그레이드의 개요

업그레이드는 **기존 컴퓨터의 부품이나 소프트웨어를 성능이 더 좋은 것으로 교체·추가**하여  
컴퓨터의 성능을 향상시키는 작업입니다.

| 구분 | 내용 |
| --- | --- |
| 하드웨어 업그레이드 | CPU, RAM, 하드디스크/SSD, 그래픽 카드, 메인보드 등의 교체·추가 |
| 소프트웨어 업그레이드 | 운영체제, 응용 프로그램, 드라이버를 최신 버전으로 변경 |

#### 왜 업그레이드를 할까?

새 컴퓨터를 사는 것보다 **필요한 부품만 교체하는 편이 훨씬 저렴**한 경우가 많습니다.

특히 성능 저하의 원인이 특정 부품 하나에 있을 때는,  
그 부품만 바꿔도 체감 성능이 크게 좋아집니다.

---

### 2. 업그레이드 시 고려 사항

- **업그레이드 목적을 명확히 합니다.** (게임, 영상 편집, 문서 작업 등)
- **현재 시스템의 사양과 호환되는지** 반드시 확인합니다.
- 여러 부품을 동시에 바꾸기보다 **성능 저하의 원인이 되는 부품부터** 교체합니다.
- **비용 대비 효과**를 따져 봅니다.
- 작업 전 **중요한 데이터를 백업**합니다.
- 정전기 방지를 위해 **금속 물체를 만져 방전**한 후 작업합니다.

#### 왜 "원인이 되는 부품부터" 교체해야 할까?

컴퓨터의 성능은 **가장 느린 부품에 맞춰집니다.**

예를 들어 CPU가 아무리 빨라도 하드디스크가 느리면,  
CPU는 데이터를 기다리느라 성능을 발휘하지 못합니다.

이런 부품을 **병목(Bottleneck)** 이라고 합니다.

따라서 업그레이드의 핵심은  
**"가장 좋은 부품을 넣는 것"이 아니라 "가장 발목을 잡는 부품을 찾는 것"** 입니다.

---

### 3. 주요 부품별 업그레이드

**RAM (주기억장치)**

- 여러 프로그램을 동시에 실행할 때 느려진다면 RAM 부족일 가능성이 큽니다.
- **메인보드가 지원하는 규격(DDR4, DDR5 등)과 최대 용량**을 확인해야 합니다.
- 기존 RAM과 **같은 규격·같은 속도**로 맞추는 것이 좋습니다.
- 용량이 클수록, 접근 속도(ns)는 **작을수록** 좋습니다.

**저장 장치 (하드디스크 → SSD)**

- 부팅과 프로그램 실행이 느리다면 **HDD를 SSD로 교체**하는 것이 체감 효과가 가장 큽니다.
- 용량이 클수록, **RPM(회전 속도)이 높을수록** 좋습니다. (HDD 기준)

**CPU**

- **메인보드의 소켓 규격과 칩셋이 지원하는 CPU**인지 반드시 확인해야 합니다.
- 클럭 주파수(GHz)는 **높을수록**, 코어 수는 **많을수록** 좋습니다.

**그래픽 카드**

- 게임이나 영상 편집 성능을 높일 때 교체합니다.
- 메모리 용량, 파워 서플라이의 **전력 공급 용량**, 케이스 공간을 확인해야 합니다.

#### 왜 RAM은 규격을 맞춰야 할까?

RAM은 세대별로 **핀의 배치와 전압, 동작 방식이 다릅니다.**

DDR4 슬롯에 DDR5 메모리는 **물리적으로 꽂히지도 않습니다.**  
이는 잘못된 메모리를 꽂아 손상되는 것을 막기 위한 설계입니다.

또한 같은 세대라도 속도가 다른 메모리를 섞으면,  
**전체가 느린 쪽 속도에 맞춰 동작**하게 됩니다.

#### 왜 HDD → SSD 교체의 체감 효과가 가장 클까?

일상적인 작업(부팅, 프로그램 실행, 파일 열기)의 대부분은 **저장 장치에서 데이터를 읽는 시간**이 차지합니다.

CPU나 RAM은 이미 충분히 빠른데, 하드디스크만 수백 배 느립니다.

이 병목을 제거하면 **다른 부품을 바꾸지 않아도 컴퓨터가 훨씬 빨라진 것처럼** 느껴집니다.

---

### 4. 수치의 방향 정리

시험에서 자주 묻는 부분입니다.

| 항목 | 좋은 방향 |
| --- | --- |
| CPU 클럭 주파수(GHz) | **높을수록** 좋음 |
| RAM 용량(GB) | **클수록** 좋음 |
| RAM 접근 속도(ns) | **작을수록** 좋음 |
| 하드디스크 용량(GB/TB) | **클수록** 좋음 |
| 하드디스크 회전 속도(RPM) | **높을수록** 좋음 |
| 모니터 해상도 / 재생률 | **높을수록** 좋음 |
| 모니터 점 간격(dot pitch) | **작을수록** 좋음 |
| 프린터 해상도(DPI) | **높을수록** 좋음 |
| 전송 속도(bps) | **높을수록** 좋음 |

> **"시간·간격·지연"을 나타내는 단위는 작을수록 좋고, "양·횟수·속도"를 나타내는 단위는 클수록 좋다"** 고 기억하면 헷갈리지 않습니다.

---

### 5. 소프트웨어 업그레이드

| 대상 | 내용 |
| --- | --- |
| 운영체제 | 최신 버전으로 변경하거나 업데이트를 적용합니다. |
| 장치 드라이버 | 장치 관리자나 제조사 홈페이지에서 최신 드라이버를 설치합니다. |
| 펌웨어 | BIOS, SSD, 공유기 등의 펌웨어를 업데이트합니다. |
| 응용 프로그램 | 보안 취약점 해결과 기능 개선을 위해 최신 버전으로 유지합니다. |

- 소프트웨어 업그레이드는 하드웨어 교체 없이 성능과 안정성을 개선할 수 있는 방법입니다.
- 다만 **업그레이드 후 기존 프로그램과의 호환성 문제**가 생길 수 있으므로, 중요한 시스템은 사전에 확인이 필요합니다.

---

### 한 줄 정리

업그레이드는 **호환성 확인이 최우선**이며,  
**병목이 되는 부품부터 교체**하는 것이 효율적이고,  
**RAM 접근 속도(ns)와 모니터 점 간격은 작을수록, 나머지 대부분의 수치는 클수록** 좋습니다.
