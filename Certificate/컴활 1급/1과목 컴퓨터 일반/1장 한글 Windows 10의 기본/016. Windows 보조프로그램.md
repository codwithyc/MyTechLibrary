## 016. Windows 보조프로그램

### 1. 보조프로그램의 개요

보조프로그램은 Windows에 **기본으로 포함되어 있는 간단한 응용 프로그램**입니다.

- [시작] → [Windows 보조프로그램] 에서 실행할 수 있습니다.
- 별도의 설치 없이 문서 작성, 그림 그리기, 계산 등의 기본 작업을 수행할 수 있습니다.

#### 왜 운영체제가 보조프로그램까지 제공할까?

운영체제를 설치한 직후에는 아무 응용 프로그램도 없습니다.  
그런데 메모를 남기거나 간단한 계산을 하는 일은 **설치 직후부터 바로 필요**합니다.

보조프로그램은 이런 **가장 기본적인 작업을 별도 설치 없이 처리할 수 있게** 제공됩니다.

---

### 2. 메모장(Notepad)

**서식 없는 순수한 텍스트만** 편집할 수 있는 가장 간단한 문서 편집기입니다.

- 기본 저장 확장자는 **`.TXT`** 입니다.
- **글꼴, 글꼴 스타일, 크기는 문서 전체에 동일하게 적용**되며, 일부 문장에만 다르게 지정할 수 없습니다.
- 그림, 표, 개체(OLE)를 삽입할 수 없습니다.
- **자동 줄 바꿈**, **머리글/바닥글** 지정이 가능합니다.
- 문서의 첫 줄 맨 앞에 **`.LOG`** 를 입력하고 저장하면,  
  파일을 열 때마다 **마지막 줄에 현재 시간과 날짜가 자동으로 추가**됩니다.
- `F5`를 누르면 현재 시간과 날짜가 삽입됩니다.

#### 왜 메모장은 서식을 지원하지 않을까?

메모장의 목적은 **문서를 예쁘게 꾸미는 것**이 아니라  
**텍스트를 있는 그대로 저장하는 것**입니다.

프로그램 소스 코드나 설정 파일처럼 **서식이 섞이면 안 되는 파일**을 다룰 때,  
메모장은 불필요한 정보를 넣지 않아 안전합니다.

즉, 메모장의 단순함은 부족함이 아니라 **의도된 특성**입니다.

#### 왜 `.LOG` 기능이 있을까?

메모장은 간단한 기록용으로 자주 사용됩니다.  
이때 "언제 적었는지"가 함께 남으면 훨씬 유용합니다.

`.LOG`는 파일을 열 때마다 자동으로 시각을 남겨,  
메모장을 **간단한 일지(로그) 도구**로 쓸 수 있게 해 줍니다.

---

### 3. 워드패드(WordPad)

메모장보다 기능이 많은 **서식 있는 문서 편집기**입니다.

- 기본 저장 확장자는 **`.RTF`** 이며, `.TXT`, `.DOCX`, `.ODT` 형식도 지원합니다.
- **글꼴, 크기, 색, 정렬, 들여쓰기, 글머리 기호** 등 서식을 지정할 수 있습니다.
- 그림, 그림판 그림, 날짜/시간, 개체 삽입(OLE)이 가능합니다.
- **여러 문서를 동시에 편집할 수는 없습니다.**

#### 메모장 vs 워드패드

| 구분 | 메모장 | 워드패드 |
| --- | --- | --- |
| 서식 지정 | 불가능(문서 전체 통일) | 가능 |
| 그림·개체 삽입 | 불가능 | 가능 |
| 기본 확장자 | `.TXT` | `.RTF` |
| 파일 크기 | 작음 | 상대적으로 큼 |

---

### 4. 그림판(Paint)

간단한 그림을 그리거나 편집할 수 있는 프로그램입니다.

- 기본 저장 확장자는 **`.PNG`** 이며, `BMP`, `JPG`, `GIF`, `TIF` 형식으로도 저장할 수 있습니다.
- **비트맵(Bitmap) 방식**으로 그림을 처리합니다.
- `Shift`를 누른 채 드래그하면 **정원, 정사각형, 수평/수직선**을 그릴 수 있습니다.
- 그림의 **크기 조정, 기울이기, 회전, 대칭 이동**이 가능합니다.
- 작성한 그림을 **바탕 화면 배경으로 지정**할 수 있습니다.
- 레이어 기능은 지원하지 않습니다.

#### 왜 `Shift`를 누르면 정사각형이 그려질까?

마우스 드래그만으로는 가로세로 비율을 정확히 맞추기 어렵습니다.

`Shift`는 **비율을 1:1로 고정**하는 보조 키로, 대부분의 그래픽 프로그램에서 동일하게 동작합니다.  
덕분에 손으로 맞추지 않아도 정확한 도형을 그릴 수 있습니다.

---

### 5. 계산기(Calculator)

| 모드 | 기능 |
| --- | --- |
| 표준 | 사칙연산, 제곱근, 백분율 등 기본 계산 |
| 공학용 | 삼각함수, 로그, 지수 등 공학 계산 |
| 그래프 | 함수의 그래프를 그림 |
| 프로그래머 | **2진수·8진수·10진수·16진수 변환** 및 비트 연산 |
| 날짜 계산 | 두 날짜 사이의 차이를 계산 |
| 변환기 | 통화, 부피, 길이, 무게, 온도, 속도 등 단위 변환 |

- 계산 결과는 `Ctrl` + `C`로 복사하여 다른 프로그램에 붙여 넣을 수 있습니다.

### 6. 그 밖의 보조프로그램

| 프로그램 | 기능 |
| --- | --- |
| 캡처 도구 / 캡처 및 스케치 | 화면의 원하는 영역을 캡처하고 간단히 편집합니다. (자유형, 사각형, 창, 전체 화면) |
| 원격 데스크톱 연결 | 다른 컴퓨터에 접속하여 원격으로 조작합니다. |
| 단계 레코더 | 작업 과정을 화면과 함께 기록하여 문제 상황을 재현합니다. |
| 빠른 지원 | 다른 사용자에게 원격 지원을 제공하거나 받습니다. |
| Windows 미디어 플레이어 | 음악과 동영상을 재생합니다. |
| 문자표 | 키보드에 없는 특수 문자를 찾아 입력합니다. |

---

### 한 줄 정리

메모장은 **서식 없는 `.TXT` 전용 편집기**이고, 워드패드는 **서식과 개체를 지원하는 `.RTF` 편집기**이며,  
그림판은 **비트맵 방식의 `.PNG` 기본 저장** 프로그램입니다.
