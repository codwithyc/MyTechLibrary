## 054. 운영체제

### 1. 운영체제(OS, Operating System)의 개요

운영체제는 **사용자와 컴퓨터 하드웨어 사이에서 중계 역할을 하며, 시스템 자원을 관리하는 시스템 소프트웨어**입니다.

- 컴퓨터를 켜면 **가장 먼저 주기억장치에 적재되어 실행**됩니다.
- 대표적인 운영체제 : Windows, macOS, Linux, UNIX, Android, iOS

#### 왜 운영체제가 필요할까?

운영체제가 없다면 프로그램은 다음을 모두 스스로 처리해야 합니다.

- 메모리의 어느 위치를 사용할지 직접 결정
- CPU를 언제 얼마나 쓸지 다른 프로그램과 직접 조율
- 디스크의 어느 섹터에 파일을 저장할지 직접 계산

프로그램이 여러 개라면 서로 충돌할 수밖에 없습니다.

운영체제는 이 자원들을 **혼자서 관리하고 필요한 만큼 나누어 주는 관리자** 역할을 합니다.

---

### 2. 운영체제의 목적(성능 평가 기준)

| 기준 | 설명 | 방향 |
| --- | --- | --- |
| **처리 능력(Throughput)** | 일정 시간 안에 처리하는 작업의 양 | **향상(증가)** |
| **반환 시간(Turnaround Time)** | 작업을 요청한 후 결과를 얻기까지 걸린 시간 | **단축(감소)** |
| **사용 가능도(Availability)** | 자원을 필요할 때 즉시 사용할 수 있는 정도 | **향상(증가)** |
| **신뢰도(Reliability)** | 시스템이 주어진 작업을 정확하게 처리하는 정도 | **향상(증가)** |

> **반환 시간만 "단축"** 이고 나머지 셋은 "향상"입니다. 시험에서 자주 나오는 함정 포인트입니다.

#### 왜 반환 시간만 방향이 반대일까?

나머지 세 가지는 **많을수록 좋은 것**(양, 가용성, 정확성)이지만,  
반환 시간은 **기다린 시간**이기 때문입니다.

기다리는 시간은 짧을수록 좋으므로 "단축"이 목표가 됩니다.

---

### 3. 운영체제의 기능

| 기능 | 설명 |
| --- | --- |
| **프로세스 관리** | CPU를 어느 프로그램에 얼마나 할당할지 결정하고, 실행 순서를 조정합니다. |
| **기억장치 관리** | 주기억장치의 공간을 프로그램에 할당하고 회수합니다. (가상 메모리 포함) |
| **주변장치 관리** | 입출력 장치의 사용을 조정하고 스케줄링합니다. |
| **파일 관리** | 파일의 생성·삭제·저장·검색을 관리하고 디렉터리 구조를 유지합니다. |
| 사용자 인터페이스 제공 | GUI 또는 CUI 형태로 사용자가 컴퓨터를 조작할 수 있게 합니다. |
| 보안 및 사용자 관리 | 계정과 권한을 관리하고 자원 접근을 통제합니다. |

---

### 4. 운영체제의 구성

운영체제는 **제어 프로그램**과 **처리 프로그램**으로 구성됩니다.

**제어 프로그램(Control Program)**

| 종류 | 역할 |
| --- | --- |
| **감시 프로그램(Supervisor)** | 시스템 전체의 동작 상태를 감시하고 **제어 프로그램 전체를 총괄**합니다. |
| **작업 관리 프로그램(Job Management)** | 작업의 연속적인 처리와 작업 전환을 담당합니다. |
| **데이터 관리 프로그램(Data Management)** | 데이터와 파일의 입출력, 저장, 검색을 관리합니다. |

**처리 프로그램(Processing Program)**

| 종류 | 역할 |
| --- | --- |
| **언어 번역 프로그램** | 원시 프로그램을 기계어로 번역합니다. (컴파일러, 어셈블러, 인터프리터) |
| **서비스 프로그램** | 사용자의 편의를 위해 제공되는 프로그램입니다. (정렬, 병합, 유틸리티) |
| **문제 처리 프로그램** | 사용자가 문제 해결을 위해 직접 작성한 프로그램입니다. |

#### 왜 제어와 처리로 나눌까?

두 프로그램은 **역할의 성격**이 다릅니다.

- **제어 프로그램** : 시스템이 원활히 돌아가도록 **관리하고 감시**
- **처리 프로그램** : 실제로 **사용자의 일을 수행**

관리자와 실무자를 나눈 조직 구조와 비슷하게 이해하면 됩니다.

---

### 5. 부팅과 운영체제

- 컴퓨터를 켜면 **ROM BIOS → POST → 부트로더 → 운영체제 적재** 순으로 진행됩니다.
- 운영체제의 **핵심 부분(커널)** 은 실행 중에 항상 주기억장치에 남아 있습니다.
- 자주 사용하지 않는 부분은 필요할 때 디스크에서 불러옵니다.

#### 왜 커널은 항상 메모리에 남아 있을까?

커널은 **프로세스 관리, 메모리 관리, 입출력 처리** 등 가장 기본적인 기능을 담당합니다.

이 기능들은 **거의 모든 순간 사용**되므로, 매번 디스크에서 불러오면 시스템이 극도로 느려집니다.

그래서 커널은 부팅 시 메모리에 올라온 뒤 **종료할 때까지 상주**합니다.

이렇게 항상 메모리에 남아 있는 부분을 **상주(Resident) 프로그램**,  
필요할 때만 불러오는 부분을 **비상주(Non-resident) 프로그램**이라고 합니다.

---

### 한 줄 정리

운영체제는 **사용자와 하드웨어 사이에서 자원을 관리하는 시스템 소프트웨어**이며,  
성능 평가 기준은 **처리 능력·사용 가능도·신뢰도는 향상, 반환 시간은 단축**이고,  
**제어 프로그램(감시·작업 관리·데이터 관리)** 과 **처리 프로그램(언어 번역·서비스·문제 처리)** 으로 구성됩니다.
