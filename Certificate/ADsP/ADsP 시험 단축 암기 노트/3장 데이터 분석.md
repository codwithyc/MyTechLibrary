분석 기획은 데이터 분석 전에 주제와 문제를 정의하고,
결과 도출을 위한 데이터, 분석 방법, 수행 방안을 사전에 계획하는 작업이다.

분석 주제 유형은 분석 대상인 What과 분석 방법인 How가 정해졌는지에 따라
Optimization, Solution, Insight, Discovery로 구분된다.

Optimization은 분석 대상과 분석 방법이 모두 정해진 경우이며,
기존 방법을 개선해 효율과 성능을 높이는 유형이다.

Solution은 분석 대상은 정해졌지만 분석 방법이 정해지지 않은 경우이며,
유사 사례와 방법론을 탐색해 해결 방안을 찾는 유형이다.

Insight는 분석 방법은 정해졌지만 분석 대상이 명확하지 않은 경우이며,
기존 분석 방법을 다양한 데이터에 적용해 문제와 통찰을 찾는 유형이다.

Discovery는 분석 대상과 분석 방법이 모두 명확하지 않은 경우이며,
데이터와 사례를 탐색해 새로운 분석 주제와 방법을 발견하는 유형이다.

목표 시점에 따른 분석 기획은 단기적 과제 중심 접근 방식과
중장기적 마스터 플랜 방식으로 구분된다.

과제 중심 접근 방식은 짧은 시간과 자원으로 빠른 성과를 얻는 방식이며,
속도, 실험, Quick-Win을 중시한다.

마스터 플랜 방식은 전사적이고 중장기적인 관점에서 분석 과제를 도출하는 방식이며,
정확성, 실무 적용, 장기 로드맵을 중시한다.

분석 기획 시에는 데이터 확보 가능성, 분석 결과의 활용 방안,
기술·비용·시간·인력 등 장애 요소를 사전에 고려해야 한다.

분석 방법론은 효과적인 데이터 분석을 위해 절차, 방법, 도구와 기법,
템플릿과 산출물을 체계적으로 정리한 것이다.

폭포수 모델은 순차적으로 단계를 진행하는 하향식 방법론이며,
요구사항 변경에 유연하게 대응하기 어렵다.

나선형 모델은 반복을 통해 점진적으로 개선하는 방법론이며,
처음 시도하는 복잡한 프로젝트에 적합하다.

프로토타입 모델은 초기 시제품을 만들고 피드백을 반영해
반복적으로 개선하는 방법론이다.

애자일 방법론은 소통과 협업을 중심으로 반복적이고 점진적으로 개선하며,
변화에 유연하게 대응하는 방법론이다.

KDD는 데이터 선택, 데이터 전처리, 데이터 변환,
데이터 마이닝, 결과 평가의 5단계로 구성된다.

CRISP-DM은 비즈니스 이해, 데이터 이해, 데이터 준비,
모델링, 평가, 전개의 6단계로 구성된다.

빅데이터 분석 방법론은 분석 기획, 데이터 준비, 데이터 분석,
시스템 구현, 평가 및 배포의 5단계로 구성된다.

분석 과제 발굴 방식은 비즈니스 문제에서 출발하는 하향식 접근 방식과,
데이터 탐색에서 출발하는 상향식 접근 방식으로 구분된다.

하향식 접근 방식은 문제가 먼저 주어지고,
문제 탐색, 문제 정의, 해결방안 탐색, 타당성 검토 순서로 진행된다.

상향식 접근 방식은 문제가 명확하지 않은 상태에서
데이터 탐색과 반복적 실험을 통해 문제와 분석 주제를 발견하는 방식이다.

분석 프로젝트 관리는 범위, 시간, 비용, 품질, 통합, 조달,
자원, 리스크, 의사소통, 이해관계자 영역을 관리하는 것이다.

분석 프로젝트에서는 데이터의 양, 데이터 복잡도, 속도,
분석 복잡도, 정확도와 정밀도를 추가로 고려해야 한다.

분석 마스터 플랜은 여러 분석 과제의 우선순위를 정하고,
적용 범위와 방식을 고려해 실행 로드맵을 수립하는 것이다.

분석 과제 우선순위는 전략적 중요도, 비즈니스 성과와 ROI,
실행 용이성을 기준으로 평가한다.

빅데이터 분석 ROI에서 투자 비용은 Volume, Variety, Velocity와 관련되고,
비즈니스 효과는 Value와 관련된다.

시급성과 난이도 기준에서는 현재 시급하고 난이도가 낮은 과제가
가장 우선적으로 추진된다.

로드맵은 분석 과제의 우선순위와 선후행 관계를 고려해
단계별 추진 목표와 실행 계획을 정리한 것이다.

분석 거버넌스는 분석 목표를 효과적으로 달성하기 위해
조직, 프로세스, 시스템, 데이터, 인력 체계를 수립하는 것이다.

분석 준비도는 분석 업무, 분석 인력과 조직, 분석 기법,
분석 데이터, 분석 문화, IT 인프라의 6개 영역으로 진단한다.

분석 성숙도는 조직의 분석 활용 수준을 평가하는 것이며,
도입, 활용, 확산, 최적화 단계로 구분된다.

데이터 거버넌스는 전사 데이터를 표준화하고 관리하기 위한 체계이며,
원칙, 조직, 프로세스의 3요소로 구성된다.

데이터 거버넌스 체계는 데이터 표준화, 데이터 관리 체계,
데이터 저장소 관리, 모니터링 및 개선 활동으로 구성된다.

분석 조직 구조는 집중적 조직 구조, 기능 중심 조직 구조,
분산 조직 구조로 구분된다.

집중적 조직 구조는 독립된 분석 전담 조직이 전사 분석 업무를 담당하는 구조이다.

기능 중심 조직 구조는 별도 전담 조직 없이 각 현업 부서가 분석 업무를 수행하는 구조이다.

분산 조직 구조는 분석 조직 인력을 현업 부서에 배치해
전사 관리와 현업 적용을 함께 수행하는 구조이다.

분석 과제 관리 프로세스는 과제 발굴 단계와 과제 수행 단계로 구분된다.

과제 발굴 단계에서는 분석 과제 풀을 관리하고 우선순위를 설정하며,
과제 수행 단계에서는 분석 과제를 실행하고 모니터링과 결과 공유를 수행한다.

분석 교육과 변화관리는 조직 구성원의 데이터 활용 역량을 높이고,
데이터 기반 의사결정 문화를 정착시키기 위한 활동이다.
