## 076. 정보보안 개요

### 1. 정보보안의 3대 요소

| 요소 | 설명 |
| --- | --- |
| **기밀성(Confidentiality)** | **인가된 사용자만** 정보에 접근할 수 있어야 합니다. |
| **무결성(Integrity)** | 정보가 **허가 없이 변경되지 않아야** 합니다. |
| **가용성(Availability)** | 인가된 사용자가 **필요할 때 언제든 사용**할 수 있어야 합니다. |

여기에 다음 요소를 추가하기도 합니다.

| 요소 | 설명 |
| --- | --- |
| **인증(Authentication)** | 정보를 주고받는 상대가 **본인이 맞는지 확인**합니다. |
| **부인 방지(Non-repudiation)** | 송·수신 사실을 **나중에 부인할 수 없도록** 합니다. |

#### 왜 이 세 가지를 핵심으로 볼까?

정보가 위협받는 방식은 결국 세 가지로 정리됩니다.

- 남이 **몰래 보는 것** → 기밀성 침해
- 남이 **몰래 바꾸는 것** → 무결성 침해
- 필요할 때 **쓸 수 없게 되는 것** → 가용성 침해

이 세 가지를 모두 지켜야 정보가 안전하다고 말할 수 있습니다.

#### 왜 가용성도 보안에 포함될까?

정보를 아무도 보지 못하게 하고 아무도 바꾸지 못하게 하는 가장 확실한 방법은  
**서버를 꺼 버리는 것**입니다.

하지만 그러면 정작 필요한 사람도 쓸 수 없습니다.

보안은 **정보를 막는 것이 아니라, 필요한 사람이 안전하게 쓸 수 있게 하는 것**입니다.  
그래서 가용성이 반드시 함께 고려됩니다.

DDoS 공격이 대표적인 **가용성 침해** 사례입니다.

#### 왜 부인 방지가 필요할까?

전자 상거래에서 "나는 그런 주문을 한 적이 없다"고 주장하면,  
종이 계약서처럼 서명을 확인할 방법이 없습니다.

부인 방지는 **전자 서명 등을 통해 행위의 주체를 증명**하여,  
나중에 사실을 부인할 수 없게 만드는 요소입니다.

### 2. 보안 위협의 유형

| 유형 | 설명 | 침해되는 요소 |
| --- | --- | --- |
| **가로막기(Interruption)** | 데이터의 전달을 **방해하여 못 쓰게** 만듭니다. | **가용성** |
| **가로채기(Interception)** | 데이터를 **몰래 훔쳐봅니다.** | **기밀성** |
| **수정(Modification)** | 데이터를 **불법으로 변경**합니다. | **무결성** |
| **위조(Fabrication)** | **가짜 데이터를 만들어** 정상적인 것처럼 보내는 행위입니다. | **무결성 / 인증** |

#### 네 가지를 구분하는 요령

데이터가 A에서 B로 가는 흐름을 그려 보면 쉽게 구분됩니다.

- **가로막기** : 화살표가 **중간에서 끊김** → 도착하지 않음
- **가로채기** : 화살표는 도착하지만 **옆에서 복사해 감**
- **수정** : 화살표가 중간에서 **내용이 바뀌어** 도착
- **위조** : **A가 보내지도 않은** 데이터가 B에 도착

### 3. 주요 해킹 기법

| 기법 | 설명 |
| --- | --- |
| **스니핑(Sniffing)** | 네트워크를 오가는 **데이터를 몰래 엿보는** 행위입니다. (수동적 공격) |
| **스푸핑(Spoofing)** | IP 주소나 신원을 **속여 접근**하는 행위입니다. |
| **피싱(Phishing)** | 가짜 사이트나 메일로 **사용자를 속여 정보를 입력하게** 만듭니다. |
| **파밍(Pharming)** | **DNS를 조작**하여 정확한 주소를 입력해도 가짜 사이트로 접속하게 합니다. |
| **스미싱(Smishing)** | **문자 메시지(SMS)** 의 링크를 이용한 피싱입니다. |
| **키로거(Key Logger)** | 키보드 입력을 기록하여 정보를 탈취합니다. |
| **DoS / DDoS** | 대량의 데이터를 보내 **서버를 마비**시킵니다. |
| **백도어(Back Door)** | 인증을 우회하는 비밀 통로를 만들어 둡니다. |
| **분산 서비스 거부(DDoS)** | 여러 대의 좀비 PC를 이용해 동시에 공격합니다. |
| **트로이 목마** | 정상 프로그램으로 위장하여 침입합니다. |
| **랜섬웨어** | 파일을 암호화하고 금전을 요구합니다. |
| **사회 공학** | 기술이 아닌 **사람의 심리를 이용**해 정보를 얻어냅니다. |

#### 피싱 vs 파밍

| 구분 | 피싱 | 파밍 |
| --- | --- | --- |
| 방식 | **가짜 링크로 유도** | **DNS를 조작** |
| 사용자 행동 | 잘못된 링크를 클릭함 | **정확한 주소를 직접 입력함** |
| 탐지 난이도 | 주소를 확인하면 알 수 있음 | **주소가 정상으로 보여 알아채기 어려움** |

파밍이 더 위험한 이유는, 사용자가 아무 잘못을 하지 않아도  
**정상 주소를 입력했는데 가짜 사이트로 연결**되기 때문입니다.

#### 왜 DDoS를 막기 어려울까?

DoS는 한 곳에서 공격하므로 **그 주소를 차단**하면 됩니다.

DDoS는 감염된 수만 대의 **일반 사용자 컴퓨터(좀비 PC)** 를 동원합니다.

- 공격 트래픽이 **전 세계의 정상 IP에서** 들어오고
- 정상 사용자의 접속과 **구별하기 어렵습니다.**

그래서 단순 차단으로는 대응할 수 없고, 전문 방어 장비가 필요합니다.

#### 왜 사회 공학 공격이 효과적일까?

시스템의 보안이 아무리 강력해도,  
**정당한 권한을 가진 사람이 스스로 알려 주면** 소용이 없습니다.

- "전산실입니다. 점검을 위해 비밀번호를 알려 주세요."
- "택배 배송 조회입니다. 링크를 클릭해 주세요."

이처럼 사회 공학은 기술이 아니라 **신뢰와 급박함이라는 심리**를 이용합니다.

그래서 보안에서는 흔히 **"가장 약한 고리는 사람"** 이라고 말합니다.

### 4. 보안 등급과 접근 통제

| 개념 | 설명 |
| --- | --- |
| **식별(Identification)** | 사용자가 자신이 누구인지 밝힙니다. (아이디 입력) |
| **인증(Authentication)** | 그것이 사실인지 확인합니다. (비밀번호, 생체 인식) |
| **인가(Authorization)** | 인증된 사용자에게 **어떤 권한을 줄지** 결정합니다. |

**인증 방식의 세 가지 요소**

| 요소 | 예 |
| --- | --- |
| **알고 있는 것** | 비밀번호, PIN |
| **가지고 있는 것** | 보안 카드, OTP, 스마트폰 |
| **자신인 것** | 지문, 홍채, 얼굴 |

#### 왜 2단계 인증이 안전할까?

비밀번호 하나만 사용하면, **그것이 유출되는 순간 계정이 뚫립니다.**

2단계 인증은 서로 다른 종류의 요소를 조합합니다.  
예를 들어 **비밀번호(아는 것) + 휴대폰 인증(가진 것)** 을 함께 요구합니다.

공격자가 비밀번호를 알아내더라도  
**휴대폰까지 물리적으로 확보하지 않으면** 로그인할 수 없습니다.

---

### 한 줄 정리

정보보안의 3대 요소는 **기밀성·무결성·가용성**이며,  
보안 위협은 **가로막기(가용성)·가로채기(기밀성)·수정(무결성)·위조(인증)** 로 구분하고,  
**피싱은 가짜 링크 유도, 파밍은 DNS 조작**이라는 점이 핵심 차이입니다.
