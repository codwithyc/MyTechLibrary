## 004. 바탕화면 & 바로가기 아이콘

### 1. 바탕 화면(Desktop)의 개요

바탕 화면은 Windows를 시작했을 때 나타나는 기본 작업 공간으로,  
아이콘·바로 가기 아이콘·작업 표시줄 등이 배치되는 화면입니다.

- 바탕 화면의 바로 가기 메뉴(마우스 오른쪽 단추 클릭)에서는 다음 작업을 할 수 있습니다.

| 메뉴 | 기능 |
| --- | --- |
| 보기 | 아이콘 크기 변경, 아이콘 자동 정렬, 아이콘을 그리드에 맞춤, 바탕 화면 아이콘 표시 |
| 정렬 기준 | 이름, 크기, 항목 유형, 수정한 날짜 기준으로 아이콘 정렬 |
| 새로 고침 | 바탕 화면의 내용을 최신 상태로 갱신 |
| 새로 만들기 | 폴더, 바로 가기, 문서 파일 등을 생성 |
| 디스플레이 설정 | [설정] → [시스템] → [디스플레이] 창 표시 |
| 개인 설정 | [설정] → [개인 설정] 창 표시 |

#### 왜 바탕 화면이 필요할까?

컴퓨터에는 수많은 프로그램과 파일이 설치되어 있지만, 실제로 자주 쓰는 것은 일부입니다.  
매번 설치 경로를 찾아 들어가야 한다면 매우 번거롭습니다.

바탕 화면은 **가장 먼저 보이는 화면**이므로,  
자주 사용하는 항목을 올려 두는 "작업대" 역할을 합니다.

---

### 2. 아이콘(Icon)

아이콘은 파일, 폴더, 프로그램 등을 그림으로 나타낸 것입니다.

| 종류 | 특징 |
| --- | --- |
| 일반 아이콘 | 실제 파일이나 폴더 그 자체를 나타냅니다. |
| 바로 가기 아이콘 | 원본 항목을 빠르게 실행하기 위한 연결 아이콘으로, 왼쪽 아래에 **화살표 표시(↗)** 가 있습니다. |

---

### 3. 바로 가기 아이콘(Shortcut)

바로 가기 아이콘은 자주 사용하는 프로그램이나 파일을 **빠르게 실행하기 위해 만든 연결 아이콘**입니다.

- 확장자는 **`.LNK`** 이며, 크기는 보통 **1KB 내외**로 매우 작습니다.
- 아이콘 왼쪽 아래에 **화살표(↗)** 가 표시됩니다.
- **원본 파일의 경로 정보만 가지고 있습니다.**
- 하나의 원본 파일에 대해 **여러 개의 바로 가기 아이콘을 만들 수 있습니다.**
- 바로 가기 아이콘을 삭제해도 **원본 파일은 삭제되지 않습니다.**
- 반대로 원본 파일을 삭제하면 바로 가기 아이콘은 **실행할 수 없습니다.**
- 폴더, 프린터, 디스크 드라이브, 다른 컴퓨터 등에도 바로 가기를 만들 수 있습니다.

#### 왜 바로 가기 아이콘의 크기가 1KB밖에 되지 않을까?

바로 가기 아이콘은 프로그램 자체를 복사한 것이 아니라,  
**"원본이 어디에 있는지"를 적어 둔 안내판**에 가깝습니다.

따라서 저장하는 내용은 경로와 실행 옵션 정도이므로 용량이 매우 작습니다.

즉, 바로 가기는  
**내용을 복사하는 것이 아니라 위치를 가리키는 것**입니다.

#### 왜 원본을 지우면 바로 가기가 동작하지 않을까?

바로 가기는 원본의 경로만 가지고 있기 때문에,  
그 경로에 실제 파일이 없으면 실행할 대상 자체가 사라진 것과 같습니다.

반대로 바로 가기를 지우는 것은 **안내판만 치우는 것**이므로 원본에는 아무 영향이 없습니다.

---

### 4. 바로 가기 아이콘 만드는 방법

| 방법 | 설명 |
| --- | --- |
| 바로 가기 메뉴 이용 | 원본을 마우스 오른쪽 단추로 클릭 → [바로 가기 만들기] |
| 마우스 오른쪽 드래그 | 원본을 오른쪽 단추로 드래그한 후 [여기에 바로 가기 만들기] 선택 |
| `Ctrl` + `Shift` + 드래그 | 원본을 `Ctrl` + `Shift`를 누른 채 드래그 |
| 복사 후 붙여넣기 | 원본 복사(`Ctrl` + `C`) → [바로 가기 붙여넣기] |
| 새로 만들기 | 바탕 화면 바로 가기 메뉴 → [새로 만들기] → [바로 가기] |

---

### 5. 바로 가기 아이콘의 속성

바로 가기 아이콘에서 마우스 오른쪽 단추 → [속성]을 선택하면 다음 정보를 확인·변경할 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| 대상 형식 / 대상 위치 | 원본 파일의 종류와 위치를 확인합니다. |
| 대상 | 원본 파일의 전체 경로를 지정합니다. |
| 시작 위치 | 프로그램이 실행될 때 기준이 되는 폴더를 지정합니다. |
| 바로 가기 키 | 해당 항목을 실행할 단축키를 지정합니다. |
| 실행 | 실행 시 창의 크기(기본 창, 최소화, 최대화)를 지정합니다. |
| 아이콘 변경 | 바로 가기 아이콘의 그림을 변경합니다. |

#### 왜 바로 가기에 단축키를 지정할 수 있을까?

자주 쓰는 프로그램은 바탕 화면에서 찾아 클릭하는 것조차 번거로울 수 있습니다.  
바로 가기 키를 지정해 두면 **어떤 화면에 있든 키 입력만으로 실행**할 수 있습니다.

---

### 한 줄 정리

바로 가기 아이콘은 **원본의 경로만 담은 `.LNK` 파일**이므로 크기가 매우 작고,  
**바로 가기를 지워도 원본은 남지만, 원본을 지우면 바로 가기는 동작하지 않습니다.**
