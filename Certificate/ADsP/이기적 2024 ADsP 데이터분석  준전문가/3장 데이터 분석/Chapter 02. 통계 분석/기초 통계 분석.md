# 기초 통계 분석

기초 통계 분석은 데이터를 본격적으로 모델링하기 전에, 데이터의 **중심, 퍼짐, 관계, 차이**를 파악하는 단계다.

데이터 분석에서 통계는 단순 계산이 아니라, 데이터를 근거로 현상을 이해하고 판단하기 위한 도구다.

```markdown id="6w2t9a"
기초 통계 분석 = 데이터의 특성을 수치로 요약하고, 집단 간 차이와 변수 간 관계를 파악하는 분석
```

ADsP 시험에서는 주로 다음 내용을 묻는다.

* 기술통계와 추론통계의 차이
* 평균, 중앙값, 최빈값
* 분산, 표준편차, 범위, 사분위수
* 공분산과 상관계수
* 표본과 모집단
* 가설검정의 기본 개념
* t검정, 분산분석, 카이제곱검정
* 상관분석과 회귀분석의 차이

---

# 01. 통계 분석의 개념

## 통계 분석의 정의

**통계 분석**이란 데이터를 수집, 정리, 요약, 해석하여 의미 있는 정보를 도출하는 과정이다.

예를 들어 시험 점수 데이터가 있다고 하자.

```markdown id="6it6ix"
70, 80, 90, 100, 60
```

이 데이터를 그대로 보면 전체적인 특성을 파악하기 어렵다.
하지만 평균, 분산, 표준편차를 구하면 데이터의 중심과 퍼짐을 이해할 수 있다.

```markdown id="3ksbdj"
평균 = 전체 점수의 대표값
표준편차 = 점수가 평균에서 얼마나 흩어져 있는지
```

즉, 통계 분석은 데이터를 숫자로 요약하고, 그 숫자를 통해 현상을 해석하는 과정이다.

---

## 통계 분석의 목적

| 목적     | 설명                          |
| ------ | --------------------------- |
| 데이터 요약 | 평균, 중앙값, 표준편차 등으로 데이터 특성 파악 |
| 데이터 비교 | 집단 간 평균이나 비율 차이 확인          |
| 관계 파악  | 변수 간 관련성 확인                 |
| 예측     | 변수 간 관계를 이용해 결과값 예측         |
| 의사결정   | 데이터 기반으로 합리적인 판단 수행         |

시험에서는 이렇게 이해하면 된다.

```markdown id="uvokm0"
통계 분석은 데이터를 요약하고, 차이와 관계를 파악하여 의사결정을 지원하는 방법이다.
```

# 02. 기술통계와 추론통계

통계 분석은 크게 **기술통계**와 **추론통계**로 나눌 수 있다.

```markdown id="3i8iq9"
기술통계 = 현재 데이터를 요약
추론통계 = 표본을 통해 모집단을 추정
```

---

## 1) 기술통계

**기술통계**는 수집된 데이터를 요약하고 정리하는 통계 방법이다.

예를 들어 평균, 중앙값, 최빈값, 분산, 표준편차, 그래프 등이 기술통계에 해당한다.

```markdown id="ahjedn"
기술통계 = 데이터를 있는 그대로 요약하고 설명하는 통계
```

### 기술통계 예시

| 분석 항목 | 설명                   |
| ----- | -------------------- |
| 평균    | 데이터의 대표적인 중심값        |
| 중앙값   | 데이터를 정렬했을 때 가운데 값    |
| 최빈값   | 가장 자주 등장하는 값         |
| 분산    | 데이터가 평균에서 얼마나 퍼져 있는지 |
| 표준편차  | 분산의 제곱근              |
| 히스토그램 | 데이터 분포를 시각적으로 표현     |

기술통계는 표본을 넘어 모집단을 추정하는 것이 아니라,
현재 가지고 있는 데이터를 설명하는 데 초점이 있다.

---

## 2) 추론통계

**추론통계**는 표본 데이터를 바탕으로 모집단의 특성을 추정하거나 검정하는 통계 방법이다.

예를 들어 전체 고객 100만 명을 모두 조사하기 어렵다면,
일부 고객 표본을 뽑아 전체 고객의 평균 구매 금액을 추정할 수 있다.

```markdown id="v9glpg"
추론통계 = 표본을 이용해 모집단의 특성을 추정하거나 판단하는 통계
```

### 추론통계 예시

| 분석 항목  | 설명                      |
| ------ | ----------------------- |
| 모수 추정  | 표본을 통해 모집단 평균, 비율 등을 추정 |
| 신뢰구간   | 모수가 존재할 것으로 예상되는 범위     |
| 가설검정   | 주장이나 가설이 통계적으로 타당한지 판단  |
| t검정    | 두 집단 평균 차이 검정           |
| 분산분석   | 세 집단 이상 평균 차이 검정        |
| 카이제곱검정 | 범주형 변수 간 관계 검정          |

시험에서는 이렇게 구분하면 된다.

```markdown id="g1kauy"
기술통계는 데이터를 요약하는 것이고,
추론통계는 표본으로 모집단을 추정하거나 검정하는 것이다.
```

# 03. 중심 경향 측도

중심 경향 측도는 데이터가 어느 값을 중심으로 모여 있는지 나타내는 값이다.

대표적으로 다음 3가지가 있다.

```markdown id="0tpq64"
평균
중앙값
최빈값
```

---

## 1) 평균, Mean

**평균**은 모든 값을 더한 뒤 데이터 개수로 나눈 값이다.

```markdown id="yhxrr6"
평균 = 전체 합계 / 데이터 개수
```

예를 들어 다음 데이터가 있다.

```markdown id="heduqw"
10, 20, 30
```

평균은 다음과 같다.

```markdown id="51rz08"
(10 + 20 + 30) / 3 = 20
```

| 장점                 | 단점       |
| ------------------ | -------- |
| 계산이 쉽고 대표값으로 많이 사용 | 이상값에 민감함 |

평균은 가장 자주 쓰이는 중심값이지만, 이상값의 영향을 크게 받는다.

예를 들어 다음 데이터가 있다.

```markdown id="e90qql"
10, 20, 30, 1000
```

이 경우 평균은 매우 커진다.
따라서 이상값이 있는 데이터에서는 중앙값을 함께 보는 것이 좋다.

```markdown id="7j6um0"
평균은 모든 값을 반영하지만 이상값에 민감하다.
```

---

## 2) 중앙값, Median

**중앙값**은 데이터를 크기순으로 정렬했을 때 가운데에 위치한 값이다.

```markdown id="p36hsl"
중앙값 = 정렬된 데이터의 가운데 값
```

예를 들어 다음 데이터가 있다.

```markdown id="xripg5"
10, 20, 30
```

중앙값은 `20`이다.

데이터 개수가 짝수라면 가운데 두 값의 평균을 사용한다.

```markdown id="t9i8wv"
10, 20, 30, 40
```

중앙값은 다음과 같다.

```markdown id="3snv1y"
(20 + 30) / 2 = 25
```

| 장점             | 단점                  |
| -------------- | ------------------- |
| 이상값의 영향을 적게 받음 | 모든 값을 세밀하게 반영하지는 않음 |

시험에서는 이렇게 기억하면 된다.

```markdown id="de65n4"
중앙값은 이상값이 있는 경우 평균보다 대표값으로 적합할 수 있다.
```

---

## 3) 최빈값, Mode

**최빈값**은 데이터에서 가장 자주 등장하는 값이다.

```markdown id="ab6eeo"
최빈값 = 가장 많이 나타나는 값
```

예를 들어 다음 데이터가 있다.

```markdown id="p4zuh2"
A, B, B, C, C, C
```

최빈값은 `C`이다.

최빈값은 숫자형 데이터뿐 아니라 범주형 데이터에서도 사용할 수 있다.

| 장점              | 단점                  |
| --------------- | ------------------- |
| 범주형 데이터에도 사용 가능 | 최빈값이 없거나 여러 개일 수 있음 |

시험에서는 이렇게 기억하면 된다.

```markdown id="gjsgew"
최빈값은 가장 자주 등장하는 값이며, 범주형 데이터에도 사용할 수 있다.
```

---

## 중심 경향 측도 비교

| 구분  | 의미                  | 특징              |
| --- | ------------------- | --------------- |
| 평균  | 전체 합계를 데이터 개수로 나눈 값 | 이상값에 민감         |
| 중앙값 | 정렬했을 때 가운데 값        | 이상값에 강함         |
| 최빈값 | 가장 자주 등장하는 값        | 범주형 데이터에도 사용 가능 |

암기 방식은 다음과 같다.

```markdown id="2cu75p"
평균 = 합계 / 개수
중앙값 = 가운데 값
최빈값 = 가장 자주 나오는 값
```

# 04. 산포도

산포도는 데이터가 얼마나 퍼져 있는지 나타내는 값이다.

중심값이 같더라도 데이터가 모여 있는 정도는 다를 수 있다.

예를 들어 두 반의 평균 점수가 모두 80점이라고 하자.

```markdown id="ls8y1g"
A반: 78, 79, 80, 81, 82
B반: 50, 60, 80, 100, 110
```

두 반의 평균은 비슷할 수 있지만, B반의 점수가 훨씬 더 많이 퍼져 있다.
이런 퍼짐 정도를 나타내는 것이 산포도다.

```markdown id="4wbr6f"
산포도 = 데이터가 중심값 주변에 얼마나 흩어져 있는지를 나타내는 값
```

대표적인 산포도는 다음과 같다.

```markdown id="k8oz3q"
범위
분산
표준편차
사분위수 범위
```

---

## 1) 범위, Range

**범위**는 최댓값에서 최솟값을 뺀 값이다.

```markdown id="mk2ccd"
범위 = 최댓값 - 최솟값
```

예를 들어 다음 데이터가 있다.

```markdown id="dd22pi"
10, 20, 30, 40
```

범위는 다음과 같다.

```markdown id="4ulvgn"
40 - 10 = 30
```

| 장점         | 단점                      |
| ---------- | ----------------------- |
| 계산이 매우 간단함 | 최댓값과 최솟값에만 의존하여 이상값에 민감 |

```markdown id="bmjjrd"
범위는 데이터의 전체 퍼짐을 간단히 보여주지만 이상값에 민감하다.
```

---

## 2) 분산, Variance

**분산**은 각 데이터가 평균에서 얼마나 떨어져 있는지를 제곱하여 평균낸 값이다.

```markdown id="fjqj9w"
분산 = 평균으로부터 떨어진 정도의 제곱 평균
```

분산이 크면 데이터가 평균 주변에 넓게 퍼져 있고,
분산이 작으면 데이터가 평균 주변에 모여 있다는 의미다.

| 분산 크기  | 의미                |
| ------ | ----------------- |
| 분산이 큼  | 데이터가 많이 흩어져 있음    |
| 분산이 작음 | 데이터가 평균 근처에 모여 있음 |

분산은 편차를 제곱하기 때문에 단위가 원래 데이터 단위와 달라진다.

예를 들어 점수 데이터의 분산 단위는 점수가 아니라 점수의 제곱 형태가 된다.

```markdown id="s8pimf"
분산은 데이터의 퍼짐 정도를 나타내지만, 단위가 제곱되어 해석이 어렵다.
```

---

## 3) 표준편차, Standard Deviation

**표준편차**는 분산의 제곱근이다.

```markdown id="ioee1t"
표준편차 = 분산의 제곱근
```

표준편차는 분산과 달리 원래 데이터와 같은 단위를 가지므로 해석하기 쉽다.

예를 들어 점수 데이터의 표준편차는 다시 점수 단위로 해석할 수 있다.

| 표준편차 크기  | 의미                 |
| -------- | ------------------ |
| 표준편차가 큼  | 데이터가 평균에서 멀리 퍼져 있음 |
| 표준편차가 작음 | 데이터가 평균 근처에 모여 있음  |

시험에서는 이렇게 기억하면 된다.

```markdown id="mpr8h2"
표준편차는 분산의 제곱근이며, 데이터가 평균에서 얼마나 흩어져 있는지 나타낸다.
```

---

## 4) 사분위수와 IQR

**사분위수**는 데이터를 크기순으로 정렬했을 때 4등분하는 위치의 값이다.

| 구분 | 의미                |
| -- | ----------------- |
| Q1 | 제1사분위수, 하위 25% 위치 |
| Q2 | 제2사분위수, 중앙값       |
| Q3 | 제3사분위수, 하위 75% 위치 |

**IQR**은 Q3에서 Q1을 뺀 값이다.

```markdown id="o3ck2l"
IQR = Q3 - Q1
```

IQR은 이상값 탐지에도 자주 사용된다.

```markdown id="ej3ivd"
Q1 - 1.5IQR보다 작거나 Q3 + 1.5IQR보다 크면 이상값으로 판단할 수 있다.
```

---

## 산포도 비교

| 구분   | 의미            | 특징              |
| ---- | ------------- | --------------- |
| 범위   | 최댓값 - 최솟값     | 계산은 쉽지만 이상값에 민감 |
| 분산   | 평균과의 거리 제곱 평균 | 퍼짐 정도를 나타냄      |
| 표준편차 | 분산의 제곱근       | 원래 단위로 해석 가능    |
| IQR  | Q3 - Q1       | 이상값 영향을 덜 받음    |

암기 방식은 다음과 같다.

```markdown id="qto5va"
범위 = 최대 - 최소
분산 = 편차 제곱의 평균
표준편차 = 분산의 제곱근
IQR = Q3 - Q1
```

# 05. 표본과 모집단

## 모집단

**모집단**은 연구나 분석의 대상이 되는 전체 집단이다.

예를 들어 “대한민국 성인 남성의 평균 키”를 알고 싶다면,
대한민국 성인 남성 전체가 모집단이다.

```markdown id="1ffmw5"
모집단 = 분석 대상이 되는 전체 집단
```

---

## 표본

**표본**은 모집단에서 일부를 추출한 집단이다.

모집단 전체를 조사하기 어렵기 때문에 일부 표본을 조사하고, 이를 통해 모집단을 추정한다.

```markdown id="g1dedj"
표본 = 모집단에서 추출한 일부 데이터
```

---

## 모수와 통계량

| 구분  | 의미              | 예시             |
| --- | --------------- | -------------- |
| 모수  | 모집단의 특성을 나타내는 값 | 모집단 평균, 모집단 분산 |
| 통계량 | 표본의 특성을 나타내는 값  | 표본 평균, 표본 분산   |

시험에서는 이렇게 기억하면 된다.

```markdown id="d22vti"
모수는 모집단의 값이고,
통계량은 표본에서 계산한 값이다.
```

# 06. 공분산과 상관계수

공분산과 상관계수는 두 변수 간 관계를 파악할 때 사용한다.

```markdown id="kel0bo"
공분산과 상관계수 = 두 변수가 함께 변하는 정도를 나타내는 지표
```

---

## 1) 공분산

**공분산**은 두 변수가 함께 변하는 방향을 나타내는 값이다.

| 공분산 값 | 의미                         |
| ----- | -------------------------- |
| 양수    | 한 변수가 증가할 때 다른 변수도 증가하는 경향 |
| 음수    | 한 변수가 증가할 때 다른 변수는 감소하는 경향 |
| 0 근처  | 두 변수 간 선형 관계가 약함           |

예를 들어 공부 시간이 증가할수록 시험 점수가 증가한다면 공분산은 양수다.
반대로 가격이 증가할수록 수요가 감소한다면 공분산은 음수다.

```markdown id="yklkch"
공분산은 두 변수의 관계 방향을 나타내지만, 단위의 영향을 받아 크기 해석이 어렵다.
```

---

## 2) 상관계수

**상관계수**는 공분산을 표준화한 값으로, 두 변수 간 선형 관계의 방향과 강도를 나타낸다.

상관계수는 보통 `-1`에서 `1` 사이의 값을 가진다.

|    상관계수 | 의미          |
| ------: | ----------- |
|  1에 가까움 | 강한 양의 상관관계  |
| -1에 가까움 | 강한 음의 상관관계  |
|  0에 가까움 | 선형 상관관계가 약함 |

```markdown id="vjsk9x"
상관계수 = 두 변수 간 선형 관계의 방향과 강도를 나타내는 표준화된 지표
```

상관계수는 공분산과 달리 단위 영향을 제거했기 때문에 비교와 해석이 쉽다.

---

## 공분산과 상관계수 비교

| 구분    | 공분산             | 상관계수               |
| ----- | --------------- | ------------------ |
| 의미    | 두 변수가 함께 변하는 방향 | 두 변수의 선형 관계 방향과 강도 |
| 값의 범위 | 제한 없음           | -1 ~ 1             |
| 단위 영향 | 있음              | 없음                 |
| 해석    | 크기 해석 어려움       | 비교적 쉬움             |

시험에서는 이렇게 기억하면 된다.

```markdown id="2i1t80"
공분산은 방향을 보고,
상관계수는 방향과 강도를 본다.
```

# 07. 가설검정

## 가설검정의 개념

**가설검정**은 모집단에 대한 가설이 통계적으로 타당한지 표본 데이터를 이용해 판단하는 방법이다.

예를 들어 다음과 같은 주장이 있다고 하자.

```markdown id="ky0ohj"
새로운 교육 프로그램을 적용하면 평균 점수가 올라간다.
```

이 주장이 맞는지 전체 학생을 모두 조사하기 어렵다면,
일부 학생 표본을 대상으로 실험하고 통계적으로 판단한다.

```markdown id="2mstcp"
가설검정 = 표본 데이터를 이용해 모집단에 대한 주장이 타당한지 판단하는 절차
```

---

## 귀무가설과 대립가설

가설검정에서는 보통 두 가지 가설을 세운다.

| 구분       | 의미                     |
| -------- | ---------------------- |
| 귀무가설, H0 | 차이가 없다, 효과가 없다, 관계가 없다 |
| 대립가설, H1 | 차이가 있다, 효과가 있다, 관계가 있다 |

예를 들어 신약 효과를 검정한다고 하자.

```markdown id="iajfay"
귀무가설 H0: 신약은 효과가 없다.
대립가설 H1: 신약은 효과가 있다.
```

시험에서는 귀무가설을 기준 상태로 이해하면 된다.

```markdown id="6cb1wh"
귀무가설은 차이·효과·관계가 없다는 기본 가설이고,
대립가설은 차이·효과·관계가 있다는 주장이다.
```

---

## 유의수준과 p-value

**유의수준**은 귀무가설을 기각할 기준이 되는 확률이다.

일반적으로 `0.05`, 즉 5%를 많이 사용한다.

```markdown id="s0uofv"
유의수준 = 귀무가설을 기각할 판단 기준
```

**p-value**는 귀무가설이 참이라고 가정했을 때, 현재와 같은 결과가 나올 확률이다.

| 조건             | 판단           |
| -------------- | ------------ |
| p-value < 유의수준 | 귀무가설 기각      |
| p-value ≥ 유의수준 | 귀무가설 기각하지 않음 |

시험에서는 이 기준을 반드시 기억해야 한다.

```markdown id="1mzj11"
p-value가 유의수준보다 작으면 귀무가설을 기각한다.
```

예를 들어 유의수준이 0.05이고 p-value가 0.03이면 다음처럼 판단한다.

```markdown id="gyeqpr"
0.03 < 0.05 → 귀무가설 기각 → 통계적으로 유의함
```

반대로 p-value가 0.08이면 다음처럼 판단한다.

```markdown id="17ylcd"
0.08 ≥ 0.05 → 귀무가설 기각하지 않음 → 통계적으로 유의하다고 보기 어려움
```

# 08. 주요 검정 방법

ADsP에서는 검정 방법의 자세한 계산보다 **어떤 상황에서 어떤 검정을 쓰는지**가 중요하다.

---

## 1) t검정

**t검정**은 두 집단의 평균 차이를 검정할 때 사용한다.

예를 들어 남학생과 여학생의 평균 점수 차이가 있는지 확인할 때 사용할 수 있다.

```markdown id="jq1knp"
t검정 = 두 집단 평균 차이 검정
```

| 상황         | 예시                  |
| ---------- | ------------------- |
| 두 집단 평균 비교 | 남학생과 여학생 평균 점수 차이   |
| 전후 평균 비교   | 교육 전과 교육 후 평균 점수 차이 |

시험에서는 이렇게 기억하면 된다.

```markdown id="39dvzs"
두 집단 평균 차이 = t검정
```

---

## 2) 분산분석, ANOVA

**분산분석(ANOVA)**은 세 집단 이상의 평균 차이를 검정할 때 사용한다.

예를 들어 A, B, C 세 가지 교육 방법에 따라 평균 점수 차이가 있는지 확인할 때 사용한다.

```markdown id="18m0ud"
분산분석 = 세 집단 이상 평균 차이 검정
```

| 상황            | 예시                    |
| ------------- | --------------------- |
| 세 집단 이상 평균 비교 | A/B/C 교육 방법별 평균 점수 차이 |
| 여러 그룹 비교      | 지역별 평균 매출 차이          |

시험에서는 이렇게 기억하면 된다.

```markdown id="o42vq6"
세 집단 이상 평균 차이 = 분산분석
```

---

## 3) 카이제곱검정

**카이제곱검정**은 범주형 변수 간 관련성을 검정할 때 사용한다.

예를 들어 성별과 상품 선호도가 관련이 있는지 확인할 수 있다.

```markdown id="9mwl9g"
카이제곱검정 = 범주형 변수 간 관계 검정
```

| 상황        | 예시                  |
| --------- | ------------------- |
| 범주형 변수 관계 | 성별과 구매 여부의 관계       |
| 독립성 검정    | 지역과 선호 브랜드가 독립인지 확인 |

시험에서는 이렇게 기억하면 된다.

```markdown id="phs7rr"
범주형 변수 간 관계 = 카이제곱검정
```

---

## 주요 검정 방법 비교

| 검정 방법  | 사용 상황         | 예시           |
| ------ | ------------- | ------------ |
| t검정    | 두 집단 평균 차이    | 남녀 평균 점수 차이  |
| 분산분석   | 세 집단 이상 평균 차이 | 지역별 평균 매출 차이 |
| 카이제곱검정 | 범주형 변수 간 관계   | 성별과 구매 여부 관계 |

암기 방식은 다음과 같다.

```markdown id="c2kql4"
두 평균 = t검정
세 개 이상 평균 = 분산분석
범주형 관계 = 카이제곱검정
```

# 09. 상관분석과 회귀분석

## 1) 상관분석

**상관분석**은 두 변수 간 선형 관계의 방향과 강도를 파악하는 분석이다.

예를 들어 공부 시간과 시험 점수 사이에 관계가 있는지 확인할 수 있다.

```markdown id="g2crz3"
상관분석 = 두 변수 간 선형 관계의 방향과 강도 분석
```

상관분석에서는 상관계수를 사용한다.

| 상관계수 | 의미                    |
| ---: | --------------------- |
|   양수 | 한 변수가 증가할 때 다른 변수도 증가 |
|   음수 | 한 변수가 증가할 때 다른 변수는 감소 |
| 0 근처 | 선형 관계가 약함             |

상관분석은 관계를 파악하는 것이지, 원인과 결과를 확정하는 분석은 아니다.

```markdown id="o13s21"
상관관계가 있다고 해서 인과관계가 있다고 단정할 수 없다.
```

---

## 2) 회귀분석

**회귀분석**은 독립변수를 이용해 종속변수를 설명하거나 예측하는 분석이다.

예를 들어 공부 시간을 이용해 시험 점수를 예측할 수 있다.

```markdown id="qsxk60"
회귀분석 = 독립변수를 이용해 종속변수를 설명하거나 예측하는 분석
```

| 구분   | 의미             |
| ---- | -------------- |
| 독립변수 | 원인 또는 설명 변수    |
| 종속변수 | 결과 또는 예측 대상 변수 |

예시:

```markdown id="7v1cl5"
독립변수: 공부 시간
종속변수: 시험 점수
```

공부 시간이 시험 점수에 어떤 영향을 주는지 분석하는 것이 회귀분석이다.

---

## 상관분석과 회귀분석 비교

| 구분    | 상관분석               | 회귀분석               |
| ----- | ------------------ | ------------------ |
| 목적    | 변수 간 관계의 방향과 강도 파악 | 변수 간 관계를 이용해 설명·예측 |
| 변수 구분 | 독립/종속 구분 없음        | 독립변수와 종속변수 구분      |
| 결과    | 상관계수               | 회귀식, 회귀계수          |
| 핵심    | 관계 파악              | 예측과 설명             |

시험에서는 이렇게 기억하면 된다.

```markdown id="8i0ezw"
상관분석은 관계의 방향과 강도를 보는 것이고,
회귀분석은 독립변수로 종속변수를 설명하거나 예측하는 것이다.
```

# 10. R 기초 통계 함수

R에서 기초 통계 분석에 자주 사용하는 함수는 다음과 같다.

| 함수             | 설명      |
| -------------- | ------- |
| `mean()`       | 평균      |
| `median()`     | 중앙값     |
| `var()`        | 분산      |
| `sd()`         | 표준편차    |
| `range()`      | 범위      |
| `min()`        | 최솟값     |
| `max()`        | 최댓값     |
| `summary()`    | 요약 통계   |
| `quantile()`   | 분위수     |
| `IQR()`        | 사분위 범위  |
| `cov()`        | 공분산     |
| `cor()`        | 상관계수    |
| `t.test()`     | t검정     |
| `aov()`        | 분산분석    |
| `chisq.test()` | 카이제곱검정  |
| `lm()`         | 선형 회귀분석 |

---

## 자주 쓰는 예시

```r id="t7ghys"
x <- c(10, 20, 30, 40, 50)

mean(x)
median(x)
var(x)
sd(x)
summary(x)
```

상관계수는 다음처럼 구할 수 있다.

```r id="p7nhu0"
x <- c(1, 2, 3, 4, 5)
y <- c(2, 4, 6, 8, 10)

cor(x, y)
```

회귀분석은 `lm()`을 사용한다.

```r id="sxg5dl"
model <- lm(y ~ x)
summary(model)
```

시험에서는 함수명과 역할을 연결해서 기억하면 된다.

```markdown id="t7tsxd"
cor() = 상관계수
lm() = 선형 회귀분석
t.test() = t검정
aov() = 분산분석
chisq.test() = 카이제곱검정
```

```markdown id="bit27b"
기초 통계 분석은 데이터의 중심, 퍼짐, 관계, 차이를 파악하여
데이터의 특성을 이해하고 의사결정을 지원하는 분석이다.

기술통계는 수집된 데이터를 평균, 중앙값, 표준편차, 그래프 등으로 요약하고 설명하는 통계이다.

추론통계는 표본 데이터를 이용해 모집단의 특성을 추정하거나 가설을 검정하는 통계이다.

평균은 전체 합계를 데이터 개수로 나눈 값이며, 이상값에 민감하다.

중앙값은 데이터를 크기순으로 정렬했을 때 가운데 위치한 값이며,
이상값의 영향을 평균보다 적게 받는다.

최빈값은 데이터에서 가장 자주 등장하는 값이며, 범주형 데이터에도 사용할 수 있다.

범위는 최댓값에서 최솟값을 뺀 값이고,
분산은 데이터가 평균에서 얼마나 떨어져 있는지를 제곱하여 평균낸 값이다.

표준편차는 분산의 제곱근이며,
데이터가 평균 주변에 얼마나 흩어져 있는지를 나타낸다.

IQR은 Q3에서 Q1을 뺀 값이며,
사분위수 기반 이상값 탐지에 사용된다.

모집단은 분석 대상 전체 집단이고,
표본은 모집단에서 추출한 일부 데이터이다.

모수는 모집단의 특성을 나타내는 값이고,
통계량은 표본의 특성을 나타내는 값이다.

공분산은 두 변수가 함께 변하는 방향을 나타내고,
상관계수는 두 변수 간 선형 관계의 방향과 강도를 나타낸다.

상관계수는 -1에서 1 사이의 값을 가지며,
1에 가까우면 강한 양의 상관관계,
-1에 가까우면 강한 음의 상관관계를 의미한다.

귀무가설은 차이, 효과, 관계가 없다는 기본 가설이고,
대립가설은 차이, 효과, 관계가 있다는 주장이다.

p-value가 유의수준보다 작으면 귀무가설을 기각하고,
통계적으로 유의하다고 판단한다.

t검정은 두 집단의 평균 차이를 검정할 때 사용하고,
분산분석은 세 집단 이상의 평균 차이를 검정할 때 사용한다.

카이제곱검정은 범주형 변수 간 관계를 검정할 때 사용한다.

상관분석은 두 변수 간 관계의 방향과 강도를 파악하는 분석이고,
회귀분석은 독립변수를 이용해 종속변수를 설명하거나 예측하는 분석이다.
```
