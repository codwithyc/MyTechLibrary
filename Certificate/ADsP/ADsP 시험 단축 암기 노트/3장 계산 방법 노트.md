# 3장 데이터 분석 계산 공식 정리

## 01. 기초 통계 계산

### 1. 평균

평균은 모든 값을 더한 뒤 데이터 개수로 나눈 값이다.

공식:
평균 = 데이터의 합 / 데이터 개수

예시:
데이터가 2, 4, 6, 8일 때

평균 = (2 + 4 + 6 + 8) / 4
평균 = 20 / 4
평균 = 5

---

### 2. 편차

편차는 각 데이터 값에서 평균을 뺀 값이다.

공식:
편차 = 데이터 값 - 평균

예시:
데이터가 2, 4, 6, 8이고 평균이 5일 때

2의 편차 = 2 - 5 = -3
4의 편차 = 4 - 5 = -1
6의 편차 = 6 - 5 = 1
8의 편차 = 8 - 5 = 3

편차의 합은 항상 0이다.

---

### 3. 분산

분산은 데이터가 평균으로부터 얼마나 흩어져 있는지를 나타낸다.

모분산 공식:
모분산 = 편차 제곱의 합 / n

표본분산 공식:
표본분산 = 편차 제곱의 합 / (n - 1)

예시:
데이터가 2, 4, 6, 8일 때 평균은 5이다.

편차:
-3, -1, 1, 3

편차 제곱:
9, 1, 1, 9

편차 제곱의 합:
20

모분산 = 20 / 4 = 5

표본분산 = 20 / 3 = 6.67

시험에서 단순히 분산을 묻는 경우에는 문제 조건에서 모집단인지 표본인지 확인해야 한다.

---

### 4. 표준편차

표준편차는 분산의 제곱근이다.

공식:
표준편차 = √분산

예시:
분산이 25이면

표준편차 = √25 = 5

분산은 단위가 제곱되지만,
표준편차는 원래 데이터와 같은 단위로 해석할 수 있다.

---

## 02. 분위수와 IQR 계산

### 1. 중앙값

중앙값은 데이터를 크기순으로 정렬했을 때 가운데 위치한 값이다.

예시 1:
데이터가 1, 3, 5, 7, 9이면

중앙값 = 5

예시 2:
데이터가 1, 3, 5, 7이면

중앙값 = (3 + 5) / 2 = 4

---

### 2. 사분위수

사분위수는 데이터를 4등분하는 위치의 값이다.

Q1 = 제1사분위수, 하위 25%
Q2 = 제2사분위수, 중앙값
Q3 = 제3사분위수, 하위 75%

---

### 3. IQR

IQR은 제3사분위수에서 제1사분위수를 뺀 값이다.

공식:
IQR = Q3 - Q1

예시:
Q1 = 20, Q3 = 50이면

IQR = 50 - 20 = 30

---

### 4. 이상값 판단 기준

IQR을 이용해 이상값을 판단할 수 있다.

하한값:
Q1 - 1.5 × IQR

상한값:
Q3 + 1.5 × IQR

예시:
Q1 = 20, Q3 = 50이면

IQR = 50 - 20 = 30

하한값 = 20 - 1.5 × 30 = 20 - 45 = -25
상한값 = 50 + 1.5 × 30 = 50 + 45 = 95

따라서 -25보다 작거나 95보다 큰 값은 이상값으로 볼 수 있다.

---

## 03. 확률 계산

### 1. 확률

확률은 특정 사건이 발생할 가능성이다.

공식:
확률 = 사건이 발생한 경우의 수 / 전체 경우의 수

예시:
주사위를 던져 3이 나올 확률

확률 = 1 / 6

---

### 2. 여사건 확률

어떤 사건 A가 발생하지 않을 확률은 1에서 A가 발생할 확률을 뺀 값이다.

공식:
P(A가 아님) = 1 - P(A)

예시:
비가 올 확률이 0.3이면

비가 오지 않을 확률 = 1 - 0.3 = 0.7

---

### 3. 조건부 확률

조건부 확률은 어떤 사건이 발생했다는 조건에서 다른 사건이 발생할 확률이다.

공식:
P(A | B) = P(A ∩ B) / P(B)

의미:
B가 발생한 상황에서 A가 발생할 확률

예시:
전체 고객 중 광고를 클릭한 고객이 100명이고,
그중 구매한 고객이 20명이라면

P(구매 | 광고 클릭) = 20 / 100 = 0.2

---

### 4. 독립사건

두 사건 A와 B가 독립이면 한 사건의 발생이 다른 사건의 발생 확률에 영향을 주지 않는다.

공식:
P(A ∩ B) = P(A) × P(B)

예시:
동전을 던져 앞면이 나올 확률 = 1/2
주사위를 던져 6이 나올 확률 = 1/6

둘이 동시에 발생할 확률:

P(앞면 ∩ 6) = 1/2 × 1/6 = 1/12

---

### 5. 배반사건

두 사건 A와 B가 동시에 발생할 수 없으면 배반사건이다.

공식:
P(A ∩ B) = 0

A 또는 B가 발생할 확률:
P(A ∪ B) = P(A) + P(B)

예시:
주사위를 한 번 던져 1이 나오는 사건과 2가 나오는 사건은 동시에 발생할 수 없다.

P(1 또는 2) = 1/6 + 1/6 = 2/6 = 1/3

---

### 6. 일반적인 합집합 확률

두 사건이 배반사건이 아닐 때는 중복되는 부분을 빼야 한다.

공식:
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)

예시:
P(A) = 0.5
P(B) = 0.4
P(A ∩ B) = 0.2

P(A ∪ B) = 0.5 + 0.4 - 0.2 = 0.7

---

## 04. 확률분포의 기댓값과 분산

### 1. 기댓값

기댓값은 확률변수가 평균적으로 가질 것으로 기대되는 값이다.

공식:
E(X) = Σ x × P(x)

계산 순서:
1. 확률변수 값 x를 확인한다.
2. 각 값의 확률 P(x)를 확인한다.
3. x와 P(x)를 곱한다.
4. 모두 더한다.

예시:
어떤 확률변수 X가 다음과 같을 때

| X | P(X) |
|---|---|
| 1 | 0.2 |
| 2 | 0.5 |
| 3 | 0.3 |

E(X) = 1×0.2 + 2×0.5 + 3×0.3
E(X) = 0.2 + 1.0 + 0.9
E(X) = 2.1

따라서 기댓값은 2.1이다.

---

### 2. 확률분포의 분산

확률분포의 분산은 확률변수가 기댓값으로부터 얼마나 흩어져 있는지 나타낸다.

공식:
Var(X) = Σ (x - E(X))² × P(x)

또는

Var(X) = E(X²) - [E(X)]²

계산에서는 두 번째 공식이 더 빠르다.

---

### 3. E(X²) 계산

E(X²)는 X 값을 제곱한 뒤 확률을 곱해서 더한 값이다.

공식:
E(X²) = Σ x² × P(x)

예시:
위의 예시에서

| X | P(X) |
|---|---|
| 1 | 0.2 |
| 2 | 0.5 |
| 3 | 0.3 |

E(X) = 2.1

E(X²) = 1²×0.2 + 2²×0.5 + 3²×0.3
E(X²) = 1×0.2 + 4×0.5 + 9×0.3
E(X²) = 0.2 + 2.0 + 2.7
E(X²) = 4.9

Var(X) = E(X²) - [E(X)]²
Var(X) = 4.9 - 2.1²
Var(X) = 4.9 - 4.41
Var(X) = 0.49

표준편차 = √0.49 = 0.7

---

## 05. 대표 확률분포 계산

### 1. 베르누이 분포

베르누이 분포는 성공/실패처럼 결과가 두 가지인 분포이다.

성공 확률이 p일 때

기댓값:
E(X) = p

분산:
Var(X) = p(1 - p)

예시:
구매할 확률이 0.3이면

E(X) = 0.3

Var(X) = 0.3 × 0.7 = 0.21

---

### 2. 이항 분포

이항 분포는 베르누이 시행을 n번 반복했을 때 성공 횟수의 분포이다.

성공 확률이 p이고 시행 횟수가 n일 때

기댓값:
E(X) = np

분산:
Var(X) = np(1 - p)

예시:
불량률이 0.1인 제품을 20개 검사할 때 불량품 개수의 기댓값은

E(X) = 20 × 0.1 = 2

분산은

Var(X) = 20 × 0.1 × 0.9 = 1.8

---

### 3. 포아송 분포

포아송 분포는 일정 구간에서 사건이 발생하는 횟수의 분포이다.

평균 발생 횟수가 λ일 때

기댓값:
E(X) = λ

분산:
Var(X) = λ

예시:
1시간 평균 문의 수가 5건이면

E(X) = 5
Var(X) = 5

포아송 분포는 평균과 분산이 같다.

---

### 4. 균일 분포

이산형 균일 분포에서 모든 값이 같은 확률을 가진다.

예시:
공정한 주사위의 눈 X는 1, 2, 3, 4, 5, 6이다.

E(X) = (1 + 2 + 3 + 4 + 5 + 6) / 6
E(X) = 21 / 6 = 3.5

---

## 06. 공분산과 상관계수 계산

### 1. 공분산

공분산은 두 변수가 함께 변하는 방향을 나타낸다.

표본 공분산 공식:
Cov(X, Y) = Σ(x - x̄)(y - ȳ) / (n - 1)

모공분산 공식:
Cov(X, Y) = Σ(x - μx)(y - μy) / n

시험에서는 보통 표본 공분산 형태를 많이 사용한다.

계산 순서:
1. X의 평균을 구한다.
2. Y의 평균을 구한다.
3. 각 X값에서 X평균을 뺀다.
4. 각 Y값에서 Y평균을 뺀다.
5. 두 편차를 곱한다.
6. 곱한 값을 모두 더한다.
7. 표본이면 n - 1로 나누고, 모집단이면 n으로 나눈다.

예시:

| 번호 | X | Y |
|---|---:|---:|
| 1 | 1 | 2 |
| 2 | 2 | 4 |
| 3 | 3 | 6 |

X 평균 = (1 + 2 + 3) / 3 = 2
Y 평균 = (2 + 4 + 6) / 3 = 4

| X | Y | x - x̄ | y - ȳ | 편차 곱 |
|---|---:|---:|---:|---:|
| 1 | 2 | -1 | -2 | 2 |
| 2 | 4 | 0 | 0 | 0 |
| 3 | 6 | 1 | 2 | 2 |

편차 곱의 합 = 4

표본 공분산 = 4 / (3 - 1) = 2

공분산이 양수이면 두 변수는 같은 방향으로 움직인다.
공분산이 음수이면 두 변수는 반대 방향으로 움직인다.
공분산이 0에 가까우면 선형 관계가 약하다.

---

### 2. 상관계수

상관계수는 공분산을 표준화하여 두 변수의 선형 관계 방향과 강도를 나타낸다.

공식:
r = Cov(X, Y) / (Sx × Sy)

Sx = X의 표준편차
Sy = Y의 표준편차

해석:
r이 1에 가까우면 강한 양의 상관관계
r이 -1에 가까우면 강한 음의 상관관계
r이 0에 가까우면 선형 관계가 약함

예시:
Cov(X, Y) = 10
X의 표준편차 = 2
Y의 표준편차 = 5

r = 10 / (2 × 5)
r = 10 / 10
r = 1

따라서 완전한 양의 상관관계이다.

---

## 07. 데이터 변환 계산

### 1. 최소-최대 정규화

최소-최대 정규화는 데이터를 0과 1 사이로 변환한다.

공식:
x' = (x - 최솟값) / (최댓값 - 최솟값)

예시:
데이터가 10, 20, 30, 40, 50이고
x = 30일 때

x' = (30 - 10) / (50 - 10)
x' = 20 / 40
x' = 0.5

---

### 2. 중심화

중심화는 각 값에서 평균을 빼는 것이다.

공식:
x' = x - 평균

예시:
평균이 50이고 x = 70이면

x' = 70 - 50 = 20

---

### 3. 표준화

표준화는 평균이 0, 표준편차가 1이 되도록 변환하는 것이다.

공식:
z = (x - 평균) / 표준편차

예시:
평균이 70, 표준편차가 10, x = 85일 때

z = (85 - 70) / 10
z = 15 / 10
z = 1.5

즉, 85는 평균보다 표준편차 1.5개만큼 높은 값이다.

---

## 08. 회귀 평가 지표 계산

### 1. MAE

MAE는 실제값과 예측값 차이의 절댓값 평균이다.

공식:
MAE = Σ |실제값 - 예측값| / n

예시:

| 실제값 | 예측값 | 절대 오차 |
|---:|---:|---:|
| 100 | 90 | 10 |
| 200 | 210 | 10 |
| 300 | 330 | 30 |

MAE = (10 + 10 + 30) / 3
MAE = 50 / 3
MAE = 16.67

---

### 2. MSE

MSE는 실제값과 예측값 차이를 제곱한 값의 평균이다.

공식:
MSE = Σ (실제값 - 예측값)² / n

예시:

오차가 10, -10, -30이라면

제곱 오차 = 100, 100, 900

MSE = (100 + 100 + 900) / 3
MSE = 1100 / 3
MSE = 366.67

---

### 3. RMSE

RMSE는 MSE의 제곱근이다.

공식:
RMSE = √MSE

예시:
MSE = 366.67이면

RMSE = √366.67
RMSE ≈ 19.15

---

### 4. MAPE

MAPE는 절대 오차를 실제값으로 나누어 백분율로 표현한 지표이다.

공식:
MAPE = Σ |실제값 - 예측값| / 실제값 × 100 / n

예시:

| 실제값 | 예측값 | 절대 오차 | 절대 백분율 오차 |
|---:|---:|---:|---:|
| 100 | 90 | 10 | 10% |
| 200 | 210 | 10 | 5% |
| 300 | 330 | 30 | 10% |

MAPE = (10% + 5% + 10%) / 3
MAPE = 8.33%

---

## 09. 분류 평가 지표 계산

### 1. 오차 행렬

| 실제 / 예측 | Positive 예측 | Negative 예측 |
|---|---:|---:|
| 실제 Positive | TP | FN |
| 실제 Negative | FP | TN |

TP = 실제 Positive를 Positive로 맞게 예측
TN = 실제 Negative를 Negative로 맞게 예측
FP = 실제 Negative를 Positive로 잘못 예측
FN = 실제 Positive를 Negative로 잘못 예측

---

### 2. 정확도

공식:
정확도 = (TP + TN) / (TP + TN + FP + FN)

---

### 3. 오분류율

공식:
오분류율 = (FP + FN) / (TP + TN + FP + FN)

또는

오분류율 = 1 - 정확도

---

### 4. 정밀도

공식:
정밀도 = TP / (TP + FP)

의미:
Positive라고 예측한 것 중 실제 Positive인 비율

---

### 5. 재현율

공식:
재현율 = TP / (TP + FN)

의미:
실제 Positive 중 Positive로 맞게 찾아낸 비율

---

### 6. F1 Score

공식:
F1 Score = 2 × (정밀도 × 재현율) / (정밀도 + 재현율)

---

### 7. FPR

공식:
FPR = FP / (FP + TN)

의미:
실제 Negative 중 Positive로 잘못 예측한 비율

---

### 8. 분류 지표 계산 예시

| 실제 / 예측 | Positive 예측 | Negative 예측 |
|---|---:|---:|
| 실제 Positive | 40 | 10 |
| 실제 Negative | 5 | 45 |

TP = 40
FN = 10
FP = 5
TN = 45

전체 = 40 + 10 + 5 + 45 = 100

정확도 = (TP + TN) / 전체
정확도 = (40 + 45) / 100 = 0.85

오분류율 = (FP + FN) / 전체
오분류율 = (5 + 10) / 100 = 0.15

정밀도 = TP / (TP + FP)
정밀도 = 40 / (40 + 5) = 40 / 45 = 0.889

재현율 = TP / (TP + FN)
재현율 = 40 / (40 + 10) = 40 / 50 = 0.8

F1 Score = 2 × (0.889 × 0.8) / (0.889 + 0.8)
F1 Score ≈ 0.842

FPR = FP / (FP + TN)
FPR = 5 / (5 + 45) = 5 / 50 = 0.1

---

## 10. 연관 분석 계산

### 1. 지지도

지지도는 전체 거래 중 A와 B가 함께 발생한 비율이다.

공식:
Support(A → B) = P(A ∩ B)

또는

지지도 = A와 B를 모두 포함한 거래 수 / 전체 거래 수

---

### 2. 신뢰도

신뢰도는 A가 발생한 거래 중 B도 함께 발생한 비율이다.

공식:
Confidence(A → B) = P(B | A)

또는

신뢰도 = A와 B를 모두 포함한 거래 수 / A를 포함한 거래 수

---

### 3. 향상도

향상도는 A가 B의 발생 가능성을 얼마나 높이는지 나타내는 지표이다.

공식:
Lift(A → B) = Confidence(A → B) / P(B)

또는

향상도 = P(A ∩ B) / [P(A) × P(B)]

해석:
향상도 > 1 : 양의 연관 관계
향상도 = 1 : 독립
향상도 < 1 : 음의 연관 관계

---

### 4. 연관 분석 계산 예시

전체 거래 수 = 100건
A를 포함한 거래 수 = 40건
B를 포함한 거래 수 = 50건
A와 B를 모두 포함한 거래 수 = 20건

지지도 = 20 / 100 = 0.2

신뢰도 = 20 / 40 = 0.5

P(B) = 50 / 100 = 0.5

향상도 = 신뢰도 / P(B)
향상도 = 0.5 / 0.5 = 1

따라서 A와 B는 독립 관계로 볼 수 있다.

# 시험 직전 계산 공식 초압축

평균 = 합계 / 개수

편차 = 값 - 평균

분산 = 편차 제곱의 평균

표준편차 = √분산

IQR = Q3 - Q1

이상값 하한 = Q1 - 1.5 × IQR

이상값 상한 = Q3 + 1.5 × IQR

조건부 확률 = P(A ∩ B) / P(B)

독립사건 = P(A ∩ B) = P(A) × P(B)

배반사건 = P(A ∩ B) = 0

기댓값 = Σ xP(x)

분산 = E(X²) - [E(X)]²

베르누이 평균 = p

베르누이 분산 = p(1-p)

이항 평균 = np

이항 분산 = np(1-p)

포아송 평균 = λ

포아송 분산 = λ

공분산 = Σ(x - x̄)(y - ȳ) / (n - 1)

상관계수 = 공분산 / (X표준편차 × Y표준편차)

최소-최대 정규화 = (x - 최솟값) / (최댓값 - 최솟값)

표준화 = (x - 평균) / 표준편차

MAE = 절대 오차 평균

MSE = 제곱 오차 평균

RMSE = √MSE

MAPE = 절대 백분율 오차 평균

정확도 = (TP + TN) / 전체

오분류율 = (FP + FN) / 전체

정밀도 = TP / (TP + FP)

재현율 = TP / (TP + FN)

F1 = 2 × 정밀도 × 재현율 / (정밀도 + 재현율)

FPR = FP / (FP + TN)

지지도 = A와 B 동시 발생 수 / 전체 거래 수

신뢰도 = A와 B 동시 발생 수 / A 발생 수

향상도 = 신뢰도 / P(B)
