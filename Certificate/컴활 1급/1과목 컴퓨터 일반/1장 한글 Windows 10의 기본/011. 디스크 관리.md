## 011. 디스크 관리

### 1. 디스크 관리의 개요

디스크 관리는 컴퓨터에 설치된 **하드디스크의 파티션을 나누고, 포맷하고, 드라이브 문자를 지정**하는 등  
디스크를 관리하는 도구입니다.

- 실행 방법 : `⊞` + `X` → [디스크 관리], 또는 [컴퓨터 관리] → [저장소] → [디스크 관리]

#### 왜 디스크를 따로 관리해야 할까?

하드디스크는 물리적으로는 하나의 장치이지만, 그대로는 사용할 수 없습니다.

운영체제가 파일을 저장하려면

1. 저장 공간을 어떻게 나눌지 정하고(**파티션**)
2. 파일을 어떤 규칙으로 기록할지 정해야 합니다(**파일 시스템 / 포맷**)

디스크 관리는 이 준비 과정을 수행하는 도구입니다.

---

### 2. 파티션(Partition)

파티션은 **하나의 물리적 디스크를 여러 개의 논리적 영역으로 나누는 것**입니다.

- 나뉜 각 영역은 C:, D: 처럼 **별도의 드라이브로 인식**됩니다.
- 파티션을 나눈 후에는 반드시 **포맷**을 해야 사용할 수 있습니다.

| 종류 | 설명 |
| --- | --- |
| 주 파티션(Primary Partition) | 운영체제를 설치하고 부팅할 수 있는 파티션입니다. |
| 확장 파티션(Extended Partition) | 논리 드라이브를 만들기 위한 파티션으로, 직접 부팅할 수는 없습니다. |
| 논리 드라이브 | 확장 파티션 안에 만드는 저장 영역입니다. |

#### 왜 파티션을 나눌까?

디스크 전체를 하나로 쓰면 다음과 같은 문제가 생깁니다.

- 운영체제를 다시 설치할 때 **개인 자료까지 함께 지워질 위험**이 있습니다.
- 파일 종류가 섞여 관리가 어렵습니다.

파티션을 나누면 **운영체제 영역과 데이터 영역을 분리**할 수 있어,  
시스템을 다시 설치해도 데이터 영역은 그대로 보존됩니다.

즉, 파티션은  
**물리적으로는 하나인 디스크를 목적별로 분리해서 쓰기 위한 개념**입니다.

---

### 3. 포맷(Format)

포맷은 **디스크에 파일을 기록할 수 있도록 초기화하는 작업**입니다.

- 포맷을 하면 기존에 저장된 **데이터는 모두 삭제**됩니다.
- 포맷 창에서는 다음 항목을 지정합니다.

| 항목 | 설명 |
| --- | --- |
| 용량 | 포맷할 드라이브의 전체 용량입니다. |
| 파일 시스템 | NTFS, FAT32, exFAT 중에서 선택합니다. |
| 할당 단위 크기 | 파일을 저장할 때 사용하는 최소 단위(클러스터) 크기입니다. |
| 볼륨 레이블 | 드라이브에 붙일 이름입니다. |
| 빠른 포맷 | 파일 관리 정보만 지우고 실제 데이터 영역은 검사하지 않아 속도가 빠릅니다. |

#### 왜 빠른 포맷이 더 빠를까?

일반 포맷은 디스크의 **모든 섹터를 검사하면서** 초기화합니다.  
반면 빠른 포맷은 **"어디에 무엇이 있다"는 관리 정보만 지웁니다.**

책에 비유하면

- **일반 포맷** : 모든 페이지를 지우고 상태까지 점검
- **빠른 포맷** : 목차만 지움 (본문은 그대로 남지만 찾을 수 없음)

그래서 빠른 포맷은 속도가 빠르지만 **디스크 오류를 검사하지는 못합니다.**

---

### 4. 파일 시스템

| 파일 시스템 | 특징 |
| --- | --- |
| FAT32 | 대부분의 운영체제에서 호환되지만, **파일 하나의 최대 크기가 4GB로 제한**됩니다. |
| NTFS | Windows의 표준 파일 시스템으로, **대용량 파일 지원, 파일 단위 보안, 압축, 암호화, 디스크 할당량** 기능을 제공합니다. |
| exFAT | FAT32의 용량 제한을 해결한 파일 시스템으로, USB 메모리나 SD 카드에 주로 사용됩니다. |

#### 왜 NTFS를 주로 사용할까?

FAT32는 구조가 단순해 호환성은 좋지만, 다음과 같은 한계가 있습니다.

- 4GB보다 큰 파일을 저장할 수 없습니다.
- 파일별 접근 권한을 지정할 수 없습니다.
- 오류가 발생했을 때 복구 기능이 약합니다.

NTFS는 이런 문제를 해결하기 위해 만들어졌으며,  
**보안·안정성·대용량 지원**이 필요한 Windows 시스템 드라이브에 사용됩니다.

---

### 5. 볼륨 관련 작업

| 작업 | 설명 |
| --- | --- |
| 볼륨 축소 | 사용하지 않는 공간을 분리하여 볼륨 크기를 줄입니다. |
| 볼륨 확장 | 인접한 사용 가능 공간을 합쳐 볼륨 크기를 늘립니다. |
| 드라이브 문자 및 경로 변경 | C:, D: 같은 드라이브 문자를 변경합니다. |
| 볼륨 삭제 | 해당 볼륨을 제거하고 사용하지 않는 공간으로 되돌립니다. |

- **시스템 드라이브(운영체제가 설치된 드라이브)의 문자는 변경할 수 없습니다.**

#### 왜 시스템 드라이브 문자는 바꿀 수 없을까?

설치된 프로그램들은 대부분 **"C:\Program Files\..."** 처럼 드라이브 문자가 포함된 경로를 기억하고 있습니다.

만약 문자가 바뀌면 이 경로가 모두 어긋나서 프로그램이 실행되지 않습니다.  
그래서 시스템 드라이브의 문자는 변경할 수 없도록 막아 두었습니다.

---

### 한 줄 정리

디스크 관리는 **파티션 분할 → 포맷 → 드라이브 문자 지정**의 과정을 수행하는 도구이며,  
**NTFS**는 대용량·보안·압축·암호화를 지원하고, **빠른 포맷은 관리 정보만 지우므로 오류 검사를 하지 않습니다.**
