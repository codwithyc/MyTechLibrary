## 빅데이터와 데이터 사이언스
### 데이터 사이언스
- 데이터 사이언스는 데이터로부터 의미 있는 정보를 추출해내는 학문입니다.
- 정형, 반정형, 비정형의 다양한 유형의 데이터를 대상으로 합니다.
- 분석뿐만 아니라 효과적으로 구현하고 전달하는 과정까지 포함한 포괄적 개념입니다.
- 데이터 공학, 수학, 통계학, 컴퓨터 공학, 시각화, 해커의 사고방식, 해당 분야의 전문 지식을 종합한 학문으로서 총계적 접근법을 사용합니다.
- 데이터 사이언스는 과학과 인문의 교차로이며, 특히 시각화와 효과적 커뮤니케이션이 중요합니다.

#### 데이터 사이언스의 한계
- 분석 과정에서 가정 등 인간의 해석이 개입되어 사람마다 전혀 다른 의미와 해석을 내릴 수 있습니다.
- 아무리 정량적인 분석이라도 모든 분석은 가정에 근거합니다. 즉, 분석의 정확성에 초점을 맞춰 분석하는 것이 아닙니다.
- 모델의 능력에 대해 항상 의구심을 갖고, 가정과 현실의 불일치에 대해 계속 고찰하며, 분석 모델이 예측할 수 없는 위험을 살펴야 합니다.

#### 빅데이터 가치 패러다임 변화
- 가치 패러다임이 디지털화(Digitalization, 과거) -> 연결(Connection, 현재) -> 에이전시(Agency 미래)순서로 변화하였다.
- 미래의 가치 패러다임에서 빅데이터, 데이터 사이언스는 중요한 역할을 담당하게 된다.

> 가치 페러다임 변화

| 가치 패러다임 변화 | 설명 | 
| ---- | ----------------------- |
| 디지털화 (Digitalization, 과거) | 아날로그 시대에서 디지털 시대로의 가치 창출 |
| 연결 (Connection, 현재) | 디지털화된 데이터들이 서로 연결되어 가치를 창출 | 
| 에이전시(Agency, 미래) | 복잡하게 연결된 네트워크를 신뢰성 있게 관리하는 에이전트를 이용한 가치 창출

- 데이터 사이언스 구성요소에는 IT, 분석, 비즈니스 컨설팅이 있습니다.

> 데이터 사이언스의 핵심 구성요소

| 구성 요소 | 설명 | 
| ---- | -------------------------- |
| IT(Data Management) | - 데이터 처리와 관련된 영역 <br> - 신호처리(시그널 프로세싱), 데이터 엔지니어링, 데이터 웨어하우스, 프로그래밍(파이썬 프로그래밍)<br> 고성능 컴퓨터(분산 컴퓨팅) |
|분석 | - 수학, 분석학, 패턴인식과 불확실성 확률모델 머신러닝 등 | 
| 비즈니스 컨설팅 | - 스토리텔링, 시각화, 커뮤니케이션 프레젠테이션 등 |

#### 데이터 분야 직무
1. 데이터 분석가
    - 데이터 분석 보고서 및 시각화 자료를 통해 비즈니스 결정에서 인사이틀 제공한다.
    - 추측에 의한 결정을 없앨 수 있도록 해주고, 서로 다른 팀 간의 중재자 역할을 합니다.
    - 데이터 경향, 이상치 등 인식을 위한 시각화 및 보고서를 작성합니다.
    - 조직의 성장에 대한 정확한 지표를 확인합니다.
    - 데이터 기반 의사 결정을 위해 통계적 데이터 분석 및 시각화를 수행합니다.
    - 비즈니스 미 ㅊ도메인 지식, 데이터 시각화 역량, 데이터 분석을 위한 통계적 지식 SQL 능력을 갖추어야 한다.

2. 데이터 사이언티스트
    - 머신러닝 모델을 구축하기 위한 기본적인 코딩 스킬이 필요합니다.
    - 머신러닝 모델을 통해 정형, 비정형 데이터로부터 인사이트를 추출할 수 있어야 합니다.
    - 빅데이터의 다각적 분석을 통해 인사이트를 도출하고 이를 조직의 전략 방향 제시에 활용할 줄 아는 기획자입니다.
    - 데이터 분석을 위한 통계적 지식, 머신러닝 AI에 대한 지식을 갖춰어야 합니다.

> 데이터 사이언티스트에 요구되는 인문학적 사고의 특성과 역할

| | 과거 | 현재 | 미래 |
| -- | --- | ------ | ----- |
| 정보 (Information) | 무슨 일이 일어났는가? | 무슨 일이 일어나고 있는가? | 무슨 일이 일어날 것인가? |
| 통찰력 (insight) | 어떻게 왜 일어났는가? | 차선 행동은 무엇인가? | 최악, 최선의 상황은 ? |

3. 데이터 엔지니어
    - 데이터 플랫폼과 데이터 파이프라인 아키텍처를 개발하고 운영한다.
    - 대규모 데이터를 처리하기 위해 하둡, 스파크 등 분산처리에 대한 기술적 이해도가 필요합니다.
    - 소프트웨어 개발에 필요한 프로그래밍 능력이 있어야 됩니다.

### 데이터 사이언티스트
#### 데이터 사이언티스트 필요 역량
- 데이터 사이언티스트는 타이터 해커, 애널리스트, 커뮤니케이션, 신뢰받는 어드바이저 등의 조합이라 할 수 있습니다.
- 데이터 사이언티스트에게는 주로 데이터 처리나 분석 기술과 관련된 스킬뿐만 아니라 통찰력 있는 분석, 설들력 있는 전달, 협력 등의 스킬도 필요합니다.
- 데이터 사이언티스트는 하드 스킬과 소프트 스킬 능력을 동시에 갖추고 있어야 합니다.

> 하드 스킬과 소프ㅏ트 스킬 비교

| 구분 | 설명 | 
| ---- | ----------------- | 
| 하드 스킬 | - 머신러닝, 모델링 데이터 다루는 기술 <br> - 빅데이터에 대한 이론적 지식, 관련 기법에 대한 이해와 방법론 습득 <br> 분석 기술에 대한 숙련 목적에 따른 최적의 분석 설계 및 노하우 축적 | 
| 소프트 스킬 | - 통찰력 있는 분석, 창의적 사고, 호기심, 논리적 비판 <br> - 호기심, 문제의 이면을 파고들어 질문을 찾고, 검증 가능한 가설을 세울 수 있는 능력 <br> 설득력 있는 전달, 스토리텔링 및 시각화 | 다분야 간 협력, 커뮤니케이션 능력 | 

#### 효과적 분석모델 개발을 위해 고려해야 하는 사항
- 데이터 분석의 객관성에 항상 의문을 제기하고 분석 모델에 포함된 가정과 해석의 개입 등의 한계를 고려합니다.
- 분석 모델 범위를 벗어나는 외부 요인은 판단하지 않는다.
- 분석 모델이 예측할 수 없는 위험을 살펴보기 위해 현실 세계를 돌아보고 분석을 경험과 세상에 대한 통찰력과 함께 활용한다.
- 가정과 현실의 불일치에 대해 계속해서 고찰하고, 모델의 능력에 대해 끊임없는 의구심을 갖는다.

> 범할 수 있는 의사 결정 오류 

| 오류 | 설명 | 
| --- | ------------------ |
| 로직(논리) 오류 | 부정확한 가능을 하고 테스트를 하지 않는 것 | 
| 프로세스 오류 | - 결정에서 분석과 통찰력을 고려하지 않은 것 <br> 데이터 수집이나 분석이 너무 늦어 사용할 수 없게 되는 것 <br> 대안을 진지하게 고려하지 않은 것|
