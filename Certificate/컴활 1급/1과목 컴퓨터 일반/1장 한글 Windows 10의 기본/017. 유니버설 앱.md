## 017. 유니버설 앱

### 1. 유니버설 앱(Universal App)의 개요

유니버설 앱은 **PC, 태블릿, 스마트폰 등 여러 종류의 기기에서 동일하게 실행되도록 만들어진 앱**입니다.

- Windows 10에 기본으로 포함되어 있으며, **Microsoft Store**에서 추가로 설치할 수 있습니다.
- 화면 크기와 입력 방식(마우스 / 터치)에 맞춰 **화면 구성이 자동으로 조정**됩니다.

#### 왜 유니버설 앱이 등장했을까?

과거에는 같은 서비스라도 기기별로 앱을 따로 만들어야 했습니다.

- PC용 프로그램
- 태블릿용 앱
- 스마트폰용 앱

이렇게 나누면 개발 비용이 커지고, 기기마다 기능이 달라지는 문제가 생깁니다.

유니버설 앱은 **하나의 앱을 만들어 여러 기기에서 사용**할 수 있게 하여,  
개발자에게는 효율을, 사용자에게는 **어느 기기에서든 동일한 사용 경험**을 제공합니다.

---

### 2. 유니버설 앱의 특징

- **하나의 코드로 여러 기기에서 실행**됩니다.
- 화면 크기에 따라 레이아웃이 자동으로 바뀝니다. (반응형)
- **Microsoft Store를 통해 배포·설치·업데이트**가 이루어집니다.
- Microsoft 계정으로 로그인하면 여러 기기에서 **설정과 데이터가 동기화**됩니다.
- 앱은 서로 분리된 환경에서 실행되므로 **보안성이 높습니다.**

#### 왜 Store를 통해서만 설치하도록 했을까?

인터넷에서 직접 내려받아 설치하는 방식은 **악성 프로그램이 섞여 들어올 위험**이 큽니다.

Microsoft Store는 등록된 앱을 사전에 검사하므로,

- 사용자는 **검증된 앱만 설치**할 수 있고
- 업데이트도 **한곳에서 자동으로 관리**됩니다.

즉, Store 방식은 **보안과 관리 편의성을 함께 확보하기 위한 구조**입니다.

### 3. 주요 유니버설 앱

| 앱 | 기능 |
| --- | --- |
| 계산기 | 표준 / 공학용 / 프로그래머 / 그래프 / 날짜 계산 / 단위 변환 기능을 제공합니다. |
| 사진 | 사진과 동영상을 관리하고 간단히 편집합니다. 앨범 자동 생성 기능이 있습니다. |
| 지도 | 지도 검색, 길 찾기, 3D 보기 기능을 제공하며 오프라인 지도를 내려받을 수 있습니다. |
| 메일 / 일정 | 여러 계정의 메일과 일정을 한곳에서 관리합니다. |
| 알람 및 시계 | 알람, 세계 시계, 타이머, 스톱워치 기능을 제공합니다. |
| 날씨 | 지역별 날씨와 예보를 제공합니다. |
| 그림판 3D | 2D뿐 아니라 3D 개체를 만들고 편집합니다. |
| 음성 녹음기 | 마이크를 이용해 소리를 녹음합니다. |
| 스티커 메모 | 바탕 화면에 붙여 두는 간단한 메모를 작성합니다. |
| Microsoft Store | 앱, 게임, 영화 등을 검색하고 설치합니다. |
| Microsoft Edge | Windows 10의 기본 웹 브라우저입니다. |

### 4. 앱의 관리

| 작업 | 방법 |
| --- | --- |
| 설치 | Microsoft Store에서 앱을 선택 → [설치] |
| 제거 | 시작 메뉴에서 앱 바로 가기 메뉴 → [제거], 또는 [설정] → [앱] → [앱 및 기능] |
| 시작 화면에 고정 | 앱 바로 가기 메뉴 → [시작 화면에 고정] |
| 업데이트 | Microsoft Store → [다운로드 및 업데이트] |

- 일부 기본 앱은 **제거할 수 없습니다.** (예: Microsoft Edge, Microsoft Store)

#### 왜 일부 앱은 제거할 수 없을까?

Microsoft Store나 Edge처럼 **다른 앱을 설치하거나 시스템 기능을 수행하는 데 필요한 앱**이 있습니다.

이런 앱을 제거하면 다시 설치할 방법 자체가 사라지거나,  
운영체제의 기본 동작이 정상적으로 이루어지지 않을 수 있습니다.

그래서 시스템 유지에 필요한 앱은 **제거를 막아 두었습니다.**

### 5. 유니버설 앱과 데스크톱 프로그램의 비교

| 구분 | 유니버설 앱 | 데스크톱 프로그램 |
| --- | --- | --- |
| 설치 경로 | Microsoft Store | 설치 파일(`.exe`) 직접 실행 |
| 실행 환경 | 여러 기기에서 공통 실행 | 주로 PC 전용 |
| 화면 구성 | 화면 크기에 맞춰 자동 조정 | 고정된 형태 |
| 보안 | 분리된 환경에서 실행되어 상대적으로 안전 | 시스템 전체에 접근 가능 |
| 업데이트 | Store에서 자동 관리 | 프로그램별로 개별 관리 |

---

### 한 줄 정리

유니버설 앱은 **하나의 앱으로 PC·태블릿·스마트폰에서 모두 실행되는 앱**으로,  
**Microsoft Store를 통해 설치·업데이트**되며 화면 크기에 맞춰 구성이 자동 조정됩니다.
