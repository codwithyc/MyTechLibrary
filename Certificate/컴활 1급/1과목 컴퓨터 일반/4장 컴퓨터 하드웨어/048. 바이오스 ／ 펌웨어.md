## 048. 바이오스 / 펌웨어

### 1. 바이오스(BIOS)의 개요

**BIOS(Basic Input Output System, 기본 입출력 시스템)** 는  
컴퓨터의 전원을 켰을 때 **가장 먼저 실행되어 하드웨어를 점검하고 운영체제를 불러오는 프로그램**입니다.

- **ROM에 저장**되어 있으므로 **ROM BIOS**라고도 합니다.
- 전원을 켜면 **POST(Power On Self Test)** 를 수행하여 하드웨어 이상 여부를 검사합니다.
- 키보드, 디스크, 프린터 등 **기본 입출력 장치를 제어**합니다.
- 부팅 순서, 시스템 시간 등의 설정을 담당합니다.

#### 왜 BIOS가 ROM에 저장될까?

컴퓨터의 전원을 켠 직후에는 **운영체제가 아직 메모리에 올라와 있지 않습니다.**

그렇다면 운영체제를 불러올 프로그램은 어디에 있어야 할까요?

전원이 꺼져도 지워지지 않는 **비휘발성 메모리(ROM)** 에 저장되어 있어야 합니다.

즉, BIOS는  
**아무것도 준비되지 않은 상태에서 가장 먼저 실행되어야 하므로 ROM에 저장**됩니다.

---

### 2. POST(자체 진단 프로그램)

전원을 켰을 때 **하드웨어가 정상인지 검사하는 과정**입니다.

- 검사 대상 : CPU, 메모리, 그래픽 카드, 키보드, 저장 장치 등
- 이상이 발견되면 화면에 메시지를 표시하거나 **경고음(비프음)** 으로 알립니다.

#### 왜 경고음으로 알릴까?

그래픽 카드나 메모리에 문제가 있으면 **화면 자체가 나오지 않습니다.**

메시지를 띄울 수 없는 상황이므로, **소리로 문제를 알리는 방법**이 필요합니다.

비프음의 횟수와 길이는 문제 유형에 따라 다르므로,  
메인보드 설명서를 참고하면 어떤 부품에 문제가 있는지 파악할 수 있습니다.

---

### 3. CMOS 설정(CMOS Setup)

**CMOS**는 BIOS의 **설정값을 저장해 두는 반도체 메모리**입니다.

- 부팅 초기에 **`Delete` 키 또는 `F2` 키**를 눌러 진입합니다. (제조사마다 다름)
- **메인보드의 배터리**로부터 전원을 공급받아 내용을 유지합니다.

**설정 가능한 항목**

| 항목 | 설명 |
| --- | --- |
| 시스템의 날짜와 시간 | 컴퓨터의 기준 시각을 지정합니다. |
| **부팅 순서(Boot Sequence)** | 어떤 장치에서 먼저 운영체제를 찾을지 지정합니다. (HDD/SSD, USB, DVD 등) |
| 하드디스크 정보 | 연결된 저장 장치의 종류와 용량을 확인합니다. |
| 칩셋 / 전원 관리 | 메인보드와 전원 관련 세부 설정을 지정합니다. |
| **암호(Password)** | 부팅 암호나 CMOS 설정 진입 암호를 지정합니다. |
| Anti-Virus | 부트 영역에 대한 기록을 감시합니다. |
| 시스템 온도·팬 속도 | 하드웨어 상태를 확인합니다. |

#### 왜 메인보드에 배터리가 있을까?

CMOS는 **휘발성 메모리**입니다.  
전원이 끊기면 저장한 설정값이 사라집니다.

그래서 컴퓨터의 전원을 뽑아도 설정이 유지되도록,  
메인보드에 작은 **동전형 배터리**를 두어 CMOS에 전원을 계속 공급합니다.

배터리가 다 되면

- 시간이 자꾸 초기화되고
- 부팅 순서 등 설정이 기본값으로 되돌아갑니다.

이럴 때는 **배터리를 교체**하면 해결됩니다.

#### 왜 부팅 순서를 바꿀까?

운영체제를 새로 설치하려면 **USB나 DVD에서 부팅**해야 합니다.

하지만 기본 설정은 하드디스크에서 먼저 부팅하도록 되어 있으므로,  
설치 매체로 부팅하려면 CMOS에서 부팅 순서를 변경해야 합니다.

### 4. 펌웨어(Firmware)

펌웨어는 **하드웨어를 제어하기 위해 ROM에 저장된 소프트웨어**입니다.

| 특징 | 설명 |
| --- | --- |
| 성격 | **하드웨어와 소프트웨어의 중간적 성격**을 가집니다. |
| 저장 위치 | **ROM(주로 EEPROM, 플래시 메모리)** 에 저장됩니다. |
| 변경 가능성 | 필요할 때 **업그레이드(펌웨어 업데이트)** 할 수 있습니다. |
| 대표 예 | **BIOS**, 프린터·공유기·SSD·스마트 가전의 내장 프로그램 |

#### 왜 펌웨어를 "하드웨어와 소프트웨어의 중간"이라고 할까?

- **하드웨어처럼** : 장치 안에 내장되어 있고, 사용자가 임의로 설치·삭제하지 않습니다.
- **소프트웨어처럼** : 프로그램 코드로 되어 있어 **수정하고 업데이트할 수 있습니다.**

과거에는 ROM의 내용을 바꿀 수 없어 완전히 하드웨어에 가까웠지만,  
**EEPROM과 플래시 메모리**가 등장하면서 전기적으로 다시 기록할 수 있게 되었습니다.

그 결과 **장치를 교체하지 않고도 기능을 개선하거나 오류를 수정**할 수 있게 되었습니다.

#### 왜 펌웨어 업데이트는 신중해야 할까?

펌웨어는 장치가 동작하기 위한 **가장 기본적인 프로그램**입니다.

업데이트 도중 전원이 꺼지면 펌웨어가 손상되어  
**장치 자체가 켜지지 않는 상태**가 될 수 있습니다.

그래서 펌웨어 업데이트는

- 전원이 안정적인 상태에서
- 제조사가 제공한 정확한 버전으로

수행해야 합니다.

### 5. BIOS와 UEFI

| 구분 | BIOS | UEFI |
| --- | --- | --- |
| 방식 | 전통적인 16비트 방식 | 현대적인 32/64비트 방식 |
| 인터페이스 | 키보드 중심의 텍스트 화면 | 마우스 사용 가능한 그래픽 화면 |
| 지원 디스크 용량 | 2TB 이하 | 2TB 초과 지원 |
| 부팅 속도 | 상대적으로 느림 | 빠름 |
| 보안 | 제한적 | **보안 부팅(Secure Boot)** 지원 |

---

### 한 줄 정리

BIOS는 **ROM에 저장되어 부팅 시 가장 먼저 실행되며 POST와 기본 입출력을 담당**하고,  
설정값은 **배터리로 유지되는 CMOS**에 저장되며,  
펌웨어는 **ROM에 저장된, 하드웨어와 소프트웨어의 중간 성격을 갖는 프로그램**입니다.
