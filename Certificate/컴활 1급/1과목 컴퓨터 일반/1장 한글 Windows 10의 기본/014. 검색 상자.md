## 014. 검색 상자

### 1. 작업 표시줄의 검색 상자

작업 표시줄의 검색 상자는 **컴퓨터와 웹을 한 번에 검색**하는 기능입니다.

- 실행 방법 : 작업 표시줄의 검색 상자 클릭, `⊞` + `S`, `⊞` + `Q`
- 검색 대상 : 앱, 문서, 전자 메일, 웹, 설정, 폴더, 사진, 음악, 동영상 등
- 검색어를 입력하면 **입력하는 즉시 결과가 표시**됩니다.
- 검색 결과는 **범주별(앱 / 문서 / 웹 등)** 로 구분되어 나타납니다.

#### 왜 검색 상자가 시작 메뉴와 별도로 있을까?

시작 메뉴는 **설치된 앱을 목록에서 찾는 방식**입니다.  
하지만 앱이 아니라 특정 문서나 설정 항목을 찾고 싶을 때는 목록을 뒤지는 것이 비효율적입니다.

검색 상자는 **찾는 대상이 무엇이든 이름만 알면 바로 도달**할 수 있게 해 줍니다.

즉, 검색은  
**"어디에 있는지 몰라도 찾을 수 있게 하는 접근 방법"** 입니다.

---

### 2. 파일 탐색기의 검색 상자

파일 탐색기 오른쪽 위에 있는 검색 상자는 **현재 폴더와 그 하위 폴더**를 대상으로 검색합니다.

- 검색을 시작하면 리본 메뉴에 **[검색] 탭**이 나타납니다.

| [검색] 탭 항목 | 기능 |
| --- | --- |
| 현재 폴더 / 모든 하위 폴더 | 검색 범위를 지정합니다. |
| 수정한 날짜 | 오늘, 어제, 이번 주, 지난달, 올해 등으로 필터링합니다. |
| 종류 | 문서, 그림, 음악, 폴더 등 파일 종류로 필터링합니다. |
| 크기 | 비어 있음, 매우 작음, 작음, 보통, 큼, 매우 큼, 거대함으로 필터링합니다. |
| 기타 속성 | 유형, 이름, 폴더 경로, 태그 등으로 조건을 지정합니다. |
| 최근 검색 | 이전에 수행한 검색 조건을 다시 사용합니다. |
| 고급 옵션 | 색인된 위치 변경, 파일 내용 검색, 압축 파일 포함 여부를 지정합니다. |
| 검색 저장 | 현재 검색 조건을 저장하여 나중에 다시 사용합니다. |

### 3. 만능 문자(와일드카드)를 이용한 검색

| 기호 | 의미 | 예시 |
| --- | --- | --- |
| `*` | **임의의 개수**의 문자를 대신합니다. | `보고*` → `보고서`, `보고자료`, `보고서최종` |
| `?` | **한 개**의 문자를 대신합니다. | `보고?` → `보고서`, `보고자` (`보고서류`는 해당 없음) |

- 확장자로 검색할 수도 있습니다. (예: `*.hwp` → 모든 한글 파일)

#### 왜 만능 문자가 필요할까?

파일 이름을 정확히 기억하지 못하는 경우가 많습니다.  
"보고"로 시작한다는 것만 알고 뒷부분은 모를 수 있습니다.

만능 문자는 **모르는 부분을 비워 둔 채로 검색**할 수 있게 해 줍니다.

즉,

- 길이를 모를 때 → `*`
- 글자 수는 알지만 글자를 모를 때 → `?`

---

### 4. 검색 조건 연산자

| 연산자 | 의미 | 예시 |
| --- | --- | --- |
| `AND` | 두 조건을 모두 만족 | `보고서 AND 2024` |
| `OR` | 두 조건 중 하나라도 만족 | `보고서 OR 계획서` |
| `NOT` | 해당 조건을 제외 | `보고서 NOT 임시` |
| `" "` | 정확히 일치하는 구문 검색 | `"연간 보고서"` |
| `>` , `<` | 크기나 날짜 비교 | `크기:>10MB` |

- 연산자는 **반드시 대문자**로 입력해야 합니다.

### 5. 색인(Index)

색인은 **검색 속도를 높이기 위해 파일 정보를 미리 정리해 둔 데이터베이스**입니다.

- 색인이 만들어진 위치는 **파일 이름뿐 아니라 내용까지 빠르게 검색**할 수 있습니다.
- 색인되지 않은 위치를 검색하면 시간이 오래 걸립니다.
- [제어판] → [색인 옵션]에서 색인 위치를 추가하거나 제외할 수 있습니다.

#### 왜 모든 폴더를 색인하지 않을까?

색인을 만들려면 **파일을 미리 읽어서 정리하는 작업**이 필요합니다.  
대상이 많을수록 시간과 디스크 공간이 소모되고, 파일이 바뀔 때마다 갱신도 해야 합니다.

그래서 Windows는 **자주 검색하는 위치(문서, 사진, 바탕 화면 등)만 기본 색인 대상**으로 두고,  
나머지는 사용자가 필요할 때 추가하도록 합니다.

---

### 한 줄 정리

검색 상자는 **앱·문서·설정·웹을 한 번에 찾는 통합 검색 기능**이며,  
`*`는 여러 글자, `?`는 한 글자를 대신하고,  
**색인된 위치는 파일 내용까지 빠르게 검색**할 수 있습니다.
