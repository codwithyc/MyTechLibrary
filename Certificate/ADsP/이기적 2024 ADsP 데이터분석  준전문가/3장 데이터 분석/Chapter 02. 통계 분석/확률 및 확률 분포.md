# 확률 및 확률 분포

확률 및 확률 분포는 통계 분석의 기초가 되는 단원이다.
통계 분석은 불확실한 데이터를 다루기 때문에, 어떤 사건이 발생할 가능성을 수치로 표현하는 **확률**과 데이터가 어떤 형태로 나타나는지 설명하는 **확률 분포**를 이해해야 한다.

```markdown
확률 = 어떤 사건이 발생할 가능성을 수치로 나타낸 것
확률 분포 = 확률변수가 가질 수 있는 값과 그 값이 나타날 확률의 대응 관계
```

ADsP 시험에서는 계산 자체보다 다음 개념 구분이 중요하다.

* 확률의 기본 개념
* 표본공간과 사건
* 조건부 확률
* 독립사건과 종속사건
* 배반사건
* 확률변수
* 이산확률분포와 연속확률분포
* 이항분포, 포아송분포, 정규분포
* 표준정규분포
* 중심극한정리

# 01. 확률의 개념

## 확률의 정의

**확률(Probability)**은 어떤 사건이 발생할 가능성을 0과 1 사이의 수로 표현한 것이다.

```markdown
확률 = 사건이 발생할 가능성
```

확률은 다음 범위를 가진다.

```markdown
0 ≤ P(A) ≤ 1
```

| 확률값 | 의미                       |
| --: | ------------------------ |
|   0 | 절대 발생하지 않음               |
| 0.5 | 발생할 가능성과 발생하지 않을 가능성이 같음 |
|   1 | 반드시 발생함                  |

예를 들어 동전을 한 번 던졌을 때 앞면이 나올 확률은 다음과 같다.

```markdown
P(앞면) = 1/2 = 0.5
```

주사위를 한 번 던졌을 때 3이 나올 확률은 다음과 같다.

```markdown
P(3) = 1/6
```

시험에서는 이렇게 이해하면 된다.

```markdown
확률은 사건이 발생할 가능성을 0 이상 1 이하의 값으로 나타낸 것이다.
```

# 02. 표본공간과 사건

## 1) 표본공간

**표본공간(Sample Space)**은 어떤 실험에서 발생할 수 있는 모든 결과의 집합이다.

```markdown
표본공간 = 가능한 모든 결과의 집합
```

예를 들어 주사위를 한 번 던지는 실험의 표본공간은 다음과 같다.

```markdown
S = {1, 2, 3, 4, 5, 6}
```

동전을 한 번 던지는 실험의 표본공간은 다음과 같다.

```markdown
S = {앞면, 뒷면}
```

---

## 2) 사건

**사건(Event)**은 표본공간의 부분집합이다.

즉, 가능한 모든 결과 중에서 우리가 관심을 가지는 결과의 집합이다.

```markdown
사건 = 표본공간 중 관심 있는 결과의 집합
```

예를 들어 주사위를 한 번 던졌을 때 짝수가 나오는 사건을 A라고 하면 다음과 같다.

```markdown
S = {1, 2, 3, 4, 5, 6}
A = {2, 4, 6}
```

이때 A는 표본공간 S의 부분집합이다.

---

## 표본공간과 사건 비교

| 구분   | 의미           | 예시                   |
| ---- | ------------ | -------------------- |
| 표본공간 | 가능한 모든 결과    | `{1, 2, 3, 4, 5, 6}` |
| 사건   | 관심 있는 결과의 집합 | `{2, 4, 6}`          |

시험에서는 이렇게 기억하면 된다.

```markdown
표본공간은 전체 가능한 결과이고,
사건은 그중 관심 있는 결과의 집합이다.
```

# 03. 확률의 기본 성질

확률에는 몇 가지 기본 성질이 있다.

## 1) 전체 확률

표본공간 전체가 발생할 확률은 1이다.

```markdown
P(S) = 1
```

즉, 가능한 결과 중 하나는 반드시 발생한다.

---

## 2) 공사건 확률

아무 결과도 포함하지 않는 사건을 **공사건**이라고 한다.

공사건의 확률은 0이다.

```markdown
P(∅) = 0
```

---

## 3) 여사건 확률

어떤 사건 A가 발생하지 않는 사건을 **여사건**이라고 한다.

A의 여사건은 보통 `Aᶜ`로 표현한다.

```markdown
P(Aᶜ) = 1 - P(A)
```

예를 들어 비가 올 확률이 0.3이라면, 비가 오지 않을 확률은 다음과 같다.

```markdown
1 - 0.3 = 0.7
```

---

## 확률의 기본 성질 정리

| 성질                 | 의미             |
| ------------------ | -------------- |
| `0 ≤ P(A) ≤ 1`     | 확률은 0과 1 사이    |
| `P(S) = 1`         | 전체 표본공간의 확률은 1 |
| `P(∅) = 0`         | 공사건의 확률은 0     |
| `P(Aᶜ) = 1 - P(A)` | 여사건의 확률        |

시험에서는 다음 정도를 기억하면 된다.

```markdown
어떤 사건의 확률은 0과 1 사이이며,
전체 표본공간의 확률은 1이고,
여사건의 확률은 1에서 해당 사건의 확률을 뺀 값이다.
```

---

# 04. 합사건과 곱사건

## 1) 합사건

**합사건**은 두 사건 A와 B 중 적어도 하나가 발생하는 사건이다.

기호로는 다음처럼 표현한다.

```markdown
A ∪ B
```

읽을 때는 “A 또는 B”라고 이해하면 된다.

예를 들어 주사위를 던졌을 때 다음 사건이 있다고 하자.

```markdown
A = 짝수가 나오는 사건 = {2, 4, 6}
B = 3보다 큰 수가 나오는 사건 = {4, 5, 6}
```

그러면 A 또는 B가 발생하는 사건은 다음과 같다.

```markdown
A ∪ B = {2, 4, 5, 6}
```

```markdown
합사건 = A 또는 B가 발생하는 사건
```

---

## 2) 곱사건

**곱사건**은 두 사건 A와 B가 동시에 발생하는 사건이다.

기호로는 다음처럼 표현한다.

```markdown
A ∩ B
```

읽을 때는 “A 그리고 B”라고 이해하면 된다.

위 예시에서 A와 B가 동시에 발생하는 사건은 다음과 같다.

```markdown
A ∩ B = {4, 6}
```

즉, 짝수이면서 3보다 큰 수는 4와 6이다.

```markdown
곱사건 = A와 B가 동시에 발생하는 사건
```

---

## 합사건과 곱사건 비교

| 구분  | 기호      | 의미        | 키워드 |
| --- | ------- | --------- | --- |
| 합사건 | `A ∪ B` | A 또는 B    | OR  |
| 곱사건 | `A ∩ B` | A와 B가 동시에 | AND |

시험에서는 이렇게 기억하면 된다.

```markdown
합사건은 OR이고,
곱사건은 AND이다.
```

# 05. 덧셈정리와 곱셈정리

## 1) 확률의 덧셈정리

확률의 덧셈정리는 A 또는 B가 발생할 확률을 구할 때 사용한다.

```markdown
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
```

왜 `P(A ∩ B)`를 빼야 할까?

A와 B의 확률을 더하면 A와 B가 동시에 발생하는 부분이 두 번 계산된다.
따라서 한 번 빼주는 것이다.

```markdown
덧셈정리 = A 또는 B가 발생할 확률
```

---

## 2) 배반사건의 덧셈정리

**배반사건**은 두 사건이 동시에 발생할 수 없는 사건이다.

즉, 교집합이 없다.

```markdown
A ∩ B = ∅
```

배반사건일 때는 동시에 발생하는 부분이 없으므로 다음처럼 계산한다.

```markdown
P(A ∪ B) = P(A) + P(B)
```

예를 들어 주사위를 한 번 던졌을 때 1이 나오는 사건과 2가 나오는 사건은 동시에 발생할 수 없다.
이런 사건이 배반사건이다.

```markdown
배반사건 = 동시에 발생할 수 없는 사건
```

---

## 3) 확률의 곱셈정리

확률의 곱셈정리는 A와 B가 동시에 발생할 확률을 구할 때 사용한다.

일반적으로는 조건부 확률을 이용해 다음처럼 표현한다.

```markdown
P(A ∩ B) = P(A) × P(B|A)
```

또는

```markdown
P(A ∩ B) = P(B) × P(A|B)
```

```markdown
곱셈정리 = A와 B가 동시에 발생할 확률
```

---

# 06. 조건부 확률

## 조건부 확률의 개념

**조건부 확률(Conditional Probability)**은 어떤 사건 B가 이미 발생했다는 조건하에서 사건 A가 발생할 확률이다.

기호로는 다음처럼 표현한다.

```markdown
P(A|B)
```

읽을 때는 “B가 발생했을 때 A가 발생할 확률”이라고 한다.

```markdown
조건부 확률 = 어떤 사건이 발생했다는 조건에서 다른 사건이 발생할 확률
```

조건부 확률 공식은 다음과 같다.

```markdown
P(A|B) = P(A ∩ B) / P(B)
```

단, `P(B) > 0`이어야 한다.

---

## 조건부 확률 예시

고객 100명 중에서 다음과 같은 데이터가 있다고 하자.

| 구분      | 구매함 | 구매 안 함 |  합계 |
| ------- | --: | -----: | --: |
| 쿠폰 받음   |  30 |     20 |  50 |
| 쿠폰 안 받음 |  10 |     40 |  50 |
| 합계      |  40 |     60 | 100 |

쿠폰을 받은 고객 중 구매한 고객의 확률은 다음과 같다.

```markdown
P(구매 | 쿠폰 받음) = 30 / 50 = 0.6
```

전체 고객 중 구매 확률은 40/100이지만,
쿠폰을 받은 고객이라는 조건을 붙이면 분모가 전체 100명이 아니라 쿠폰 받은 고객 50명이 된다.

시험에서는 이 점이 중요하다.

```markdown
조건부 확률에서는 조건에 해당하는 집단이 새로운 기준이 된다.
```

# 07. 독립사건과 종속사건

## 1) 독립사건

**독립사건**은 한 사건의 발생이 다른 사건의 발생 확률에 영향을 주지 않는 사건이다.

즉, B가 발생했더라도 A의 확률이 변하지 않는다.

```markdown
P(A|B) = P(A)
```

이때 A와 B는 독립이다.

독립사건에서는 다음 식도 성립한다.

```markdown
P(A ∩ B) = P(A) × P(B)
```

예를 들어 동전을 두 번 던질 때, 첫 번째 결과와 두 번째 결과는 서로 영향을 주지 않는다.

```markdown
독립사건 = 한 사건의 발생이 다른 사건의 확률에 영향을 주지 않는 사건
```

---

## 2) 종속사건

**종속사건**은 한 사건의 발생이 다른 사건의 발생 확률에 영향을 주는 사건이다.

예를 들어 카드 한 장을 뽑고 다시 넣지 않은 상태에서 두 번째 카드를 뽑는 경우, 첫 번째 카드가 무엇이었는지에 따라 두 번째 카드의 확률이 달라진다.

```markdown
종속사건 = 한 사건의 발생이 다른 사건의 확률에 영향을 주는 사건
```

---

## 독립사건과 종속사건 비교

| 구분     | 독립사건                  | 종속사건                |      |            |
| ------ | --------------------- | ------------------- | ---- | ---------- |
| 의미     | 한 사건이 다른 사건에 영향 없음    | 한 사건이 다른 사건에 영향 있음  |      |            |
| 조건부 확률 | `P(A                  | B) = P(A)`          | `P(A | B) ≠ P(A)` |
| 곱셈정리   | `P(A ∩ B) = P(A)P(B)` | `P(A ∩ B) = P(A)P(B | A)`  |            |
| 예시     | 동전 두 번 던지기            | 카드를 뽑고 다시 넣지 않기     |      |            |

시험에서는 이렇게 기억하면 된다.

```markdown
독립사건은 조건이 붙어도 확률이 변하지 않고,
종속사건은 조건이 붙으면 확률이 변한다.
```

# 08. 확률변수

## 확률변수의 개념

**확률변수(Random Variable)**는 확률적 실험의 결과를 숫자로 대응시킨 변수다.

예를 들어 동전을 두 번 던졌을 때 앞면의 개수를 X라고 하자.

| 결과 | 앞면 개수 X |
| -- | ------: |
| 앞앞 |       2 |
| 앞뒤 |       1 |
| 뒤앞 |       1 |
| 뒤뒤 |       0 |

여기서 X는 확률변수다.

```markdown
확률변수 = 확률적 실험의 결과를 숫자로 나타낸 변수
```

확률변수는 크게 두 가지로 나뉜다.

```markdown
이산확률변수
연속확률변수
```

---

## 1) 이산확률변수

**이산확률변수**는 셀 수 있는 값을 가지는 확률변수다.

예를 들어 다음과 같다.

```markdown
동전을 3번 던졌을 때 앞면의 개수
주사위를 던졌을 때 나오는 눈의 수
하루 동안 발생한 불량품 개수
한 시간 동안 고객센터에 걸려온 전화 수
```

```markdown
이산확률변수 = 셀 수 있는 값을 가지는 확률변수
```

---

## 2) 연속확률변수

**연속확률변수**는 연속적인 범위 안에서 어떤 값이든 가질 수 있는 확률변수다.

예를 들어 다음과 같다.

```markdown
키
몸무게
시간
온도
제품 수명
대기 시간
```

```markdown
연속확률변수 = 연속적인 값을 가지는 확률변수
```

---

## 이산확률변수와 연속확률변수 비교

| 구분    | 이산확률변수              | 연속확률변수         |
| ----- | ------------------- | -------------- |
| 값의 형태 | 셀 수 있음              | 연속적            |
| 예시    | 불량품 개수, 전화 수, 주사위 눈 | 키, 몸무게, 시간, 온도 |
| 확률 표현 | 특정 값의 확률 가능         | 구간 확률로 표현      |
| 관련 분포 | 이항분포, 포아송분포         | 정규분포, t분포 등    |

시험에서는 이렇게 기억하면 된다.

```markdown
이산확률변수는 셀 수 있는 값이고,
연속확률변수는 측정되는 연속적인 값이다.
```

# 09. 확률분포

## 확률분포의 개념

**확률분포(Probability Distribution)**는 확률변수가 가질 수 있는 값과 그 값이 발생할 확률을 나타낸 것이다.

```markdown
확률분포 = 확률변수의 값과 그 값이 발생할 확률의 대응 관계
```

예를 들어 주사위를 한 번 던지는 경우 확률변수 X를 주사위 눈의 수라고 하면 다음과 같다.

|  X |  확률 |
| -: | --: |
|  1 | 1/6 |
|  2 | 1/6 |
|  3 | 1/6 |
|  4 | 1/6 |
|  5 | 1/6 |
|  6 | 1/6 |

이것이 확률분포다.

확률분포는 크게 두 가지로 나뉜다.

```markdown
이산확률분포
연속확률분포
```

# 10. 이산확률분포

이산확률분포는 이산확률변수의 확률분포다.
즉, 셀 수 있는 값에 확률이 대응되는 형태다.

대표적인 이산확률분포는 다음과 같다.

```markdown
베르누이분포
이항분포
포아송분포
```

---

## 1) 베르누이분포

**베르누이분포**는 결과가 성공 또는 실패처럼 두 가지로만 나오는 시행의 분포다.

```markdown
베르누이분포 = 결과가 성공/실패 두 가지뿐인 확률분포
```

예를 들어 다음이 베르누이 시행이다.

```markdown
동전을 한 번 던져 앞면이 나오면 성공, 뒷면이 나오면 실패
고객이 상품을 구매하면 성공, 구매하지 않으면 실패
메일을 열람하면 성공, 열람하지 않으면 실패
```

|  값 | 의미 |
| -: | -- |
|  1 | 성공 |
|  0 | 실패 |

시험에서는 이항분포의 기초 개념으로 이해하면 된다.

```markdown
베르누이분포는 한 번의 시행에서 성공 또는 실패만 나타나는 분포이다.
```

---

## 2) 이항분포

**이항분포(Binomial Distribution)**는 성공 또는 실패로 나뉘는 베르누이 시행을 여러 번 반복했을 때, 성공 횟수의 분포다.

```markdown
이항분포 = 베르누이 시행을 n번 반복했을 때 성공 횟수의 분포
```

예를 들어 동전을 10번 던졌을 때 앞면이 나오는 횟수는 이항분포를 따른다.

이항분포가 성립하려면 다음 조건이 필요하다.

| 조건       | 설명                 |
| -------- | ------------------ |
| 시행 횟수 고정 | 실험을 n번 반복          |
| 결과는 두 가지 | 성공 또는 실패           |
| 성공 확률 일정 | 매 시행의 성공 확률 p가 동일  |
| 시행은 독립   | 각 시행이 서로 영향을 주지 않음 |

예시:

```markdown
동전을 10번 던졌을 때 앞면이 나온 횟수
제품 100개 중 불량품 개수
광고를 본 고객 1,000명 중 구매한 고객 수
```

시험에서는 이렇게 기억하면 된다.

```markdown
이항분포는 성공/실패 시행을 여러 번 반복했을 때 성공 횟수를 나타내는 분포이다.
```

---

## 3) 포아송분포

**포아송분포(Poisson Distribution)**는 일정한 시간이나 공간에서 어떤 사건이 발생하는 횟수를 나타내는 분포다.

```markdown
포아송분포 = 일정 시간 또는 공간에서 사건이 발생하는 횟수의 분포
```

예를 들어 다음과 같은 경우에 사용된다.

```markdown
1시간 동안 고객센터에 걸려오는 전화 수
하루 동안 웹사이트에 발생하는 오류 수
특정 도로에서 한 시간 동안 발생하는 교통사고 수
단위 면적당 결함 수
```

포아송분포는 “횟수”를 다룬다는 점에서 이산확률분포에 해당한다.

| 구분 | 설명                     |
| -- | ---------------------- |
| 대상 | 일정 시간·공간에서 발생 횟수       |
| 값  | 0, 1, 2, 3, ...        |
| 예시 | 전화 수, 사고 수, 불량 수, 오류 수 |

시험에서는 이렇게 기억하면 된다.

```markdown
포아송분포는 일정 시간이나 공간에서 사건이 몇 번 발생하는지를 나타내는 분포이다.
```

---

## 이산확률분포 비교

| 분포     | 핵심              | 예시                |
| ------ | --------------- | ----------------- |
| 베르누이분포 | 한 번의 성공/실패      | 동전 1번 던지기         |
| 이항분포   | n번 시행 중 성공 횟수   | 동전 10번 중 앞면 횟수    |
| 포아송분포  | 일정 시간·공간의 발생 횟수 | 1시간 전화 수, 하루 오류 수 |

암기 방식은 다음과 같다.

```markdown
베르누이 = 한 번 성공/실패
이항 = 여러 번 성공 횟수
포아송 = 일정 시간·공간의 발생 횟수
```

---

# 11. 연속확률분포

연속확률분포는 연속확률변수의 확률분포다.

연속확률변수는 특정 값 하나의 확률보다 **구간에 속할 확률**을 계산한다.

예를 들어 키가 정확히 170.000000cm일 확률보다는,
키가 170cm 이상 180cm 이하일 확률을 구한다.

```markdown
연속확률분포는 특정 값의 확률보다 구간 확률을 다룬다.
```

대표적인 연속확률분포는 다음과 같다.

```markdown
정규분포
표준정규분포
t분포
카이제곱분포
F분포
```

ADsP 기초에서는 특히 **정규분포와 표준정규분포**가 중요하다.

---

## 1) 정규분포

**정규분포(Normal Distribution)**는 평균을 중심으로 좌우 대칭인 종 모양의 분포다.

```markdown
정규분포 = 평균을 중심으로 좌우 대칭인 종 모양의 연속확률분포
```

정규분포는 현실에서 많이 나타나는 대표적인 분포다.

예를 들어 다음과 같은 데이터가 정규분포에 가까운 형태를 가질 수 있다.

```markdown
키
몸무게
시험 점수
측정 오차
제품 길이
```

---

## 정규분포의 특징

| 특징             | 설명                   |
| -------------- | -------------------- |
| 좌우 대칭          | 평균을 중심으로 양쪽 모양이 대칭   |
| 종 모양           | 가운데가 높고 양쪽으로 갈수록 낮아짐 |
| 평균 = 중앙값 = 최빈값 | 중심 위치가 같음            |
| 평균과 분산으로 결정    | 평균은 위치, 분산은 퍼짐을 결정   |
| 전체 면적은 1       | 확률분포 전체 면적은 1        |

시험에서는 이 특징이 중요하다.

```markdown
정규분포는 평균을 중심으로 좌우 대칭이며,
평균, 중앙값, 최빈값이 모두 같다.
```

---

## 2) 표준정규분포

**표준정규분포(Standard Normal Distribution)**는 평균이 0이고 표준편차가 1인 정규분포다.

```markdown
표준정규분포 = 평균 0, 표준편차 1인 정규분포
```

기호로는 보통 다음처럼 표현한다.

```markdown
Z ~ N(0, 1)
```

정규분포를 표준정규분포로 바꾸는 것을 **표준화**라고 한다.

표준화 공식은 다음과 같다.

```markdown
Z = (X - μ) / σ
```

| 기호 | 의미         |
| -- | ---------- |
| X  | 원래 값       |
| μ  | 평균         |
| σ  | 표준편차       |
| Z  | 표준화된 값, Z값 |

---

## 표준화의 의미

표준화는 서로 다른 평균과 표준편차를 가진 데이터를 평균 0, 표준편차 1의 기준으로 바꾸는 것이다.

예를 들어 수학 점수와 영어 점수의 평균과 표준편차가 다를 때,
어떤 학생이 상대적으로 더 잘했는지 비교하려면 표준화가 필요하다.

```markdown
표준화 = 원래 값을 평균 0, 표준편차 1 기준의 Z값으로 변환하는 것
```

시험에서는 이렇게 기억하면 된다.

```markdown
표준정규분포는 평균이 0이고 표준편차가 1인 정규분포이며,
Z = (X - μ) / σ로 표준화한다.
```

---

## 3) t분포

**t분포**는 모집단의 분산을 모르고 표본 크기가 작을 때 평균 검정이나 신뢰구간 추정에 사용하는 분포다.

```markdown
t분포 = 표본 크기가 작고 모집단 분산을 모를 때 사용하는 분포
```

t분포는 정규분포와 비슷하게 좌우 대칭이지만, 꼬리가 더 두껍다.

표본 크기가 커질수록 t분포는 정규분포에 가까워진다.

```markdown
t분포는 표본 크기가 커질수록 정규분포에 가까워진다.
```

---

## 4) 카이제곱분포

**카이제곱분포**는 주로 분산 검정이나 범주형 자료의 독립성 검정에 사용되는 분포다.

```markdown
카이제곱분포 = 분산 검정과 범주형 자료 검정에 사용되는 분포
```

ADsP에서는 카이제곱검정과 연결해서 기억하면 된다.

```markdown
카이제곱검정 = 범주형 변수 간 관계 검정
```

---

## 5) F분포

**F분포**는 두 분산의 비율과 관련된 분포이며, 분산분석에서 사용된다.

```markdown
F분포 = 두 분산의 비율을 다루는 분포
```

분산분석, 즉 ANOVA에서는 세 집단 이상의 평균 차이를 검정할 때 F분포를 사용한다.

```markdown
분산분석은 F분포를 이용한다.
```

---

## 연속확률분포 비교

| 분포     | 핵심                 | 사용 상황        |
| ------ | ------------------ | ------------ |
| 정규분포   | 평균 중심 좌우 대칭        | 자연·사회 현상 데이터 |
| 표준정규분포 | 평균 0, 표준편차 1       | 표준화, Z값      |
| t분포    | 표본 크기가 작고 모분산 모를 때 | t검정          |
| 카이제곱분포 | 분산, 범주형 자료 검정      | 카이제곱검정       |
| F분포    | 분산 비율              | 분산분석         |

시험에서는 이렇게 기억하면 된다.

```markdown
정규분포 = 좌우 대칭 종 모양
표준정규분포 = 평균 0, 표준편차 1
t분포 = 작은 표본 평균 검정
카이제곱분포 = 범주형 검정
F분포 = 분산분석
```

# 12. 정규분포의 경험 법칙

정규분포에서는 평균을 기준으로 데이터가 일정한 비율로 분포한다.

이를 경험 법칙이라고 한다.

| 범위         |   포함 비율 |
| ---------- | ------: |
| 평균 ± 1표준편차 |   약 68% |
| 평균 ± 2표준편차 |   약 95% |
| 평균 ± 3표준편차 | 약 99.7% |

```markdown
정규분포에서는 평균 ± 1표준편차 안에 약 68%,
평균 ± 2표준편차 안에 약 95%,
평균 ± 3표준편차 안에 약 99.7%의 데이터가 포함된다.
```

시험에서는 이 수치를 가볍게 기억해두면 좋다.

```markdown
68 - 95 - 99.7 법칙
```

# 13. 중심극한정리

## 중심극한정리의 개념

**중심극한정리(Central Limit Theorem)**는 모집단의 분포가 어떤 형태이든, 표본의 크기가 충분히 크면 표본평균의 분포가 정규분포에 가까워진다는 정리다.

```markdown
중심극한정리 = 표본 크기가 충분히 크면 표본평균의 분포는 정규분포에 가까워진다
```

예를 들어 모집단이 한쪽으로 치우친 분포를 가지더라도,
표본을 여러 번 뽑아 표본평균들을 구하면 그 표본평균들의 분포는 정규분포에 가까워진다.

---

## 중심극한정리의 의미

중심극한정리는 추론통계의 핵심 기반이다.

왜냐하면 모집단이 정규분포가 아니어도 표본 크기가 충분하면 정규분포를 이용해 추정과 검정을 할 수 있기 때문이다.

| 핵심     | 설명                 |
| ------ | ------------------ |
| 모집단 분포 | 어떤 형태여도 가능         |
| 표본 크기  | 충분히 크면             |
| 결과     | 표본평균의 분포가 정규분포에 근사 |
| 의미     | 추정과 검정에 정규분포 활용 가능 |

시험에서는 이렇게 기억하면 된다.

```markdown
중심극한정리는 모집단의 분포와 관계없이 표본 크기가 충분히 크면
표본평균의 분포가 정규분포에 가까워진다는 정리이다.
```

# 14. 기대값과 분산

## 1) 기대값

**기대값(Expected Value)**은 확률변수가 평균적으로 가질 것으로 기대되는 값이다.

```markdown
기대값 = 확률변수의 평균적인 값
```

예를 들어 주사위를 한 번 던졌을 때 나오는 눈의 기대값은 다음과 같다.

```markdown
(1 + 2 + 3 + 4 + 5 + 6) / 6 = 3.5
```

실제로 주사위를 한 번 던져서 3.5가 나올 수는 없지만,
아주 많이 반복하면 평균은 3.5에 가까워진다.

```markdown
기대값은 장기적으로 기대되는 평균값이다.
```

---

## 2) 분산

확률분포에서 **분산**은 확률변수가 기대값 주변에서 얼마나 퍼져 있는지를 나타낸다.

```markdown
분산 = 확률변수가 기대값 주변에 얼마나 흩어져 있는지를 나타내는 값
```

분산이 크면 값들이 기대값에서 멀리 퍼져 있고,
분산이 작으면 기대값 근처에 모여 있다.

| 구분   | 의미            |
| ---- | ------------- |
| 기대값  | 확률변수의 평균적인 값  |
| 분산   | 기대값 주변의 퍼짐 정도 |
| 표준편차 | 분산의 제곱근       |

# 15. ADsP 시험 포인트

이 단원에서 시험에 자주 나오는 포인트는 다음이다.

| 포인트    | 핵심                          |
| ------ | --------------------------- |
| 확률     | 사건 발생 가능성                   |
| 표본공간   | 가능한 모든 결과의 집합               |
| 사건     | 표본공간의 부분집합                  |

# 시험 직전 암기 문장

```markdown
확률은 어떤 사건이 발생할 가능성을 0과 1 사이의 값으로 나타낸 것이다.

표본공간은 어떤 실험에서 발생할 수 있는 모든 결과의 집합이고,
사건은 표본공간 중 관심 있는 결과의 집합이다.

합사건은 A 또는 B가 발생하는 사건이고,
곱사건은 A와 B가 동시에 발생하는 사건이다.

배반사건은 두 사건이 동시에 발생할 수 없는 사건이며,
배반사건에서는 P(A ∪ B) = P(A) + P(B)가 성립한다.

조건부 확률은 어떤 사건이 발생했다는 조건하에서 다른 사건이 발생할 확률이며,
P(A|B) = P(A ∩ B) / P(B)로 계산한다.

독립사건은 한 사건의 발생이 다른 사건의 발생 확률에 영향을 주지 않는 사건이며,
독립사건에서는 P(A ∩ B) = P(A)P(B)가 성립한다.

확률변수는 확률적 실험의 결과를 숫자로 나타낸 변수이다.

이산확률변수는 불량품 수, 전화 수처럼 셀 수 있는 값을 가지며,
연속확률변수는 키, 몸무게, 시간처럼 연속적인 값을 가진다.

확률분포는 확률변수가 가질 수 있는 값과 그 값이 발생할 확률의 대응 관계이다.

베르누이분포는 한 번의 시행에서 성공 또는 실패만 나타나는 분포이고,
이항분포는 베르누이 시행을 여러 번 반복했을 때 성공 횟수의 분포이다.

포아송분포는 일정한 시간이나 공간에서 어떤 사건이 발생하는 횟수를 나타내는 분포이다.

정규분포는 평균을 중심으로 좌우 대칭인 종 모양의 연속확률분포이며,
평균, 중앙값, 최빈값이 모두 같다.

표준정규분포는 평균이 0이고 표준편차가 1인 정규분포이며,
Z = (X - μ) / σ로 표준화한다.

정규분포에서는 평균 ± 1표준편차 안에 약 68%,
평균 ± 2표준편차 안에 약 95%,
평균 ± 3표준편차 안에 약 99.7%의 데이터가 포함된다.

중심극한정리는 모집단의 분포와 관계없이 표본 크기가 충분히 크면
표본평균의 분포가 정규분포에 가까워진다는 정리이다.

t분포는 표본 크기가 작고 모집단의 분산을 모를 때 사용하며,
카이제곱분포는 범주형 자료 검정이나 분산 검정에 사용된다.

F분포는 두 분산의 비율과 관련된 분포이며,
분산분석에서 사용된다.
```
