## 021. 설정 창의 앱

### 1. 앱 및 기능

설치된 앱을 확인하고 **수정하거나 제거**하는 화면입니다.

| 항목 | 설명 |
| --- | --- |
| 앱 목록 | 설치된 모든 앱을 이름·크기·설치 날짜순으로 정렬하여 표시합니다. |
| 수정 / 제거 | 앱을 선택하면 [수정]과 [제거] 단추가 나타납니다. |
| 앱 설치 위치 선택 | 앱을 어디에서 받을 수 있게 할지(Store 전용 / 모든 위치) 지정합니다. |
| 선택적 기능 | 필기 인식, 미디어 기능 팩 등 추가 기능을 설치·제거합니다. |
| 앱 실행 별칭 | 같은 이름으로 실행되는 앱이 여러 개일 때 어느 것을 실행할지 지정합니다. |

> 앱을 제거하려면 **반드시 [설정] → [앱] 또는 [제어판] → [프로그램 및 기능]** 을 이용해야 합니다.  
> 설치 폴더를 직접 삭제하면 **레지스트리 정보가 남아 시스템에 문제가 생길 수 있습니다.**

#### 왜 폴더만 지우면 안 될까?

프로그램을 설치하면 실행 파일만 복사되는 것이 아닙니다.

- 레지스트리에 설정 정보가 기록되고
- 시스템 폴더에 공용 파일(DLL 등)이 추가되며
- 서비스나 시작 프로그램으로 등록되기도 합니다.

폴더만 삭제하면 **이런 흔적이 그대로 남아** 오류의 원인이 됩니다.

제거 프로그램(언인스톨러)은 설치할 때 기록해 둔 목록을 보고  
**설치 과정에서 만들어진 것들을 역순으로 정리**해 줍니다.

---

### 2. 기본 앱

파일 형식이나 작업별로 **어떤 프로그램을 사용할지 지정**하는 화면입니다.

| 항목 | 설명 |
| --- | --- |
| 기본 앱 선택 | 전자 메일, 지도, 음악 플레이어, 사진 뷰어, 비디오 플레이어, 웹 브라우저의 기본 앱을 지정합니다. |
| 파일 형식별 기본 앱 선택 | 확장자(`.txt`, `.jpg` 등)별로 연결할 프로그램을 지정합니다. |
| 프로토콜별 기본 앱 선택 | `http`, `mailto` 등 프로토콜별 기본 앱을 지정합니다. |
| 앱별 기본값 설정 | 특정 앱이 처리할 파일 형식을 한꺼번에 지정합니다. |

#### 왜 "연결 프로그램"이라는 개념이 필요할까?

파일은 그 자체로는 데이터일 뿐이며, **스스로 실행되지 않습니다.**

`.jpg` 파일을 더블클릭했을 때 그림이 열리는 것은,  
운영체제가 **"이 확장자는 이 프로그램으로 연다"** 는 규칙을 기억하고 있기 때문입니다.

- 개별 파일만 다른 프로그램으로 열고 싶을 때 → 바로 가기 메뉴 → [연결 프로그램]
- 해당 형식 전체를 바꾸고 싶을 때 → **기본 앱 설정**

---

### 3. 오프라인 지도

- 인터넷에 연결되지 않은 상태에서도 사용할 수 있도록 **지도를 미리 내려받아 저장**합니다.
- 저장 위치를 지정하고, 사용하지 않는 지도를 삭제할 수 있습니다.

---

### 4. 웹 사이트용 앱

웹 사이트 주소를 열 때, 브라우저 대신 **해당 사이트의 전용 앱으로 열도록** 설정합니다.

---

### 5. 비디오 재생 / 시작 프로그램

| 항목 | 설명 |
| --- | --- |
| 비디오 재생 | HDR 스트리밍, 배터리 사용 시 비디오 해상도 자동 조정 등을 설정합니다. |
| **시작 프로그램** | **Windows에 로그인할 때 자동으로 실행되는 앱**을 켜거나 끕니다. |

- 시작 프로그램 목록에는 각 앱의 **시작 영향(높음 / 중간 / 낮음 / 측정되지 않음)** 이 함께 표시됩니다.

#### 왜 시작 프로그램을 관리해야 할까?

프로그램을 설치하면 **사용자 동의 없이 시작 프로그램에 등록되는 경우**가 많습니다.

이런 프로그램이 늘어나면

- 부팅 시간이 길어지고
- 메모리를 계속 차지하여 전체 성능이 떨어집니다.

자주 쓰지 않는 프로그램은 시작 프로그램에서 꺼 두는 것이  
**부팅 속도와 시스템 자원을 확보하는 가장 간단한 방법**입니다.

> 시작 프로그램은 **[작업 관리자] → [시작프로그램] 탭**에서도 관리할 수 있습니다.

---

### 한 줄 정리

[앱] 범주에서는 **앱 설치·제거, 파일 형식별 기본 앱, 시작 프로그램**을 관리하며,  
앱을 제거할 때는 **폴더를 직접 지우지 말고 반드시 [앱 및 기능]이나 [프로그램 및 기능]** 을 이용해야 합니다.
