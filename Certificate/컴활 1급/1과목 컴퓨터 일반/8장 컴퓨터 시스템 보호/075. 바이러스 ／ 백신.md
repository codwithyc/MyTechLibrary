## 075. 바이러스 / 백신

### 1. 컴퓨터 바이러스의 개요

컴퓨터 바이러스는 **자기 자신을 복제하여 다른 프로그램이나 파일을 감염시키는 악성 프로그램**입니다.

**감염 경로**

- 인터넷에서 내려받은 파일
- 전자 우편의 첨부 파일
- USB 메모리 등 이동식 저장 장치
- 불법 복제 소프트웨어
- 네트워크를 통한 공유 폴더

**감염 증상**

- 시스템 속도가 느려지거나 자주 멈춥니다.
- 파일이 사라지거나 크기가 변합니다.
- 알 수 없는 메시지나 광고 창이 표시됩니다.
- 사용 가능한 메모리와 디스크 공간이 줄어듭니다.
- 부팅이 되지 않거나 시간이 오래 걸립니다.
- CMOS 설정값이 변경됩니다.

#### 왜 "바이러스"라는 이름이 붙었을까?

생물학적 바이러스는 **스스로 살아가지 못하고, 숙주 세포에 들어가 자신을 복제**합니다.

컴퓨터 바이러스도 마찬가지로

- 단독으로 존재하기보다 **다른 프로그램에 붙어 있고**
- 그 프로그램이 실행될 때 **함께 실행되어 자신을 복제**합니다.

이 동작 방식이 매우 비슷하여 같은 이름이 사용되었습니다.

---

### 2. 바이러스의 분류

**감염 위치에 따른 분류**

| 종류 | 설명 |
| --- | --- |
| **부트 바이러스** | 부트 섹터를 감염시켜 **부팅 시 실행**됩니다. (브레인, 미켈란젤로) |
| **파일 바이러스** | 실행 파일(`.exe`, `.com`)을 감염시킵니다. (예루살렘, CIH) |
| **부트/파일 바이러스** | 부트 섹터와 파일을 모두 감염시킵니다. (에볼라, 나타스) |
| **매크로 바이러스** | 문서 파일의 **매크로 기능**을 이용해 감염됩니다. (멜리사, 라룩스) |

**동작 방식에 따른 분류**

| 종류 | 설명 |
| --- | --- |
| **은닉 바이러스** | 감염 사실을 숨겨 백신이 발견하지 못하게 합니다. |
| **암호화 바이러스** | 자신의 코드를 암호화하여 탐지를 어렵게 합니다. |
| **다형성 바이러스** | 감염될 때마다 **형태를 바꾸어** 탐지를 회피합니다. |

#### 왜 다형성 바이러스는 탐지가 어려울까?

백신은 알려진 악성 코드의 **특징적인 패턴(시그니처)** 을 저장해 두고 비교합니다.

다형성 바이러스는 감염할 때마다 **코드의 모양을 조금씩 바꿉니다.**  
기능은 같지만 겉모습이 달라지므로, 저장된 패턴과 일치하지 않습니다.

그래서 최근의 백신은 패턴 비교뿐 아니라  
**행동을 관찰하여 판단하는 방식(행위 기반 탐지)** 도 함께 사용합니다.

---

### 3. 악성 프로그램의 종류

| 종류 | 특징 |
| --- | --- |
| **웜(Worm)** | 다른 프로그램에 기생하지 않고 **스스로 복제하여 네트워크로 전파**됩니다. 시스템 자원을 소모시킵니다. |
| **트로이 목마(Trojan Horse)** | 정상 프로그램인 것처럼 위장하여 설치되며, **자기 복제 능력은 없습니다.** 정보 유출이나 백도어 설치에 사용됩니다. |
| **랜섬웨어(Ransomware)** | 파일을 **암호화한 뒤 금전을 요구**합니다. |
| **스파이웨어(Spyware)** | 사용자 몰래 정보를 수집하여 외부로 전송합니다. |
| **애드웨어(Adware)** | 원치 않는 광고를 표시합니다. |
| **키로거(Key Logger)** | 키보드 입력을 기록하여 **아이디와 비밀번호를 탈취**합니다. |
| **백도어(Back Door)** | 정상적인 인증을 거치지 않고 시스템에 접근할 수 있는 **비밀 통로**입니다. |
| **루트킷(Rootkit)** | 침입 사실을 숨기고 지속적인 접근을 유지하는 도구 모음입니다. |
| **봇넷(Botnet)** | 감염된 여러 컴퓨터를 원격 조종하여 공격에 이용합니다. |

#### 바이러스 vs 웜 vs 트로이 목마

가장 자주 출제되는 구분입니다.

| 구분 | 자기 복제 | 숙주 필요 | 전파 방식 |
| --- | --- | --- | --- |
| **바이러스** | **○** | **○ (다른 파일에 기생)** | 감염된 파일 실행 |
| **웜** | **○** | **✕ (독립 실행)** | **네트워크를 통해 스스로 전파** |
| **트로이 목마** | **✕** | — | 사용자가 직접 설치 |

#### 왜 웜이 더 빠르게 퍼질까?

바이러스는 **사람이 감염된 파일을 실행해야** 퍼집니다.  
즉, 전파 속도가 사람의 행동에 좌우됩니다.

웜은 **네트워크의 취약점을 스스로 찾아** 다른 컴퓨터로 이동합니다.  
사람의 개입이 필요 없으므로, 몇 시간 만에 전 세계로 퍼질 수 있습니다.

#### 왜 랜섬웨어는 백신으로 복구할 수 없을까?

백신은 악성 프로그램을 **제거**할 수 있지만,  
이미 **암호화된 파일을 되돌리지는 못합니다.**

암호를 풀려면 공격자가 가진 **복호화 키**가 필요하기 때문입니다.

그래서 랜섬웨어에 대한 가장 확실한 대비책은 치료가 아니라  
**정기적인 백업**입니다. 특히 백업 매체는 **평소에 연결을 끊어 두어야** 함께 암호화되지 않습니다.

---

### 4. 백신 프로그램

바이러스를 **검사하고 치료하는 프로그램**입니다.

| 기능 | 설명 |
| --- | --- |
| 실시간 감시 | 파일이 실행되거나 열릴 때 자동으로 검사합니다. |
| 검사 | 빠른 검사, 전체 검사, 사용자 지정 검사, 오프라인 검사 |
| 치료 / 격리 | 감염된 파일을 치료하거나, 치료가 어려우면 격리 보관합니다. |
| 업데이트 | 새로운 악성 코드 정보를 갱신합니다. |

- Windows 10에는 **Windows Defender(Microsoft Defender)** 가 기본 내장되어 있습니다.

#### 왜 백신을 항상 최신 상태로 유지해야 할까?

백신은 **알려진 악성 코드의 정보**를 기준으로 판단합니다.

새로운 악성 코드는 매일 수만 개씩 만들어지므로,  
업데이트를 하지 않은 백신은 **최신 위협을 전혀 알아보지 못합니다.**

즉, 백신을 설치했다는 사실보다 **최신 상태를 유지하는 것**이 훨씬 중요합니다.

#### 왜 백신 프로그램은 한 개만 설치해야 할까?

여러 백신을 동시에 설치하면

- 서로를 **악성 프로그램으로 오인**하여 충돌하고
- 실시간 감시 기능이 겹쳐 **시스템이 매우 느려지며**
- 오히려 정상적인 검사가 이루어지지 않을 수 있습니다.

---

### 5. 바이러스 예방 수칙

- 백신 프로그램을 설치하고 **항상 최신 버전으로 업데이트**합니다.
- **실시간 감시 기능**을 켜 둡니다.
- 운영체제와 응용 프로그램의 **보안 업데이트**를 적용합니다.
- 출처가 불분명한 **메일의 첨부 파일과 링크를 열지 않습니다.**
- 인터넷에서 내려받은 파일은 **먼저 검사한 후 실행**합니다.
- **불법 복제 소프트웨어를 사용하지 않습니다.**
- 중요한 자료는 **정기적으로 백업**합니다.
- 공유 폴더는 **필요할 때만, 읽기 권한 위주로** 설정합니다.
- 감염이 의심되면 **네트워크를 먼저 차단**한 후 검사합니다.

---

### 한 줄 정리

**바이러스는 숙주에 기생하며 복제**, **웜은 숙주 없이 네트워크로 스스로 전파**, **트로이 목마는 위장하지만 복제하지 않습니다.**  
백신은 **최신 업데이트 유지가 핵심**이며, **랜섬웨어에 대한 가장 확실한 대비는 백업**입니다.
