## 057. 웹 프로그래밍 언어

### 1. HTML (HyperText Markup Language)

- 웹 문서를 작성하기 위한 **가장 기본적인 언어**입니다.
- **태그(Tag)** 를 이용하여 문서의 구조와 내용을 표현합니다.
- 프로그래밍 언어가 아니라 **마크업 언어**입니다.
- **HTML5** 는 별도의 플러그인 없이 **동영상, 음악, 그래픽**을 표현할 수 있습니다.

#### 왜 HTML은 프로그래밍 언어가 아닐까?

프로그래밍 언어는 **조건 판단, 반복, 계산** 등의 논리를 수행합니다.

HTML은 "이 부분은 제목이다", "이 부분은 표다"처럼  
**내용의 구조와 의미를 표시(markup)** 할 뿐, 계산이나 판단을 하지 않습니다.

그래서 마크업 언어로 분류합니다.

---

### 2. 마크업 언어 계열

| 언어 | 특징 |
| --- | --- |
| **SGML** | 마크업 언어의 **원형**으로, 매우 복잡하고 규모가 큽니다. |
| **HTML** | SGML을 웹 문서용으로 단순화한 언어입니다. |
| **XML** | **사용자가 태그를 직접 정의**할 수 있는 확장 가능한 마크업 언어로, **데이터 교환**에 주로 사용됩니다. |
| **XHTML** | HTML을 XML의 엄격한 문법 규칙에 맞게 재정의한 언어입니다. |
| **WML** | 무선 단말기(휴대폰)에서 사용하기 위한 마크업 언어입니다. |

#### 왜 XML이 필요할까?

HTML의 태그는 **미리 정해져 있습니다.** (`<p>`, `<table>`, `<img>` 등)

이 태그들은 **화면에 어떻게 보일지**를 나타낼 뿐,  
**그 데이터가 무엇인지**는 표현하지 못합니다.

예를 들어 `<td>홍길동</td>` 만 봐서는 이것이 이름인지 지역인지 알 수 없습니다.

XML은 `<이름>홍길동</이름>` 처럼 **태그를 직접 정의**할 수 있으므로,  
**데이터의 의미까지 함께 전달**할 수 있습니다.

그래서 XML은 화면 표현보다 **서로 다른 시스템 간의 데이터 교환**에 주로 사용됩니다.

### 3. 스크립트 언어

| 언어 | 실행 위치 | 특징 |
| --- | --- | --- |
| **JavaScript** | **클라이언트(웹 브라우저)** | 웹 페이지에 동적인 기능을 추가합니다. 브라우저에서 직접 실행됩니다. |
| **VBScript** | 클라이언트 | Microsoft가 개발한 스크립트 언어로, Internet Explorer에서 동작했습니다. |
| **ASP** | **서버** | Microsoft의 서버 측 스크립트 언어로, Windows 서버에서 동작합니다. |
| **JSP** | **서버** | Java 기반의 서버 측 스크립트 언어로, 다양한 운영체제에서 동작합니다. |
| **PHP** | **서버** | 서버 측 스크립트 언어로, 리눅스·유닉스·윈도우에서 모두 사용할 수 있습니다. |

#### 왜 클라이언트 측과 서버 측으로 나뉠까?

**클라이언트 측 스크립트(JavaScript)**

- 사용자의 컴퓨터(브라우저)에서 실행됩니다.
- 서버에 요청하지 않고 처리하므로 **반응이 즉각적**입니다.
- 예 : 입력값 검사, 메뉴 펼치기, 이미지 슬라이드

**서버 측 스크립트(ASP, JSP, PHP)**

- 웹 서버에서 실행된 후, **결과인 HTML만 사용자에게 전송**됩니다.
- 사용자는 원본 코드를 볼 수 없으므로 **보안이 필요한 처리**에 적합합니다.
- 예 : 로그인 인증, 데이터베이스 조회, 결제 처리

즉,

- **눈앞에서 바로 반응해야 하는 일** → 클라이언트 측
- **감춰야 하고 데이터가 필요한 일** → 서버 측

으로 나누어 처리합니다.

### 4. 그 밖의 웹 관련 언어와 기술

| 용어 | 설명 |
| --- | --- |
| **CSS** | 웹 문서의 **글꼴, 색상, 배치 등 디자인**을 지정하는 스타일 언어입니다. |
| **DHTML** | HTML, CSS, JavaScript를 결합하여 **동적인 웹 페이지**를 만드는 기술입니다. |
| **UML** | 시스템을 **시각적으로 모델링**하기 위한 통합 표기 언어입니다. (프로그래밍 언어가 아님) |
| **VRML** | 웹에서 **3차원 가상 공간**을 표현하기 위한 언어입니다. |
| **JAVA 애플릿** | 웹 페이지 안에서 실행되는 작은 Java 프로그램입니다. |
| **AJAX** | 페이지 전체를 새로 고치지 않고 **필요한 부분만 갱신**하는 기술입니다. |
| **XSL** | XML 문서의 표현 방식을 지정하는 스타일 언어입니다. |

#### 왜 CSS를 HTML과 분리했을까?

초기에는 HTML 안에 글꼴과 색상까지 함께 작성했습니다.

그러면 디자인을 바꿀 때 **모든 페이지의 HTML을 일일이 수정**해야 했습니다.

CSS로 디자인을 분리하면

- **내용(HTML)과 표현(CSS)** 이 나뉘고
- CSS 파일 하나만 바꿔도 **모든 페이지의 디자인이 한 번에 변경**됩니다.

이는 앞서 살펴본 **캡슐화나 구조적 프로그래밍과 같은 발상**입니다.  
즉, **바뀔 것과 바뀌지 않을 것을 분리**하는 것입니다.

#### 왜 AJAX가 등장했을까?

기존 웹은 작은 정보 하나를 갱신하려 해도 **페이지 전체를 다시 불러와야** 했습니다.

화면이 깜빡이고, 불필요한 데이터까지 전송되어 느렸습니다.

AJAX는 필요한 데이터만 백그라운드로 주고받아 **화면의 일부만 갱신**하므로,  
웹 페이지가 마치 **설치된 프로그램처럼 부드럽게 동작**합니다.

---

### 한 줄 정리

**HTML은 문서 구조를 표시하는 마크업 언어**, **XML은 태그를 직접 정의해 데이터를 교환**하는 언어이며,  
**JavaScript는 클라이언트에서, ASP·JSP·PHP는 서버에서 실행**되고,  
**CSS는 내용과 디자인을 분리**하기 위한 스타일 언어입니다.
