## 002. 한글 Windows 10의 시작과 종료

### 1. 부팅(Booting)의 개요

부팅이란 컴퓨터의 전원을 켰을 때, 운영체제를 주기억장치에 올려 사용할 수 있는 상태로 만드는 과정입니다.

부팅 과정은 다음과 같은 순서로 진행됩니다.

**전원 공급 → ROM BIOS 실행 → POST(자체 진단) 실행 → CMOS 설정값 확인 → 부팅 매체 검색 → 부트로더 실행 → 운영체제 로드 → 로그인**

#### 왜 ROM BIOS가 가장 먼저 실행될까?

컴퓨터의 전원을 켠 직후에는 운영체제가 아직 메모리에 올라와 있지 않습니다.  
그렇다면 "무엇으로 운영체제를 불러올 것인가"라는 문제가 생깁니다.

그래서 전원이 꺼져도 지워지지 않는 ROM에 **가장 먼저 실행될 기본 프로그램(BIOS)** 을 저장해 둡니다.

즉, BIOS는  
**운영체제를 불러오기 위한 최초의 프로그램**입니다.

#### 왜 POST 과정이 필요할까?

운영체제를 불러오기 전에, 하드웨어가 정상인지 먼저 확인해야 합니다.  
메모리나 키보드에 문제가 있는데도 그냥 부팅을 진행하면 이후 동작을 신뢰할 수 없기 때문입니다.

POST(Power On Self Test)는  
**부팅을 계속해도 되는 상태인지 판단하는 자체 진단 과정**입니다.

---

### 2. 부팅의 종류

| 종류 | 특징 |
| --- | --- |
| 콜드 부팅(Cold Booting) | 전원이 꺼진 상태에서 전원을 켜서 부팅하는 방식입니다. POST를 포함한 전체 과정을 수행합니다. |
| 웜 부팅(Warm Booting) | 컴퓨터가 켜져 있는 상태에서 다시 시작하는 방식입니다. `Ctrl + Alt + Delete` 또는 [다시 시작]을 이용합니다. |

#### 왜 웜 부팅이 더 빠를까?

콜드 부팅은 전원 공급부터 시작하므로 하드웨어 점검(POST)을 처음부터 모두 수행합니다.  
반면 웜 부팅은 이미 하드웨어가 동작 중인 상태에서 소프트웨어적으로 다시 시작하는 것이므로,  
점검 과정 일부를 생략할 수 있어 상대적으로 빠릅니다.

---

### 3. 고급 부팅 옵션(시스템 복구 옵션)

시스템에 문제가 생겼을 때 사용하는 특수한 부팅 방법입니다.

| 옵션 | 특징 |
| --- | --- |
| 안전 모드(Safe Mode) | 시스템 구동에 필요한 최소한의 드라이버와 서비스만으로 부팅합니다. 문제 원인을 찾을 때 사용합니다. |
| 안전 모드(네트워킹 사용) | 안전 모드에 네트워크 기능을 추가하여 부팅합니다. |
| 안전 모드(명령 프롬프트 사용) | 안전 모드로 부팅하되 GUI 대신 명령 프롬프트 화면으로 시작합니다. |
| 부팅 로깅 사용 | 부팅 과정에서 로드된 드라이버 정보를 `ntbtlog.txt` 파일에 기록합니다. |
| 저해상도 비디오 사용 | 현재 그래픽 드라이버를 낮은 해상도로 실행하여 부팅합니다. |
| 마지막으로 성공한 구성 | 마지막으로 정상 부팅되었을 때의 레지스트리 정보로 부팅합니다. |
| 디버깅 모드 | 부팅 정보를 다른 컴퓨터로 전송하면서 부팅합니다. |

#### 왜 안전 모드가 필요할까?

시스템이 부팅되지 않는 원인은 대부분 **잘못된 드라이버나 프로그램** 때문입니다.  
그런데 문제가 되는 프로그램이 부팅과 동시에 실행되면, 문제를 고칠 기회조차 얻지 못합니다.

안전 모드는 **꼭 필요한 것만 실행한 상태로 진입**하게 해 주므로,  
그 안에서 문제가 되는 드라이버나 프로그램을 제거할 수 있습니다.

즉, 안전 모드는  
**문제를 고칠 수 있는 최소한의 작업 환경을 확보하기 위한 부팅 방식**입니다.

### 4. Windows 10의 종료 옵션

[시작] → [전원]을 통해 다음과 같은 종료 방법을 선택할 수 있습니다.

| 옵션 | 특징 |
| --- | --- |
| 절전(Sleep) | 작업 상태를 메모리(RAM)에 저장하고 최소 전력만 사용하는 상태로 전환합니다. 복귀 속도가 매우 빠릅니다. |
| 최대 절전 모드 | 작업 상태를 하드디스크에 저장한 후 전원을 완전히 차단합니다. 전력을 사용하지 않으며, 복귀 시 이전 작업 상태가 그대로 복원됩니다. |
| 시스템 종료 | 실행 중인 프로그램을 모두 종료하고 전원을 끕니다. |
| 다시 시작 | 시스템을 종료한 후 자동으로 다시 부팅합니다. |

#### 왜 절전과 최대 절전 모드를 구분할까?

두 기능은 **작업 상태를 어디에 저장하는가**가 다릅니다.

- **절전** : RAM에 저장 → 빠르지만 전원이 완전히 끊기면 작업 내용이 사라질 수 있음
- **최대 절전 모드** : 하드디스크에 저장 → 느리지만 전원을 완전히 꺼도 작업 내용이 유지됨

RAM은 휘발성 메모리이므로 전력 공급이 필요하고,  
하드디스크는 비휘발성이므로 전력이 없어도 내용이 남습니다.

즉,

- 잠깐 자리를 비울 때 → **절전**
- 오래 쓰지 않지만 작업은 그대로 두고 싶을 때 → **최대 절전 모드**

### 5. 로그아웃과 사용자 전환

| 기능 | 특징 |
| --- | --- |
| 로그아웃(로그오프) | 현재 사용자의 실행 중인 프로그램을 모두 종료하고 로그인 화면으로 돌아갑니다. |
| 사용자 전환 | 현재 사용자의 작업 상태를 유지한 채 다른 사용자로 전환합니다. |

#### 왜 사용자 전환은 프로그램을 종료하지 않을까?

한 대의 컴퓨터를 여러 사람이 함께 쓰는 경우, 잠시 다른 사람이 사용한 뒤 다시 돌아오는 상황이 생깁니다.  
이때마다 작업을 모두 종료해야 한다면 매우 불편합니다.

사용자 전환은 기존 사용자의 작업을 **메모리에 그대로 유지한 상태로** 다른 계정만 추가로 로그인시키는 방식입니다.

다만 여러 사용자의 작업이 동시에 메모리에 남아 있으므로 **메모리 사용량이 늘어난다**는 단점이 있습니다.

---

### 한 줄 정리

부팅은 **ROM BIOS → POST → 운영체제 로드** 순으로 진행되며,  
문제가 생겼을 때는 **안전 모드**로 최소 환경을 확보하고,  
종료 시에는 작업 상태를 **RAM에 저장하는 절전**과 **하드디스크에 저장하는 최대 절전 모드**를 구분해서 사용합니다.
