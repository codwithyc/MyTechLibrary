# 통계학 개론

통계학 개론은 통계 분석을 이해하기 위한 가장 기본 단원이다.
이 단원에서는 통계가 무엇인지, 데이터를 어떻게 구분하는지, 모집단과 표본이 무엇인지, 그리고 표본을 이용해 모집단을 어떻게 추정하는지를 이해해야 한다.

```markdown id="f91x0a"
통계학 = 데이터를 수집·정리·분석·해석하여 의사결정에 필요한 정보를 도출하는 학문
```

ADsP 시험에서는 계산보다 **개념 구분**이 중요하다.

주로 다음 내용을 묻는다.

* 통계학의 정의
* 기술통계와 추론통계
* 모집단과 표본
* 모수와 통계량
* 자료의 종류
* 척도의 종류
* 표본추출 방법
* 확률표본추출과 비확률표본추출
* 표본오차와 비표본오차

기존 정리처럼 개념을 먼저 이해하고 표로 압축하는 방식이 시험 직전 복습에 좋다. 

---

# 01. 통계학의 개념

## 통계학의 정의

**통계학**은 불확실한 상황에서 데이터를 수집하고, 정리하고, 분석하여 의미 있는 정보를 도출하는 학문이다.

단순히 숫자를 계산하는 것이 아니라, 데이터를 통해 현상을 이해하고 합리적인 판단을 내리기 위한 방법이다.

예를 들어 다음과 같은 질문을 생각해볼 수 있다.

```markdown id="vt7t93"
우리 서비스의 평균 이용 시간은 얼마인가?
고객 만족도가 재구매에 영향을 주는가?
신규 마케팅 캠페인 이후 매출이 증가했는가?
표본 고객의 구매 패턴으로 전체 고객의 특성을 추정할 수 있는가?
```

이런 질문에 답하기 위해 통계학을 사용한다.

```markdown id="rz68tw"
통계학은 데이터를 근거로 현상을 설명하고, 추정하고, 의사결정을 지원하는 도구이다.
```

---

## 통계학의 목적

| 목적      | 설명                           |
| ------- | ---------------------------- |
| 데이터 요약  | 복잡한 데이터를 평균, 비율, 표준편차 등으로 요약 |
| 현상 설명   | 데이터의 분포, 경향, 관계를 파악          |
| 모집단 추정  | 표본을 이용해 전체 집단의 특성을 추정        |
| 가설 검정   | 주장이나 차이가 통계적으로 의미 있는지 판단     |
| 예측      | 과거 데이터를 바탕으로 미래나 결과값을 예측     |
| 의사결정 지원 | 데이터 기반으로 합리적 판단을 내림          |

시험에서는 이렇게 이해하면 된다.

```markdown id="bbz2aj"
통계학은 데이터를 요약하고, 모집단을 추정하며, 가설을 검정하고, 의사결정을 지원하는 학문이다.
```

# 02. 기술통계와 추론통계

통계학은 크게 **기술통계**와 **추론통계**로 나뉜다.

```markdown id="veq06k"
기술통계 = 데이터를 요약하고 설명
추론통계 = 표본으로 모집단을 추정하고 검정
```

---

## 1) 기술통계

**기술통계**는 수집된 데이터를 정리하고 요약하여 데이터의 특성을 설명하는 통계 방법이다.

예를 들어 학생 10명의 점수 데이터가 있을 때, 평균 점수, 최고 점수, 최저 점수, 표준편차를 계산하는 것이 기술통계다.

```markdown id="jz6say"
기술통계 = 현재 가지고 있는 데이터를 요약하고 설명하는 통계
```

### 기술통계 예시

| 구분     | 예시                |
| ------ | ----------------- |
| 중심 경향  | 평균, 중앙값, 최빈값      |
| 산포도    | 범위, 분산, 표준편차, IQR |
| 분포 형태  | 히스토그램, 도수분포표      |
| 데이터 요약 | 요약 통계량, 그래프, 표    |

기술통계는 **현재 데이터 자체를 설명하는 것**이 목적이다.
표본을 이용해 모집단 전체를 추정하는 단계는 아니다.

---

## 2) 추론통계

**추론통계**는 표본 데이터를 이용해 모집단의 특성을 추정하거나 가설을 검정하는 통계 방법이다.

전체 데이터를 모두 조사하기 어려울 때 일부 표본을 뽑아 전체 모집단의 특성을 추정한다.

예를 들어 대한민국 성인 전체의 평균 키를 알고 싶다고 하자.
모든 사람을 조사하기 어렵기 때문에 일부 사람을 표본으로 뽑아 평균 키를 계산하고, 이를 바탕으로 전체 성인의 평균 키를 추정한다.

```markdown id="aag6yi"
추론통계 = 표본을 이용해 모집단의 특성을 추정하거나 가설을 검정하는 통계
```

### 추론통계 예시

| 구분   | 예시                         |
| ---- | -------------------------- |
| 추정   | 표본 평균으로 모집단 평균 추정          |
| 신뢰구간 | 모집단 평균이 존재할 것으로 예상되는 범위 제시 |
| 가설검정 | 두 집단 평균 차이가 통계적으로 유의한지 판단  |
| 예측   | 회귀분석 등을 이용해 결과값 예측         |

시험에서는 이렇게 구분하면 된다.

```markdown id="p1wg0l"
기술통계는 데이터를 요약하는 것이고,
추론통계는 표본을 이용해 모집단을 추정하거나 검정하는 것이다.
```

# 03. 모집단과 표본

통계학에서 가장 중요한 기본 개념은 **모집단**과 **표본**이다.

```markdown id="rlf3uz"
모집단 = 알고 싶은 전체 집단
표본 = 모집단에서 추출한 일부 집단
```

---

## 1) 모집단

**모집단(Population)**은 연구나 분석의 대상이 되는 전체 집단이다.

예를 들어 “우리 회사 전체 고객의 평균 구매 금액”을 알고 싶다면,
우리 회사 전체 고객이 모집단이다.

```markdown id="dbyjvt"
모집단 = 분석 대상이 되는 전체 집단
```

### 모집단 예시

| 알고 싶은 것          | 모집단        |
| ---------------- | ---------- |
| 전국 고등학생 평균 키     | 전국 고등학생 전체 |
| 쇼핑몰 고객 평균 구매 금액  | 쇼핑몰 전체 고객  |
| 서울시 직장인 평균 출근 시간 | 서울시 직장인 전체 |
| 앱 사용자 평균 이용 시간   | 앱 사용자 전체   |

---

## 2) 표본

**표본(Sample)**은 모집단에서 일부를 추출한 집단이다.

모집단 전체를 조사하는 것은 시간과 비용이 많이 들기 때문에, 일부 데이터를 뽑아 분석하고 전체 모집단을 추정한다.

```markdown id="fi9vmo"
표본 = 모집단에서 추출한 일부 데이터
```

예를 들어 쇼핑몰 전체 고객이 100만 명이라면,
그중 1만 명을 뽑아 평균 구매 금액을 계산할 수 있다.
이때 1만 명이 표본이다.

---

## 3) 전수조사와 표본조사

| 구분   | 설명         | 장점        | 단점           |
| ---- | ---------- | --------- | ------------ |
| 전수조사 | 모집단 전체를 조사 | 정확성이 높음   | 시간과 비용이 많이 듦 |
| 표본조사 | 모집단 일부를 조사 | 시간과 비용 절감 | 표본오차 발생 가능   |

시험에서는 이렇게 이해하면 된다.

```markdown id="j6fhxz"
전수조사는 모집단 전체를 조사하는 것이고,
표본조사는 모집단 일부를 조사하는 것이다.
```

---

# 04. 모수와 통계량

모집단과 표본을 구분했다면, 다음으로 **모수**와 **통계량**을 구분해야 한다.

```markdown id="jh9d85"
모수 = 모집단의 특성값
통계량 = 표본의 특성값
```

---

## 1) 모수

**모수(Parameter)**는 모집단의 특성을 나타내는 값이다.

예를 들어 전체 고객의 평균 구매 금액, 전체 학생의 평균 점수, 전체 상품의 불량률 등이 모수다.

```markdown id="0pqei4"
모수 = 모집단의 평균, 분산, 비율 같은 특성값
```

---

## 2) 통계량

**통계량(Statistic)**은 표본에서 계산한 특성값이다.

예를 들어 표본 고객 1,000명의 평균 구매 금액, 표본 학생 100명의 평균 점수가 통계량이다.

```markdown id="c7pttx"
통계량 = 표본에서 계산한 평균, 분산, 비율 같은 값
```

---

## 모수와 통계량 비교

| 구분 | 모수                     | 통계량                 |
| -- | ---------------------- | ------------------- |
| 기준 | 모집단                    | 표본                  |
| 의미 | 모집단의 특성값               | 표본의 특성값             |
| 예시 | 모집단 평균, 모집단 분산, 모집단 비율 | 표본 평균, 표본 분산, 표본 비율 |
| 특징 | 실제로 알기 어려운 경우가 많음      | 표본으로 계산 가능          |

시험에서는 이렇게 외우면 된다.

```markdown id="hbl8u0"
모수는 모집단의 값이고,
통계량은 표본에서 계산한 값이다.
```

# 05. 자료의 종류

통계 분석에서는 자료를 크게 **질적 자료**와 **양적 자료**로 나눈다.

```markdown id="b5pdzq"
질적 자료 = 범주로 구분되는 자료
양적 자료 = 숫자로 크기와 양을 표현하는 자료
```

---

## 1) 질적 자료

**질적 자료(Qualitative Data)**는 숫자의 크기보다 범주나 속성을 나타내는 자료다.

예를 들어 성별, 혈액형, 지역, 직업, 상품 유형 등이 질적 자료다.

```markdown id="3vu7kk"
질적 자료 = 범주나 속성을 나타내는 자료
```

질적 자료는 다시 명목척도와 순서척도로 연결된다.

---

## 2) 양적 자료

**양적 자료(Quantitative Data)**는 숫자로 측정되며 크기나 양의 의미를 가지는 자료다.

예를 들어 키, 몸무게, 나이, 매출, 구매 금액, 시험 점수 등이 양적 자료다.

```markdown id="yz5wrh"
양적 자료 = 숫자로 크기나 양을 나타내는 자료
```

양적 자료는 다시 이산형 자료와 연속형 자료로 나눌 수 있다.

---

## 질적 자료와 양적 자료 비교

| 구분    | 질적 자료           | 양적 자료          |
| ----- | --------------- | -------------- |
| 의미    | 범주나 속성          | 숫자와 크기         |
| 예시    | 성별, 혈액형, 지역, 직업 | 키, 몸무게, 나이, 매출 |
| 연산    | 산술 연산 의미 없음     | 산술 연산 가능       |
| 관련 척도 | 명목척도, 순서척도      | 등간척도, 비율척도     |

시험에서는 이렇게 기억하면 된다.

```markdown id="oorodl"
질적 자료는 범주를 나타내고,
양적 자료는 숫자로 크기나 양을 나타낸다.
```

# 06. 이산형 자료와 연속형 자료

양적 자료는 다시 **이산형 자료**와 **연속형 자료**로 나뉜다.

---

## 1) 이산형 자료

**이산형 자료(Discrete Data)**는 셀 수 있는 값으로 표현되는 자료다.

값과 값 사이가 끊어져 있으며, 보통 정수 형태로 나타난다.

예를 들어 고객 수, 방문 횟수, 구매 건수, 불량품 개수 등이 이산형 자료다.

```markdown id="6adzgg"
이산형 자료 = 셀 수 있는 값으로 표현되는 자료
```

---

## 2) 연속형 자료

**연속형 자료(Continuous Data)**는 연속적인 범위 안에서 어떤 값이든 가질 수 있는 자료다.

예를 들어 키, 몸무게, 시간, 온도, 거리, 매출 금액 등이 연속형 자료다.

```markdown id="a3qxl0"
연속형 자료 = 연속적인 범위 안에서 측정되는 자료
```

---

## 이산형 자료와 연속형 자료 비교

| 구분    | 이산형 자료             | 연속형 자료         |
| ----- | ------------------ | -------------- |
| 의미    | 셀 수 있는 자료          | 측정되는 자료        |
| 값의 형태 | 주로 정수              | 소수 포함 가능       |
| 예시    | 고객 수, 방문 횟수, 구매 건수 | 키, 몸무게, 시간, 온도 |
| 특징    | 값 사이가 끊어짐          | 값 사이가 연속적      |

시험에서는 이렇게 외우면 된다.

```markdown id="2zazrw"
이산형은 셀 수 있는 값이고,
연속형은 측정되는 값이다.
```

# 07. 척도의 종류

척도는 데이터를 측정하는 기준이다.

ADsP에서는 척도 4가지를 반드시 구분해야 한다.

```markdown id="1btk2d"
명목척도
순서척도
등간척도
비율척도
```

---

## 1) 명목척도

**명목척도(Nominal Scale)**는 단순히 대상을 구분하기 위한 척도다.

값 사이에 순서나 크기 의미가 없다.

예를 들어 성별, 혈액형, 지역, 직업, 상품 코드 등이 명목척도다.

```markdown id="5xp33a"
명목척도 = 단순 분류를 위한 척도
```

| 예시    | 설명          |
| ----- | ----------- |
| 성별    | 남, 여        |
| 혈액형   | A, B, O, AB |
| 지역    | 서울, 부산, 광주  |
| 상품 코드 | A001, A002  |

숫자로 표현하더라도 크기의 의미는 없다.

예를 들어 남자를 1, 여자를 2로 표현한다고 해서 여자가 남자보다 크다는 의미는 아니다.

---

## 2) 순서척도

**순서척도(Ordinal Scale)**는 값 사이에 순서가 있는 척도다.

하지만 순서 간 간격이 동일하다고 볼 수는 없다.

예를 들어 만족도, 학점, 등급, 선호 순위 등이 순서척도다.

```markdown id="0tgyjw"
순서척도 = 순서는 있지만 간격이 일정하지 않은 척도
```

| 예시    | 설명                             |
| ----- | ------------------------------ |
| 만족도   | 매우 불만족 < 불만족 < 보통 < 만족 < 매우 만족 |
| 학점    | F < D < C < B < A              |
| 고객 등급 | Bronze < Silver < Gold < VIP   |
| 순위    | 1등, 2등, 3등                     |

시험에서는 “순서는 있지만 차이의 크기를 정확히 해석할 수 없다”는 점이 중요하다.

---

## 3) 등간척도

**등간척도(Interval Scale)**는 값 사이의 간격이 일정한 척도다.

하지만 절대적인 0이 없기 때문에 비율 계산은 의미가 없다.

대표적인 예시는 섭씨온도, IQ, 날짜 등이 있다.

```markdown id="s5sk1e"
등간척도 = 간격은 일정하지만 절대적 0이 없는 척도
```

예를 들어 섭씨 20도는 섭씨 10도보다 10도 높다.
하지만 20도가 10도보다 “2배 더 덥다”고 말할 수는 없다.

즉, 차이는 의미가 있지만 비율은 의미가 없다.

---

## 4) 비율척도

**비율척도(Ratio Scale)**는 값 사이의 간격이 일정하고, 절대적인 0이 존재하는 척도다.

절대적 0이 있기 때문에 배수 비교가 가능하다.

예를 들어 키, 몸무게, 나이, 소득, 매출, 거리, 시간 등이 비율척도다.

```markdown id="w43ev1"
비율척도 = 간격이 일정하고 절대적 0이 있어 비율 계산이 가능한 척도
```

예를 들어 몸무게 80kg은 40kg의 2배라고 말할 수 있다.
매출 200만 원은 100만 원의 2배라고 말할 수 있다.

---

## 척도 비교

| 척도   | 의미       | 순서 | 간격 | 절대적 0 | 예시             |
| ---- | -------- | -- | -- | ----- | -------------- |
| 명목척도 | 단순 분류    | 없음 | 없음 | 없음    | 성별, 혈액형, 지역    |
| 순서척도 | 순서 있음    | 있음 | 없음 | 없음    | 만족도, 등급, 순위    |
| 등간척도 | 간격 일정    | 있음 | 있음 | 없음    | 섭씨온도, IQ       |
| 비율척도 | 절대적 0 존재 | 있음 | 있음 | 있음    | 키, 몸무게, 매출, 시간 |

암기 방식은 다음과 같다.

```markdown id="8hw6vp"
명목 = 분류
순서 = 순위
등간 = 간격은 있지만 절대 0 없음
비율 = 절대 0이 있어 배수 비교 가능
```

---

# 08. 표본추출

## 표본추출의 개념

**표본추출(Sampling)**은 모집단에서 분석에 사용할 표본을 선택하는 과정이다.

모집단 전체를 조사하기 어렵기 때문에 일부 표본을 추출해 분석한다.

```markdown id="8u4pak"
표본추출 = 모집단에서 일부 표본을 선택하는 과정
```

표본추출에서 가장 중요한 것은 표본이 모집단을 잘 대표해야 한다는 점이다.

표본이 한쪽으로 치우치면 분석 결과도 왜곡될 수 있다.

---

## 표본추출 방법의 구분

표본추출 방법은 크게 두 가지로 나뉜다.

```markdown id="0b75lq"
확률표본추출
비확률표본추출
```

| 구분      | 설명                             |
| ------- | ------------------------------ |
| 확률표본추출  | 모집단의 각 대상이 표본으로 선택될 확률을 알 수 있음 |
| 비확률표본추출 | 표본으로 선택될 확률을 알 수 없음            |

---

# 09. 확률표본추출

**확률표본추출**은 모집단의 각 구성원이 표본으로 선택될 확률을 알 수 있는 방법이다.

무작위성이 포함되므로 표본의 대표성을 확보하기 쉽다.

```markdown id="mvambx"
확률표본추출 = 각 대상이 표본으로 뽑힐 확률을 알 수 있는 표본추출 방법
```

대표적인 방법은 다음과 같다.

```markdown id="q43a2i"
단순무작위추출
계통추출
층화추출
군집추출
```

---

## 1) 단순무작위추출

**단순무작위추출**은 모집단의 모든 대상이 동일한 확률로 선택되도록 표본을 뽑는 방법이다.

예를 들어 전체 학생 명단에서 난수표나 랜덤 함수로 100명을 뽑는 방식이다.

```markdown id="rcrxe4"
단순무작위추출 = 모든 대상이 같은 확률로 선택되는 방법
```

| 장점              | 단점          |
| --------------- | ----------- |
| 방법이 단순하고 편향이 적음 | 모집단 목록이 필요함 |

---

## 2) 계통추출

**계통추출(Systematic Sampling)**은 모집단 목록에서 일정한 간격으로 표본을 추출하는 방법이다.

예를 들어 전체 고객 목록에서 10명마다 1명씩 선택하는 방식이다.

```markdown id="iiobz7"
계통추출 = 일정한 간격으로 표본을 선택하는 방법
```

| 예시                       |
| ------------------------ |
| 1,000명 중 매 10번째 사람 선택    |
| 제품 생산 라인에서 매 100번째 제품 검사 |

단순하지만, 목록에 주기성이 있으면 표본이 편향될 수 있다.

---

## 3) 층화추출

**층화추출(Stratified Sampling)**은 모집단을 서로 다른 층으로 나눈 뒤, 각 층에서 표본을 추출하는 방법이다.

예를 들어 학생을 학년별로 나누고, 각 학년에서 표본을 뽑는 방식이다.

```markdown id="a99vi6"
층화추출 = 모집단을 동질적인 층으로 나눈 뒤 각 층에서 표본을 추출하는 방법
```

| 예시                       |
| ------------------------ |
| 남성과 여성으로 나눈 뒤 각각 표본 추출   |
| 학년별로 나눈 뒤 각 학년에서 표본 추출   |
| 연령대별로 나눈 뒤 각 연령대에서 표본 추출 |

층화추출은 각 집단이 표본에 반영되도록 할 수 있어 대표성을 높이는 데 유리하다.

---

## 4) 군집추출

**군집추출(Cluster Sampling)**은 모집단을 여러 군집으로 나눈 뒤, 일부 군집을 선택하고 그 군집 내 대상을 조사하는 방법이다.

예를 들어 전국 학교 중 일부 학교를 선택하고, 선택된 학교의 학생을 조사하는 방식이다.

```markdown id="01sk3l"
군집추출 = 모집단을 군집으로 나눈 뒤 일부 군집을 선택하여 조사하는 방법
```

층화추출과 군집추출은 헷갈리기 쉽다.

| 구분    | 층화추출                 | 군집추출                  |
| ----- | -------------------- | --------------------- |
| 집단 구성 | 층 내부가 비슷함            | 군집 내부가 다양함            |
| 표본 선택 | 각 층에서 표본 추출          | 일부 군집을 선택             |
| 목적    | 대표성 확보               | 조사 비용 절감              |
| 예시    | 학년별로 나눠 각 학년에서 학생 추출 | 학교 몇 개를 뽑아 그 학교 학생 조사 |

시험에서는 이렇게 기억하면 된다.

```markdown id="cq5uf5"
층화추출은 각 층에서 뽑고,
군집추출은 일부 군집을 통째로 뽑는다.
```

---

# 10. 비확률표본추출

**비확률표본추출**은 각 대상이 표본으로 선택될 확률을 알 수 없는 방법이다.

조사자가 편의나 판단에 따라 표본을 선택하는 경우가 많다.

```markdown id="oiz6vf"
비확률표본추출 = 표본으로 선택될 확률을 알 수 없는 표본추출 방법
```

대표적인 방법은 다음과 같다.

```markdown id="qnyu6r"
편의추출
판단추출
할당추출
눈덩이추출
```

---

## 1) 편의추출

**편의추출**은 조사하기 쉬운 대상을 표본으로 선택하는 방법이다.

예를 들어 길거리에서 만난 사람에게 설문하거나, 주변 친구들에게 설문하는 방식이다.

```markdown id="8hgu0x"
편의추출 = 조사하기 쉬운 대상을 선택하는 방법
```

| 장점           | 단점                |
| ------------ | ----------------- |
| 빠르고 비용이 적게 듦 | 대표성이 낮고 편향 가능성이 큼 |

---

## 2) 판단추출

**판단추출**은 조사자의 전문적 판단에 따라 표본을 선택하는 방법이다.

예를 들어 전문가 인터뷰 대상자를 연구자가 직접 선정하는 방식이다.

```markdown id="626kcy"
판단추출 = 조사자의 판단으로 적합한 대상을 선택하는 방법
```

---

## 3) 할당추출

**할당추출**은 모집단의 특성 비율에 맞게 표본 수를 미리 할당한 뒤, 각 집단에서 임의로 표본을 선택하는 방법이다.

예를 들어 성별 비율에 맞게 남성 50명, 여성 50명을 조사하는 방식이다.

```markdown id="mn6o4z"
할당추출 = 집단별 표본 수를 미리 정해놓고 조사하는 방법
```

층화추출과 비슷해 보이지만, 할당추출은 무작위 추출이 아니므로 비확률표본추출이다.

---

## 4) 눈덩이추출

**눈덩이추출**은 기존 조사 대상자가 다른 조사 대상을 소개해 주는 방식이다.

희귀 집단이나 접근하기 어려운 대상을 조사할 때 사용한다.

```markdown id="hy60zw"
눈덩이추출 = 조사 대상자가 다른 대상자를 소개하며 표본을 늘리는 방법
```

예를 들어 특정 커뮤니티 사용자, 희귀 질환자, 특정 전문가 집단을 조사할 때 사용할 수 있다.

---

## 확률표본추출과 비확률표본추출 비교

| 구분      | 확률표본추출            | 비확률표본추출         |
| ------- | ----------------- | --------------- |
| 선택 확률   | 알 수 있음            | 알 수 없음          |
| 무작위성    | 있음                | 약하거나 없음         |
| 대표성     | 상대적으로 높음          | 낮을 수 있음         |
| 표본오차 추정 | 가능                | 어려움             |
| 예시      | 단순무작위, 계통, 층화, 군집 | 편의, 판단, 할당, 눈덩이 |

시험에서는 이렇게 기억하면 된다.

```markdown id="3xa065"
확률표본추출은 선택 확률을 알 수 있고,
비확률표본추출은 선택 확률을 알 수 없다.
```

# 11. 오차

통계 조사에서는 오차가 발생할 수 있다.

대표적으로 **표본오차**와 **비표본오차**가 있다.

---

## 1) 표본오차

**표본오차**는 모집단 전체가 아니라 표본만 조사했기 때문에 발생하는 오차다.

표본을 어떻게 뽑느냐에 따라 결과가 조금씩 달라질 수 있다.

```markdown id="g9o5ky"
표본오차 = 표본을 사용하기 때문에 발생하는 오차
```

표본의 크기가 커질수록 일반적으로 표본오차는 줄어든다.

---

## 2) 비표본오차

**비표본오차**는 표본 추출 외의 원인으로 발생하는 오차다.

예를 들어 설문 응답자가 거짓으로 답하거나, 조사자가 잘못 기록하거나, 데이터 입력 오류가 발생하는 경우다.

```markdown id="bxxyb1"
비표본오차 = 표본 추출 이외의 원인으로 발생하는 오차
```

| 원인     | 설명                  |
| ------ | ------------------- |
| 측정 오류  | 잘못된 측정 도구 사용        |
| 응답 오류  | 응답자가 거짓 또는 부정확하게 응답 |
| 무응답 오류 | 응답하지 않은 사람 때문에 발생   |
| 입력 오류  | 데이터 입력 과정에서 실수      |
| 조사자 오류 | 조사 방식이나 질문 방식의 문제   |

---

## 표본오차와 비표본오차 비교

| 구분    | 표본오차               | 비표본오차                   |
| ----- | ------------------ | ----------------------- |
| 원인    | 표본만 조사하기 때문에 발생    | 조사, 측정, 응답, 입력 과정에서 발생  |
| 발생 상황 | 표본조사에서 발생          | 전수조사와 표본조사 모두 발생 가능     |
| 감소 방법 | 표본 크기 증가, 적절한 표본추출 | 조사 설계 개선, 교육, 검증, 품질 관리 |
| 예시    | 표본 평균과 모집단 평균 차이   | 응답 오류, 입력 오류, 무응답 오류    |

시험에서는 이렇게 기억하면 된다.

```markdown id="e1wnl0"
표본오차는 표본을 뽑았기 때문에 생기는 오차이고,
비표본오차는 조사나 측정 과정에서 생기는 오차이다.
```

# 시험 직전 암기 문장

```markdown id="gva6kg"
통계학은 데이터를 수집, 정리, 분석, 해석하여
의사결정에 필요한 정보를 도출하는 학문이다.

통계학은 크게 기술통계와 추론통계로 구분된다.

기술통계는 수집된 데이터를 평균, 중앙값, 표준편차, 그래프 등으로 요약하고 설명하는 통계이다.

추론통계는 표본 데이터를 이용해 모집단의 특성을 추정하거나 가설을 검정하는 통계이다.

모집단은 분석 대상이 되는 전체 집단이고,
표본은 모집단에서 추출한 일부 데이터이다.

모수는 모집단의 특성을 나타내는 값이고,
통계량은 표본에서 계산한 특성값이다.

전수조사는 모집단 전체를 조사하는 것이고,
표본조사는 모집단 일부를 조사하는 것이다.

질적 자료는 성별, 혈액형, 지역처럼 범주나 속성을 나타내는 자료이고,
양적 자료는 키, 몸무게, 매출처럼 숫자로 크기나 양을 나타내는 자료이다.

이산형 자료는 고객 수, 방문 횟수처럼 셀 수 있는 값이고,
연속형 자료는 키, 시간, 온도처럼 연속적인 범위에서 측정되는 값이다.

명목척도는 성별이나 혈액형처럼 단순 분류를 위한 척도이고,
순서척도는 만족도나 등급처럼 순서가 있는 척도이다.

등간척도는 섭씨온도나 IQ처럼 간격은 일정하지만 절대적 0이 없는 척도이고,
비율척도는 키, 몸무게, 매출처럼 절대적 0이 있어 배수 비교가 가능한 척도이다.

확률표본추출은 각 대상이 표본으로 선택될 확률을 알 수 있는 방법이고,
비확률표본추출은 각 대상이 표본으로 선택될 확률을 알 수 없는 방법이다.

단순무작위추출은 모든 대상이 같은 확률로 선택되는 방법이고,
계통추출은 일정한 간격으로 표본을 선택하는 방법이다.

층화추출은 모집단을 층으로 나눈 뒤 각 층에서 표본을 추출하는 방법이고,
군집추출은 모집단을 군집으로 나눈 뒤 일부 군집을 선택하여 조사하는 방법이다.

편의추출은 조사하기 쉬운 대상을 선택하는 방법이고,
판단추출은 조사자의 판단으로 적합한 대상을 선택하는 방법이다.

할당추출은 집단별 표본 수를 미리 정해놓고 조사하는 방법이며,
눈덩이추출은 조사 대상자가 다른 대상자를 소개하며 표본을 늘리는 방법이다.

표본오차는 모집단 전체가 아니라 표본을 사용하기 때문에 발생하는 오차이고,
비표본오차는 조사, 측정, 응답, 입력 과정에서 발생하는 오차이다.
```
