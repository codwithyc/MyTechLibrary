# 고속 LAN 및 광대역 기술

## 4-1 고속 이더넷(Fast Ethernet)

고속 이더넷은 기존 이더넷의 전송 속도를 높인 LAN 기술입니다.
기존 10Mbps 이더넷보다 빠른 **100Mbps 전송 속도**를 제공하며, 기존 이더넷과 호환성이 좋아 널리 사용되었습니다.

1. 고속 이더넷의 특징

   * IEEE 802.3u 표준을 사용합니다.
   * 전송 속도는 100Mbps입니다.
   * 기존 이더넷과 동일하게 CSMA/CD 방식을 기반으로 합니다.
   * 기존 이더넷보다 빠른 속도를 제공하면서도 구축 비용이 비교적 낮습니다.

| 구분    | 내용                        |
| ----- | ------------------------- |
| 표준    | IEEE 802.3u               |
| 전송 속도 | 100Mbps                   |
| 접근 방식 | CSMA/CD                   |
| 특징    | 기존 이더넷과 호환성이 좋고 구축 비용이 낮음 |
| 주요 종류 | 100BASE-TX, 100BASE-FX    |

#### 주요 종류

| 종류         | 전송 매체   | 특징                |
| ---------- | ------- | ----------------- |
| 100BASE-TX | UTP 케이블 | 가장 일반적인 고속 이더넷 방식 |
| 100BASE-FX | 광섬유 케이블 | 장거리 전송에 적합        |

#### 한 줄 정리

```text
Fast Ethernet = 100Mbps 이더넷
```

## 4-2 기가비트 이더넷(Gigabit Ethernet)

기가비트 이더넷은 기존 이더넷을 1Gbps 속도로 확장한 LAN 기술입니다.
고속 LAN 환경, 서버 연결, 백본망 등에 주로 사용됩니다.

1. 기가비트 이더넷의 특징

   * 전송 속도는 1Gbps입니다.
   * 기존 이더넷 프레임 형식을 유지합니다.
   * 고속 데이터 전송이 필요한 서버, 스위치, 백본망 연결에 적합합니다.
   * 대표 표준으로 IEEE 802.3z와 IEEE 802.3ab가 있습니다.

| 구분    | 내용                                   |
| ----- | ------------------------------------ |
| 표준    | IEEE 802.3z, IEEE 802.3ab            |
| 전송 속도 | 1Gbps                                |
| 특징    | 기존 이더넷 구조를 유지하면서 속도를 1Gbps로 확장       |
| 활용    | 서버 연결, 스위치 간 연결, 백본망                 |
| 주요 종류 | 1000BASE-SX, 1000BASE-LX, 1000BASE-T |

#### 주요 종류

| 종류          | 전송 매체   | 특징               |
| ----------- | ------- | ---------------- |
| 1000BASE-SX | 광섬유     | 단거리 광섬유 전송       |
| 1000BASE-LX | 광섬유     | 장거리 광섬유 전송       |
| 1000BASE-T  | UTP 케이블 | 일반적인 기가비트 이더넷 방식 |

#### 한 줄 정리

```text
Gigabit Ethernet = 1Gbps 이더넷
```

## 4-3 토큰링(Token Ring)

토큰링은 링 형태의 네트워크에서 **토큰(Token)을 가진 장비만 데이터를 전송**할 수 있는 LAN 기술입니다.
토큰을 순서대로 전달하기 때문에 충돌이 발생하지 않는다는 특징이 있습니다.

1. 토큰링의 특징

   * IEEE 802.5 표준을 사용합니다.
   * 토큰 패싱(Token Passing) 방식을 사용합니다.
   * 토큰을 가진 장비만 데이터를 전송할 수 있습니다.
   * 충돌은 발생하지 않지만, 구조가 복잡하고 현재는 거의 사용되지 않습니다.

| 구분    | 내용                              |
| ----- | ------------------------------- |
| 표준    | IEEE 802.5                      |
| 구조    | 링형 구조                           |
| 접근 방식 | 토큰 패싱(Token Passing)            |
| 전송 속도 | 주로 4Mbps, 16Mbps                |
| 특징    | 충돌이 없지만 구조가 복잡하고 현재는 거의 사용하지 않음 |

#### 한 줄 정리

```text
Token Ring = 토큰을 가진 장비만 전송 가능
```

## 4-4 FDDI

FDDI는 광섬유를 이용한 고속 LAN 기술입니다.
이중 링 구조를 사용하여 장애가 발생해도 보조 링을 통해 통신을 유지할 수 있습니다.

1. FDDI의 특징

   * Fiber Distributed Data Interface의 약자입니다.
   * 광섬유 기반의 100Mbps 고속 LAN 기술입니다.
   * 이중 링 구조를 사용합니다.
   * 토큰 패싱 방식을 사용합니다.
   * 장애 발생 시 보조 링을 사용하여 안정성을 높입니다.

| 구분    | 내용                               |
| ----- | -------------------------------- |
| 전체 이름 | Fiber Distributed Data Interface |
| 전송 매체 | 광섬유                              |
| 전송 속도 | 100Mbps                          |
| 구조    | 이중 링 구조                          |
| 접근 방식 | 토큰 패싱                            |
| 특징    | 안정성이 높고 과거 백본망, 캠퍼스망 등에 사용       |

#### 한 줄 정리

```text
FDDI = 광섬유 기반 100Mbps 이중 링 네트워크
```

## 4-5 X.25와 프레임 릴레이

X.25와 프레임 릴레이는 광역 통신망에서 사용된 패킷 교환 방식의 통신 기술입니다.
둘 다 데이터를 패킷 단위로 전송하지만, **X.25는 신뢰성**, **프레임 릴레이는 속도**에 더 초점을 둡니다.

### X.25

X.25는 오류가 많은 회선 환경에서도 안정적인 통신을 제공하기 위해 만들어진 패킷 교환 기술입니다.

1. X.25의 특징

   * 패킷 교환 방식의 WAN 기술입니다.
   * 물리 계층, 데이터 링크 계층, 네트워크 계층을 포함합니다.
   * 오류 제어와 흐름 제어 기능이 강합니다.
   * 신뢰성은 높지만 속도가 느립니다.

### 프레임 릴레이(Frame Relay)

프레임 릴레이는 X.25의 복잡한 오류 제어 기능을 단순화하여 더 빠른 전송을 가능하게 한 기술입니다.

1. 프레임 릴레이의 특징

   * X.25보다 단순화된 고속 패킷 교환 기술입니다.
   * 주로 데이터 링크 계층에서 동작합니다.
   * 오류 제어를 단순화하여 속도를 높였습니다.
   * 품질이 좋은 디지털 회선 환경에서 사용하기 적합합니다.

| 구분    | X.25                | 프레임 릴레이                |
| ----- | ------------------- | ---------------------- |
| 의미    | 패킷 교환 방식의 WAN 기술    | X.25를 단순화한 고속 패킷 교환 기술 |
| 계층    | 물리, 데이터 링크, 네트워크 계층 | 주로 데이터 링크 계층           |
| 오류 제어 | 강함                  | 단순화                    |
| 전송 속도 | 비교적 느림              | 비교적 빠름                 |
| 핵심 특징 | 신뢰성 중심              | 속도 중심                  |
| 사용 환경 | 품질이 낮은 회선 환경        | 품질이 좋은 디지털 회선 환경       |

#### 한 줄 정리

```text
X.25 = 신뢰성 중심, 느림
프레임 릴레이 = 속도 중심, 빠름
```

## 4-6 HDLC(High-Level Data Link Control)

HDLC는 데이터 링크 계층에서 사용하는 **비트 지향형 전송 제어 프로토콜**입니다.
데이터를 프레임 단위로 전송하며, 흐름 제어와 오류 제어 기능을 제공합니다.

1. HDLC의 특징

   * High-Level Data Link Control의 약자입니다.
   * 데이터 링크 계층에서 동작합니다.
   * 비트 지향형 프로토콜입니다.
   * 프레임 단위로 데이터를 전송합니다.
   * 오류 제어와 흐름 제어 기능을 제공합니다.
   * 동기식 전송 방식을 사용합니다.

| 구분    | 내용                           |
| ----- | ---------------------------- |
| 전체 이름 | High-Level Data Link Control |
| 계층    | 데이터 링크 계층                    |
| 방식    | 비트 지향형 프로토콜                  |
| 전송 단위 | 프레임                          |
| 전송 방식 | 동기식 전송                       |
| 기능    | 오류 제어, 흐름 제어                 |
| 활용    | 전용 회선, WAN 환경                |

#### HDLC 프레임 종류

| 프레임 종류  | 의미                | 역할             |
| ------- | ----------------- | -------------- |
| I-Frame | Information Frame | 실제 데이터 전송      |
| S-Frame | Supervisory Frame | 흐름 제어와 오류 제어   |
| U-Frame | Unnumbered Frame  | 링크 설정, 해제 등 제어 |

#### 한 줄 정리

```text
HDLC = 데이터 링크 계층의 비트 지향형 전송 제어 프로토콜
```

## 4-7 셀 릴레이 ATM(Asynchronous Transfer Mode)

ATM은 데이터를 고정 길이의 셀(Cell) 단위로 나누어 전송하는 고속 통신 기술입니다.
음성, 영상, 데이터 등 다양한 트래픽을 하나의 네트워크에서 통합 전송할 수 있습니다.

1. ATM의 특징

   * Asynchronous Transfer Mode의 약자입니다.
   * 데이터를 고정 길이의 셀 단위로 전송합니다.
   * 셀의 크기는 53바이트입니다.
   * 음성, 영상, 데이터 통신을 통합 전송할 수 있습니다.
   * QoS를 지원하여 서비스 품질 관리가 가능합니다.
   * 구조가 복잡하고 셀 헤더로 인한 오버헤드가 존재합니다.

| 구분    | 내용                         |
| ----- | -------------------------- |
| 전체 이름 | Asynchronous Transfer Mode |
| 전송 방식 | 셀 릴레이                      |
| 전송 단위 | 셀(Cell)                    |
| 셀 크기  | 53바이트                      |
| 셀 구성  | 헤더 5바이트 + 데이터 48바이트        |
| 특징    | 음성, 영상, 데이터 통합 전송 가능       |
| 장점    | 고속 전송, QoS 지원              |
| 단점    | 구조가 복잡하고 오버헤드 존재           |

#### 한 줄 정리

```text
ATM = 53바이트 고정 길이 셀을 사용하는 고속 통신 기술
```

| 기술               | 핵심 의미                | 주요 특징                   |

| Fast Ethernet    | 100Mbps 이더넷          | IEEE 802.3u, 기존 이더넷 고속화 |
| Gigabit Ethernet | 1Gbps 이더넷            | 서버, 백본망, 고속 LAN에 사용     |
| Token Ring       | 토큰 기반 링 네트워크         | 토큰을 가진 장비만 전송, 충돌 없음    |
| FDDI             | 광섬유 기반 이중 링 네트워크     | 100Mbps, 안정성 높음         |
| X.25             | 패킷 교환 WAN 기술         | 신뢰성 높지만 느림              |
| Frame Relay      | 고속 패킷 교환 기술          | X.25보다 단순하고 빠름          |
| HDLC             | 데이터 링크 계층 전송 제어 프로토콜 | 비트 지향, 오류 제어, 흐름 제어     |
| ATM              | 셀 릴레이 기반 고속 통신       | 53바이트 고정 셀, QoS 지원      |
