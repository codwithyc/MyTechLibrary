## 005. 작업 표시줄

### 1. 작업 표시줄(Task Bar)의 개요

작업 표시줄은 화면 아래쪽에 위치하며, **현재 실행 중인 프로그램을 아이콘으로 표시**하는 막대입니다.

- 기본 위치는 화면 아래쪽이지만, **위·아래·좌·우 네 방향 어디로든 이동**할 수 있습니다.
- 작업 표시줄의 크기는 **화면의 1/2까지** 늘릴 수 있습니다.
- 작업 표시줄이 **잠금 상태이면 크기 조절과 위치 이동이 불가능**합니다.

#### 왜 작업 표시줄이 필요할까?

여러 프로그램을 동시에 실행하면 창이 서로 겹쳐서 어떤 프로그램이 실행 중인지 알기 어렵습니다.

작업 표시줄은 **실행 중인 프로그램을 한 줄로 모아 보여 주므로**,  
창이 가려져 있어도 무엇이 실행 중인지 확인하고 바로 전환할 수 있습니다.

즉, 작업 표시줄은  
**실행 중인 작업을 한눈에 파악하고 전환하기 위한 공간**입니다.

---

### 2. 작업 표시줄의 구성 요소

| 구성 요소 | 기능 |
| --- | --- |
| 시작 단추 | [시작] 메뉴를 표시합니다. |
| 검색 상자 | 앱, 파일, 웹 등을 검색합니다. |
| 작업 보기 단추 | 실행 중인 앱을 미리 보고, 가상 데스크톱을 관리합니다. |
| 프로그램 단추 표시 영역 | 실행 중인 프로그램과 고정된 프로그램의 아이콘이 표시됩니다. |
| 알림 영역(시스템 트레이) | 시계, 볼륨, 네트워크, 백신 등 상주 프로그램의 아이콘이 표시됩니다. |
| 알림 센터 | 시스템과 앱의 알림을 모아서 보여 줍니다. |
| 바탕 화면 보기 단추 | 작업 표시줄 오른쪽 맨 끝에 위치하며, 클릭하면 모든 창이 최소화되어 바탕 화면이 표시됩니다. |

#### 왜 알림 영역을 따로 두었을까?

백신 프로그램이나 메신저처럼 **계속 실행되어 있지만 화면을 차지할 필요는 없는 프로그램**이 있습니다.

이런 프로그램까지 모두 작업 표시줄에 큰 단추로 표시하면 공간이 부족해집니다.  
그래서 상주 프로그램은 작은 아이콘 형태로 알림 영역에 모아 둡니다.

---

### 3. 작업 표시줄 설정

작업 표시줄의 바로 가기 메뉴에서 [작업 표시줄 설정]을 선택하면 다음 항목을 설정할 수 있습니다.

| 항목 | 설명 |
| --- | --- |
| 작업 표시줄 잠금 | 위치와 크기를 변경하지 못하도록 고정합니다. |
| 데스크톱 모드에서 작업 표시줄 자동 숨기기 | 평소에는 숨겨져 있다가 마우스를 가져가면 나타납니다. |
| 작은 작업 표시줄 단추 사용 | 아이콘을 작게 표시하여 더 많은 항목을 배치합니다. |
| 화면에서의 작업 표시줄 위치 | 위쪽 / 아래쪽 / 왼쪽 / 오른쪽 중 선택합니다. |
| 작업 표시줄 단추 하나로 표시 | 같은 프로그램의 여러 창을 하나의 단추로 묶어서 표시합니다. |
| 알림 영역 | 표시할 아이콘과 시스템 아이콘을 선택합니다. |

#### 왜 작업 표시줄을 자동으로 숨길까?

작업 표시줄은 항상 화면의 일부를 차지합니다.  
문서 작업이나 영상 시청처럼 **화면을 넓게 쓰고 싶은 상황**에서는 이 공간이 아깝습니다.

자동 숨기기는 필요할 때만 나타나게 하여 **작업 영역을 최대한 확보**하는 기능입니다.

---

### 4. 점프 목록(Jump List)

작업 표시줄의 프로그램 아이콘을 **마우스 오른쪽 단추로 클릭**하면 나타나는 메뉴입니다.

- 해당 프로그램에서 **최근에 사용한 파일 목록**이 표시됩니다.
- 자주 사용하는 항목은 **고정(핀)** 하여 목록 위쪽에 계속 유지할 수 있습니다.

#### 왜 점프 목록이 유용할까?

같은 프로그램이라도 실제로 다시 여는 파일은 대부분 최근에 작업하던 것입니다.

점프 목록은 프로그램을 먼저 실행한 뒤 파일을 찾는 두 단계를,  
**"프로그램 아이콘에서 바로 파일 열기"** 한 단계로 줄여 줍니다.

---

### 5. 창 정렬

작업 표시줄의 빈 공간에서 마우스 오른쪽 단추를 클릭하면 열려 있는 창을 정렬할 수 있습니다.

| 정렬 방식 | 설명 |
| --- | --- |
| 계단식 창 배열 | 창의 제목 표시줄이 보이도록 계단 모양으로 겹쳐서 배열합니다. |
| 창 가로 정렬 보기 | 창을 위아래로 나누어 배열합니다. |
| 창 세로 정렬 보기 | 창을 좌우로 나누어 배열합니다. |
| 바탕 화면 보기 | 열려 있는 모든 창을 최소화합니다. |

---

### 한 줄 정리

작업 표시줄은 **실행 중인 프로그램을 표시하고 전환하는 영역**으로,  
화면의 네 방향으로 이동할 수 있고 **최대 화면의 1/2까지 크기를 조절**할 수 있으며,  
**잠금 상태에서는 이동과 크기 조절이 불가능**합니다.
