## 043. 출력장치

### 1. 출력장치의 개요

출력장치는 컴퓨터가 처리한 결과를 **사람이 알아볼 수 있는 형태로 표현**하는 장치입니다.

- 대표적인 출력장치 : 모니터, 프린터, 스피커, 플로터, 프로젝터

---

### 2. 모니터

**모니터의 종류**

| 종류 | 특징 |
| --- | --- |
| CRT | 음극선관을 이용하며 부피가 크고 전력 소모가 많습니다. (현재는 거의 사용하지 않음) |
| **LCD** | 액정을 이용하며 얇고 전력 소모가 적지만, 보는 각도에 따라 화면이 달라 보일 수 있습니다. |
| **LED** | LCD의 백라이트를 LED로 바꾼 방식으로, 더 얇고 밝으며 전력 소모가 적습니다. |
| **PDP** | 플라즈마를 이용하며 화면이 크고 반응 속도가 빠르지만 전력 소모와 발열이 큽니다. |
| OLED | 화소가 스스로 빛을 내므로 백라이트가 필요 없고, 명암비가 뛰어납니다. |

**모니터 관련 용어**

| 용어 | 설명 |
| --- | --- |
| **픽셀(Pixel, 화소)** | 화면을 구성하는 **가장 작은 단위의 점**입니다. |
| **해상도(Resolution)** | 화면에 표시할 수 있는 **픽셀의 수**입니다. (예: 1920 × 1080) 값이 클수록 선명합니다. |
| **점 간격(Dot Pitch)** | 픽셀 사이의 거리로, **값이 작을수록 선명**합니다. |
| **재생률(Refresh Rate)** | 1초에 화면을 다시 그리는 횟수(Hz)로, **값이 클수록 화면 떨림이 적습니다.** |
| **화면 크기** | 화면의 **대각선 길이**를 인치(inch)로 나타냅니다. |
| 응답 속도 | 픽셀의 색이 바뀌는 데 걸리는 시간(ms)으로, 값이 작을수록 잔상이 적습니다. |

#### 왜 해상도가 높으면 글자가 작아 보일까?

해상도는 화면의 **물리적 크기가 아니라 점의 개수**를 나타냅니다.

같은 크기의 화면에 점이 더 많아지면, 점 하나의 크기가 작아지므로  
글자도 함께 작아 보이고, 대신 **한 화면에 더 많은 내용**이 들어갑니다.

#### 왜 점 간격은 작을수록 좋을까?

점 간격은 픽셀과 픽셀 사이의 거리입니다.

간격이 넓으면 점 사이의 빈틈이 보여 **화면이 거칠게** 느껴집니다.  
간격이 좁을수록 점들이 촘촘히 붙어 **매끄럽고 선명한 화면**이 됩니다.

이처럼 모니터 관련 수치는

- **해상도·재생률** : 클수록 좋음
- **점 간격·응답 속도** : 작을수록 좋음

으로 방향이 반대라는 점에 주의해야 합니다.

### 3. 프린터

| 종류 | 방식 | 특징 |
| --- | --- | --- |
| **도트 매트릭스 프린터** | 핀으로 잉크 리본을 때려 인쇄 | 소음이 크고 인쇄 품질이 낮지만, **먹지를 이용한 복사 인쇄가 가능**합니다. 속도 단위는 **CPS**. |
| **잉크젯 프린터** | 노즐에서 잉크를 분사 | 가격이 저렴하고 컬러 인쇄에 유리하지만, 번짐이 생길 수 있습니다. 속도 단위는 **PPM**. |
| **레이저 프린터** | 레이저로 드럼에 상을 만들고 토너를 묻혀 인쇄 | 속도가 빠르고 인쇄 품질이 높으며 소음이 적습니다. 속도 단위는 **PPM**. |

**프린터 관련 단위**

| 단위 | 의미 |
| --- | --- |
| **DPI(Dots Per Inch)** | 1인치당 인쇄되는 점의 수 = **해상도** (클수록 선명) |
| **CPS(Characters Per Second)** | 1초에 인쇄되는 문자 수 |
| **LPM(Lines Per Minute)** | 1분에 인쇄되는 줄 수 |
| **PPM(Pages Per Minute)** | 1분에 인쇄되는 페이지 수 |

#### 왜 프린터마다 속도 단위가 다를까?

프린터가 **한 번에 처리하는 단위**가 다르기 때문입니다.

- 도트 매트릭스 : 글자를 하나씩 찍음 → **문자 단위(CPS)**
- 라인 프린터 : 한 줄씩 찍음 → **줄 단위(LPM)**
- 잉크젯·레이저 : 한 페이지를 통째로 처리 → **페이지 단위(PPM)**

즉, 속도 단위만 봐도 그 프린터의 **인쇄 방식**을 짐작할 수 있습니다.

### 4. 그 밖의 출력장치

| 장치 | 설명 |
| --- | --- |
| 플로터(Plotter) | 펜을 이용해 도면이나 대형 그래픽을 정밀하게 출력합니다. 설계도, 지도 출력에 사용합니다. |
| 프로젝터(Projector) | 화면을 스크린에 확대 투사합니다. |
| 스피커 | 소리를 출력합니다. |
| 3D 프린터 | 입체적인 물체를 실제로 만들어 냅니다. |

---

### 5. 입력장치(참고)

출력장치와 비교하여 함께 정리해 두면 좋습니다.

| 장치 | 설명 |
| --- | --- |
| 키보드 / 마우스 | 가장 기본적인 입력장치입니다. |
| **스캐너** | 그림이나 문서를 읽어 디지털 이미지로 변환합니다. 해상도 단위는 **DPI**. |
| **OMR**(광학 마크 판독기) | 연필로 칠한 표시를 읽습니다. (OMR 카드, 시험 답안지) |
| **OCR**(광학 문자 판독기) | 인쇄된 문자를 읽어 텍스트로 변환합니다. (공과금 고지서) |
| **MICR**(자기 잉크 문자 판독기) | 자성 잉크로 인쇄된 문자를 읽습니다. (수표, 어음) |
| **BCR**(바코드 판독기) | 바코드를 읽습니다. (상품 계산) |
| 디지타이저 / 태블릿 | 도면이나 그림을 좌표 형태로 입력합니다. |
| 터치스크린 | 화면을 직접 눌러 입력합니다. (입력과 출력을 동시에 수행) |

#### 왜 수표에는 MICR을 사용할까?

수표는 위조 위험이 매우 큰 문서입니다.

MICR은 **자성을 띤 특수 잉크**로 인쇄되어,  
글자를 복사하거나 인쇄해도 **자성까지는 흉내 낼 수 없습니다.**

또한 얼룩이나 도장이 겹쳐도 자기 신호로 읽을 수 있어 **인식률이 매우 높습니다.**

---

### 한 줄 정리

모니터는 **해상도·재생률은 클수록, 점 간격·응답 속도는 작을수록 좋으며 화면 크기는 대각선 길이**로 나타내고,  
프린터의 해상도 단위는 **DPI**, 속도 단위는 인쇄 방식에 따라 **CPS / LPM / PPM** 으로 구분합니다.
