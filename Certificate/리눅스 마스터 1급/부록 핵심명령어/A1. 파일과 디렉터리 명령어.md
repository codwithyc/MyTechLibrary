### 1. 이동과 조회

#### `pwd` / `cd`

```bash
$ pwd                      # 현재 위치 출력
/home/masterway

$ cd /etc                  # 절대 경로
$ cd ..                    # 상위 디렉터리
$ cd ~                     # 홈 디렉터리
$ cd                       # 홈 (인자 생략)
$ cd -                     # ⭐ 직전 디렉터리로 이동
$ cd ~user                 # 특정 사용자의 홈
```

#### `ls` — 목록 조회

```bash
$ ls                       # 기본
$ ls -l                    # 상세 (long)
$ ls -a                    # 숨김 파일 포함
$ ls -al                   # 조합 ⭐
$ ls -lh                   # 사람이 읽기 쉬운 크기 ⭐
$ ls -lt                   # 수정 시각순 (최신 먼저) ⭐
$ ls -ltr                  # 시각 역순 (오래된 것 먼저) ⭐
$ ls -lS                   # 크기순
$ ls -lR                   # 하위 디렉터리까지 재귀
$ ls -ld /etc              # ⭐ 디렉터리 자체의 정보 (내용 아님)
$ ls -li                   # inode 번호 표시 ⭐
$ ls -lZ                   # SELinux 컨텍스트 ⭐
$ ls -l --time=atime       # 접근 시각 기준
```

| 옵션 | 의미 |
| --- | --- |
| **`-l`** | 상세 정보 |
| **`-a`** | 숨김 파일 포함 |
| **`-h`** | 읽기 쉬운 단위 (K/M/G) |
| **`-d`** | **디렉터리 자체** |
| **`-t`** | 수정 시각순 |
| `-r` | 역순 |
| **`-i`** | inode 번호 |
| **`-Z`** | SELinux 컨텍스트 |
| `-R` | 재귀 |

**`ls -l` 출력 읽기**

```
-rw-r--r--. 1 masterway developers 4096 Feb  9 06:00 report.txt
│└─┬┘└┬┘└┬┘  │     │         │       │        │          │
│  u  g  o   │  소유자      그룹    크기    수정시각    파일명
│            └── 하드 링크 수
└── 파일 종류 (- d l b c s p)
```

### 2. 생성·복사·이동·삭제

```bash
# 파일 생성
$ touch file.txt                  # 빈 파일 생성 / 타임스탬프 갱신
$ touch -t 202602090600 file.txt  # 시각 지정

# 디렉터리 생성
$ mkdir dir
$ mkdir -p a/b/c                  # ⭐ 상위 디렉터리까지 한 번에
$ mkdir -m 750 secure             # 권한 지정
$ mkdir -p project/{src,test,doc} # ⭐ 여러 개 한 번에

# 복사
$ cp file.txt backup.txt
$ cp -r dir/ backup/              # ⭐ 디렉터리 (재귀)
$ cp -p file.txt backup.txt       # ⭐ 권한·시각 보존
$ cp -a dir/ backup/              # ⭐ 아카이브 모드 (-dpR)
$ cp -i file.txt dest.txt         # 덮어쓰기 전 확인
$ cp -u src.txt dest.txt          # 원본이 더 새것일 때만
$ cp -v file.txt dest.txt         # 진행 표시

# 이동·이름 변경
$ mv old.txt new.txt              # 이름 변경
$ mv file.txt /tmp/               # 이동
$ mv -i file.txt /tmp/            # 확인
$ mv -n file.txt /tmp/            # 덮어쓰지 않음

# 삭제
$ rm file.txt
$ rm -f file.txt                  # 강제 (확인 없음)
$ rm -r dir/                      # ⭐ 디렉터리
$ rm -rf dir/                     # 강제 재귀 ❗주의
$ rm -i *.txt                     # 하나씩 확인
$ rmdir emptydir                  # 빈 디렉터리만 삭제
```

| 옵션 | 의미 |
| --- | --- |
| **`-r` / `-R`** | **재귀 (디렉터리)** |
| **`-p`** | **권한·타임스탬프 보존** (cp) / **상위 경로 생성** (mkdir) |
| **`-a`** | 아카이브 모드 (cp) |
| `-i` | 확인 후 실행 |
| `-f` | 강제 |
| `-v` | 상세 출력 |
| `-u` | 더 새로울 때만 |

> **⚠️ `rm -rf`는 되돌릴 수 없습니다.**  
> 실행 전 반드시 경로를 확인하세요. 특히 변수를 쓸 때 위험합니다.
> ```bash
> $ rm -rf "$DIR"/          # $DIR가 비어 있으면 rm -rf / 가 됨 ❗
> $ rm -rf "${DIR:?}"/      # ✅ 변수가 비면 오류로 중단
> ```
>
> **안전장치** : `alias rm='rm -i'` 를 `~/.bashrc`에 추가

### 3. 파일 내용 보기

```bash
# 전체 출력
$ cat file.txt
$ cat -n file.txt            # 행 번호 ⭐
$ cat -A file.txt            # 특수문자 표시 (탭·개행)
$ cat file1 file2 > merged   # 파일 병합
$ tac file.txt               # ⭐ 역순 출력

# 페이지 단위
$ less file.txt              # ⭐ 권장 (앞뒤 이동 가능)
$ more file.txt              # 앞으로만

# 앞·뒤 일부
$ head file.txt              # 처음 10줄
$ head -n 20 file.txt        # 처음 20줄
$ head -c 100 file.txt       # 처음 100바이트

$ tail file.txt              # 마지막 10줄
$ tail -n 50 file.txt
$ tail -f /var/log/messages  # ⭐ 실시간 추적 (로그 감시)
$ tail -F /var/log/messages  # ⭐ 파일이 교체돼도 계속 추적
$ tail -n +10 file.txt       # 10번째 줄부터 끝까지
```

**`less` 사용 중 단축키**

| 키 | 기능 |
| --- | --- |
| `Space` / `b` | 다음 / 이전 페이지 |
| `/문자열` | **앞으로 검색** ⭐ |
| `?문자열` | 뒤로 검색 |
| `n` / `N` | 다음 / 이전 검색 결과 |
| `g` / `G` | 처음 / 끝으로 |
| `F` | **tail -f 처럼 실시간 추적** ⭐ |
| `q` | 종료 |

> **`tail -f`와 `tail -F`의 차이**  
> `-f` : 파일을 **inode 기준**으로 추적 → logrotate로 교체되면 **더 이상 안 보임**  
> `-F` : **파일명 기준** → 교체돼도 계속 추적 ⭐

### 4. 파일 검색 — `find`

```bash
find [경로] [조건] [동작]
```

#### 이름·종류

```bash
$ find /etc -name "*.conf"              # 이름 (대소문자 구분)
$ find /etc -iname "*.CONF"             # 대소문자 무시
$ find / -type f -name "passwd"         # 일반 파일만
$ find / -type d -name "log"            # 디렉터리만
$ find / -type l                        # 심볼릭 링크
$ find . -maxdepth 2 -name "*.log"      # 깊이 제한 ⭐
```

#### 시간

```bash
$ find /var/log -mtime +30       # ⭐ 30일보다 이전에 수정
$ find /var/log -mtime -7        # 최근 7일 이내 수정
$ find /home -atime +90          # 90일 이상 접근 안 함
$ find /tmp -mmin -60            # 최근 60분 이내 수정
$ find /etc -newer /etc/passwd   # 특정 파일보다 새것
```

| 옵션 | 기준 | 단위 |
| --- | --- | --- |
| **`-mtime`** | **내용 수정** | 일 |
| `-atime` | 접근 | 일 |
| `-ctime` | inode 변경 | 일 |
| `-mmin`/`-amin`/`-cmin` | 위와 동일 | **분** |

#### 크기

```bash
$ find /var -size +100M          # ⭐ 100MB 초과
$ find /var -size -1k            # 1KB 미만
$ find / -size +1G -type f       # 1GB 넘는 파일 (디스크 정리)
$ find . -empty                  # 빈 파일·디렉터리
```

| 단위 | 의미 |
| --- | --- |
| `c` | 바이트 |
| `k` / **`M`** / **`G`** | KB / MB / GB |
| `+` / `-` | 초과 / 미만 |

#### 권한·소유자

```bash
$ find / -perm -4000 -type f          # ⭐ SetUID (보안 점검)
$ find / -perm -2000 -type f          # SetGID
$ find / -perm -1000 -type d          # Sticky Bit
$ find / -type f -perm -o+w           # ⭐ 누구나 쓰기 가능 (위험)
$ find /home -user devuser            # 특정 사용자 소유
$ find /home -group developers        # 특정 그룹
$ find / -nouser -o -nogroup          # ⭐ 소유자 없는 파일
```

| `-perm` 형태 | 의미 |
| --- | --- |
| `-perm 644` | **정확히** 644 |
| **`-perm -644`** | 644 권한을 **모두 포함** |
| `-perm /644` | 644 중 **하나라도** 포함 |

#### 동작 실행

```bash
$ find /var/log -name "*.log" -mtime +30 -exec rm {} \;
$ find /var/log -name "*.log" -mtime +30 -exec rm {} +      # ⭐ 빠름
$ find /var/log -name "*.log" -ok rm {} \;                  # 하나씩 확인
$ find /tmp -name "*.tmp" -mtime +7 -delete                 # 삭제 전용

# 공백이 있는 파일명도 안전하게
$ find . -name "*.log" -print0 | xargs -0 rm

# 권한 일괄 수정 (실무 관용구) ⭐
$ find /var/www -type d -exec chmod 755 {} +
$ find /var/www -type f -exec chmod 644 {} +
```

> **`\;` vs `+`**  
> `\;` : 파일 **하나마다** 명령 실행 (파일 10,000개면 10,000번)  
> `+` : 여러 파일을 **한 번에** 전달 (훨씬 빠름) ⭐

#### 조건 조합

```bash
$ find /var -name "*.log" -a -size +10M          # AND (기본)
$ find /var \( -name "*.log" -o -name "*.tmp" \) # OR ⭐
$ find /var ! -name "*.log"                      # NOT
$ find / -path "/proc" -prune -o -name "*.conf" -print   # 제외 ⭐
```

### 5. 빠른 검색 — `locate`, `which`, `whereis`

```bash
$ locate passwd                  # DB에서 검색 (매우 빠름) ⭐
$ locate -i PASSWD               # 대소문자 무시
$ locate -n 10 conf              # 결과 개수 제한
$ sudo updatedb                  # ⭐ DB 갱신

$ which ls                       # PATH에서 실행 파일 위치 ⭐
/usr/bin/ls
$ which -a python                # 모든 경로

$ whereis passwd                 # 실행 파일 + 소스 + 매뉴얼
$ type cd                        # ⭐ 내부/외부 명령어 구분
cd is a shell builtin
```

| 명령어 | 특징 |
| --- | --- |
| **`find`** | 실시간 검색 — **느리지만 정확** |
| **`locate`** | DB 조회 — **빠르지만 최신 파일 누락** |
| **`which`** | PATH 상의 실행 파일 |
| `whereis` | 실행·소스·매뉴얼 |
| **`type`** | 내부 명령어 여부 |

### 6. 텍스트 검색 — `grep`

```bash
$ grep "error" file.log
$ grep -i "error" file.log         # ⭐ 대소문자 무시
$ grep -v "info" file.log          # ⭐ 일치하지 않는 줄 (제외)
$ grep -n "error" file.log         # ⭐ 행 번호 표시
$ grep -c "error" file.log         # ⭐ 개수만
$ grep -l "error" *.log            # 파일명만
$ grep -r "TODO" /src              # ⭐ 재귀 검색
$ grep -w "cat" file.txt           # ⭐ 단어 단위 (category 제외)
$ grep -A 3 "error" file.log       # 일치 줄 + 뒤 3줄 ⭐
$ grep -B 3 "error" file.log       # 앞 3줄
$ grep -C 3 "error" file.log       # 앞뒤 3줄 ⭐
$ grep -E "error|warn" file.log    # ⭐ 확장 정규식 (= egrep)
$ grep -o "[0-9]\+" file.txt       # 일치 부분만 출력
$ grep -q "error" file.log         # 조용히 (스크립트 조건용)
```

| 옵션 | 의미 |
| --- | --- |
| **`-i`** | 대소문자 무시 |
| **`-v`** | **반대 (제외)** |
| **`-n`** | 행 번호 |
| **`-c`** | 개수 |
| **`-r`** | 재귀 |
| **`-w`** | 단어 단위 |
| **`-E`** | 확장 정규식 |
| **`-A`/`-B`/`-C`** | 뒤/앞/앞뒤 문맥 |
| `-l` | 파일명만 |
| `-q` | 출력 없이 종료 코드만 |

#### 정규식 기본

| 기호 | 의미 |
| --- | --- |
| `^` | 줄의 시작 |
| `$` | 줄의 끝 |
| `.` | 임의의 한 문자 |
| `*` | 앞 문자 0회 이상 |
| `[]` | 문자 집합 |
| `[^]` | 제외 |
| `\|` | OR (확장) |
| `+` | 1회 이상 (확장) |
| `?` | 0 또는 1회 (확장) |

```bash
$ grep "^root" /etc/passwd         # root로 시작하는 줄 ⭐
$ grep "bash$" /etc/passwd         # bash로 끝나는 줄 ⭐
$ grep "^$" file.txt               # 빈 줄
$ grep -v "^#" /etc/ssh/sshd_config | grep -v "^$"   # ⭐ 주석·빈줄 제외
$ grep -E "^[0-9]{3}-[0-9]{4}$" file.txt
```

> **설정 파일에서 실제 설정만 보는 관용구** ⭐
> ```bash
> $ grep -vE "^#|^$" /etc/httpd/conf/httpd.conf
> ```

### 7. 텍스트 처리

#### `sort` / `uniq`

```bash
$ sort file.txt
$ sort -r file.txt              # 역순
$ sort -n file.txt              # ⭐ 숫자 정렬
$ sort -h file.txt              # 사람이 읽는 크기 (1K, 2M)
$ sort -k 2 file.txt            # ⭐ 2번째 필드 기준
$ sort -t: -k3 -n /etc/passwd   # ⭐ 구분자 : , 3번 필드 숫자순
$ sort -u file.txt              # 중복 제거

$ sort file.txt | uniq          # ⭐ 중복 제거 (정렬 필수)
$ sort file.txt | uniq -c       # ⭐ 개수와 함께
$ sort file.txt | uniq -d       # 중복된 것만
$ sort file.txt | uniq -u       # 유일한 것만
```

> **집계 관용구** (실무에서 매우 자주 사용) ⭐
> ```bash
> $ awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -10
> ```
> `uniq`는 **인접한 중복만** 제거하므로 반드시 `sort`를 먼저 해야 합니다.

#### `cut` / `paste` / `tr`

```bash
$ cut -d: -f1 /etc/passwd          # ⭐ 구분자 : , 1번 필드
$ cut -d: -f1,3 /etc/passwd        # 1,3번 필드
$ cut -c1-10 file.txt              # 1~10번째 문자
$ cut -d, -f2- data.csv            # 2번째부터 끝까지

$ paste file1 file2                # 파일을 열로 병합

$ tr 'a-z' 'A-Z' < file.txt        # ⭐ 소문자→대문자
$ tr -d ' ' < file.txt             # 공백 삭제
$ tr -s ' ' < file.txt             # 연속 공백을 하나로 ⭐
$ tr '\n' ' ' < file.txt           # 개행을 공백으로
```

#### `wc`

```bash
$ wc file.txt
  10   50  300 file.txt
  줄   단어  바이트

$ wc -l file.txt      # ⭐ 줄 수
$ wc -w file.txt      # 단어 수
$ wc -c file.txt      # 바이트 수
$ ls | wc -l          # ⭐ 파일 개수
```

#### `sed` — 스트림 편집

```bash
$ sed 's/old/new/' file.txt          # 각 줄의 첫 번째만 치환
$ sed 's/old/new/g' file.txt         # ⭐ 전부 치환
$ sed -i 's/old/new/g' file.txt      # ⭐ 파일 직접 수정
$ sed -i.bak 's/old/new/g' file.txt  # ⭐ 백업 생성 후 수정
$ sed -n '5p' file.txt               # 5번째 줄만 출력
$ sed -n '10,20p' file.txt           # 10~20줄
$ sed '/^#/d' file.txt               # ⭐ 주석 줄 삭제
$ sed '/^$/d' file.txt               # 빈 줄 삭제
$ sed '2d' file.txt                  # 2번째 줄 삭제
$ sed 's/^/> /' file.txt             # 각 줄 앞에 추가
```

> **`sed -i`는 파일을 직접 바꿉니다.**  
> 설정 파일을 수정할 때는 반드시 **`-i.bak`으로 백업**을 남기세요. ⭐

#### `awk` — 필드 처리

```bash
$ awk '{print $1}' file.txt              # ⭐ 1번째 필드
$ awk '{print $1, $3}' file.txt          # 여러 필드
$ awk '{print NF}' file.txt              # 필드 개수
$ awk '{print NR, $0}' file.txt          # ⭐ 행 번호 + 전체
$ awk -F: '{print $1}' /etc/passwd       # ⭐ 구분자 지정
$ awk -F: '$3 >= 1000 {print $1}' /etc/passwd    # ⭐ 조건
$ awk '{sum += $1} END {print sum}' nums.txt     # ⭐ 합계
$ awk 'NR % 2 == 0' file.txt             # 짝수 줄만
$ awk 'length > 80' file.txt             # 80자 넘는 줄
```

| 변수 | 의미 |
| --- | --- |
| **`$0`** | **전체 줄** |
| **`$1`, `$2`** | **필드** |
| **`NF`** | **필드 개수** |
| **`NR`** | **행 번호** |
| `FS` / `OFS` | 입력 / 출력 구분자 |

> **실무 조합 예시** ⭐
> ```bash
> # 디스크 사용률 85% 이상 경고
> $ df -h | awk '$5+0 >= 85 {print $6, $5}'
>
> # UID 1000 이상 일반 사용자 목록
> $ awk -F: '$3>=1000 && $3<65534 {print $1}' /etc/passwd
>
> # 접속 상위 IP
> $ awk '{print $1}' access.log | sort | uniq -c | sort -rn | head
> ```

### 8. 링크

```bash
$ ln original.txt hardlink.txt        # 하드 링크
$ ln -s original.txt softlink.txt     # ⭐ 심볼릭 링크
$ ln -sf new.txt link.txt             # 기존 링크 덮어쓰기 ⭐
$ ln -sfn /opt/v2 /opt/current        # ⭐ 디렉터리 링크 갱신

$ ls -li
1234567 -rw-r--r--. 2 user user 6 ... hardlink.txt
1234567 -rw-r--r--. 2 user user 6 ... original.txt      ← 같은 inode
7654321 lrwxrwxrwx. 1 user user 12 ... softlink.txt -> original.txt

$ readlink softlink.txt               # 링크가 가리키는 대상
$ readlink -f softlink.txt            # 최종 실제 경로 ⭐
```

| 구분 | **하드 링크** | **심볼릭 링크** |
| --- | --- | --- |
| inode | **원본과 동일** | 별도 |
| 원본 삭제 시 | **사용 가능** ✅ | **깨짐** ❌ |
| 파일시스템 넘기 | **불가** | **가능** |
| 디렉터리 | **불가** | **가능** |

### 9. 압축과 아카이브

```bash
# ────────── tar ──────────
$ tar cvzf backup.tar.gz /data        # ⭐ 생성 (gzip)
$ tar cvjf backup.tar.bz2 /data       # bzip2
$ tar cvJf backup.tar.xz /data        # xz
$ tar xvzf backup.tar.gz              # ⭐ 해제
$ tar xvzf backup.tar.gz -C /restore  # ⭐ 특정 위치에 해제
$ tar tvzf backup.tar.gz              # ⭐ 목록 확인 (해제 전 필수)
$ tar cvzf backup.tar.gz --exclude="*.log" /data
$ tar xvzpf backup.tar.gz             # 권한 유지 ⭐

# ────────── 개별 압축 ──────────
$ gzip file.txt                # → file.txt.gz (원본 삭제)
$ gzip -k file.txt             # 원본 유지
$ gunzip file.txt.gz
$ zcat file.txt.gz             # ⭐ 압축 해제 없이 보기
$ zgrep "error" file.log.gz    # ⭐ 압축 파일에서 검색

$ bzip2 / bunzip2 / bzcat
$ xz / unxz / xzcat

# ────────── zip ──────────
$ zip -r archive.zip dir/      # ⭐ 재귀
$ unzip archive.zip
$ unzip -l archive.zip         # 목록
$ unzip archive.zip -d /dest   # 위치 지정
```

| tar 옵션 | 의미 |
| --- | --- |
| **`c`** | 생성 |
| **`x`** | 해제 |
| **`t`** | 목록 |
| **`v`** | 상세 |
| **`f`** | **파일명 (반드시 마지막)** ⭐ |
| **`z`/`j`/`J`** | gzip / bzip2 / xz |
| `p` | 권한 유지 |
| `-C` | 대상 디렉터리 |

> **압축률** : xz > bzip2 > gzip / **속도** : gzip > bzip2 > xz

### 10. 파일 비교와 정보

```bash
# 비교
$ diff file1 file2
$ diff -u file1 file2          # ⭐ 통합 형식 (패치용)
$ diff -r dir1 dir2            # 디렉터리 비교
$ diff -y file1 file2          # 좌우 비교
$ cmp file1 file2              # 바이너리 비교
$ comm sorted1 sorted2         # 정렬된 파일 비교

# 파일 정보
$ file /bin/ls                 # ⭐ 파일 종류 판별
$ stat file.txt                # ⭐ 상세 정보 (inode, 타임스탬프)
$ du -sh dir/                  # ⭐ 디렉터리 크기
$ du -h --max-depth=1 /var | sort -rh | head    # ⭐ 큰 것부터
$ df -hT                       # ⭐ 파일시스템 사용량

# 체크섬
$ md5sum file.txt
$ sha256sum file.txt           # ⭐ 무결성 검증
$ sha256sum -c checksums.txt
```

### 11. 권한 관리

```bash
# 권한 변경
$ chmod 755 script.sh          # ⭐ 숫자 방식
$ chmod u+x script.sh          # 기호 방식
$ chmod -R 755 dir/            # 재귀
$ chmod a+r file.txt           # 모두에게 읽기
$ chmod go-w file.txt          # 그룹·기타 쓰기 제거

# 특수 권한
$ chmod 4755 file              # ⭐ SetUID
$ chmod 2775 dir               # ⭐ SetGID
$ chmod 1777 dir               # ⭐ Sticky Bit

# 소유권
$ sudo chown user file.txt
$ sudo chown user:group file.txt      # ⭐
$ sudo chown -R user:group dir/
$ sudo chgrp group file.txt

# 기본 권한
$ umask                        # 확인
$ umask 022                    # ⭐ 파일 644, 디렉터리 755

# ACL
$ getfacl file.txt             # ⭐
$ setfacl -m u:devuser:rw file.txt    # ⭐
$ setfacl -x u:devuser file.txt
$ setfacl -b file.txt          # 전체 제거

# 파일 속성
$ lsattr file.txt
$ sudo chattr +i file.txt      # ⭐ 변경 불가 (root도)
$ sudo chattr -i file.txt
```

| 권한 | 값 | 파일 | 디렉터리 |
| --- | --- | --- | --- |
| **r** | 4 | 내용 읽기 | **목록 조회** |
| **w** | 2 | 내용 수정 | **파일 생성·삭제** ⭐ |
| **x** | 1 | 실행 | **진입(cd)** |

### 12. 실무 관용구 모음

```bash
# 큰 파일 상위 10개 찾기 ⭐
$ sudo find / -type f -size +100M -exec ls -lh {} \; 2>/dev/null | \
    awk '{print $5, $9}' | sort -rh | head -10

# 30일 지난 로그 삭제
$ sudo find /var/log -name "*.log" -mtime +30 -delete

# 디렉터리별 용량 (큰 것부터) ⭐
$ du -h --max-depth=1 /var 2>/dev/null | sort -rh | head -10

# 설정 파일에서 실제 설정만 ⭐
$ grep -vE "^#|^$" /etc/ssh/sshd_config

# 확장자 일괄 변경
$ for f in *.txt; do mv "$f" "${f%.txt}.md"; done

# 파일 안전하게 백업 후 수정 ⭐
$ cp -p file.conf file.conf.$(date +%F)
$ sudo sed -i.bak 's/old/new/g' file.conf

# 특정 문자열이 포함된 파일 찾기
$ grep -rl "password" /etc 2>/dev/null

# 빈 파일·디렉터리 정리
$ find /tmp -type f -empty -delete
$ find /tmp -type d -empty -delete

# 권한 일괄 정리 (디렉터리 755, 파일 644) ⭐
$ find /var/www -type d -exec chmod 755 {} +
$ find /var/www -type f -exec chmod 644 {} +

# 최근 변경된 설정 파일 확인 (침해 점검) ⭐
$ sudo find /etc -mtime -7 -type f 2>/dev/null

# 디스크 사용률 경고 대상 ⭐
$ df -h | awk '$5+0 >= 85 {print $6" "$5}'
```

### 한 줄 정리

파일 작업의 핵심은 **`find`(조건 검색) + `grep`(내용 검색) + `awk`/`sed`(가공)** 조합이며,  
`tar`는 **`c`(생성)/`x`(해제)/`t`(목록)** 에 **`z`(gzip)** 를 붙이고 **`f`는 항상 마지막**,  
`ls -ld`(디렉터리 자체)·`tail -f`(실시간)·`sort | uniq -c`(집계)는 실무에서 매일 쓰는 관용구입니다.
