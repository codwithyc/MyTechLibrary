## 063. 인터넷 서비스

### 1. WWW(World Wide Web)

- 인터넷에서 **하이퍼텍스트 방식으로 정보를 제공**하는 서비스입니다.
- **HTTP** 프로토콜을 사용하며, **웹 브라우저**를 통해 이용합니다.
- 문자, 그림, 소리, 동영상 등 **멀티미디어 정보를 통합**하여 제공합니다.

#### 왜 웹이 인터넷의 대표 서비스가 되었을까?

이전의 인터넷 서비스(FTP, TELNET, 고퍼)는 **명령어를 알아야** 사용할 수 있었습니다.

웹은 **링크를 클릭하는 것만으로** 원하는 정보로 이동할 수 있고,  
그림과 영상까지 함께 볼 수 있습니다.

즉, 웹은 **인터넷을 전문가의 도구에서 일반인의 도구로 바꾼 서비스**입니다.

---

### 2. 전자 우편(E-mail)

인터넷을 통해 편지를 주고받는 서비스입니다.

**전자 우편 주소 형식** : `사용자ID@호스트주소` (예: `user@example.com`)

**관련 프로토콜**

| 프로토콜 | 역할 |
| --- | --- |
| **SMTP** | 메일을 **보낼 때** 사용합니다. |
| **POP3** | 메일을 서버에서 **내려받을 때** 사용합니다. |
| **IMAP** | 메일을 **서버에 두고 관리**할 때 사용합니다. |
| **MIME** | 메일에 **멀티미디어 파일을 첨부**할 수 있게 합니다. |

**주요 기능**

| 기능 | 설명 |
| --- | --- |
| **참조(CC)** | 참고로 함께 받을 사람을 지정합니다. **모든 수신자에게 공개**됩니다. |
| **숨은 참조(BCC)** | 함께 받을 사람을 지정하되, **다른 수신자에게는 보이지 않습니다.** |
| 회신(Reply) | 받은 메일의 발신자에게 답장합니다. |
| 전체 회신 | 발신자와 참조된 모든 사람에게 답장합니다. |
| 전달(Forward) | 받은 메일을 다른 사람에게 그대로 보냅니다. |
| 첨부 파일 | 문서나 이미지 등을 함께 보냅니다. |

#### 왜 숨은 참조가 필요할까?

여러 사람에게 같은 메일을 보낼 때, 참조(CC)를 쓰면  
**모든 수신자의 메일 주소가 서로에게 공개**됩니다.

이는 개인 정보 노출이며, 스팸 발송에 악용될 수도 있습니다.

숨은 참조(BCC)를 사용하면 각 수신자는 **자신만 받은 것처럼** 보게 되므로,  
다수에게 안내 메일을 보낼 때 안전합니다.

### 3. FTP(File Transfer Protocol)

- 인터넷을 통해 **파일을 전송하는 서비스**입니다.
- **업로드(올리기)** 와 **다운로드(내려받기)** 를 모두 지원합니다.
- **익명 FTP(Anonymous FTP)** : 계정이 없어도 `anonymous` 라는 ID로 접속할 수 있습니다.

**전송 모드**

| 모드 | 대상 |
| --- | --- |
| **ASCII 모드** | 텍스트 파일 (`.txt`, `.htm`, 소스 코드) |
| **Binary 모드** | 그림, 음악, 동영상, 실행 파일, 압축 파일 |

#### 왜 전송 모드를 나눌까?

운영체제마다 **줄 바꿈을 표현하는 방식**이 다릅니다.

- Windows : `CR + LF`
- UNIX/Linux : `LF`

ASCII 모드는 전송하면서 이 차이를 **자동으로 변환**해 줍니다.

그런데 이미지나 실행 파일에 이런 변환을 적용하면,  
**데이터가 변형되어 파일이 손상**됩니다.

그래서 텍스트가 아닌 파일은 반드시 **Binary 모드(있는 그대로 전송)** 를 사용해야 합니다.

### 4. 그 밖의 인터넷 서비스

| 서비스 | 설명 |
| --- | --- |
| **텔넷(TELNET)** | 원격지의 컴퓨터에 접속하여 **직접 조작**하는 서비스입니다. |
| **아키(Archie)** | FTP 서버의 파일을 검색하는 서비스입니다. |
| **고퍼(Gopher)** | 메뉴 방식으로 정보를 검색하는 서비스입니다. (웹 이전에 사용) |
| **유즈넷(Usenet)** | 주제별 게시판을 통해 정보를 교환합니다. |
| **IRC** | 실시간 채팅 서비스입니다. |
| **WAIS** | 여러 데이터베이스를 검색하는 서비스입니다. |
| **VoIP** | 인터넷을 이용한 음성 통화 서비스입니다. |
| **IPTV** | 인터넷을 통해 방송 콘텐츠를 제공하는 서비스입니다. |
| **스트리밍(Streaming)** | 파일을 **모두 내려받기 전에 재생을 시작**하는 기술입니다. |
| **클라우드 컴퓨팅** | 인터넷상의 서버에 데이터를 저장하고, 필요할 때 어디서든 이용하는 서비스입니다. |

#### 왜 스트리밍 기술이 필요할까?

2시간짜리 영화 파일을 전부 내려받으려면 오래 걸립니다.  
사용자는 그동안 아무것도 볼 수 없습니다.

스트리밍은 **앞부분부터 조금씩 받으면서 동시에 재생**합니다.

즉, "다 받고 본다"가 아니라 **"받으면서 본다"** 는 방식으로,  
대기 시간을 없애고 저장 공간도 차지하지 않습니다.

#### 왜 클라우드 컴퓨팅이 확산되었을까?

기존에는 파일을 특정 컴퓨터에 저장했으므로,  
그 컴퓨터가 없으면 작업할 수 없었습니다.

클라우드는 데이터를 인터넷상의 서버에 두므로

- **어느 기기에서든 같은 자료에 접근**할 수 있고
- 기기가 고장 나도 **자료를 잃지 않으며**
- 필요한 만큼만 **용량과 성능을 빌려 쓸 수 있습니다.**

다만 **인터넷 연결이 필수**이고, **보안과 개인 정보 관리**를 서비스 제공자에게 의존하게 된다는 점은 단점입니다.

### 5. 인터넷 서비스 관련 용어

| 용어 | 설명 |
| --- | --- |
| **웹 호스팅** | 서버의 일부 공간을 빌려 웹 사이트를 운영하는 서비스입니다. |
| **쿠키(Cookie)** | 웹 사이트가 사용자의 컴퓨터에 저장하는 **작은 정보 파일**입니다. |
| **캐시(Cache)** | 자주 사용하는 데이터를 저장해 두어 **다시 불러올 때 빠르게** 표시합니다. |
| **북마크 / 즐겨찾기** | 자주 방문하는 사이트의 주소를 저장합니다. |
| **RSS** | 사이트의 새 글을 자동으로 받아 보는 기능입니다. |
| **SNS** | 온라인에서 사람들과 관계를 맺고 소통하는 서비스입니다. |

#### 왜 쿠키가 필요하면서도 논란이 될까?

HTTP는 원래 **이전 요청을 기억하지 않는(무상태) 프로토콜**입니다.

그래서 로그인 상태 유지나 장바구니 기능을 구현하려면,  
**사용자를 구분할 정보를 어딘가에 저장**해야 합니다.

쿠키는 이 정보를 사용자의 컴퓨터에 저장하는 방법입니다.

다만 쿠키에는 **방문 기록과 관심사**가 담기므로,  
광고 추적에 활용되면서 개인 정보 침해 논란이 발생합니다.

---

### 한 줄 정리

인터넷 서비스는 **WWW(HTTP), 전자 우편(SMTP·POP3·IMAP·MIME), FTP, TELNET** 이 대표적이며,  
**FTP는 텍스트는 ASCII·나머지는 Binary 모드**로 전송하고,  
**스트리밍은 받으면서 재생하는 기술**입니다.
