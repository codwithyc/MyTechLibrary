## 001. 한글 Windows 10의 특징

### 1. 한글 Windows 10의 특징

> 한글 Windows 10 운영체제는 컴퓨터 시스템의 하드웨어를 효율적으로 관리하고 사용자에게는  
더 편리한 컴퓨터 환경을 제공하기 위하여 만들어진 운영체제로 다음과 같은 특징이 있습니다.

한글 Windows 10의 특징에는 어떤 것들이 있어야 되는지 알고 있어야 합니다.
OLE와 PnP 기능을 중심으로 숙지해야 합니다.

| 항목 | 설명 |
|---|---|
| 그래픽 사용자 인터페이스(GUI : Graphical User Interface) | 키보드로 명령어를 직접 입력하지 않고, 아이콘이나 메뉴를 마우스로 선택하여 모든 작업을 수행하는 사용자 작업 환경을 말합니다.<br><br>한글 Windows 10은 초보자도 쉽게 사용할 수 있는 그래픽 사용자 인터페이스(GUI)를 채용하였습니다. |
| 선점형 멀티태스킹 (Preemptive Multi-tasking) | 운영체제가 각 작업의 CPU 이용 시간을 제어하여 앱 실행 중 문제가 발생하면 해당 앱을 강제 종료시키고, 모든 시스템 자원을 반환하는 멀티태스킹 운영 방식을 말합니다. |
| 플러그 & 플레이 (자동감지장치 : PnP, Plug & Play) | 컴퓨터 시스템에 하드웨어를 설치했을 때, 해당 하드웨어를 사용하는 데 필요한 시스템 환경을 운영체제가 자동으로 구성해 주는 것을 말합니다.<br><br>운영체제가 하드웨어의 규격을 자동으로 인식해 시스템 환경을 설명해 주기 때문에 PC 주변기기를 연결할 때 사용자가 직접 환경을 설정하지 않아도 됩니다.<br><br>플러그 앤 플레이 기능을 활용하기 위해서는 하드웨어와 소프트웨어 모두 플러그 앤 플레이를 지원해야 합니다.<br><br>하드웨어의 IRQ, DMA 채널, I/O 주소들이 충돌하지 않도록 설정합니다. |
| OLE(Object Linking and Embedding) | 다른 여러 앱에서 작성된 문자나 그림 등의 개체(Object)를 현재 작성 중인 문서에서 자유롭게 연결(Linking) 하거나 삽입(Embedding)하여 편집할 수 있게 하는 기능입니다.<br><br>OLE로 연결된 이미지를 원본 앱에서 수정하거나 편집하면 그 내용이 그대로 해당 문서에 반영됩니다. |
| 255자의 긴 파일 이름 | 최대 255자의 긴 파일 이름을 지정할 수 있습니다.<br><br>NTFS에서는 유니코드 문자를 지원하여 세계 여러 문자를 파일 이름에 사용할 수 있습니다.<br><br>파일 이름으로는 `\ / : * ? " < > |` 를 제외한 모든 문자 및 공백을 사용할 수 있습니다. |
| 64비트 데이터 처리 | 완전한 64비트로 데이터를 처리하므로 더 많은 양의 데이터를 빠르게 처리할 수 있으며, 사용자에게 좀 더 빠르고 효율적인 시스템을 구축할 수 있게 합니다. |
