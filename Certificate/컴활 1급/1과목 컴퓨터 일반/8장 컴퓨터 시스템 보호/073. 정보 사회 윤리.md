## 073. 정보 사회 윤리

### 1. 정보 윤리의 필요성

정보 윤리는 **정보를 다루는 과정에서 지켜야 할 도덕적 기준**입니다.

#### 왜 정보 사회에 별도의 윤리가 필요할까?

인터넷 공간은 현실과 다음과 같은 차이가 있습니다.

| 특성 | 결과 |
| --- | --- |
| **익명성** | 자신을 드러내지 않으므로 책임 의식이 약해집니다. |
| **비대면성** | 상대의 반응을 직접 보지 못해 **피해를 실감하기 어렵습니다.** |
| **광범위성** | 잘못된 행동의 영향이 순식간에 널리 퍼집니다. |
| **비가역성** | 한 번 퍼진 정보는 **완전히 지우기 어렵습니다.** |

현실에서는 잘 지켜지던 규범도 이런 환경에서는 쉽게 무너집니다.

그래서 정보 사회에서는 법적 규제뿐 아니라  
**사용자 스스로의 윤리 의식**이 더욱 중요해집니다.

### 2. 정보 윤리의 기본 원칙

| 원칙 | 설명 |
| --- | --- |
| **존중** | 타인의 인격과 권리를 존중합니다. |
| **책임** | 자신의 행동과 그 결과에 책임을 집니다. |
| **정의** | 정보를 공정하게 이용하고 배분합니다. |
| **해악 금지** | 타인에게 피해를 주지 않습니다. |

### 3. 네티켓(Netiquette)

**Network + Etiquette** 의 합성어로, **인터넷상에서 지켜야 할 예절**입니다.

**전자 우편 사용 시**

- 제목은 **내용을 알 수 있도록 간결하게** 작성합니다.
- 메일 마지막에 **서명(이름, 소속, 연락처)** 을 넣습니다.
- 용량이 큰 파일은 **압축하여 첨부**합니다.
- 수신자가 여러 명일 때는 **숨은 참조(BCC)** 를 활용합니다.
- 전자 우편은 **누구나 볼 수 있다는 전제**로 작성합니다.
- 스팸 메일과 행운의 편지를 보내지 않습니다.

**게시판 사용 시**

- 게시판의 **성격에 맞는 글**을 올립니다.
- 글의 제목에 내용을 알 수 있는 표현을 사용합니다.
- **사실만 정확하게** 전달하고, 근거 없는 내용을 올리지 않습니다.
- 타인을 **비방하거나 욕설을 사용하지 않습니다.**
- 같은 글을 여러 게시판에 **중복해서 올리지 않습니다.**

**대화방(채팅) 사용 시**

- 대화방에 들어가면 **간단히 인사**를 합니다.
- 존칭을 사용하고, 상대방을 배려합니다.
- **은어나 지나친 약어 사용을 자제**합니다.
- 대화방을 나갈 때는 **인사를 하고 나갑니다.**

**공개 자료실 사용 시**

- 자료는 **바이러스 검사 후** 올립니다.
- 프로그램을 올릴 때는 **사용법과 주의 사항**을 함께 적습니다.
- **불법 소프트웨어를 올리지 않습니다.**
- 상업용 소프트웨어는 올리지 않습니다.

#### 왜 자료를 올릴 때 바이러스 검사가 필요할까?

공개 자료실은 **많은 사람이 내려받는 곳**입니다.

감염된 파일 하나가 올라가면,  
**내려받은 모든 사람에게 그대로 전파**됩니다.

즉, 자료실에서의 부주의는 **한 사람의 실수가 아니라 다수의 피해**로 이어집니다.

### 4. 사이버 범죄와 부적절한 행위

| 행위 | 설명 |
| --- | --- |
| **사이버 폭력 / 명예 훼손** | 온라인에서 타인을 비방하거나 모욕합니다. |
| **개인 정보 침해** | 타인의 개인 정보를 무단으로 수집·유포합니다. |
| **불법 복제** | 소프트웨어나 콘텐츠를 무단으로 복제·배포합니다. |
| **해킹** | 허가 없이 시스템에 침입합니다. |
| **스팸 메일** | 원하지 않는 광고성 메일을 대량 발송합니다. |
| **음란물 유포** | 유해한 콘텐츠를 배포합니다. |
| **허위 정보 유포** | 사실이 아닌 정보를 퍼뜨려 혼란을 일으킵니다. |

#### 왜 온라인 명예 훼손이 더 심각할까?

오프라인의 말은 **그 자리의 사람들에게만** 전달되고, 시간이 지나면 잊힙니다.

온라인의 글은

- **불특정 다수**에게 전달되고
- **검색을 통해 계속 발견**되며
- 복사·저장되어 **삭제해도 완전히 사라지지 않습니다.**

이 때문에 온라인에서의 명예 훼손은 피해의 **범위와 지속 기간**이 훨씬 큽니다.

### 5. 관련 법률과 제도

| 법률 / 제도 | 내용 |
| --- | --- |
| **개인정보 보호법** | 개인 정보의 수집·이용·제공에 관한 기준을 규정합니다. |
| **정보통신망법** | 정보통신망의 이용 촉진과 정보 보호에 관한 사항을 규정합니다. |
| **저작권법** | 저작물의 창작자 권리를 보호합니다. |
| **잊힐 권리** | 자신에 관한 정보의 삭제를 요구할 수 있는 권리입니다. |
| **정보통신 윤리 위원회** | 유해 정보를 심의하고 규제합니다. |

#### 왜 "잊힐 권리"라는 개념이 생겼을까?

인터넷은 **한 번 올라간 정보를 계속 보관하고 검색 가능하게** 만듭니다.

그래서 과거의 실수나 이미 해결된 일이  
**평생 따라다니며 불이익을 주는 상황**이 발생합니다.

잊힐 권리는 **"시간이 지나면 잊히는 것이 자연스럽다"** 는 현실 세계의 원리를  
온라인에서도 보장하기 위한 개념입니다.

### 6. 개인 정보 보호 실천

- 비밀번호는 **주기적으로 변경**하고, 사이트마다 **다르게** 사용합니다.
- 개인 정보를 요구하는 사이트는 **신뢰성을 확인**합니다.
- 공용 컴퓨터에서는 **로그아웃과 기록 삭제**를 반드시 수행합니다.
- 출처가 불분명한 메일의 **첨부 파일과 링크는 열지 않습니다.**
- SNS에 **과도한 개인 정보를 공개하지 않습니다.**

#### 왜 사이트마다 다른 비밀번호를 써야 할까?

한 사이트에서 비밀번호가 유출되면,  
공격자는 같은 아이디와 비밀번호로 **다른 사이트에도 로그인을 시도**합니다.  
이를 **크리덴셜 스터핑**이라고 합니다.

모든 사이트에서 같은 비밀번호를 쓴다면,  
**한 곳의 유출이 곧 모든 계정의 유출**이 됩니다.

---

### 한 줄 정리

정보 사회 윤리는 **익명성·비대면성 때문에 약해지기 쉬운 책임 의식을 보완하기 위한 기준**이며,  
네티켓은 **전자 우편·게시판·대화방·자료실** 상황별로 정리해 두면 시험에 대비하기 좋습니다.
