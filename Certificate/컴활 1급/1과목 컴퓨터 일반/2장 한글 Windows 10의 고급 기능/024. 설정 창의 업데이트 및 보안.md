## 024. 설정 창의 업데이트 및 보안

### 1. Windows 업데이트

Microsoft가 제공하는 **보안 패치, 오류 수정, 기능 개선 사항**을 내려받아 설치하는 기능입니다.

| 항목 | 설명 |
| --- | --- |
| 업데이트 확인 | 새로운 업데이트가 있는지 즉시 확인합니다. |
| 업데이트 일시 중지 | 최대 35일까지 업데이트를 미룹니다. |
| 활성 시간 변경 | 컴퓨터를 주로 사용하는 시간대를 지정하여, 그 시간에는 자동 재시작을 하지 않습니다. |
| 업데이트 기록 보기 | 설치된 업데이트 목록을 확인하고 제거합니다. |
| 고급 옵션 | 다른 Microsoft 제품 업데이트, 데이터 통신 연결에서의 다운로드 허용 등을 설정합니다. |

#### 왜 업데이트를 미루지 말아야 할까?

업데이트의 상당수는 **이미 발견된 보안 취약점을 막기 위한 패치**입니다.

취약점이 공개되면 공격자도 그 내용을 알게 되므로,  
업데이트를 하지 않은 컴퓨터는 **공격 방법이 알려진 상태로 방치**되는 셈입니다.

즉, 업데이트는 새로운 기능을 얻는 것보다  
**이미 알려진 위험을 제거하는 목적**이 더 큽니다.

#### 왜 "활성 시간"을 설정할까?

업데이트 후에는 재시작이 필요한 경우가 많습니다.  
작업 도중에 갑자기 재시작되면 저장하지 않은 내용이 사라질 수 있습니다.

활성 시간은 **사용자가 컴퓨터를 쓰는 시간대를 미리 알려 주어**,  
그 시간을 피해 재시작하도록 만드는 설정입니다.

### 2. Windows 보안

Windows에 내장된 보안 기능을 관리합니다.

| 항목 | 기능 |
| --- | --- |
| **바이러스 및 위협 방지** | Windows Defender를 통해 악성 코드를 검사하고 제거합니다. (빠른 검사 / 전체 검사 / 사용자 지정 검사 / 오프라인 검사) |
| 계정 보호 | 로그인 관련 보안 상태를 확인합니다. |
| **방화벽 및 네트워크 보호** | 허용되지 않은 외부 접근을 차단합니다. |
| 앱 및 브라우저 컨트롤 | 검증되지 않은 앱과 위험한 웹 사이트를 차단합니다. (SmartScreen) |
| 장치 보안 | 하드웨어 기반 보안 기능의 상태를 확인합니다. |
| 장치 성능 및 상태 | 저장소 용량, 배터리, 앱 상태를 점검합니다. |
| 가족 옵션 | 자녀 보호 설정을 관리합니다. |

#### 왜 방화벽이 필요할까?

인터넷에 연결된 컴퓨터는 외부에서 접속을 시도할 수 있는 **여러 개의 통로(포트)** 를 가지고 있습니다.

이 통로를 모두 열어 두면 누구나 접근할 수 있게 됩니다.

방화벽은 **어떤 통신을 허용하고 어떤 것을 막을지 판단하는 관문**으로,  
필요한 통신만 통과시키고 나머지는 차단합니다.

### 3. 백업

| 항목 | 설명 |
| --- | --- |
| 파일 히스토리 | 지정한 폴더의 파일을 주기적으로 다른 드라이브에 백업하여, 이전 버전으로 되돌릴 수 있게 합니다. |
| 이전 백업 찾기 | 이전 Windows 버전에서 만든 백업을 복원합니다. |

#### 왜 백업 드라이브를 따로 두어야 할까?

백업의 목적은 **원본을 잃었을 때 대비하는 것**입니다.

원본과 백업이 같은 디스크에 있다면, 디스크가 고장 났을 때 **둘 다 함께 사라집니다.**

그래서 백업은 반드시 **다른 물리적 저장 장치**(외장 하드, 네트워크 드라이브 등)에 보관해야 의미가 있습니다.

### 4. 복구

시스템에 문제가 생겼을 때 이전 상태로 되돌리는 기능입니다.

| 항목 | 설명 |
| --- | --- |
| **이 PC 초기화** | Windows를 다시 설치합니다. **'내 파일 유지'** 와 **'모든 항목 제거'** 중 선택할 수 있습니다. |
| 고급 시작 옵션 | 안전 모드, 시동 복구, 명령 프롬프트, 시스템 복원 등으로 진입합니다. |

**시스템 복원(System Restore)**

- 시스템 파일과 레지스트리를 **특정 시점(복원 지점)의 상태로 되돌립니다.**
- **개인 파일(문서, 사진 등)은 삭제되지 않습니다.**
- 복원 지점은 프로그램 설치나 업데이트 전에 자동으로 만들어지며, 사용자가 직접 만들 수도 있습니다.

#### 왜 시스템 복원은 개인 파일을 건드리지 않을까?

문제의 원인은 대부분 **프로그램 설치나 드라이버 변경 같은 시스템 변경**입니다.  
사용자가 작성한 문서 때문에 시스템이 망가지는 일은 거의 없습니다.

그래서 시스템 복원은 **시스템 영역만 되돌리고 개인 파일은 그대로 유지**하여,  
"문제만 해결하고 작업물은 지킨다"는 목적을 달성합니다.

### 5. 문제 해결 / 개발자용

| 항목 | 설명 |
| --- | --- |
| 문제 해결 | 인터넷 연결, 오디오, 프린터, Windows 업데이트 등의 문제를 자동으로 진단하고 해결합니다. |
| 개발자용 | 개발자 모드를 켜서 서명되지 않은 앱을 설치하거나 원격 디버깅을 허용합니다. |

---

### 한 줄 정리

[업데이트 및 보안]에서는 **Windows 업데이트, Windows Defender(바이러스·방화벽), 백업, 복구**를 관리하며,  
**시스템 복원은 시스템 영역만 되돌리고 개인 파일은 유지**한다는 점이 핵심입니다.
