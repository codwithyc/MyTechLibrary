## 065. 정보통신 기술 활용

### 1. 사물 인터넷(IoT, Internet of Things)

- 사물에 **센서와 통신 기능을 넣어 인터넷에 연결**하고, 사물끼리 정보를 주고받는 기술입니다.
- 예 : 스마트 홈, 스마트 워치, 스마트 팩토리, 커넥티드 카

#### 왜 사물 인터넷이 주목받을까?

기존에는 **사람이 정보를 입력**해야 컴퓨터가 무언가를 알 수 있었습니다.

IoT는 사물이 **스스로 상태를 측정하고 알려 줍니다.**

- 냉장고가 재고를 파악하고
- 공장의 기계가 고장 징후를 미리 알리고
- 자동차가 도로 상황을 주고받습니다.

즉, IoT는 **사람의 개입 없이 현실 세계의 데이터를 수집하는 통로**를 만들어 줍니다.

---

### 2. 클라우드 컴퓨팅(Cloud Computing)

인터넷상의 서버에 데이터를 저장하고, **필요할 때 필요한 만큼 자원을 빌려 쓰는** 방식입니다.

| 서비스 유형 | 제공 범위 |
| --- | --- |
| **IaaS(Infrastructure as a Service)** | 서버, 저장 공간, 네트워크 등 **인프라**를 제공합니다. |
| **PaaS(Platform as a Service)** | 개발과 실행에 필요한 **플랫폼(개발 환경)** 을 제공합니다. |
| **SaaS(Software as a Service)** | 완성된 **소프트웨어**를 인터넷으로 제공합니다. (웹메일, 온라인 문서 도구) |

#### 왜 "빌려 쓰는" 방식이 유리할까?

직접 서버를 구축하려면

- 최대 사용량에 맞춰 장비를 구입해야 하고
- 그 장비는 평소에 대부분 **놀게 됩니다.**
- 고장 나면 직접 관리해야 합니다.

클라우드는 **쓴 만큼만 비용을 내고**, 필요하면 즉시 늘리거나 줄일 수 있습니다.

즉, 클라우드의 본질은 저장 공간이 아니라  
**"소유에서 사용으로"의 전환**입니다.

### 3. 빅데이터(Big Data)

기존 방식으로는 처리하기 어려운 **방대한 양의 데이터**와 이를 분석하는 기술입니다.

**빅데이터의 특징(3V)**

| 요소 | 설명 |
| --- | --- |
| **Volume(규모)** | 데이터의 양이 매우 큽니다. |
| **Velocity(속도)** | 데이터가 매우 빠르게 생성되고 처리되어야 합니다. |
| **Variety(다양성)** | 정형 데이터뿐 아니라 텍스트, 이미지, 영상 등 **비정형 데이터**를 포함합니다. |

> 여기에 **Value(가치)**, **Veracity(정확성)** 를 더해 4V, 5V로 설명하기도 합니다.

### 4. 인공지능(AI)과 관련 기술

| 용어 | 설명 |
| --- | --- |
| **인공지능(AI)** | 인간의 학습·추론·판단 능력을 컴퓨터로 구현하는 기술입니다. |
| **머신 러닝(기계 학습)** | 데이터를 학습하여 스스로 규칙을 찾아내는 기술입니다. |
| **딥 러닝** | 인공 신경망을 여러 층으로 쌓아 복잡한 패턴을 학습하는 기술입니다. |

#### 왜 머신 러닝이 필요할까?

기존 프로그램은 **사람이 규칙을 전부 알려 주어야** 동작합니다.

그런데 "고양이 사진을 알아보라"는 문제는  
규칙을 말로 정의하기가 거의 불가능합니다.

머신 러닝은 **수많은 예시를 보여 주고 스스로 규칙을 찾게 하는 방식**입니다.

즉, "어떻게 하는지 알려 주기" 대신 **"많이 보여 주고 배우게 하기"** 로 접근 방식을 바꾼 것입니다.

### 5. 가상 현실 관련 기술

| 용어 | 설명 |
| --- | --- |
| **VR(가상 현실)** | 컴퓨터로 만든 **완전한 가상 공간**을 체험합니다. |
| **AR(증강 현실)** | **현실 화면 위에 가상 정보를 겹쳐서** 보여 줍니다. |
| **MR(혼합 현실)** | VR과 AR을 결합하여 현실과 가상이 상호 작용합니다. |
| **메타버스** | 현실과 연결된 3차원 가상 세계에서 사회·경제 활동을 하는 공간입니다. |

#### VR vs AR

| 구분 | VR | AR |
| --- | --- | --- |
| 배경 | **완전한 가상** | **실제 현실** |
| 몰입도 | 높음 | 상대적으로 낮음 |
| 예 | VR 게임, 가상 훈련 | 스마트폰 길 안내, 가구 배치 앱 |

### 6. 그 밖의 정보통신 기술

| 용어 | 설명 |
| --- | --- |
| **블록체인(Blockchain)** | 거래 기록을 **여러 참여자가 나누어 저장**하여 위조를 어렵게 만드는 기술입니다. |
| **핀테크(FinTech)** | 금융(Finance)과 기술(Technology)의 결합으로, 간편 결제·송금 서비스를 제공합니다. |
| **웨어러블 기기** | 몸에 착용하는 형태의 기기입니다. (스마트 워치, 스마트 밴드) |
| **텔레매틱스** | 통신과 자동차를 결합하여 차량에 정보 서비스를 제공합니다. |
| **RFID** | 무선 주파수로 태그의 정보를 읽습니다. 물류·출입 관리에 사용합니다. |
| **NFC** | 10cm 이내의 근거리 무선 통신 기술입니다. 모바일 결제에 사용합니다. |
| **위치 기반 서비스(LBS)** | 사용자의 위치 정보를 활용한 서비스입니다. |
| **유비쿼터스(Ubiquitous)** | **언제 어디서나** 네트워크에 접속하여 정보를 이용할 수 있는 환경입니다. |
| **그리드 컴퓨팅** | 여러 컴퓨터의 자원을 연결하여 하나의 고성능 컴퓨터처럼 사용합니다. |
| **유틸리티 컴퓨팅** | 필요한 만큼 컴퓨팅 자원을 사용하고 사용량만큼 비용을 지불합니다. |
| **트랙백(Trackback)** | 다른 블로그 글에 자신의 글을 링크로 연결하는 기능입니다. |
| **스마트 그리드** | 전력망에 정보 기술을 접목하여 에너지 효율을 높입니다. |

#### 왜 블록체인은 위조가 어려울까?

일반적인 시스템은 거래 기록을 **중앙 서버 한 곳에 보관**합니다.  
그 서버를 조작하면 기록을 바꿀 수 있습니다.

블록체인은 같은 기록을 **모든 참여자가 나누어 보관**하고,  
각 블록이 **이전 블록의 정보를 포함**하도록 연결되어 있습니다.

따라서 하나의 기록을 바꾸려면

- 그 이후의 모든 블록을 다시 계산해야 하고
- **참여자 대다수의 사본을 동시에** 바꿔야 합니다.

이것이 현실적으로 불가능하기 때문에 **위조가 어렵다**고 말합니다.

---

### 한 줄 정리

정보통신 기술은 **IoT(사물 연결) → 빅데이터(수집된 데이터) → 클라우드(처리 자원) → AI(분석·판단)** 로 이어지는 흐름으로 이해하면 정리하기 쉽고,  
**VR은 완전한 가상, AR은 현실 위에 정보를 겹치는 방식**입니다.
